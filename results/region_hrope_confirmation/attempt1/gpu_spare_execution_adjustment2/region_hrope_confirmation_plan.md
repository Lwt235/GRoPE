# 同相机信息的区域PE：未用地点上的对齐确认

2026-11-09。本方案承接已完成的[HRoPE旧数据比较](../results/region_hrope_control/attempt1/report.md)。保留原[四方法确认计划](region_pose_confirmation_plan.md)和元数据冻结记录，采用其中预先选定的十地点及机械取帧规则；模型替换为最新同相机信息的五方法×三个种子，共15个已选checkpoint。新像素开放前固定本方案、全部权重、源码与评分规则。

## 问题与竞争解释

旧五场景HRoPE比F/Distance/Geo的对齐成功率高3.194/5.903/5.417 pp，三种子及联合区间正。F−Distance仍有+2.708 pp平均收益，但区间跨零。要确认的是：这些相对关系能否迁移到未使用地点，还是依赖旧开发场景。完整五维保持不变；HRoPE不是新的高斯方法，也不能用其胜出来宣称原高斯研究目标完成。

全部方法共同输入原11维区域特征、3维中心、6维形状和8维相机信息；HRoPE继续原self/cross接法，其余四组保持原self接法。比较包括编码形式及作用层，不能单独归因于协方差或跨视图作用。无真实外参进入模型，无RGB、预训练编码器、重训、适配、选模、温度搜索或附加模块。

## 固定模型、数据与执行

模型来自`results/region_hrope_control/attempt1/selected.json`：relative5、distance_mlp、geotransformer_rpe、fixed_isotropic5、predicted_hrope各11/22/33。保持原FP32、batch16、TF32关闭、共同匹配头和top1对应规则。15份权重全部在新像素前固定，不按新数据表现剔除方法或种子。

沿用`results/region_pose_confirmation/preparation/cohort_lock.json`与已完成元数据选择。brown/harvard/home/hotel/mit各两个地点，机械选取每场景96对、总960对；十场景元数据均可用。排除清单、盐、首次子扫描与原查询间隔全部保持。仅下载已选帧的深度，官方SUN3D直连、禁用代理、最多4并发，保存在用户指定数据盘原`GRoPE/region_pose_confirmation_20261109/raw`目录。缓存另存`camera_matched_cache`，与旧四方法草稿隔离。

每帧从完整观测均值与pair尺度归一化后固定抽512点，按原tokenize构造64区域/32成员，所有方法使用同一缓存。成员平均像素和归一化K由原`camera_fields`计算，不接收位姿或对应标签；世界坐标仅生成标签和评分真值。预处理采用CPU4保持与已核对的旧相机恢复路径一致；学习模型推理及大批量刚体求解用GPU。

少于512观测点时按原规则登记排除；不能按重叠、预测或误差过滤。固定地点/扫描/帧不替换；网络失败只重试相同来源，缺失完整披露。至少两个可转换场景才计算跨地点区间。报告计划960、实际可转换数量和排除原因；若不完整，不能称完成全部原计划。不同目录名仍不保证不存在未知的物理别名。

## 指标、统计与决定

保持旧刚体估计器：所有64个top1对应、41,664三点假设、0.1归一化一致性半径、最多5次非恶化重估；无置信度门控、ICP或真值筛选。主指标是全部源区域中心对齐RMSE<0.2米，场景等权再种子等权，无解记失败。完整保留旋转、中心化输入坐标平移和RMSE的中位数及p90，并报告恒等与不可部署的真值辅助最近邻诊断。后者不是理论上界。

主比较为F−HRoPE。其余预定比较依次F−Distance、F−Geo、F−固定球形、HRoPE−Distance、HRoPE−Geo；10,000次配对种子×整场景bootstrap，固定种子96001–96006。另报告种子/场景单独区间与逐种子、逐场景效果。同场景的96对不充当96个独立场景。辅助区域R@1、全查询正确比例、中心PCK和soft EPE共同报告，不用辅助指标替换对齐主比较。

对主比较采用对称解释：F−HRoPE均值至少+1 pp、三个种子正且联合95%区间下界>0，支持F有限领先；均值至多−1 pp、三个种子负且联合上界<0，支持HRoPE有限领先；其他情况报告幅度和不确定性。对其余用途比较采用相同的正/负方向规则；F−固定球形另描述额外形状的平均信号，不因跨零就断言零效应。无需全部场景或次指标同向。

若HRoPE领先被确认，收窄当前含相机信息任务中F的强对照主张，保留HRoPE并完整呈现F对其他控制的剩余收益。若排名不稳定，报告迁移不确定；若F反向领先，也只能限定于这批未用地点和固定接法。各结果都结束这次确认，不追加种子、挑地点或调求解器补救。绝对成功率和尾部必须共同解释；任一有限确认都不等于原生3DGS、RGB、稀疏重构或一般性目标完成。

最多四个GPU工作进程，先获取实时空闲GPU并检查CUDA。低显存几何工作可以在只由本控制器占用的卡上并行，不在存在外部进程的卡上新增工作；保留其他用户任务。普通工程失败保留版本后修复，不另起科学轮次，不因无关微小浮点差异扩张门禁。
