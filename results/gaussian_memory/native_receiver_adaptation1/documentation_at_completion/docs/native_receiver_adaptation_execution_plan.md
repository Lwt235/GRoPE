## 科学问题与大纲对应

同一3DGS保存内容、单次输入融合，允许原生接收网络共同学习，是否增加Render相对Local/Global的原生深度净用途？假设为固定接收网络限制了来源内容的利用；竞争解释是内容混合/错配、当前图像已足够、小训练集与泛化、通用任务适配而非memory增益，以及附加上下文选择并非严格嵌套。

服务O4/O5，复用O2/O3，主要改C6。C1/C2保存场景和内容、C3融合结构、C5给定相机保持；C4旧投影修补仍结束，O6增量未由本轮验证。原生网络的可训练范围是实验实现选择，旧数据/来源传感器共同有效性/给定相机/静态和12训练地点都是临时边界，不是导师永久要求。

rendered_feature_native1的固定接收输入融合已完成，R对Local主误差高3.20%，原始缺失/完整AbsRel高18.99%/17.15%；支持ROI对Global低13.60%和绑定依赖25.77%保留。native_gaussian_pe1已有末四层LoRA，无实用PE增量；surface1、joint_write1、write_confirmation1已有联合writer和独立粗头的正负结果。本项不同在于相同真实3DGS保存内容＋完整原生交互层/DPT的任务适配，不是首次适配、首次renderer或新PE。

## 评价与决定

主终点缺失ROI空间log-MSE，主比较新Render/新Local及新Global；配对交互为`(E_R−E_control)_adapted−(E_R−E_control)_frozen`，负值有利于共同训练增加来源相对用途。使用地点/查询等权、配对种子和原5000次重采样；完整原始误差/偏差/AbsRel、全部地点/种子、完整训练集与开发对照、支持分解及成本保留。打乱仅为依赖，不替代重训控制。新预测独立NumPy复算，实际查看总体与固定/最大反例图。

若共同训练下R可靠超过同条件Local/Global且代价可接受，保留接收训练条件，后续另定O6强中心/球形/完整PE比较。若三组均改善但R无净优势，只支持通用任务适配；若训练集改善而开发不改善，保留泛化缺口，结束此固定小数据候选。支持子区或干预敏感只保留有限证据；不据此使用GT门控或晋升整体方法。不要求每个辅助项胜出，不设精确1%门禁，不将此项设为所有PE研究的普遍前置条件。无自动后继研究。
