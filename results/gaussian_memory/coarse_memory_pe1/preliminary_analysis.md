# coarse_memory_pe1：训练期间的初步分析

本分析由用户“目前的已有结果可以进行初步分析吗”触发。只纳入读取评分前已完整结束的配对种子20261110：中心、球形、完整高斯各2000步，12个旧开发地点、完整输入/持续遮挡、256/1024槽，共144份预测。第二种子的中心模型已结束，但其余两组尚未齐备，不混入方法比较。不是最终报告或新确认；训练、比较和取舍规则继续按原计划执行。

假设是：粗记忆代表不同大小与方向的空间区域，范围/协方差可能比强中心位置编码更有用途。竞争解释包括中心已足够、内容聚合损失或预测几何噪声限制收益，以及变化主要对应整体深度偏差。当前比较能够检验是否有增量，不能单独诊断是哪种竞争解释成立。

三组实际初始化、训练样本顺序与容量曝光一致；检查点及预测哈希核对通过。144份预测对原标签用NumPy独立重算，评分最大绝对差9.16e-16。此项检查确认评分实现，不构成方法有效性的证据。详细身份、逐地点结果和均值见`preliminary_analysis.json`，独立分数见`preliminary_independent_rows.json`。

## 持续遮挡：完整高斯相对中心

以下为12地点等权均值的相对误差变化。“降低”为收益，“升高”为退步。

| 记忆容量 | 遮挡区空间误差：去均值log-MSE | 遮挡区总log-MSE | 遮挡区均值偏差平方 |
| --- | --- | --- | --- |
| 256槽，主比较 | 升高0.35% | 降低0.29% | 降低1.10% |
| 1024槽，辅助比较 | 升高0.16% | 降低0.69% | 降低1.35% |

256槽的中心/球形/完整高斯空间误差分别为0.04785425/0.04795969/0.04801983，总误差为0.08573133/0.08539812/0.08547979。完整高斯对中心的主空间误差仅6/12地点改善；全图空间误差也没有平均改善。完整输入条件下，遮挡ROI所对应区域的空间误差仍未优于中心，256/1024槽分别高0.38%/0.27%。

空间指标为区域内去除平均对数深度偏差后的残差方差，是空间结构代理，不能直接等同于完整三维形状或渲染质量。总log-MSE等于该方差加均值偏差平方。256槽完整高斯的总误差绝对降低约0.00025155，来自偏差平方降低约0.00041713，同时空间项增加约0.00016558。因此不能把这部分总误差下降解释为更精确的局部结构恢复。

## 完整形状尚未超越简单范围

持续遮挡256槽，完整高斯比球形的空间/总误差分别高0.13%/0.10%；1024槽空间误差低0.03%，总误差高0.39%。球形相对中心的总误差降低约0.39%/1.07%，但空间误差分别高0.22%/0.19%。当前既未建立完整各向异性形状的额外价值，也未建立球形范围的空间结构收益。

这些细小差异不是实用失败的充分证据，也不能证明等效；现阶段没有达到预期的明确空间增量。仅一个配对种子，地点改善数不能替代跨种子稳定性。1024槽的总误差高于256槽的现象也只能保留为辅助观察，因为容量同时改变粗分组、第一遍查询几何和读取条件，不能据此推导“压缩越强越好”。

## 对研究主线的含义与后续决定

本轮已经消除了上一轮“查询前缀和早期DPT特征先读取完整历史”的绕行条件：两遍查询均从第一层读取粗记忆。即使在这个更直接的接口下，首个种子仍未显现完整高斯的空间收益。因此，不能仅以“存在粗聚合”作为引入协方差PE的充分理由；还需要完成跨种子验证并说明哪个关系产生可重复的额外作用。

继续固定三种子比较及原定冻结粗记忆/官方/单帧参照和成本测量。若后续出现有意义且一致的空间增益，再考虑保留完整形状；若仅简单范围有可靠用途，优先较精炼的表示；若仍主要是偏差变化或方法间近似持平，则按原计划收束这一固定粗记忆读取配置，不继续靠换公式或微小数值筛选追逐正结果。当前不作最终方法取舍。
