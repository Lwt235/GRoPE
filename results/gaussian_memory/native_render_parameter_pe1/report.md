# native_render_parameter_pe1：保留原Render的直接参数Q/K位置编码检验

2026-11-13T00:48:28.551245+00:00。9次配对拟合各2000步、6336新预测与4224继承评分、独立复算、200次完整暖查询成本及两图实际审阅已完成。结果交回同一Astra作方法取舍；实现阶段不选择下一科学方案或宣布总体目标达成。

## 固定问题与方法

本轮检验：在原Render内容、局部合成、覆盖与融合全部保留时，基元intrinsic log-cov作为原生Q/K位置编码，能否超出强中心字段并保持下游用途。竞争解释是中心集合/原Render已足够、球形范围足够、完整形状确有额外用途，或此固定Q/K接法不能使参数产生可用增量。与旧单次输入attention替换及局部/覆盖分解不同，本轮不替换内容读取、不以历史分解残差加做扫描。

三组均有中心均值3、多尺度Fourier30、中心间离散二阶矩6、中心—射线7共46维。末六维P为零、S为同迹球形intrinsic log-cov、G为完整intrinsic log-cov；按原实际合成贡献绑定，FP64构建后FP32保存，保存旋转和正scale直接计算log-cov。共同中心间离散二阶矩不能算成基元协方差独有收益。

唯一共享52→64→1024 MLP（68,928参数，GELU、无末层bias、末层零初始），e=a·PE(z)加入24个既有global attention的patch Q/K，在q_norm/k_norm和原2D RoPE之前；特殊token和零覆盖e=0，V无直接改动。原Render内容r、覆盖a、融合、原生frame/global/DPT保留；没有新增reader/head/gate。P有384个不活跃首层系数，S/G有效容量相同；原Render内容已含高斯信息，P不是移除全部高斯的表示。

44份既有场景（32训练、12开发）、四个静态来源、2048基元及1024维内容只读复用。拟合查询[2,5,8,11]，其他查询[1,4,7,10]，full及中央约25%均值填充missing；448输入、210×210评分。全部是已用数据，其他查询不等于未见场景独立确认。

种子20261110/11/12配对；每fit共同官方预训练重置，原fusion初值与actual schedule精确匹配，PE初始化隔离RNG。637,383,906原生+787,712原fusion+68,928 PE=638,240,546可训练参数；编码器/场景冻结。FP32参数/Adam、原BF16算术，batch2、固定2000步、原loss/两学习率/clip5，不按开发结果选检查点。

主终点为开发原查询缺失ROI centered log-MSE。5000次配对seed/place重采样，seed20261113，地点/查询等权；3种子12开发地点范围有限。至少1%降误差、区间下界>0且三种子同向为预定主筛；材料性开发损伤为至少1%增加且区间支持。均值/训练片段权衡按范围报告，不施加微小负均值零容差。完整字段、终点与决定分支见[事前方案](../../../docs/native_render_parameter_pe_execution_plan.md)。
