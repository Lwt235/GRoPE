# 高斯场景记忆的补缺与保真：固定 A/B/C 实验结果

2026-11-10。十二次新增 GPU 训练、十八个固定模型、十八个开发片段和十二个预定后续片段的全部评分、独立核对及七张图的实际审阅均已完成。

**结论：仅改变监督分配、加入完整输入恒等约束，未使当前单层中心读取获得可迁移的净收益。** 等权监督改善了旧目标的取舍，完整输入约束也能减小扰动；但新片段中，三组中心记忆的全图误差都高于各自配对的无记忆对照。按事前计划结束本轮权重调整，保留共享记忆可学性和旧开发收益，收窄实际 token 接入的用途主张。没有继续扫描权重、层号或挑选检查点。

## 本轮改变了什么

保持冻结 VGGT、原共享写入器/PCA、256 个高斯、最后一层实际 2048 维 patch token、单层残差读取及中心位置项。Local 是 277,202 参数的当前视图 MLP，Center 为 273,604 参数；二者都能学习残差修复。相机已知，四个参考视图一次写入场景记忆，查询图像不参与写入。没有新形状项、门控或推理模块。

| 组别 | 训练目标 | 训练数量 |
| --- | --- | --- |
| A | `0.8 × 遮挡区均值 + 0.2 × 可见区均值` | 复用 Local/Center × 3 种子，共 6 模型 |
| B | 遮挡输入的全部 300 patch 等权 | 新增 Local/Center × 3 种子，共 6 模型 |
| C | B + 独立完整输入的恒等误差，系数固定为 1 | 新增 Local/Center × 3 种子，共 6 模型 |

各次新训练均为 2,000 步、每步两个遮挡样例、AdamW 3e-4/wd .01。B/C 从对应 A 的 `initial.pt` 精确初始化，所有 2,000 步的片段/样本顺序一致。C 每步另处理同两查询的完整 token，作为独立合法输入；完整 token 从未替代遮挡分支输入，也不进入记忆。C 的额外前后向是真实计算开销，不是与 B 等 FLOPs 的比较。所有比较采用第 2,000 步，不作模型选择。

假设是旧训练每个遮挡 patch 约有可见 patch 13.1 倍权重，造成保真代价；竞争解释包括记忆质量、读取层/任务适配和迁移不足。预定判断要求保真改善同时保住相对同条件 Local 的遮挡与全图收益，不能只看完整输入越来越接近恒等。

## 数据与评价边界

训练仍为原三个场景的十二片段、72 查询、288 遮挡样例。开发评价包含同场景留出 36 查询，以及六个未用于这轮优化的旧开发场景共 54 查询。之后固定全部十八模型，再对 R6/R7 十二历史场景中第 80–92 个已下载帧构成的片段提取和评分：每片段四参考、九查询、每查询两个 7×10 patch 遮挡，共 108 查询/216 遮挡样例。图像路径与此前 0–12 和 40–52 两批片段不重叠。

这是一批本设计尚未评分的新片段，**不是全新场景**。片段、视角和遮挡样本均与旧批次不同，不能把成绩变化单独归因为时间跨度或某一几何因素。查询 RGB 在进入冻结 VGGT 前遮挡，各查询独立按 S=1 前向。完整输入 token 是教师/独立完整样例；原高斯记忆只由四参考构建。写入器仍只有原一个训练种子，读取器为三个配对种子。

误差为沿通道 LayerNorm 后的 token MSE。全图直接平均 300 个 patch，等价于 `(70 × 遮挡误差 + 230 × 可见误差) / 300`。完整输入列表示接入适配器后的归一化 token 改变量；它与遮挡输入中可见 patch 的恢复误差是两种条件，不可互相替代。这里没有深度真值精度、渲染质量或一般 PE 的效果证明。

**这轮否定的不是一个极小数值偏差，而是预定的联合用途条件：新片段上未保住遮挡收益，全图还有一致代价。** 所有适配器仍能改善原冻结骨干的遮挡恢复，但 Local 也能做到；这部分改善不能全部归给场景记忆。

## 训练目标确实改变了取舍，但开发收益未迁移

下表仍为 Center 相对配对 Local 的误差变化，负号为改善。

| 数据部分 | 组别 | 遮挡区 | 可见区 | 全图 |
| --- | --- | ---: | ---: | ---: |
| 同场景留出 | A | −10.17% | +0.34% | −4.09% |
| 同场景留出 | B | −8.33% | −1.96% | −5.05% |
| 同场景留出 | C | −8.57% | −2.23% | −5.29% |
| 六旧开发场景 | A | −5.31% | +3.96% | +0.29% |
| 六旧开发场景 | B | −3.74% | +1.14% | −0.99% |
| 六旧开发场景 | C | −3.76% | +1.11% | −0.99% |
| 十二新片段 | A | +0.36% | +4.31% | +2.85% |
| 十二新片段 | B | +0.83% | +2.43% | +1.79% |
| 十二新片段 | C | +2.18% | +3.75% | +3.16% |

开发集的约 1% 全图平均改善并不稳定：B/C 各有一个种子反向，B 场景区间跨零，C 区间下界接近零。新片段全部评分后才作本结论，没有因开发均值为正就提前宣布通过。

在**同一批新片段**内，B Center 比 A Center 的可见误差降低 8.90%、全图降低 3.54%，但遮挡误差增加 5.96%。等权监督因此是一个有效的目标取舍控制，却没有建立记忆对 Local 的增量。

C Center 的完整输入改变量相对 A 在同场景留出/旧开发/新片段分别减少 93.51%/80.85%/40.13%。但新片段上 C 比 B 的遮挡误差增加 5.69%、可见误差增加 18.07%、全图增加 13.17%；C 对 B 的完整输入改变量平均减少 14.48%，场景区间仍跨零。完整输入保真没有自动成为不完整输入上的可见区保真，也没有稳定迁移到新片段。

旧 A 在上一批 40–52 片段的遮挡收益为 −1.94%、全图代价为 +1.78%；本批 A 为 +0.36%/+2.85%。旧结果保留，这表明其补缺增量的适用范围比此前一批结果提示的更窄，而非推翻共享写入网络曾经学会记忆的证据。

## 记忆干预提供什么信息

正常 Center 的遮挡 MSE 与移除/打乱特征/交换场景/错误相机的比较：

| 组别 | 正常 | 移除 | 打乱 | 交换场景 | 错误相机 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 0.028365 | 0.028951 | 0.029893 | 0.029273 | 0.029808 |
| B | 0.030056 | 0.030517 | 0.031151 | 0.030703 | 0.031217 |
| C | 0.031766 | 0.032035 | 0.033000 | 0.032285 | 0.033137 |

模型仍依赖场景、特征对应和相机，不能说它完全忽略记忆。但干预是未重训的输入分布改变，不能替代训练过的 Local 对照。C 移除记忆后，遮挡误差增加 0.85%，全图反而减少 0.80%；交换场景的全图变化仅约 −0.003%，近似持平。这里的小差异不制造新门禁，关键是记忆依赖并未带来配对对照上的稳定净收益。

## 实现与成本核对

- B/C 十二模型的参数初始化与对应 A 完全相同；所有组逐步样本序列一致；损失和梯度有限，全部达到 2,000 步。C 初始完整输入误差为零，所有步骤的目标组成均核对通过。
- A 在十八旧开发片段的 Local/Center 分数回放最大差为 **0**。四个 B/C 首种子模型的独立 CPU/NumPy 误差重算最大差为 **1.49e-8**，全图加权核对最大差 **3.91e-9**。
- 完整分支的独立前向不会改变遮挡分支输出。沿用已核对的像素遮挡缓存与冻结骨干；新片段的图像、相机、原始缓存、记忆和 token 缓存均记录哈希。
- C Center 独立命令仅输入观测 RGB、K、c2w、记忆和检查点，成功回填实际 VGGT token 并被原 depth head 接收，输出有限。实时与 half/bfloat16 缓存读出的归一化差约 `3.47e-5`，此接口核对不用于主评分；原 depth head 的输出改变约 `1.90e-4`，不声称深度精度提高。
- 卡 1 经两次实时占用核对后运行一个共享工作进程，12 GiB 上限；训练实测峰值 **1.013 GiB**，新片段完整骨干提取峰值 **4.647 GiB**。B 六次训练共 **102.18 秒**，C 六次共 **139.88 秒**，合计 **242.06 秒**，不含准备/等待/评估。C 每次多 4,000 个完整样例、适配器前向批次数从 2,000 增为 4,000；共享卡上的墙钟时间不是独占吞吐基准。

全部正确性检查通过。无需修复训练源码或重跑科学比较，也没有把数值核对当成路线继续与否的替代。

## 可视化与决定

已生成三十片段的固定首查询/首遮挡/首种子图和总览；实际查看七张：总览、fit_00、val_12、fidelity_02/03/08/09。包含 B/C 场景平均收益的正反例，使用同图共同色标。单张首查询的方向有时与整个场景均值不同，例如 fidelity_09 的 B 首查询略优而场景平均为负；判断以全部预定样本和配对种子统计为准。图像不显示预测 RGB 重建，热图表示 token 误差。

**本轮收尾决定：结束靠这两种损失改动挽救当前单层 token 读取的尝试。** 保留现有结构作为可学性/机制原型，不把 B 或 C 提升为已确认有效的方法，也不把旧的有限收益改写为普适结论。形状必要性、未知相机、长期记忆和实际几何任务效果依然未建立。

下一项更有辨别价值的工作是**直接参考特征读取的可达性对照**：先判断保留更多参考信息时，这个 token 恢复接法能否得到稳定额外收益，区分“记忆压缩/写入造成信息瓶颈”与“当前层、任务或训练覆盖本身限制收益”。更多参考 token 属于更高预算的诊断，不能直接当作公平方法胜负；若它有明确收益，再做同预算点记忆/高斯记忆的形式比较。这里是后续建议，本轮未启动新训练，也没有继续消耗确认片段进行调参。
