# 原生接收适配结果：收益迁移到哪里，以及下一步建议

2026-11-12。基于已完成的 `native_receiver_adaptation1` 和相关旧结果。本文是结果解释与下一项实验的设计，**没有建立新执行目标，没有启动训练或推理**。上一有限目标的结果与结束决定不变。

## 1. 当前可以相信的判断

**保存的场景内容及其对应关系已被模型利用，但相对强当前图像对照的收益尚未稳定迁移到未见地点。完整接收网络适配改善了部分空间表现，没有解决这个缺口。**

Local 使用当前图像 token 及其全局均值；Global 使用同一保存场景的平均内容与覆盖；Render 使用实际按查询视角合成的局部内容。三组融合参数量一致。A 表示融合层、全部原生 frame/global 交互块和 DPT 共同适配；F 表示仅训练融合、原生接收冻结。

| 已完成比较 | 主要结果 | 支持的解释 |
| --- | --- | --- |
| A_Render 对 A_Local，未见地点 | 缺失 ROI 空间误差高 1.37%；降误差区间 [−29.36,+16.57]% | 未建立可靠净收益；也不足以认定明确伤害或两方法等效。 |
| A_Render 对 A_Global，未见地点 | 空间误差低 22.89% [4.32,39.45]% | 这个实现中，保留空间组织优于把来源压成一个平均向量。 |
| 正确绑定对打乱绑定，A_Render | 空间误差低 22.16% [8.53,37.70]%，12/12 地点方向一致 | 模型依赖绑定关系；破坏输入有损失并不证明加入输入有净收益。 |
| A_Render 对 A_Local，拟合训练画面 | 空间误差低 41.42% [33.34,49.74]%，12/12 地点方向一致 | 训练画面的收益真实存在，但这里不是未见视角或未见地点成绩。 |
| A_Render 对 F_Render | 开发空间误差低 11.02%，区间 [−1.04,25.94]% | 接收适配有改善迹象；Local 同时低 9.41%，R−Local 的适配交互区间仍跨零。 |

开发地点中，Render 对 Local 有 8/12 个地点改善，另 4 个较大退步抵消了均值收益。因此问题具有明显的地点差异，不能概括为所有场景都无效，也不能删去反例后声称有效。[完整结果及地点/种子分布](../results/gaussian_memory/native_receiver_adaptation1/report.md)、[原始汇总](../results/gaussian_memory/native_receiver_adaptation1/scoring/summary.json)。

## 2. 可能原因：证据与推测分开

1. **收益的迁移范围有限，是当前最直接的线索。** 训练画面有明显增益、未见地点没有可靠增益，与样本覆盖不足或对具体观测分布的适应相容。当前只有 12 个训练地点，而本轮训练了约 6.37 亿原生参数。但这不能单独证明过拟合，更不能保证多加数据会解决问题：训练与开发还存在内容质量、视角与场景分布差异。F_Render 原先就比 F_Local 低 53.08% 的训练空间误差，说明现象并非本轮解冻才出现。
2. **“冻结接收器不会用外来特征”只能是部分解释。** A_Render 和 A_Local 都有空间改善，R−Local 的改善差仍不确定；R 对 Global 的相对改善还包含 Global 自身退步。不能把共同适配的改善全部归因于记忆价值。[冻结行结果](../results/gaussian_memory/rendered_feature_native1/report.md)。
3. **保存的内容仍可能有几何误差和特征混合。** 先前 sensor 对照改善了部分原生深度，但载体的空间质量与特征重观察并未全面改善；它不是完美来源。即使 alpha 覆盖较高，也不等于该像素获得了正确内容。[来源质量对照](../results/gaussian_memory/source_geometry_control1/report.md)。这一解释尚未与泛化问题分离。
4. **整体深度标定也有代价。** 本轮 Render 相对 Local 的原始 ROI log-MSE 高 7.29%，完整全图 AbsRel 高 4.61%，两项区间均跨零。原始 ROI 差额约 95.92% 伴随均值偏差平方项，属于误差恒等分解，不是因果定位。仅报告去均值的空间改善会漏掉整体偏差；直接使用查询真值校正偏差也不能当作方法成绩。
5. **比较结构限制结论范围。** Local 与 Render 是两种附加上下文输入，后者没有保留 Local 的全局均值通道。它们是同容量对照，但不是“完整 Local 加一个可忽略记忆输入”的严格嵌套实验。因此失败不能证明来源的条件信息为零；本次也没有证据据此立即增加一个融合模块。

本轮没有更换或比较新的 Gaussian PE，**不能回答 O6 的高斯参数相对强中心编码是否有额外价值**。O4 的记忆用途、O5 的渲染读取和 O6 的 PE 增量继续分开。现有负结果不否定所有 3DGS memory，也不把记忆融合测试变成其他 PE 设计的通用门禁。

## 3. 首选下一项：固定权重的跨视角迁移检查

建议名称：`native_receiver_view_transfer1`；状态：**仅设计，未执行**。目的不是再拟合一次，而是补上当前证据链缺失的一层：**收益是否能从训练画面迁移到同一片段的未训练视角？**

目前已比较“训练画面”和“未见地点”。两者之间同时改变了视角与地点，不能判断收益首先在哪一层丢失。下一项保留全部权重、保存场景与接口，增加同片段未用于这两轮训练的查询，并在训练和开发地点同步增加同位置查询，控制查询采样位置变化。

### 假设与竞争解释

- 主假设：当前正确空间读取已学到能在同一保存场景内迁移的用途；主要缺口发生在跨地点迁移。因此训练地点的未训练视角仍应保留相对 Local 的收益。
- 竞争解释：收益主要局限于被拟合的查询或具体观测分布；换为同片段未训练视角后，相对 Local 的优势即明显衰减。另一种可能是新视角本身的来源支持和难度不同，需要开发地点的同步查询变化作为参照。
- F/A 两组都保留，用于描述该现象是否随完整原生接收适配改变；不把它当成第二项独立的训练实验。

### 固定比较和规模

| 项目 | 固定安排 |
| --- | --- |
| 权重 | A_Local/A_Render 和 F_Local/F_Render，各既有三个种子；共 12 个已有模型，零次训练。 |
| 场景 | 原 12 个训练地点和 12 个旧开发地点；原 24 份保存场景不重建，不重新写入内容。 |
| 来源 | 原序号 `[0,3,6,9]` 不变，所有查询共享对应来源状态。 |
| 既有查询 | `[2,5,8,11]`，复用完整既有评分；训练地点这组明确称“拟合查询”。 |
| 新增查询 | 同一已保存 12 帧窗口中的 `[1,4,7,10]`，与本轮来源及拟合查询互斥；两地点集合均执行。 |
| 条件 | 原完整图像与中央缺失两条件，同预处理、相机、尺度、掩码与有效像素规则。 |
| 数量 | 12 模型 × 24 地点 × 4 新查询 × 2 条件 = 2304 份新预测；另复用相应 2304 份既有预测指标。 |
| 主比较 | A_Render−A_Local 在训练地点新查询上的缺失 ROI centered log-MSE；同时报告相对原拟合查询的变化。 |
| 配对对照 | 开发地点也比较新旧查询的 R−Local 差；考察训练地点优势衰减是否超过开发地点的查询位置变化。 |
| 保留指标 | 原始 ROI log-MSE、均值偏差项、完整输入全图 AbsRel；原来源支持分层只作解释，不筛选地点或改主终点。 |

令 `d = E_Render − E_Local`，负值有利。分别报告训练/开发地点的 `d_old`、`d_new`，以及 `Δ_train = d_new − d_old`、`Δ_dev = d_new − d_old` 和 `Δ_train − Δ_dev`。最后一个差值只能帮助识别训练查询暴露相关的衰减，不能消除所有新旧视角难度差异或证明神经网络记忆了图片。地点/查询等权；沿用 5000 次配对地点和种子重采样，训练/开发地点分别抽样、同地点新旧查询保持配对，不把像素视作独立样本。

2026-11-12 的只读文件检查确认两集合各 48 张新增查询 RGB 和 48 份对应深度均存在，合计 96 对；没有下载需求。这只是可用性检查，执行时沿用既有身份核对与预处理。新查询曾属于历史数据，且属于原片段，**不是新确认数据，也不是独立新场景**。新增缓存放入独立目录，保留原输入、模型、结果及评分。

运行时使用实际空闲 GPU 完成编码、渲染和原生推理，启动前核对占用及 CUDA；不需要优化器、梯度或重新训练。仅需基本配对身份、有限输出和沿用评分的核对；不增加参考积分、数值扫描或新的通用审核门禁。

### 结果怎样改变决定

- **同片段未训练视角仍有一致、实质的优势，跨地点仍没有：** 将证据收窄为“已见片段内可跨视角利用记忆”，不能直接宣称可泛化场景方法。届时才值得另立一次固定结构的训练覆盖对照，检验增加独立训练场景是否提高 R 相对 Local 的收益；不能只看两者都变好。现有数据可支持扩大训练覆盖，但更多数据有效仍是待检验假设。
- **同片段未训练视角优势也明显消失，且超过开发地点查询变化：** 限定为拟合观测上的收益，停止用相同接口的追加训练或微调扫描解释成可靠场景记忆。后续若继续导师路线，须明确改变内容学习或跨视角训练目标等实质假设；并保留其他已有 PE 用途的证据。
- **结果不确定，或主要随来源支持/视角变化：** 如实保留无法区分的结论，不自动扩种子、选子集或接续修补。该有限检查仍结束，不能延长为无限诊断。

以上是证据到研究取舍的分支，不是规定每个指标都必须显著的硬门禁。若未来直接研究 O6，只需其自身明确且匹配的实验理由，不必先让本检查通过。

## 4. 与旧尝试及大纲的对应

**大纲对应核对：** 已读[研究入口](research_current.md)与[持续对应记录](research_outline_alignment.md)。本建议直接服务 O4/O5，复用 O2/O3，并限定 O6 仍未检验。C1–C6 的模型、来源与训练条件都不改；改变的是评价查询范围，检查 C6 已完成适配的迁移边界。给定相机、sensor 辅助来源/共同有效性、静态四来源、冻结编码器/保存内容、旧数据是临时实验范围，不是导师的核心要求。

相关旧尝试已有训练片段内和跨片段差异，不能写成第一次发现泛化问题：

- [coverage1](../results/gaussian_memory/coverage1/report.md)曾把相同总量的 12 训练片段从 3 地点改为 12 地点。末层 token 恢复的 Center/Direct 未获得跨地点净收益，且同地点被移出训练的片段也失去原优势。故本建议不承诺“扩大覆盖就会成功”。
- [context_supervision1](../results/gaussian_memory/context_supervision1/report.md)中，多视图教师也出现训练片段留出视角收益而跨场景无净收益；这限制了简单更换教师的解释。
- 当前 [native_receiver_adaptation1](../results/gaussian_memory/native_receiver_adaptation1/report.md)已变为实际高斯特征渲染、原生深度任务、完整接收与 DPT 训练；直接比较了拟合查询与未见地点，却没有在这一接法上填补同片段未训练查询这一层。**新信息来自在这组已有权重上的迁移层级，不来自新增种子、改名或重复 token 代理实验。**
- [source_geometry_control1](../results/gaussian_memory/source_geometry_control1/report.md)和[learned_projection_pe1](../results/gaussian_memory/learned_projection_pe1/report.md)的质量线索及 PE 阴性结果继续保留。本建议没有重新启动投影标量修补，也不能用 O4 的任何局部通过替代 O6。
