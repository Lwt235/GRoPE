# 固定权重跨视角迁移：片段内收益保留，跨地点净用途仍未建立

2026-11-12。`native_receiver_view_transfer1` 的2304份新预测、2304份既有预测的评分回放、配对迁移分析、成本记录和两图实际审阅已完成。**零重训；12份既有权重和24份保存场景均保持。**

**主要结论：Render的收益能够迁移到训练片段内未参与本轮优化的查询视角，并非只能在拟合画面上出现；未见地点仍未建立相对强Local的可靠净收益。** 这使片段内跨视角用途的证据更完整，但没有证明跨场景有效、纯RGB有效或高斯PE有独特增量。

## 固定问题和比较

按[授权执行方案](../../../docs/native_receiver_view_transfer_execution_plan.md)，对原12训练/12开发地点、同一12帧窗口，来源`[0,3,6,9]`不变。旧查询`[2,5,8,11]`的匹配结果继承，新查询`[1,4,7,10]`在两地点集合中同步增加。两组查询互斥且均不作为本轮来源。训练地点的旧查询是拟合输入，新查询未进入这两轮模型的训练损失；它们仍属于旧数据和同一片段，不能称全新独立确认。

A_Local/A_Render是完整原生frame/global与DPT共同适配行，F_Local/F_Render是仅融合层训练、原生接收冻结行，各三个配对种子。Local使用当前patch与当前patch均值，Render使用当前patch与实际alpha合成的保存内容，融合结构和容量相同。两者是不同附加上下文选择，非严格嵌套来源增量。

主假设为片段内视角间保留记忆用途、跨地点迁移受限；竞争解释包括只适应拟合观测、新查询位置/来源支持变化以及保存内容和接口质量限制。主终点仍是中央缺失ROI的centered log-MSE；原始误差、偏差和完整输入AbsRel保留。地点/查询等权，5000次配对地点与种子重采样；训练/开发的地点分别抽样，同地点新旧查询及方法保持配对。

## 主要结果

| 完整接收适配 | Local空间误差 | Render空间误差 | Render相对Local降误差及95%区间 |
| --- | ---: | ---: | --- |
| 训练地点，拟合查询 | 0.007476 | 0.004379 | +41.42% [33.34,49.74]% |
| 训练地点，未训练查询 | 0.015069 | 0.006692 | **+55.59% [46.53,61.31]%** |
| 未见地点，原查询位置 | 0.022665 | 0.022975 | −1.37% [−29.36,16.57]% |
| 未见地点，新查询位置 | 0.023986 | 0.024735 | **−3.12% [−33.40,22.80]%** |

训练地点新视角的三个种子分别降误差56.04%/57.37%/53.32%，12/12地点均有利。未见地点新视角三个种子为−1.43%/−8.76%/+0.69%，9/12地点有利、3个较大退步抵消了总体均值；仍不能证明普遍有害或与Local等效。

空间优势从41.42%变为55.59%，**不表示新视角绝对更容易或预测更准**：新视角上Render误差从0.004379升至0.006692，Local从0.007476升至0.015069，后者增加更多。可以说优势保留，不能说换视角使绝对质量提升。

冻结接收行在训练地点新视角也有55.79% [53.10,58.70]%优势，三个种子及12地点方向一致；在开发新视角为−7.56% [−46.69,24.89]%。因此片段内正证据并不依赖本轮完整解冻。完整适配相对冻结的Render和Local新训练视角误差分别低15.46% [7.99,22.16]%和15.85% [6.56,26.16]%，接近的共同改善不能称高斯记忆独特收益。

完整表格见[report_tables.md](report_tables.md)，所有地点、种子、条件和指标见[summary.json](scoring/summary.json)。

## 查询变化与来源支持

令`d=E_Render−E_Local`，负值有利；`Δ=d_new−d_old`，正值表示优势衰减。完整适配行训练地点Δ为−0.005280 [−0.009619,−0.001786]，开发地点为+0.000439 [−0.004816,+0.005796]。没有出现“训练地点换到新查询后优势消失”的预期。

`Δ训练−Δ开发`为−0.005719 [−0.012631,+0.000856]，区间跨零。这个差分不支持将迁移缺口唯一归因于地点，也不为某一原因给出因果证明。

传感器几何一致的ROI来源支持在训练地点由93.02%变为96.47%，开发地点由77.56%变为80.48%。两集合的新查询均有略高支持，但集合之间仍存在明显差异。它是输入机会，不保证高斯内容正确，不能把训练/开发差距全部归因于训练规模。

新查询支持ROI内，Render对Local在训练地点低58.36% [48.80,64.15]%，开发地点低18.52% [−1.45,31.93]%，后者三个种子同向但区间跨零。无支持ROI内分别低20.83% [12.93,27.96]%和高5.01%，开发区间跨零。来源支持是条件线索，没有作为GT门控或样本筛选；分别去均值的条件方差也不能简单加权分解全ROI方差。

## 原始误差与完整输入

训练地点新视角的原始ROI log-MSE对Local低50.32% [31.63,59.78]%，因此正证据并非只存在于去均值空间指标。完整输入全图AbsRel低2.42%，区间[−9.70,12.89]%，不能宣称全面改善。

开发新视角的原始ROI误差平均高4.18%，完整输入AbsRel高2.76%，两区间均跨零。其原始ROI差额0.004584可分为空间差0.000749和偏差平方差0.003835；约83.67%伴随偏差平方，属于代数描述，不能定位唯一病因。

## 实现、图像与成本

24份新增查询缓存共96个视角、192份完整/缺失编码。两个固定旧样例的编码和渲染回放差均为0；12个模型各回放两个旧预测，最大深度差0。每份加载权重按原完成记录SHA核对，原24份场景SHA在前后保持，固定推理源码身份一致。没有优化器、反向传播或新模型权重。

2304新预测和2304旧预测已用独立NumPy float64复算，最大指标差2.39e−15，旧公共指标回放差0。旧训练查询原来没有的支持条件指标由同一旧预测补算，明确属于补充评价而非新推理。[独立核对](scoring/independent_recomputation.json)。

[迁移图](figures/transfer.png)已实际查看：训练地点的新旧查询优势均为正，开发地点分布混合且反例较大；A/F的新训练视角相对优势接近。图中的各地点连接线不是独立重复试验。

[深度案例图](figures/depth_cases.png)已实际查看。fit_00/q1中两模型均恢复了平滑黑板与椅子布局，仍有细节平滑，不能凭单图判断55.59%的总体幅度。训练新视角最大反例coverage_04/q1的三种子平均差仅+0.000004465，两图均有床头/墙面模糊，不作为明显失败。开发最大反例fidelity_00/q1的Render/Local误差为0.327232/0.216062，Render在中央墙面出现扩大的高深度区域，与GT不符。后者同时是固定首开发案例，图中去重后共三行，未从评分排除任何样本。[实际审阅](figures/visual_review.json)。

## 大纲对应与取舍

服务O4/O5、复用O2/O3；C1–C6的模型/训练选择不变，只扩评价范围。O6的高斯PE增量未检验，给定相机/尺度、sensor辅助、静态来源、旧片段与冻结保存内容仍是临时范围，不是导师原始要求的全部能力。

旧[coverage1](../coverage1/report.md)和[context_supervision1](../context_supervision1/report.md)已经出现片段内收益、跨场景无可靠净收益，负结果保留。本轮提供的是实际渲染内容、原生深度、完整接收已有权重上的对应证据，不能写成首次发现泛化问题。旧覆盖实验保持总训练片段数，只重新分配地点；没有证明增加总训练样本一定无效，也没有为增加数据必然有效提供依据。

本轮支持的范围是：**在已参与训练的同一片段及给定来源条件下，空间记忆能帮助恢复未用于本轮优化的遮挡视角；跨地点相对强Local的稳定用途仍缺证据。** 不将其晋升为一般有效的3DGS memory/PE方法，不把新查询称为独立新确认。上一完整适配候选的跨地点结束决定不改写。

后续最值得考虑的是一次固定结构、固定对照的训练覆盖实验，检验增加独立场景与总样本是否提高Render相对Local的跨地点收益；两者共同变好不能替代这个比较。来源质量和分布差异仍是竞争解释，当前证据不承诺多数据一定解决问题。O6的独立设计也不必把这项检查当作通用前置门禁。

此有限检查至此结束，不自动追加训练、种子、GT选择器或新模块。研究总体目标仍未达成。
