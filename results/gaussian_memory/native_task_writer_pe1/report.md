## 问题、实际实现和证据范围

假设是共享source-only物理支撑与内容能通过实际原生查询任务梯度形成，从而改变Gaussian参数PE超过强中心的用途。竞争解释为共同内容／coverage适配、非物理任务捷径、强中心足够或训练片段记忆。对照为C只改f/opacity、J另改μ/Σ，分别P/S/G；不同结果的原定分支保留，未添加科学方案、扫描、seed、step、数据或辅助目标。

复用原44场的2048槽／1024D初始化和四源0/3/6/9；共享1034→128→128→1034 GELU点式writer，末层权重/bias零。输入原f、第一source相机坐标系的unit归一化中心、完整logΣ6、opacity；API只有来源场和C/J训练范围，无query RGB／相机／ID／标签，无逐场景可训练参数。C/J六组均有全部输出头；C不启用九个几何输出。f加法残差后FP16，opacity为logit残差；J中心各轴0.25unit、logscale0.7、轴角范数π/6有界，正scale及规范rotation。原有效槽、绑定、unit及sources保持。学得任务几何不等于更准确物理几何。

每训练样本当前writer形成field，以真实gsplat渲染2048个basis颜色得到当前alpha贡献，再以当前FP16内容合成1024D未归一化内容；贡献矩阵每次实际重算且保留梯度，不是冻结缓存或detached几何。物理field与真实raster输入FP32；描述符矩／logΣ沿原prepare的FP64代数后castFP32进入fusion/PE，梯度保留且各组相同。当前贡献同样形成完整logΣ六个未归一化普通输入与46维强中心：中心均值、多尺度Fourier、中心混合散布、原七个ray量。最后六位置维P=0、S=同迹球logΣ、G=完整logΣ；实际物理场／渲染在S仍完整各向异性。普通Σ六维对所有组相同，fusion首层由2048扩2054，新增六列零初始化，原列及输出初值保留；原52→64→1024末层零PE进入全部24global Q/K，V和原2D RoPE保持。中心混合散布不是G独享信息。

basis后矩阵乘法与原颜色直接raster的浮点累加路径可能不同，继承Render不是逐值同路径回放或严格新增writer容量消融；本轮C/J×P/S/G全部共同使用同一路径。主G/P识别整条训练链总效应，含不同成场和不同receiver；不是固定相同场直接PE因果量，交互也不单独识别Σ、覆盖或唯一病因。
