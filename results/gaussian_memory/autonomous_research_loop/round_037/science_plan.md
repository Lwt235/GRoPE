# round037：保留历史收益，检验有界的原生patch保存

2026-11-15。**结束`stream_history_factorization1`及其自动分解变体；不晋升任何四格为部署方法。下一项只检验`stream_patch_retention1`：在同一实际历史字节上限下，三维中心覆盖是否比普通分散保存更有效保留原生patch K/V。** 不加入高斯、融合、PE或训练；这是为[当前目标](../goal_revision_20261115/revised_goal.md)选择值得采用的保存单位与空间基线，不自动进入P2。

**结果与范围。** [完整报告](../../stream_history_factorization1/report.md)的主`I_read=3.4547° [−0.1270,7.8404]`未达到原材料标记，但7/9地点正、逐一留出均值1.67–4.37°，不能据边缘跨零断言直接历史无效。`I_write=3.0551° [−3.1883,9.5292]`，联合改善`6.7670° [0.8223,14.1369]`；直接交互仅`0.2572° [−4.5194,5.7864]`，**没有证明必须耦合，也没有证明可加性**。F形成条件下增加读取的辅助改善3.7120° [1.1005,7.0153]保留，不替换主效应。旧A相对FF为−0.0291° [−0.0965,0.0340]，未支持“固定W相机隐藏值会消除原收益”；小区间不等于全系统相机无作用。

WF／FW／FF全帧AbsRel分别增加0.01077／0.02273／0.02272，均为原规则下的明显代价；WF和FF去均值log-MSE改善，而FW的raw退步主要对应偏差平方。全帧轨迹中心／绝对点误差、非重访旋转等辅助正证据与重访平移／一致性的未决区间分列。保留12地点、3处NA、零支持及全部反例，尤其home_bksh的主均值退步和38/1对的−13.09°。支持层内正值不构成因果或改阈值理由。完整F教师／W影子库及转移已计费，四格是条件反事实，不能称同byte、独立在线、高斯或fresh成功。故只保留“主干历史存在有代价的用途，直接读回仍值得考虑”的范围，不继续扫描窗口、层或相机状态。

**唯一新问题。** 少量整帧必须连同大量重复patch一起占容量；能否改为保存跨时间的独立原生patch束，在真正有界、自身反馈的流中取得更好的旋转—深度取舍，并且三维覆盖比不看几何的分散保存更有用？依据是未压缩历史的用途仍在，而[两种整帧T/D](../round_035/science_plan.md)没有保住它；这并未证明粒度是唯一原因。竞争解释是普通分散样本已经足够、预测几何错误／离群点误导覆盖、原生上下文不能这样稀疏保留，或减少近期容量的代价仍更大。此次不融合K/V，保留实际源位置，从而不同时引入平均内容、位置重投影或合并质量近似。

**共同科学条件。** 一个patch束保留同一来源patch的全24层未融合raw K/V、原二维位置与来源ID；它不是单个物理点的充分表示。三维中心仅用该组当时原生深度的patch内中位数、patch中心射线及预测相机反投影，写后固定；U也得到相同字段。两组各自从自己的有界状态产生未来内容／几何，不读Full教师、W影子库、另一组或淘汰历史。移出近期时才入远端；未满M保留全部。C几何未定义条目不参与距离，若有效候选不足M，以同U优先级补足；完整评价不删这些帧／patch。这比较在线保存政策的总效应，不能将C/U直接解释为固定内容下纯几何因果。

两组全24层的5个特殊token另统一保留首帧＋最近7帧，相机也统一采用该帧政策并完成每帧4轮，隐藏值由各组自己产生；其字节全部扣除后确定共同M。原当前图像计算、归一化／源位置RoPE、dtype／SDPA保持；只改变过去条目集合。每个保留条目质量为1，不把被淘汰项虚计为融合成员，不加`log n`。不新增编码器、置信筛选、空间尺度阈值、反馈模块或训练。必要不规则读取接口沿用已核实的原生语义，普通工程核对不另立科学轮。

**固定输入、端点与预算。** 同一官方模型及原12×96完整RGB、189重访／756远端目标、分层与NA；GT仅离线、所有数据used，不重选场景或标签。主比较为地点等权重访旋转的 **`I_space=E_U−E_C`**；预定C/W与U/W分别检验净用途，不按事后最佳者改主比较。沿用地点配对区间／留出和全部反例，同时报告全帧与非重访旋转、raw／去均值／偏差、AbsRel、平移／绝对几何／失败及完整构建、更新、读取和转移成本；不用GT尺度修正或Full差距恢复率。

U/C各完整12流；W评分继承，只允许固定首地点一次必要的匹配完整成本重放。共同总历史上限沿用[round034](../../stream_native_retention1/report.md)的 **B=2,726,555,844 bytes**；同一恢复／副本策略，索引、中心、特殊／相机状态、可读RGB、所有历史backing及原子保存峰值入账，M由字段和实际字节在看效果前一次确定，不能换副本策略给某组暗增容量。淘汰条目不得藏在可读库；不可回流预测归档另列。一次投入 **4 GPU worker小时（含全部加载／失败／恢复及≤0.5小时预检／成本）、新增DATA≤12GiB、项目≤1GiB、单worker显存≤40GiB，0训练／下载**。先固定首流验证实际资源可完成；不足交实测缺口，不暗改M规则、精度、样本或预算。实时空卡并行、脚本／精确调用／存储恢复由Sol实现。
