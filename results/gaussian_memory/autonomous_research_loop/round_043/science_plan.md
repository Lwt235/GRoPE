# round043：有界有效K/V合并，形状只决定来源分配

2026-11-15。**选择一次 `stream_spatial_merge1`，比较内容、球形与各向异性三种递推合并政策。** 它直接检验[现行目标](../goal_revision_after_round042/revised_goal.md)中的空间组织是否值得保存和更新：在相同信息／容量／实际字节上限下，完整支撑矩能否比球形与普通内容聚合更好地保留原生重访几何。不是将M直接上线，也不是恢复XYZ仿射响应闭合；保存与读取仅用原有效K/V的计数均值，**Σ只参与决定合并成员**，不生成PE或连续高斯attention。

**具体假设与反事实。** 来源patch的预测三维支撑可帮助区分“内容相近、可沿表面合并”与“内容相近但跨薄轴／跨面混合”。设两组内容相同、中心距离相同、支撑均为 \(\mathrm{diag}(\lambda_t,\lambda_t,\lambda_n)\)，\(\lambda_n<\lambda_t\)。等质量合并的完整协方差代价含 \(\log(1+d^2/(4\lambda_{axis}))\)，故跨薄轴更昂贵；同迹球形代价不能区分这两个方向。这是一个具体分配偏置，不要求K/V随XYZ仿射。竞争解释是普通内容已经足够；原生上下文／来源位置并不服从局部表面支撑；预测漂移、早期分配和累计质量可能使空间规则更差。支撑协方差不是定位不确定性，内容相近也不保证同表面。

**唯一递推规则。** 三组共用以下状态、融合与读取，仅容量不足时的合并排序不同。

1. 官方冻结StreamVGGT，完整RGB，全部24个global层。保留首帧＋最近3帧的原生patch；特殊token与CameraHead均保持首帧＋最近7帧及每帧全部4轮。刚移出近期的patch才进入远端，每个来源恰好入库一次；首帧不重复计入远端。当前帧先预测，随后才成为未来帧来源。各组从自己的有界状态产生未来K/V与预测几何，**无Full教师／影子库／他组／已淘汰原条目或GT回流**；这是在线政策的总效应，不冒称固定内容的纯形状因果。
2. 一个远端槽保存同一成员集合的全24层有效key／value均值、整数成员数n、几何有效成员数m、中心μ和完整支撑协方差Σ、必要来源ID。有效key严格是原 `k_norm → source二维RoPE` 后的向量；均值不能再次归一化或旋转。读时所有远端均值与原生精确部分共用softmax，远端加 \(\log n\)，精确条目质量为1。保存均值FP32，实际attention按共同原生dtype读取；必要转换副本收费。没有query几何投影、新编码器、门控、训练或质量衰减。
3. 新patch的μ／Σ由该帧自己的原生深度和相机反投影其14×14像素，取有限正深度点的均值与总体协方差；每patch占一个成员质量，不把有效像素数当token数。合并两槽时，K/V按n加权；几何按有效成员数m更新均值及“组内协方差＋中心散布”，只需当前充分统计。缺失几何不删帧／patch；若超容量且有m=0槽，三组先用同一最低内容代价合并涉及该槽的对，几何仍只累计有效成员。缺失量完整报告。
4. 容量未满不合并；超过共同M时逐次合并一对至M。内容距离使用全部层／head的有效K/V均值，各层／head的K、V分别以首帧patch RMS固定缩放，三组共享该标度，不按效果选层或学习描述子。令缩放后均值为f，普通Ward代价为 \(c_{ij}=n_i n_j\|f_i-f_j\|^2/(n_i+n_j)\)。在当前N个有效几何槽的全部无序对中，取内容代价最低的N对作为共同候选（不足取全部），平局按最小来源ID。此约束只定义低合并代价候选，不宣称语义相同；每次合并后更新，禁止扫描候选数。“共同”指相同算法，状态分化后使用各自的内容与候选，不引入共同教师。

| 政策 | 从共同候选中选择的合并对 |
| --- | --- |
| C：普通全内容 | 最小 \(c_{ij}\)；包含全局最小内容对，是同信息、同融合的普通控制。 |
| I：球形空间 | 最小同迹球形合并体积增量 \(g_I=3[m_{ij}\log(s_{ij}+\delta^2)-m_i\log(s_i+\delta^2)-m_j\log(s_j+\delta^2)]\)，\(s=\operatorname{tr}\Sigma/3\)。 |
| G：完整支撑 | 最小 \(g_G=m_{ij}\log\det(\Sigma_{ij}+\delta^2I)-m_i\log\det(\Sigma_i+\delta^2I)-m_j\log\det(\Sigma_j+\delta^2I)\)。 |

这里μ_ij／Σ_ij是同一几何矩合并，包含中心散布，m_ij=m_i+m_j。δ²固定为首个几何有效来源帧的一像素反投影尺度平方中位数 \(z_p^2(f_x^{-2}+f_y^{-2})/2\)，z_p取patch内有效深度中位数；尺度未定义前各组共同走C。它只是有限分辨率的共同正则，不是预测置信度，不调倍率。I也保存完整普通Σ，读取、内容和几何形成与G一致；仅分配分数将其球形化。C同样取得全部几何字段。真实STAC不是这三个控制之一；[round031已核实的作者实现](../round_031/science_plan.md)留作以后相应系统主张所需的强基线，当前不冒称胜过STAC。

**输入、字节与反馈。** 固定原12地点×96帧、官方权重／预处理及[原重访标签与NA](../../stream_patch_retention1/report.md)；三组各完整12流，均为used开发，0模型训练／下载。GT仅离线评价。共同总历史上限选已核实W参照的 **B=2,726,555,844 bytes**，是本轮选择而非永久预算。Sol在看效果前按共同状态格式、同M、必要工作区与同一恢复协议算出合法容量，完整计入所有层、近期／首帧、特殊／相机、几何／计数／缩放／索引、所有模型可读backing、独立副本和恢复峰值；不得藏Full或旧RGB重读旁路。实际未用余量及方法特有临时峰值分报，不靠填充字节宣称最优预算前沿。预测／评分归档不能供模型回读；额外激活、权重、完整I/O与更新时间另报。这是同信息同容量的受控预算点，非整个预算前沿或长期千帧证明。

**原生终点与投入。** 主比较为地点等权重访相对旋转误差的 **\(I_{shape}=E_I-E_G\)**；正数有利。预定G/C与I/C辨别空间用途，C/I/G各对W辨别共同净用途；沿用原配对区间、留出、支持、全部反例及平移／绝对几何／一致性、raw／去均值／偏差、全帧AbsRel和失败报告，不换成响应SSE或挑层／地点。另记录合并的内容代价、几何缺失／质量分布，作为解释而非同表面真值。W完整预测／评分继承，固定首地点至多一次同条件完整成本重放；不重算旧像素或重跑U/C。

一次上限 **8 GPU worker小时**（含≤1小时必要接口／首流成本预检、全部实现运行／失败／恢复）、新增DATA峰值 **32GiB**、项目 **1GiB**、单worker显存 **40GiB**。首个固定来源流的预检结果复用，确认无合并同条目语义及实际时间／存储后完成固定三组；资源或成本无法容纳时保留实测缺口，不暗改M规则、精度、组数、帧数或预算。按实时安全空卡与任务／内存余量并行，普通脚本、等价加速、精确调用账和恢复由Sol决定；不为常规工程另设科学轮。所有构建／合并／读取与完整帧成本必须分列，较慢方法不能称全面加速。

**结果如何改变决定。** 本开发点仍用旋转均值≥1°且配对95%下界>0作为材料信号；AbsRel增加≥0.01且区间支持退步为明显代价，小幅不确定差异不作零容差门禁。G/I主增量、G/C与G/W净方向用途均支持且无明显深度代价，才保留一个各向异性开发候选，并据完整成本界定其取舍。若G/I不成立而I/C、I/W成立，主形状假设仍失败，优先简单球形路线；若只有C/W成立，只保留普通聚合用途，结束空间分配增量。仅胜过更差控制、没有W净用途或伴明显代价，均不晋升；无成立路线则关闭本固定内容候选集＋空间体积合并家族及自动变体，不调候选数、正则、近期配额、描述子、层、精度、种子或数据。机制未唯一解释不阻止有限测试，阴性也不否定所有三维记忆。结果统一交回Astra，不自动后继；任何方法采用均须先审查全历史使用身份，再锁真正未用确认。
