# round_012：关闭特征形成接法，检验一次查询内的原生场景交互

2026-11-13。**结束 native_feature_field_pe1 及该 source-only 特征形成条件下的自动 PE 变体，不采用 C、J 或球形为方法。** [完整报告](../../native_feature_field_pe1/report.md)显示：来源 raw MSE 的 C／J 降幅为 23.249%／33.302%，Σ 确经完整特征渲染梯度改变；但主 J/G 对 J/P 仅降 0.0857% [−2.8703,+3.1167]%，C 为 0.1106%且不确定，形成交互 −4.812×10⁻⁶ 的区间跨零。C/G、J/G 相对 Native 的主降误差均值分别为 −11.50%／−20.13%，未建立净用途。共同 reader 特征改善和固定模型的绑定依赖保留；J/G 全图 AbsRel 对 RasterFill 增约 0.706%且区间支持，低于原材料阈值仍不是零代价。完整查询约122–123ms，对应 Native 约108–109ms，另有逐场拟合成本。两行各10个零覆盖 query、最大反例、全数表／代价／身份均保留；0.794 GPU worker小时和35.241GiB峰值在原预算内。

这削弱了“补上实际特征→Σ梯度便足以解锁 PE”的解释，不证明源特征具有唯一世界支撑，也不证明强中心普遍足够。视角相关表示、非唯一分解、覆盖／幅度、普通内容质量与接收方式仍未分离；不能据源重构或训练内改善换主终点。按[事前合同](../round_011/science_plan.md)收束，不补种子、步数、损失或形状修补；整体目标未达，无 fresh 候选或外部阻塞。

**后继只选一个问题：native_scene_exchange_pe1。** 在持久场完全不变时，让 GS 的临时隐藏表示先吸收当前图像证据、再被下一原生层读取，是否改变参数 PE 对强中心的原生增量？这里新增的是消息路径
\(x^{(0)}\rightarrow m^{(1)}\rightarrow x^{(2)}\)，不是给固定 K/V 换名称。它不增加原始信息；假设是位置组织对经当前观测调节的记忆内容更有用途。竞争解释为强中心同样足够、普通双向交互／额外计算已解释收益，或错误场景内容经回传放大。

[Native Gaussian](../../native_gaussian_pe1/report.md)和[coarse memory](../../coarse_memory_pe1/report.md)已做原生层及全层粗 K/V，但来源表示在查询时不被当前图像更新，形状增量未立；不能声称首次原生接入。[incremental](../../incremental_vggt1/report.md)是直接观测后的规则持久更新；[joint_write](../../joint_write1/report.md)及[来源 context writer](../../native_memory_context_pe1/report.md)不接 query，非查询内反馈。[Gaussian scene](../../gaussian_scene_memory1/report.md)为独立读取器，[native receiver adaptation](../../native_receiver_adaptation1/report.md)允许接收网络训练但仍读固定场的渲染图。新问题只针对缺少的查询内消息回传，不认定它是过去失败的唯一病因，也不续用本轮 C/J 拟合场。

**最小结构与匹配反事实。** 复用原44份、2048槽／1024D alpha绑定的公共粗GS，不重建、分组或优化。每次 query 从保存场建立工作副本；仅在原生最初两对 frame/global 块（索引0、1）中加入 GS scene tokens，之后丢弃它们，原图像 token 继续全部原生层与 DPT。两个已有 global 块是出现上述回传路径的最小长度，不新增 Transformer 层、外部 reader、融合 gate 或深度头。GS 工作槽在 frame 块中单独做自身交互，在 global 块与图像 token 共同参与；几何／位置标签不随隐藏表示更新，所有临时内容均不写回持久场。

| 消息条件 | 强中心 P | 同迹球形 S | 完整形状 G |
| --- | --- | --- | --- |
| R：GS 可自身演化，禁止其读取当前图像 | R/P | R/S | R/G |
| U：GS 可读取当前图像，下一块可读回 | U/P | U/S | U/G |

两行原生变换、token 数和训练完全相同，仅切换第一个 global 块中“GS query 读取 image keys”的 mask；图像读取 GS 与图像自身交互始终允许。R不是每层重置或常数KV，这个强控制保留相同的原生来源变换，检验允许反馈的整体效应；mask也改变该行softmax归一化，不能将差异唯一解释为语义配准。第二个 global 的 GS 输出不再使用。不同query及full／missing条件各自从原场重建工作副本，绝不共享更新。

共同源 token 输入含完整 f／Σ／opacity、中心B／density，并加真实 GS alpha 合成的逐槽可见贡献量；普通几何统一按给定query相机坐标／原unit表示，保留既有asinh中心／log-cov变换，使P直接获得同一视角下的完整Σ。仅一个共享 affine 映射到原生1024维，f子块恒等初始化，其余零。真实渲染用于共同可见量，内容由原生 attention 读出，不称标准特征 alpha 合成。共同二维 RoPE 用投影中心；图像原二维 RoPE 保留。新增 K 位置字段沿用[既有 P/S/G 规则](../../../../docs/camera_only_feature_pe_execution_plan.md#3-唯一小模型与匹配pe)：共同中心／多尺度／B投影外四维是 density、球形、完整 footprint，单个共享29→64→1024位置 MLP末层零初始化，在两个 global 的 GS K 归一化／RoPE之前加入，不直接改V。全部 PE 组都有完整Σ普通内容及相同真实渲染信息；只比较编码分配，不声称新增信息或 nested 消融。原共同投影有效性规则保留，零覆盖 query 不筛除。

另训一个 **L 当前图像工作槽控制**：同样2048槽、U交互和全部可训练模块，内容由当前输入的1024个 encoder patch各复制两次；共享给定相机／坐标单位，但不读来源RGB、基元或GS内容。仅以query射线在一个单位深度平面上的交点生成中心／B／density，形状等其余普通输入用固定零／单位编码；采用P位置规则和原patch二维位置。这是无场的计算控制，单位平面不是预测或真值几何。它匹配可学习内容映射、计算深度与工作槽容量，少数固定几何输入系数不活跃须报告，不冒称信息相同。保留完全不适配、无场的 Native。这样可区分“多一条可训练当前图像通路”的解释；P/S/G之间仍是严格同信息、同参数、同采样比较。

**关键学习条件与预算。** 原32训练／12开发、来源[0,3,6,9]、四拟合 query／八query评价、full与missing、全部身份／ROI／valid不变。仅训练共同源映射、位置MLP以及最初两对原生 frame/global 的 rank8 QKV／输出 LoRA；其余官方权重、图像encoder、DPT和持久GS冻结。从同一官方权重和配对初值开始，不续训旧读取器；三原种子、每条件2000更新、batch2，共 **21 fits**。AdamW 1e−4、wd .01、clip5，沿原全图有效区域 raw／centered log-MSE 等权损失，末步评价，不新增feature目标。L与所有PE组同训练范围；所有持久场仅由来源形成，当前输入只进入本次工作副本，query GT只用于训练损失／评分。

**GPU总上限12 worker小时，新增DATA峰值≤12GiB、项目≤1GiB**，覆盖必要预检／恢复、全部拟合／评价／实际成本。只保留必要adapter最终与恢复状态，旧大权重只引用；Sol按实时GPU/CUDA、完整剩余产物及安全余量准入，保护他人和旧成果，预算不足保存交回。成本分列持久GS／模型、query工作副本峰值、实际渲染／场景处理、完整原生query与多query摊销；不把每query重新演化的隐藏状态称永久缓存或零成本。普通工程与计数遵守[现行协议](../protocol.md)，不增科学预审轮。

**主终点与决定。** 十二开发地点原四query的 missing-ROI centered log-depth MSE，首要 U/G 对 U/P；R行相同比较及反馈×PE交互 \((E_{U,P}-E_{U,G})-(E_{R,P}-E_{R,G})\) 预先指定，P/S/G全比较、对L／Native及完整raw／bias／全图AbsRel、拟合／其他query、逐地点／零覆盖／最大反例全部公开。沿用配对地点／种子区间。PE与对L、Native净用途均须有实用支持（平均降误差≥1%、95%下界>0、三seed同向），才留至多一个开发候选；G/S另界定非球形额外用途。正交互才能支持“反馈改变PE作用”，单独U比R好只属共同交互用途；若R已有效而U无实质增益，优先简化R，不能据差异不显著称等效。若S有效而G无额外支持，优先球形。仅共同适配／局部／feature改善或无原生净用途则结束这个两块工作副本PE家族，不自动加层、改mask、补seed或数据。全图和成本的材料代价由Astra权衡，小幅不确定辅助负均值不硬否决。所有数据仍已用，任何候选均须另审全历史并锁真正未用身份后确认。

O2/O3公共粗GS保持；O4/O5用实际渲染可见量及原生场景交互读取；O6这次直接位于既有原生 global attention，而非外部reader。C1来源回用原场、C2持久状态不变；实质改变C3的查询内消息图，C4复用同信息位置字段，C6改为匹配早期LoRA／原生深度学习；C5给定相机继续是临时选择。静态四源、sensor、已知ROI／深度端点、有限旧地点和两块／rank8均不是核心要求或已解决能力。本分析0 GPU／训练／新预测，无外部检索；完整目标未达、未暂停，旧结果／锁／反例不改。
