# round_029：结束固定预算的来源分解 PE 接法

2026-11-14。**按[round028合同](../round_028/science_plan.md)结束 native_source_resolved_pe1 及其自动变体；不晋升 F/G、F/S 或 F/M 表示，本次没有后继实施合同。** [完整报告](../../native_source_resolved_pe1/report.md)与[全部数表](../../native_source_resolved_pe1/report_tables.md)保留15×1000的正负结果、分层、反例、成本及原身份，不重训或改主终点。

**主 PE、表示效应和交互均未建立。** 开发原 query 的 F/G−F/P 为 **+0.156 pp [−0.718,+0.986]**；F/P−M/P 为 +0.307 pp [−0.956,+1.706]；交互为 +0.320 pp [−1.342,+2.114]。三者回答不同问题，不能互相替代。F/S−F/P 为−0.398 pp，次要候选也未达原筛。开发其他 query 的 F/G−F/P 为−0.609 pp，训练原／其他 query 为−0.029／−0.264 pp，区间均跨零；因此不能仅归为跨地点泛化。主 PE 的 EPE／尾部差也近零且不确定，不能把失败只归于 PCK 阈值。结束投入不等于零效应、非劣性或强中心普遍充分。

**共同用途和辅助正证据仍保留。** F/G 对 Native4 的 PCK 提升 **16.449 pp [13.457,20.064]**，EPE／尾部也有支持的改善；F/P同样提升16.293 pp，且[原跟踪轮](../round_027/science_plan.md)的 L 已有共同适配收益。Native4未获GS来源sensor／pose特权，正差只属该条件。F/G 对旧完整均值 P、L 的主差分别为−2.499／−1.176 pp，区间跨零，未建立净优势，也未证明材料性损伤。新表示在训练拟合时对旧 P 的 EPE 改善同时见于 F/P 和 M/P；训练其他 query 的 F/P 对 L 有+0.785 pp [0.086,1.516]的辅助改善。开发对 L 的连续误差有利均值仍不确定。这些与此前[区域差分 K 阳性、绝对替代 R 未决](../round_026/science_plan.md)一起保留，不能改称来源残差、形状 PE 或主 PCK 成功。

**这次真正检验了关联保留，仍未支持“提前均值是主要障碍”。** F/M 在同1024维预算下共享均值、来源质量和几何，F保留M不能恢复的逐来源残差；区别于[先前单均值读出](../round_027/science_plan.md)，不是仅换 PE 名称。结果削弱的是“用此来源分解就足以解锁原生对应和 footprint 增量”，没有证明所有来源差异无用。来源编号仍不等于跨图同一物理点；上下文／遮挡差异、通道分辨率取舍、强中心与普通完整Σ吸收布局、几何可见性及当前学习范围仍是相容解释，现有结果未选出唯一病因。PCA保留94.50%来源方差也不保证保留对应所需的区别性信息。

实数解码初值相同，但FP16保存／BF16计算的固定预检产生最大4.655像素的输出差，不能当作可忽略的纯舍入量。故F/M及其交互是**实际表示与学习链的总比较**，不是排除数值路径后的纯残差因果量；这项F/M边界不使同一F表示内的G/P比较失去意义。既不能据此把阴性改判实现失败，也不能推断差异恰好掩盖了正效应。原合同已预见有限精度披露，本轮没有理由追加精度修补或重训。

**具体取舍：保留完整均值为简单研究参照，不采用本次来源分解，不派生秩／来源权重／分量数／PE层／seed／步数／数据扫描或置换诊断串。** [round016成场](../round_016/science_plan.md)、[round020地址偏置](../round_020/science_plan.md)及round027的关闭不改。本次已经检验一个非可逆的关联保留改动，不能再把“是否试过保留来源分量”列为未知。尚未建立的是：压缩场中哪一种可保留的关系能被原生对应实际利用，并使同信息参数位置组织优于强中心；来源残差存在本身未给出这种任务条件。现有证据没有在上述竞争解释间提供足以选择另一项精炼干预的依据；这不是要求实验前证明收益，而是不由一个未决均值自动选择下一种压缩或读取变体。**本次后继实施预算为零，下一实质问题尚未选定；没有工程待完成项或需要用户补给的外部输入。**

O2/O3公共粗GS、O4多query读取、O5渲染参数、O6同信息强中心增量与下游用途仍是核心；本轮C2来源分解与配套C4/C6接法结束，C1/C3/C5沿用范围不晋升普适要求。来源sensor／相机特权、静态四源、PCA255、混合锚前缀、冻结范围和有限点标签均是实验选择。开发只有112/192个view对有标签，全部零支持及反例保留；例如fidelity_09／seed20261111／锚6→query5的38点PE反例并非只有极少标签的个案。共同源前缀、全局PCA和旧场形成仍计依赖，固定顺序单例成本不证明G加速或纯GS替代历史。全部数据used，无fresh候选；完整目标未达、未暂停，无外部阻塞，持续研究授权保持。本分析0 GPU／训练／新预测／下载／旧统计复算。
