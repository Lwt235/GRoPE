# round_025：同一区域的跨视图内容能否替换

2026-11-14。**锁定一次 native_crossview_content1 测量，交 Sol 实施；不训练或重开旧 reader。** 唯一问题是：实际用于公共记忆绑定／形成监督的单图1024维DINO特征，在共同可见的同一表面区域，是否保留可跨视图识别的空间内容，以及原向量是否可以直接替换？这是C2内容载体证据，允许独立获取；后续任何参数PE主张仍须同信息强中心、共同容量／训练及原生基线。本轮不设置PE组，不把内容阳性当O6成功。

**为何值得测量。** [round024](../round_024/science_plan.md)已结束局部输入支撑理由：G/P未达，G/S条件阳性与广域敏感度保留。导数布局不能回答实际向量跨视图是否对应；[source-only特征形成](../round_012/science_plan.md)与[原生任务成场](../round_016/science_plan.md)的重构／训练内正例也没有隔离共同可见成员、区域身份和view变化。本次改变的是观测量与匹配关系，不是场、PE位置或训练量。[新输入事实](crossview_input_facts.json)确认现有RGB／相机／完整特征／sensor缓存可用，尚无跨视图统计。竞争解释为：存在稳定区域内容；只有地点／图像整体相似；有稳定区域差分但向量带view成分；遮挡、成员变化或几何重采样造成表观不一致。

**固定输入和匹配。** 只用既有12开发地点、四source（0/3/6/9）和四query（2/5/8/11），共96图。主集合是每地点全部query×source；六个source–source对仅辅助。完整原1024维缓存保持，无新编码、白化、PCA或学习；query特征／sensor仅用于离线测量，不写回公共状态。J场不重建，也不用其Σ／读行挑区域。

- 在共同210网格做几何：query用已存target/valid/K_metric；source的448 sensor与common_valid按原最近邻变换缩到210，相机内参同比例变换。不能由填充值1反推sensor有效性，必须保留common_valid。沿既有裁剪／像素约定回投到448图及32×32特征网格。
- 区域固定为query原生14×14像素patch足迹；source–source辅助按较早帧作锚。区域内210网格表面点须两端有效、在画面内，双向深度差不超过max(0.02 m, 2%深度)，双向回投误差不超过1个210网格像素。共同可见点至少占区域网格点一半且不少于16个，才定义该区域。两视图在**同一批世界点、同一权重**上双线性读取并平均原特征；权重为锚网格均匀，非均匀表面积。这样固定可见成员与采样量；上下文及patch混合仍是被测表征的一部分。
- 每个view对内，区域r匹配一个异区域t：两端深度分别相差不超过25%，公共样点在两端投影的两主轴尺度分别不超过1.5倍，覆盖率相差不超过0.10；各视图中参与特征插值的patch索引集合须不相交。仅由几何选取最接近者，固定网格顺序、无放回；距离为上述有界差异按各自容差归一后等权平方和，平手按网格ID。匹配表在读取特征数值前确定。不合格／无匹配项列入覆盖账，不放宽条件或换数据。

**同一四向量的反事实与主终点。** 对每对区域得到 \(x=f_q(r),y=f_s(r),u=f_q(t),v=f_s(t)\)，令 \(d(a,b)=\|a-b\|^2/1024\)：

\[
E_{\rm same}=\tfrac12[d(x,y)+d(u,v)],\quad
E_{\rm swap}=\tfrac12[d(x,v)+d(u,y)],\quad
E_{\rm within}=\tfrac12[d(x,u)+d(y,v)].
\]

同区域与交换区域完全复用四个向量、view和质量边际，不用容易的跨地点负例。**主量 \(K=(\bar E_{\rm swap}-\bar E_{\rm same})/\bar E_{\rm within}\)** 衡量区域差分的跨视图保留，范围[−1,1]；它消去共同view偏移的交叉项，故不能单凭K阳性称原向量可替换。必要辅助 **\(R=\bar E_{\rm same}/\bar E_{\rm within}\)** 保留原向量差异：R=1是跨view误差与同view异区域差异相当的参照。无额外中心化／范数匹配消掉R的代价。

每个view对先等权平均区域对的三个E，再按source、query等权形成地点量，最后计算该地点K/R；主报告地点等权均值及5000次地点bootstrap 95%区间（固定seed=20261114）。零空间对比的区域不筛掉；地点分母为零则未定义，不补零。完整记录地点／query／视图对／区域覆盖、无效原因、深度及回投残差、投影尺度／视角和空间间隔、原三个E、K/R及反例。source–source只作辅助，不以不同区间冒充交互。跨地点推断限实际有定义地点；仅一个地点时不估总体区间。实看对应区域与最大反例，避免将明显错配解释为表征性质。几何阈值是本次观测精度和范围，不是普适前置门禁；不扫描阈值、区域、归一化或子组以救主量。

**事前取舍。** K的主区间下界>0才支持具体区域身份超出整体view／地点相似；否则按区间和覆盖明确未支持／反证／不可辨，结束本测量，不推断所有内容或PE无效。在K有支持时：若R区间上界<1，保留“该共同可见范围内原内容有直接替换基础”，削弱必须先改变内容表示的理由；若R区间下界>1，则“区域差分共享、原向量替换代价大”成为下一状态形成问题的具体依据，优先考察共享内容与view成分如何分离，不能继续把单一常量向量当已证稳定地址；R跨1则只支持区域信号、替换性未决。几何残差／覆盖若不足以承载上述解释，如实限缩范围，不改条件填满。任何分支都不自动重训或采用旧方法；Astra据完整结果决定唯一后续问题。
