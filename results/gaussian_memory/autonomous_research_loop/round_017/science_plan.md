# round_017：相对仿射运输有明确含义，但不据此重开原生 PE 实验

2026-11-14。**拒绝把当前猜想直接立为下一项实验；本轮无 Sol 实施合同。** 双侧逆／对偶作用不是 R5 期望衰减或 R6 二次位置项的同义改写，但其核心相对算子与自关系抵消已经进入实际 R50/R53 和 HRoPE 接法。把矩阵改由保存的物理 GS 确定，是尚需判断的条件差异；它不因已有阴性被普遍否决，也不足以仅凭恒等式获得下一次拟合预算。[round016关闭决定](../round_016/science_plan.md)及其全部正负证据不变，不重新分析结果。

**算子究竟增加什么。** 令 \(A_i=[L_i,\mu_i;0,1]\)、\(L_iL_i^T=\Sigma_i\)，则

\[
T_{ij}=A_i^{-1}A_j=
\begin{bmatrix}L_i^{-1}L_j&L_i^{-1}(\mu_j-\mu_i)\\0&1\end{bmatrix},
\quad (A_i^{-T}q_i)^T(A_jk_j)=q_i^TT_{ij}k_j.
\]

它把 j 的仿射坐标送到 i 的坐标：共享 L 时仍保留位移白化，\(T_{ii}=I\)，且相对变换可复合。这些是具体归纳偏置。它一般不同于 \(q_i^TT_i^TT_jk_j\) 的双侧同变换；[R5及其代码](../../../../models/round5_cross_attention.py)用 Gaussian 期望旋转／后归一化，后归一化控制范数但一般不恢复任意 q、k 的原自点积。[R6实际代码](../../../../models/gaussian_quadratic_pe.py)则把 Mahalanobis 位置能量作为内容点积外的五维二次项，不能与内容相关的 \(T_{ij}\) 混称。[R5结果](../../../../docs/archive/2026-11-04/round5_report.md)未支持强点对照增量；[R6结果](../../../../docs/archive/2026-11-04/round6_report.md)的区域分布正证据仍保留，二者都不决定此算子在原生任务的效果。

**更直接的历史覆盖。** [R50的 `matrices/encode`](../../../../models/round50_local_frame.py)已构造 \(G=[R\operatorname{diag}(e^s)R^T,\mu;0,1]\)，Q 乘 \(G^{-T}\)、K 乘 G，正是这里的 \(q_i^TG_i^{-1}G_jk_j\)，另有 V／输出运输和半头二维旋转。[R50报告](../../../../docs/archive/2026-11-04/docs/round50_local_frame_report.md)保留普通条件细定位收益，但完整形状未稳定胜过同信息 MLP／一般仿射，且真实视觉依赖受其任务信息结构限制。[R53实际代码](../../../../models/round53_ray_frame.py)进一步用射线中心、Cholesky 与 \((CG)^{-1}\)；[结果](../../../../docs/archive/2026-11-04/docs/round53_ray_frame_report.md)支持有限射线坐标收益，完整形状相对射线点的额外 EPE 仅 0.0201 px、方向不稳。现用[HRoPE实现](../../../../models/region_hrope_control.py)的几何部分为 \(q_i^TH_iH_j^{-1}k_j\)，取 \(A_i=H_i^{-1}\)属于同一对偶关系族；矩阵约束、维数和 V／输出路径并不完全相同。**因此“逆框架／自抵消尚未试过”不成立；“物理场直接定框架已经完全试过”也不能由这些学习型潜在框架推出。**

**两个有界反事实，均非数值门禁。** 同一 Σ 可用 \(L_iO_i\) 表示；对应 \(T'_{ij}=\bar O_i^TT_{ij}\bar O_j\)，未随基底转动的内容会得到不同分数。对称正定平方根或正对角 Cholesky 可以固定这一选择，R50/R53也已这样处理；不是不可解决的障碍。再取中心相同、\(L_i=I,L_j=2I\)，单位内容 \(q=k=(1,0,0,0)^T\)：自分数为1，跨 token 分数为2。自关系抵消没有消除跨 token 的尺度增益，也不保证注意力偏好相同支撑。这个有限例子不证明方法会失败；它限定了自恒等式能说明的内容。薄法向还可能同时放大有用的表面区分与几何误差，不能据极端上界否决，也不据此自动增加归一化／截断扫描。

**未成立的是任务桥接，而非代数。** 当前公共 GS 的1024D内容由来源特征绑定或共享 writer 形成，没有按 L 保存的局部坐标基系数／一阶空间特征；原生图像 query 也没有与某一 GS 相同的 i 身份。因此跨视图读取中的正确对应并不自动得到 \(T_{ii}=I\)。可以合法地把来源 Gaussian 投影到图像、用已知 patch 作为 query 框架，但公共 query 尺度固定后，新增形状作用主要成为 key 端内容线性变换；“局部坐标运输避免自衰减”仍未说明为何它应改善现有内容的原生读取。若内容本身是局部仿射函数／矩的坐标表示，对偶运输会有直接意义，但那需要具体改变并匹配内容形成，不能仅给现有特征换名称。[round008的内容地址边界](../round_008/science_plan.md)与[round010的直接算子判断](../round_010/science_plan.md)仍适用。

这里**不要求 Q/K 每个通道都有物理解释，也不要求实验前证明收益**；同信息下确定性几何先验可能优于学习型映射。问题是当前唯一新增理由——由物理支撑取代已试潜在框架、凭自抵消服务读取——没有给出相对于上述历史的具体内容／任务条件反事实。仅换平方根、移除 V 运输或移植进已关闭 reader，会留下同一缺口。故不选择矩阵、接口、监督或训练，不追加玩具／组件成绩、矩阵／尺度／频率扫描或综述。

本阶段仅原报告／代码只读核对和上述解析例子，**0 GPU、训练、新预测、下载及新外部取证；后继实验预算为0**。O2–O5 公共粗 GS 与真实读取要求保持，O6 仍要求同信息强中心上的可靠原生增量；本轮只澄清 C2 内容坐标与 C4 算子，C1–C6无新实施选择。sensor、给定相机、静态来源、depth、旧数据等仍是临时范围，不升级为排除其他任务的要求。整体目标未达、未暂停、无外部阻塞或 fresh 候选；本候选的有界审查结束，不等于全部 Gaussian PE 研究结束。
