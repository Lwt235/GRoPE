# round_027：结束本次原生跟踪 PE 接法

2026-11-14。**按[原合同](../round_026/science_plan.md)结束 native_track_memory_pe1 的单块只读 GS／实际预测 query 相机／原生 TrackHead 接法及自动变体；不晋升 G、S 或 P，本轮没有后继实施合同。** 完整[报告](../../native_track_memory_pe1/report.md)与[数表](../../native_track_memory_pe1/report_tables.md)保留全部正负、覆盖、反例和成本；不重跑或改主终点。

**主结果没有建立参数 PE 增量。** 开发原 query 的 G−P 为 **−0.081 pp [−2.135,+1.982]**，三种子一正两负；S−P 为 +0.724 pp [−1.497,+2.902]，均未达到原定均值≥1 pp且区间下界>0。G−S也未支持非球形增量。开发其他 query 的 G−P为−0.252 pp，训练原／其他 query 为−0.012／+0.101 pp，区间均跨零，因此不能只归因为跨地点泛化。区间仍容许有意义的正效应，结束投入不等于零效应、非劣性或强中心普遍充分。

**共同适配、来源线索与 PE 分开。** G 对 Native4 的主 PCK 提升 **18.867 pp [12.584,26.659]**，但 L 同样提升17.625 pp；G−L为 **1.242 pp [−1.277,+4.684]**，预定净用途未立。另一方面，G 对 L 的连续 EPE／每 view 对95%尾部减少 **1.552／2.334像素**，对应区间均支持；其他 query 同样改善，P/S也有相关改善。保留这份来源信息与几何条件下的辅助用途线索，不能概括成“只有适配有效”，也不能把它改称 PCK 主成功或形状 PE。L并非同信息基线，G/L同时改变来源内容、几何输入及学习结果；Native4缺少 GS 的来源 sensor／pose 特权，不能从其低分单独证明记忆特有收益。

**竞争解释有所收窄，尚未唯一定位。** [R5](../../../../docs/archive/2026-11-04/round5_report.md)在已知 query 相机的对应任务中未建立实用形状增量；[原生 pose](../round_010/science_plan.md)有真实初值但监督全局位姿，本轮直接监督原生点坐标。因而“换成真实相机初值与局部对应任务就足以解锁形状”没有得到支持，PCK约27%也不能用接近上限解释。此前[区域差分 K 阳性](../round_026/science_plan.md)继续有效，但未证明 alpha 绑定后的场保留了原生跟踪所需的全部区别性关系。强中心／普通完整Σ已吸收可用布局、内容压缩与原生对应表征不匹配、预测几何／可见性及当前学习范围限制，仍是相容解释。训练可响应且 L 提升削弱了“整个链不能学习”，但不证明此配置已充分优化；2280个无标签 batch、冻结 TrackHead 等边界不能自动变成补步数或解冻的理由。[工作副本](../round_013/science_plan.md)、[任务成场](../round_016/science_plan.md)等已试条件与关闭决定不改。

**范围和代价限制采用。** 开发主标签仅覆盖112/192个 view 对、2414/12288个点，fidelity_03仅一对；56个标定无效对和38个零 GS 支持对均无 GT 点，不能据此证明这些条件的用途。sensor／pose可见对应不是独立实物追踪真值，全部稀疏反例保留。混合锚前缀＋GS仍需两次 query 原生路径；固定已准备RGB单例 G 完整 query 为1.781秒、一次来源前缀／标定0.559秒，部署依赖173.817 MiB，不只依赖4.614 MiB的场／来源几何张量。固定顺序首次开销未分离，不据此推断稳定速度排序；10.769 worker小时的完整交付、旧 manager 停止来源 unknown 等工程事实无需追加验收。

**后继取舍与可行动信息缺口。** 不再把内容支撑／区域信号写成全未知，也不重复其测量。尚需区分的是：公共场在压缩后保留的来源区域关联，如何影响真实原生对应，是否提供超出共同几何与当前图像适配的可组织信息。可取证对象是源点对应、现有绑定来源关系与原生读取；当前 K 测压缩前特征，G/L不是固定接收器、同几何下的关联干预。若后续能提出保持信息／容量、直接改变关联保留方式的具体对照，或由内容／可见性事先定义的任务条件，才有新的可推翻问题；不需要先证明 PE 阳性或唯一病因。当前结果尚不能指定这样一个精炼改变。仅再置换值确认固定模型依赖，也没有预定的设计选择可据其结果改变，故不串联另一项诊断，不自动换内容层、加模块、修相机、补 seed／步数／数据。**本次后继实施预算为零；持续研究授权保持，下一实质问题尚未选定。**
