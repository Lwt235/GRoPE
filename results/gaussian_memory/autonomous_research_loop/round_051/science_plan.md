# round051：有界几何矩地图，直接读取位姿约束

2026-11-15。**选择一次`stream_geometric_map1`。** 唯一问题：原生点图压成可递推的公共表面统计后，能否在同实际总历史byte下改善长间隔重访定位？地图直接参与当前位姿的几何配准，不再拟合／合并各层K/V、不加PE，也不把已关闭STAC加cap后重跑。完整高斯形状是待检验选择；强面元控制可能更好。以下为唯一科学合同，工程实现及精确调用／存储账由Sol补充。

**机制与竞争解释。** 原图和隐藏值删除后，一个表面区域的中心与二阶矩仍能定义当前点图相对它的几何残差；这个任务含义不要求K/V随XYZ平滑或可以互换。非球形支撑可能保留有限表面的方向和范围；竞争解释是中心＋法向已经足够，或原生深度的尺度／非刚性误差、初值偏差、遮挡与融合漂移使配准损害定位。[Generalized-ICP §III](https://www.robots.ox.ac.uk/~avsegal/resources/papers/Generalized_ICP.pdf)给出了双侧局部几何矩进入配准度量的先例，但其range-scan结果不证明本原生点图方案有效。这里的Σ描述已预测表面样本的分布，**不是已标定的定位／测量不确定性**；本轮不声称发明配准算法。

**状态、递推、遗忘与读取。**

- 状态为`S_t=(有界原生KV/相机状态, H_t, h, {cell_id,n,μ,Σ}_{≤4096})`。`H_t∈SE(3)`是原生坐标到地图的当前校正；固定首帧gauge。冻结既有官方权重，单帧因果输入，所有24层保持原norm／来源RoPE语义。CameraHead每次只对首帧＋最近7帧（含当前帧）的pose-token做原四轮精化，只发布当前姿态，不回溯修订旧输出。地图前端使用下述C的有界内容政策；G/P完全共享该前端、分开维护各自地图和校正，不向原生hidden或训练权重写回几何。当前图像先读旧地图得到输出，再成为未来来源；没有GT、教师、他组状态或已淘汰图像回流。
- 当前原生depth／intrinsics／camera把每个原生patch内有限正深度像素反投影，得到`(x_i,Q_i)`中心和总体协方差。先施加上一校正`H_{t−1}`；从单位增量开始，至多20次共同配准外迭代，修正当前camera和当前世界点图，depth与intrinsics不改。无可定义匹配／秩不足／数值失败时保持上一校正，输出与失败仍评价。不会按GT或预测效果跳过帧。
- 地图用固定世界立方格。边长`h`取首个有效原生来源帧正深度中位数的1/32，之后不改；未定义前地图为空。当前校正后的patch按中心所在cell入库，合并矩含组内`Q_i`与中心散布；同一帧同cell先汇总，再以一个视图的质量递推`n,μ,Σ`，不把像素密度当独立观测证据。只保存统计，不保存成员／旧patch／图像。已占格超过4096时保留固定64-bit hash优先级最小的4096个cell，其他永久忘记；碰撞按cell坐标，seed固定20261115，不搜索。计数固定宽度并饱和处理，不扩展来源ID列表。此共同规则只控制有界存储，不宣称新颖或最优空间选择。
- 每次迭代按变换后中心找地图最近中心，距离超过`3h`不参加配准；所有组同规则、同求解器。令`r=R x_i+t−μ_j`，`D=F(Σ_j)+R F(Q_i)Rᵀ+(h/10)^2 I`，最小化共同Huber损失`ρ(√(rᵀD⁻¹r))`，转折固定3。G取`F(Σ)=Σ`；强面元P保留完整普通统计用于递推，但读取时将最大两特征值替为其均值，保留最小特征值及法向。故P获得中心、法向、trace、法向厚度和相同来源信息，G只额外保留切向非对称形状；不是拿无几何或弱距离控制制造优势。这个能量是条件几何度量，不冒称完整生成似然或精确Bayes后验。

**必要对照与真实byte。** 一次固定**B=3 GiB**总历史上限：这是面向小历史内存的部署点，低于本96帧全部原生KV的已知存储需求；不由效果寻找临界配额。G/P同4096槽、同最大合法前端容量、同形成和求解条件。C是强普通内容基线：首帧＋最近3个已提交帧固定，当前帧另作当前输入，提交后更新近期槽；余下容量按已核实作者attention列和／衰减规则保留HH有效K/V，禁止空间库；W为同接口下首帧＋最大合法近期窗口。C/W可把地图／求解器释放的字节用于更多原生条目，不填充预算；几何组按包括其完整工作区的同一B确定前端容量，全部容量在效果评价前固定。C/W各完整运行，不继承旧chunk4／全前缀camera成绩；如果某对照在实际容量下等价，只作一个输出条件解释。

有界性来自固定原生容量、固定8个camera-token、4096格、一个SE(3)及固定分辨率当前帧／有上界配准工作区，**与流长无关**。所有层、特殊token、统计／索引、转换与恢复副本、模型可读CPU／磁盘backing都计入B；不得缓存全历史RGB、点图、pose graph或成员。评价归档只可写，模型不能回读；导出的历史轨迹也不是可访问状态。权重和通用当前模型激活另报，历史专属工作区计费。记录实际byte和未用余量；这是一个受控预算点，不声称最优前沿。全局容量规则是算法性质，96帧只检验其有限运行和效果，不冒称任意长时间定位可靠。

**主终点、条件与投入。** 原12地点×96稀疏帧、原RGB／GT重访身份不变；全部used，0训练、0新数据／权重下载。GT仅离线评分，不定h／容量／匹配／入库。主终点为地点等权重访相对旋转改善`E_C−E_G`；预定G/P辨别完整形状，G/W辨别普通窗口净用途，P/C与P/W是优先简化的次要比较。沿用原配对地点区间、留一地点、主NA、零覆盖、支持层与全部反例；保留平移、绝对几何、全帧／非重访、raw／centered／bias／AbsRel及失败，不以配准残差代替原生输出。G/P是原生预测＋几何记忆的系统输出，不宣称原生attention本身改善；其共享前端可复用实际推理，但每种方法完整成本均须包含前端和本地图的构建／读取／更新，不把共享执行当免费推理。地图反馈导致分组后的形成不同，比较是在线政策总效应，不是固定地图上的纯形状因果。

一次总上限：**6 GPU worker小时、8 CPU worker小时、新增DATA峰值32 GiB、项目1 GiB、单worker显存40 GiB**，含必要预检、失败／恢复和全部评价成本；预检包含在正式预算，能复用的固定首流结果复用。普通接口、共同数值求解和计数由Sol完成，不另开审核轮；预算无法容纳则保存实测缺口，不暗改组数、帧数、地图／窗口或求解超参数。按实时安全空卡与剩余任务并行，保护旧成果及他人进程。

**结果分支。** 主G/C均值≥1°且95%下界>0、G/W有支持的正收益，才保留一个开发用途线索；只有G/P也达到上述材料标准，才称完整形状超过强面元。若完整形状不支持而P对C/W均有材料收益，优先简单面元，不把它改称G主成功。若仅改善配准残差／局部支持、只胜较差控制或未建立原生净用途，结束这个固定“矩地图＋局部刚体配准”家族及自动变体，不改grid、hash、容量、距离／正则、SE(3)/尺度自由度或数据救它。明显平移／几何尾部损伤及完整时延必须限制采用；小且不确定辅助负均值不作零容差门禁。所有结果交Astra统一取舍；开发阳性仍须另锁真正未用数据独立确认。
