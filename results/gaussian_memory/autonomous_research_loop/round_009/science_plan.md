# round_009：真实原生初值下的公共 GS 相机细化

2026-11-13。**支持一次有限开发比较 `native_pose_memory_pe1`。** 新问题是：完整 query RGB 与同一公共粗 GS 建立内容—位置联系后，Gaussian PE 能否比同信息强中心编码，更可靠地改善 **VGGT 原生相机头输出的真实 6DoF 位姿**？本次仅论证和定合同，0 GPU、训练、新预测、外部取证；不重开深度填补或 round008 区域语义问题。

**依据和反事实。** 已知 query 相机的深度任务把视图—地图对齐作为输入；这里对齐本身是待预测量，训练信号要求同一个相机修正同时解释整幅图像中的内容关系。物理 Σ 的投影支撑可能帮助注意力在真实初值误差下组织这些关系；也可能只是模糊了精确中心，或其信息已被普通内容／学习型相机编码充分利用。Σ 仍是基元支撑，**不是位姿估计的协方差**，不按初值误差调其大小。若所有组改善、G 不胜 P，结论是共同适配／记忆用途；若 G 只改善匹配代理而不改善原生相机，O6 的本任务用途不成立。这个可推翻问题来自任务响应与监督的变化，不是“未知相机”或新注入层本身。

**直接历史限制。** [incremental_vggt1](../../incremental_vggt1/report.md)已做在线状态，[native_history1](../../native_history1/report.md)已复现因果原生缓存；本轮不主张首次 streaming。[native_gaussian_pe1](../../native_gaussian_pe1/report.md)甚至已用第一遍预测相机／深度形成 PE，但只训练和评分深度，位置增量近零；因此预测相机不是新发明。[区域配准](../../../region_pose_utility/attempt1/report.md)的五维正例是观测区域中心求解，随后[同相机信息 HRoPE 确认](../../../region_hrope_confirmation/attempt1/report.md)中 HRoPE/F 为 35.382%/32.569%，五维剩余优势不可靠；本轮不退回仅标量距离的弱控制，也不把旧中心 RMSE 称真实相机误差。[来源质量](../../source_geometry_control1/report.md)及[camera-only](../../camera_only_feature_pe1/report.md)的阴性保持：本轮既不改善来源来挽救旧 PE，也不再以特征／深度填补当主终点。

**共同初始化与真正的范围。** 复用官方 StreamVGGT、原 44 场及 [32 训练／12 开发身份](../../native_training_coverage1/plan.json)，来源仍为 `[0,3,6,9]`；完整 query RGB，无人工遮挡或扰动。先逐来源建立官方 aggregator／camera prefix，再对每个 query 独立分叉，得到同一冻结的原生相机、内参、深度和特征初值。只用来源把其坐标映入原 GS：首来源相机定旋转／原点，四来源有效相机基线比的中位数定尺度；无有效基线时，仅用首来源有效 sensor/predicted depth 比中位数回退。对齐不可用须记录并在全部组计失败，不按效果删 query。该变换一次形成，query 真值不参与初始化、尺度、PE、渲染或选择；所有组共用。query 内参保持第一遍实际预测值，本轮只细化外参。

单图原生相机的自有坐标系不能直接冒充地图全局位姿。故 **Native 是“同一来源 prefix、无 GS 的原生基线”，不是无历史单帧定位**；全部 prefix 状态与两次相机头调用计入成本。GS 仍是一次构建、多 query 复用的公共附加状态，本轮不证明它替代 dense prefix、独立紧凑重定位、因果在线 SLAM 或纯 RGB 建图。

**唯一模型与必要对照。** 官方 VGGT／相机头、原 GS 几何及绑定内容全部冻结。只学一个宽 192、4 头的 attention reader 和其 camera-token 残差输出：Q 来自当前图像 patch 特征、同一预测几何及在初值相机下的真实 GS 渲染特征／覆盖；K/V 来自同一保存 GS。逐 patch 读出与共同 Q 表示拼合后平均池化，经一个小残差 MLP 加到原生末层 camera token，零初始化末层；再以同一查询前 camera prefix 运行原相机头，不把第一次 query 的缓存追加为新历史。不另设独立 pose 预测头、writer、外层迭代或深度修补分支。

| 组别 | 固定作用与可支持的比较 |
| --- | --- |
| Native | 未适配的官方初始化；保留完整真实相机误差与来源 prefix 成本 |
| L | 同 reader／输出容量与训练，K/V 改为当前 query 的 patch 内容和第一遍预测的 patch 几何，GS 渲染输入置零；控制仅靠当前视图适配，无新增 GS 信息 |
| P / S / G | 同一 GS、完整 Σ 普通内容、中心邻域散布 B／多尺度密度、相机和覆盖、可训练容量及样本流；只比较位置组织 |

P/S/G 共同使用已核查的[区域 HRoPE 结构化 Q/K/V／输出变换](../../../../docs/region_hrope_control_plan.md)，由各自的共同普通 token 内容预测；query 像素与初值投影的 GS 中心提供二维坐标，所有组均不输入真实 query 外参。它是同一 attention 内的共同强基底，不另堆一个 Transformer。K 加位置后再施加上述共同变换。位置字段沿用[camera-only 合同 §2–3](../../../../docs/camera_only_feature_pe_execution_plan.md)的 **29 维 K 位置字段**及同容量位置 MLP：共同 25 维含中心方向、多尺度投影和 B 的投影；末四维 P 为中心密度，S 为 trace 球形 footprint，G 为完整 Σ footprint。三组普通内容均保留完整 Σ，P 也能学习利用它；S/G 不独占源信息，B 不算 Gaussian 特有信息。这是固定位置容量的组织比较，非 nested 加信息实验。L 沿用同一强基底及 P 字段，用其预测 patch 点集矩／邻域形成当前视图几何；不破坏 P 的中心或给 G 人造误差优势。公共 GS 基底及 learned K/V 可缓存；query 相关投影／HRoPE 在读取时计算。

**学习、主终点与一次预算。** 拟合 query `[2,5,8,11]`，其余 `[1,4,7,10]` 只评价；全部旧数据，仅开发。L/P/S/G × 原三种子 `20261110/11/12`，每次 2000 更新、batch 2、同初始化和样本顺序；AdamW `lr=3e-4, wd=.01, clip=5`，最终权重，不选模／搜索。唯一 loss 为地图相机中心误差平方除来源单位平方，加旋转 geodesic 误差（弧度）平方；训练真值只进入此 loss。Native 无新训练。预算 **12 fits，GPU ≤8 worker 小时，新增 DATA ≤24 GiB、项目 ≤2 GiB**，含必要预检／失败恢复／完整评价与成本；不下载或重拟合来源。Sol 负责精确计数、普通接口和恢复，启动前按实时 GPU/CUDA 与峰值空间准入，保护他人任务与旧成果，预算不足完整保存交回，不悄悄缩样本或增预算。

主终点为 **12 开发地点原四 query，真实相机旋转误差 <5° 且相机中心误差 <0.2 m 的成功率，G−P（pp）**；这是本轮室内细化容差，不称标准 benchmark，也不是旧区域中心 RMSE。地点／种子等权及配对重采样，保留全部 query、无效／零支持／大错，不事后按初始化或重叠挑样本。实用开发筛为均值 ≥1 pp、95% 下界 >0、三种子同向；同时报告 S−P、G−S、每组对 L／Native。直接旋转／平移的完整分布、中位数和 p90、训练拟合／其他 query、开发其他 query、初值误差与预测覆盖分层、最大反例及完整成本均保留。成本分开列 source/GS 构建、dense prefix、单 query 原生初始化、GS 读取与相机头、缓存 bytes 和摊销；不能只报小 reader 时延。

**结果改变什么决定。** 至多保留一个 G 或更简单的 S 开发候选：主 PE 增量及对 L／Native 的净成功率均须满足上述实用筛；只有 G−S 也有明确增量才称各向异性额外用途。若只是共同读取有益，保留该条件用途、关闭本相机细化 PE 家族的自动变体；若 PE 有组件／局部线索而原生净用途未达，分层记录并同样结束，不靠换端点、增加拟合或人造扰动续命。全部阴性也不普遍否定 GS-PE。旋转／平移尾部和成本损伤由 Astra 按实质权衡，小且不确定的反向辅助均值不作零容差门禁；不把跨零当非劣性。开发候选不等于采用，后续须先全历史审查并锁真正未用身份；当前没有 verified fresh reserve。

O2/O3 公共粗 GS、O4 读取、O5 实际渲染／参数、O6 同信息 PE 与原生用途保持；O6 位于服务原生 camera head 的 memory-reader Transformer，**非官方 24 层本体新增 PE**。C1 来源形成不变；C2 共享 K/V、C3 相机细化、C4 匹配强基底与 P/S/G、C5 实际 query 初值、C6 位姿监督按上述改变。来源传感器／给定来源相机、静态四源、额外 dense prefix、冻结 backbone、旧数据均是临时范围，不冒称完整目标已达。分析不调度实施；主顺序交回既有 Sol CLI，早 query 仍可读取后时刻 reference，这是静态地图定位，不是因果流式评价。原报告、锁、反例及 round008 无设计结论均不改。
