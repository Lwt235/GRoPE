# 当前权威研究目标：revision31的近期目标更新

2026-11-15。依据用户本次请求及[原Astra/max复核](analysis.md)，总体目标保持revision31，近期目标更新到正在实施的round036；旧[目标形成记录](../round_031/revised_goal.md)和所有结果保留。持续自主授权与已经收到的恢复指令有效，当前active。本次不是新的实验合同。

为VGGT／StreamVGGT研究可跨视图、跨时间复用的有界公共三维场景记忆，以各向异性高斯空间组织为待验证候选。在相同实际总历史字节预算与输入权限下，与短窗、普通原生token保存／检索及相应强空间基线比较，评价原生几何精度、长间隔重访一致性、失败范围和完整读写／传输成本。区分历史信息价值、受控组织机制、独立在线反馈与最终系统效用，不预设高斯获胜。

PE与渲染是可选组件；另主张PE收益时，仍须同信息强中心及球形对照。未具备相应外观、opacity和渲染证据的K/V组织称高斯空间记忆，不预称完整3DGS。保留全部旧正负、反例和家族关闭决定；已有数据继续登记为used，方法采用前须在真正未参与开发的数据上独立确认。目标是有依据的方法或适用边界，不保证高斯获胜或论文录用。

近期按[round035原合同](../round_035/science_plan.md)完整交付round036 `stream_history_factorization1`，保持四格干预、端点及4 GPU worker小时／32GiB新增DATA上限不变，原预检、项目、显存等其他限制亦不变。随后依据完整结果，判断长历史收益主要支持直接读回旧条目、改变状态形成，还是两者耦合，并同时评价深度／尺度代价与适用范围。至多提出一个有明确辨别价值的后继合同；直接读取阳性不自动证明可压缩或高斯有用，形成阳性不等于有界在线可实现。证据不足时结束对应解释及自动变体，不扫描T/D配额、不重开旧PE家族、不强行进入P2。

O2/O3公共空间记忆与实际预算、O4原生用途为核心；O5渲染／O6 PE可选。冻结模型、旧稀疏序列和当前缓存政策属于C项实验选择，不升级为永久要求。有限阶段完成不等于总体成功；暂停／恢复及终止规则保持，目标服务旧正文的接口限制不以伪造完成来解决。
