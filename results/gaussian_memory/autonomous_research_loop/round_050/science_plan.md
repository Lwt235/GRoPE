# round050：结束此预算点的作者STAC配置，保留深度正证据

2026-11-15。依据[round048事前合同](../round_048/science_plan.md)与[round049完整报告](../../stac_native_budget1/report.md)，**关闭`stac_native_budget1`的这套固定作者配置及其自动变体，不晋升候选，本轮不设后继实验合同。** [总体revision31](../goal_revision_after_round042/revised_goal.md)保持active、未达；这不是全部空间记忆无效、总体暂停或外部阻塞。

**结果与范围。** 主重访旋转改善`E_H−E_S=−1.6314°`，95%区间`[−3.6151,−0.2662]`；9个有定义地点仅2个微正，全部留一地点均值仍负，不能只归为home_md反例。3个主NA地点、全部零覆盖／支持层及反例保留。与此同时，S的全帧AbsRel确实改善`+0.008912 [0.003580,0.015169]`；raw log-MSE改善主要对应偏差平方下降，去均值结构反而变差，全帧锚旋转、中心和绝对GT几何也退步。深度正证据是这套政策的任务权衡，既不能换成主成功，也不能因主阴性抹去；不称S被所有指标严格支配。

**同byte比较有效，但只回答这个预算点。** 预定规则在看GT前锁定`B=14.3125 GiB`；H/W均能保存全部96帧，HH实际上无需淘汰。它们相同输出不是两次独立科学复制，也没有测出压缩HH相对短窗的优劣。S实际历史峰`14.307 GiB`高于H/W的`11.755/11.446 GiB`，完整执行成本也未显示补偿主精度损失的优势；共享调度、失败及归档差异使这些计时不能解释为精确算法速度因果排名。因此，本轮不支持在该输入／成本点采用S，却不能外推为压缩真正必要时STAC或所有空间组织都无价值；Full也不因此成为精度上界。有限96帧的逐体素cap和全前缀相机仍不构成任意长流的全局内存上界。

**解释更新。** 真实作者CUDA融合、原有效KV／来源RoPE、现有官方权重和原生输出均已运行，不能再用“只测了简化体素”解释本轮。作者的多代表、HH、几何检索与自身反馈这一整体也没有恢复主收益。选择／融合的信息损失、预测几何与检索误差、上下文异质及在线反馈仍是竞争解释；当前比较没有唯一分离它们。raw／去均值的分解支持描述偏差变化，不证明唯一标定机制。既有[长历史及形成×读取证据](../../stream_history_factorization1/report.md)仍保留历史价值和代价；[C/I/G关闭](../round_045/science_plan.md)、[XYZ闭合关闭](../round_042/science_plan.md)及旧U/C、T/D、PE决定不变，本轮的实质新增是实际作者整套政策与共同chunk／前缀相机权限，不能借作者名称重开旧变体。

**下一步的具体缺口与取舍。** 未回答的问题是：在普通完整历史确实放不下时，什么公共空间状态能比同byte普通保存／聚合更好地保留任务信息。本轮没有选中一个值得实施的全局有界规则；单纯增大时长、缩小普通容量、删除S的计费项或换深度主指标，都不足以成为后继。下一项有行动价值的工作应当是提出一个明确的**状态递推及遗忘设计**：说明淘汰原条目后保留什么任务信息、当前输入如何找回它，并同时约束空间库、相机历史与模型仍可访问的backing；普通内容对照获得相同输入权限和释放字节。它须给出区别于已试均值／体素／代表保存的可反驳预测，而不是再证明接口可运行或重复源码取证。现有[状态与字节账](../../stac_native_budget1/history_bytes.json)和[作者路径事实](../../stac_route_review1/report.md)已足够用于这种设计，不缺加载、权限或普通工程验收。尚无这样的具体方案，故本次不编造参数、训练或GPU预算，也不派发Sol；这份缺口说明不是一个隐含实施合同。后续若形成实质设计，再前瞻固定一个由任务理由决定的预算／输入点及原生端点，不按当前效果扫描配额、层、voxel、seed或数据。
