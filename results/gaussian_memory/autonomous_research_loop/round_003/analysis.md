## 2. 保留、削弱与关闭

保留原Render的局部内容与覆盖，不恢复全场景softmax替换。round_001中C−R的大代价及N/M保留40%以上片段内用途，说明固定模型依赖局部内容/分布；N完整输出的损害又说明不能丢掉幅度信息。它们不是对native_input失败的唯一因果定位，也不继续做温度、范数、覆盖扫描。

本轮已削弱“只要保留有效Render内容、让完整接收适配，再把真实参数送到query Q/K，就会有跨地点空间增量”的具体理由。强中心组共同获得中心集合均值、多频率、离散二阶矩和射线量；因此不能把中心集合信息漏给P作为本轮形状优势或失败的解释。本次G没有胜出，也不说明所有信息组织都等价。

未排除：源场质量和特征语义；固定sensor/joint-validity条件；真实3DGS的内在形状对内容关系是否适合；投影汇聚后字段与原生任务需求不匹配；小数据训练/开发分布；loss同时含raw与centered项的优化权衡。它们目前均不是唯一病因。既有来源质量、32地点覆盖和完整原生适配已经提供过对照，不能再靠扩大数据/预算自动维护原假设。

**关闭范围：** 当前渲染后直接参数Q/K接法，以及已结束的输入attention＋投影标量和相关固定机制诊断不再自动派生调参轮。保留其raw、训练内正线索和历史Render的条件用途；总体公共3DGS记忆＋可靠参数PE目标仍未达成。

## 3. 为什么只选保存前关系编码

下一有限方案 [native_memory_context_pe1](../../../../docs/native_memory_context_pe_execution_plan.md)改变一个目前尚未直接比较的计算阶段：先在公共坐标中的真实高斯基元之间使用关系PE，把原独立绑定特征改写为一份共享内容状态，再保存并由原Render读取。查询相机不参与写入，状态可在不同query间缓存；query原生attention保持原2D RoPE。这不是把渲染后的均值/参数再喂进另一读时模块。

已有区域关系PE的正证据给出有限理由：完整共同几何信息下，self-attention中的q依赖关系向量曾优于强中心控制。但区域二阶矩与真实3DGS固有形状不同，不能把该正结果移植成结论。本轮恰好检验这种组织方式能否在真实公共场景状态中产生原生下游用途；不提出新五维公式，也不恢复失败的跨帧关系一致性模块。

| 历史 | 已知结论 | 本轮实质差别及未跨越的边界 |
| --- | --- | --- |
| bound_read1/soft_read1、address_intervention1 | 已知相机读取约束、软化和教师地址改善未建立原生净用途 | 不改查询读取权重或加地址教师；原Render保持 |
| gaussian_scene_memory1、learned_projection_pe1 | 真实场、冻结四次读取及可学习投影标量未胜中心 | 原独立绑定内容此前没有基元间context编码；不重开这些reader |
| source_geometry_control1 | 来源传感器辅助可被利用，但G/P增量未确立 | 几何与来源质量固定，不重建更好的oracle或扩大来源 |
| native_input_pe1、native_render_factorization1 | 输入attention没有保留旧片段内用途；固定Render分解支持局部内容/分布依赖 | 保留原Render，写入后仍同几何同覆盖；不唯一解释attention失败 |
| native_gaussian_pe1/coarse_memory_pe1 | 预测查询几何、读时关系偏置/粗K/V均无可靠空间增量 | 此次节点是来源内实际基元，q依赖关系向量用于状态形成；不是旧读时标量偏置重命名，仍共享同类关系量 |
| surface1/geometry_transport1 | 早期writer/独立粗深度及latent读出有正负混合，空间代价不能忽略 | 不更新几何、不换独立输出头；仍用原native深度输出及主空间量 |
| joint_write1 | 逐槽MLP闭环保留raw用途，几何更新额外作用弱且空间损伤 | 本次只学跨基元内容关系；学习writer本身不是新贡献，P/S/G均有同writer |
| 本轮native_render_parameter_pe1 | 渲染后参数Q/K无开发空间增量，raw/训练内线索保留 | 不延长该模型；移到保存前、去掉24层附加query PE，一次写入可复用 |

只新增**一个**128维四头局部Transformer block，中心邻域固定32，输出零初始化的内容残差，场景几何/opacity不变。三组共享完整1024维内容、中心、完整log-cov与opacity普通输入；共同中心PE含多尺度距离、相对方向及两端近邻角度。最后四个关系PE输入分别P零/S同迹球形/G完整形状。P能访问完整形状普通内容、中心邻域及三点几何，避免将输入缺失或中心集合结构收益误记成高斯关系特有增量。P仍有256个恒零输入对应系数，活跃输入秩差如实列出。

这项比较可改变路线：若共同writer改善但G/P与S/P不改善，只保留内容编码线索并关闭这条局部Gaussian关系PE写入路线；若主空间参数增量可复现且实际净用途/摊销代价可接受，才值得锁定真正未用地点确认。仅raw或训练内增量仍关闭本接法。没有同时添加新任务、相机估计、来源数据或细化模块。

主开发筛查沿用≥1%降误差、配对95%区间下界>0、三种子均正；R/Local均值和训练内权衡不是零容差门禁，材料性开发损害仍按≥1%且区间支持判定。未检出损害不等于用途保持。成本必须拆分原来源构建、一次新状态编码、每query及N=1/4/8/32摊销，N=8用于本轮实用性决定；不能只报G/P相近隐藏共同成本。

O2/O3公共状态、O4/O5原Render及原生输出、O6公共记忆writer中的关系PE直接对应核心目标。**本轮不检验原生query attention的参数PE；两者不能混称。** C1/C3/C5保持，C2/C4/C6按上述有限改变；sensor、已知相机/单位、静态四源、固定2048槽及depth任务为临时范围。原生query侧候选关闭不等于O6从核心目标删除。
