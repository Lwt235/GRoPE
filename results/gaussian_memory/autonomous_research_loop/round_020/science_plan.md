# round_020：公共 GS 读行地址偏置收束

2026-11-14。**按[round019合同](../round_019/science_plan.md)结束 `native_read_address_pe1` 的固定接收器＋24标量地址偏置及自动变体，不晋升 A/P/S，本轮没有有据的后继实施合同。** 九个1000步拟合及完整评价已经交付；结束依据是实用增量与净用途未建立，不是槽标识等价、微小负均值或 Gaussian 数学独占要求。[完整报告](../../native_read_address_pe1/report.md) · [全数表](../../native_read_address_pe1/report_tables.md) · [预定 flags](../../native_read_address_pe1/method_decision.json)。

**最重要结果。** 正数为十二旧开发地点原四 query 的 missing-ROI 空间 log-depth MSE 降幅。A/P 为 **−0.05170% [−0.34941,+0.24871]%**，三种子两负一正；A/B 为 −0.02237% [−0.47908,+0.41901]%，A/S 为 +0.04094% [−0.61855,+0.72207]%。本交付管线下，A/P、A/B 的区间上界均未接近事前1%实用幅度；不能据此宣称零效应、等价或所有地址 PE 无用。A/Native、A/Local 虽为 +14.24%／+8.60%，区间仍跨零，不能把近乎不变的原模型用途计为新偏置贡献。开发其他 query 对 Native／Local 均值转负且不确定，也没有补强。

**正证据、代价与范围。** 训练片段其他 query 的 A 对 Local／Render 分别改善44.67%／4.69%，区间支持；但同处 A/P 为 −0.0124%、A/B 为 −0.1052%，均不确定，训练拟合 A/P 也仅 +0.0469%且跨零。保留共同系统的片段内用途，以及开发相对 Native 的 raw／bias／AbsRel 正证据，不替代 PE 或主空间净用途。开发 full 全图 AbsRel 相对 Render **增误差16.44% [2.14,45.85]%**，不能由对 Native 的改善掩去。完整新 query 中位 A/B/Native 为126.660/124.981/105.887 ms，已包含实际 W／核构建；小标量并非零成本。全部10个零覆盖 query、`fidelity_01` 的 A/P 主反例、`fidelity_05` 的 Native 反例和 `fidelity_03` 的全图反例，以及来源缓存摊销，均保留于原报告，不再选择性重评分。

**解释与算术边界。** 本次较[round016](../round_016/science_plan.md)的逐 token 参数编码，真正检验了完整读行的成对结构；[round018](../round_018/science_plan.md)的普通槽标识等价仍成立，但不是拒绝一般地址用途的理由。P 同样取得完整 W、普通 Σ 和强中心信息；A/P 区分共享槽地址与中心关系组织，不能叫“有形状信息对无形状信息”。结果削弱了“把共享内容来源显式加入 attention 即可改善固定原生模型”的理由；内容已含相关性、中心关系足够、冻结接收器限制利用方式仍是相容解释，A/S 未分出稳定形状优势，尚无唯一病因。

反传使用 MATH、评价沿原 fused 后端的共同差异须保留：三个固定首批零 γ 训练损失较旧 B 相差约−0.055%至−0.503%，单个预检深度最大差0.025074 m；这些不是主指标的误差条或全部样本上界，不能相减“修正”结果。A/P/S 同种子首批损失相同，零 γ 的评价精确回放 B，输入和训练配对没有变；非零 γ 的学习仍可能与算术差异交互，不能宣称完全抵消。因此不解读0.05%级排序的精细机制，只对实际交付的训练—评价管线作不采用决定。当前没有支持其会恢复合格增量的证据，**不追加统一后端重训或数值修补轮**。

**后继取舍。** 冻结接收器确实限定本结论；解冻本算子尚未被本实验直接否定。不过，仅有“还可以解冻”不构成下一次投入的具体依据：本轮训练内也没有地址增量，而历史全接收器适配、任务成场和工作副本检验不能被当作从未尝试过的通用缺口。本轮也未指出一个可事前定义、会改变地址与强中心比较的适用条件，故不补层、seed、步数、尺度、损失，或从已见分层中挑正子组另立成功。尚缺的是有任务依据的下一项内容—位置关系或适用条件及其可推翻比较；不要求实验前证明收益、唯一病因或数学独占。没有这样的具体问题时不编造合同，也不把阴性叫作资源、权限或外部阻塞。[round017](../round_017/science_plan.md)及既有关闭与正负证据保持。
