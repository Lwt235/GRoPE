# round035：结束两种整帧保存；区分历史形成与当前读取

2026-11-15。**关闭`stream_native_retention1`的T/D固定配额方案及其自动变体，不晋升T或D，不由其失败自动进入高斯P2。** 按用户已采纳的[revision31目标](../round_031/revised_goal.md)，只继续一次有决定作用的`stream_history_factorization1`：判断值得压缩的是可直接读回的旧K/V，还是长历史已经改变的状态形成过程。

**结果及边界。** [完整结果](../../stream_native_retention1/report.md)的主T/W旋转改善为 **−1.5162° [−10.3813,5.1687]**，D/T为−4.4114°、D/W为−5.9277°，均未达到[原合同](../round_033/science_plan.md)的材料旋转线索。宽区间不证明等价或普遍无效；T在mit_46_6conf改善14.54°，却在home_md退步31.39°，全部9个可评地点、3处NA及最大反例保留。T的全帧AbsRel确实增加0.00612，虽低于预定0.01材料线，仍是代价。**辅助正证据不删也不换主身份**：T的重访平移方向改善4.59° [1.55,8.10]，全帧轨迹中心／绝对点误差改善0.0468／0.0539m；D/T的AbsRel改善0.01326，D/W的raw log-MSE改善0.1425主要对应偏差平方下降，去均值结构未见同向改善。无方法取得完整精度—成本采用资格，约2.539GiB共同总历史上限和全部实际成本保留。

[round032](../../stream_history_value1/report.md)的长主干历史旋转改善6.74°及raw深度代价仍有效。本轮削弱“保留少数时间／图像多样的完整帧即可取得该收益”，但T/D也减少近期容量并改变未来所有写入，**不能唯一归因为关键帧选错、近期连续性丢失或缺高斯形状**。可见支持分层是关联；DINO均值多样性不是原生对应信息的充分统计量。这些都不是扫描配额／描述子的理由。

**唯一问题与实质变化。** 在固定历史来源和接收端相机状态后，额外旧K/V能否直接带来旋转收益？竞争解释是：旧条目可直接利用；长历史主要通过改变随后写入的K/V起作用；两者必须联合作用；或原收益很大部分经相机头的历史隐藏状态传播。[native_history1](../../native_history1/report.md)已有H-drop，但仅在短前缀单query移除3帧，且主深度收益未立；此次是有旋转阳性依据的96帧完整交叉干预，不能称首次发现间接历史。[coarse_memory_pe1](../../coarse_memory_pe1/report.md)的静态压缩／PE阴性保持；本轮不改变聚合方法或重训它。

**固定四格，不另加候选模型。** 两条因果参考流分别用完整主干历史`F`、首帧＋最近7帧主干历史`W`形成每层raw K/V。W流在淘汰前仅向诊断库记录本帧K/V；该库绝不反流给W参考流。每个当前帧从相同RGB重新计算，以两种来源×两种读取构成以下四格：

| 条件（首字母为历史形成，次字母为当前读取） | 读取过去的K/V |
| --- | --- |
| WW | W形成，读首帧＋最近7帧 |
| WF | W形成，读全部已到达帧 |
| FW | F形成，读首帧＋最近7帧 |
| FF | F形成，读全部已到达帧 |

在同一帧，**四格使用逐tensor相同的W相机头前缀状态**，各自完成原4轮精化；仅WW提交下一帧W相机状态，其他查询的相机／主干工作副本丢弃。参考F/W主干各按自己的原生规则继续，不接收交叉分支输出；与参考流数值相同的计算可以复用，不能让交叉结果改变参考状态。全24层、5个特殊token、原patch位置、dtype／SDPA及当前帧自身K/V计算均保留；没有投影PE、GT输入或修Issue40。官方[数据流](../../../../third_party/streamvggt/src/streamvggt/models/streamvggt.py)中相机头不反馈主干，使这一干预可定义。`FF`在此使用W相机状态，**不是旧F或旧A**；旧A与FF只作预定接收端历史辅助比较，不当重复实验或数值相等要求。

这是**逐帧条件反事实集合**，不会把FW/WF/FF的输出作为它们自己下一帧的状态；由这些输出计算的跨时几何不是三条独立在线系统轨迹。两个相机历史规则相同曾不足以排除隐藏值作用，本轮实际固定隐藏值；这种干预仍可能有分布失配，不能唯一解释全部在线失败。

**输入、端点与投入。**

- 同一冻结官方模型及原精度、原12×96完整RGB；原189重访、756远端目标、NA及支持标签全部继承，GT只离线评价，所有数据仍used。四格覆盖全部96帧，早期相同计算可复用；已有WW指标可继承。生成F/W历史的必要重放全部计费，不为验收重算旧W像素分数／标签或大权重。
- 主终点为原固定重访对的地点等权相对旋转误差；**主效应`I_read=E_WW−E_WF`**。预定辅助`I_write=E_WW−E_FW`、联合作用`E_WW−E_FF`和交互`(E_FW−E_FF)−(E_WW−E_WF)`，不将“一个显著另一个不显著”当交互。保持地点配对区间／留出、全帧与非重访旋转、全部raw深度／偏差／去均值、平移、绝对几何、失败和反例；不作GT尺度修正，不换有利子组或Full差距分母。
- **4 GPU worker小时**（含全部历史形成、预检／失败／恢复，其中预检与成本≤0.5小时）、**新增DATA≤32GiB、项目≤1GiB、单worker显存≤40GiB**；0训练／下载。完整历史库、W影子库、GPU/CPU/磁盘独立副本、索引和可读RGB都计账；必要CPU staging可用但须计真实字节／传输，不能暗改精度或把参考库当免费。此诊断**不受旧8帧B假装约束，也不声称等字节获胜**：每格依赖的完整形成及保存成本单列，共享物理storage只在联合实际账计一次。Sol在科学评分前完成成本准入，预算不足即保留实测缺口；脚本／精确调用／恢复工程归Sol。一次四格后结束，不扫形成长度、层、窗口或强度。

**决定分支。** 沿用≥1°且地点配对95%下界>0作为开发材料旋转线索，raw AbsRel增加≥0.01且区间支持退步视为明显代价；阈值用于本轮投入排序，小幅不确定代价不自动否决，跨零也不称非劣。若`I_read`获支持，说明即使由有界W形成，旧条目仍可直接有用，才有针对“保存／压缩这些条目”的新依据；仍不证明几何／高斯能压好或净用途成立。若只`I_write`获支持，应将问题收窄为状态形成，**不把Full教师产出的紧凑读取成绩当有界在线可实现性**。若只联合作用或交互有支持，保留耦合范围，不强分唯一病因。只有预定A/FF直接配对差支持固定W相机状态后收益下降，才加强相机历史隐藏值这一解释；不能仅由FF未显著推出该解释，也不据此修相机头。没有材料、可区分信号则结束这一直接读取／形成分解理由及其自动诊断变体，不补样本或继续分解到微差。任何阳性都只决定后续值得研究的对象，不自动派发P2/P3、采用方法或宣告总体完成。
