**必须保留的正证据。** 训练拟合 J、C 的 G/P 主空间收益分别 +3.80% [1.54,6.55]、+3.86% [0.82,6.80]，属于训练范围内的 PE 总训练链证据；训练片段其他 query 的 J/G 对 J/P +2.57% [−0.24,+5.24] 尚不确定，但对 Local／旧 Render 分别 +45.42% [39.17,50.41]／+5.99% [2.91,9.47]，保留整个学习系统的片段内迁移用途。开发原 query 的 J/G 对 J/P 在 raw、bias²、missing／full 全图 AbsRel 分别下降 16.08%、20.08%、13.61%／12.36%，各区间支持正向；**这些是辅助指标上的 PE 训练链收益，不能统统归为共同 writer 收益，也不能替换主空间终点。** 已报告的 raw＝空间＋bias² 分解显示主要下降落在偏差项。J/G 对 C/G 的开发 raw／full AbsRel 还分别改善 6.01%／3.78%，但 C/G 对 C/P 的 full AbsRel 同样改善 10.62%；辅助改善不证明可学几何是必要条件或正空间交互成立。

**解释与范围。** 本轮实际把 native 梯度传到中心／scale／rotation／opacity／f，形成并重载多视图共用物理场，故“此前只有粗头或源重构、缺少原生任务成场梯度”的缺口已被实测填补。相比 [joint_write1](../../joint_write1/report.md) 的粗头、[native_feature_field_pe1](../../native_feature_field_pe1/report.md) 的来源重构、[native_memory_context_pe1](../../native_memory_context_pe1/report.md) 的仅内容更新，以及 [native_scene_exchange_pe1](../../native_scene_exchange_pe1/report.md) 的临时隐藏反馈，这是实质干预；其结果削弱了“补上此闭环即可建立可靠空间 PE”的理由。全接收器解冻早已覆盖，不能再当缺口。片段适配／均值标定、完整普通形状与强中心的冗余、跨地点泛化不足仍是相容解释，未定位唯一病因；不同组的场和接收器都可变化，G/P 不是固定同场直接效应，J 的几何变化也不证明物理更准确。没有依据把主空间阴性改成“纯中心已足够”。

**代价与反例不省略。** C/P 对 Local／Render、J/P 对 Render 的完整图 AbsRel 增误差分别约 23.01%／18.29%／16.08%，区间支持；J/G 未触发材料损害规则不等于非劣性。原十个整 query 零覆盖均保留；固定原支持层的 G/P 区间亦跨零，新支持层随 arm 改变，不能据此挑选因果子组。最大主反例 `fidelity_02/q5` 与相对最佳但仍有严重 raw 偏差的 `fidelity_05/q8` 保留在[例图选择及审阅](../../native_task_writer_pe1/figures/figure_review.json)。完整暖 query J/G 123.3 ms，Native／Render 104.8／111.5 ms；另有一次 writer、来源构建和持久化费用，不以 G/P 小差称加速，也不称这些共享 GPU 测量为独占极限。[完整成本](../../native_task_writer_pe1/cost.json)。

**取舍及大纲。** 不补 seed／步数／数据、残差界限、损失、模块或 PE 层扫描，也不以本轮 raw 阳性改主终点。现有结果没有选出一个既实质不同、又能进一步区分机制与共同适配的后继条件，因此不给 Sol 新实验；这不禁止以后依据新的具体条件另作可推翻论证。O2/O3 公共粗 GS、O4/O5 多视图渲染读取已经实现；O6 的训练内及开发辅助增量与未建立的可靠主空间增量分列，原生净用途与独立确认仍未达。C1/C2/C6 原生任务成场条件已检验，C3/C4 测量接法收束，C5 给定相机及 sensor、静态四源、2048／1024、depth／人工缺失／旧地点均是临时范围。所有数据已用，无 fresh 候选或 reserve；既有区域正例、全部原生正负和旧关闭决定保留。**整体目标未达、未暂停、无外部阻塞；本阶段与后继已分配实验预算均为 0 GPU／训练／新预测。**
