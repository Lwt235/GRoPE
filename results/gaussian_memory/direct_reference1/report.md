# 直接参考特征读取：可学，但未获得跨场景净收益

2026-11-10。六次新增 GPU 训练、十二个固定模型、四十二片段评价、全部记忆干预、独立评分和实际图像读出完成。七张图已实际查看。数据全部为历史已用数据，本轮是预先固定设计的诊断，不是新确认。

**直接保留更完整的参考特征，在同场景留出视角上有效，但在两批历史场景片段上均变差。** 相对参数量匹配的无记忆网络，同场景全图误差降低 6.30%，两批旧片段分别增加 6.01%/8.23%。因此，“绕过现有压缩与写入就能恢复稳定额外收益”的本轮假设没有获得支持。当前通路能够学习使用参考信息，其跨场景收益尚未建立；不把结果解释成所有高斯场景记忆无效。

## 固定比较与信息边界

| 组别 | 实际输入 | 可学习参数 | 本轮训练 |
| --- | --- | ---: | --- |
| Local | 当前遮挡视图 token | 277,202 | 复用 B，3 种子 |
| Center | 当前 token + 原 256 个高斯/32维内容 | 273,604 | 复用 B，3 种子 |
| Wide | 当前 token，加宽同一个 MLP | 530,548 | 新增 3 次 |
| Direct | 当前 token + 四参考最后层 token，1200槽×2048维 | 531,652 | 新增 3 次 |

所有组保持冻结 VGGT、最后层残差接入、全 patch 等权 MSE、相同遮挡缓存与查询相机。Direct 沿用 width64/head4 和原中心距离位置项；Wide 仅将原 MLP 隐藏宽度加至125。新训练各 2,000 步、batch2、AdamW 3e-4/wd .01/clip5，种子20261110/11/12。Direct 复制原 Center 初始的共同模块、位置尺度、几何列和匹配的 bias，扩展特征权重固定种子初始化；Wide 因宽度变化单独固定种子初始化。六新模型全部采用第2,000步，无评价选模。

四个参考视图 [0,4,8,12] 以 S=4 联合编码，仅提取最后层参考 patch token；每 token 无参数 LayerNorm 后以 half 存储。参考深度、置信度和已知参考相机生成 patch 中心与协方差，沿用原置信度过滤和场景尺度，失效槽opacity=0。四十二片段有效槽为1080–1200，重算与旧尺度之比全部为1。

参考构建函数只接收四参考图像、四参考相机和既有场景尺度，不接收查询图像/教师。查询像素先遮挡再独立 S=1 编码，输入和教师缓存全部复用；查询只在训练监督或完整输入评价时出现。Direct 的共享场景状态保存后可反复供不同查询读取。

原写入器已经读取参考最后层 context，因此不能说旧记忆完全不含高层信息。本轮同时放宽内容维数、槽数并移除原聚合/写入；它检验一个更宽松预算的读取方案，**不能唯一隔离 PCA、空间压缩、写入目标或高斯几何的作用，也不是严格上界**。竞争解释保留当前层/恢复目标、参考几何误差、仅三个训练场景和固定优化预算。

同场景留出中，Direct 对三个对照的遮挡与全图收益在三个种子、三个场景均为正。这支持当前接法在熟悉场景分布中的信息使用，不能凭三个训练场景推断普遍泛化。六旧开发场景仅有很小平均全图收益，对 Wide 有两个种子反向，场景区间跨零。

| 全图收益区间 | 40–52片段 | 80–92片段 |
| --- | --- | --- |
| Local−Direct | [−0.001292, −0.000666] | [−0.002490, −0.001050] |

合并同场景两片段后，Direct 全图比 Local/Wide 分别高8.71%/7.23%，十二场景均为负收益，三个种子同向。这不是极小数值瑕疵，也不靠某一个离群场景成立。全部分组、种子、场景和其他指标区间保存在 analysis.json。

完整输入改变量相对 Wide 在两批平均少8.63%/12.86%，单批场景区间均跨零；相对 Local 则平均多3.55%/3.69%。完整输入的接近恒等不能代替遮挡输入的恢复用途；本轮不追加恒等约束挽救。

## 记忆确实被使用，但使用方式未稳定迁移

下表为 Direct 干预相对正常输入的遮挡/全图误差变化，正号表示干预损害：

| 干预 | 40–52：遮挡/全图 | 80–92：遮挡/全图 |
| --- | ---: | ---: |
| 移除记忆 | +14.17% / +6.39% | +3.20% / −1.36% |
| 打乱特征空间对应 | +8.14% / +5.60% | +1.98% / +2.00% |
| 交换参考场景 | +15.63% / +8.09% | +2.93% / −0.20% |
| 错误查询相机 | +7.48% / +3.59% | −1.68% / −0.62% |

同场景留出移除/交换也明显损害读取，符合它确实利用参考信息的结果。但80–92片段中，移除记忆改善全图，错误相机甚至略微改善遮挡与全图。不能写成“正确场景几何在所有条件下有效”。干预具有分布偏移，这些变化只能作为机制线索；最重要的用途证据仍是对训练过的 Local/Wide 的比较。

## 实现、独立核对与资源

共同初始化、所有2,000步采样序列、零输出初值、有限损失与梯度检查通过。十八开发及80–92片段的旧 B 分数回放最大差为 **0**；四组首种子 CPU/NumPy 独立误差重算最大差 **1.12e-8**，全图加权核对最大差 **4.35e-9**。参考仅包含四视图的输入边界和四十二状态身份已核对，没有训练/提取失败或结果后修补。

独立命令只读观测RGB、K、c2w、Direct记忆和检查点，成功回填VGGT真实最后层token，并由原depth head接收。输出有限；实时与缓存读出归一化差约2.70e-5，遮挡MSE分别0.015464/0.015446，属于不同half/bfloat16缓存路径的接口核对，不影响主评分。depth输出平均绝对变化约5.80e-4；没有深度准确率结论。

卡1两次占用核对后，一个共享GPU进程完成所有阶段，上限12GiB。六次训练共 **94.42秒**（Wide35.63、Direct58.79），训练峰值 **2.544GiB**，其中包含常驻训练/参考缓存；参考提取峰值 **4.627GiB**。这些时间不含资源等待和模型加载。

每场景保存的核心状态张量：Direct **4,977,600 bytes（约4.75MiB）**，原GS **46,080 bytes（45KiB）**，约 **108倍**，不包含图像、相机等共同输入及文件封装。Direct 的有效槽更多、内容维度更大，明确不是等存储比较。

同一共享卡、batch2/300patch、交错顺序30次测量的适配器前向＋反向中位时间：Local1.665ms、Center3.173ms、Wide1.693ms、Direct3.628ms。不含几何预处理、VGGT、数据加载、优化器步骤；不是独占性能基准，不据细小时差作加速主张。完整分位数与驻留内存见cost.json。

## 可视化审阅与本轮决定

生成四十二片段的固定首查询/首遮挡/首种子图及总览；实际查看总览、fit_00、val_12、transfer_08/11、fidelity_07/04共七张。覆盖同场景收益、旧40–52的较大退步/接近持平、80–92的明显退步和少数正例。transfer_08 与 fidelity_07 可见 Direct 的误差扩展到未遮挡区域；fidelity_04 仍有正例。热图统一同图色标，只表达token误差，不是RGB重建质量；判断采用全样本统计。

**按事前决定结束此轮固定诊断，保留局部正结果和跨场景负结果。** 没有依据直接进入“高斯压缩是主要瓶颈”的优化阶段，也没有依据宣布整个3DGS记忆方向不可行。当前证据支持：读写通路可学，单靠保留更多最后层参考内容不足以建立迁移净收益。

后续更值得先审视：当前“恢复完整单视图token”的监督是否适合跨视图场景记忆；参考S=4与查询S=1的最后层表示是否容易对齐；三个训练场景的覆盖与参考预测几何是否限制迁移。本轮没有分别检验这些原因，不能选一个当作既定病因。应据此制定一个能区分解释的后续实验，再决定是否回到同预算点/高斯形式比较；本轮不扫描层号、PE、损失权重，不追加训练或新确认数据。
