# native_input_pe1：单次输入注意力未建立值得采用的高斯PE增量

2026-11-13。四组各三个配对种子、各2000步，12次训练、8448份新预测、4224份有来源标记的历史评分、独立复算、实际查询成本与两图实际审阅均已完成。

**结论：结束这版单次输入注意力＋投影标量PE候选，不采用G/S/P为新的高斯记忆方法。** 完整高斯G对中心P主空间误差低0.323%，区间[−0.047,+0.985]%跨零；对Local平均高1.524%，未建立净用途。部分小幅正线索保留，不能说形状完全无效或方法严格等效。更有决策价值的是：当前替换方案在训练片段上也没有保留原渲染读取的收益，不能继续只用跨地点泛化不足解释这版失败。

32地点Render仍是前轮的有条件研究候选，既有片段内正证据和跨地点不确定性不变。本轮未得到一般有效方法、纯RGB方法或新确认。

## 问题、历史与固定设计

按[执行方案](../../../docs/native_input_pe_execution_plan.md)，主假设是32地点、完整原生接收适配和单次输入读取的条件下，高斯投影信息可提供超出同内容中心关系编码的用途。竞争解释包括中心/内容足够、球形范围足够、投影标量不足，以及保存内容或训练条件仍受限。

[learned_projection_pe1](../learned_projection_pe1/report.md)在12地点、冻结接收和四层内部读取上，G对P主空间误差高3.02%；[native_gaussian_pe1](../native_gaussian_pe1/report.md)与[coarse_memory_pe1](../coarse_memory_pe1/report.md)也已有受限原生接口的形状阴性。本次明确复用旧描述，在单次输入、32地点和全部接收块/DPT适配下复测，不包装成新公式，也不把结果变化唯一归因于解冻、数据或插入位置。

同一44份场景（32训练/12开发）、2048高斯/1024维FP16绑定特征、来源[0,3,6,9]及已保存当前图像patch全部复用。场景不重建、不重绑。拟合查询[2,5,8,11]，其他查询[1,4,7,10]；完整与中央约25%均值填充缺失，448输入、210×210评分。其他查询未参与本轮拟合，但数据及片段均已用于研究，不是新确认或自然遮挡测试。

用一个width256/4-head注意力残差替换旧输入MLP融合，放在编码器patch之后、特殊token加入之前，只读一次，原生2D RoPE及全部原生层/DPT保留。logit为内容QK项加位置偏置，没有叠加旧融合或四个内部读取点。

四组形式参数1054672，公共1054464；L不使用几何映射，P的零列少16个有效输入自由度，S/G有效容量相同。L与场景组的K/V数量不同，参数匹配不等于FLOPs匹配，实际成本另报。原32地点Local/Render为不同接口的历史背景，不能冒充本轮PE匹配控制。

主终点为固定开发原四查询的缺失ROI centered log-MSE，主G/P；G/S、S/P、对L净用途及原始/偏差/完整输入/支持分层/其他查询/训练片段用途全部保留。地点、查询等权，5000次配对地点/种子重采样；查询集合相关，不能算独立重复。

## 解释线索与图像

已有正确性证据不支持把本轮简单视为接线失败。但学习到的投影偏置直接作用很弱：预定首种子、原/新增首训练片段q2缺失输入中，G新增列权重范数约0.0944，逐query去常数偏置RMS约0.00033–0.00038，中心部分约0.026–0.033。移除第八输入后的描述性注意力KL约6.5e−8–8.1e−8。

相同样例中，正投影项约占0.85%–1.32%的有效query-slot对，承载约0.87%–1.41%的注意力质量。它说明这些样例中读取没有显著集中到投影非零基元，不能把对的稀疏率当成像素覆盖率，更不能将首种子两幅训练画面的注意力描述外推为所有模型完全忽略几何。该描述没有运行原生深度输出消融，不能证明唯一病因。[预定描述](pe_description.json)。

一个与结果相容的解释是：原Render先完成明确的视图局部合成，新注意力允许从整个场景软读取，当前较弱的几何偏置未维持同等空间选择；内容混合、接口与监督也可能共同影响。新Local没有出现类似的大幅训练内退步，而新G丢失了旧Render用途，使读取/融合替换值得重新评估。不能据此宣布更大数据、解冻或数值精度是唯一病因，也不继续扫描温度修补此标量。

另一个明确的实现差别是：旧Render按实际合成贡献加权，不除以alpha，因此保留覆盖量与未覆盖时的零内容；新attention对全部有效槽作softmax，投影为零时仍允许全局读取，没有同等的查询覆盖抑制。局部寻址和覆盖置信度一起变化，不能把两种接口的差异唯一算成协方差作用，也尚未通过本轮消融分别定位二者。这是后续设计应理解的边界，不是自动追加门控或重启硬/软投影扫描的理由。

[结果图](figures/outcomes.png)及[深度案例](figures/depth_cases.png)已实际查看。P/S/G图像接近，固定q2/q1仍平滑且与传感器边界/纵深不同。最大三种子G−P差为fidelity_00/q5：P/G为0.074055318/0.074715812，差+0.000660494；天花板/墙面过渡仍被平滑。confirm_12/q1的来源组改变宽尺度门平面深度，但没有可见一致的形状细节优势，该片段参与训练。深度图只展示首种子、每行相同米制色阶，白色为GT无效掩码，全部案例计分。[实际审阅](figures/visual_review.json)。逐地点图至少±1%的显示跨度不是实用/等效门槛。

## 大纲对应与最终取舍

本轮服务O4–O6，复用O2/O3；改C3为一次输入attention，在新接口/覆盖/完整适配条件下复测C4投影描述，C1/C2/C5/C6沿用。O6已直接检验，但尚无值得采用的中心/球形增量；O4也未建立该接口的可靠来源净用途。实现正确、注意力依赖线索、原生用途和新确认分别陈述。

**结束当前单次输入注意力＋投影标量PE候选，不采用G/S/P，不通过补种子、加步数或温度扫描延续本固定尝试。** 部分小幅正效应、历史区域关系PE正证据、旧Render片段内用途和覆盖正线索均保留，不否定所有高斯参数编码。有限目标完成，总体“精炼且可信有效的方法”仍未达成。

sensor/joint-validity辅助来源、给定相机/尺度、静态四来源和旧数据均是临时边界。若后续研究O6，需保留清楚的视图对齐用途并提出实质不同的假设；这一方向尚非新的执行计划，本轮无自动后继训练。
