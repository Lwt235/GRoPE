# native_input_pe1：单次输入注意力中的高斯PE对照

**进行中，尚无完整方法结论。** 用户授权四组各三种子2000步，预期8448份新预测；44份来源状态与全部当前图像patch直接复用，352份相机几何缓存及八项旧训练输入预检完成。正式训练已在GPU3/4/7启动。结果齐备、实际图像审阅及科学取舍完成后更新本报告。

本轮直接检验读取时高斯投影关系相对同内容强中心PE的增量（O6），同接口L比较来源净用途（O4），复用公共粗3DGS（O2/O3），实际投影合成贡献进入位置偏置（O5）。[固定执行方案](../../../docs/native_input_pe_execution_plan.md)。

单个width256/4-head输入注意力替换旧MLP融合，只调用一次；输出残差加在编码器patch之后、特殊token之前。原生2D RoPE、全部frame/global层及原DPT保留。L读取当前patch、无场景几何；P/S/G读取同一2048×1024冻结内容及相同有效槽，只变8维几何描述第八项：0、球形投影、完整投影。前三七维为相同多尺度中心—射线关系，8→16→4映射可学习。球形仅在读时采用同迹球形，中心/opacity/保存内容不变，不是纯朝向操纵。

四组形式读取参数1054672、公共1054464；L不使用几何映射，P第八列无有效自由度，S/G有效容量相同。原生可训练637383906参数，全部24组frame/global和DPT同等训练；编码器、其他头和保存状态冻结。2000步、batch2、相同配对种子/采样、预训练起点、原双AdamW/lr/损失，FP32参数/Adam、BF16计算与castcache关闭。当前读取器输出零初始化，新列零初始化；预检参数均丢弃。

主终点为12开发地点原四查询的中央缺失ROI centered log-MSE，主G/P，辅助G/S、S/P及各组对L。保留其他查询、训练片段未训练视角、原始误差/偏差、完整全图AbsRel、支持分层、地点差异与真实查询成本，不以某个微小辅助负值作否决。旧32地点Local/Render仅不同接口历史背景，不是本轮匹配控制。

八项预检的零残差原生差和新reader/reader-Adam恢复差均0；48交互块及DPT、新增形状列有梯度，峰值10.063GiB。完整原生双Adam格式的实际恢复沿用既有验证。full/missing字段在正式worker启动前补齐；记录见[普通修复](failures/pre_run_conditions_v1/record.json)，未改变科学比较或预算。

来源sensor/joint-validity、给定相机尺度、静态四来源（早查询可能用未来来源）、旧数据均是临时边界；非纯RGB、未知相机、在线或新确认。P/S/G内容已由高斯绑定构建，主比较仅隔离读取PE增量，不证明所有高斯信息的必要性或优于所有PE家族。此前冻结接收四层读取的投影阴性保留；本次是单次输入、32地点、完整适配的受控复测，尚无理由晋升任何方法。
