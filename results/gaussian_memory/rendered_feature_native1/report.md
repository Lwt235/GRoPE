# rendered_feature_native1：直接渲染特征融合仍未建立原生净收益

**本有限验证已完成九次训练、864份适配预测、288份绑定打乱预测、全量独立复算、完整查询成本及两张图的实际审阅。** Render对同容量Local的缺失ROI空间误差平均高3.20%，三个种子均退步；缺失原始误差和完整全图AbsRel分别高18.99%和17.15%，区间支持增加。因此不采用本版Render或Global，结束这一固定来源内容＋单次输入融合候选。Local保留为参照，不晋升为高斯记忆方法。

保留有限正证据：正确绑定比打乱的主空间误差低25.77% [15.86,37.59]%；来源一致支持ROI内，Render比Global低13.60% [1.81,25.75]%。这些说明内容的空间组织有作用，但尚未建立相对强Local的可靠净用途或高斯参数PE增量。

本轮全部为**旧数据、来源传感器/共同有效性特权、给定相机、静态来源、冻结骨干与DPT**的诊断。没有纯RGB部署、新地点确认、未知相机、因果流式或一般有效方法结论。总体研究目标仍未达成，本有限目标不自动启动后继研究。

## 问题、大纲与固定实现

服务O4/O5，复用O2/O3公共粗3DGS，主要改变C3接收接口；O6仍是未解决的核心问题。[执行方案](../../../docs/rendered_feature_native_execution_plan.md) · [大纲对应](../../../docs/research_outline_alignment.md)。假设是同层特征的显式空间对齐及早期融合这个组合，比原四层共享attention更容易被冻结原生网络利用。竞争解释包括场景整体信息足够、保存局部内容混合/不足、当前观测足够，以及接收网络或训练覆盖限制。该组合不能单独分解读取运算和接入位置的因果贡献。

复用source_geometry_control1/sensor全部24份保存场景，2048槽、1024维FP16内容，中心/形状/opacity/特征/有效性均不改变，不重新建图或写入。一份场景服务四查询；12旧训练/12地点隔离旧开发场景，来源[0,3,6,9]、查询[2,5,8,11]。早查询可以用后时刻来源，不能称因果流式。完整/中心约25%均值填充两条件，448输入、210×210评分；不是自然遮挡评测。

当前编码器输出x与附加特征r拼接，经一个2048→256→1024 GELU残差MLP融合一次；输出层权重/偏置零初始化。每组787,712参数、同种子完整初值一致。五个特殊token、全部24层原生网络、二维RoPE及原DPT按原流程执行，全部冻结；不保留原四层memory attention，也没有替换深度头。

| 组别 | 融合的附加特征r | 信息边界 |
| --- | --- | --- |
| Local | 当前图像全部patch特征的平均 | 不访问来源场景或覆盖 |
| Global | a·g，g为同一保存场景所有有内容槽的平均 | 使用来源内容及与Render相同的投影覆盖 |
| Render | Σ有效j w_ij f_j | 使用相同来源集合、有效性及实际alpha合成，保留局部排列 |

w来自标准renderer，保留原遮挡顺序，a是有内容槽贡献之和。合成特征保留幅度，不除以alpha；零覆盖r=0，不用GT阈值或新增门控。三组第二输入选择不同：**这是同容量的附加上下文选择比较，不是完整Local再追加一个可忽略来源通道的严格嵌套实验。** 因而阴性不能单独证明来源信息的条件价值为零。Global与Render共用来源集合和覆盖，但Global也含覆盖几何，不能称完全无空间信息。

三种子20261110/11/12，各2000步、有效batch2、AdamW lr1e−4/wd.01/clip5，固定最后检查点和原配对采样。损失0.5×(全图原始log-MSE＋去均值log-MSE)。查询GT只进训练损失与评分；给定查询相机只决定渲染。派生特征FP32缓存、CPU驻留逐样本搬运，当前编码器缓存保持原dtype。没有按中间结果修改配置、种子、样本、检查点或预算。

prototype1已渲染低维教师特征，view_token1/context_supervision1已做末层教师恢复，joint_write1已做共享writer与独立粗头。本轮的区别是当前保存1024维场景、同层一次融合、通过完整原生栈及DPT学习深度用途，不是首次renderer、首次可学习记忆或新RoPE。最近三轮和更早的正负结果均保留。

**整体原生净用途未建立。** Render相对Local三个种子均退步，但地点差异很大，区间很宽；不能断言总体必然有害，也不因7个地点改善便宣布稳定收益。Render相对Global的正均值和同向种子保留，整体区间仍跨零。采用与否根据效应、重复方向、不确定性和辅助代价判断，没有精确1%门禁或要求每个辅助项获胜。

**辅助代价具有实际大小。** Render对Local缺失ROI原始误差高18.99%，相对降误差区间[−39.88,−1.33]%；完整全图AbsRel高17.15%，区间[−42.21,−2.51]%，三个种子同向。完整ROI空间误差高6.76%，区间跨零。Render对Global的原始缺失误差反而平均高3.32%、完整全图AbsRel高4.55%，区间均跨零；不能将主空间均值的6.00%改善扩写成全面优势。

**来源支持区域保留有限正线索。** 支持ROI内，Render对Global空间误差低13.60% [1.81,25.75]%，三种子均改善、8/12地点改善；对Local平均低9.53% [−16.92,+21.70]%，三种子同向但区间跨零。无支持ROI对Local平均高4.39%、对Global平均低1.09%，均不确定。各区域分别去均值，不能直接相加分解总体误差；GT支持标签也不能成为部署选择器或事后删样依据。

**绑定依赖与用途分开。** 三个最终Render只在原有效槽内置换内容，保存几何、原有效性与覆盖不变，共288份预测。正确读取优于打乱的25.77%及正区间支持对应被使用；该干预改变训练时分布，不能代替与重新训练Local/Global的比较，更不是形状PE独有证据。

旧L、原生当前图像和previous_P/S/G全部独立标记为继承背景，共1248行，不计新证据。旧中心P主空间误差0.024212505，Render平均高6.64%、区间跨零。新Local对旧L原始误差平均低22.66%，三个种子同向但区间[−6.97,+36.81]%跨零；空间均值仅低0.031%。原生当前图像主空间误差0.023478416、原始误差1.185752017，说明整体偏差与空间项胜负不同。它们是不同接口/容量或静态背景，不替代新匹配对照，也不能把当前图像适配收益归给3DGS。[完整数表](report_tables.md) · [全部指标/分层](scoring/summary.json)。

## 实际图像与可能原因

[总体图](figures/outcomes.png)和[深度案例](figures/depth_cases.png)均已实际打开查看。新组的种子点较接近，但地点间正负效应大；旧中心明确标为继承、非匹配。案例为三个固定查询加三种子平均选出的最大Render−Local退步，四个唯一案例都保留。首种子图中预测常较平滑，Render没有在四例中一致恢复局部结构；最差例的墙面区域可见深度偏浅及局部差异。不能用这一种子或四张图替代总体指标。

最大反例fidelity_02/q11的三种子Local/Render空间误差为0.065698327/0.145884401，差0.080186074；图只显示首种子。每行采用同一米制色阶，白色是评价GT无效掩码，不是模型未输出或记忆未覆盖。图为缺失输入，不代替完整输入定量结果。[实际审阅与SHA](figures/visual_review.json)。

R末20步训练损失在三个配对种子中都低于Local，而开发主误差都更高；这与泛化限制相容，但训练目标是全图组合损失、主评价是缺失ROI空间项，末20步也不是完整训练集评价，不能唯一确诊过拟合或训练不足。

当前源特征仍由多来源alpha平均写入，可能混合局部信息；同层融合并未修复保存内容。几何和查询相机通过渲染权重影响排列，没有把三维坐标、米制深度或来源基线作为独立通道送入融合层。投影内容相同不唯一决定完整三维状态，是表示边界；它不能证明该边界就是当前失败的唯一原因。Local/Render还替换了不同附加上下文，故不能把净用途缺失简单归因于冻结骨干、writer或几何本身。

加入深度到V或直接输出也不是未尝试的答案：surface1、geometry_transport1已有不同粗读出条件的正负证据，不能忽略后重命名为新方案。完整解释与理论例子见[代码核对记录](interpretation_notes.md)，其中的缩放例子是分析推理，没有被冒称为本轮新实验。source_geometry_control1的来源质量正证据及早期区域关系结果保留，本轮不否定所有3DGS memory或PE。

## 成本、恢复与实现证据

两旧训练片段、完整/缺失、三组共12条件，每组2次热身、5次保留；每组20个保留时长合并中位Local/Global/Render为273.67/305.73/300.68ms，范围207.51–347.78/237.07–357.20/248.56–340.86ms。计时重新编码当前准备好的GPU RGB，并实际渲染覆盖/1024维特征、执行融合及全部24层/DPT，没有用开发缓存替代；不含图像I/O或模型加载。GPU6共享且占用变化，不作独占速度排序或跨轮加速主张。

进程首次原生模型加载16.55秒另计，测量进程峰值约5.204GiB，包含三个同时驻留的fuser与来源场景。保存场景张量4,319,652字节，约4.12MiB；共同骨干、共享fuser及临时显存另计。约1.129GiB派生特征缓存仅为开发资产，不能算作部署记忆。来源构建成本原样继承sensor，排除预测器生成、传感器采集、原图预处理和冷加载，不能称端到端RGB成本。[原始成本](cost.json) · [成本与范围](cost_description.json)。

九次保留优化循环共6.594327 worker小时，包含共享GPU等待，排除模型/数据加载及暂停墙钟；不是独占GPU计算时间或全部项目成本。正式训练峰值allocated5.602GiB，预检峰值5.621GiB。GPU1外部显存突增时，仅停止本任务Global第二种子子进程，按原队列在GPU6从300步模型/优化器检查点恢复；18次未保存更新、28.82秒另存，不计最终参数。最终每组均保留2000次完整更新，采样连续配对；没有改变精度、损失、参数或预算。[训练成本](training_summary.json) · [恢复记录](resource_resume_description.json)。

六个原训练预检通过，零融合与官方当前输出最大差0，缓存对实际renderer最大差2.86e−6，输入残差与两层参数均获得预期梯度，预检权重丢弃。九组真实初始化、全部实际采样、科学源码身份、原生权重SHA和24份保存来源/缓存均已核对。1152份新预测全部独立NumPy float64复算，最大差1.67e−15；12份导出各96条、864适配/288干预，来源和配置身份明确。[预检](preflight.json) · [匹配与来源检查](matched_checks.json) · [独立复算](scoring/independent_recomputation.json)。

## 最终取舍

不采用当前Render或Global，也不把Local的共同适配效果晋升为高斯方法；结束这一固定来源内容与输入融合候选。保留绑定依赖、支持区域对Global的有限正信号、全部反例和三种子不确定性，不把任何一项局部通过写成一般有效。

O2/O3的保存与共享载体、O5的实际渲染输入实现成立；O4可靠净用途仍未建立，O6新增PE用途未在本轮验证。该有限目标完成不等于整体精炼有效方案目标达成；不自动追加门控、层号/损失/温度扫描、更多种子、writer、解码器或新任务。[方法决定](method_decision.json)。
