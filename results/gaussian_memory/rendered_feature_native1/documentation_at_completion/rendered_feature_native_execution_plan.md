## 问题与大纲对应

固定同一保存场景，把来源图像编码器内容按查询视角直接渲染，在当前图像编码器输出处一次融合，能否为VGGT原生深度提供超出同容量当前图像适配和场景平均内容的空间用途？服务O4/O5，复用O2/O3；主要修改C3。O6高斯参数的PE增量仍未解决，不由此次渲染用途代替。

prototype1已直接渲染32维教师特征，view_token1/context_supervision1已恢复末层教师token，joint_write1已有共享writer及独立粗深度头。当前实质变化是复用sensor保存场景的1024维内容，在相同编码器层级融合，通过全部原生层和原DPT的深度损失学习。最近三轮的四层共享attention及投影PE负结果完整保留；不称首次renderer、首次可学习memory或新的RoPE。

假设是显式空间对齐和同层早期融合这个组合更容易被固定原生网络利用。竞争解释是场景平均信息足够、保存的局部内容混合/不足、当前输入已足够，或冻结接收/训练覆盖仍有限。本轮不能单独分解读取运算和接入位置的原因。

## 固定实现与对照

复用source_geometry_control1/sensor的24份2048槽场景、1024维FP16绑定内容和原has_content，不重新构建、拟合或写入。当前编码器输出x和附加特征r拼接，经过单个2048→256→1024 GELU残差MLP，输出层权重/偏置零初始化；三组各787,712参数，初值与采样配对。只融合一次，特殊token、全部24层、原生2D RoPE和DPT按原流程；不保留原四层memory attention。

- Local：r为当前图像所有patch特征的平均，不访问场景或覆盖。
- Global：r=a·g，g为保存场景有内容槽的算术平均特征。
- Render：r=Σ有效j w_ij f_j，a=Σ有效j w_ij。

w为现有标准renderer实际alpha合成贡献，保持原遮挡顺序；有效性只由保存状态决定。Global/Render共享覆盖，Global不是完全无几何信息的控制。合成特征保留幅度，零覆盖r=0，不用GT阈值或新增门控。派生特征FP32缓存，训练CPU驻留、逐样本搬运；不把缓存算作部署场景大小。暖查询成本必须重新编码当前RGB并实际渲染，不以缓存替代。

12旧训练地点、12隔离旧开发地点，来源[0,3,6,9]、查询[2,5,8,11]，一场景四查询共享；完整/中心约25%均值填充两条件。448输入、210×210评分。静态来源包含早查询之后的来源；来源传感器及共同有效性、给定相机、冻结骨干/DPT和旧数据均是临时诊断条件，不是纯RGB、未知相机、流式或新确认成绩。

三种子20261110/11/12，各2000步、有效batch2，原固定采样、AdamW lr1e−4、wd.01、clip5，损失0.5×(全图原始log-MSE＋去均值log-MSE)，固定最后检查点。九次拟合、864份适配输出。三个最终Render另对全部96输入各做固定有效槽内容打乱，288份依赖输出；几何、有效性与覆盖不变，不把干预损害当作净用途。

## 评价与取舍

主终点沿用缺失ROI空间log-MSE，主比较Render/Local和Render/Global；保留Global/Local及Render/打乱，完整输入、全图、原始误差/偏差、来源支持分层和全部地点/种子。地点/查询等权、配对种子和5000次重采样；旧P/G/L与原生背景按继承身份记录，不替代新控制。全部新预测独立NumPy复算，实际查看总体图和固定/最大反例。

若Render可靠超过两项控制且实际代价可接受，保留接口，后续另议强中心/球形/完整高斯PE；若只体现整体条件信息，则收窄空间主张；若只有依赖或辅助特征效果、没有原生净用途，结束这次固定融合。各组均无净用途时，下一战略判断须讨论任务/内容共同学习和训练规模，不继续用本配置筛选PE。依据效应与不确定性判断，无精确1%门禁或“全部辅助项都要赢”。

必要预检限于两个原训练片段：保存状态身份、实际renderer与派生特征一致、零融合原生一致、输入残差和两层参数梯度、资源峰值；权重丢弃。完成时核对九组真实初值/采样、源状态不变、全部新预测与成本。旧载体和构建证据复用，不重跑全套积分或来源质量审计。
