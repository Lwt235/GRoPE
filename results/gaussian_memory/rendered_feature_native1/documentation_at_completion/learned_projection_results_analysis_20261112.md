## 当前可以作出的判断

**结束当前投影标量PE在四层共享读取接口上的修补。下一项优先检验保存场景的空间内容，能否通过表示层级更直接匹配的接口改善VGGT原生深度。** 场景表示的总体构想与O6的PE目标保留，后者仍未得到当前原生任务的支持。

本轮九次训练、三个配对种子、864份预测已完成。缺失ROI去均值log-MSE越低越好：

| 方法 | 主空间误差 | 相对本轮中心P的误差变化 |
| --- | ---: | ---: |
| 同容量当前图像适配L，继承 | 0.02502744 | — |
| 中心P | 0.02421251 | 参照 |
| 中心＋球形投影S | 0.02470694 | 增加2.04% |
| 中心＋完整投影G | 0.02494330 | 增加3.02% |

G对P三个种子的误差分别增加3.03%、1.07%、5.18%，12地点中9个退步；相对降误差95%区间为[−7.29,+0.05]%。区间略跨零不足以证明总体必然有害，采用与否的判断也不取决于该边界的最后一位。主方向、跨种子一致性和辅助代价共同不支持采用G。缺失ROI原始误差增加5.95%，完整全图AbsRel增加3.90%，两项区间均支持增加；因此失败也不能简单归因于只关注去均值空间指标。

存在真实修复：新G相对旧固定G的完整输入ROI空间误差低17.08% [4.68,28.09]%，三个种子同向。该改动同时保留中心关系和学习投影映射，不能单独归因于其中一项；它仍未超过本轮P。P相对L的主均值低3.26%，区间[−5.26,+11.42]%，种子方向混合；G相对L仅低0.34%，同样不确定。**连“场景信息稳定增加原生用途”这一段证据也尚未成立。**

## 原因：已有证据与尚待验证的解释

1. **“只因固定映射、丢掉中心关系而失败”的解释已被削弱。** 本轮修正这两个问题后，主比较仍退步；但由于两项同时改变，旧完整输入损失中各自占多少尚未隔离。没有必要为分清这两个比例再开一轮公式修补。
2. **来源质量有作用，仍不是充分解释。** 上一轮P-sensor对P-pred空间误差低4.27%且区间支持改善，说明质量可以被利用；当前已经复用较好的sensor场景，投影仍无增量。该场景仍非oracle：原生查询的直接场景覆盖约78.37%，空间误差未全面改善，且存在局部空洞和混合。[来源质量报告](../results/gaussian_memory/source_geometry_control1/report.md)。
3. **保存的内容与原生接收接口值得优先检查，尚不能判为唯一病因。** 当前内容由图像编码器的1024维patch特征按alpha贡献加权平均得到；在0/6/12/18四个global层后，用同一组Q/K/V与输出映射注入。来源表示和不同深度的接收表示并不因维数相同就成为同一种状态，冻结骨干/DPT也没有随记忆共同适配。这是代码事实及由其引出的兼容性假设，不是已测得的因果结论。[写入/读取](../models/gaussian_scene_memory.py) · [原生接入](../models/gaussian_scene_native.py)。
4. **区域混合仍可能妨碍中心/表面定位。** 写入实际是“多个来源patch按覆盖权重求平均”；改变PE只改变如何挑选这些已有值，不能保证恢复已混合的局部细节。投影标量同时包含范围、透明度和遮挡贡献，它表达“对该视图位置贡献多少”，不直接保证“该值包含当前token需要的表面信息”。这与先前区域描述和中心定位的张力相容，但本轮没有唯一证实该机制。两张实际查看的图中P/S/G输出接近、缺失处较平滑，不能仅凭四个案例判因。[图像](../results/gaussian_memory/learned_projection_pe1/figures/depth_cases.png)。
5. **投影输入作用弱是线索，不是放大权重的理由。** 新增列确已更新；均匀query-slot抽样中G非零投影约0.632%，直接偏置变化较小。这是基元对稀疏度，不是像素覆盖率；没有按实际attention加权，不能声称模型完全忽略几何。中心描述本来已经包含多尺度射线距离、前后位置和距离信息，新增投影在当前任务中是否提供必要信息仍不明。[描述性证据](../results/gaussian_memory/learned_projection_pe1/pe_description.json)。

九次训练均完成2000步，损失和梯度有限，分段平均损失持续下降。按事后固定500步窗口核对，末500步G相对P是两个种子略低、一个更高；不能照搬前轮“G训练更好、开发更差”的描述并直接认定过拟合。全图训练损失也不能与ROI开发空间误差直接比较。现有记录支持训练过程在学习，但不能证明已达到最优，亦不能唯一归因于训练不足。

早期prototype1已有渲染特征的有限正证据，joint_write1在独立粗深度头上也有用途并伴随空间代价；view_token1、direct_reference1、reference_encoding1和context_supervision1则显示，内容依赖或表示拟合改善不自动迁移成跨场景净用途。这里保留这些结果，不把“加renderer”“增加内容维数”“重新做蒸馏”当作首次设计。

## 下一项建议：直接渲染特征接入原生预测

**状态：仅设计，建议名 rendered_feature_native1。** 科学问题限定为：固定当前保存场景及其内容，把来源图像编码器特征按查询视角渲染，并在当前图像编码器输出处一次融合，是否比同容量当前图像适配和场景平均内容提供额外的原生空间用途？

假设：同层特征的显式空间对齐与早期融合，比现有跨多个深层的共享attention接口更容易被固定原生网络利用。竞争解释：保存状态已缺少可靠的局部信息、当前观测足够、区域平均造成混合，或训练覆盖/冻结接收条件仍限制收益。本设计改变读取运算和接入位置这个组合，不声称能把两者的因果贡献单独分解。

最小结构是：**同一份粗3DGS → 查询相机下的1024维特征图 → 单个小残差融合层 → 原有24层VGGT与DPT → 深度。** 当前RGB仍由同一原生图像编码器编码；只在patch输入处融合一次，五个特殊token按原流程加入。图像编码器、主干、DPT、场景几何和保存内容固定。

建议固定为一个2048→256→1024的GELU残差MLP，输入拼接当前patch特征x和附加特征r，末层零初始化；三个组均787,712个可训练参数，从相同初值和相同样本顺序训练。不在原四层attention上再叠加这个模块。

| 新组 | 附加特征r | 所检验的解释 |
| --- | --- | --- |
| Local | r为当前图像全部patch特征的平均；只含当前输入 | 同容量当前局部＋全局适配是否已经足够 |
| Global | r=a·g；g为同一保存场景所有有内容槽的平均特征 | 场景整体内容和相同覆盖是否已经足够 |
| Render | r=Σ有效j w_ij f_j，a=Σ有效j w_ij | 按当前视角排列的局部场景内容是否有额外价值 |

w使用现有renderer实际alpha合成贡献，保留原遮挡顺序；有效槽仅沿用保存的has_content，a为这些槽的贡献之和。Global和Render共用同一投影覆盖和源特征集合，因此Global不是完全无几何信息的对照。r保留合成幅度，不再除以覆盖量；零覆盖时r=0，通过同一融合层处理，不使用GT覆盖阈值或额外学习门控。无记忆Local既不读取场景也不读取其覆盖，其第二输入为当前图像的全局统计，避免用重复x或补零虚增形式参数。

三个组都实际重训；旧P/G/L可作为身份明确的背景，但旧接口参数量/接入位置不同，不能代替新接口的同容量对照。复用目前24份sensor场景、12训练/12旧开发地点、相同来源/查询及完整/缺失输入；三个配对种子、各2000步、原AdamW及全图组合损失、固定最终检查点。名义预算为9次训练，不按中间结果扩组、增种子或选检查点。所有新实现的形状/资源细节只在两个既有训练片段检查。

主要比较Render对Local和Global，沿用缺失ROI空间log-MSE；同时报告原始误差、完整输入代价、全部地点/种子及成本。既有来源支持分层仅作解释，不筛掉困难地点。对最终Render另作一次固定槽内容打乱、几何和覆盖保持的依赖诊断；其退步不能代替与重新训练Local/Global的净收益比较。原生深度始终决定任务用途，渲染质量和特征相似性只作为辅助说明。

| 观察结果 | 能作出的下一项决定 |
| --- | --- |
| Render相对Local和Global都有可重复、实际大小有意义的空间收益，完整输入代价可接受 | 保留这一精炼接收接口；随后另行设计在可用接口内的强中心、球形和完整高斯PE比较。此时仍未证明形状PE或3DGS相对其他表示独有优势。 |
| Render和Global相近，两者优于Local | 只支持场景整体条件信息，收窄空间读取主张；不把它写成局部几何或形状PE成功。 |
| 仅对打乱敏感、或渲染/特征指标改善，而原生用途未改善 | 结束这一次冻结场景内容的直接融合接法，保留阴性；不自动加门控、换层或重配损失。 |
| 各组仍无可靠净用途 | 原生场景记忆仍未解决；下一次战略判断须讨论任务/内容共同学习及训练规模，而不能继续把本配置当作PE筛选器。该结果本身不否定所有3DGS memory或所有联合训练方案。 |

依据效应大小、重复方向、不确定性和实际代价作决定；没有精确1%门禁，不要求每个辅助项获胜，也不把这次局部验证设为其他实质不同研究的普遍前置门禁。

## 大纲对应与旧尝试的区别

已读[研究入口](research_current.md)、[大纲对应](research_outline_alignment.md)及所链接相关报告。保留O2/O3的公共粗3DGS，直接检验O4/O5的视角相关内容读取与渲染用途；本轮暂不提供O6新增PE证据，O6仍是完整研究目标。主要修改C3，复用C1/C2；C4投影偏置处于已收束状态，C5/C6中的给定相机、静态、冻结和传感器特权仍为临时范围。

- [prototype1](../results/gaussian_memory/prototype1/report.md)已直接渲染低维特征，回答载体可学性；本建议使用当前保存1024维场景、同容量原生对照，以实际原生深度训练/评价，不重做教师特征重建任务。
- [view_token1](../results/gaussian_memory/view_token1/report.md)及[context_supervision1](../results/gaussian_memory/context_supervision1/report.md)在末层恢复教师token；本建议在图像编码器输出处融合并通过原生全栈学习深度损失，不更换蒸馏教师。
- [joint_write1](../results/gaussian_memory/joint_write1/report.md)已研究联合写入与独立粗深度头；本建议不宣称首次闭环、不新增writer或替代深度头。
- [gaussian_scene_memory1](../results/gaussian_memory/gaussian_scene_memory1/report.md)、[source_geometry_control1](../results/gaussian_memory/source_geometry_control1/report.md)和[learned_projection_pe1](../results/gaussian_memory/learned_projection_pe1/report.md)均使用场景槽attention；本建议复用同一场景，只更换为显式渲染内容的早期融合接口，检验目前未在该条件下测过的用途。

当前只完成分析和提案；没有新增训练、方法胜出、新地点确认或后继目标。
