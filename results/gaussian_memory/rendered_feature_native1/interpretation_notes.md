# 输入通路的解释边界：代码核对记录

2026-11-12，Asia/Shanghai。首种子结果开放后的描述性分析；其余固定训练继续。本文不改变模型、输入、损失、预算、主终点或取舍规则，没有新增实验或效果证明，最终结论等待三种子完整结果。

## 代码直接支持的事实

[输入融合模型](../../../models/gaussian_scene_rendered.py)只把当前图像编码器特征x与附加特征r送入一个残差MLP。Render的r是保存图像特征的alpha合成，Global是相同覆盖乘以场景平均特征。高斯中心/尺度/旋转/opacity及查询相机通过renderer影响合成权重；高斯三维坐标、中心米制深度、源相机基线和场景长度单位均没有作为独立数值通道输入融合MLP。原生24层与DPT仍冻结，保留的原生RoPE是二维位置项。

这意味着本轮测试的是视角相关的场景**内容**能否在同一编码器层级帮助原生几何预测。它没有单独检验把三维高斯参数编码成向量PE的用途，也没有把物理几何读数直接传到原生深度输出。O6仍未解决。

[内容写入](../../../models/gaussian_scene_memory.py)把多个来源patch按实际合成贡献平均到每个槽；1024维保存了通道数，并不保证每个槽是准确表面点、特征在不同视角完全一致，或局部混合可逆。当前R/Global共同复用该固定内容，故这次比较不能单独定位writer或冻结接收网络为唯一原因。

## 一个理论解释例子，不是本轮新实验

在理想针孔投影和高斯局部线性投影下，对一个固定查询相机中心o，作μ'=o+k(μ−o)、Σ'=k²Σ，k>0；保留特征与opacity，并假定没有跨过near/far裁剪、可见深度顺序不变。投影中心不变，投影Jacobian缩小为原来的1/k，因此二维协方差JΣJᵀ不变。理想合成权重和渲染特征可以保持不变，而基元的相机深度改变为原来的k倍。

该例子说明“渲染内容相同”本身不能唯一标识完整的米制三维状态。它不证明实际保存场景经过缩放后仍与固定来源图像/相机一致，不是对当前数据的反例测试，也不否认当前图像先验或可见性排列可以提供深度线索。有限精度、裁剪和实际source-only构建限制也未在此作实验隔离。不能从这个例子推出本轮必然无效或病因已经确定。

## 防止把旧尝试重新包装为答案

“增加几何内容或直接传递深度”已有相关尝试：[surface1](../surface1/report.md)的K含相机几何、V含中心对数米制深度，联合写入加独立粗深度头未建立跨地点净收益；[geometry_transport1](../geometry_transport1/report.md)共39次训练比较Latent、Transport与PriorResidual。预测几何的显式Transport对强Local更差；传感器中心条件有有限正信号和明显空间代价；Latent的总体正结果主要伴随整体偏差降低。它们是不同的粗读出接口，不能外推成所有原生几何输入都失败，也不能忽略这些结果再把“加深度到V/输出”称为新发现或保证有效。

因此，若最终缺乏净收益，应限定为“当前固定来源内容＋单次输入特征融合”的结果，连同此前接口阴性保留。该结构分析只帮助解释用途与参数PE为何仍有缺口，不新增下一轮计划或授权。

## Local比较回答的是哪一个问题

当前Local的第二输入是当前patch集合的全局均值，Render的第二输入是渲染来源内容。两者都得到同一完整当前patch集合并运行同一冻结原生栈，但其融合MLP没有共同保留一个显式当前均值通道后再追加来源通道。因此本轮首先比较同容量的不同附加上下文选择，测试这一候选能否超过强Local；它不是严格嵌套的“完整Local＋可忽略场景输入”边际信息实验。阴性支持收束本固定候选，不足以单独推出来源信息条件价值为零。Global/Render之间仍共用完全相同来源内容集合与投影覆盖，空间排列比较的边界保持。此事实来自原定输入定义，记录解释边界，不调整剩余训练或新增对照。
