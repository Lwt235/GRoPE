## 固定问题、匹配控制与范围

假设：将高斯参数关系放在公共内容形成时的单个Transformer中，可以产生超过强中心关系的可复用原生空间用途。竞争解释包括独立绑定内容已足够、共同中心/完整几何内容覆盖有用信息、固有形状主要适于渲染、邻域改写损害局部信息，或raw/训练内标定改善不能转成跨地点空间用途。它改变保存前的计算阶段，不是旧查询PE改名或续训。

仅一个128宽/4头/32固定中心邻域pre-LN block，QKV、输出映射、128→256→128 GELU FFN、18→64→128关系MLP（末层无bias）；分数(q_i·k_j+q_i·r_ij)/sqrt32。最终LN+128→1024输出权重/bias零初始化。writer精确408,768参数，原637,383,906 native+787,712融合，共638,580,386可训练参数；不按约数修结构。

三组共同原FP16内容、第一source camera坐标/既有unit、完整intrinsic log-cov6、opacity、asinh中心，普通token输入1034维。共同14维中心关系包括5多尺度距离、3相对方向、两端各3近邻方向余弦；固定中心self+31邻居，稳定距离/原index并列排序，原has_content掩码。额外四关系PE槽P零、S同迹球形、G原完整协方差；共享18→64→128网络及全部初值。四量为两端Mahalanobis距离及双向trace(inv(S_i)S_j)，log1p变换，FP64由原正scale/rotation计算后FP32。P有256首层恒零输入系数，形式参数量相同、活跃输入秩不同。中心集合/完整形状普通内容信息三者都有，不能记作G独占收益。

writer仅接收源features/graph/kind，不接受queryRGB/camera/depth/mask/id。仅原有效内容槽更新；f′=FP16(f.float()+residual)，训练与保存同cast。几何/opacity/unit/有效性不变；原完整形状Render、合成贡献/覆盖、原融合及2D RoPE保持，渲染内容允许因学习而变化。**没有上一轮24层Q/K参数PE，没有新reader/gate/head/几何更新。**

每model×scene保存重载一份完整state（9×44=396），随后八个query/two conditions共享其SHA，评价writer/sourceRGB调用为0。共享writer收益相对原R改变架构，不能当O6增量；P/S/G隔离关系PE的组织方式。O6是服务VGGT公共记忆的writer Transformer PE，未检验原生queryattention直接参数PE。
