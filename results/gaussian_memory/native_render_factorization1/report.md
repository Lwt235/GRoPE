## 固定问题、身份与历史区别

按[事前执行方案](../../../docs/native_render_factorization_execution_plan.md)及[机器计划](../autonomous_research_loop/round_001/plan.json)，问题是旧Render用途依赖局部合成内容、连续覆盖衰减、整体输入幅度还是共同作用。竞争解释包括全局场景条件已足够、接收网络对分布扰动敏感以及训练片段/开发地点范围差异。

复用native_training_coverage1三份step2000最终Render权重和44份保存场景，种子20261110/11/12；原生参数、融合参数、patch、相机、GT有效性、评分尺度及BF16/FP32状态不变，eval/no_grad。主集合为32已训练片段其他查询[1,4,7,10]，副集合为12旧开发地点原查询[2,5,8,11]；full/missing各一条件。两集合均为旧研究数据，confirm目录名和未参与拟合的查询都不是fresh。

令r为原渲染内容，a为实际合成贡献乘has_content后的和，g为有效保存特征均值。R直接原缓存r；N在a>0处用双精度r/a后返回FP32、a=0处填g；C=a×g；U广播g；M=sN，s=||r||F/||N||F，分母为0时s=0。无覆盖或零范数查询全部保留，不加阈值、epsilon或新超参。M仅匹配完整1024×1024特征图的一个范数，不使用GT/ROI或输出成绩。

旧bound/soft已有覆盖/null和绑定控制；旧Global本来就是a×g，但此前是另行匹配训练的模型。本轮C/U始终使用Render权重，是条件干预，不能称新训练Global方法。实质新增是已具有片段内用途的32地点Render上，局部/全局×实际/单位覆盖四格加唯一范数控制；不是首次加renderer，也不是旧投影PE修补重开。[Astra历史分析](../autonomous_research_loop/round_001/analysis.md)。
