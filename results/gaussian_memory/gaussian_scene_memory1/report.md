# gaussian_scene_memory1：粗3DGS场景记忆与VGGT读取

**本有限验证的训练、评价及审阅已完成。** 15次2000步训练、2592份预测的独立复算和三张最终图的实际审阅全部完成。当前配置未建立相对强匹配控制的可靠场景几何用途或投影PE增量，结束此版接法，不晋升为有效方法；结论不外推为所有3DGS memory不可行。

本轮检验：来源RGB建立并保存一份粗3DGS特征场后，VGGT能否从中获得实际几何收益；相同场景内容下，投影与可见性产生的位置偏置能否超出可学习中心编码。**首轮给定相机，采用静态来源和逐场景300步拟合，冻结骨干与DPT。** 这不是未知相机、因果在线记忆或新地点确认。

## 方法与大纲对应

本轮对应O2–O6及C1–C6：[大纲对应记录](../../../docs/research_outline_alignment.md)、[固定方案](../../../docs/gaussian_scene_memory_plan_20261111.md)。构建、绑定、读取和PE形式都是实现选择，不能反过来视为导师大纲的唯一解释。

1. 固定官方AnySplat，仅输入四张来源RGB预测高斯、来源深度与相机；以来源相机建立一个公共Sim3，不用查询标签修正记忆。空间覆盖采样得到2048个初始基元，只在来源视图优化中心、旋转、尺度、透明度及DC色彩300步。来源RGB、构建器预测深度和覆盖保持项使用评分前锁定的配置。
2. 冻结StreamVGGT图像编码器，独立提取四来源的1024维特征。由标准gsplat在32×32特征像素网格计算实际前后alpha合成贡献，再加权写入每个高斯。无贡献槽标无内容，不使用查询特征补写。内容以FP16保存，几何为FP32；各查询读取同一份保存状态。
3. 一个共享的width256、4-head读取器，在原生global块0/6/12/18后复用。查询从当前RGB开始，保留原生二维RoPE，经全部原生层和DPT输出；没有先读取完整历史前缀或绕过早期层。
4. G使用标准投影/遮挡贡献的单一偏置`b_ij=log1p(N*w_ij)`，加入内容attention。零覆盖时偏置为零，仍可读内容；空记忆返回零残差。这是几何相对位置偏好，不是新的旋转编码，也不宣称该公式首次提出。

保存的主体为`μ/R/s/α/f/DC`，并计入有效内容标记、贡献权重总和、来源相机、内参、尺度单位及索引等持久张量。G/C/P每场景4,319,652字节；T为4,318,215字节、2095个来源token。1024维、2048槽、静态来源、已知相机和冻结骨干均是首版条件，不是已验证的最优值。

来源：AnySplat仓库commit`5f5e208a7dd57d52e43ea0d553a95eab526e8775`，HF revision`d2e8c343672646041ad4ea518184968f94362f01`；官方权重严格加载1405个state键。StreamVGGT固定权重SHA256为`3d3d914d09609fdb485e16947c4885cca0e5ea4e5557598a3b3ffb1cfe0a2f59`。完整下载、源码和运行身份见[权重记录](setup/anysplat_weights.json)、[运行记录](setup/anysplat_runtime.json)、[固定配置](plan.json)。保持原系统GLIBC不变，兼容处理及下载失败记录保留。

## 固定比较、数据与评价

| 组别 | 内容与新增位置项 | 回答的问题 |
| --- | --- | --- |
| L | 当前图像特征，同容量适配，无历史 | 是否超过共同适配 |
| T | 同字节来源token及来源预测中心，中心—射线PE | 是否优于简单的历史保存方式 |
| C | 同一高斯场景的内容，关闭新增PE | 场景内容是否有净用途 |
| P | 与C/G相同内容和中心，中心—射线PE | 同内容中心编码是否足够 |
| G | 同一场景内容，实际投影/可见性偏置 | 高斯参数化整体位置项是否有增量 |

T/P的中心描述是五个多尺度横向射线距离，加纵向位置和中心距离，经7→16→4小MLP生成各head偏置。它们使用给定相机及来源尺度，不使用查询深度；比L/C/G多192个有效参数。基础读取器1,054,464参数。P不是完整Point3R系统，本比较也不覆盖所有强PE。

另外导出未适配当前图像、同四来源官方历史前缀和直接GS期望深度。官方历史不匹配状态预算、适配或给定相机输入；直接渲染不使用查询RGB。这些是背景参照，不替代L/T/P匹配控制。

固定12训练地点及12隔离旧开发地点，**全部已用数据，无新确认**。来源位置`[0,3,6,9]`，查询`[2,5,8,11]`；四查询共享一个场景，早查询也可使用后时刻来源，因此不能称因果流式预测。统一448方形裁切、224来源拟合、210×210评分。缺失条件将当前图像中心约25%区域填RGB均值；来源完整，同一ROI也用于完整输入评价，不称自然遮挡。

五组各三个配对种子20261110/11/12、2000步、batch2，固定最终检查点，AdamW学习率1e-4、wd0.01、clip5。训练损失为全图有效区域原始与去均值log-MSE等权。查询训练标签只通过共享读取器的训练损失进入，不进入逐场景构建或内容写入。

主终点为缺失ROI去均值log-MSE，保留原始误差、偏差平方、AbsRel、全图、完整输入及来源支持分层。地点与查询等权，种子配对，按预定5000次地点/种子重采样给出区间。去均值误差是空间结构代理，不独自证明准确三维表面；约1%只是投入兴趣参考，不是通用门禁。

来源GT支持仅作评价：查询表面在至少一个来源传感器深度中可见，最近邻容差0.05m+2%深度。标签不参与writer、PE或样本筛选。ROI/全图平均来源支持为77.56%/70.03%，只代表输入机会，不代表高斯已经保存了相同比例的信息。[支持记录](source_conditions.json)

## 完整三种子结果与证据链

| 组别 | 缺失ROI空间log-MSE（主） | 缺失ROI原始log-MSE | 完整输入ROI空间log-MSE |
| --- | --- | --- | --- |
| L | 0.025027 | 0.114113 | 0.010602 |
| T | 0.025058 | 0.122093 | 0.011097 |
| C | 0.024764 | 0.125768 | 0.011939 |
| P | 0.024685 | 0.123298 | 0.011787 |
| G | 0.026404 | 0.125863 | 0.012038 |

**G没有建立可靠PE增量。** 相对P/L/T，主空间误差平均高6.97%/5.50%/5.37%；对应“相对降误差”95%区间为[−31.23,+10.89]%/[−28.12,+12.87]%/[−28.39,+12.26]%。G对P三个种子的误差分别高3.06%/9.08%/9.04%，平均仅6/12地点改善。方向一致但地点区间宽，既不能称可靠改善，也不能断言总体必然退步。

**较简单的场景内容读法也未建立稳定净用途。** P/C对L的主空间降误差均值为1.37%/1.05%，区间[−7.25,+8.40]%/[−7.52,+7.91]%，首种子退步、后两改善；相对T为1.49%/1.17%，区间也跨零。因此不因G失败而自动晋升P或C，不把约1%的均值当作门禁通过。

**原始误差与空间误差分开解释。** 两种子中G对P原始误差低8.87%的中间迹象在第三种子翻转：三个种子的降误差为+9.08%/+8.66%/−30.85%，合并G反而高2.08%，区间跨零。G对L原始误差平均高10.30%。未适配当前图像的原始ROI误差为1.185752，L已经降低90.38%，但L的空间误差反而平均高6.60%；共同适配主要伴随均值偏差减少，不能把大幅原始下降归为高斯记忆或空间恢复。原始log-MSE=空间方差+均值偏差平方是代数分解，不是唯一因果机制。

**辅助正迹象完整保留，但不足以改变主结论。** 完整输入全图AbsRel的G/P/T/L为0.271377/0.288820/0.290130/0.271464：G对P/T平均低6.04%/6.46%，区间[−9.48,+17.30]%/[−8.84,+18.42]%，第三种子均翻为退步；对L仅低0.032%，区间[−15.34,+9.27]%。完整输入ROI空间误差的G对P平均高2.13%，单种子先前+2.34%的改善也未保持。缺失全图AbsRel对P平均低5.60%，对L高1.31%，均不确定。没有因主指标不赢而抹去平均辅助收益，也没有将辅助指标改成主终点。

**事前来源支持分层没有给出稳定例外。** 有支持/无支持ROI内，G对P空间降误差为−0.32%/−4.24%，区间[−27.35,+13.35]%/[−20.76,+7.44]%。有支持区域对L的+0.44%也不确定。输入的来源支持较高，不能推断保存状态准确，亦不能把无净收益简单解释成没有可补充信息。完整逐地点、原始/偏差/全图及全部条件结果见[固定结果表](report_tables.md)和[完整评分](scoring/summary.json)。

**存在机制依赖证据，但可靠净用途尚未建立。** G每个种子在全部96查询/条件上执行三项固定干预。正确G的主空间误差0.026404，打乱绑定0.033751，错误相机0.031576；正确对应分别降21.77%[8.38,38.95]%和16.38%[1.38,35.30]%，三个种子同向。这支持当前模型使用了内容—几何关系和相机信息。三个G模型移除记忆后的288份输出与原生当前图像逐像素完全一致；移除还取消了已训练适配，不能替代L。正确状态优于人为破坏，不等于它优于强匹配控制。[全部种子空记忆身份](trained_empty_memory_identity_all_seeds.json)

三张最终图已[实际审阅并记录SHA](figures/visual_review.json)：[总体结果](figures/outcomes.png)、[固定与最大退步例](figures/depth_cases.png)、[同场景重观察](figures/scene_reobservation.png)。结果图黑点是三个种子均值，置信区间以上述数表为准。深度图白色为无效GT，同一行共享米制范围，显示裁切不影响评分。最大主误差差例为fidelity_00/q11：三种子P/G为0.029474/0.094416，差0.064942；它恰好与固定示例重复，未替换为另一个案例，四行只有三个唯一案例。原始/粗场景中已经存在错位与几何损失，不将它唯一归因PE。

官方历史前缀背景实测的来源处理时间中位约0.552秒，当前图像/历史查询中位约141/164ms，峰值约6.17GiB；前缀K/V与相机张量合计405,667,840字节。它来自参照导出时的共享GPU测量，输入/预算/适配条件不同，不能据此构成性能胜负。GS与同预算T都显著减少持久来源状态；这不是G独有或形状PE收益。[背景成本记录](references/native.json)

## 最终取舍与范围

按原计划结束此固定配置：保留可保存/重观察载体、真实内部读取与对应依赖证据，不采用G为有效PE方法，也不因C/P的小幅不确定均值而晋升它们。不补种子、扫温度、改公式或自动切换任务。全部模型权重、源码、输入身份、预测、正负结果和修复记录保留。[方法取舍](method_decision.json)

这次完成的是C1–C6的一项有限实现与检验，尚未得到可靠的通用方案。结果约束已知相机、静态来源、2048槽/1024维、固定来源拟合、固定软偏置及冻结接收网络的组合；没有比较直接渲染特征融合，没有唯一定位writer、特征混合、PE强度或接收网络中的病因，也没有否定导师原始公共3DGS memory构想。未来若另行研究，必须说明与本轮的实质变化和新的判别问题，不能重命名重试来扩大结论。

[最终输入/状态/模型与导出核对](final_runtime_integrity.json)覆盖24份来源状态、全部锁定缓存、实际权重及2592份预测的预定键集合；独立NumPy复算最大指标差8.58e−13。未知相机、在线融合、全骨干联合训练和未用地点确认均未执行，且没有自动后继任务。

有限目标的交付与范围核对见[完成清单](completion_audit.json)；该清单验证预定工作是否交付，不增设效果门禁。
