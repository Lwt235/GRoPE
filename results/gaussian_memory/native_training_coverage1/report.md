# 固定结构的12→32地点训练：覆盖有正向证据，跨地点净用途仍待确立

2026-11-12。native_training_coverage1六次Local/Render配对拟合各2000步、4224份新预测、2304份继承评分、独立复算、两图实际审阅及最终权重持久化已完成。

**结论：增加训练覆盖改善了Render的开发空间误差，并对其相对Local的收益提供了有限正证据；但还没有建立可靠的跨地点净收益。** 改善并非仅由Local变差造成，也不是高斯PE独特价值的证明。32地点版本保留为候选，不晋升为一般有效方法；本有限对照结束，不自动追加地点、步数或模块。

## 固定设计与历史区别

按[授权方案](../../../docs/native_training_coverage_execution_plan.md)，主假设为训练覆盖限制记忆迁移；竞争解释包括普通任务适配、来源内容/分布限制、片段特定适应，以及大数据在固定步数下尚未充分学习。

原12训练地点保留、原12开发地点排除在新增候选之外。旧目录中21个地点前12帧具有完整RGB/深度，每地点取字典序首ID，按事前SHA规则取20，mit_lab_hj保留未用。选择没有使用效果、来源支持或几何质量。全部旧数据，地点与不同样本量同时增加，不作纯多样性/纯样本量因果分解或无限计算下结论。[清单](inventory.json)。

旧24份场景保持；新增20份按相同四来源[0,3,6,9]、sensor/joint-validity初始化、2048基元/300步来源拟合、1024维alpha绑定构建。AnySplat仍作相同来源预测和尺度/unit计算；只保存构建实际消费的缩放预测深度、共同有效性、给定相机与unit，不单独保存未消费的稠密高斯/预测相机。两个旧样例的unit和预测深度回放差0。[配方核对](source_recipe_equivalence.json)。

融合仍2048→256→1024、787712参数；同样开放全部24组frame/global块与原DPT，原生可训练参数637383906；编码器与保存场景冻结。三个种子20261110/11/12的融合初值逐张量与原模型一致，同预训练原生状态、AdamW、学习率、损失、精度和截断。每次2000步、batch2、4000次样例呈现；32地点256条件样例的平均重复曝光减少，没有增加计算预算。

训练查询仍[2,5,8,11]，完整/中央缺失两条件；[1,4,7,10]保留为未参与当前拟合的同片段视角。主终点为固定12开发地点原四查询的缺失ROI centered log-MSE；主交互为(R−Local)32−(R−Local)12，负值有利，同时看32净用途与Render自身绝对变化。沿用5000次配对地点/种子重采样、地点/查询等权。其他四查询与八查询合并相互相关，不是独立确认。

旧[coverage1](../coverage1/report.md)保持12片段只重新分配地点，在token代理任务中无跨地点净收益；本轮增加总片段、使用原生深度与完整接收训练，实质条件不同。旧负结果不改写；当前单份32地点选择也不能建立数据规模规律。

## 主结果

| 固定开发原四查询 | 12训练地点 | 32训练地点 |
| --- | ---: | ---: |
| Local空间误差 | 0.022665450 | 0.022031336 |
| Render空间误差 | 0.022975235 | 0.020101690 |
| R对Local降误差 | −1.37% [−29.36,16.57]% | **+8.76% [−8.42,21.86]%** |

32地点三个种子对Local分别低12.14%/8.23%/5.99%，方向一致；地点均值7/12有利、5/12未改善。原12地点模型8/12有利，说明均值改善不等于有利地点数增加：一些原较大反例修复，仍有局部退步。home_bksh主比较由−64.27%变为约−0.015%，近乎持平，不把这个微小负值定性为实质伤害。

主覆盖交互为**−0.002239431 [−0.005161622,−0.000033643]**，三个种子与10/12地点有利。区间端点接近零，是有限正证据，不能靠一次二元显著判定宣布瓶颈已解决。

Render自身对12地点Render低**12.51% [3.93,23.34]%**，三个种子均有利；Local也低2.80%，区间[−8.39,10.50]%跨零。因此主改善不只是Local退步造成。仍须区分“相对差距改善”和“当前方法可靠优于Local”：后者8.76%的区间跨零，不证明普遍优势、伤害或等效。

其他四查询中，R对Local低3.64% [−15.75,26.27]%，两个种子正、一个约−0.48%；覆盖交互−0.001643260 [−0.005692748,0.001702976]。八查询合并低6.06% [−11.95,23.27]%，三种子正；交互−0.001941346 [−0.005180187,0.000443430]。它们保留均值改善方向，但未重复建立主交互的区间支持，不能扩大为所有视角稳定有效。[完整数表](report_tables.md)、[所有地点/种子/指标](scoring/summary.json)。

## 原始输出与片段内用途

原开发查询原始ROI log-MSE的Render/Local为0.071489/0.075912，R低5.83%，区间[−18.45,15.41]%跨零；完整全图AbsRel为0.195862/0.188348，R高3.99%，区间也跨零。支持/无支持ROI的空间误差分别平均低11.68%/5.48%，两区间跨零；GT支持没有作选择器或排除样本。

扩大覆盖也明显改善普通深度适配：原始ROI误差Render/Local分别较各自12地点版本低36.09%/27.19%，完整全图AbsRel分别低28.94%/28.51%，四个区间均为正；偏差平方分别低42.19%/33.97%。不能把这些共同改善都归因于记忆或高斯几何，空间相对改善另行记账。

在原12训练片段的未训练视角，32地点R对Local低51.67% [45.91,58.12]%，三种子/12地点均正；新增20训练片段未训练视角低35.25% [25.85,42.96]%，三种子/19地点正；全部32训练地点的未训练视角低41.95% [35.30,47.91]%，31/32地点正。拟合查询上原训练/新增训练分别低46.74%/33.56%，各地点均值都正。

这说明片段内用途能够在更多训练片段学到；新增片段已参与训练，绝非新场景确认。原训练片段留出视角的优势从旧55.59%变为51.67%，不需要修补这几百分点，也不要求减少每样本曝光后所有拟合指标同时获胜。

## 大纲对应与取舍

服务O4/O5、扩展O2/O3数据实例；C1/C6只改数据覆盖，结构、训练范围与预算不变。sensor/joint-validity辅助、给定相机/尺度、静态来源和旧数据仍是临时边界，非纯RGB、在线更新或新确认；O6的高斯参数PE增量仍未检验。

**结束这一次固定预算覆盖对照，保留32地点Render为候选，不定稿为可靠跨地点高斯方法。** 覆盖值得重视，但不是已被隔离的唯一病因；也不能保证更多数据或步数必然解决问题。不自动补种子、扩地点、改步数或叠加模块。

后续建议固定当前候选，围绕O6另行提出同内容、强几何对照的明确假设；不把现有改善当PE成功，也不把本轮未建立可靠净优势设成所有PE研究的通用门禁。总体“精炼且可信有效的方法”尚未达成。继承计划未使用旧字段的[澄清记录](metadata_clarifications_v1.json)没有改变科学配置或运行预算。
