# 固定预测诊断：一致但不准

2026-11-10。十二个模型、46片段评价及主分析全部完成后，发现 Gaussian 相对 Local 的主深度误差增加9.47%，而完整输入的跨视图三维误差不一致性减少44.76%。这份追加计划先于下面的诊断计算写入；它是旧数据上的事后机制诊断，不是新确认，也不改变模型、训练、数据或主指标。

竞争解释：A）记忆提供更好的相对空间组织，但整体深度偏置恶化；B）一致性指标被共同错误或更平滑的输出改善，尚不能支持正确场景记忆。

只读取已经保存的预测，做两件事：

1. 每查询有效patch的对数深度误差分成均值偏置平方与去均值后的空间残差，检验恒等式 MSE=bias²+centered MSE。同时报有效相邻patch的预测/真值对数深度梯度能量。去均值需要真值，只是分解，绝不把它当成可部署的精度改善。
2. 对每个查询的第一份既有遮挡预测，使用主实验已经固定的真值三维对应，比较正常、移除、交换、打乱、恢复初始几何及错误相机的误差不一致性，并加入已保存的训练均值、初始几何无训练读取基线。所有方法使用同一对应、同一遮挡样本。主实验的完整输入一致性不被这个遮挡诊断替换。

若只见一致性改善、空间残差也更差，停止把一致性称为有效空间建模；若空间残差改善而均值偏置主导绝对误差，下一项问题可以聚焦共享场景尺度/偏置的可识别性。干预诊断若说明正确绑定仍有作用，只支持局部机制，不挽救未通过的跨地点用途。无需新训练，无阈值/温度/权重搜索，不挑场景。
