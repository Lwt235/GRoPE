# learned_projection_pe1：保留中心关系后，投影输入是否提供新增用途

**九次训练、864份新预测、全量独立复算、成本测量和两张最终图的实际审阅均已完成。** 完整投影G相对本轮中心P的缺失区域空间误差平均高3.02%，三个种子均退步；相对球形S也未建立增量。组合改动缓解了旧固定G的完整输入空间代价，但没有建立对强中心或同容量L的可靠净用途。因此结束这一次固定对照，不采用新的投影PE，不继续为这一接法扫描强度或补种子。

本轮是**旧数据、来源传感器及共同有效性特权、给定相机、静态来源、冻结骨干/DPT**的有限诊断。没有纯RGB有效方法、新地点确认、未知相机、因果流式或在线融合的结论；总体有效方案目标仍未达成。

## 科学问题与大纲对应

服务O4–O6，复用O2/O3的公共粗3DGS。只改C4：在同一个可学习位置映射中保留中心关系，再增加球形或完整高斯的渲染贡献。C1/C2来源状态和alpha绑定、C3四层共享读取、C5给定相机和C6静态/冻结条件保持。[执行方案](../../../docs/learned_projection_pe_execution_plan.md) · [大纲](../../../docs/research_outline_alignment.md)。

此前gaussian_scene_memory1和source_geometry_control1的G都用固定log1p(Nw)，并替代可学习中心编码。source_geometry_control1中P能利用来源几何/绑定质量改善，但G相对P仍无可靠增量。本轮假设是：保留中心关系、给予投影输入学习机会，可能消除旧比较的信息/映射差异。竞争解释是中心和内容已经足够、保存场景局部对应不足、投影标量不足，或接收接口/训练目标限制。

bound_read1/soft_read1已经检验硬/软投影；native_gaussian_pe1/coarse_memory_pe1也做过可学习几何对照且结果有限。本轮不是首次加入MLP或renderer；实质条件是当前可渲染场景、同一内容、四层共享读取和保留强中心描述。历史正负结果不改写。

## 固定实现、来源与评价

复用source_geometry_control1/sensor的全部24份场景，2048个基元、1024维FP16特征和相同alpha写入内容；不重建、拟合或重新绑定。12旧训练/12隔离旧开发地点，来源[0,3,6,9]、查询[2,5,8,11]；同一场景供四查询共享。完整和中心约25%均值填充缺失两条件，448图像、210×210输出评分。早查询可使用后时刻来源，不能称因果流式测试。

三组共享8→16→4 MLP：前7维为原中心—射线描述，第8维P=0，S=log1p(2048*w_sphere)，G=log1p(2048*w_full)。球形仅在PE计算中令Σ←tr(Σ)I/3，保留中心、opacity、特征与内容有效性；它同时改变投影范围和合成，不是只移除相对朝向。原生2D RoPE及全部24层/DPT保留，一个width256/4heads读取器在global0/6/12/18复用。零覆盖仍全局读内容，没有新增覆盖门控。

每组1,054,672个形式参数，PE为208；P第8列恒零，少16个有效输入自由度，S/G有效容量相同。共同初值与原L、中心权重逐张量核对，第8列初值零；所有组使用配对采样，种子20261110/11/12、各2000步、有效batch2、AdamW1e−4/wd.01/clip5、最终检查点。损失仍为0.5×(全图原始log-MSE+去均值log-MSE)。查询GT只进训练损失/评分，不进入来源场景或测试时位置描述。

主终点是缺失ROI去均值log-MSE，主比较G/P和G/S，保留S/P及各组相对同容量当前图像适配L的净用途。地点等权、查询等权、种子配对，5000次地点/配对种子重采样。原始误差、偏差、全图、完整输入和支持分层全部保留，不按有利结果改终点。支持标签来自评价GT，不能作为部署选择器。

L及原生当前图像为身份明确的父轮背景；旧P-sensor和固定G-sensor同样独立标记为历史复用。960行继承指标不计新证据，主比较使用本轮P/S/G，避免用旧中心分数替代本轮配对参照。新P相对旧P主误差平均高0.97%，区间跨零、种子方向混合，不宣称逐位重现旧训练成绩。

**投影信息未建立新增用途。** G对P/S分别仅3/12和4/12地点改善，S对P也仅3/12；三个种子的主要PE比较均同向退步。区间仍跨零，不能断言总体必然有害，但数据方向、效应与辅助代价不支持采用G或S。没有把G/P区间上界约+0.05个百分点是否跨零当作新门禁。

**记忆净用途仍未确立。** 三组对L均有较小的正均值，但区间跨零、首种子均退步。原生单帧背景的主空间误差点值为0.023478416、原始误差为1.185752017；终点胜负不同，不能由单项宣布全面优势，也不能把共同适配的整体偏差收益算作高斯记忆或PE收益。

**保留完整输入的真实修复，同时限制其含义。** 新G对旧固定G的完整ROI空间误差低17.08% [4.68,28.09]%，三个种子均改善。这支持组合改动缓解旧接法的代价；该组合同时保留中心关系并学习投影映射，不能唯一归因于其中一项。新G对本轮P完整ROI空间误差反而平均高1.75%，区间跨零；主终点对旧G只平均低0.96%，区间[−27.27,+24.14]%且种子混合。因此追回旧损失不能作为独立PE收益。

**辅助指标也有具体代价。** 缺失ROI原始误差G对P高5.95%，相对降误差区间[−9.79,−1.29]%；S对P高4.26%，区间[−9.55,−0.56]%。完整全图AbsRel的G对P高3.90%，区间[−7.45,−0.96]%。这些是预定辅助项的结果，不是要求每项获胜的附加门禁。

来源支持ROI内G对P的空间降误差为−1.15% [−6.61,+2.53]%，未确认旧固定G的条件性正迹象；无支持ROI为−2.77% [−6.44,−0.11]%。区域各自去均值，不能与总体误差直接相加，也不据此拟合GT选择阈值。[完整数表](report_tables.md) · [所有比较及分层](scoring/summary.json)。

## 机制线索、实际图像与解释边界

S/G新增列权重范数分别约0.117–0.232／0.099–0.243，P始终为零。固定均匀抽样的query-slot对中，开发集S/G投影非零比例约0.581%/0.632%；这是全部基元对的稀疏性，不是查询像素覆盖率。

在同一固定抽样上，移除第8维输入引起的各head偏置RMS，G约4.8e−5至2.81e−3，S约5.9e−5至2.41e−3；中心部分RMS更大。这支持新增投影映射已学习但直接偏置作用较弱的描述。采样未按实际注意力或有效槽加权，少数对应仍可能重要；该CPU偏置诊断不是原生输出消融，不能据它证明模型完全忽略几何。[描述性记录](pe_description.json)。

两张最终图均已实际查看：[总体结果](figures/outcomes.png)、[缺失输入案例](figures/depth_cases.png)。总体图中P均值较低，主G/P区间略跨零；旧固定G完整输入空间误差较大，不能由修复它宣布新方法有效。案例包括三个固定查询及三种子均值选出的最大G−P退步fidelity_02/q11，四个唯一案例均保留。该最差查询三种子P/G空间误差为0.059722908/0.073833544，差0.014110636。

案例显示P/S/G深度图接近、缺失区域仍平滑，未观察到完整投影一致恢复细节。图只显示首种子、同一行同一米制色阶；白色表示评价GT无效掩码，不是模型或记忆没有覆盖。案例是缺失条件，不能代替完整输入的定量结果。图像实际审阅记录见[visual_review.json](figures/visual_review.json)。

来源传感器场仍有局部覆盖、空间质量和内容混合局限，继承前轮质量证据，不称精确oracle。更好的来源质量能被中心读法利用这一旧正证据保留；本轮进一步表明，保留中心并增加可学习投影输入并不足以建立PE增量。没有唯一定位writer、V、投影标量、冻结接收网络或训练目标中的病因。前两个采用原缓存运行的配对种子也同向退步，资源恢复实现只是末段运行条件的记录。

## 方法取舍

保留中心读法作为当前接口的简单参照，不将P相对L的不确定均值晋升为有效memory方法。旧固定G完整输入代价得到部分修复，属于接口修复证据；完整高斯和球形投影都未提供稳定新增用途，结束此类投影标量输入在本接口上的映射/强度修补。

O2/O3的公共粗3DGS构想没有被本轮普遍否定，已有区域关系任务的有限正证据也不被改写。若后续另行研究，开放问题是场景内容如何可靠帮助原生预测、以及什么关系需要形状信息；应先说明与prototype1、joint_write1、native/coarse等旧尝试的实质差异。本轮不自动增加writer、decoder、门控、温度/容量扫描或新任务，也不启动新数据确认。[方法决定](method_decision.json)。
