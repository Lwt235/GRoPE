## 假设、竞争解释与固定设计

假设：移除可学习中心关系并强加固定投影偏置，是旧G损失的一部分原因；保留中心且允许忽略投影输入，可能获得新增用途。竞争解释是中心/内容已足够、场景局部对应不足、投影标量不足，或当前接收接口/训练目标限制。

复用source_geometry_control1/sensor的全部24份保存场景和原查询、当前patch缓存，不重建、拟合或重新绑定。12训练/12地点隔离的旧开发场景，来源[0,3,6,9]、查询[2,5,8,11]；每场景四查询共享同一来源状态，完整/中心均值填充缺失两条件，给定相机，原生输出210×210评分。早查询可见后时刻来源，非因果流式实验。

三组均用8→16→4 MLP，前7维保留原中心—射线描述。P第8维为零，S为log1p(2048*w_sphere)，G为log1p(2048*w_full)。球形只在PE渲染中将协方差变为tr(Σ)I/3，不改中心、opacity、特征或内容有效性，不重新写入。它也改变投影范围和合成，不能把S/G差仅解释成朝向作用。

保留原种子共同初始化，将第8列初始化为零；三组正式参数量相同，P该列无有效自由度，S/G多16个有效输入权重，S/G有效容量相同。一个读取器width256/4heads在原生global0/6/12/18复用，保留全部24层、2D RoPE与原生DPT。无覆盖时仍全局内容读取，不新增门控。

三种子20261110/11/12，各2000步，有效batch2，AdamW lr1e−4/wd.01/clip5；原固定样本轨迹配对、最终检查点。训练损失仍为0.5*(全图原始log-MSE+去均值log-MSE)。派生几何BF16存储，与PE线性层的BF16 autocast输入一致，不改变来源场景和特征。九次新拟合、864份开发预测；预检权重丢弃。

必要验证限于：来源/缓存身份、保迹球形实现、共同初始化与真实采样、原两个训练片段的零适配一致性及四层/新增投影列梯度；全部新预测独立NumPy复算，并实际查看总体图和预定案例/最大反例。另在全部场景/四查询上，按固定种子20261112各均匀抽4096个query-slot对，描述训练后新增输入引起的位置偏置变化；只检查是否使用该输入，不产生新的原生输出效果证据或据此调参。复用已完成的场景质量与来源独立性证据，不重建积分门禁或重复全套干预。检查无记忆接口即可，历史破坏干预不冒称本轮新证据。

成本报告九次训练实际worker时间/峰值显存、投影缓存增量，以及从准备好的当前RGB和驻留场景开始的完整暖查询（重新编码当前图像、实际生成本组位置描述、原生24层/四读取/DPT）。原场景构建成本沿用且注明不含预测器生成/传感器采集；共享GPU不作独占速度排序。

- G对P/S均有用途且相对L有净收益：支持此接口的各向异性投影信息，后续再另议预测来源验证。

综合实际效应、不确定性及完整输入代价作判断，无固定1%门禁，也不要求所有辅助项获胜。阴性结果仅约束当前接口和输入；完整科研目标不因有限验证完成而自动达成。
