# 当前 PE 的整模型计算成本诊断

五维输入确实比旧十一维版本省计算，但不能由输入维数少推断它比距离 MLP 更快。此次使用同一张 A6000、相同旧验证输入及既有种子 11 checkpoint；八个模型的原批量回放 logits 完全一致。没有优化器更新，全部模型状态前后完全一致。

区域输入为 batch16、每视图 64 tokens；原生输入为 batch16、512 tokens。保留原 FP32 网络和 FP64 几何，关闭 TF32。每个任务/方法/模式先热身 5 次，再轮换方法顺序，测量 5 个块、每块 5 次调用；区间是这五个块的最小/最大值，不是统计置信区间。主耗时来自 CUDA events，原始记录也保留同步墙钟时间。

对 Distance，五维的区域前向约慢 15.6%，前向＋反向约慢 5.3%，后者与块间波动重叠；原生前向约慢 28.1%，前向＋反向约慢 11.6%，差异明显超过本次块间波动。原生前向＋反向峰值约 10.981 GiB，Distance 为 10.918 GiB，接近。不能称整个方案普遍高效或更快。

对 Direct，原生五维前向约慢 3.4%，前向＋反向约慢 1.0%，属于本次相近计算成本。对旧 full11，原生五维前向约快 18.8%，前向＋反向约快 9.4%；区域前向约快 8.6%，反向整体的差距较小且有波动重叠。减少输入既避免了一部分几何处理，也稍减 MLP 参数，但未消除成对特征的二次开销。

本测量包含完整模型及原任务损失/参数反向，排除数据加载、预处理、优化器步骤/状态以及训练时常驻 GPU 的完整数据缓存；输入几何不求导。故峰值不可直接替代真实完整训练峰值，时间也不是端到端训练吞吐。一个已用输入 batch、一个 GPU 和有限重复不支持跨设备、跨任务或大规模效率结论；节点上其他 GPU 仍在运行作业。

决定：保留现有冻结训练。若用途证据支持继续扩大原生实验，可独立测量已知等价的末层投影/查询收缩重排，确认能否减少成对中间量；目前尚无该重排的 GPU 正反向或速度证据，不把代数 MAC 估计当成已实现收益。
