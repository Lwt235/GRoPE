# Ray pushforward PE：独立对抗性数学审读（未选择）

2026-10-31。只读审阅 [可行性草稿](/home/liwt/GRoPE/docs/ray_pushforward_pe_feasibility_draft.md) 并独立推导；没有实现、生成实验数组、执行数值积分、读取目标或选择候选。本审读不改变 R17/R18/R20 的失败或 R21 的诊断范围。

**核心恒等式成立，但尚未证明固定预算可计算。** 对合法单个三维 Gaussian，正深度 pushforward 加独立图像 Gaussian blur，可精确化为一维正深度积分与二维 Gaussian cell primitive 的组合。它适用于 PSD 分布，不需要人为增加三维厚度。它确实消去了显式 blur 的二维积分，却不提供固定深度节点的统一精度保证，也不恢复原 patch 被 Gaussian closure 丢掉的高阶结构。

**条件化与秩的边界。** 写三维随机量为 `(U,Z)`，`U∈R²`，相机投影为 `π(U,Z)=H U/Z+c`。H 必须包含实际相机线性内参与图像单位换算。若 `v=Σzz>0`，令

```text
β = ΣUz / v
D = ΣUU − ΣUz ΣzU / v
U | Z=z ~ N(μU + β(z−μz), D)
Y | Z=z ~ N(H[μU+β(z−μz)]/z+c, H D Hᵀ/z²+h²I)
M_h(B) = ∫₀∞ φ(z;μz,v) Pr(Y∈B | Z=z) dz.
```

这是 Gaussian 条件分布、独立 Gaussian 相加与全期望的直接结果。这里**不能再乘一次 z²**：该 Jacobian 出现在从三维密度推导 ray-density 的表达中，已经被条件分布与投影概率变换吸收；再乘会改变测度。`D` 是 PSD Schur complement，允许 rank 0/1/2。h>0 使图像条件协方差严格正定，所以在合法 PSD 输入下不需要 jitter 来定义二维 cell 积分。

v=0 时，PSD 的二阶主子式给出 `|Σiz|²≤Σii v=0`，故 cross covariance 必须为零。此时 Z=μz 是常量：μz>0 时直接计算一次二维 Gaussian cell mass，协方差为 `HΣUUHᵀ/μz²+h²I`；μz≤0 时所有原始质量为零，不能先对 Z 做正数 clamp 再投影。v>0 时，即使 μz≤0，`Pr(Z>0)=Φ(μz/√v)>0`；把负均值 Gaussian 整体当作背面零质量是另一模型。

直接计算 D 会发生消减。若输入保留因子 `L`，令 `l_z` 为其深度行，取 N 为 `l_z` 零空间的正交基，可写 `D=(L_U N)(L_U N)ᵀ`；这是同一实数条件协方差的一种因子表达，不是添加厚度。但一个已经舍入的 Σ 可能丢失小条件方差，不能从该 Σ 恢复被丢掉的信息，再宣称与原矩阵输入等价。因子与矩阵的实际精度合同必须统一。检查 `HDHᵀ/z²+h²I` 为正定，也不能替代对原 Σ/D 合法性的检查，h 可能掩盖错误的负方向。

在相机平面附近，不存在覆盖所有秩变化的连续点极限。解析反例是 `μ=0,Σ=ε²I,ε>0`：投影律与 ε 无关，正深度质量始终为 1/2；到 ε=0 的相机原点，严格 `Z>0` 事件却变为空，原始质量为零。可以要求固定 μz>0 时的点极限，不能把上述边界不连续性判成算法错误并用 jitter 消除。

**正深度归一化、FOV 与 floor 必须固定顺序。** 设 `p+=Pr(Z>0)`、`mΩ=Σ_j M_h(B_j)`、`f_j=10⁻³⁰ area_ref8(B_j)`，并令 `F=Σ_j f_j`。未条件归一化版本为

```text
P_j = (M_h(B_j)+f_j)/(mΩ+F).
```

当 p+>0 时，先做正深度条件化再加**同一个** floor，得到的是

```text
P'_j = (M_h(B_j)+p+ f_j)/(mΩ+p+ F),
```

一般不等于 P。若希望在条件化表达下保持 P，floor 也必须除以 p+。最简单反例：两等面积格，全部微小正深度质量 ε 落在第一格。原式在 ε/f→0 时趋于 `(1/2,1/2)`；条件化后加同 floor 则接近 `(1,0)`。μz 远在后方时，这种区别正是主要行为，不能当作无关实现细节。p+=0 时条件化本身未定义；面积 floor 给出的输出只是明确的面积先验，不是可见性或正确对应的证据。

必须先投影并模糊，再取有限 FOV。预先删除 FOV 外的投影点会丢掉 blur 流入边缘格的质量。未加 floor 的 cell 质量可加，面积 floor 也可加；但加入不同 native key 内容之后，跨分区一致性不再自动成立。`Z>0` 只表示相机前方，不含遮挡、透射率或传感器可见性判断。

**它实际减少了什么计算。** 在 ray 图像位置和二维 blur 位移上做显式积分会产生四维积分；独立 Gaussian blur 与条件 Gaussian 的解析卷积把这一步消掉，条件式是正确降维。剩余成本仍为每个 query/cell 的深度外积分，且每个深度点都需二维 rectangle primitive。若后者采用现有一维条件-CDF/GL 实现，通常是 depth-order×cell-order 的工作，而不是一次旧二维 Gaussian 的成本。近零 z 的 `1/z,1/z²`、远后方的极小正尾、FOV 归一化放大都仍存在。表示只有一个 μΣ，不等于积分预算、反向传播或内存成本也小。

**固定 h 下的有限节点反例。** 不需要 h→0 就可制造深度窄峰。取 H=I、c=0，固定 `Z~N(m,v)` 且 v>0，选 `z*>0`，构造 rank1 Gaussian

```text
U_x = β(Z−z*) + u* z*,     U_y = 0
x(z) = β + (u*−β) z*/z,    y(z)=0.
```

这有合法 PSD 协方差 `v(β,0,1)(β,0,1)ᵀ`，D=0。固定 h=.25，并选以 `(u*,0)` 为内点的有限矩形 B。对于任意有限的、只依赖该固定深度边缘分布的正深度节点集合，可以预先选不等于任何节点的 z*。当 β→+∞，每个固定节点的 x(z_i) 都远离 B，其 blurred cell 权重以 Gaussian 尾速率趋零；但 z* 附近宽度为 `Θ(1/β)` 的区间始终投影在 B 内部，原始 cell mass 至少为 `c/β`，c>0。因此有限节点积分的相对误差可趋于 1。若恰好有节点命中 z*，其固定正权重又可能不能随峰宽缩小，产生相反的高估。

该反例针对未随几何条件调整的固定深度节点，尤其是只按 Z 的均值/方差设计的 GH/GL；它不是所有有界输入域或所有 geometry-aware 积分方案都不可能的证明。一个生产实现若依赖 adaptive subdivision、截断或几何相关节点，就必须把实际预算、失败条件和误差证据另外声明，不能借“一维”直接继承旧 GL32 的可靠性。独立参考可对上述 rank1 情形改用投影坐标积分：令 `α=(u*−β)z*`，`z=α/(x−β)>0`，Jacobian 为 `|α|/(x−β)²`，与深度节点法形成不同的数值路径。

另一个精确退化例是 `U=kZ`：条件图像位置恒为 Hk+c，对任意 μz、v>0，

`M_h(B)=Φ(μz/√v) W_B,h(Hk+c)`。

它同时检验 rank1 条件方差为零、负均值正尾和原始质量因子；若实现只输出 W，便已经悄悄做了正深度条件化。全秩零均值等方 Gaussian 在归一化像平面 `(y₁,y₂)` 的子密度为 `1/[4π(1+y₁²+y₂²)^(3/2)]`，质量 1/2；该重尾没有可直接拿来替换旧 trace 温度的有限全局二阶矩。加入图像 Gaussian blur 不会自动消除这个重尾问题。

**同信息控制与 patch 压缩边界。** 新算子需要真实合法的三维 μΣ。二维缓存 μ2/C2 不足以反演它。仓库已有 RGB 深度、相机和三维点/within-pixel 矩来源，但将原始三维 patch 先压成一个 Gaussian 再透视投影，与先逐像素投影、再压成二维 Gaussian 是不同的压缩次序。前者也丢掉多峰、平面边缘、遮挡和颜色结构，不是原 patch 测度的无损表达。

至少应分清三类比较：共享同一三维 μΣ的 Jacobian Gaussian 与精确 pushforward，用于隔离投影律；共享同一原始合法点集合的二维/三维 closure，用于报告压缩次序变化；旧完整控制，用于保留历史基准。它们不能互相替代。各方需共享实际 h、坐标单位、FOV、floor、前向人口与固定内容规则；旧正深度 clamp/clip 与新严格 Z>0 的差异必须单列，不能用新前向点极限声称完整复现了旧背面/近面行为。Opacity 也不是无需定义就能乘入的可见概率。

**最小无标签验收建议，尚未选定或执行。** 只选择事先列明的少量解析类型，冻结实际参数、camera/cells、运行预算和误差合同：

| 类型 | 独立预期与必须暴露的失败 |
| --- | --- |
| 前方/后方/相机平面 rank0 | 一次 W 或严格零原始质量；面积 fallback 显式标记；不允许 z-clamp 冒充等价 |
| v=0 的 rank2 定深 Gaussian | 单次二维 Gaussian cell 积分，核对 covariance/h/单位/floor |
| 径向 rank1 `U=kZ`，含负 μz | 精确 `Φ(μz/√v)W`，同时核正尾和未条件质量；加入一个正尾小于 floor 的固定例 |
| 偏置 rank1 深度窄峰 | 上述 β/z* 例，参数在执行前固定；参考用投影坐标积分，不能只用相邻 depth orders 自证 |
| fullrank 零均值等方 | 解析重尾子密度、总质量1/2；独立 ray-density 与 cell-blur 积分参考 |
| 前向窄支撑与相机平面秩极限 | 分别核预期点极限和明确不连续边界；不得把零 v 阈值化掩盖差别 |

所有例都应同时保存 raw cell/FOV mass、正深度质量、floor 后 P、zero/tiny/fallback、argmax、节点/函数调用数、时间和内存。只比较 floor 后 P 的绝对误差不足以判定成功。若 raw cell 误差为 ε_j、FOV 误差为 ε_Ω，则当真实 `mΩ>ε_Ω` 时，无 floor 归一化的分量误差可界为

`|M̂_j/m̂Ω − M_j/mΩ| ≤ (ε_j+ε_Ω)/(mΩ−ε_Ω)`，

其中使用 `0≤M_j≤mΩ`。若不能提供足以控制这一放大的 raw/尾部误差，tiny-FOV 行的归一化准确性就没有建立；加 floor 后可对 `mΩ+F` 作对应推导，但仍需另报原始质量及其误差。合并可加性、共同正尺度变换 `(μ,Σ)→(sμ,s²Σ)` 的像平面质量不变性、图像单位换算、和共享输入下的分支一致性应固定验证。任何失败都保留，不在同一次运行中增加节点、放宽阈值或改 h。

本审读支持这一定义的数学一致性，尚不支持固定成本实现、相对尾部精度、实际 GS 泛化或任务效果。它可以成为单个三维 Gaussian 的位置测度定义；尚不是有限维精确 Q/K 编码、RoPE 性质或完整 patch 高阶信息保留的证明。
