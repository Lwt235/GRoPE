## 唯一数学修订与确定的执行细节

保留 R34 的完整 finite-X、GL32/48、窄区间 GL8、跨度 .25、SVD、严格正深度、原深度域、初始断点合并、固定 midpoint pilot 尺度和全部尾界。替换 SciPy 外层驱动；GK21 的节点、权重、标量 Gauss–Kronrod 差和 resasc 非线性截断估计保持。

每个区间记录原标量截断估计 `e_l`（施加舍入 floor 前），以及向量 `r_l = 50 eps * h_l * sum_n w_n abs(f_n)`。GK21 输入必须是原 float64 非负有限向量。保留全部已评估区间的舍入向量，包括后来被细分的父区间。每轮用 `math.fsum` 重算当前叶积分各分量、当前叶标量截断项总和和历史舍入各分量总和，禁止增量 `children−parent` 更新。

判据固定为 `E = sum_active e_l + max_j sum_history r_lj`，`target = max(epsabs, epsrel * max_j abs(I_j))/8`，要求严格 `E < target`。epsabs=0、32/48 阶 epsrel=1e−11/1e−12 保持。舍入项本身不低于 target 时保留明确收敛失败；不静默接受。不以此误差估计宣称真实误差或全流程严格界。

初始所有区间求完即检查该判据；若未过，按原每叶标量优先级 `max(e_l,max_j r_lj)` 选择一个最大者，平局取最左区间，每次在严格可表示中点二分。保留原 workers=1。新驱动不采用原批量细分及增量累计；这些是明确的数值实现变更，而不是声称与原 SciPy 控制流逐条相同。无法取严格中点、非有限值、预算或时间耗尽、区间上限、收敛失败均留存失败。

保存全部已完成区间的 `[left,right]`、向量积分、标量截断估计、舍入向量及当前叶索引；记录各项汇总、target、状态和实际回调计数。每个完整区间恰有 21 次已有 ledger 计费的深度回调，未完成区间已用资源仍计费。异常要保留完整已完成区间和 partial 信息，不补齐或伪造缺失项。独立审计只用保存数组重算汇总、非负性、维度、区间分裂/全域覆盖及收敛判据，不重新积分、不导入参考的数学函数。

局部非负向量满足 `max(sum r_l) <= sum(max r_l)`；该改变移除跨分量最大值相加的保守性膨胀。标量 resasc 非线性项仍保持，避免同时改变整个截断误差模型。历史舍入仍累计，且新停止量包括它；旧失败不会因新规则回写为通过。
