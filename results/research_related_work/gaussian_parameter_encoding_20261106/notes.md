# 高斯参数进入 Transformer：补充原文核对

2026-11-06。本次在 matched256 固定训练期间进行限定范围检索，核对四篇作者原文的方法部分；没有下载它们的数据、运行代码或复现成绩。不是完整的新颖性排查，不改变正在运行的模型、比较或选模规则。

| 工作与原文位置 | 已核实的接法 | 与当前研究的关系 |
| --- | --- | --- |
| [GPSToken，arXiv:2509.01109v1](https://arxiv.org/html/2509.01109v1)，§3.1–3.2 | 二维高斯的中心、两轴尺度和相关系数定义 token；初始化参数投影成 query，结合局部图像特征由 Transformer 更新，再进行特征 splatting | 已有“高斯参数→Transformer 查询”的直接先例。其二维可学习 tokenizer 与当前三维成对关系项不同；不能声称首次将高斯参数用于 Transformer |
| [JSRE，arXiv:2601.02339v1](https://arxiv.org/html/2601.02339v1)，§3.1，式(1)–(9)；[ICCV 2025 记录](https://openaccess.thecvf.com/content/ICCV2025/html/He_Joint_Semantic_and_Rendering_Enhancements_in_3D_Gaussian_Modeling_with_ICCV_2025_paper.html) | 协方差定义度量 `M_i=(I+βΣ_i)⁻¹`；两端平均度量产生图边权，谱描述子再与中心 PE 相加进入 Transformer；传播还使用马氏距离权重 | 已有协方差感知的邻域关系和 Transformer 形状编码。当前直接学习五个关系量避免该谱描述流程，但尚未和完整 JSRE 同条件比较，不能声称效果或效率胜出 |
| [GST-VLA，arXiv:2603.09079v1](https://arxiv.org/html/2603.09079v1)，§III-A.2–4，式(2)–(4) | 中心采用 Fourier PE，log-scale 和 opacity 与语义特征共同投影，随后进行可学习汇聚；正文协方差为 `diag(exp(2σ))` | 区域参数进入 token 内容有先例。固定坐标系的对角协方差不能表达任意旋转的主轴，这是公式的代数限制；不能照搬文中关于任意表面法向的宽泛表述。其复杂 VLA 系统成绩不作为本项目 PE 的证据 |
| [GaussianGPT，arXiv:2603.26661v1](https://arxiv.org/html/2603.26661v1)，§3.1–3.2 | 原始高斯先压缩到稀疏潜在网格；Transformer 使用网格三维坐标 RoPE，并添加 token 类型维度 | 证明高斯场景与三维 RoPE 结合已有先例；所核对的 RoPE 输入是坐标和类型，没有把每对原生协方差写入旋转公式 |

对当前方案的判断：

- “区域有中心、方向与范围”是已有研究动机；经典高斯 KL 的位移项、迹项也不是新公式。当前需要证实的是：在信息、骨干及预算匹配时，保留双侧分量并学习相对位置项，能否稳定优于中心关系及更简单的形状组织。
- 这些文章的 tokenizer、几何来源、监督及任务不同。只比较它们报告的分数，不能证明当前 PE 更好；本次也没有把它们标为已经实现的基线。
- 原生 matched256 继续按事前计划回答数量匹配问题。区域可学习 Jeffreys 对照已完成；原生尚无同样控制，这个比较缺口保留，待当前完整结果解释后决定优先级。没有为填满空闲 GPU 临时增加训练。
- 检索没有发现与五维输入逐项完全相同的已核对公式，并不构成未存在此方法的证明。一般用途、精炼性和强对照收益仍依赖本项目实验。
