# 当前五维关系与已有高斯编码的关系

本次为限定范围的原文核对，不是完整的新颖性检索。专用 arXiv/CrossRef 工具不可用，Hugging Face 论文搜索接口返回 UNAVAILABLE；使用可读的官方 arXiv 论文原文，未使用第三方抓取器。核对目的为确定一个必要的同条件控制，不据文献直接更改候选或宣称任务收益。

Vilnis 与 McCallum 的 ICLR 2015 论文已把对象表示为高斯分布，并使用 KL 等关系学习词嵌入；其学习的潜在协方差与这里观测/重建的物理支撑语义不同。论文 §5.2 的闭式 KL 包含马氏位移项、迹项及 log 行列式比。[原文](https://arxiv.org/pdf/1412.6623)

Cordonnier 等的 ICLR 2020 论文附录 E 已把注意力位置权重写成含协方差的二次型。那里的协方差属于注意力头，定义像素偏移上的形状；当前协方差属于每个输入 token 的物理区域。其非各向同性扩展在所报实验中未提高性能。这提醒我们，结构能表达形状并不能单独证明使用价值。[原文](https://arxiv.org/pdf/1911.03584)

令 m_i=δᵀΣ_i⁻¹δ、m_j=δᵀΣ_j⁻¹δ、t_i=tr(Σ_i⁻¹Σ_j)、t_j=tr(Σ_j⁻¹Σ_i)。由经典高斯 KL 公式，三维的双向 KL 之和为：

`J = KL(i||j) + KL(j||i) = (m_i + m_j + t_i + t_j - 6) / 2`。

因此当前五维是普通距离加上述四个分量的 log1p 变换，再由 MLP 组合。它不是新的高斯距离，也不是首次高斯 attention。R58 的 `gaussian` 实际已经编码 `sqrt(J)`；但它用固定 sin/cos 嵌入加线性投影，数据与共同内容也不同。因此，R58 的失败**尚不能隔离“先合成标量”与“固定读出方式”各自的作用**。

分量的确可能携带一个总散度不保留的信息。例如，δ=(1,0,0)，两端协方差均为 (8/37)I，或者分别为 2I 与 .5I，普通距离和 J 都相同，四个分量不同。这只是表达能力上的例子，不能说明实际任务需要这一区别。反过来，五维也不是完整的高斯对不变量：δ=0、Σ_i=I 时，Σ_j 特征值 (1,2,3) 与 (1.2, 2.4−√.96, 2.4+√.96) 有相同的迹与逆迹，却有不同行列式；完整共同内容仍可能区分它们。

下一项旧数据诊断固定一个控制：`[d, log1p(J), log1p(J), log1p(J), log1p(J)]`，使用当前完全相同的五输入 MLP、初始化、完整内容与训练预算。重复只为保留配对参数化，只有两个独立输入；不宣称已经实现二输入模型的运行效率。若能保留五维收益，考虑收缩设计；若稳定落后，则支持在这一学习设置中分别组织分量有用。单次对照不能证明任意散度或任意编码都不可能达到同样效果。当前原生归因、RGB 负结果及新场景结果继续保留。
