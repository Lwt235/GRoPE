# R21：固定匹配分解的设计审查

2026-10-31。仅审阅冻结源码、旧完成元数据和已接受 R20 指标；未运行新前向，未读取标签数组。本文件限定下一次诊断可以回答的问题，不选择新模型，不修改 R20 的停止结论。

R20 的 g24→g8 KL 为 .332541337，旧 trace 为 .325707938，quad16 为 .308352829。中心保护全部通过，但两个同参考的逐条件检查失败。现有同 tau 归因中，primary 在全部14条件的 KL 均优于 mean-only 和 isotropic，不能据此直接删除 `ddᵀ` 或各向异性。旧 h=.25/T0 full1/full4 的 g24→g8 KL=.326041016/.259883581，提供了粗区域形状损失的线索；这些开发结果不是新的确认，也没有使 full4 成为获选候选。

## 同矩成立的范围

令每个预测像素的位置为 `x_i`，其 within-pixel 协方差为 `V_i`。full1 使用

`μ=mean_i(x_i)`，`C=mean_i[(x_i−μ)(x_i−μ)ᵀ+V_i]`。

full4 按源图像矩形固定分成四个等面积层；第 s 层使用 `m_s=mean_s(x_i)`、`C_s=mean_s(V_i)+mean_s[(x_i−m_s)(x_i−m_s)ᵀ]` 和像素数权重 `w_s`。在实数算术下，`Σw_s m_s=μ`，`Σw_s[C_s+(m_s−μ)(m_s−μ)ᵀ]=C`。q8/q16/q24 的层面积各相等，所以权重都是可精确表示的 .25。每个分量加同一个 `h²I` 后，混合总协方差为 `C+h²I`；within-pixel 项不能再次添加或遗漏。full4 不是仅保留 within-pixel 项的 quad4/quad16。

生产代码的同矩不是逐位恒等：`models/round10_partition_pe.py` 对全组直接累加 float32 的 scatter+pixel covariance；`models/round11_stratum_pe.py` 分别归约局部 pixel covariance 与 scatter 后再作 float32 相加。全局均值字段来自相同全组路径，但四个节点的加权均值另有归约误差。R13 小机制实验使用 float64，其约 1e−14 同矩误差不能转作这里的生产容差。应保留旧 float32 准备顺序，记录生产混合均值/总协方差对 full1 的绝对及尺度归一化残差，并用独立像素参考审计；不得校正节点或协方差以制造精确同矩。数值接受标准须在运行前固定，不能看到区域差再放宽或以差异小为由删行。

上述同矩描述未截断的连续分布。FOV 条件化、native cell 离散化及面积 floor 后的概率均值和协方差不必相同；这正是形状对实际算子的影响范围，不能把它们强行匹配后仍称原对照。

## 执行路径可以匹配，但不能更换运算语义

旧 `models/round15_validation_pe.py` 与 R20 均调用同一个 Gaussian GL32 路径，均在 reference-8 坐标以 `(bounds−.5)/8` 积分。旧方法先合并数值子格，再对 full4 分量加权求和，最后只加一次 `1e−30*key_area/64` 并取 log。R21 的 g8 key 每格面积64px、无数值子格，每格 floor 恰为 1e−30。不能对各分量先加 floor/各自做 FOV 归一化，也不能用格中心密度代替矩形质量。

四种几何共用 R20 的 `μ32,C32,a64` 所构造的 `Ca64=C32.double()+(μ32.double()−a64)(...)ᵀ` 及其现有 tau。内容必须是相同父 query/key 的完整 float32 pooled-feature 点积；`tau64→tau32` 后与 `content32` 相乘，所得同一 `bias32` 再转 double 加入每个几何。不能让 full4 从自身重建矩计算另一个 tau，不能给各分量独立内容，也不能改成 double 内容乘法。这种共同 bias 是受控归因条件，不是 full4 自己的既有部署温度或完整成本。

旧 full1/full4 的 h=.25/T0 应与 R15 grid index 0 的逐矩阵承诺哈希完全对应；R20 的 `G(a,C)+b`、`G(a,Ca)+b` 应对应原 mean-only/primary。重算 softmax(log P−b) 只在实数中可逆，不能用它声称旧概率逐位重放：应走冻结原始 geometry、bias、softmax 路径，再核验原哈希。

## 最小配对关系与解释

记 `G0=G(μ,C)`、`G1=G(a,C)`、`G2=G(a,Ca)`、`M0=full4(μ,C)`，h固定 .25；每种仅执行零内容和共同现有 bias b。固定以下配对，不按结果挑比较：

| 对比 | 固定不变的量 | 可以检验的变化 |
| --- | --- | --- |
| G1−G0 | C、h、b、key 和人口 | 指定中心替换 |
| G2−G1 | a、h、b、key 和人口 | 既定 rank-one 二阶矩修正 |
| M0−G0 | 实数整体 μ/C、h、b、key 和人口 | 原 μ 处的支撑压缩/高阶形状，附生产归约误差 |
| 各几何的 b−0 | 完整几何、key 和人口 | 该固定内容项的增量 |

前三组分别在零内容和共同 b 下报告，再报告各组的差分之差。这是四几何×两内容的配对分解；没有 `M(a,C)` 或 `M(a,Ca)`，不是中心、宽度、形状三个因素的完整 factorial。它不能将形状证据直接解释为指定 a/Ca 高斯的全部残差，也不能估计任意最佳协方差、最优带宽或内容规则。rank-one 对照只否证/支持该一次修正的作用，不构成对所有宽度选择的结论。

全48 TRAIN、三 query→g8 均保留；先在 scene/condition 内使用原质量分母，再作等场景汇总。q8/q16 的原 common16-query 主 KL/JS 与 direct-native KL/JS 同报；q24 使用 native。定位沿旧 R13 人口报告 PCK、benefit/harm、连续误差；front/FOV 只作描述，不作删行条件。中心与区域人口不互相替代。所有场景、方向及反例完整报告；KL/JS 的正差表示变差，PCK 的正差表示改善。

本诊断不设新的效果 PASS，不在事后增加“足够大”阈值或挑获益子集，不做配置选择、bootstrap 显著性筛选或自动 promotion。数值/来源审计通过只准许解释这些开发对照；接近数值误差的变化明确记作无法可靠分辨，不用自定 epsilon 改符号。R20 原门槛和停止决定不变。

## 历史数组与可能的设计启发

`results/round15_regional/forward_complete.json` 明确 `all_probabilities_retained=false`。全64,512矩阵均有哈希，但只保存每场景 metadata-first pair 的原始数组，共4,032矩阵；路径为 `forward/<scene>/samples/000_0000030_0000045/<condition>.npz`。因此 R21 所需 full4 T0 有144条历史承诺、仅9个所需原矩阵直接存档；其余必须从已冻结输入/源码再生并逐位匹配，不能描述成读取全量旧存档。R20 则保留完整概率。复用统计值不能代替新 counterfactual 全局封存及独立审计。

若固定共同内容后，M0 相对 G0 的粗尺度区域优势仍存在，而中心保护未得到同步改善，可支持的原则是：二阶矩压缩可能丢失任务所需的区域形状；区域质心与指定原语中心是两种语义；增加准确区域形状不自动保证同一 argmax 的定位。它不直接支持增加 Gaussian 数量、OU 收缩、硬 mode 约束或另借 point winner。任何精炼后续设计都需先明确单个 GS 原语与聚合区域的身份、保留的信息及可组合的积分规则，再接受同一输出的区域/定位和成本要求。

这里的 full4 使用了 μ/C 之外的局部几何信息；即使它获益，也不能声称该信息已经由单个 μ/Σ 恢复。实际 GS 若指定中心本就等于 μ，则 a 修正为恒等；无内容的 T0 情形也不会受益于内容缩放。实际 GS、learned V、原鲁棒性和未见数据仍须另行验证。本诊断本身没有提供一个一般有效的紧凑 PE。
