# GSModel60 release notice

The GSModel60 dataset maintainer confirmed on 2026-09-16 that the complete
dataset, including all 13,847 PLY files, may be publicly published and
redistributed.

No standard SPDX license identifier was supplied with that confirmation.
Accordingly, the Hugging Face dataset card uses `license: other`. This notice
records the maintainer's publication authorization and does not relicense
third-party software.

Please cite GAPrompt++ when using GSModel60 and retain this notice, the dataset
card, split files, and source metadata when redistributing the dataset.
