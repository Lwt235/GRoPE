# 平均精度归一化收尾控制：结果、解释与决定

2026-11-09。六次完整拟合、统一选模、24 组新预测与 96 组旧预测比较和实际审阅全部完成。**保留完整五维 F，结束这项机制收尾。** N 保留区域用途，但没有解决原生分类相对 Distance 的不稳定性，不作为新的主方案。

本轮问题是：保留方向依赖后，平均精度的标量放大是否仍然必要？竞争解释是标量与方向需要共同作用，或两任务依赖不同部分。N 仅将非自身关系中以 i 端为度量的两项除以 `pi=tr(Σi)tr(Σi⁻¹)/9`，j 端同理，再应用 log1p；自关系保持 F 原值。完整共同内容、初始化、采样流、训练预算与选模规则匹配。详见[事前方案](../../../docs/normalized_precision_plan.md)。

## 区域用途保留，但不能归结为纯朝向

N 对 Distance 的基础 / 固定成员稀疏 R@1 为 **+3.081 / +3.889 pp**，三个种子均正，联合区间分别为 [0.380,6.504] / [1.001,6.996] pp。两条件下三个种子的 PCK、hard/soft EPE 和 CE 都改善：PCK 均值 +1.370 / +1.499 pp，hard EPE −0.02500 / −0.03478，soft EPE −0.02346 / −0.02934，CE −0.09860 / −0.11953。EPE 沿用原配对归一化坐标单位，不解释为跨场景物理米制精度。

F 对 N 的基础 / 稀疏召回仍高 **0.878 / 0.814 pp**，三个种子均正；PCK 高 0.323 / 0.482 pp，hard EPE 低 0.00592 / 0.01077，均为逐种子改善。两召回联合区间 [−0.047,1.776] / [−0.241,1.717] pp 仍跨零。F−N 的 soft EPE 和 CE 平均较好，但两条件都保留 seed 11 soft EPE 变差、seed 22 CE 变差的反例。

N−Q 两条件召回分别 +2.110 / +2.800 pp、三个种子均正；N−T 为 +1.927 / +3.006 pp，基础 seed 22 为 −0.431 pp。N−Distance 的四个预定义组×两条件×三个种子共 24 项召回差均正；高、低中心歧义两组也均有收益。F−N 的分组均值均正但有逐种子负项，没有从这些分组导出通用几何阈值。

这些结果说明平均精度标量放大不足以单独解释区域用途，移除它后仍保留有效关系。N 同时保留方向与归一化谱权重，共同内容也含完整协方差；它不能证明纯朝向足够、标量无用，或将准确率差拆成可加的因果贡献。完整五维的平均结果仍较好，继续保留 F。

## 完成情况与证据等级

区域三个种子各完成 60 epochs / 1,080 updates，选中 epoch 36/18/39；原生各完成 120 epochs / 46,800 updates，选中 110/120/100。六次训练均正常退出，完整初始化、采样流、参数量及原验证最优选模核对通过；全部选定后才导出开发结果。冻结源码、模型、缓存和预测身份无变化。原生峰值分配约 12.17 GiB；共享卡上的训练墙钟时间不能用于方法效率比较。

120 组预测的独立指标复算最大差为 8.88e−16。N 的三个原生排列最大 logit 差分别约 5.01e−6、7.15e−6、4.29e−6，类别变化均为零。主比较图已实际查看：三个种子和均值与表格方向一致，无明显裁剪；图中未画置信区间，区间见表。这是同一研究代理的独立计算与人工阅读，不是外部复现。
