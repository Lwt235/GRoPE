# 区域重叠标签与中心对齐：旧 fit 输入核对

2026-11-10。按照先写的[诊断计划](plan.json)，只读取既有 fit0 的576帧对及两方向标签，没有模型预测、新训练或新求解器运行。正在运行的共同旋转骨干比较不作任何修改。

在 overlap≥0.3、即存在有效重叠区域的查询中，**只有49.987%在64个候选中存在中心距离≤0.1的候选；选重叠最大的候选时，中心PCK为41.722%。** 因此，即使区域标签预测正确，也不保证两区域中心是精确点对应。这里的0.1是原指标的pair归一化单位，不是0.1米，也不等于主对齐评分的0.2米阈值。

| 固定统计 | 旧 fit0 结果 |
| --- | ---: |
| 有效重叠查询占全部查询 | 31.293% |
| 有效查询中存在距离≤0.1中心的比例 | 49.987% |
| 选择最高重叠区域的中心PCK | 41.722% |

有效查询只占全部查询约三成，原损失只监督这些查询。最高重叠候选、真值最近中心及软目标统计均使用真值，只是诊断，不能部署；其中最近中心不保证最高重叠，最高重叠也不保证最近中心。大量目标质量离中心较远，与区域支撑的范围及多候选标签定义相容，不能解释成标签必然错误。

这量化了此前已经记录的“区域描述与中心定位不同”这一限制。它不证明当前模型达到标签最优，不预测刚体求解成功率，也没有分离为何HRoPE、固定H或五维会获胜：全体方法使用相同标签，集体一致的多个粗对应仍可能支持准确刚体估计。当前PE比较和所有先前正负结论继续保留，不能据此调损失、阈值、筛查询或重新定义成功。
