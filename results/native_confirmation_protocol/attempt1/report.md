**本页固定后续确认的对象、模型范围和主比较；尚未执行官方 TEST 评价。** 当前五组新种子复现继续按原计划训练。只有它完整结束、原定新五组信号成立且完成实际审阅后，才封存全部最终模型与执行源码，再开放测试基元。若该批次不支持继续，保留这份未执行计划，重新评估设计。

## 要回答的问题

当前五维在原生旧开发集上优于固定球形，支持变化协方差的额外作用；对 Distance 的旧三种子效果仍混合。确认要问的是：**保持模型和训练规则不变，五维对最强 Distance 的平均收益，能否在无已知历史对象重叠的数据上重复？** 竞争解释是旧对象特性、少数有利种子，或完整官方基准中历史复用对象造成的表面改善。

官方 TEST 的 6,090 个对象全部保留。其中 2,245 个底层对象在早期研究中已使用，另外 **3,845 个无已知历史 ID 重叠，覆盖全部 60 类**。完整官方基准、两个来源组、历史复用组和无已知重叠组均固定报告。后者承担主要泛化判断；完整基准的好成绩不能替代它。元数据和类别已知，不等于测试基元和效果已经开放，也不能证明没有几何近重复。

主要终点是 **3,845 对象组、base 条件、新五组的 relative5 减 Distance 的 mCA 差**。60 个类别等权，每类内部对象等权，五个种子对等权。支持条件预先固定为：平均至少 **+0.5 pp**，且同时重采样种子对及类内对象所得 95% 百分位区间下界大于零。它是有限实验的正面信号，不能单独完成整体研究目标。正均值但效果幅度或区间不足时保留不确定性；均值非正时保留负确认，不追加种子、改指标或换测试子集救分。

旧三组与合并八组分别报告，不能替换新五组主比较。固定球形只与相同旧三组候选比较，不声称有八组机制结果；其效应及区间单独解释，不另加最小效应门槛。稀疏、密集、抖动、倾斜和排列条件，OA、CE、逐类与逐种子结果全部保留。一个主终点成立不表示所有条件、类别或既有 RGB/迁移实验均通过。

## 统计实现及边界

种子是一个变动来源，对象是另一个；同一个对象被所有种子和两种方法共同评价。程序独立重采样种子对和各类别内部的对象，并将同一对象的重复次数共享给所有种子及两种方法，再乘上种子权重。类别本身在主区间中固定，保持本基准 mCA 的定义。另报固定对象下的种子区间、固定种子下的类内对象区间，以及与历史报告可对照的类别区间。主方法与固定球形机制比较的两个主要人群、六条件均计算联合区间；其他比较的范围见计划。

该做法借鉴了交叉因子的分别重采样，而不是将每个种子×对象单元独立抽样。文献本身也没有给交叉数据提供通用精确 bootstrap；此处的类内分层适配和五种子百分位区间没有额外的精确覆盖率保证。保留这种局限，并结合全部种子和条件解释结果。[Owen，2007](https://arxiv.org/abs/0712.1111) · [Owen 与 Eckles，2012](https://arxiv.org/abs/1106.2125)

实现采用固定 10,000 次重复、固定随机种子及每块 128 次，内存按块和单类对象数控制。五项检查覆盖类别等权与对象准确率的区别、共享对象依赖、纯种子波动、预测身份配对，以及主种子/人群不能被其他分数替换。另读取九份既有 base 预测，只复现旧 765 对象上五维对 Distance/固定球形的三个配对点估计；最大差约 1.64e−14。该执行检查使用 200 次重采样，不将其区间解释为新增科学证据或正式确认结果。
