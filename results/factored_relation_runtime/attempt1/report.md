# 关系投影重排的 GPU 验证与成本

**相同参数和数学公式可以用更省资源的方式执行；此次收益主要出现在原生 512-token 模型。** 五维模型原生前向＋反向中位耗时 188.602→123.812 ms（减少 34.35%），峰值显存 10.986→7.888 GiB（减少 28.20%，约 3.098 GiB）。前向为 86.095→48.422 ms（减少 43.76%），前向峰值仍约 3.155 GiB，未下降。不能仅凭避免一个中间量就宣称所有阶段的峰值都会降低。

重排使用末层无偏置这一既有结构：`q_hᵀ(W_h z_ij) = (W_hᵀ q_h)ᵀ z_ij`。保留同一个关系 MLP、所有参数名和值、GELU、内容、attention 和损失。代码只在私有模型实例上改变收缩顺序，没有加入可学习模块、更新权重，或替换已冻结训练/预测。隐藏的成对特征仍存在，复杂度仍为二次。

四种方法都统一应用同一重排，防止只优化候选后作不公平速度比较。各方法均为既有种子 11 checkpoint，旧验证输入 batch16；区域每视图 64 tokens，原生 512 primitives。FP32 网络、FP64 几何，TF32 关闭。同一张空闲 A6000 上，每组热身 5 次，8 个轮换顺序的测量块，每块 3 次调用；原始结果保留 CUDA 与同步墙钟时间、各块范围和基线分配。下表只报告这次同卡对照，不用上一张卡的时延做混合比值。

## 观测区域：原版 → 重排版

| 方法 | 前向 ms | 前向＋反向 ms | 前向＋反向峰值 GiB |
| --- | ---: | ---: | ---: |
| distance_mlp | 8.459 → 8.636 | 29.517 → 30.679 | 0.356 → 0.275 |
| direct_mlp | 9.384 → 9.564 | 30.781 → 31.092 | 0.365 → 0.283 |
| gaussian_relation | 10.289 → 10.395 | 31.624 → 32.409 | 0.361 → 0.280 |
| relative5 | 9.723 → 9.818 | 30.145 → 30.897 | 0.359 → 0.277 |

公平重排后，原生五维的前向＋反向仍比 Distance 慢约 16.34%（123.812 vs 106.425 ms），前向慢约 56.36%（48.422 vs 30.969 ms）。这是所有兼容 MLP 都可使用的执行优化，不是高斯参数化专属收益，也没有证明新的任务准确率。

区域五维前向/前向＋反向分别约慢 0.98%/2.49%，时间区间有重叠，不能声称该小规模模型得到加速。区域反向峰值减少约 22.80%（0.359→0.277 GiB），本来就较小；原生与区域的结论应分开。

## 数值与梯度检查

CPU float64 的独立收缩检查，以及两个完整模型族、四种 PE 的全参数梯度检查均通过。GPU 使用全部 64 对旧区域验证样本和全部 765 个旧原生验证对象；原版对保存的旧验证 logits 回放完全一致。原生四模型及区域五维、Distance、full11 的预测索引不变。八组完整 batch 的训练损失与全参数梯度检查均通过；最大整体梯度相对范数差约 8.61e−7，最大 PE 梯度相对范数差约 1.56e−5。保留每个参数的差异，未声称 FP32 位级相等或长训练轨迹相同。

原定“索引零变化”机械检查为 **7/8 通过**，该原始结果没有改写。例外是区域 Direct：前向有 10 处索引变化，补查反向还有 3 处。所有变化都处于原先定义的无有效匹配查询，不进入 R@1/PCK；竞争目标的整列匹配标签相同，原 logits 间隔最多 1.91e−6，目标世界中心差最多 2.38e−7，但输入并非位级完全相同，不能称为严格重复 token。实际召回、PCK 和 hard EPE 完全不变，Soft EPE 差约 −4.46e−9、CE 差约 −2.00e−8。该现象不足以解释百分点级用途结论，也不值得为达到索引一致再改算法。

补查报告曾因对列表型计数做标量相减而序列化失败。原日志、源码和已经生成的 logits 保留；后续仅在 CPU 完成同一批预测的标量差与列表一致性报告，没有重跑 GPU 或选择更有利结果。

## 适用范围与决定

将此适配器保留为后续原生实验的实现选项，并对兼容的强对照一致使用。当前三个原生归因训练仍用原冻结实现；既有确认预测和已准备的固定种子复现源锁也保持原样。一次旧 checkpoint、有限验证输入和单批参数反向不能证明新实现的完整优化轨迹一致，若未来正式采用，须在新的执行计划中明确版本。

本测量不包含数据加载、优化器及常驻整套训练缓存；几何输入不求导。没有测量 RGB/NVS、BF16、更多 token 数或其他硬件，不将早期 R70 代数估算当成本次这些范围的实测证据。原生固定球形归因、稳定性及实际任务证据仍决定科学路线，不因计算优化而宣布一般方案完成。
