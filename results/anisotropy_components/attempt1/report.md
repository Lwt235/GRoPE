# 位移与协方差各向异性：结果与实际审阅

2026-11-07。本轮 12 次新训练、统一选模、48 组新预测及 96 组既有预测的比较均已完成。区域六次训练各完成 60 epochs / 1,080 updates，原生六次各完成 120 epochs / 46,800 updates。24 项执行任务全部正常退出，队列没有剩余任务。

**结论：位移—形状关系在区域匹配中保住了主要用途，单独保留协方差—协方差关系没有做到；原生分类则仍以完整五维的平均效果最好。两任务给出的简化方向不一致，本轮不推出通用替代，保留完整五维候选。** 这是旧开发数据上的机制检验，不是新的独立确认。

F 为完整五维；M 只在位移项保留各向异性；S 只在协方差项保留各向异性；T 将两组关系都改为各自大小的球形。四组保持五个槽位、同一关系 MLP、完整初始化、共同内容和训练预算。M/S 的名字描述 PE 的变化：完整几何仍在所有模型的共同内容中。

## 区域匹配：M 的收益同时体现在匹配与中心定位

M 相对 T 的基础/稀疏召回分别提高 **3.665 / 4.231 pp**，相对 Distance 为 **4.819 / 5.114 pp**，相对固定球形为 **4.201 / 3.774 pp**。这六个比较的三个配对种子均为正，五个场景均值、四个预定分组及高/低中心歧义组均值也为正。基础 M−T 的种子×场景区间为 [1.679, 5.858] pp，M−Distance 为 [2.301, 8.066] pp。

M 相对 F 的基础/稀疏召回平均高 **0.861 / 0.411 pp**。基础三个种子均正、五场景中四个均值正，但联合区间为 [−0.138, 1.772] pp；稀疏种子差为 +0.598 / +0.830 / −0.195 pp，区间 [−0.756, 1.219] pp。结果支持继续研究这一简化，尚未确立它对 F 的稳定优势，也不是正式等效证明。

中心定位没有与区域召回发生总体冲突。基础 M−F 的中心 PCK 为 **+0.520 pp**，三个种子均改善；平均 hard/soft EPE 和 CE 也改善，但种子 33 的两个 EPE 有退步。稀疏 PCK 平均 +0.262 pp，种子 22 为 −0.021 pp；这些局部反例保留，不放大成整体否决。相对 Distance，M 的基础/稀疏 PCK 分别 +2.213 / +2.243 pp，平均两种 EPE 和 CE 均更好。

S 相对 T 的基础/稀疏召回平均为 −0.425 / −0.080 pp，方向随种子改变；F 相对 S 则为 +3.229 / +3.900 pp，三个种子均正，中心 PCK 也在三个种子改善。原假设“只保留协方差关系就能保住主要用途”没有得到支持。不能据此声称协方差关系在所有任务无用，也不能把 M 的收益全部称为朝向的作用。

## 原生分类：单独保留任一组都未形成更好的通用方案

F−M 的基础差为 **+1.801 pp**，三个种子为 +3.258 / −0.284 / +2.428 pp，联合种子×类别区间 [−0.949, 4.731] pp。F−S 为 **+2.379 pp**，三个种子均正，区间 [−0.428, 5.121] pp。两项平均损失都超过事前 1 pp 工程参考，但区间仍宽，不能将其表述为所有新对象上都成立的确定差异。

F 的六条件 mCA 均值均高于 M 和 S；F−S 在全部条件的三个种子均正，F−M 在基础、稀疏、密集仍有种子反例。基础 F−M 的 OA 三种子均正，CE 三种子均更好；F−S 的 CE 同样均改善，但 OA 种子 33 为 −0.261 pp。基础 F−M 的 MACGS/ModelNet 平均差分别 +3.442 / +0.159 pp，后者三个种子方向混合；F−S 的两个来源平均为 +1.919 / +2.840 pp，均为三个种子正。

强对照进一步限制了简化结论：M−Distance 基础平均 **−0.197 pp**，六条件均值仅稀疏为正（+0.142 pp）；噪声和倾斜条件分别 −0.885 / −0.699 pp，三个种子均负。M−固定球形基础 +0.931 pp，但种子方向混合且平均 CE 略差。S−Distance 基础 −0.776 pp，同样没有建立稳定优势。不能用它们对较弱 T 的局部改善代替对 Distance 的比较。

基础 F−M 的 60 类中，26 类平均改善、18 类退步、16 类不变；28 个对象在不同种子间出现纠正/退步方向反转。F−S 对应为 32 / 18 / 10 类和 31 个反转对象。原生每类样本有限，不能由少数稳定案例推出普遍成功条件。

## 交互、错误交换与机制解释

成绩交互 I=F−M−S+T 在区域基础/稀疏为 −0.436 / −0.331 pp，原生基础为 +1.622 pp。原生其他条件均值也为正，但所有联合区间跨零，基础和稀疏有负种子。它提示任务差异，不能单独证明两组几何量存在物理因果协同。

基础区域 F−M 的纠正/新增错误率为 9.578% / 10.438%，净 −0.861 pp；对应三种子均纠正/均退步的查询数为 67 / 64，另有 1,318 个查询在种子间反转。F−S 为 15.214% / 11.985%，净 +3.229 pp，稳定纠正/退步为 250 / 140。稳定案例的个数没有包含全部错误交换，也没有场景宏平均权重，不能用它代替主指标。

原生 F−M 为 6.946% / 5.145%，净 +1.801 pp，稳定纠正/退步为 3 / 3。固定 ID 案例中，`58/bookshelf_0048.ply` 的三个 F 模型都正确、三个 M 模型都错误；`46/sink_0029.ply` 则相反。它们是事前规则按 ID 排序的案例，没有据结果挑选“典型图片”，本次未查看新原始图像。完整 96 组错误分解和全部事件保留在 `error_analysis.json` 与 `events/`。

训练期间的代数分解和固定旧 fit 输入诊断说明另一个竞争解释：完整项既包含方向残差，也包含方向无关的平均精度。令 r=tr(Σ)/3、h=tr(Σ⁻¹)/3，则完整位移项为 h·d² 加方向残差，完整协方差项为 3hᵢrⱼ 加方向残差。T 同时改变这些成分，M/S 也没有将平均精度与方向作用完全分开。旧 fit 中 r·h 的幅度及来源差异确实存在，但不能从输入分布直接推断网络的准确率收益。

因此下一步值得预先固定的单一控制是：**保留 r、h，用 hᵢd² / hⱼd² / 3hᵢrⱼ / 3hⱼrᵢ 替换四个关系量，再经过相同 log1p 和五输入 MLP。** 它保留方向无关的大小/谱信息，移除两组方向残差，不增加模块。它不是同一个球形协方差的物理替代；本轮尚未实现、训练或选择这个版本。后续若推进，仍匹配两任务、三个种子和原预算，先比较 F、T、M/S 与 Distance：若它保住两任务用途，才讨论进一步精简；若仅保住某一任务，则明确分任务机制；若明显损失，则保留联合方向关系。先回答这一可区分的问题，不追加多种任意组合。
