假设：五维相对 Distance 修正的错误与区域形状、中心配置歧义或两端形状关系不同有关，并在部分种子、场景或对象上重复出现。竞争解释：收益只是整体难度、类别/来源构成或种子波动的结果；五维也可能引入相同类型的新错误。分析不能把相关性当作位置编码作用的因果证明。

固定范围：区域旧五场景及已经使用的九场景，各基础/固定查询 sparse256、种子 11/22/33；原生旧 dev_eval 的 512 模型八种子、256 模型三种子，以及已用官方 TEST，保留原六条件。官方主对象组仍按原 3,845 无已知历史 ID 重叠对象，新五种子主读数；全量、历史复用及合并八种子只作明确标注的描述。区域五维对 Distance 为主，对固定球形为归因背景，旧五场景再对已有 symmetric3；原生保留 Distance、固定球形、已有 symmetric3 对照，均按可用的相同种子配对。没有对照的格子明确缺失，不新增训练补齐。

逐查询/对象记录四类：两者均正确、五维独有正确（修正）、对照独有正确（引入错误）、两者均错误。计数以 query/object×seed 为预测事件，不当独立样本；另报告唯一查询/对象在种子间一致与反转的数量。区域沿用 overlap≥.3 的有效查询与正确规则；中心 PCK≤.1、hard EPE、soft EPE、CE 作为配对次指标。原生保留完整 60 类预测和真实标签。重建的原指标必须与既有汇总一致；宏平均和原始计数分开呈现。

区域几何特征固定为：已有中心配置 ambiguity、候选 shape diversity；本次补充 log(λmax/λmin) 和最近八个邻居的平均两端关系差异 mean(|log1p(mi)−log1p(mj)|+|log1p(ti)−log1p(tj)|)。后两项均从实际输入同视图中心/协方差计算，不使用标签、预测或真实跨视图变换；该差异是描述符性质，并非网络依赖该分量的证明。前两项继续使用原 fit 阈值与四组；新增特征用旧 fit0/fit1 的合并中位数二分，不扫描阈值。base 特征用于两条件，防止稀疏前后分组对象改变。报告每个场景内的高低组差，以检查总体关联是否由场景构成解释。

原生几何特征固定为：前 512 个实际 base 输入基元的各向异性 log(λmax/λmin) 中位数、log(sqrt(trΣ/3)) 的对象内标准差、3e−8/trΣ 的中位数。使用旧 fit 对象计算每一类别的中位数阈值，再在相同类别内部划高低组，以减轻类别/来源混淆。256 流程的样本错误照常整理，但几何关联主要报告 512 流程，不把 base 几何当稀疏实际输入。均只描述，不筛选最佳阈值或新增显著性门槛。

案例清单：主比较中按三/五/八种子全部同方向的唯一案例，按既有 ID 字典序选择有限示例；完整事件表保留，避免只挑容易解释的成功案例。分类同时报告类别对混淆与来源；不从结果新增合并类别或别名。区域不以跨视图中心误差解释同视图 PE 的直接机制。
