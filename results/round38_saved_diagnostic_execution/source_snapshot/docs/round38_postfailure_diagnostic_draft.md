## 1. 明确锚点与可比较范围

令 `a=input__mu`，它是 R38 真实采用的齐次三维锚点；`p=a[:2]/a[2]` 是 reference-8 投影。每行分别保存：

- `a_z` 的正、零、负符号；`a_z=0` 时投影未定义。
- 除法结果是否有限；不把溢出替换为屏幕边界。
- `p` 相对原 FOV 的内部、外边界或外部位置，以及是否恰处于 native cell 边界。
- 原 `structural_branch/structural_zero`；结构零的 raw 不存在有意义的最大质量位置，不能默认第 0 格并将其计为几何偏移。

只在 `a_z>0`、投影有限、位于闭 FOV、且非结构零的行上定义主要的锚点 cell 检查。闭 FOV 的外边界另列计数；常规内部可同时保存半开区间的唯一 owner，但边界推断使用下面的集合。非前方、视野外或除零行仍完整保留其一般 winner 诊断，只将主锚点检查标为不适用；不会声称模型应该把赢家放进不存在的 FOV cell。

定义 `A(p)` 为闭矩形包含 `p` 的全部 native cells。恰落内边界时允许两个或四个 cell；因此不会把邻接格或 first-index 平局规则误写成锚点丢失。另记 `8*(p-old_a2)` 的二维差和长度（仅投影有限时定义），以显示旧 R20 经过深度/屏幕处理的二维中心与新三维锚点投影是否语义一致。此差仅是已保存中心的比较，不推断两种算法具有匹配输入或匹配概率。

## 2. 将 raw、floor、内容与物化严格拆开

对每个非结构零行，记封存向量

`R_j=log_raw_mass_j`，`G_j=log_floored_mass_j`，`b_j=input__content_bias_j`，`L_j=G_j+b_j`。

依次保存 `R`、`G`、`L`、封存 `log_probability`、封存普通 `probability` 的 first-index argmax、精确最大值集合、精确并列数和 top-two gap。单一 key 时无 top-two，但本固定人口始终为 432；整行并列时 gap=0。结构零行不定义 `R` 的 winner，其余阶段照常定义。

先复核 `G=logaddexp(R, log(1e-30*area))`，以及 `L-logsumexp(L)` 对封存 log-P 的一致性。沿用已有算术审核容差，只审核代数复现，不把容差当作数学模式相同的证明。原 g8 等面积意味着 floor 在精确算术中不应改变 raw 大小次序；任何实际的最大值集合扩张或 winner 改变须独立报告，不能归到内容。`L`、log-P 和普通 P 的 winner 差异也独立报告，覆盖减归一化常数、指数物化和舍入带来的并列。实际生效的 winner 始终是封存 `argmax(probability)`。

对有主锚点定义的每行，在 `R/G/L/普通P` 四阶段分别报告：

1. 最大值集合是否与 `A(p)` 相交；另报真实 first-index winner 是否属于 `A(p)`。集合相交回答锚点格是否仍是共同最大之一，first-index 回答实际实现选了哪格，两者不能混淆。
2. 对 log 阶段记录 `max_j score_j - max_{j in A(p)} score_j`。严格正值证实在这个封存数值向量中，任何锚点格都不是最大格；零值不能证明连续密度峰值在锚点。
3. 保存 `8*distance(p, winning_cell_rectangle)`，以及对全部并列最大格取最小矩形距离。矩形内距离为零，避免把 cell 中心的正常量化偏移误当成质量格离开锚点。另保存到 first winner 的 cell 中心距离供实际离散定位解释，但不以它判定锚点格丢失。

上述检查全部使用 native cell 的面积质量。**它不能定位连续 density mode，也不能排除 mode 位于锚点却由非对称形状、cell 边界或 FOV 限制导致另一格积累更多质量。** 若要研究连续模式，需要另一份预先声明的密度/导数实验，本草案不授权。

## 3. 内容项的固定输出反事实与精确账

将同一 `G` 的 winner 与 `L=G+b` 比较，相当于只在已封存几何质量上移除原内容 bias；这不是重新前向或一个被选中的无内容候选。无需计算新任务指标或扫描温度。

设 `j_g` 是 `G` 的 first winner，`j_b` 是 `L` 的 first winner。记录 winner 是否改变；若改变，保存

`geometry_loss = G[j_g]-G[j_b]`，

`content_gain = b[j_b]-b[j_g]`，

以及 `L[j_b]-L[j_g]` 和与 `content_gain-geometry_loss` 的舍入残差。它给出原内容克服了多少既有几何分差。不能把极小的舍入级差值隐藏为宏观机制；保存实际 gap 和残差，不事后发明重要性阈值。

在有主锚点定义的行上，对 `G` 和 `L` 的最大值集合与锚点集合关系形成完整 2×2 计数：两者都含锚点格、仅 G 含、仅 L 含、两者都不含；另对实际 first winner 给出同样计数。表格措辞为“内容将赢家移入/移出预测锚点格”，不能称为真值收益/损害。一般的 winner 是否变化则对全部 2304 行都有定义，包含结构零行。

这个代数对比可以直接认定**固定封存质量下**内容是否改变了选择；它不证明 Gaussian 建模、深度截断或几何精度对真实 PCK 的因果贡献。

## 4. 最少的深度描述与可证伪假说

记录原输入决定的 `a_z`、`sigma_z=||factor_z||`、`s=sqrt(a_z^2+sum(factor_z^2))`、`a_z/s`、`sigma_z/s`、已保存 `front_mass` 和 `tau32`。`s` 以 `math.hypot(a_z,*factor_z)` 的稳定多参数标量归约计算，不是逐元素的二元 `hypot`。`s=0` 时两个标准化比值为 null；确定深度分支明确标记。另固定记录深度相对变化 `sigma_z/a_z`，**只在 `a_z>0` 时定义**；不为非正中心深度制造一个替代分母，除法溢出应单列状态而非截断。

为了描述几何集中程度，只对同一封存向量作 `w_raw=softmax(R)`、`w_floor=softmax(G)` 后处理，保存两者的熵和最大概率；结构零时 raw 版本为 null，floor 版本仍定义。同步记录已保存 raw 总质量与总 floor 的 log 比，防止把 floor 主导的平坦分布误归因于 RMS 投影。熵仅描述这个 FOV 上的离散集中程度，不是无限屏幕上的协方差或单峰宽度，也不能证明其比旧 R20 Gaussian 更宽。

固定报告全部查询、三个场景及上述 2×2 单元的计数/定义域分母、均值、最小最大、p50/p90/p99（明确固定一种线性插值分位数实现）。不按结果寻找切点、top-k 子集或最优相关阈值；这些描述不得把与深度变异的关联写成其因果效应。

预先明确的判断只有以下范围：

- **“只要三维均值在 a，封存 raw 的最大 native 质量格就必然包含 pi(a)”**：任一主锚点定义行的 raw 锚点 log-gap 严格正即可在该数值实现中否证；若全为零，只支持这批已封存输入，没有一般保证。
- **“所有锚点格偏离都由旧内容引起”**：存在 raw 或 G 阶段已经丢失锚点格的行即可否证这个强说法。不能据此分开 RMS 横向正则、严格前方条件、透视非线性和有限 cell 积分各自的影响，因为此处没有改变它们的受控实验。
- **“加入原内容从未改变赢家/从未把赢家移出锚点格”**：分别由全人口 winner 改变记录或上述 2×2 中相应非空单元否证。若这些单元为空，也只约束这批封存输出，不能证明内容在其他任务无作用。
- **待检验的机制线索：RMS 投影后的质量较分散或偏离锚点，而内容温度仍取旧二维 Ca，因而原内容可能更容易移动赢家。** 本草案将其可直接证伪的必要预测限制为“至少有一部分锚点格丢失发生在 G→L 的内容注入这一步”：若 2×2 表中 `G 含锚点格、L 不含` 的计数为零，则它不能解释本批输出中新增的锚点格丢失。若非零，则用已固定的几何损失/内容增益账确认位移在哪一步发生，并并列报告该单元的深度相对变化、raw/floor 熵、几何 margin 和旧 tau 的连续分布。只报告上述固定单元，不按 sigma_z/a_z、熵或 tau 搜索切点。不同单元的集中程度或深度差异最多是相关线索；没有另一个温度或 matched geometry 的受控比较，不能证明“tau 错配”因果、比较同一内容在另一几何上是否更易推动赢家，或声称重算温度能解决问题。

所有“否证”只针对本次保存的数值算子和上述有限人口断言。R38 的完整独立概率参考未通过，因此无法将数值 winner 的反例直接升级为理想连续分布的精确反例；gap 的完整分布会显示推断对数值精度可能有多敏感，但不会补成缺失的精度证书。
