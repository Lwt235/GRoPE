# 方向无关平均精度控制：完成结果与实际审阅

2026-11-07。六次训练、统一选模、24 组新预测及 144 组既有预测的固定比较全部完成。18 项执行任务均退出 0，队列于北京时间 11:10 完成；区域各 60 epochs / 1,080 updates，原生各 120 epochs / 46,800 updates。

**决定：不推广方向无关版本 Q，保留完整五维 F。平均大小与平均精度不足以保住本轮两个任务的主要准确率收益。** 区域证据更明确，原生差异仍有类别与来源不确定性；本轮没有建立一般有效或完成新的独立确认。

## 固定控制与主结果

Q 保留 `r=tr(Σ)/3` 与 `h=tr(Σ⁻¹)/3`，将不同 token 的四个关系量改为 `hᵢd²、hⱼd²、3hᵢrⱼ、3hⱼrᵢ`；相同 token 保留原自关系 0、0、3、3。普通距离、log1p、五输入 MLP、参数、全部初始化、共同几何内容和训练预算一致。这是去掉 PE 中的方向相关部分，不是让整个模型失去方向信息，也不是保留全部形状特征谱。

Q−Distance 原生基础 **−1.046 pp**，三个种子均更低；六条件均值均负，噪声/倾斜也为三个种子负。Q−T 基础 −0.091 pp、Q−固定球形 +0.082 pp，均有种子混合。正面局部信号仍保留：Q 对 T 的基础 CE 三种子改善，稀疏 mCA +0.819 pp、三个种子正；MACGS 来源基础 Q−T 平均 +1.072 pp，而 ModelNet −1.254 pp。这些信号不足以支持用 Q 替代 F 或强 Distance，也不能把平均精度整体判为无用。

## 错误交换与解释边界

区域基础 F−Q 的纠正/新增错误率为 **14.980%/11.992%**，净 +2.988 pp；268/156 个查询在三种子均纠正/均退步，另有 1,842 个查询在种子间改变方向。低/高中心歧义组的净差 +2.833/+3.146 pp，只是固定分组关联，不据此宣布高歧义为唯一机制。

原生 F−Q 为 **7.532%/4.882%**，净 +2.649 pp，4/2 个对象在三种子均纠正/均退步，另有 21 个对象反转。按 ID 排序的固定案例中，`18/18009b0d.ply` 的三个 F 模型都预测正确类 18，Q 分别预测 0/3/33；`16/1700c4b7.ply` 的 Q 均正确，F 均错为 17。成功与失败都保留，未查看或挑选新的原始图像。全部 56 组分解、所有查询/对象事件和固定案例见原始文件。

与上一轮结合，本轮更支持**保留方向相关的区域关系**：只有大小与平均精度不能保住收益，尤其区域 M−Q 的差较明确。不过它不证明方向是唯一信息来源、不证明一个特定朝向量的唯一因果贡献，也不证明平均精度在方向存在时没有条件性价值。后者正是当前仍未区分的问题。

下一项有针对性的设计方向是保留完整方向关系，检验是否必须同时保留标量放大因子 `pᵢ=rᵢhᵢ`。候选归一化可以在非对角关系中将以 i 为度量端的位移量和形状量除以 pᵢ，以 j 为度量端的两量除以 pⱼ，自关系继续保持原值。它保留方向依赖而让方向平均与 T 相同，可与 F/Q/T 构成互补控制；没有新增模块或可学习系数。**这仍是待固定和验证的假设，本轮没有运行这个版本，也没有证明这种归一化会提高性能。** 若推进，应先检查历史是否已有同等控制、固定比较和不同结果对应的决定，再实施；不由当前负结果直接推出该新设计有效。
