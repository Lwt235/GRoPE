# 已知有效查询仍未改善对齐，主要差距留在预测对应中

2026-11-10。六方法各三个既有种子、18组新增几何求解全部完成并独立复算。原480个旧帧对全部保留，零训练、零模型推理、零新数据。预测索引、候选区域和求解器不变，只使用相同真值有效源查询掩码。所有新成绩均为不可部署诊断。

**五维从41.736%变为39.653%，差−2.083个百分点，三个种子均下降，种子×整场景95%区间[−4.861,0.903]。六种方法的平均成绩均下降，没有支持“只需筛除无有效区域标签查询就能显著提高当前对齐”的假设。** 区间仍跨零，不能声称筛选普遍有害或所有效应等于零。

在相同真值有效查询及同一求解预算中，五维39.653%，理想最大重叠对应71.042%；差31.389个百分点。最低索引并列的区域参照仍为70.208%。这使有效查询中的对应选择与几何一致性成为下一设计应直接回答的问题；不能把这31个百分点写成换一个PE必然可得到的增益。

## 固定比较与含义

掩码为A→B方向 `max(overlap)>=0.3`，与上一项有效查询oracle完全相同。30,720个源查询中保留10,264个；B端全部64候选及每个模型原top1对应不变。这里的无有效标签只表示没有该方向的有效查询直接损失，token或logit仍可能作为反向B→A候选获得梯度。

m个源查询枚举C(m,3)假设，沿用0.1 pair单位一致性半径与最多5次非恶化重估；34对不足3个查询计失败。仍对全部64个源中心评分，RMSE<0.2米为成功。相对原全64查询，筛选也改变了假设集合、可用空间约束与共识评分，所以不能把变化当作对“完全没有任何对应”的纯因果分解。原有效阈值也不等同于绝对物理不可匹配。

## 判断与后续方向

**结束“删除缺少有效区域标签的查询可显著挽救现有对应”这一固定假设。** 不扫描overlap阈值、温度、置信度或mask，不由本轮增加拒识头。也不据跨零区间断言任何拒识方法均无用；这只检验了当前标签有效性定义和既有预测。

与上一项oracle合看：理想区域对应能够配合原求解器；已知查询有效性没有挽救实际预测；同一有效集合内仍有约30–31个百分点区域对应差距。下一阶段应把设计问题落在未知相对位姿下如何用高斯关系区分正确对应、形成跨帧几何一致性，同时保留Distance、固定旋转和HRoPE强对照。该方向尚未形成冻结的新实现或训练计划，不把它写成已验证方法；若采用局部框架必须回应R50/R53既有负结果。

保持完整五维公式、现有骨干、全部旧正负结果与原确认数据已用状态。本轮是机制诊断，新增可部署用途证据为零。一般性3DGS参数化PE目标仍active，不能由某项诊断差距或有限比较宣称完成。
