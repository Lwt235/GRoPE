# R48：原生三维 Transformer 位置编码开发实验

本轮已完成 50 次训练及预定开发评估。官方测试集仍未使用，完整研究目标尚未完成。

固定主方案 conditional 的开发 OA 为 **88.622%**；强对照中最高均值来自 mlp，差 **-0.269pp**。

主方案未达到本轮预定开发信号条件；全部连续差值和次要结果保留如下。

这是同一四层全局标量 self-attention 分类骨干内的 PE 比较；NoPE 同样接收 XYZ 内容。这不是论文 Point Transformer 的完整复现。本轮结果不消除 R47 匹配任务的负结果，也不能单独证明一般性。

官方训练缓存分为 7910 fit / 965 val / 965 dev_eval；所有模型选定后才进行 dev_eval。各角色使用相同 120 epochs、29,760 次更新和选模规则。五个种子是优化重复，表中种子标准差和范围不是总体置信区间。
