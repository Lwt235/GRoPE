# R48：在原生三维 Transformer 内检验高斯位置参数化

2026-11-01，数据数组解码及训练前固定。主目标仍是将 3DGS 的参数化形式用于
Transformer 位置编码。点云分类是检验载体，渲染质量不参与本轮目标、选模或
晋级标准。当前没有通过完整研究目标的候选；R47 匹配负结果原样保留。

## 科学问题与备择解释

R47 的动态椭球相对自身简化版和等容量自由二次函数有收益，但整体三维匹配
低于 RoPE/MLP。该任务还包含预测深度和相机投影。本轮在不包含相机、预测
深度、渲染器或物理输入协方差的原生点云中，检验**同一高斯 PE 公式**是否
具有独立的任务效用。正结果不能推翻 R47；负结果也不否定所有可能的 GS PE。

主假设：位置中心及正定完整形状的条件参数化，比普通 RoPE、非高斯可学习
映射和等参数自由二次位置项提供稳定的分类收益。
备择：收益只来自额外容量/非线性映射；或高斯局部偏置不适合当前任务；或
只有更精简的各向同性形式有用。各备择分别由对应控制检验。

完整 PE 为 `T * normalized(q_i)·normalized(k_j) - (δ-m_i)^T P_i (δ-m_i)/2`。
一层共享线性预测器从各层归一化 token 输出每个头的相对中心及 Cholesky
精度参数，完整三维新增 1746 参数。正定精度对应一个有尺度和方向的椭球，
与 GS 正定协方差的结构对应；不是读取已训练 3DGS 的物理尺寸。查询行的
高斯幅度在 softmax 中抵消，因此没有加入无效幅度参数。内部等价为 9 维
二次位置 Q/K 通道；复用 R47 实现，不追加 RoPE 混合或新损失。

动态高斯注意力已有先例，不能把参数化迁移称为首次提出高斯注意力。新颖性
与效用分别讨论。一般 Transformer PE 目标不要求绑定一个渲染器或某个 GS
重建系统，也不要求把形状协方差等同于定位不确定性。

## 配对骨干和对照

新建固定全局标量 self-attention 分类骨干：XYZ→96→96 的 GELU stem、4 层
96D/2 头 pre-LN 注意力和 192D FFN、末端 LN、mean/max 合并池化、192→128
GELU、dropout .3、40 类头。含 V 聚合、残差和 FFN；PE 进入每层 Q/K 或
注意力分数，末端分类头没有几何捷径。这不是论文 Point Transformer 的
局部向量注意力复现，不能与其已发表准确率直接做公平方法比较。

所有角色同样接收 XYZ 内容。因此 NoPE 是没有显式注意力 PE，仍然知道坐标。
每个输入点集先按自身中心/RMS 半径归一化，radius floor=1e-6；内容 RMS=1，
PE 坐标乘 12。不使用类别或跨数据集统计。除退化半径情况外，该处理提供
整体平移/正等比缩放不变性，不承诺任意三维旋转不变性。

十个角色各 5 种子 11/22/33/44/55，共 50 次训练：

| 角色 | 改变的显式位置形式 | 新增参数 |
| --- | --- | ---: |
| conditional，固定主方案 | R47 动态完整三维椭球 | 1746 |
| diagonal | 动态对角形状 | 1164 |
| isotropic | 动态各向同性 | 776 |
| static | 每头静态中心和完整形状 | 18 |
| fixed | 固定宽度 4 的高斯 | 0 |
| free_quadratic | 等容量自由二次项，匹配高斯初值及一阶导数 | 1746 |
| rope | 24 个三维球面频率的点 RoPE | 0 |
| fourier | R46 Fourier 坐标映射后接同一 RoPE | 320 |
| mlp | R46 MLP 坐标映射后接同一 RoPE | 448 |
| nope | 无显式注意力 PE | 0 |

GaussianPosition、SpatialMap3D 与球面频率直接复用旧实现。自由二次对照
同时改变正定约束与中心—精度耦合，不把其差值全归因于正定性。简化版
容量不同，等容量控制为 free_quadratic。MLP/Fourier 是明确的坐标映射控制，
不是 Learnable Fourier 或其它论文的完整复现。

非 PE 权重初始化按种子严格一致；所有公共参数先构造，再创建位置模块。
所有高斯角色初始函数相同；Fourier/MLP 初始为相同 RoPE。不声称两类初始
函数相同。数据/增强 RNG 独立，dropout 按种子/步编号设置共同随机流。

## 固定优化与评估

120 epochs，batch32，最后不足一批也使用，每批每物体随机无放回取 512 点。
训练绕 Y 轴均匀旋转、原单位球坐标 jitter σ=.01 截断 ±.05，再进行输入
归一化。AdamW lr=.001、weight_decay=.01，前 5 epochs 线性 warmup，其后
cosine 到 .00001；梯度裁剪 1，训练 label smoothing=.1，无任务专属新损失。
不为某个角色独立调学习率、宽度、坐标尺度或训练预算。

epoch0 及每 5 epochs 验证一次，按未平滑 val CE 最小选模，同值取最早。
验证/开发评估点序列按物体固定盐值哈希生成，每物体用固定 2048 点排列的
前 512。保存逐物体 logits、标签和身份，回算 OA、平均类别准确率 MCA、CE；
报告 5 个配对种子及逐类别结果。类别不是额外独立训练重复。

主开发信号定义：conditional 的平均 OA 相对 rope/fourier/mlp/nope/
free_quadratic **各提高至少 1pp**，每项至少 4/5 种子正向，MCA 每项不下降
超过 .5pp。这个幅度标准用于决定是否值得未使用数据确认，不是数学有效性
的二元定理。报告全部连续差值，小幅收益和取舍不能被阈值抹去，组件结果
不能替代主方案，不能事后将胜出的简化版改名为本轮成功主方案。

预定次要诊断：同一 dev_eval 上固定 Y90°、Rz45°Rx30°、jitter σ=.02 截断
±.1、固定序列前 256/1024 点、反转点顺序。旋转/噪声/密度是鲁棒性描述，
不要求未训练的 SO(3) 不变性。排列应只产生可解释的浮点差异，报告 logits
误差与分类翻转。任何正结果仍需跨任务和未使用确认，不覆盖 R47 匹配失败。

## 适度验证、资源与决定

六项合成 CPU 检查：共同初始化及初始函数、非零参数独立直接公式、平移/
等比缩放/排列、V 与 PE 梯度、分区/采样、独立指标。CUDA 合成 smoke 验证
训练路径并测两个角色固定 batch32/N512 的短步耗时；不据此搜索科学配置。
全部选定模型在第一层 8 查询行/全部 key/两个头用 NumPy 直接公式复核 PE；
全量逐物体 logits 回算指标。这不是第二套完整网络或独立作者复现。

数值误差超过 5e-5 为定位告警，完整训练后的微小告警不自动否决科学收益；
非有限值、数据身份/配对错位和错误选模需修复。保留错误版本和失败记录，
例行运行前修复不制造新科学轮次。禁止旧静态积分求积/CPU 时间要求充当本轮
前置门禁。禁止在看到 dev_eval 后扫温度或改配方追分。

使用实际空闲 GPU，连续两次占用检查后启动，最多 5 个种子分片并行；每
分片 8 GPU 小时上限、16 GiB allocated 上限，空闲队列最多等待一小时。
只停止自身有记录的子进程。float32 主网络，沿用 PE 内部 float64；TF32 关，
确定性算法，CPU 每进程 4 线程。记录时间和显存，不把训练计时当正式吞吐基准。

若整体不胜强对照，停止把该固定三维候选当作通用成功方案；保留组件证据，
以明确病因决定后续简化或换机制。若在此任务胜出，只得到任务条件下的开发
支持，后续仍需验证适用范围、成本及独立确认。目标不随下游任务改写。
