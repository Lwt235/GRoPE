# 官方 TEST 的历史对象复用核对

**官方 GSModel60 TEST 的 6,090 个对象，不能全部称为本研究从未见过的对象。** 按早期实际使用的 PointNet HDF5 逐行对象映射，其中 2,245 个来源对象已进入 R48/R58 的开发流程：1,826 个属于历史 fit、210 个属于 val、209 个属于 dev_eval。虽然当时读取的是点云、现在拟评价的是原生高斯，底层对象身份仍然相同。

其余 3,845 个对象由 2,124 个 MACGS 对象及 1,721 个原 ModelNet TEST 对象组成，在本次已登记历史来源中没有发现对象 ID 重叠；它们仍覆盖全部 60 类，每类 14–100 个。这里只核对 ZIP 内的七份 ID 映射与已保存清单，没有读取原 ModelNet 测试点数组、GSModel60 测试 PLY 或模型得分。“未发现历史来源重叠”不等于证明没有几何近重复。

此前缓存的 ShapeSplat 原 TRAIN 文本清单有 9,842 个 ID，实际 HDF5 TRAIN 映射有 9,840 个；交集为 9,839。三项只在前者、一项只在后者，已完整记入结果。本次以实际使用文件的映射为准；这处差异没有改变 GSModel60 TEST 的 2,245 个重叠数。最初误设两份清单完全相同的检查停止记录及修正前脚本均保留，没有读取新效果数据或重新选择模型。

当前原生模型从 GSModel60 TRAIN 从头训练，与官方 TEST 无精确路径、对象 ID 或文件哈希交集。因此，这不是发现当前模型训练直接读取了官方 TEST，而是补上**研究过程已使用底层对象**的限制。已有开发结果不因此作废。

后续固定模型评价应保留完整 6,090 个对象作为官方基准，同时在读取测试 PLY 和得分前，固定报告“历史复用 2,245”与“无已知历史对象重叠 3,845”两层。不能依据分数挑对象，也不能把全量成绩表述成全新对象确认。当前三卡训练和新种子提案不变，本核对不增加效果通过门槛。
