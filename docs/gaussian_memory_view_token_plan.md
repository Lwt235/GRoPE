# 高斯记忆接入 VGGT 实际视图 token：有限验证

2026-11-10。承接已有写入器和中心读取结果；旧形状项负结果保留。本轮不是继续寻找更有利的协方差公式，也不以渲染指标替代 token 接入。

## 科学问题与可改变的决定

假设：在当前图像缺少一块观测时，来自其他四个参考视图、保存为 256 个高斯的场景状态，能帮助 VGGT 的实际 patch token 接近完整观测时的表示。竞争解释是当前视图中的上下文和额外网络容量已足够，或读取器只是利用场景/位置先验，未提取对应的记忆内容。

以冻结 VGGT 第 23 层输出的 2048 维 frame/global 拼接 patch token 为接入位置。共享的小型残差层以当前 token 和五维像素/射线描述产生 Q，以已保存高斯的特征和相机下几何产生 K，以特征产生 V。四头、宽度 64、一个 cross-attention；加入旧中心位置偏置，再用一个输出映射回 2048 维。输出层零初始化。另有同层局部变换，不增加循环、门控网络或新几何模块。

固定三组：仅当前 token 的残差 MLP（宽度 66，容量略大于记忆组）、中心读取、原样保留的 gsplat 一致高斯形状读取。后两组全部共同输入和参数量相同，只变位置偏置。中心尺度沿用旧训练几何中位数，不重新搜索。此比较不证明高斯形状必要，也不替代直接参考 token memory 等未来强对照。

## 输入、监督与数据边界

- 输入图像 210×280，patch 为 14×14。在 RGB 上遮住 7×10 个连续 patch（70/300，23.33%），填 VGGT 归一化均值；遮挡发生在 DINO 和全部 VGGT 计算之前。不同图像放在 batch 轴，各自 S=1，禁止跨查询全局注意力。
- 完整查询单独前向，仅提供最后一层 token 教师。训练比较逐 token LayerNorm 后的 2048 维表示，隐藏区 MSE 权重 0.8、可见区 0.2。输入端、参考提取和记忆构建均不能读取完整查询教师。目标是教师表示一致性，不是几何真值或图像生成质量。
- 冻结 VGGT、原共享写入器、原训练 PCA 和场景记忆；相机已知。接入层从头学习，不按新结果修改记忆。旧 12 个 fit 片段、72 个查询各四个固定随机矩形；留出查询和六个旧开发场景各两个独立固定矩形。记录图像、记忆、缓存、源码及配置身份。
- 如开发信号明确，在模型固定后使用 R6/R7 的全部 12 个已有场景，每场景第 40–52 个已下载帧组成新片段，四参考、九查询、两矩形。与上轮前 13 帧不重叠；这些场景历史上已评估，必须称新片段迁移确认，不能称全新场景或完全未接触测试集。不按内容或结果换片段。

## 预算、评估和诊断

三组×三个原配对种子，各固定 2,000 步 AdamW（lr=3e-4，wd=.01），每步两例，clip=5；相同样本次序、最后一步评价，不选最佳检查点。每组初始模型等于原始冻结 VGGT token。旧 fit 的查询/遮挡用于训练，开发与新片段不参与训练。

主比较为遮挡区 token MSE；同时检查可见区和完整输入上的扰动。按片段/场景配对，种子不当作新的场景。中心读取三个种子均改善、六场景多数同向并存在合理的记忆依赖时，执行固定新片段迁移；小或混合效果如实说明，不扫描遮挡率、损失或层号寻找正结果。

在相同已训练模型上做移除记忆、交换场景记忆、打乱特征与几何对应、错误相机诊断；这些是有分布偏移的干预，须与训练过的无记忆对照合看。按训练几何固定的投影覆盖分层，明确它只是参考记忆支持度代理，不是实际遮挡可见性的真值。完整输入检查只作保真诊断。

必要正确性检查：零初始化等于原 token；空记忆有限；共同刚体坐标重表达/记忆排列不改变中心读取；被遮区域像素替换不能影响输入 token；教师不参与输入构造；独立命令只凭不完整查询、相机、记忆和适配器运行。实际将修正 token 回填 VGGT 输出列表、送入冻结 depth head，检验可运行和输出变化；深度只作接口示例，不作为本轮主效用结论。

正面结果只支持给定相机、冻结骨干、小规模室内数据下的信息补充；若迁移失败，区分“层可训练/开发有收益”与“可靠适用范围未建立”，结束本轮，不立即堆叠模块。可视化同时展示输入遮挡、完整参考、token 误差与干预反例；最终报告保留全部正负结果。
