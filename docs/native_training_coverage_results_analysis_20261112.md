# 训练覆盖结果分析与下一项建议

**后续状态（2026-11-13）：** 下方形成时提出的native_input_pe1已获授权并完成，主G/P增量0.323%不确定，单次attention候选结束；不改写原覆盖实验或当时建议的历史状态。[完成报告](../results/gaussian_memory/native_input_pe1/report.md)。

2026-11-12。依据已完成的 [native_training_coverage1](../results/gaussian_memory/native_training_coverage1/report.md)。本文为结果解释和下一项设计，未设新目标、未启动训练；上一有限目标保持完成。

## 证据支持到哪一步

**扩大训练覆盖改善了当前场景记忆的迁移表现，但“已训练片段内有效”仍比“未见地点有效”有力；高斯参数作为 PE 的独特收益尚未建立。**

Local 是当前图像 token 加其平均上下文，Render 是当前 token 加按查询相机渲染的保存特征；二者融合容量和接收训练范围相同。以下“空间误差”均为中央缺失 ROI 的 centered log-MSE，下降为好，不代表全部深度指标。

| 比较 | 已完成结果 | 含义 |
| --- | --- | --- |
| 原开发四查询，Render 对 Local | 12 地点训练时高 1.37%；32 地点时低 8.76%，三个种子均有利 | 相对差距有改善；32 地点净收益区间 [−8.42,+21.86]% 仍较宽。 |
| 32 地点 Render 对原 Render | 误差低 12.51% [3.93,23.34]% | Render 自身确实改善，收益不是由 Local 退步制造。 |
| 主覆盖交互 | −0.002239 [−0.005162,−0.0000336] | 覆盖对相对收益有有限正证据；端点接近零，其他查询/合并交互没有相同区间支持。 |
| 开发其他四查询／八查询合并，Render 对 Local | 低 3.64%／6.06%，区间均跨零 | 改善方向保留，不能称所有视角稳定有效。 |
| 原／新增训练片段的未训练视角，Render 对 Local | 低 51.67%／35.25%，相应区间均支持改善 | 用途可迁移到训练片段的其他视角；新增训练地点不是新场景测试。 |
| 完整输入全图 AbsRel，32 地点 Render 对 Local | 高 3.99%，区间跨零 | 尚无整体深度精度优势，不能只报空间项。 |

主开发比较只有 7/12 地点改善，但三个种子都改善，提示地点差异值得重视；这不足以量化每种不确定性的贡献。home_bksh 的约 −0.015% 接近持平，不是要修复的新失败。没有必要要求每个辅助指标或每个地点都获胜。

这些数据是反复用于研究的旧数据。三种子、更多查询和独立评分提高本轮结论的可信度，不会把旧开发结果变成新确认。[固定数表](../results/gaussian_memory/native_training_coverage1/report_tables.md)。

## 可能原因及证据强弱

1. **训练覆盖不足确实是因素之一。** 结构、更新步数和优化规则固定时，扩到 32 地点后 Render 绝对误差和主相对差距都改善。但地点数与样本数同时增加，每个样本重复次数减少；本轮不能隔离纯多样性效应，也不能保证继续扩数据必然有效。
2. **场景特定适应仍是主要竞争解释。** 同片段未训练视角有约 35%–52% 优势，开发地点平均约 4%–9%，与学会利用具体片段布局、内容或其误差模式相容。完整接收网络约 6.37 亿可训练参数、训练仅 32 个短片段，也是有限泛化的可能条件；这不是仅凭参数量就证明过拟合。
3. **改善的一大部分属于普通深度适配。** Local 和 Render 的完整输入 AbsRel 相对各自旧版都低约 29%；原始缺失误差也分别低 27%/36%。两者共享的标定改善不能计为记忆或高斯 PE 收益。本轮特有线索是 Render 相对 Local 的空间差距改善。
4. **保存内容仍可能混合或错位。** [source_geometry_control1](../results/gaussian_memory/source_geometry_control1/report.md)中，传感器来源改善了部分指标，却没有全面改善空间保真与特征重观察。当前仍复用这类状态；几何覆盖不等于对应内容准确。粗高斯与 patch 特征混合可能帮助恢复大布局，同时损失边界，但尚未定位为唯一病因。
5. **当前证据不能区分“有可重投影的内容”与“需要高斯形状 PE”。** 当前 Render 使用真实 alpha 合成特征，再经一次融合进入原生 VGGT，原生 2D RoPE 未变。中心、形状和透明度都参与了渲染，但没有同内容强中心读取比较。因此本轮没有直接检验 O6。早期 [learned_projection_pe1](../results/gaussian_memory/learned_projection_pe1/report.md)已做过同内容 P/S/G，完整投影对中心空间误差高 3.02%；这个阴性不能被本轮渲染收益覆盖。

Local/Render 是两种附加上下文选择，Render 没有另保留 Local 的平均上下文通道；它们不是严格嵌套的“完整 Local 加记忆”。所以目前未建立净收益也不等于来源条件信息为零。

## 首选下一项：一次输入端注意力的匹配 PE 对照

建议登记名 `native_input_pe1`，**仅设计**。主问题：在固定 32 地点和完整原生接收适配条件下，同一保存内容的读取，增加高斯投影信息能否超过强中心关系编码？

主假设：完整高斯的投影范围和合成关系，在可共同适配的单次读取接口中提供中心关系之外的用途。竞争解释是中心与内容足够、平均尺度已足够、当前投影标量遗漏有用关系，或保存内容/接收训练仍限制收益。

**具体接口选择：** 用一个 width256、4-head 的记忆 cross-attention 替换当前输入端 MLP 融合块，残差加在图像编码器的 1024 维 patch token 上，再运行全部原生层及 DPT。只读一次，不同时保留 MLP 融合或原四个内部读取点。Q 来自当前 patch，K/V 来自相同冻结场景特征，注意力 logit 为内容 QK 项加几何偏置；输出投影零初始化。原生位置编码和特殊 token 处理保持。它是拟检验的 C3 选择，不是已经有效的方法。

| 组别 | 注意力内容 | 读取位置偏置 |
| --- | --- | --- |
| L | 当前图像 patch | 无场景几何；同一基础注意力容量 |
| P | 同一保存的 2048×1024 场景内容 | 强中心—射线关系 MLP |
| S | 与 P 相同 | 中心关系＋球形高斯投影贡献 |
| G | 与 P 相同 | 中心关系＋完整高斯投影贡献 |

P/S/G 明确复用旧 learned_projection 的描述，不发明或扫描新核：前七维为原多尺度中心—射线描述；同一 8→16→4 MLP 的第八维分别为 0、log1p(2048×w_sphere)、log1p(2048×w_full)，新增列零初始化。球形仅在读取偏置计算中用 tr(Σ)I/3，中心、opacity、特征及有效槽保持；不重写场景或重新绑定。它改变投影范围和遮挡合成，G/S 不是纯朝向的隔离因果实验。

四组基础读取容量一致；按现有模块公共参数 1,054,464，几何 MLP 另 208 个形式参数。L 不使用几何映射，P 的零输入列少 16 个有效自由度，须如实记录；S/G 的有效容量相同。主 G/P 比较由 S/G 辅助判断，不能把几个无效参数说成完全相同的有效容量。原 Local/Render 六模型仅作实现不同的历史用途与成本参照，不冒充本轮匹配控制。

固定 32 训练/12 开发地点、44 份保存状态、来源 [0,3,6,9]；拟合查询 [2,5,8,11]、其他查询 [1,4,7,10]。四组各三个配对种子、各 2000 步、batch2，共 12 次拟合；同样的原生预训练起点、共同初值、采样、原双优化器学习率和损失，训练全部 frame/global 块及 DPT，编码器/场景冻结。模型从共同预训练起点训练，不能只给 G 继承已有 Render 拟合权重。

主比较 G/P，主指标仍是固定开发原四查询的缺失 ROI centered log-MSE。S/P、G/S 判断平均尺度及完整投影的增量，P/S/G 对 L 判断同接口来源用途。保留训练片段未训练视角、开发其他查询、原始误差与偏差、完整全图 AbsRel、原有支持分层、逐地点差异和成本；各查询组有关联，不能算独立重复。全量为 12×44×8×2=8448 份预测，旧预测另标来源。沿用配对地点/种子区间和最终检查点，不增加新的数值门禁。

**这不是“证明为什么一定需要 3DGS”的全部答案。** P/S/G 的保存内容都已由高斯 alpha 绑定构建；比较隔离的是读取时投影信息的增量，不是移除所有高斯几何、优于所有 PE 家族或优于所有点云记忆。若 G/P 有收益，也不能因本轮同时改变接口和训练条件，唯一归因于原生解冻。

## 结果怎样改变决定

- G 相对 P 有可信且有实际大小的开发收益、同时保留对 L 的用途：保留该输入端 Gaussian PE 候选。若 G 与 S 接近，则优先球形，缩小完整各向异性的主张；若 G/S 也有增量，再支持完整投影关系的必要性。之后固定设计，在真正未用于选型的场景上确认。
- P/S/G 都有用途但 G 无中心增量：保留较简单的读取；此投影 PE 在该实现上没有足够采用理由。公共 3DGS 内容载体和高斯 PE 贡献须分别陈述，不能用载体用途完成 O6。
- 只有训练片段有优势，或所有组仍无开发净用途：保留条件性证据，结束这一固定接法；不自动加数据、延长训练或扫描同一标量。若 G/P 正向但整体比现有 Render 差，也只能支持有限机制线索，尚不替换当前候选。
- 结果不确定：记录效应与范围，有限实验结束。没有“一项微小负值即否决”，也没有“持续加试直到全部通过”。

## 大纲对应与前次区别

已读 [research_current.md](research_current.md)、[大纲对应](research_outline_alignment.md)及上述报告。直接服务 O6，配对 L 同时检验 O4；复用 O2/O3，O5 通过真实投影合成贡献参与读取。核心要求是公共高斯记忆及参数 PE；一次读取、8维描述、32地点、完整接收训练是实验选择。sensor/joint-validity、给定相机/尺度、静态四来源、旧数据仍是临时范围，非纯 RGB、在线或新确认。

[learned_projection_pe1](../results/gaussian_memory/learned_projection_pe1/report.md)在 12 地点、冻结接收、四层内部共享读取上已为阴性；[native_gaussian_pe1](../results/gaussian_memory/native_gaussian_pe1/report.md)与 [coarse_memory_pe1](../results/gaussian_memory/coarse_memory_pe1/report.md)也已有可学习几何比较、空间增量不足。本建议是同一描述在**32地点、完整原生适配、单次输入读取**下的有限复测，改变 C3、重开一个有明示新条件的 C4 比较，沿用当前 C1/C2/C5/C6；不是新的 PE 公式，也不是推翻旧阴性。C3 改动及与既有 Render 的容量差异明确记录，不能叫“当前结构完全不变”。

本轮覆盖证据使这种条件复测值得考虑，但它既不是成功保证，也不是所有 PE 研究的前置门禁。本次只提出该有限建议，当前研究目标仍未达成。
