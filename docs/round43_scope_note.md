# R43：研究对象、已有工作与几何适用范围

2026-11-01。写于已冻结的 R43 训练期间；不改变模型、训练或评估规则。
本轮研究对象是 Transformer 内的位置编码，匹配任务提供效果证据。
没有为渲染器或颜色读出增加模块，也没有打开未使用确认数据。

## 与 3DGS 参数化的关系

借用均值和各向异性协方差的结构，在频率空间定义四组参数：
`w_gm = sigma_g (mu_g + L_g epsilon_gm)`，然后仅用 `w_gm^T x` 旋转 Q/K。
协方差 `sigma_g^2 L_g L_g^T` 可以分解为旋转与轴尺度。它是可学习频率
的协方差，不是输入基元的物理范围，也不是位置估计误差。
这里的均值是频率中心，不是物理空间的高斯中心；没有 opacity、球谐或
增密机制。本轮不能证明把完整 3DGS 渲染表示直接作为 PE 有效。

结构只增加 20 个参数，但“参数少”不等于有用。固定高斯模板排除初始化
优势，自由频率和分组仿射对照排除“只是学习了频率”的解释。
仿射对照包含主方法的有限频率函数族，因此不主张更强的表达能力。
20 个参数约为原 166611 个参数的 0.012%；与自由频率的 48 个参数相比，
整网大小差异极小，不能把它宣传为整个 Transformer 的显著压缩。

与早期幅度衰减的负结果兼容之处是：R43 保留每个旋转块的范数，输入的
物理区域协方差不会压低它。定位坐标仍是原始中心，学习的是频率组织。
这避免了把“物理区域覆盖范围”和“中心对应标签”直接绑成同一监督目标；
它没有证明区域与中心冲突是以前失败的唯一原因，也不保证本轮有效。

## 直接先例

- [Wilson 与 Adams，ICML 2013](https://proceedings.mlr.press/v28/wilson13.html)
  以高斯混合描述谱密度并得到平稳核。“频谱用高斯参数化”本身已有先例。
  [正文第 3 节](https://proceedings.mlr.press/v28/wilson13.pdf)给出谱密度与核的
  Fourier 对应。R43 没有实现其 GP 推断或连续积分，不能冒称完整复现。
- [RoPE for ViT，第 3.2 节](https://arxiv.org/html/2403.13298v2)
  学习混合轴频率。R43 的自由频率角色是同一骨干内的机制对照，未复现该
  工作的全部网络、初始化与训练；不能用本轮排名声称击败完整论文方法。
- [3D Gaussian Point Encoders，WACV 2026](https://openaccess.thecvf.com/content/WACV2026/html/James_3D_Gaussian_Point_Encoders_WACV_2026_paper.html)
  已用学习的空间高斯构造逐点编码。空间高斯基函数与 R43 的频率组是不同
  具体设计。未来若转向空间基函数，需要直接比较这条已有路线。

## 由公式得到的性质及限制

以下是本项目的推导，不是上述论文替 R43 作出的保证。

1. 对每个通道块，旋转不改变内容范数。同一坐标系内给 Q/K 坐标加相同
   平移时，内积只依赖相对相位，平移项抵消。预检已验证这一性质。
2. 坐标改为 `x' = A x + b` 时，若显式把频率改为 `w' = A^{-T} w`，
   相对相位也保持。这不表示保持参数不变就具有尺度或旋转不变性。
3. 将均值和协方差旋转，再通过 Cholesky 重建有限模板，通常不等于
   把每一条频率一起旋转。原因是六个固定点只精确匹配一、二阶矩，
   不具备连续高斯的全部旋转对称性。Cholesky 唯一性解决同一矩阵的
   因子歧义，不自动解决坐标系变化下的有限特征等变性。
4. 连续高斯的特征函数为 `exp(i mu^T delta - delta^T C delta / 2)`。
   有限旋转块没有精确实现该积分；内容 Q/K 对不同通道还有不同权重，
   因而完整注意力也不能直接等同于一个标量高斯谱混合核。

独立于真实数据和训练权重的固定合成例子见
`experiments/round43_frame_diagnostic.py`，结果保存在
`results/round43_frequency/frame_diagnostic.json`。二维和三维各 128 个相对
位移、六点模板，在旋转 0.73 弧度后：

| 检查 | 二维最大差异 | 三维最大差异 |
| --- | ---: | ---: |
| 连续高斯随坐标变换 | 3.10e-16 | 2.79e-16 |
| 显式变换有限频率 | 3.18e-16 | 3.86e-16 |
| 仅变换矩后 Cholesky 重建有限频率 | 0.7697 | 0.8568 |

最后一行是复数平均相位的绝对差，不是 PCK 降幅、训练失败或浮点瑕疵。
重建的均值/协方差仍匹配到约 1e-16。这给出“矩匹配就保证有限 PE 旋转
等变”的反例；没有用反例调节模板、带宽或训练。

## 后续证据应该回答什么

完成本轮固定比较后，再根据结果决定是否值得进行真正三维 Transformer
任务和尺度、噪声、坐标系变化的任务验证。这些验证比较所有强对照，
不要求只有主方法满足一个其他编码也不具备的性质。
既有静态积分、区域概率校准、渲染的结果保留其原范围；本轮不主张
已经通过这些检查，也不把它们自动变成所有 PE 的串行前置条件。
跨任务收益、效率、适用几何性质及未使用数据的最终确认仍然缺失。

与 [R38 时期的六项验证索引](research_gate_map_20261101.md) 的对应如下，
用于限定结论范围，不把旧失败改写成通过：

| 旧索引 | R43 的对应及未完成项 |
| --- | --- |
| 1：静态区域积分及独立求积 | R43 不输出区域概率，不能继承或宣称通过该门；实际旋转算子的数值检查使用独立复数公式。若以后重新主张区域概率，恢复相应概率验证。 |
| 2：多尺度区域与中心交集 | 本轮完整保留中心匹配人口并报告 PCK4/8、EPE；没有完成区域 KL 或多尺度保护，不能声称解决区域/中心冲突。 |
| 3：扰动与完整成本 | 仍需同输入扰动下的任务鲁棒性及整网前后向成本；静态求积的 CPU 耗时比例不能替代 Transformer 成本比较。 |
| 4：learned Q/K 与 V | 本轮直接在两层 Transformer 内训练 PE，并导出零 V 对照；这不等于通过原 R12 深度合同，跨任务效用仍待验证。 |
| 5：真实 GS/RGB | R41/R42 的失败保留；R43 没有检验物理 R/S 或 RGB 改善。渲染可作为转移任务，物理形状利用的主张仍需单独实证。 |
| 6：未使用数据联合确认 | 仍为最终要求。当前五个 old_eval 场景已使用，不可当确认集。最后需针对最终模型和实际主张预先冻结完整联合合同；不能借旧区域/深度合同冒充对新任务的确认。 |
