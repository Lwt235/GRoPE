# 实际视图 token 的信息补充与观测保真：固定 A/B/C 实验

2026-11-10。用户已授权设为目标并执行。承接 view_token1：中心读取迁移遮挡误差 −1.94%，可见误差 +4.33%、全图 +1.78%。本轮判断已有精炼接法能否兼顾补缺和保真，保留此前所有正负结果。

## 假设、竞争解释和固定比较

假设：原先每个遮挡 patch 约为可见 patch 13.1 倍的训练权重，使残差读取偏向修复缺失、容忍对已有信息的扰动；均匀监督和独立完整观测约束能改善这一取舍，同时保留记忆的额外信息。

竞争解释：额外记忆本身不够准确、当前层的 token 不适合此读取，或收益只来自允许更大改写的取舍；保真训练也可能同样帮助无记忆网络，而无法保住记忆增量。一次训练目标控制不能唯一归因到所有潜在病因。

保持冻结 VGGT、原写入器/PCA、256 个高斯、实际最后一层 token、中心读取和已有全部模型结构。Local 277,202 参数，Center 273,604 参数，不增加门控或形状模块。

- **A：** 原 `0.8 E_hidden + 0.2 E_visible`，复用 Local/Center × 三个种子的六个已有模型。
- **B：** 遮挡输入的全部 300 个 patch 等权，`L_B = E_all(masked)`。
- **C：** `L_C = E_all(masked) + E_all(clean)`，完整输入经适配器后以原完整 token 为恒等目标，系数固定为 1。完整输入是独立样例，绝不替换遮挡分支输入、不进入记忆构建。

每种新训练目标都配对 Local/Center，各三个原种子 20261110/11/12，共 12 次新增训练。B/C 从 A 的对应 initial.pt 精确初始化，各 2,000 步、两例遮挡样本、AdamW 3e-4/wd .01、clip 5，完全相同的遮挡采样序列。C 每步多处理同两查询的完整 token，保留遮挡样本暴露和优化步数，额外适配器前后向次数和耗时单列；不声称计算量完全相同。完整 token 缓存已存在，不需再运行完整 VGGT 提取训练特征。

## 数据和实验顺序

复用 view_token1 的 12 个训练片段/72 查询/288 遮挡样本，及 18 片段中的留出视角、六个旧开发场景。上一轮 12 个已用迁移片段只作历史证据，不改称新确认。

训练前从已有 R6/R7 元数据固定全部 12 个场景第 80–92 个已下载帧（零基序号）为下一批片段，引用完整 RGB 原始索引与外参。每片段参考 [0,4,8,12]，其余九查询、每查询两个固定 7×10 patch 矩形。与首轮 0–12、上一轮 40–52 的图像路径不重叠；已检查每场景至少 96 个现有帧。它们是历史场景的新片段，仍不是全新场景。

先完成全部 12 次训练和开发评分，再固定六个 A 与十二个 B/C 检查点，一起执行一次新片段迁移。新片段在固定模型后才解码/提取/评分；不依开发分数淘汰组，不按确认结果修改权重、换种子或选择检查点。B/C 都保留在完整结果表中。

查询 RGB 先在像素层遮挡，再独立 S=1 冻结 VGGT 前向；各查询在 batch 轴而非多视图轴。完整 token 仅作监督或 C 的独立完整样例。新片段记忆仅由四个参考图像经冻结原写入器产生；相机仍已知。

## 指标、干预和决定

同时报告遮挡区、可见区、全图（按真实 70/230 patch 数）MSE，以及完整输入的归一化 token 改变量。主效用是同训练条件下 Center 相对 Local 的遮挡与全图净收益；B−A、C−B 解释监督分配和完整输入约束的影响。每组全部种子与逐场景结果保留；场景内平均配对种子，场景 bootstrap 仅用于表明不确定性，不以极小数值差异制造新门禁。

Center 做正常/移除/交换/打乱特征空间对应/错误相机干预，与训练过的 Local 对照合看。需避免把接入层学成接近恒等就称成功：完整输入扰动减少只有在遮挡收益和记忆依赖仍存在时才有价值。干预存在分布偏移，不能单独证明记忆贡献大小。

若 B 或 C 保留可重复的遮挡增益、全图净收益和明显改善的保真，保留最简有证据支持的训练方案，提出同预算点记忆/直接参考 token 记忆对照。若额外收益消失、只是所有组同样改善、或保真代价仍存在，收窄当前用途并结束本轮权重调整。没有依据扫描损失系数或立即叠加模块。高斯形状必要性、几何精度、未知相机和长期记忆均不由本轮建立。
