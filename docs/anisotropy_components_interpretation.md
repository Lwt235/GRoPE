# 四组关系检验的解释补充：平均精度与方向残差

2026-11-07。在 M/S 原生训练仍进行、尚未导出本轮开发预测时补充。本文展开[固定计划](anisotropy_components_plan.md)中“朝向与轴比共同改变”的限制，不修改模型、比较、选模或判定规则，也不启动下一组训练。

**四组实验能判断两组关系的实际用途，但不能单独将收益归因于相对朝向。** 保迹球形还改变了平均精度（逆协方差的平均特征值）。需要区分“哪组输入有用”和“该组输入中的哪种几何信息有用”。

## 一个精确分解

对当前流水线中已经包含 floor 的正定协方差定义

\[
r_i=\operatorname{tr}(\Sigma_i)/3,\quad
h_i=\operatorname{tr}(\Sigma_i^{-1})/3,\quad
B_i=\Sigma_i^{-1}-h_iI,\quad C_i=\Sigma_i-r_iI.
\]

其中 B、C 均无迹。对 \(\delta=\mu_i-\mu_j\)、\(d^2=\delta^\top\delta\)，有

\[
m_i^F=h_id^2+\delta^\top B_i\delta,\qquad
t_{ij}^F=3h_ir_j+\operatorname{tr}(B_iC_j).
\]

而当前 trace 球形控制是 \(m_i^T=d^2/r_i\)、\(t_{ij}^T=3r_j/r_i\)。因此

\[
m_i^F-m_i^T=(h_i-1/r_i)d^2+\delta^\top B_i\delta,
\]
\[
t_{ij}^F-t_{ij}^T=3r_j(h_i-1/r_i)+\operatorname{tr}(B_iC_j).
\]

交换 i、j 得到另两个槽位。第一部分不依赖方向，第二部分包含位移与主轴或两端主轴的相对关系；两部分也都受特征值影响，不能把残差称为纯朝向量。

令 \(p_i=r_ih_i=(\sum_k\lambda_{ik})(\sum_k1/\lambda_{ik})/9\)。由 Cauchy–Schwarz，\(p_i\ge1\)，仅球形时取等。它在整体缩放协方差时不变，却随谱的离散程度变化。因此 trace 球形去掉的不仅是朝向，还包括这个与轴比有关、方向无关的因子。

固定 d、对位移方向作球面均匀平均时，\(E[\delta^\top B_i\delta]=0\)；固定谱、对 j 的朝向作均匀独立旋转平均时，\(E[\operatorname{tr}(B_iC_j)]=0\)。实际数据不满足这种随机方向假设的保证，不能直接用这些期望替代任务分数。

## 一个无需训练的反例

取 \(\Sigma_i=\operatorname{diag}(1/4,1,4)\)、\(\Sigma_j=I\)。此时 \(r_i=h_i=1.75\)、\(p_i=3.0625\)。完整形状槽位 \(t_{ij}^F=5.25\)，而 trace 控制只有 \(t_{ij}^T=12/7\approx1.7143\)。任意旋转 i 都不改变这两个数，因为 j 是球形。两者的差已经存在，完全不需要两椭球的相对朝向变化。

位移槽位也有同类区别：单位位移在三个主轴上的完整值为 4、1、0.25，均值 1.75；trace 控制在各方向都是 4/7。完整值既可能大于控制，也可能小于控制，不能将方向残差理解为一律增大的加权。

## 对本轮结果的含义

- M−T 或 S−T 的正结果支持对应关系组的用途；竞争解释仍包括平均精度/谱信息、方向残差以及学习中的数值表示作用。它们不能自动证明相对朝向是主要收益来源。
- F−M−S+T 是重新训练后、特定指标上的成绩交互。M、S 都可能包含上述方向无关因子，加上 log1p、MLP 和非线性指标，不能将它解释为两种独立物理机制的信息比例。
- 本轮仍按原计划决定保留完整五维或优先研究某个简化版本。若后续确需区分谱与方向，可先考虑保持平均精度的方向中性表达 \(m_i^0=h_id^2,t_{ij}^0=3h_ir_j\)。这只是代数上的竞争解释，**不是已选方案、已验证改进或新增必过门禁**；是否需要训练取决于本轮完整结果及要支持的实际主张。

上述方向中性表达同时使用 r、h，一般无法由同一个球形协方差同时保留两者。因此不能将其称为“精度和大小均匹配的真实球形基元”。分解是在 log1p 之前成立，网络输出和准确率没有相同的加法分解。
