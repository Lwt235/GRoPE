# 多视图上下文监督：先检验参考信息与显式空间读取的用途

2026-11-10。用户要求明确下一步、设为目标并执行。本轮是有边界的开发实验：新增九次固定训练，复用上一轮六模型作历史诊断，不根据中途结果追加模型或追逐小幅均值差异。

## 科学问题

上一轮S1参考编码解决了S4读取器的大部分性能损失，但相对同容量Wide只有0.46%的不确定平均收益。原监督是恢复冻结VGGT的独立单视图表示，不直接要求保留其他观测带来的信息。

本轮假设：把目标改为“当前完整查询与四参考共同编码后，查询位置上的表示”，能让参考信息在未训练场景上产生额外用途。第二个问题是：保留完整参考内容时，显式空间位置项是否比内容读取更有帮助。竞争解释包括教师只引入序列长度/特殊token角色变化、额外内容只提供全局外观、当前残差结构无法实现上下文转换，或有限数据/优化预算限制。不能仅因目标来自多视图就声称已得到共同三维几何监督。

## 教师与信息边界

冻结现有VGGT，分别对每个查询运行长度5序列 `[完整查询, 参考0, 参考4, 参考8, 参考12]`，只取第0视图最后层的300×2048 patch tokens作为目标。查询排在首位，与旧S1查询的首视图特殊token角色一致。每个查询独立生成目标，不把其他训练或留出查询放入序列。教师可以使用完整查询，仅提供监督；学生仍只得到旧的遮挡查询S1输入与仅由参考构造的S1记忆。

预先加入同长度控制 `[完整查询, 完整查询, 完整查询, 完整查询, 完整查询]`。它用于测量真实参考引起的教师变化，排除仅比较S=1/S=5带来的解释混杂；该控制含完整查询，是诊断参照，不能当作可部署学生或误差下界。真实教师与此控制都只离线生成监督缓存，不用于参考特征、几何、学生Q/K/V或初始化。

原46片段的S1参考状态完全复用，来源、几何、掩码与缓存身份固定；不下载新数据、不重新估计几何。已知相机条件保留。

## 三个固定组别

1. Wide：容量匹配的无记忆MLP，530,548参数。
2. Content：保留1200×2048全部S1参考特征，同一cross-attention，关闭key中的十个显式几何通道与中心距离惩罚。仍与Spatial共享查询射线和相机有效槽/透明度过滤，因此是“内容读取＋共同有效性”对照，不声称完全不含空间信息。原图像token本身也可能携带位置信息。名义参数531,652，其中644个几何相关参数不影响输出，有效参数531,008，与Wide接近。
3. Spatial：上一轮同一中心读取结构，531,652参数；使用完整参考几何key与中心距离位置项。

三组各三个种子20261110/11/12，均从上一轮对应的完整初始权重开始；Content与Spatial逐值相同，Wide复用其原初值。全部使用同一12场景×1片段、72训练查询、288遮挡样例、2000步采样顺序，batch2、AdamW 3e-4/wd .01、clip5、全patch归一化MSE。仅监督目标改为多视图上下文目标，结构不增层，不扫权重/位置尺度/训练步数，固定最终模型。

上一轮S1目标训练的Wide与Spatial六模型也在新目标上评分，作为目标变化诊断，不假称与新任务训练的对照预算完全相同。主结论必须来自同一新目标下重新训练的三组。

## 评价与干预

主评价沿用与训练按地点和帧隔离的十二地点、40–52/80–92两片段；先同地点平均，再十二地点等权。全部46片段分原组别报告，不把已转训练的旧开发场景称未训练数据。本轮没有新的独立确认。

主比较：Spatial对Wide（额外参考用途）和Spatial对Content（显式空间组织增量）；同时报告Content对Wide。主指标为全patch归一化MSE，附遮挡、可见、完整查询输入下的同一上下文目标MSE及逐种子/地点方向、配对场景×种子区间。新任务的完整输入预期需要改变，不能再把对原S1输出的零偏离当成目标；原S1误差仅作为行为变化记录。不同目标的原始MSE不直接横向排优劣。

Content/Spatial均测试移除记忆和空间打乱。打乱按每个查询，在每张参考图的当前有效槽内置换内容，保留有效内容集合、几何及有效性；两组用同一置换，Content应在数值精度内对该置换不敏感。这避免把改变可用特征集合误当作空间绑定效应。干预仍是分布扰动，不代替重新训练的Wide/Content强对照，也不证明协方差的独有价值。

教师诊断报告真实参考/重复查询/S1目标的归一化距离，含空间去均值后的教师变化，判断参考是否只改变全局偏置；只作描述，不用评价结果选阈值、目标分量或新结构。生成固定首查询热图，实际审阅训练留出、主评价正反例及总览。

## 不同结果改变什么

- Spatial可靠优于Wide和Content，且正确绑定有作用：支持把此上下文目标用于后续紧凑共享高斯记忆的联合写入/读取；本轮自身不证明高斯压缩、可学习几何或真实三维输出提升。
- Content和/或Spatial优于Wide，但Spatial没有稳定超过Content：支持额外参考内容，不主张显式空间PE必要；后续压缩应保留强内容对照。
- 两种记忆均未可靠超过Wide：结束此固定多视图token蒸馏候选，不再添加温度/层/损失组合补救，重新讨论任务监督与直接共同场景输出；不宣布所有共享记忆不可行。
- 教师主要受序列或全局偏置影响：明确该目标的解释局限，不能把较低蒸馏误差包装成空间记忆证据。

本目标包括完整训练、评价、适度核对、实际图像审阅、分析报告与研究入口更新；后续联合高斯写入训练不在这一轮自动启动。

## 实现与资源

保留输入、教师、源码和模型身份。检查查询不进入参考状态、教师每序列只含一查询、首视图角色固定、初值/采样配对、有限训练、Content置换不变性、Spatial原模型兼容、独立MSE复算。普通运行问题记录失败并修复，不为小数值差建立额外科研轮次。
