# native_covariance_role1：固定 Render 的固有形状条件用途

2026-11-13，round_004。状态：事前有限开发诊断，尚未实施。对应[分析](../results/gaussian_memory/autonomous_research_loop/round_004/analysis.md)及[机器计划](../results/gaussian_memory/autonomous_research_loop/round_004/plan.json)。下一实现者为**待主建立的 Sol/High/Fast CLI 任务，实际 UUID 待填**；由主任务在 Astra 本阶段结束后顺序派发。

## 1. 问题、范围与历史区别

结束 `native_memory_context_pe1` 的单层局部关系 writer PE 自动变体，不补层、宽度、种子、步数或数据。它没有形成开发空间 PE 增量；共同 writer 的均值线索与训练片段用途保留。完整公共 GS 记忆＋可靠参数 PE 目标仍未达成。

下一问题是：**原 Render 已有的条件用途，是否依赖原固有非球形支撑中超出中心邻域结构、每基元大小及最薄轴尺度的信息？** 若该信息在实际读取中也没有可辨识的实用支持，就没有理由继续在同一固定场上换 PE 接口；若有支持，才保留“将有效局部合成显式写成匹配 attention PE”的后续设计理由。本轮本身不加 Transformer、没有新 PE 候选，不验证 O6 增量。

竞争解释：中心集合结构和共享尺度已足够；主要变化是覆盖/输入幅度；原形状与绑定内容/已训练接收器共同适应导致分布敏感；只有片段内或标定收益；源形状是粗拟合支撑而非真实表面。固定权重干预只能量化此配置对输入变化的条件依赖，不能证明从头训练的中心方法更差，不能唯一诊断过去 PE 失败。

与历史的实质区别：`native_render_factorization1` 换局部内容为全局摘要并改变覆盖，未比较两种局部几何；本轮保留局部组成，并单独匹配原有效覆盖。`source_geometry_control1` 改来源质量后重拟合/绑定，未隔离读时固有协方差。`native_gaussian_pe1`、`coarse_memory_pe1`、`learned_projection_pe1` 及最近两轮 P/S/G 均共享完整原场/内容，其形状 PE 控制没有移除载体中的完整形状。旧 `bound_read1`/`soft_read1` 与单次输入 PE 的阴性继续有效，任何阳性也不自动重开这些候选。

`surface1` 的恢复初始几何干预已表明固定模型依赖不等于重训比较；`geometry_transport1` 的 Latent G/C raw 正线索主要伴随均值偏差下降，空间项略差，显式中心深度传递未形成预测几何方案。本轮不重复该粗头/显式深度路线，也不以渲染支撑损失证明几何更准确。

大纲核对：直接检查 O4/O5、只读复用 O2/O3，为 O6 的下一设计或适用范围提供条件证据；不是把载体几何用途改称 PE 成功。O1 图像 token 解释不变。C1/C2/C5/C6 保持原保存场、绑定内容、给定相机及已有权重；C3 仅作四种评价输入，C4 无新增 PE。32/12 旧地点、sensor/joint-validity、静态四来源、给定相机尺度、深度任务、2048 槽/1024 维均是临时实现范围，不升级为核心要求。

## 2. 固定数据、模型与四种输入

复用 `native_training_coverage1/plan.json` 与 `configuration_lock.json` 的 44 场景、原始内容和三份 **Render** 最终权重，种子 20261110/11/12，全部保持 eval/frozen；不使用新 writer 权重。来源帧 0/3/6/9。训练 32 地点只评价其他 query 1/4/7/10；开发 12 地点评价原 query 2/5/8/11；两种 full/missing。每组 44×4×2×3=1056 预测。只读继承同 cohort 的旧 Render/Local 共 2112 条评分。目录 confirm 不代表 fresh；全部地点和 query 已用，无新确认。

设原协方差为 Σ_i=R_i diag(s_i²) R_iᵀ，t_i=Σ_j s_ij²，m_i=min_j s_ij²>0。在保存场坐标中，用**全部保存中心**的 self＋31 个最近中心（N<32 时取全部；平方距离/原 index 稳定排序），计算邻域均值和 FP64 散布 B_i=(1/K)Σ_j(p_j−p̄_i)(p_j−p̄_i)ᵀ。设 D_i=B_i−λ_min(B_i)I。若 tr(D_i)>0，定义

`Σ_C,i = m_i I + (t_i − 3m_i) D_i / tr(D_i)`；否则定义 `Σ_C,i = (t_i/3)I`。

非退化时中心替代 C 与原场具有相同 trace、相同最小特征值；方向及另两轴的相对分配仅由中心集合产生。退化各向同性邻域没有可选方向，固定回退同迹球形并记录数量，不另扫正则项。S 为 `Σ_S,i=(t_i/3)I`。C 得到原每基元大小和最薄轴这一**额外优待**，不能叫“只给中心的纯消融”；本轮仅问剩余非球形支撑的增量。所有组的中心、opacity、has_content、FP16 内容、unit 及 query camera 不变，不重新绑定。C/S 仅改变传给 renderer 的 scale/rotation，原源文件不覆盖。用 FP64 eigendecomposition 转换为合法 scale/WXYZ rotation，协方差等价的符号选择不构成方法差异。

使用原 gsplat 参数和 32×32 网格，三个几何场 X∈{F,C,S} 由同一路径渲染 `colors=[f·has_content, has_content]`，得到 FP32 未归一化内容 r_X 和**有效内容覆盖** a_X（包括原遮挡合成）。不用总 alpha 替代有效 alpha。对 a_X>0，n_X=r_X/a_X（FP64 除法再转 FP32，不加 epsilon/阈值）；a_X=0 时，n_X 为距离该 patch 中心最近的正相机深度、有效内容中心的原 f，距离在投影平面度量、并列按原 index。若没有该中心，取全部有效 f 均值；无有效 f 则零。零覆盖及回退均保留、计数，不能筛掉不利 query。a_F=0 的匹配输入固定为零。

| 组 | 传入原融合层的内容 | 用途 |
| --- | --- | --- |
| F | r_F，原完整形状重新走本轮相同渲染路径 | 固定权重事实基线 |
| C_raw | r_C | 中心结构替代的总输入变化 |
| C_match | a_F n_C | 同原有效覆盖下的中心结构局部组成 |
| S_match | a_F n_S | 同原有效覆盖下的同迹球形组成 |

**同内容与覆盖的含义有限而明确：** C_match/S_match 与 F 共享原 a_F、原 f 和接收器；原 f 的绑定、a_F 本身仍含完整形状信息。改变的局部组成正是被干预量；既不是把完整形状从系统删除，也不是纯方向旋转实验。归一化后不另作整体范数匹配。空支持回退属于固定中心规则，报告其像素比例和原 a_F 质量占比，并列出相关 query，不能把回退损失唯一归为形状信息。

上轮发现旧缓存 r 与实际 renderer 有微小浮点路径差，并可经 BF16 放大。因此本轮必须产生 **1056 条新 F 预测**作为三种干预的共同基线；旧 R 仅作继承参考。报告 F−旧 R，不要求 native 输出逐值相等，不再套 1e−4 输出门槛。

## 3. 终点与决定分支

主范围：12 开发地点原 query、missing ROI centered log-MSE。主比较 `D_center=E(C_match)−E(F)`；固定配套 `D_sphere=E(S_match)−E(F)`、`D_mass=E(C_raw)−E(C_match)`、`D_total=E(C_raw)−E(F)`。D_total=D_center+D_mass 是同一误差量的算术恒等式，不是已识别的独立因果份额。同时给绝对差及 `(E(X)/E(F)−1)×100%`；D_mass 用 C_match 作百分比分母。地点/query 等权，沿用 5000 次配对地点/种子 bootstrap，seed 20261113。

训练 32 地点其他 query 是预定条件用途范围，分旧 12/新增 20 地点报告；不替换开发主量。全部 raw log-MSE、bias²、full ROI spatial/full whole AbsRel、原支持分层、seed/place/query、旧 Local 净用途、零覆盖与回退反例一并输出。原 source 支持掩码固定，不能按新几何覆盖重定义主样本。

“明确实用依赖”仅用于后续工作排序：相对 F 误差均值增加≥1%、配对 95% 下界>0 且三种子同为正。该幅度沿用前轮开发的实用量级；小均值负或区间跨零不叫等价，不因微小不确定波动否决总体目标。固定分支：

1. **开发 C_match 与 S_match 都有明确实用代价：** 原固有支撑在这个已训练读取系统中有超出强中心结构＋共享尺度的条件信息。仅保留一个后续设计问题：能否在保持原 1024 维值、局部合成及原覆盖的初始化行为下，把该信息进入 attention 的 PE；不得据此采用方法、宣布 O6 或直接启动训练。区别旧低维冻结 bound/soft 及全场景输入替换的实质条件，须由下次有限分析说明，不能把阳性当旧失败已被推翻。
2. **仅 S_match 有代价，而 C_match 没有上述支持：** 非球形支撑可能有用，但中心结构＋共享尺度尚足以解释；结束当前固定场上固有协方差 PE 的自动接口修补，不宣称纯中心与原场等效。
3. **C_raw 有代价而覆盖匹配的 C/S 没有支持：** 保留覆盖/幅度敏感，不据此主张非球形组成 PE；结束该固定场的形状 PE 修补。其他混合方向同样完整报告，不作唯一分解归因。
4. **只有训练片段正线索，或两匹配控制皆无实用支持/不确定：** 收窄条件范围并结束此诊断及同场 PE 接口轮换；不补 seed/邻域/温度/尺度扫描。总体目标未成功，未来须有不同的实质问题或状态证据，不能用“再换一个接口”自动续接。
5. **C_match 实用优于 F：** 记录中心结构可能更合适的载体线索，仍按本轮结束；这不是 Gaussian PE 正结果，也不是可直接采用的中心方法。将来若做载体简化，须另有同训练比较和独立确认，不在本预算追加。

原图完整输出有代价、回退集中或新 F 与旧 R 存在变化时，明确限制上述解释；不建立事后筛样本/追加扫描规则。无论哪一分支，都结束本次四组诊断。没有从固定权重干预直接进入 fresh 确认的分支；只有以后形成匹配训练的合格 PE 候选，才先审全历史并锁定真正未用数据。

## 4. 固定预算、实际准入与必要交付

0 训练、0 optimizer 更新/拟合/pilot 更新、0 source 重建/下载/新模型权重。4224 正式新预测＋2112 继承评分；native 总前向硬上限 4272（正式 4224、最多16预检、32普通失败恢复余量）。两个训练场景、四组一次共8前向足以做预检，其余是上限而非任务。三种几何×176 query=528 个内容/有效覆盖输入缓存；原矩阵若可复用须说明同一路径，不能给某组单独换算术。独立 gsplat 准备调用上限 600，包含预检/失败，不另跑 GPU 成本扫描。

GPU 总≤1 worker 小时（所有准备、加载、推理、预检/失败/恢复均计入），最多2 worker、最多1张存在外部作业的共享卡。首次单进程 cap 8GiB、准入 free≥12GiB、运行可用边距4GiB；只在完全空闲卡允许 cap10GiB/free≥14GiB。启动前由 Sol 实查 GPU 占用、CUDA和盘空间，保护他人进程；上轮峰值约5.2GiB仅作估计，不能代替实查。本分析未调用 GPU。

新增数据盘硬限4GiB、项目盘1GiB，含临时文件和普通失败版本。预计3类 FP32 内容缓存约2.063GiB、4224 深度输出约0.70GiB、几何/覆盖/指标与原子暂存<0.5GiB；不复制旧模型。分析时 `df -BG` 数据盘约352GiB、项目盘16GiB，是时点快照。启动时预计峰值后余量 H≥8GiB，项目预计完成后≥8GiB；H=实时 free−尚未物化的固定产物−真实同时暂存，已写产物不重复扣除。每30s及大写入前记账；H<6GiB 或实际 free<5GiB 安全退出；仅 H<8GiB 时把30s无解释下降≥0.5GiB另作触发，充裕时外部正常写入只记账。工程余量可另作明确附录调整，科学条件和硬预算不随意扩大。
