# R53：射线局部坐标改善定位，高斯形状额外收益仍弱

2026-11-02。按原冻结协议完成18次新训练、12个明确复用的参考模型、60组

## 结果与解释

相机参考是R52的PRoPE式适配，仍接收RGB。下表为五个旧开发场景等权、
再对三个配对种子取均值。连续误差来自匹配概率的坐标期望。

| MLP | 43.113 | 79.331 | 6.1923 | 6.852 |
| 预测式HRoPE适配 | 43.938 | 80.758 | 5.9931 | 6.728 |
| PRoPE式参考 | 50.484 | 87.841 | 4.2069 | 3.173 |
| 仅相机位姿，全头 | 46.996 | 84.818 | 4.8210 | 3.959 |
| 射线点，全头 | **51.251** | **88.398** | 4.0813 | 3.169 |
| 射线各向同性，全头 | 51.042 | 88.234 | 4.1042 | 3.311 |
| 射线完整高斯，全头，主方案 | 51.057 | 88.291 | **4.0611** | **3.068** |
| 射线一般仿射，全头 | 50.997 | 88.209 | 4.0635 | 3.122 |
| 射线完整高斯＋半头2D旋转 | 50.947 | 87.984 | 4.1675 | 3.342 |

主方案相对PRoPE式参考的连续误差下降0.1457px（3.464%），PCK8提高0.449pp，
两个指标三个种子均改善。连续误差五场景均改善，但其中两场景仅0.004/0.006px，
主要收益集中在hotel场景（0.510px）。这是有限开发收益，不是普适性证明。

射线点模型已经达到4.0813px，接近完整高斯；后者只再降低0.0201px，三个
种子仅2个、五场景仅2个更好，PCK8反而降低0.107pp。与一般仿射只差
0.00236px，与各向同性差0.0431px且种子方向不一致。把这些视为弱信号/近似
持平；没有理由将其放大为数值失败，也没有证据宣称完整Gaussian特有优势。

仅位姿控制与PRoPE参考还同时改变了内参和旋转通道，不能据二者差异单独
归因于内参。相对R52，本轮同时改变射线锚定、框架顺序、形状参数化和通道
分配；跨轮进步不能单独归因于逆框架或白化。固定的半头旋转混合控制没有
成为更好的方案，其尾部也更差；不事后切换主方案。
