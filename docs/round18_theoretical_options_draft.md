# Round18 条件备用方向：同一空间测度能增加什么

2026-10-30。**未选择、未冻结的理论草稿，不是实验协议。** 当前 R17 旧 VAL
已冻结并执行前向；本稿没有读取其输入、标签、预测、指标或科学结论，没有
修改生产实现，也没有运行新合成或真实实验。推导使用已知 R13–R16 机制和
已接受的旧 TRAIN 证据。以下反例均为解析构造，不能当作候选的效果结果。

**当前建议是不自动启动任何 R18 实验。** 保留两个有明确适用条件的方向：
固定内容场的空间积分只能修复粗 key 的内容聚合；位置–外观交叉矩可能改变
粗 query 的细粒度匹配，但确实增加输入统计、计算和建模假设。仅凭“同一个
连续密度”或“一个公式”，不足以证明结构精炼、有效或有新颖性。

## 一、现有证据允许什么结论

[R13](round13_target_conflict_report.md) 的 q24→g8 区域真值峰值与中心允许
集合的严格冲突率为 29.7195%，但联合有效 query 的质量加权最小调整
KL 只有 0.00026293。它说明两个目标并非完全一致，却不能将失败解释为
不可避免；这个使用 GT 的最小代价也不是可部署 PE 的性能界限或门槛豁免。

[R16](round16_mechanism_report.md) 中 quartic full 的 h=.25、T0→T5，q8
增加 .714pp、q24 降低 5.991pp；h=.5、q24 的 T0 本来比 nearest-μ 参照
高 1.012pp，T5 却使其降低 7.664pp。支持的是支撑宽度、原生格几何间隔
与内容响应的耦合，不能据此认定均值是主要故障、全部内容都有害，或原生
积分后的几何势具有点密度相同的中心曲率。

已接受的 [R17 TRAIN 报告](round17_regional_report.md) 仍有 q24→g8 相对
quad16 的区域差距；本稿只把它作为已知开发问题，不引用当前 VAL。
R17 的 trace 系数已经针对宽 support 的内容响应作了一个固定、光滑的
耦合。没有新的独立机制证据时，不应再靠更换径向曲线来扫描结果。

两个信息限制先于任何新公式：

1. 同均值、同协方差不能确定区域形状。例如中心为零、协方差为 I 的均匀
   正方形及其 45° 旋转有相同 μ/C，却有不同的原生格质量；它们的旋转
   对称径向闭合完全相同。真实 query 拆并也不能由单一二阶矩一般性闭合。
2. 区域均值和协方差没有记录“哪个源像素是中心”。只保留相同投影点集合
   及 pooled 外观时，交换源像素的对应可保留这些统计而改变中心投影。
   因而 μ/C 与 pooled 外观的确定性算子无法在所有这样的输入上同时恢复
   区域分布和指定中心。这是信息反例，不声称每种交换都由同一光滑场景实现。

后续仍须用**同一个原生概率分布及原生 argmax**满足区域和定位要求，不引入
GT anchor，不借强 point 的 winner 投影来保证 PCK，不拆成两个偷偷独立的
readout。支撑 C 仍表示区域的空间散布，不是中心误差的 confidence。

## 二、不建议自动推进：同中心尺度混合或新径向 profile

令 S=C+h²I。一个矩守恒的两尺度构造为

\[
 \rho_w(x)=w\,\mathcal N(x;\mu,h^2I)
 +(1-w)\,\mathcal N\!\left(x;\mu,h^2I+\frac{C}{1-w}\right),
 \qquad 0<w<1.
\]

它的均值为 μ、协方差为 S，C=0 时回退原 point。两分量都在 μ 取得最大
密度，所以未加内容的连续 mode 也是 μ。但它的 native mass **恰好就是
point 和更宽 full Gaussian mass 的固定凸组合**。写成单密度不改变这一
等价性；w 是新增的形状假设，第二次积分也是实际成本。为补偿窄分量，宽
分量必须把 C 放大为 C/(1−w)，无法免费增加中心质量。

记 D=h²I+C/(1−w)，中心处窄分量的责任权重为

\[
 a_0=\frac{w/\sqrt{\det(h^2I)}}
 {w/\sqrt{\det(h^2I)}+(1-w)/\sqrt{\det D}}\ge w.
\]

中心负 log-Hessian 是
`H₀=a₀ h⁻²I+(1−a₀)D⁻¹ ⪰ (w/h²)I`。因此弱线性内容 `Tgᵀ(x−μ)`
对中心附近 mode 的一阶位移不超过 `Th²||g||/w`。这是**局部微扰界**，
不是 point 的同常数上界，也不是全局 mode 或 cell argmax 的界。远处
宽分量主导，较强的内容仍可能移走全局赢家；增加窄峰也可能损害中间区域
的概率质量。此构造没有解决真实中心与区域均值不同的信息问题。

更一般地，`ρ=∫N(μ,tS)dH(t)` 在 `E_H[t]=1` 时保持协方差；H 是额外的
径向形状分布。它是已有 Gaussian scale mixture，而非从 GS 参数唯一
导出的形状。[固定 Student-t 的备用审查](round15_student_t_reserve.md)
已经给出尖中心、重尾不统一改善区域质量的反例。固定二次–四次势虽然有
非零中心曲率，也仍需新的密度假设与积分成本；其局部位移继续依赖 S。
以上均不进入本稿的两个建议方向，也不增加 w、自由度或 shape 参数搜索。

## 三、方向 1：固定内容场，在同一测度内先乘再积分

这是**仅修复 key 聚合语义**的候选，不是 q24→g8 的修复方案。
固定 query i 的 μ、S、τ，以及一个与最终 key 划分无关的内容场 cᵢ(x)，定义

\[
 r_i(x)=\bigl[\mathcal N(x;\mu_i,S_i)+\epsilon\bigr]
          e^{\tau_i c_i(x)},\qquad
 P_i(B)=\frac{\int_B r_i(x)\,dx}{\int_{\mathrm{FOV}}r_i(x)\,dx}.
\]

这里 ε 是同一面积 floor 的密度，放置顺序须与原算子一致。固定 FOV、固定
内容场下，任意不交 key 的质量可加。关键不在“概率解释”，而在内容场不能
随 key 重新划分而重新 pooling、归一化或定义。

**精确等价边界：**若内容在当前 key Bⱼ 内为常数 cᵢⱼ，则

`∫Bⱼ rᵢ = [GaussianMass(Bⱼ)+ε|Bⱼ|] exp(τᵢcᵢⱼ)`，

与现有乘法完全相同。特别是内容场分辨率仍为原 base8、g8 key 恰是这些
常值区域时，所有 query 尺度的 g8 概率都不变。因此它**不可能修复已经
在 TRAIN 暴露的 q24→g8 相对 quad16 差距**。粗 key 的不同来自把各 base8
子块的“几何质量×内容权重”相加，取代先 pooled key 外观再乘一个权重。

这不需要新网络，但会保留原先粗 key 丢掉的子块内容。其成本以 base8
分辨率计算，不能继续把粗 key 数量当成全部算力成本。公平比较也须让强
控制使用相同的内容场，否则收益混有输入信息差异。

对忽略 floor 的全平面 Gaussian，若 c(x)=c₀+gᵀ(x−μ)，配方得到

\[
 \mathcal N(x;\mu,S)e^{\tau c(x)}
 =e^{\tau c_0+\frac12\tau^2g^TSg}
   \mathcal N(x;\mu+\tau Sg,S).
\]

所以线性内容下它仍是同一个 Gaussian 均值平移，没有额外的中心稳定性。
新增更细的内容场或插值，会增加分辨率/插值假设；对一般场，原 Gaussian
GL32 质量积分不再足够。非线性内容还可产生多个模式，不能由式子简单推断
PCK 或区域 KL 改善。

若以后只发现粗 key 分区失配，最少的可证伪检查应是：同一场拆并精确可加、
g8 与旧公式精确相同、线性场满足上述配方、相反内容峰不能被误称为无条件
中心保护。**当前先暂缓**；它的适用问题与已知 q24→g8 短板不一致。

## 四、方向 2：保留位置–外观交叉矩的条件均值内容

在本稿的两个方向中，它能直接改变“粗 query、细 key”且仍保持一个连续密度，
但**不再是只用 μ/C 的 PE**。下述只是可审查的最小数学形式，没有选定为
下一真实候选，也没有证明其新增成本值得。

在 query 内的同一观测测度上，令位置为 X、原 base8 外观标记为 F∈Rᴰ。
除原 μ、C 外，新增

\[
 \bar f=E[F],\qquad B=\operatorname{Cov}(X,F)\in\mathbb R^{2\times D}.
\]

把独立的空间 blur 加入 X 后，空间协方差为 S=C+h²I，B 不变。联合
Gaussian 的条件均值为 `E[F|X=x]=f̄+BᵀS⁻¹(x−μ)`。这是标准条件化
恒等式，真正新增的是 B 所保留的“区域哪一侧有什么外观”，不是 Gaussian
条件公式本身。

现有父 query 描述 qᵢ 经过 pooled 后的 L2 归一化，通常不等于 E[F]。
不能偷偷把二者视作相同。若要求 B=0 精确回退现有内容，可以明确使用
平移后的标记 `Z=F−f̄+qᵢ`，其均值为 qᵢ、交叉矩仍为 B；由此定义

\[
 \widehat z_i(x)=q_i+B_i^TS_i^{-1}(x-\mu_i),\qquad
 r_i^G(x)=\mathcal N(x;\mu_i,S_i)
             \exp\!\left[\tau_i\widehat z_i(x)^Tk(x)\right].
\]

这是明确的**条件均值特征能量**。它不是
`N(x) E[exp(τZᵀk)|X=x]`；后者还带条件特征方差项，需更多统计。
没有引入该方差、求逆特征协方差矩阵或增添新学习模块。

当 key 内 k(x)=kⱼ 固定时，记 `vⱼ=Bkⱼ`，配方给出 Gaussian 部分的
精确原生质量

\[
 M_j^G=\exp\!\left[\tau q_i^Tk_j+
                 \frac{\tau^2}{2}v_j^TS^{-1}v_j\right]
       \int_{B_j}\mathcal N(x;\mu+\tau v_j,S)\,dx.
\]

这是一个连续内容场的积分，但每个 key 有不同的有效均值。二次幅度项不可
删除；删掉会改变测度。它还意味着当前“同一 query 均值对全部 key”的积分
实现不能直接沿用成本结论。若内容场固定在 base8 上，粗 key 仍需按 base8
子块积分，不能为便利重新定义 pooled kⱼ。

旧面积 floor 也不能在上述配方后随手加回 `ε|Bⱼ|`：如保留同一测度顺序，
须额外积分 `ε exp[τ ẑᵀkⱼ]`。其线性指数在矩形上可解析积分，但须独立
处理稳定性。远处 ẑ 的幅度可能大，这个项不能凭 floor 小就省略。

**可以证伪的新增能力：**在两个 μ/C、pooled q 完全相同、但位置–外观
相关方向相反的观测区域，B 的符号相反，上式对同一个 kⱼ 的位移也相反。
旧算子无法区分它们。若 g8 query 内只分配一个常值 base8 描述，则 B=0，
g8 原式不变；q16/q24 包含多个描述，才可能改变 q24→g8。这与方向 1 的
严格不变边界不同。验证应使用这种事先固定的成对构造，不以真实效果选择
新的内容分辨率或 B 的缩放系数。

需要先解决的风险足以阻止当前直接实施：

- **成本/输入增加。** 每个 query 新增 2D 个矩，而不是三个空间协方差
  元素；粗 query 须保留组成它的外观标记。learned Q/K 及 L2 归一化后
  的 B 通常要在线重算，不能默认由一次离线原始 RGB 统计精确替代。
  公平控制应区分“给 quad 同样的分块内容”与“只换几何核”的贡献。
- **内容语义改变。** ẑ(x) 没有逐点 L2 归一化，外推时范数可大于 1；
  因此它不再是原 bounded cosine content。强行归一化会失去上面的
  解析形式。旧 τ·osc(content) 的数值保护不能原样继承，也没有中心
  PCK 保证；B 的相关性可能是遮挡、重复纹理或外观变化造成的误导。
- **并非通用 GS 参数。** 单个 Gaussian 若只有空间常值外观标记，则
  B=0；μ、旋转、尺度及一个常值颜色并不能提供 B。要求空间变化的
  观测外观，实质上扩展了参数化。view-dependent SH 也不能直接当作
  区域内位置–外观交叉矩。若用户的核心约束是现成 GS 几何参数直接
  变 PE，这一扩展可能不符合目标，应停止而非换名包装。

因此，本方向至多值得未来在**已接受机制显示丢失内部外观关联、且确实允许
增加 B**时做合成筛查。未满足这些前提时，同样暂缓，不因一个闭式表达就
进入旧数据迭代。

## 五、研究边界与下一步判据

Gaussian 区域用于位置编码已见 [mip-NeRF](https://arxiv.org/abs/2103.13415)；
Gaussian/二次位置注意力已见
[Cordonnier 等](https://arxiv.org/abs/1911.03584)；内容与位置先验的概率建模
已见 [BAM](https://arxiv.org/abs/2505.22842)。Gaussian 尺度混合和 Gaussian
条件均值也不是新的建模原语。上述文献边界不构成完整的新颖性检索，更不
证明本稿任一具体方案是首次提出。

当前不选新候选、不扫描径向 profile、不把两方向和混合核合并。先完成
当前 R17 的完整独立验证。若失败，要按实际失败的 key 分区、query 尺度、
中心/区域及成本分别解释；只有与某个方向的可证伪机制一致，且额外统计
仍符合“精炼的 GS 参数化→PE”目标，才有理由另立预注册协议。若只有
μ/C 允许作为输入，且瓶颈确实是被丢弃的信息，合理结论也可以是该表示
边界下暂时没有有依据的新方案。
