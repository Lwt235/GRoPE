# 平均精度归一化：有限的收尾控制

2026-11-08。用户要求固定完整五维、结束机制分解，并明确允许平均精度归一化作为收尾。此前 Q 已完成；本次只执行此前记录但未实施的归一化版本 N。完整五维 F 仍为主候选。本次不作为核心成果交付的前置条件，不追加模块、种子或第二个归一化版本。原生推广和全查询可靠性检验的负结果继续有效。

## 问题与竞争解释

Q 保留平均精度却去掉方向残差，区域和原生都没有保住 F 的用途。这并未回答：保留方向依赖后，平均精度引入的标量放大是否仍然必要？假设是方向关系足以保留主要用途；竞争解释是标量与方向需要共同作用，或两个任务依赖不同部分。原生的标量放大也可能扩大优化敏感性，但 N 的改善本身不能证明优化是唯一病因。

记 ri=tr(Σi)/3，hi=tr(Σi⁻¹)/3，pi=ri·hi。N=`normalized_precision5` 保留 F 的普通距离，将非对角关系的四个原始量改为：

\[
\left(\frac{\delta^\top\Sigma_i^{-1}\delta}{p_i},\
\frac{\delta^\top\Sigma_j^{-1}\delta}{p_j},\
\frac{\operatorname{tr}(\Sigma_i^{-1}\Sigma_j)}{p_i},\
\frac{\operatorname{tr}(\Sigma_j^{-1}\Sigma_i)}{p_j}\right).
\]

之后按 F 使用 log1p。**自关系沿用 F 的原始值**，避免引入新的自注意力偏置。pi≥1；球形极限 pi=1 时 N=F。N 仍保留方向及归一化后的谱权重，不是纯朝向控制。对原始非对角量作方向平均，N 与各自大小球形 T 一致；这不等于经过 log1p/MLP 后的期望相同。F、Q、N、T 提供互补控制，但训练后的准确率差不能视为可加的物理因素分解。

## 结果如何改变判断

- 若 N 保留区域用途、原生仍未可靠胜过 Distance，则把标量必要性结论按任务收窄；不因归一化更简单而晋升。
- 若 N 相对 Distance 有三个种子一致、幅度可用且中心/OA/CE/扰动无重大矛盾的改善，并接近或超过 F，则记录可供今后独立确认的线索。与 F 的 1 pp 差仅作工程参考，接近均值不构成正式等效；本轮不自动启动新确认。
- 若 F 明显更好，支持在保留方向时仍需要标量与方向共同作用；不能单独归因于朝向，也不证明整个网络中形状的必要性。
- 混合结果如实保留。六次拟合后结束这项收尾，不通过补种子、改温度、加权或加模块挽救。

实现检查限定于独立公式、球形/自关系、刚体/置换、方向敏感性和原始量方向平均；核对匹配初始化/RNG、共同内容与有限 PE 梯度。人工已知差验证比较符号和统计种子。冻结源码、计划、数据及旧预测身份，沿用已审阅训练引擎。GPU 预检使用旧 fit 批次；最多六个自有任务、每卡一个，最多两张共享卡、启动时至少 20 GiB 空闲、单任务 allocator 上限 16 GiB，保留他人任务。预期新增文件低于 1 GiB，不复制原始数据。普通执行错误保留修复记录即可，不新设科学门禁。
