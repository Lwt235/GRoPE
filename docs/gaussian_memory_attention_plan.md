# 固定高斯记忆的 Transformer 读取实验

2026-11-10。用户授权设为目标并执行。首轮记忆闭环已完成；本轮检验读取机制，不重新训练写入器，不把原来的两帧匹配门禁移植过来。

## 假设和竞争解释

在相同实际记忆、输入和预算下，把高斯中心与协方差形成的投影区域关系显式加入 cross-attention，有望比普通 MLP 编码和中心距离项更有效地读取当前视角的特征。竞争解释是普通 MLP 已可学会这些关系、中心定位已足够，或形状项的收益仅为每个基元大小不同，而非非圆形空间组织。当前记忆由投影读取目标训练；其对 attention 的适配程度是本轮负结果的范围限制。

## 固定实现与信息边界

复用 prototype1 的 learned_geometry/step_2000.pt 写入器生成并保存的 18 份记忆，256 个高斯、32 维特征；写入器和状态全部冻结。所有组的 query 都只有相机与 patch 射线；key MLP 都得到相同的 32 维内容、查询相机坐标下中心、完整协方差、opacity。协方差以三个 log 标准差和三个相关系数无损重参数化；中心用有符号 log1p。value 只来自相同场景特征。不输入查询图像、查询教师、传感器深度、参考图像或场景标识。

一个 64 维、4 头 cross-attention；Q/K 各为两层小 MLP，V/输出为线性层，没有额外 Transformer 层、query 残差或逐场景参数。V 与输出初始构成正交映射/转置。相同前方深度范围 (.01,100)、opacity 的 log 权重、一个零值背景槽；不使用组别不同的可见性筛选，不做额外遮挡预测。现有 alpha 合成渲染含深度排序，仅作现成闭环参照，不是三种 attention 的严格配对成员。

像素中心按当前 15×20 特征网格计算；投影中心 m=π(μ)，S=JΣ_camera Jᵀ+0.1I。三组共享内容分数，只改变额外项：

- MLP：b=0。
- Center：b=-λ_h‖u-m‖²/(2s²)，s² 固定为训练查询上有效基元 tr(S)/2 的中位数，不用评价标签；同一尺度供全部头和基元使用。
- Gaussian：b=-λ_h(u-m)ᵀS⁻¹(u-m)/2。无 logdet 归一化项。λ_h 用 softplus 保正，每头一个参数，初值 1。与中心组参数相同，普通组少 4 个有效训练参数。

坐标/透明度等共同输入保持一致；几何项采用加性关系，不修改内容特征幅度。该实现是相对几何 attention bias，不预先称为 RoPE 或新颖方法。

## 训练与评价

复用原 manifest 的 12 个 fit 片段、72 个训练查询；36 个同场景留出查询和六个未优化场景的 54 个查询用于开发评价，所有这些场景已经在历史工作中用过。三组 × 种子 20261110/20261111/20261112，共九次训练。相同初始化规则、配对采样序列、AdamW 3e-4/weight_decay .01、2,000 步，每步同一片段两查询，MSE、梯度裁剪 5。固定最后一步，无评价选模。记录源代码、状态、缓存身份；正式训练前检查解析投影、保存重读、空间置换与共同坐标变换。

报告 train/heldout-view/heldout-scene 的 MSE、余弦、逐种子和逐场景方向，展示同一记忆的多视角输出；评价包含所有预定查询。训练损失下降、梯度、保存重读仅证明实现或可优化性。配对结果可提供本任务机制/用途证据，不能直接推广到 VGGT 下游、未知相机或长期记忆。

固定的额外诊断仅对 Gaussian 进行：① 显式位置项的 S 改为 tr(S)/2·I，保留投影大小，key MLP 仍收到原完整协方差；② 去掉显式位置项；③ 固定种子打乱特征与基元的绑定。① 是训练后分布干预，不等同于重新训练的球形强对照；若改善仅来自局部大小，不能据此宣称方向不可替代。独立读取命令仅加载 reader 权重、保存记忆及相机，复核正常输出。

## 决策与资源

Gaussian 若在两种留出范围均优于 MLP/Center、配对种子方向一致且多数未优化场景改善，则视为值得确认的开发信号。固定代码和九个最终模型，再在未用于此次读取设计的样本上确认；明确新片段、已知场景与新场景的区别，不把历史数据称为全新外部测试。确认不调参。若各组相当，则保留更简单读取，形状位置项未获支持；若 attention 整体弱于原渲染，先判断具体读取/冻结记忆适配限制，不凭一次失败否定所有高斯记忆，也不无止境增加模块。

启动前检查 GPU 占用与 CUDA。空闲卡优先；无空闲卡时，按既有授权，仅一个共享训练进程，两次观察空闲≥20,000 MiB、利用率≤60%，显存上限 12 GiB。九次训练在该进程中依次执行；不停止其他任务。额外诊断与统计只做能改变当前解释的项目，不恢复历史静态积分数值门禁。
