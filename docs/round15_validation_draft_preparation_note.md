# R15 旧验证草稿的提前准备边界

2026-10-30，Stage B 的三场景完整前向尚未结束，区域标签评价尚未开始。

为利用校准运行期间的时间，允许提前编写独立的新文件、以合成输入测试
旧验证的接口、聚合和门槛。此决定仅替代 `round15_validation_blueprint.md`
中“进入实施前必须已有完整 Stage B 独立审计通过”的代码准备时序限制；
其候选、人口、角色、门槛、数据访问和运行前置条件均不变。

草稿不得填写猜测的最终 h/T，不得读取 Stage B 区域分数，不得执行旧验证
前向、读取其标签或启动真实 V/GS 任务。正式 freeze 入口仍须验证 Stage B
完整通过的独立审计及被接受的 selection 来源链。冻结前继续做交叉审查；
草稿完成不能作为推进效果实验的依据。所有已有冻结源码和结果保持原样。

这使纯代码准备与当前校准并行，不允许提前推进任何科学判断。
