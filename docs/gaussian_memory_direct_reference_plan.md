# 直接参考特征读取：固定信息可用性诊断

2026-11-10。用户已授权设为目标并执行。承接 fidelity1 的固定负结果：B/C 仅改变训练目标未在后续片段保住 Center 对 Local 的遮挡和全图净收益。本轮结束损失调整，检验更完整的参考信息是否在同一最后层 token 接口上具有可用性。

## 假设、竞争解释与决定

假设：256 个高斯、32 维内容、较早层特征监督及固定写入器的组合可能形成信息瓶颈；保留四个参考视图的最后层 2048 维 token，可使当前单层读取得到更稳定的额外信息。

竞争解释：当前接入层/恢复目标、参考几何误差、仅三个训练场景或固定训练预算限制了迁移；更大网络本身也可能改善恢复。直接读取同时放宽内容、数量和写入方式，不能单独归因到 PCA、空间合并或某个高斯参数，更不是严格数学上界。

固定四组：复用 B Local（277,202 参数）与 B Center（273,604 参数）各三个种子；新增 Direct（531,652 参数）和 Wide Local（530,548 参数，隐藏宽度 125）各三个种子。Direct 保持原 width64/head4/残差输出，key/value 输入改为 2048 维参考内容；中心位置项和尺度保持原值 .7146816253662109。Wide 只加宽同一当前视图 MLP。没有新形状 PE、门控或额外层。

Direct 若在两批旧片段上对原 Local 和 Wide 同时保留遮挡与全图净收益，且正确参考优于移除/交换/打乱，支持下一步研究压缩与写入、再比较同预算点/高斯记忆。效应量、三个种子和逐场景结果联合判断，不要求所有微小指标、每个场景均胜。只有局部改善则限定条件，不宣称通用。若仍失败，当前层/任务/训练覆盖应优先重新审视，停止本轮结构或权重调整；这不证明所有场景记忆都无效。

## 参考记忆与信息边界

仍使用四个原参考 [0,4,8,12]，冻结同一 VGGT，在 S=4 轴上联合编码参考，取最后层 patch token（4×300×2048）。内容逐 token 做无参数 LayerNorm 并存为 half；无 PCA、无 256 个种子合并、无可学习写入器。原写入器本已读取参考最后层 context，本轮不是声称它完全未接触高层信息。

每个参考 patch 的中心、协方差与有效性来自同一冻结 VGGT 参考深度/置信度、参考已知相机和既有 source_geometry。复用其 10% 置信度过滤，保存 1200 个槽，失效槽 opacity=0，其余=1。用原片段记录的 unit_meters 统一尺度；查询读取沿用原 K/c2w。保留原完整几何 key 内容，attention 的位置惩罚仍仅为中心距离。参考构建函数只接受四参考图像、四相机和既有场景尺度，不能接收查询图像/教师。

查询 RGB 及其遮挡 token/完整教师缓存全部复用。完整查询只用于监督与评价，不进入参考记忆。Direct 保存的共享场景状态可重复供不同相机查询读取。存储、有效槽数、计算与参数单独报告；Direct 对 GS 的比较为较宽松预算诊断，不作等成本优越性主张。

## 固定训练与评价

新增六次训练：种子 20261110/11/12，每次 2000 步、每步两个遮挡样例、AdamW 3e-4/wd .01/clip5，全部 patch 等权。与 B 使用同一 12 片段/72 查询/288 遮挡样例，完全相同样本序列。Direct 的 query/local/output、位置尺度、key 几何列和可匹配 bias 复制 B 对应初始参数；扩展特征权重按固定种子初始化。Wide 按相同种子初始化，因宽度不同不宣称逐参数相等。输出层均零初始化，不按评价选择 checkpoint。

评价全部四组×三个种子，固定第 2000 步。包含十八个旧开发片段，以及之前已评分的 40–52 与 80–92 两批各十二片段，共四十二片段。两批属于相同十二历史场景，分别报告，合并时按场景聚类，不能当作二十四独立场景或新确认。无下载、无新片段选择、无新确认声明。

指标：遮挡区、可见区、全图归一化 token MSE，完整输入 token 改变量。全图按 70/230 真实 patch 数；三种子与逐场景配对结果全部保留。Direct/Center 做正常、移除、特征空间打乱、交换场景、错误查询相机干预；Wide/Local 只读当前视图。干预分布偏移仅提供辅助机制证据，不能替代训练过的两种无记忆对照。

## 核对、资源与收尾

训练前固定源码、原输入/模型/配置/片段身份。检查共同初始化、2000 步采样配对、有限梯度、既有 B 分数回放、至少一份独立 CPU/NumPy 评分和独立实际图像→VGGT→Direct 读出。参数匹配不等于计算匹配；记录共享卡实际时间、峰值显存和场景存储量，另作固定形状前后向成本描述，避免把共享 GPU 时间当独占测速。
