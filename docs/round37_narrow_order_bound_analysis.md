# R37 后的 narrow-normal 局部阶数界：未选择算法分析

2026-11-01。仅静态推导及精确有理数计算；没有读取真实 NPZ、计算正式 fixture、调用模型/参考积分器或修改冻结源。以下给出几何成本投影可以采用的分析阈值，**不选择新参考算法，也不改变 R37 的失败**。实际分支人口、总成本和效果尚不能由这些界推出。

## 1．保持原局部余项上限的自适应阶数

现有 [R34 分支](../experiments/round34_log_narrow_reference.py)接收标准正态区间的 midpoint m、halfwidth h>0。这里 h 是区间半宽，不是 RMS 核带宽。令

\[
a=mh,\quad b=h^2/2,\quad s=h(|m|+h)=|a|+2b\le1/4,
\quad f(u)=e^{-au-bu^2},\quad -1\le u\le1.
\]

原质量为 `h φ(m) ∫f`；其正比例因子不改变相对求积误差。记 g=log f，则 `|g|≤s, |g′|≤s, |g″|≤s`，更高阶导数为零。因此

\[
\|f^{(2n)}\|_\infty\le e^s(2n)!
\sum_{k=0}^{n}\frac{s^{2n-k}}{2^k k!(2n-2k)!},
\qquad \int_{-1}^{1}f\,du\ge2e^{-s}.
\]

Gauss–Legendre 的余项系数为

\[
C_n=\frac{2^{2n+1}(n!)^4}{(2n+1)((2n)!)^3}.
\]

这是 Gauss 余项及 Legendre 归一化的直接结果，参见 [NIST DLMF 3.5.19–21](https://dlmf.nist.gov/3.5#E19)。故相对误差不超过

\[
B_n(s)=e^{2s}\frac{C_n(2n)!}{2}
\sum_{k=0}^{n}\frac{s^{2n-k}}{2^k k!(2n-2k)!}
\le \widehat B_n(s):=
\frac{C_n(2n)!}{2(1-2s)}
\sum_{k=0}^{n}\frac{s^{2n-k}}{2^k k!(2n-2k)!}.
\]

最后一步用 `exp(x)≤1/(1−x)`（0≤x<1）：将指数级数逐项与几何级数比较即可证明。所有系数非负，故该有理上界在 `[0,1/4]` 单调。以下阈值及上界用 `Fraction` 精确计算；显示值向上简化，完整分子/分母见 [results.json](round37_narrow_order_bound_analysis_data/results.json)。旧上限仍为 **1.88×10⁻¹³**。

| 阶数 n | 充分条件 s≤ | 有理上界 ≤ |
| --- | --- | --- |
| 1 | 2⁻⁴⁰ | 1.516×10⁻¹³ |
| 2 | 2⁻¹⁸ | 1.617×10⁻¹³ |
| 3 | 2⁻¹¹ | 5.558×10⁻¹⁴ |
| 4 | 2⁻⁷ | 5.901×10⁻¹⁴ |
| 6 | 2⁻³ | 7.458×10⁻¹⁴ |
| 8 | 1/4 | 2.508×10⁻¹⁶ |

这些是充分条件，不是最优分界。低阶只用于满足其条件的区间；整个 narrow 分支直接统一降到 GL4/GL6 不成立。独立局部反例取 `m=0,h=1/2`，即 `f=exp(−u²/8)`，其 GL4/GL6 相对误差分别约为 **5.820881879×10⁻⁸ / 1.923093224×10⁻¹²**，都超过旧局部上限。

反例没有调用数值积分：对20阶指数 Taylor 多项式，用有理 Legendre 多项式 Pₙ 做多项式取余。GL 在 Pₙ 的根处求值，故对任意多项式 p，`Qₙ(p)=∫(p mod Pₙ)`，右侧仅为有理多项式积分。GL 正权重之和为2，Taylor 的积分及求和余项合计不超过 `4(1/8)²¹/21!`；另以积分自身的上下界归一化，得到 JSON 中的严格相对误差区间。GL 的正权重及多项式精确性亦见上述 DLMF 原始依据。这是标量解析算界，不是新的正式参考实验。

## 2．已形成 binary64 输入的保守分类

建议的几何投影分类算术是：

```text
sum_up  = nextafter(RN(abs(m) + h), +∞)
span_up = nextafter(RN(h * sum_up), +∞)
```

在有限 binary64 m、h>0、IEEE round-to-nearest 和渐进下溢前提下，两次各向上移动一个可表示数，分别覆盖加法、乘法可能向下的舍入。乘积舍为0时向上得到最小正 subnormal，仍是上界；溢出为∞只会保守地不选低阶。这证明 `span_up≥` **已经形成的 binary64 m/h 所对应的实数 s**，不证明 m/h 的前序构造误差。

保留原 narrow mask；在该 mask 内按表为1/2/3/4/6选最小合格阶数，否则仍走原 GL8。不要因向上取界跨过1/4而改走 broad CDF 分支。GL8 fallback 继续保留 R34 更宽 `.5` envelope 的旧局部证明；不能把本表的实数 `s≤1/4` 偷换成所有浮点 mask 边界的保证。正式实现仍需要边界合成检查，但本稿未实现或测试 selector。

若后续只做几何人口投影，应保留每阶区间数，并按 `Σ n×count_n` 记录假设的 Y 节点；X节点、pilot/GK位置及其他工作照旧计数。没有计算 PDF/CDF 不等于证明新参考完成：变阶后的浮点结果可能改变外层细分，初始成本投影不能预测完整自适应成本或收敛。正式算法若被选择，实际节点须据执行逐批预扣，不能将仍执行的 GL8 在账上改计较少节点。

## 3．另一种正项解析级数，尚非已选修复

避免尾部 CDF 差可以直接在 midpoint/halfwidth 上展开，而不形成可能舍成相同的左右端点。设 `A=h²/2, c=(mh)²/4`。由对称化和正项展开

\[
M=2h\phi(m)e^{-A}\int_0^1 e^{A(1-u^2)}\cosh(mhu)\,du
 =2h\phi(m)e^{-A}\sum_{r=0}^{\infty}t_r,
\]

其中正项可递推为

\[
t_0=v_0=1,\qquad
v_r=\frac{c}{r(r+1/2)}v_{r-1},\qquad
t_r=\frac{A}{r+1/2}t_{r-1}+v_r.
\]

推导是将 `exp(A(1−u²))` 与 cosh 分别展开，再用
`∫₀¹u²ᵏ(1−u²)ʲdu=½ B(k+½,j+1)` 合并相同总次数，参见 [Euler beta integral](https://dlmf.nist.gov/5.12#E1)。所有项非负，避免交错 Taylor/Hermite 递推的消减；直接算两端 erf 的幂级数差也没有这种保证。普通及重排 erf 级数可见 [DLMF 7.6.1–2](https://dlmf.nist.gov/7.6#E1)，本处是针对窄区间的单独推导，不作新颖性主张。

由 `|mh|+2A≤1/4` 可得 `q=A+c≤1/8`，且 `t_r≤q^r/(3/2)_r`。截到 r=N 后，剩余项与相对质量误差均有上界

\[
R_N\le\frac{q^{N+1}}{(3/2)_{N+1}}
\frac1{1-q/(N+5/2)}.
\]

在最保守 q=1/8 时，N=7 的上界约4.488×10⁻¹³，尚不足；N=8 上界小于5.897×10⁻¹⁵，可满足原局部上限。较小 q 可以更早满足同一界，但实际人口未知。可在 log 域组合 `log(2h)+logφ(m)−A+logΣt`，不把极小 raw 转成零；系数乘法、项吸收/下溢及 logφ 的有限性仍须单独处理。这里的余项界同样**不包含浮点误差**。

级数不意味着“零成本 Y”。至少要真实记录已执行递推项、乘除/求和和特殊函数；不能仅因没有 PDF abscissa 就从旧预算账本中删掉工作。最坏8次递推并不自动少于GL8的8节点预算，wall time也未测；若改变工作单位，必须另冻兼容的计费合同。相比之下，变阶GL可直接保留按实际PDF节点计费的语义。本稿不据此选择路线。

## 4．范围、科学风险和计算记录

所有界只约束局部正态区间的**精确算术**余项；不覆盖实际密度/输入舍入、X求积、外层自适应或整条概率误差。原 raw/P/direct-FOV/尾界、资源及完整失败人口门槛不能放宽。参考修复只是在建立可信测量工具，不能累计解释为 RMS 效果进展；即使参考通过，区域/中心、无缓存增量成本、实际V/GS等科学要求仍未通过。下一修复若无明确可验证的成本收益，应回到前瞻停止/开发筛查决策，而不是无限延后效果问题；不能为尽快得到效果而豁免旧门槛。
