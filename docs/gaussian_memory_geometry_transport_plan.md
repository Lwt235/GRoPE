# geometry_transport1：冻结同一场景状态，区分几何保持与隐向量回归

2026-11-10，所有本轮训练和评分前固定。承接reference_geometry1：传感器辅助几何使直接中心读取改善57.97%，却只使学习Gaussian改善0.75%。只提高初始几何没有确立学习模型的跨地点用途，下一步检验读取结构如何利用已有几何。

## 假设与竞争解释

主假设：把几何深度作为显式可传递的attention value并保留到输出，而不是完全依赖隐向量回归，能在相同场景状态上获得更可靠的跨地点收益。

竞争解释：收益仅来自一个几何初值、局部残差拟合或传感器额外信息，不需要学习跨视图attention；冻结的分组/粗协方差或训练范围仍限制用途。零训练几何读数以及固定读数加局部残差用于区分这些解释。本轮冻结整个场景状态，不据此声称学会了写入，也不把深度探针当作最终VGGT用途或一般PE优势。

## 同一状态、三种读取、两个位置项

每片段两份固定状态：原VGGT几何、reference_geometry1的部分传感器辅助几何。每份256槽，均值、完整协方差、固定opacity=0.7及32维原seed_teacher内容；成员、内容、相机、单位、查询输入和标签不变。无需查询RGB/深度写入，无逐场景优化。参考传感器缺测回退和旧分组限制完整沿用。

对每种输入几何、每个中心/协方差位置项，训练三种读取：

1. **Latent**：当前视图分支和单层四头attention的64维内容读出相加，经GELU与线性头预测对数米制深度。
2. **Transport**：与Latent完全相同的可学习层和初始参数，额外将同一attention权重对槽中心的相机坐标对数米制深度加权，四头等权平均，直接加到输出。原线性头成为零初始化残差。没有新可学习模块。
3. **PriorResidual**：固定零训练几何权重直接读取深度，再加仅由当前视图token/相机得到的零初始化局部残差。局部分支宽67；它与同宽无记忆Local具有相同参数，用于判断Transport是否超过“几何初值＋局部拟合”。

Latent/Transport共同采用64维、4头Q/K/V。Q来自冻结S1查询token与原18维相机描述；K仍含32维内容与10维几何，V为原内容及对数深度到64维的投影。中心/协方差只改变位置bias；中心key仍可见形状，不能称完全无形状。

共同初始化K投影为零、位置强度为1、输出头为零。有效槽的attention归一化，不保留一个始终与有效几何竞争的零值null槽；只有全部槽失效/移除记忆时才用零背景。这使Transport和PriorResidual初始输出等于各自预定零训练几何读数。Latent初始输出为0。**参数相同不等于预测相同；保留几何初值正是本轮干预的一部分。** 新Latent也用同一归一化和初始化，因此主对照不混淆null处理；不能把它与上一轮联合写入模型的差异单独归因于输出路径。

## 训练、强对照与固定评价

- 三读法×两位置项×两输入几何×三个种子20261110/11/12=36次，再训练同宽Local三次，共39次；同一seed的Latent/Transport各分支完整参数初值相同，PriorResidual与新Local初值相同。
- 全部2000步、batch2、AdamW 3e-4、weight decay .01、clip5；沿用surface1的十二训练地点、72训练查询/288遮挡和每步采样，不选checkpoint、不扫描权重。
- Latent/Transport预计145,477参数，新Local/PriorResidual预计147,209参数，以实现计数为准；旧435,757参数Local作为额外强对照完整保留。冻结memory不计成训练参数。
- 主指标沿用有效patch log-depth MSE；遮挡、可见、RMSE、AbsRel、完整输入与偏置/空间残差同时报告。一致性只作辅助，不能取代准确度。
- 所有模型完成后统一评估46历史片段；十二非训练地点各两个片段先合并地点、再跨三个种子配对。原三/新增九训练片段留出、同地点其他片段及其余开发地点分开报告。没有新确认。
- 主比较为同输入/同位置项Transport对Latent、PriorResidual、新Local及旧强Local；对零训练几何读数说明学习是否有增量。Transport的Gaussian对Center是形状位置项的辅助比较，不以其平均优胜替代强基线收益。

## 机制诊断与正确性

所有记忆读取组正常/移除记忆/打乱内容空间绑定/错误记忆读取相机；Transport另移除显式几何通路、移除残差、将attention路由恢复初始几何权重。PriorResidual的打乱应不变，移除残差应回到固定读数。错误相机只改记忆读取，当前视图分支相机保持原值。固定模型后作干预，不用结果调模型或挑条件。

同一状态保存后供所有读取器使用；独立命令只加载状态、查询token、相机和尺度读出。训练初值/采样、源/输入身份、初始零训练读数对齐、有效/空记忆及几何通路梯度、旧强Local回放、独立CPU读取和NumPy评分作有界核对。预先固定查看七案例与总览，保留正负结果；审计不追逐不影响结论的舍入误差。普通预运行错误留版本记录后修复，不新开科学轮次。

## 结果对应的决定

1. Transport在预测几何下稳定超过Latent、PriorResidual、强Local及固定读数：保留显式几何传递，下一项再验证联合写入及未用片段；本轮不自动扩展。
2. 只有传感器辅助成立：只保留正确几何条件下的读取证据，下一步定位可部署几何/分组限制，不能称RGB方法有效。
3. Transport优于Latent却不优于PriorResidual：收益主要支持保留几何初值，学习attention的额外价值未立；选择更简单解释，不堆模块。
4. 无稳定增量或学习破坏固定读数：结束此固定读出设计的推广，不补种子、扫温度或事后选择地点。保留原共享记忆可学性，明确当前信息/监督/结构的用途边界。

各分支可以部分成立；准确度、机制与新确认分开记录。整个研究目标仍是精炼且可信的共享3DGS场景记忆/Transformer位置编码，本轮只是其中的读取诊断。
