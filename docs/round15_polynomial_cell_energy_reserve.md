结论：**完整协方差的 quartic 点 log 密度确实具有精确的 14 个非恒定单项式
表示。但把原生矩形的积分质量改成面积乘几何平均密度，不值得作为当前方案的
下一轮候选。** 它丢失区域质量的可加性；温和协方差的合成反例已产生约
0.31–0.51 的分区总变差。新增的中心曲率不能抵消这个语义变化，真实积分本身也
已有有限单元曲率。低计算成本不能成为推进理由。

这里不提出文献新颖性声明。以下公式直接展开、积分和使用 Jensen/AM–GM
不等式得到；无需把一个已知有限次多项式展开包装成新的位置编码贡献。

## 1. 完整协方差下的 14 维表示成立

固定当前径向密度，记

\[
S=C+h^2I\succ0,\quad A=S^{-1},\quad
q=(x-\mu)^TA(x-\mu),\qquad
\log p_4(x)=-\frac{q^2}{4\pi}-2\log\pi-\frac12\log\det S.
\]

`C + h²I` 仍只是已定义的总协方差参数化；这里没有将它解释为 Gaussian 卷积。
令二维位置为 `(x,y)`，并写

\[
A=\begin{pmatrix}a&b\\b&c\end{pmatrix},\quad
\ell=-2(a\mu_x+b\mu_y),\quad m=-2(b\mu_x+c\mu_y),\quad
n=\mu^TA\mu.
\]

则 `q = ax² + 2bxy + cy² + ℓx + my + n`。按如下次序选择 key 特征：

\[
\phi(x,y)=(x,y,x^2,xy,y^2,x^3,x^2y,xy^2,y^3,
 x^4,x^3y,x^2y^2,xy^3,y^4).
\]

`q²` 对应的 14 个系数是

\[
v=(2\ell n,2mn,\ell^2+2an,2\ell m+4bn,m^2+2cn,
2a\ell,2am+4b\ell,4bm+2c\ell,2cm,
a^2,4ab,2ac+4b^2,4bc,c^2).
\]

因此

\[
\log p_4(x,y)=-\frac{v^T\phi(x,y)}{4\pi}+b_Q,\qquad
b_Q=-\frac{n^2}{4\pi}-2\log\pi-\frac12\log\det S.
\]

计数为 `2 + 3 + 4 + 5 = 14`，并不要求 `S` 对角或各向同性。
这只是 log 密度的有限特征内积表示；不自动得到 RoPE 的旋转/相对位置结构。
`b_Q` 在没有 floor 的逐 query softmax 中可以消去。

两个实现边界不能省略：

- 对面积不相等的 key，`log(area)` 是额外的已知 key 偏置。若坚持所有项都放入
  同一个点积，它还需要一个常量 query 通道；不能把它算进上述 14 个非恒定单项式。
- 对当前 `mass + 1e-30 * area` 的 floor，query-only 密度常数影响 raw mass 与
  floor 的比例，不能在加 floor 之前删除。它可以作为单独标量保留，但不应宣称
  无条件地等同于一个裸 14 维 attention 点积。

对于轴对齐矩形 `B=[x0,x1]×[y0,y1]`，所有 key 特征均可精确平均：

\[
E_B[x^r y^s]=E_B[x^r]E_B[y^s],\qquad
E_{[u,v]}[x^r]=\frac{v^{r+1}-u^{r+1}}{(r+1)(v-u)},
\]

其中 `r=0` 时期望为 1。因此 **`E_B log p4`** 有精确的 14 维 key moments。
它并不是 **`log E_B p4`**。后者是一个 log-partition 函数，其关于多项式系数的
Hessian 是 cell 内指数重加权特征的协方差，通常非零；直接用固定 cell moments
与原来的多项式系数点积不能普遍精确替代它。

## 2. 单元平均能量的闭式公式和中心曲率

令 key 矩形中心为 `c_B`，边长为 `(w_x,w_y)`，`d=c_B−μ`，
`u~Uniform(B−c_B)`，以及

\[
D=E[uu^T]=\operatorname{diag}(w_x^2,w_y^2)/12.
\]

独立、中心对称的两个坐标使所有奇数项为零。精确展开为

\[
E_B[q^2]=(d^TAd)^2
 +4d^TADAd+2(d^TAd)\operatorname{tr}(AD)+K,
\]

\[
K=a^2\frac{w_x^4}{80}+c^2\frac{w_y^4}{80}
 +(2ac+4b^2)\frac{w_x^2w_y^2}{144}.
\]

拟议权重为

\[
G(B)=|B|\exp(E_B\log p_4)
 =\frac{|B|}{\pi^2\sqrt{\det S}}
   \exp\left[-\frac{E_Bq^2}{4\pi}\right].
\]

固定 `S` 和矩形形状，在 `d=0` 的 log 权重 Hessian 为

\[
\nabla_d^2\log G\big|_0
 =-\frac{2ADA+\operatorname{tr}(AD)A}{\pi}.
\]

对于 `S=σ²I` 和边长 `w` 的方形，它等于
`−w²/(3πσ⁴) I`。所以确实出现二次曲率；但该曲率随 key 宽度平方增加，
在 key 变细时趋于零，在核变窄且 key 固定时发散。它不是一个与分区无关的
“修复平中心”机制。

尤其需要避免忽略当前候选已经做的积分。对真实质量
`M(B)=∫_B p4(x)dx`，设 `L=log p4`，则

\[
\nabla_\mu^2\log M
 =E_{p_4(\cdot\mid B)}[\nabla_\mu^2L]
 +\operatorname{Cov}_{p_4(\cdot\mid B)}(\nabla_\mu L).
\]

真实单元积分通常也有中心二次曲率，并非直接继承点 log 密度的零 Hessian。
几何平均改成 uniform expectation，并丢掉了上式的正半定协方差项。
当窄核完整落在宽 cell 内时，真实质量接近 1，对核中心的小位移近似不变；
而 `log G` 的曲率反而可以无限变大。这是错误置信度的来源，不是中心定位能力
增强的充分证据。

## 3. 拆分/合并反证：它不是同一空间概率测度

Jensen 不等式直接给出

\[
G(B)=|B|e^{E_B\log p_4}\le |B|E_Bp_4=M(B).
\]

若 `B` 被不交子矩形 `B_j` 覆盖，记 `α_j=|B_j|/|B|`，则

\[
G(B)=|B|\prod_j\left(\frac{G(B_j)}{|B_j|}\right)^{\alpha_j}
 \le \sum_jG(B_j).
\]

除非各子块的平均 log 密度恰好相同，否则严格不等。这里始终取 `T=0`，
所以反例不依赖内容特征，也不依赖对子块重新计算内容。细化 key 分区系统性地
增加 raw total，且不同父区域增加的比例不同；FOV 归一化不能普遍消掉这一偏差。

对称情况可以掩盖错误。例如，将以各向同性核中心为中心的方形仅分成四个象限，
四象限平均 log 密度相同，恰好满足等式。这不是通用可加性；位移半个小 cell 或
采用 3×3 拆分就能打破该对称。

旧协议并没有要求真实预测在所有 query 重分区下完全不变，且共同网格的 key
均匀提升本身也有离散近似。因此上述反证不是“任何实证 gate 都逻辑上不可能
通过”的证明。它精确否定的是当前方案中 **native key 权重就是同一预测密度在
该区域的积分质量** 的解释。用 `G` 代替 `M` 会重新引入 R10 已关注的 key
范围/尺度偏差，需要改写算子合同；不能称为当前算子的无损加速。

## 4. 量化合成反例

以下没有图像、深度、sensor 标签、真实训练输入或当前 Stage B 结果。所有位置
以 8 px 为一个单位。FOV 由 `3×3` 个边长 `w` 的粗方形构成，中心粗 cell 为
`[-w/2,w/2]²`；每个粗 cell 拆为边长 1 的小方形。核均值固定 `μ=(.5,.5)`。
比较在相同 FOV 内归一化的粗 cell 概率：

1. `coarse G`：每个粗 cell 的几何平均权重直接归一化；
2. `split G`：所有小 cell 的几何平均权重归一化后加回原粗 cell；
3. `true M`：对原粗 cell 独立数值积分原密度后归一化。

`G` 使用上一节的精确矩形矩公式。`M` 使用独立 NumPy 二维 tensor-product
Gauss–Legendre 96/128 阶规则，四组反例的 raw mass 最大阶数差为
`1.51e-14`。总变差定义为 `0.5 * sum(abs(coarse_probability - split_probability))`。

| 参数 | true M 中心概率 | coarse G 中心概率 | split G 中心概率 | 拆并总变差，无 floor |
| --- | ---: | ---: | ---: | ---: |
| `w=3, S=I` | 0.6409771390 | 0.9959857634 | 0.6844823461 | 0.3115034173 |
| `w=2, S=(7/12)I` | 0.4854799344 | 0.8756459390 | 0.5369931322 | 0.3386528068 |
| `w=3, S=R45 diag(.25,4) R45ᵀ` | 0.4534739444 | 0.9926238771 | 0.4834651914 | 0.5091586857 |
| `w=3, S=.25²I` | 0.999999999985 | 1.0 | 1.0 | 约 0 |

前两组分别对应理想均匀 q24、q16 support 加上 `h=.5` 的总协方差
`(.75+.25)I`、`(1/3+.25)I`；不是病态小特征值例子。第三组条件数只有 16。
其总 raw `G` 从 coarse 的 `0.0061641114` 变成 split 的 `0.7971738160`，
而同一 FOV 的真实质量为 `0.9995534511`。

最后一组说明 floor 的独立危险：coarse `G` 总质量为 `3.4742873e-56`，
split `G` 总质量为 `2.0269694e-5`，真实质量约为 1。加入当前已锁定的
`1e-30 * key_area` 一次 floor 后，coarse 的九个区域几乎只剩相等的 floor，
中心概率成为 `1/9`；split 后加回的中心概率仍近 1，拆并总变差为 `8/9`。
不能删除 floor 来回避这个反例，因为前三组即使没有 floor 也已经严重不一致。

复现所需的核心代码如下；它只使用上面的 toy 常数，不依赖任何项目数据或模型：

```python
def geometric_logmass(boxes, mu, S):
    A = np.linalg.inv(S)
    d = (boxes[:, :2] + boxes[:, 2:]) / 2 - mu
    width = boxes[:, 2:] - boxes[:, :2]
    var = width**2 / 12
    q = np.einsum('ni,ij,nj->n', d, A, d)
    constant = (A[0, 0]**2 * width[:, 0]**4 / 80
                + A[1, 1]**2 * width[:, 1]**4 / 80
                + (2*A[0, 0]*A[1, 1] + 4*A[0, 1]**2)
                * var[:, 0]*var[:, 1])
    expected_q2 = (q*q + 4*np.sum((d@A)**2*var, axis=1)
                   + 2*q*(var@np.diag(A)) + constant)
    return (np.log(width.prod(1)) - 2*np.log(np.pi)
            - .5*np.linalg.slogdet(S)[1] - expected_q2/(4*np.pi))
```

具体粗 bounds 按 `x,y ∈ {-1.5w, -.5w, .5w}` 构建为
`[x,y,x+w,y+w]`；fine bounds 在每个粗 cell 内以步长 1 遍历。二者使用相同
`S`、`μ`、FOV、`T=0`，没有选择效果最好的参数。

## 5. C→0、各向异性与尺度极限

**C→0，固定 h。** 得到 `S=h²I` 的 quartic 点核，仍是当前定义的新核，不是
Gaussian point。固定 h 不意味着核宽已经为零；上一表最后一行是在已用到的
`h=.25` 下的有限尺度反例。

**核宽趋零，固定 cell。** 对中心方形 `[-L,L]²`、`S=h²I`，

\[
E[r^4]=\frac{28L^4}{45},\qquad
G=\frac{4L^2}{\pi^2h^2}
 \exp\left[-\frac{7L^4}{45\pi h^4}\right]\longrightarrow0.
\]

真实积分质量却趋近 1。更一般地，核中心严格位于 cell 内、`S=ε²S0` 时，
`log G` 含有负的 `ε⁻⁴` 项，也趋于负无穷；在密度几乎全被 cell 覆盖时反而
丢掉全部 raw mass。

**各向异性。** `A D A`、`tr(AD)A` 和四阶常数都受窄轴控制。矩形若横跨一条
窄但高密度的斜带，真实积分保留带上的质量，几何平均却因矩形其余位置密度低而
严重压低整体。上述旋转且条件数 16 的反例已经显示这一点；不需要奇异协方差。

**整体坐标变换与分区尺度是不同问题。** 若同时把 `μ`、`S` 和真实 key 区域作
一致可逆仿射变换，密度 Jacobian 与面积抵消，`G` 可保持坐标变换的一致性。
但固定密度、只改变 key 分区大小时，`G` 不保持可加性。后一种情形正是本轮
关心的 key 拆并/多尺度语义，不能用前一种性质代替。

**无限细 key。** 当 cell 直径趋于零时，`G≈area*p(center)` 并可收敛到真实
积分；这个极限不能为宽达 16/24 px 的 native cell 提供误差保证。对近似常量
log 密度的小 cell，`log(M/G)` 的首个非零项约为 `Var_uniform(log p)/2`，
提示真正需要控制的是 cell 内 log 密度变化，而不只是 feature 维数。

## 6. 数值和研究决策

还需区分“实数上精确多项式”与“稳定的 float32 GEMM”。1000 组固定随机种子
15 的 SPD `S=BBᵀ+.25²I` 合成检查中，14 项展开与直接 `q²` 的最大缩放误差
为 `5.79e-13`（float64）。但一维嵌入的简单例子 `μ_x=20,x=20.1,μ_y=y=0,
h=.25,C=0`，直接 quartic log 能量为 `−0.00203718327`，原坐标展开的
float32 点积给出 `0.0`，float64 给出 `−0.00203718245`。中心附近大项抵消需要
单独审查；14 维并不自动意味着安全的 float32 实现。

本次备用审查建议：

1. **不推进 geometric-mean native cell score 的真实 TRAIN/val 实验。** 它有
   简洁公式，但已经在与目标相关的合成尺度下违反核心质量语义，代价过大。
2. 14 个单项式仅保留为点 log 密度的代数事实，不把它宣称为当前 native 积分
   的等价加速、不宣称消除了中心定位问题，也不据此新增模块。
3. 若将来另立明确的 point-energy 任务，可独立讨论多项式特征；那是新任务
   定义，需要新的正当目标与比较，不能悄悄替换当前区域分布检验。
4. 当前 R15 Stage B 继续依照冻结协议完成。本文不改候选、h/T 网格、可行集合、
   旧 gate 或独立审计；无论该轮成功还是失败，都保留本反证。

独立交叉检查：protocol 代理另外推导了同一 AM–GM 拆并不等式和中心方形窄核
极限，结论一致。本文没有借用任何当前 Stage B 效果来选择上述结论。
