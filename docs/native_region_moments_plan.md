# 原生高斯区域矩：固定输入可行性检验

2026-11-09。上一项区域重构新场景确认已完成，保持完整五维 F；该确认的混合结果及原生数量增强的未确立结论不变。本项只检验一个后续表示假设，不重新评分那些确认集，不训练、不改变 F 的公式，不扫描分组大小或协方差缩放。

## 问题和竞争解释

假设：把邻近原生 3DGS 基元表示为一个有明确空间范围的区域，可使当前五维关系作用于区域支撑，同时仍保留原生高斯形状的非平凡贡献。竞争解释是区域矩几乎全部由中心散布决定；这样的接法即使有效，也可能主要是普通点云区域编码，不能归功于原生 GS 协方差。

旧 fit 输入诊断已发现单基元与观测区域的尺度不同，但尺度不同不是分类失效的证明。本轮先测量区域化是否仍保留内禀形状信息；输入差异不能代替学习效果，不能据某个统计阈值宣布通过一般用途。

## 固定构造和对照

沿用旧 `geometry_scale_diagnostic` 的 120 个训练对象：60 类各按 ID 字典序取两个，每对象使用同一身份随机序列抽取的 512 个缓存基元。只读旧 fit 的 centers/covariance/labels 及身份元数据；标签仅用于固定类别均衡选择，不读取 val、dev_eval、官方 TEST 或新区域确认缓存。保持原对象 RMS 归一化和既有 `1e-8 I` floor，没有运行时 jitter。

复用 `round58_data.fps_and_neighbors`：每对象 64 个中心 FPS 锚点、每锚点 32 个中心近邻。邻域可以重叠，故不能将全部区域称为对原对象无损的密度重表示。每个局部组使用等权混合：

`m = mean(mu_k)`

`B = mean((mu_k-m)(mu_k-m)^T)`

`W = mean(Sigma_k_physical)`

`C_full = B + W + epsilon I`，`C_centers = B + epsilon I`。

缓存中已经加入一次 epsilon I；实现直接平均缓存协方差再加 B，避免重复加 floor。两项比较使用相同分组、均值和 F 公式，只对比原生内部协方差有无进入区域矩。等权是固定的统计定义，不是 opacity 权重或渲染贡献权重；不声称保持 alpha 合成或真实表面几何。

报告每组 `tr(W)/tr(C_full)`，以及 `C_full^(-1/2) W C_full^(-1/2)` 的特征值/平均值。前者只量总方差，后者检查薄方向贡献，避免只凭 trace 忽略方向差异。另报告同一非自身区域对的原五维描述符差：中心距离应完全相同，四个形状量的绝对差及联合相对差均保留。全部 4,032 个非自身有向对均用，不按结果挑组或样本。按对象给分布，保留 60 类结果；不据类别事后建立切换规则。

## 结果改变什么决定

- 若中心散布几乎解释全部区域矩和四维形状关系，不优先把这条接法包装为原生形状方案；未来若研究区域化，必须明确主要是中心构造的贡献。
- 若原生形状仍显著改变多个方向和五维输入，只说明值得考虑一个固定的原生任务开发比较：同一聚合内容、同一 64-token 骨干，比较 F(full)、F(centers-only PE) 与 Distance，并在必要时加入角度 PE。这样才能区分 PE 组织与共同 token 化收益；本轮不预设其成绩或自动启动大规模训练。
- 不管统计大小，都不晋升新方法、不重写原分类或新场景确认结论。后续训练若开展需单独固定预算、比较与决策，确认阶段须使用真正未用且适用的数据。

实现检查覆盖单分量、通过确定性 sigma 点重建的混合一二阶矩、刚体等变，以及带权分量等价拆分。带权拆分性质只属于保持混合质量的数学运算，不能推广到任意等权重采样。实际输入上独立 NumPy 原始二阶矩与 SciPy 广义特征值复算即可；不加求积或微小尾数门禁。小型合成检查用 CPU，实际分组与成对算术优先用有余量 GPU，单进程显存上限 3 GiB、保留至少 8 GiB 余量。

## 已核对的先例和边界

[ShapeSplat / Gaussian-MAE](https://arxiv.org/html/2408.10906v1#S4) §4.2–4.3 已使用基元分组和可学习特征池化；它提示 token 构造会影响学习，不能直接作为本五维 PE 的收益证据。本项等权几何矩不复现其可学习池化，也不以本文分数与之比较。

[Hierarchical 3D Gaussians](https://arxiv.org/html/2406.12080v1#S4.SS1) 式(3)–(4) 已用组内协方差与中心散布合并高斯；其后另定义面向投影贡献的权重。本项固定等权，不提出新的合并公式。仓库 R10–R13 等旧静态区域积分也使用过混合矩；本项不恢复该积分路线。若有后续贡献，应来自同信息强 PE 对照下可复现的学习用途，而不是矩恒等式本身。
