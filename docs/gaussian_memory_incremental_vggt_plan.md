# 增量高斯记忆与 VGGT 内部投影 PE：实施和验证计划

2026-11-10。状态：**计划已制定，尚未实现或启动训练；本文件不是实验结果。**

依据：[有关实现的讨论](codex://threads/01a1c599-183f-71a1-a01e-30705fb28c58?hostId=remote-ssh-discovered%3AGPU)，重点是增量结构讨论 `01a1c5ac-de9e-7931-9a85-eaee6fa8e1e9` 和随后纠偏、投影编码、内部 attention 讨论 `01a1c5b5-e0b8-7002-9bf7-c23774f92a60`。本次用户要求阅读讨论并制定具体计划，没有启动新实验的要求。

## 1. 本轮要完成的推进

把下一版收敛为：**一份可更新的高斯场景状态，在 VGGT 一个内部层通过投影几何 PE 和内容 attention 服务当前视图。**

分别回答两个问题，避免互相遮蔽：

1. 固定记忆时，历史内容和投影几何 PE 是否对 VGGT 的实际输出产生可学习、可迁移的帮助？
2. 固定读取方式时，吸收新的直接观测是否增加有用覆盖，并纠正初始错误，而不是放大错误或遗忘旧区域？

原来的“固定四参考覆盖 × 查询缺失”分析降为这两项实验的分层诊断，不再单独占用下一轮主线。保留 [Content Gaussian 工作基线](../results/gaussian_memory/content_center1/working_baseline.json) 及全部正负结果，不修改旧实验记录。

当前证据只支持有限的粗场景补充：Content Gaussian 相对匹配 Center 的开发误差降低 5.17%，主要来自整体深度偏差，完整输入的空间细节仍有反例。旧读取器是在冻结 VGGT 输出后另行预测粗深度；旧末层 token 恢复也没有建立稳定的整体收益。因此不能把旧分数当成内部 PE、增量写入或纠错已经成功的证据。

## 2. 第一版结构和边界

### 2.1 状态和观测来源

- 长期状态保持 **256 个高斯、每槽 32 维内容**：中心、形状协方差、opacity、内容，以及单独的观测支持/冲突记录。形状协方差描述区域范围，不用它充当估计误差的协方差。
- 初始状态复用现有 RGB → VGGT 几何 → patch 矩 → 256 槽压缩和 PCA 的思路，但按新的因果帧集合重新构建。首个内部读取实验冻结这些状态；原外部读取器及已训练 writer 检查点保留作历史/辅助探针，不把其旧分数直接作为新接口的性能对照。
- 第一版内容使用同一冻结 VGGT patch 特征和已有 PCA32；不同时学习新压缩器、位姿网络和几何 writer。增量融合先采用可解释规则。本轮可以证明内部读出可学、状态可更新，**不能据此声称网络已经端到端学会几何写入**。
- 已知相机内外参。短窗口固定为 **3 个最近的可写历史帧 + 当前帧**，各比较组获得完全相同的窗口。它同时为直接观测和 VGGT 原生尺度提供基线，不重跑全部历史。长期记忆的价值因此要超过同样拥有短窗口的对照。
- 直接观测分支完全不读 memory。写入时只接收窗口中“当前可写帧”的观测，历史窗口帧不重复计票。每项支持保留来源帧身份；重叠窗口不是独立重复观测。
- 短窗口用无记忆分支的预测相机基线与已知相机基线校准尺度，所有方法共享该尺度。世界坐标和归一化单位在初始化后固定；窗口预测先转换到该坐标再融合。禁止使用查询真值深度或每方法最优尺度对齐。基线退化须显式报告，并使用所有组共有的尺度无关辅助评价，不能悄悄删掉困难片段或沿用不相容的窗口单位。

### 2.2 将几何投影成 PE

对每个高斯按查询相机得到二维中心、投影协方差和深度。沿用已检查的投影实现，新增前向深度排序的 alpha 合成；这是 patch 网格上的渲染式近似，不声称是精确体积分或完整 RGB 渲染器。

令投影椭圆覆盖为 `alpha_j(u)`，按前到后排序：

```text
w_j(u) = alpha_j(u) × product_{k<j}(1 - alpha_k(u))
a(u)   = sum_j w_j(u)
e_j    = [相机坐标中心 / 初始单位, 相机坐标形状协方差的 6 个独立分量 / 初始单位²]
p(u)   = [sum_j w_j(u) e_j, a(u)]                 # 10 维
```

这相当于将归一化的几何描述再乘覆盖量，避免极弱支持被归一化为强信号。无覆盖为零；相机后方基元无贡献。几何描述只由几何生成，内容特征单独保存。位置和形状的标准化只用训练数据确定。opacity 首版保持原初值 0.7，不同时学习透明度。

上式的除法针对米制量；若记忆已存为初始化单位下的坐标，则直接变换到相机系，不重复除单位。

这一最小编码没有把物理协方差放进期望 RoPE 的振幅衰减，也不将任意外观向量的投影改名为位置编码。前后表面的混合、区域均值丢失多峰信息是待验证的限制。

### 2.3 明确内部插入点

首轮固定在 **`global_blocks[11]`（第 12 个 global block）**：

1. 在原有 Q/K normalization 和二维 RoPE 后，给 patch token 的 Q、K 分别加 `A p(u)`、`B p(u)`；A/B 是零初始化的无偏置线性映射。camera/register token 的 PE 为零。
2. 在该 block 输出增加一个 width64、4-head 的 memory cross-attention 残差：当前 token 为 Q，32 维内容为 K/V，输出映射回 1024 维并零初始化。首轮不再叠加旧 Mahalanobis attention bias，以免重复注入几何而混淆来源。
3. 继续经过后续 VGGT blocks 和原生 depth head。VGGT 与 head 权重冻结，但插入点之后的计算必须保留对适配器的反向梯度。

选择该位置的依据是代码接口，而不是试验选层：内部 token 为 1024 维；DPT 读取索引 `[4,11,17,23]` 的 frame/global 拼接表示。该位置可以影响 11、17、23 三个尺度，并留下后续层处理记忆。保持第一份 frame intermediate 的语义及输出索引正确。不把 2048 维最终拼接 token 当成内部 token。

代码依据：[aggregator](../third_party/vggt/vggt/models/aggregator.py)、[attention](../third_party/vggt/vggt/layers/attention.py)、[DPT head](../third_party/vggt/vggt/heads/dpt_head.py)。首轮不扫描层号，不解冻全骨干。

## 3. 数据和时序：先用本地数据开发

以 [content_center1 数据目录](../results/gaussian_memory/content_center1/plan.json) 的 85 个已用片段为来源，保留原 12 个训练片段和地点分组。其余数据属于已用开发评价，不能重新命名为独立确认。本次检查了文件存在性：前 12 帧 RGB 无缺失，下面四个查询位置的深度共 340 份均可从现有路径或深度索引找到；尚未重新解码和提取新缓存。

每片段按时间排序，以局部 0-based 索引固定角色：

| 角色 | 帧位置 | 用途 |
|---|---|---|
| 初始化 | 0、1、2、3 | 建立 M0，固定世界坐标和单位 |
| 后续可写观测 | 4、6、8、10 | 先预测，再从无记忆分支写入；进入后续短窗口 |
| 只读查询 | 5、7、9、11 | 预测和评价；训练地点可提供监督，但绝不写入或进入后续窗口 |
| 暂不使用 | 12 | 首轮不需要，不把未来图像提前用于记忆 |

例如读第 5 帧时，当前短窗口是 `[2,3,4,5]`；读第 7 帧时是 `[3,4,6,7]`。评价第 5 帧不会改变第 7 帧的状态。旧 `[0,4,8,12]` 联合参考缓存只保留作历史结果，不能用于这项在线实验。

初始缓存、每次写入后的记忆快照、只读查询输入各自记录来源身份。完整输入及两个固定 7×10 patch 遮挡条件复用原遮挡规则；遮挡先施加到当前查询 RGB，再计算窗口特征。其完整 RGB 不经另一分支进入遮挡样例。传感器深度只用于训练损失/评价，绝不进入可部署的状态构建。

## 4. 实验 A：固定记忆，验证内部注入

**假设：** 按视图对齐的高斯几何可以改善 attention 对历史内容的利用，并改善 VGGT 原生输出。**竞争解释：** 额外容量、当前短窗口已有内容或普通二维位置适配就能解释收益；也可能只纠正均值而损害空间细节。

固定同一个 M0。用 2×2 比较避免用未训练的 VGGT 独自承担全部基线：

| 组 | 内容 K/V | 新增 Q/K 位置输入 | 判断 |
|---|---|---|---|
| L：无历史记忆注入 | 当前短窗口的局部内容 | 固定二维位置描述 | 容量匹配的局部对照 |
| C：历史内容 | 历史高斯内容 | 同一二维位置描述 | 历史内容增量 |
| G：投影几何 | 与 L 相同的局部内容 | 高斯投影 PE | 几何信息自身的增量 |
| CG：历史内容＋投影几何 | 历史高斯内容 | 高斯投影 PE | 联合用途及相对 C 的 PE 增量 |

四组共用相同映射尺寸、初始化和采样，所有适配参数均实际参与运算。局部内容由每个窗口帧的冻结 patch 特征固定池化为 8×8，再用同一 PCA 得到 4×64×32，即同样的 256×32 内容预算。二维位置输入固定为归一化 u/v 及一、二倍频 sin/cos，共 10 维，使用与几何 PE 相同的 A/B 参数量。各组均保留原生 RoPE。额外导出零适配的原始 VGGT 作为绝对参照，但不将它替代匹配训练对照。

只训练本层适配器。种子固定 `20261110/11/12`，每组 2,000 步、有效 batch2、AdamW lr=3e-4、weight_decay=.01、gradient_clip=5，最终检查点评价。训练均匀使用原 12 个训练片段的四个查询位置及完整/两种遮挡条件；损失为原生 depth 输出在有效传感器像素上的 log-MSE，按样例等权，不再蒸馏末层教师 token。原始 VGGT 的尺度变换按 §2.1 固定并对所有组相同。

主比较是 CG−C 与 CG−L，使用未参与本轮训练地点的完整/遮挡混合误差；同时报告各条件、去均值空间误差与均值偏差。三种子和地点配对区间呈现不确定性，不能把 patch 当独立地点。51 个原非训练主地点继续分别报告旧 12、已用 20、已用 19 三批；其他训练地点片段和单个开发地点单列。

如果 CG 相对 C 有实际增量，再补 **CG-center**：同一历史内容、中心、opacity、映射容量和预算，只把形状/足迹改为训练数据固定尺度的球形点支持，三个配对训练。此比较用来判断是否值得保留高斯形状；A 的四组本身不能证明各向异性或 3DGS 形式优于点记忆。此控制的尺度只按训练几何事先确定，不根据结果扫描。

CG-center 检验形状描述和投影足迹的整体贡献，不单独归因于其中一项；新接口也不能继承旧外部读取器对 Center 的确认。

解释和决定：

- C、CG 均有效但相互接近：保留内部内容 memory，投影 PE 暂无独立依据，不增加更复杂的 PE 挽救。
- CG 比 C 和局部对照稳定更好，且没有相当量级的完整输入/空间细节损失：固定这套内部接法，进入集成确认；形状贡献仍由 CG-center 单独判断。
- G 有效而历史内容无增量：说明几何条件有用，不能宣称成功读取历史视觉内容。
- 只训练地点有效、整体有明显代价或各组无增量：记录本固定层/适配方式的限制。检查是否真正改变 attention、梯度和输出一次，不自动扫层、加模块或补种子。增量状态实验 B 仍可独立回答其问题。

## 5. 实验 B：固定读出，验证积累和纠偏

**假设：** 带有限历史权重、独立新观测和局部重建的更新，能吸收新区域并撤销旧错误。**竞争解释：** 结果仅来自更多输入；无限平均会锁死错误；表面看似改善只是遗忘/删除了困难槽；更新证据与旧错误相关，形成反馈。

### 5.1 最小更新器

1. 用已知相机投影关联新 patch 与旧槽，结合区域重叠和深度相容性；形状只参与空间关联，支持程度另行记录。
2. 相容观测更新中心、内容和二阶矩；合并协方差包含中心间散布。历史有效权重上限先固定为 4 个观测等价量，防止很老的估计完全压制新信息。
3. 保留最近 4 个可写帧的直接观测记录。初始关联采用 3σ 覆盖及 10% 相对深度相容阈值；两个不同的新帧持续矛盾才触发局部重建。它们是首版工程默认值，不是普适概率阈值，不进行结果驱动的网格搜索。
4. 只有“旧表面位于直接观测的可见自由空间”等可见性矛盾才否定旧槽；新前景遮住旧背景不能算作背景错误。不匹配的新观测也能形成候选，防止错误大到无法关联后永久失去纠偏机会。
5. 容量固定 256：优先合并同面重叠项腾出空间，再替换低支持且被重复否定的槽。不能仅因久未见到就删除；无法接纳的候选保留到有界窗口到期并记录覆盖损失。容量管理的失败也是结果，不偷偷增加槽数。

读取器不随每次更新重新训练。首先用保存状态的几何探针及既有外部读取器定位更新行为；实验 A 完成后，用固定 CG 和 C 内部适配器读取同一批更新快照，不重复拟合。外部探针的结果不能替代内部 VGGT 用途。

### 5.2 同信息、同预算对照

| 状态策略 | 可用证据 | 用途 |
|---|---|---|
| Static4 | 最初四帧 | 不吸收新证据的基线 |
| Incremental | 相同初始化＋截止当前的可写帧 | 实际候选 |
| Rebuild-prefix | 与 Incremental 完全相同的因果观测集合 | 每个时点从同一批缓存观测一次重建，判断在线压缩的代价 |

Rebuild-prefix 重用与增量组完全相同的直接观测，不把全部前缀重新联合送入 VGGT 改变观测质量。它是离线计算参照，记录更高的历史缓存/重建成本，不称严格上界。所有组的长期槽数和当前短窗口相同。

先比较干净初始化下四个时间点的 VGGT 输出、记忆可见覆盖和旧区域保持。增量优于 Static4 但接近 Rebuild-prefix，只支持“有界在线保留了更多观测的用途”，不声称更新算法比批量建库更准。

### 5.3 已知错误的恢复实验

冻结同一更新器，在 M0 的一个按初始位置确定的局部区域选择约 20% 槽，沿首相机深度方向施加固定偏移。主扰动为初始场景单位的 20%，5% 作为小误差辅助，另保留无扰动；不根据结果挑幅度。后续输入、源观测和遮挡与干净轨迹完全配对。

比较三种更新：不更新；无限历史权重的普通平均；上述有权重上限和局部重建的候选。其余关联和容量规则保持相同。这回答完整纠偏策略是否有用，首轮不宣称分别识别了截断权重与重建的独立贡献。

报告：

- 各时点扰动轨迹与同策略干净轨迹之间的几何投影差，以及固定传感器只读查询上的误差。前者是扰动恢复，不是几何真值；后者检验是否真的更接近观测。
- 受扰区域的覆盖、被修复/替换/删除的槽及来源，防止仅删掉难点就获得虚假的恢复。
- 查询 5 等早期只读视角在后续快照上的复测。它衡量旧区域保持，明确标为事后回访，不混入当时的因果预测分数；该图像始终不写回。

连续新观测没有看到受扰区域时，不能要求纠偏；按事先由投影和相机确定的是否被重访条件分别展示，保留全部片段。这只检验给定相机下的记忆错误，不验证位姿漂移、长期 SLAM 或动态物体。

决定：记忆自身误差和输出误差都降低且覆盖/旧区域保持合理，才保留纠偏方案；仅输出改善不称纠偏，追近干净轨迹却仍偏离传感器只称扰动恢复；与批量参照差距很大则优先修正更新器，而不更换 PE。

## 6. 执行顺序、预算和交付

1. **搭建共用接口和因果缓存。** 新建独立版本，保留旧实现。核对零初始化与原 VGGT 一致、无覆盖/遮挡前后顺序、模块梯度、尺度及读后写时序。只做会影响本轮解释的检查，不复活历史静态积分门禁。
2. **一次资源/可训练性小试。** 用原训练片段的前两个固定 ID，先 20 步测前后向与峰值，再同一配置做 200 步小样本训练，检查能否学动；小试检查点不进入正式比较。出现明显实现问题修复并保留记录，不把普通修复拆成科学新轮次。
3. **完成 A 的四组配对训练和 B 的固定更新诊断。** A 共 12 次 × 2,000 步；B 不新增训练，只改变保存的状态轨迹。两者独立解释，不要求一项全部指标获胜才查看另一项。A 有 PE 增量时最多新增 3 次 CG-center 配对训练。
4. **固定内部读出做增量集成评价。** 在相同短窗口、同 256 槽、同只读查询上比较 Static4/Incremental/Rebuild-prefix，报告准确性、纠偏、遗忘、状态大小和实际读/写耗时。初始短片段只支持有限的增量能力；若有效，再制定已有长片段回访及未用地点确认，不将本轮 85 个片段升级为新确认。
