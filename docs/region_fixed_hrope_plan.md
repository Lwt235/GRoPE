# HRoPE的逐区域学习变换是否提供额外用途

2026-11-10。上一轮十地点确认已经结束，完整五维F保持固定。下一步只补一个缺失的直接对照，避免把二维旋转或注意力作用层带来的效果误认为预测局部几何的效果。此计划在新对照训练前固定，只使用最初576 fit / 64 val / 480旧开发帧对，不访问刚完成确认的十地点或其他确认缓存。

假设：在相同二维旋转、self/cross位置和Q/K/V/输出变换下，HRoPE的逐区域学习变换仍提供有幅度的对齐收益。竞争解释：现有领先主要已能由固定相机变换与二维旋转传输解释。该问题直接决定是否有理由进一步研究高斯参数化的学习型局部变换；它不是再次分解五维分量，也不把任何结果当成新的高斯方法成功。

唯一新增模型为`fixed_hrope`：用常量R=I、t=0、n=(0,0,1)、κ=0.25替代原96→13预测头，因而H=K。同一相机下的几何相对块为恒等；不同K时仍保留K_i K_j^-1。其余全部复用原HRoPE前向，包括24维几何块、24维二维旋转、频率与坐标尺度、两层self与两层cross、Q/K/V和聚合输出变换。它不能简称标准Q/K-only二维RoPE。仅移除1,261个预测头参数，公共网络保持316,081参数；不添加容量补偿模块。

从同种子完整HRoPE初始化构造后将预测头替换为常量buffer，保持公共初始化和随机数消耗。新增种子11/22/33三次训练；严格复用原60周期/1,080更新、batch32、验证batch16、AdamW与学习率计划、每3周期验证CE选模。数据、几何增强和排列不变；逐种子检查与已有HRoPE及其他四方法的公共初始化和60条样本增强流一致。全部三模型选定后才导出旧480帧对。已有15模型、预测、几何评分和诊断原样复用，不重训或改写。

主比较为`predicted_hrope − fixed_hrope`；次比较为F−fixed_hrope、fixed_hrope−Distance、fixed_hrope−Geo。10,000次配对种子×整场景bootstrap，固定种子97001–97004。主指标仍为全部源区域中心对齐RMSE<0.2米，地点等权再种子等权；同一64对应、41,664三点假设、0.1一致性半径、最多5次非恶化重估。完整保留区域R@1、全查询正确率、中心PCK、soft EPE、旋转/平移/RMSE中位数及p90，不用辅助指标替代主指标。

若主差至少+1 pp、三种子均正且联合区间下界>0，支持学习变换在当前接法中的额外开发用途，下一设计才有理由针对这一作用构造高斯参数化；仍不能证明单应结构独特或预测几何真实。若反向满足对称条件，说明更简单固定变换在本任务更好。其他情况保留幅度与不确定性，不宣称等效、不追加种子或搜索旋转尺度。各分支都结束这项控制，不自动启动新地点验证或叠加F与HRoPE。

R50/R53已测试过潜在高斯局部框架，未证明完整形状稳定优于球形/仿射；不能将其重新命名后重试。本轮只检查当前未知位姿区域任务的一个未分离因素，不推翻这些旧负结果，也不复现HRoPE完整论文系统。

必要检查仅新增：常量头与原HRoPE初始变换/前向等价、公共梯度和初始化一致、旧fit上的GPU训练可用。复用已有数据/公式/求解器检查，对新增预测和几何评分独立复算并查看完整学习曲线。原始得分和源码保留；普通工程修复留版本记录。GPU启动前连续确认空闲与CUDA访问，最多四工作进程，允许在本轮独占卡上并行小任务。显卡查询超时仅延迟新任务启动，不终止已运行工作；没有待启动任务时不继续查询显卡。保护外部任务，不比较共享运行时间。
