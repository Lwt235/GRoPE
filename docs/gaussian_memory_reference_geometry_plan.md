# reference_geometry1：参考侧传感器几何辅助的固定对照

2026-11-10，训练与评价前固定。本轮承接surface1的负结果，用同一模型区分“参考几何不可靠”与“当前紧凑读写仍不能兑现信息”。这是有传感器辅助的诊断，不是最终可部署方案，也不声称有缺测传感器构成严格性能上界。

## 假设、竞争解释和固定干预

假设：只提高参考侧初始几何质量，就能使原有256高斯写入和attention读取在非训练地点产生可靠增量。竞争解释：冻结的分组/内容、压缩或读取方式限制信息利用；原方法的问题不能仅靠初始几何更准解决。

使用原46片段、参考帧0/4/8/12及已知相机。在原VGGT四参考的1200个patch上，用参考传感器深度计算世界坐标均值与协方差：PIL最近邻缩至210×280；0.1–10米像素有效；每14×14 patch至少一半有效时，以有效点计算矩，否则沿用该patch的VGGT几何。噪声正则项与原型相同。

原GPU FPS及8邻居权重已从缓存逐值恢复，46片段的256种子均值/Cholesky与旧缓存差为零。沿用这些成员和权重合并修正后的patch矩。**只替换seed_mean/seed_chol**；seed_context、seed_teacher、256槽位预算、查询token、相机、尺度、标签、掩码、网络与优化均保持原值。不按传感器几何重新分组，不删除困难场景。所有参考传感器来源及修正覆盖率单独记录。

冻结原分组能隔离输入几何变量，但原错误分组可能仍混合多个表面；本轮负结果因此只限制这套固定压缩/读取接口，不否定重新建立场景结构的可能。原S4参考上下文仍含VGGT先验；本轮也不是去除所有旧几何影响。

查询RGB从不参与记忆构建，查询传感器深度仍只作监督/评分。参考传感器输入与查询标签分开存储与核查。保留source身份、已知相机和缺测限制，不将有传感器辅助的收益称RGB部署收益。

## 对照与预算

- 新增传感器辅助的Fixed、Center、Gaussian，各三个种子20261110/11/12，共9次；从surface1对应初值开始，复制原2000步、batch2、AdamW3e-4、weight decay .01、clip5以及逐步采样。
- 复用surface1的Local/Fixed/Center/Gaussian十二模型。Local没有被更改的几何输入，直接作为共同强基线。
- 主比较：传感器Fixed−原Fixed、传感器Gaussian−原Gaussian，及两个传感器版本对Local；辅助比较传感器Gaussian对传感器Fixed/Center，区分几何写入与形状位置项。
- 固定两种训练几何×两种评价几何的交叉读取：原模型读取修正几何、新模型读取原几何，只作分布敏感性诊断，不能代替匹配训练的主比较。
- 新模型正常读取/移除记忆/打乱内容空间绑定/错误读取相机/恢复本组初始几何，以及两种初始几何的无训练读取。均不调参。

仍为十二训练地点各一片段、72训练查询/288遮挡；46片段、288评价查询/576遮挡和完整查询。主评价十二非训练地点各两片段按地点配对，均为历史开发数据，无新确认。主指标有效patch的对数米制深度MSE；遮挡/可见、RMSE、AbsRel和完整输入同时报告。跨视图不一致性只与准确度联合解释；沿用surface1的偏置/空间残差分解，防止把一致但错误的输出当成功。

## 结果改变的决定

1. 传感器辅助在匹配训练后稳定改善原几何组并超过Local：初始参考几何是实质瓶颈，下一步定位可部署几何误差，不添加读取模块。
2. 改善原几何组但仍不能超过Local：几何质量有作用但不充分，保留条件证据，不宣称方法有效。
3. 修正充分而没有可靠增量：关闭“仅修正初始几何即可挽救当前接口”的假设；下一步针对分组/压缩或读取设计可区分实验，不继续补种子或扫描形状参数。
4. 修正覆盖有限或混合表面严重：明确这项条件诊断的限制，不把不足的oracle外推成路线不可能。无论哪个分支，都不由本轮自动开启另一轮训练。
