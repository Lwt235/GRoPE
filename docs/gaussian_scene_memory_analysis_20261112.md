## 判断

目前证明了可保存的粗3DGS能够接入VGGT，并且读取会依赖内容—几何对应；尚未建立这种记忆比匹配控制更有用、或投影PE比同内容中心PE更有用。最值得优先回答的是：**可靠来源几何及其一致特征绑定，是否能改变当前PE比较的结果？**

不是因为数值精度瑕疵而拒绝方法。全部15次训练正常完成；G对P的主误差均值高6.97%，三个种子分别高3.06%/9.08%/9.04%。地点区间跨零，不能声称总体必然有害，但没有可靠收益可晋升。P/C对L约1%的平均改善同样不稳定。约1%不是通用门禁。

完整输入全图AbsRel中G对P/T平均低6.04%/6.46%的辅助迹象保留，但第三种子翻为退步、区间跨零；对同容量无历史L仅低0.032%。大幅原始误差改善中，L已对未适配当前图像下降90.38%，其ROI空间误差反而高6.60%。这些结果说明共同适配和整体偏差必须与历史几何收益分开解释，不能由某个单项指标宣布成功或失败。

原绑定优于打乱绑定、原相机优于平移相机，支持模型使用对应信息；**“原绑定”不等于几何已经准确**，对人为破坏敏感也不等于产生净收益。完整数值与不确定性见[原报告](../results/gaussian_memory/gaussian_scene_memory1/report.md)。

## 可能原因与证据强弱

### 1. 来源场景的几何及公共坐标误差是首要可疑因素

AnySplat同时从图像预测高斯及输入相机，并不天然输出传感器坐标系下的正确场景。[官方论文](https://arxiv.org/abs/2505.23716v2)。当前实现随后用来源相机的单个Sim3对齐；一个整体旋转、平移和尺度不能消除逐视图之间的相对位姿误差。

重新汇总已有记录：训练/旧开发来源旋转残差中位数为2.62°/4.74°，均值2.36°/13.98°；训练最大4.03°，开发中brown_bm_1和brown_cogsci_1分别33.70°/85.94°。对应两个开发地点G对P主误差高48.77%/33.51%。来源中心残差的训练/开发中位数为0.108/0.218m，米制残差还受场景尺度影响。

因此C5应准确理解为：给定相机降低了查询定位变量，**没有消除来源场景重建及配准误差**。训练与开发中的来源几何质量不同，可能使读取器在训练时学到对几何的依赖、在开发时被错误投影误导。这是基于已有记录的解释，不是已确认因果关系：例如home_md旋转残差仅1.79°，G仍退步；位姿残差也不能完整衡量局部表面误差。

全部12地点保留在[描述性复算](../results/gaussian_memory/gaussian_scene_memory1/followup_analysis_20261112/summary.json)；不按结果挑出“好几何子集”，不拟合质量阈值或将其称为确认。

### 2. 粗化与特征写入仍可能损失局部对应

2048槽是一次很强的粗化。48个开发查询有5个整视角无投影覆盖；已经实际查看的fidelity_00图中，来源拟合虽降低RGB误差，却呈现近乎平坦的颜色和模糊重观察。原始公共坐标GS在部分视角已失真，粗化与拟合又改变了载体，不能只归罪于容量。

1024维保留的是通道维度，不保证保留逐表面细节。按alpha对多个来源patch加权写入，在几何或遮挡有误时可能混合不同表面。覆盖部分特征cos约0.919是载体代理，不证明准确对应、原生深度收益或优于一个简单的特征平均参照；当前没有后者的匹配诊断，不能替它补结论。

### 3. 目前的PE比较同时包含固定与可学习规则的差异

P用可学习的中心—射线MLP，G用固定的`log1p(Nw)`、在四层和所有head使用同一投影偏好。P可学习弱化无用的几何描述，G若遇到错误几何，需要依靠内容logit或整个残差通路来补偿。

因此当前结果约束的是这两个具体读取规则；不能把G的失败直接解释成协方差或opacity信息没有价值。这个解释来自[实现](../models/gaussian_scene_memory.py)，尚无独立消融证明。当前不建议同时增加可学习温度、门控和新模块，否则难以判断哪一个变化起作用。

### 4. 接收网络与训练目标也可能限制用途

T保存较直接的来源token，仍未可靠超过L，因此不能把全部问题归为高斯压缩或投影PE。冻结VGGT/DPT、在不同深度共享一个读取器，以及全图训练损失与缺失ROI主终点的差别，都可能使优化更容易实现整体校准而不是局部几何补充。15次训练损失和梯度正常，只排除了明显未训练/梯度断路；没有证明泛化充分，也没有证明解冻decoder必然有效。

来源GT支持约77.56%说明很多缺失区域存在来源观测机会，但不保证特征保存和读取都成功。当前证据不足以选出writer、PE或decoder中的唯一病因。

## 下一步建议：一个固定的来源几何质量对照

**大纲对应核对：** 服务O2/O3的公共场景保真及O4–O6的读取/PE用途；暂时改变C1的场景构建输入与初始化，保留C2的alpha特征绑定、C3/C4的读取规则和C5/C6的给定相机、静态来源、冻结骨干。源传感器深度仅作为额外的诊断条件，不是导师大纲的新增要求，也不是可部署RGB方法的成绩。已核对raw_history_information1的传感器/预测投影差距、address_intervention1的对应地址干预阴性，以及本轮完整负结果；区别是对两种场景质量进行**匹配训练**，并在每种场景内比较P/G，而不是仅统计覆盖或对冻结模型改地址。

假设：来源几何和由此产生的绑定误差，压制了投影PE相对中心PE的潜在增量。竞争解释：中心编码已经足够；精细位置关系不是当前特征所需；固定投影规则或冻结接收网络不能利用更好的场景。

建议在同一个、由给定来源相机反投影的粗高斯构建接口中，只切换来源深度：

| 来源几何输入 | 中心PE | 投影PE |
| --- | --- | --- |
| 已有AnySplat来源预测深度 | P-pred | G-pred |
| 已有来源传感器深度 | P-sensor | G-sensor |

两行都用给定来源相机建立场景，避免把“换构建算法”和“换深度质量”混在行间。两行采用同一来源像素候选与有效性规则、2048槽、相同尺度规范、协方差初始化规则和有界来源拟合；各行P/G使用完全相同的保存场景与内容。源传感器深度会改变几何及后续alpha绑定，所得作用不能进一步拆成纯几何和纯内容两个独立因果效应。传感器也有缺测与标定误差，不能称完美oracle或理论上界。

查询RGB、深度和教师特征均不进入建图。查询标签仍只用于共享读取器训练和最终评价，查询传感器几何不用于构造测试时地址。使用旧12训练/12开发地点、相同四来源/四查询和两输入条件；固定三配对种子、各2000步，共12次拟合。原L可按相同输入/训练身份复用，原T及原AnySplat场景P/G保留为背景，不把额外传感器输入的成绩包装成对RGB系统的公平领先。

该表是**建议草案，尚未冻结可执行配置**：具体来源候选、缺测处理、协方差初始化和拟合约束应在原两个训练片段上具体化并记录，再开始开发评价；不看开发分数选择参数。不得只把传感器场景临时塞入旧检查点，因为这会混入未适配输入分布的影响。

同时报告源几何一致性、场景重观察和原生输出；它们在同一轮完成。来源几何/绑定是否实际得到改善，是解释干预是否生效的依据，**不是新增“先过渲染分数才准训练”的门禁**。

固定主问题为两个PE差值及其变化：`Δpred = error(P-pred) − error(G-pred)`、`Δsensor = error(P-sensor) − error(G-sensor)`；正值表示G更好，比较`Δsensor − Δpred`。保留原缺失ROI空间主终点、原始/偏差/完整输入、地点等权和配对区间，不选有利指标或排除失败场景。

| 固定结果 | 支持的解释与下一项决定 |
| --- | --- |
| 来源几何确实改善，G相对P的增量也可靠改善 | 场景可靠性影响此PE规则的作用；下一项聚焦不依赖来源传感器的可靠构建，尚不能宣称RGB方法有效 |
| P/G共同改善，但G仍不优于P | 更可靠场景内容有价值，当前投影PE尚无增量；优先保留简单中心读法，停止为投影PE找胜出指标 |
| 几何与重观察改善，原生用途仍无改善 | 上游质量不足不能单独解释结果；下一项才值得针对接收接口设计一个变化，如直接渲染特征的匹配读取，不自动解冻全部网络 |
| 来源传感器输入没有改善保存场景的几何/绑定 | 诊断操纵本身未达到目的；不能据此否定接收网络或全部高斯PE，保留失败并结束该次固定诊断 |

本建议不追加本轮种子、容量或温度扫描，不启动未知相机/在线更新/新数据确认。此次分析没有产生新模型预测或新效果确认。


## 后续实际结果（有限验证已完成）

**当前状态（2026-11-12）：source_geometry_control1有限验证已完成。** 48份来源状态、四组各三种子2000步（12次训练）、1152份适配预测及1728份干预全部完成；2880份新预测独立复算、三张最终图已实际审阅。来源质量改善有有限正证据，但投影PE增量和相对L的可靠净用途未建立，结束此固定诊断，不晋升G或自动开展后继任务。

P-sensor对P-pred的缺失ROI空间误差低4.27% [0.71,11.91]%，三个种子同向，说明中心PE读取器能利用来源几何及绑定的质量改善。G对P在pred/sensor条件主误差平均高6.62%/5.02%，区间跨零；主交互+0.000453，区间[−0.001950,+0.003349]，未建立质量解锁G优势。G-sensor对L平均高0.63%；P-sensor对L低4.18%但区间跨零。

完整输入ROI中，G对P在pred/sensor条件的空间误差高17.64%/19.25%，区间均支持增加。传感器源场景直接深度AbsRel平均低44.25%，但空间质量和特征重观察未全面改善，不能称精确oracle。两行共同有效性也使用传感器信息，均是额外来源信息的旧数据诊断，不是纯RGB方法成绩或新确认。
