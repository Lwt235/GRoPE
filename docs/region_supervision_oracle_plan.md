# 区域监督与中心几何读出的相容性：真值辅助控制

2026-11-10，在新构造的对应送入求解器之前固定。较大二维位移没有增强五维相对固定旋转的收益；旧fit诊断又表明区域对应不等于精确中心对应。本轮直接检查现有区域监督的理想top1输出是否能支持原几何读出，避免未经验证就改模型、监督或求解器。

**假设：** 即使有理想的区域对应，区域中心之间的偏移仍使原中心求解器明显受限，监督与读出不匹配值得优先验证。**竞争解释：** 原区域标签给出的理想对应已足以高成功率对齐，当前主要差距留在学习模型取得和利用对应关系的环节。两者都不等于已经证明某个PE是唯一病因。

## 两个新增不可部署参照

只使用最初五场景480个旧评价帧对、已有区域overlap标签与旧评分真值。保留所有64个源查询。对于达到原有效阈值`max(overlap)>=0.3`的查询，选择最大overlap目标，这正是原soft目标理想预测的top1集合。

- 主参照`overlap_nearest_tie`：只在最大overlap完全相等的候选中，用真值变换后的中心距离选最近者。它给区域标签最有利的中心接法，避免索引排序造成的任意并列选择被误认为语义冲突。
- 次参照`overlap_first_tie`：最大overlap按原argmax规则选择最低索引，作为并列敏感性控制。

**两者对无有效区域标签的查询都使用同一既有GT-nearest对应。** 这些查询未受原区域损失直接约束；给它们同样的真值帮助，可以把两项参照与原GT-nearest之间的变化限制在有效查询的区域最大重叠选择。它是乐观控制，不模拟真实模型，也不是理论上界。没有有效区域查询的帧对会与GT-nearest保持完全相同的对应。

所有64个对应都交给原`region_pose_solver.estimate`，保留41,664个三点假设、0.1半径、最多5次非恶化重估以及原RMSE<0.2米成功标准。不按真值删查询、不调求解阈值、不新训练或推理。原GT-nearest、恒等参照与18个学习模型的结果只复用。真值仅在这些明确标记的诊断对应生成中使用，不能把诊断成绩加入可部署PE排名。

## 固定报告与后续决定

主比较为乐观区域参照−GT-nearest，另报最低索引版本−GT-nearest及乐观版本−最低索引版本。先场景等权；两项新参照是确定性的，不人为补神经网络种子。按整场景配对bootstrap 10,000次，随机种子99101–99103，报告逐场景成功率、差值、中位与p90、有效查询数、并列比例以及相对GT-nearest改变的对应数量。

同时沿用刚完成诊断中已固定的低/高/undefined分组，只作描述性可解性对照，不重新检验或挽救“大位移五维更有优势”的已关闭假设，不增加新分组和阈值。

- 若主参照比GT-nearest下降至少10 pp，至少4/5场景下降且场景区间上界<0，说明值得优先设计一个所有PE共用、与区域几何相容的读出控制；这不证明它能提升真实模型或五维能获益。
- 若主参照成功率至少75%、相对GT-nearest下降不足10 pp，则区域监督的理想输出已能支持较高对齐率，后续优先研究模型取得对应关系的能力，不凭本诊断重做求解器。该实用决定不构成等效检验。
- 其他结果保留混合解释，不立即改主方法。10 pp和75%只用于决定下一项工作方向，不是通用方法通过标准。

模型、损失及PE完全不变。独立检查限定于对应规则与并列处理、原GT-nearest两帧对的GPU回放、独立几何评分和既有结果身份。求解适合GPU，启动前连续检查空闲或已有授权下的资源余量（至少12 GiB、利用率不超过60%，至多一个共享工作进程），CUDA探测后再核对；保护其他任务。数值小误差只在影响成功判定或结论时升级处理。
