## 1. 路线判断

优先保留 VGGT 家族，采用已训练的 StreamVGGT 原生历史通路作为下一项验证载体。Point3R 提供显式场景记忆与强三维位置编码参照；暂不同时铺开两套模型训练。

研究问题仍然是：**同一份有用的场景内容，附加高斯的范围和方向信息，能否比强点位置编码更好地服务 Transformer？** 深度输出检验信息有没有被有效利用，不把本项目变成渲染质量或通用重建排行榜研究。

当前实验支持空间寻址参与读取，但对应地址干预没有优于原读取的可靠增量。它没有定位唯一病因。旧接法同时包含规则合并、PCA32内容、新的64维读取残差，以及冻结的接收网络。因此，同一接口上继续调整地址公式，不能区分内容损失与网络利用能力。

这也不能简化成“只要换高维内容就行”：`direct_reference1`、`reference_encoding1` 已检验过高维参考内容的末层恢复接法，`state_read1`、`history_visibility_train1` 已检验过状态和遮挡训练匹配。它们的负结果保留。下一项的实质变化是**使用经过因果训练的原生多层记忆通路**，而非重做这些控制。

## 3. 下一轮：native_history1，零训练验证原生历史通路

### 假设、竞争解释与固定范围

**假设：** 之前未能有效利用的历史，在已经训练过的原生K/V通路中能够改善当前缺失观测下的预测。竞争解释是：本批历史缺乏新增信息、人工遮挡/稀疏采样偏离预训练分布、预训练模型也不能充分利用这些历史，或收益只来自尺度变化。

复用 `history_visibility_control1` 的12个fidelity地点、query11、完整和持续遮挡两个条件。全部是已用开发数据。官方模型只有一个固定检查点，不把重复推理当作多个训练种子。

官方[代码与权重入口](https://github.com/wzzheng/StreamVGGT)、[模型仓库](https://huggingface.co/lch01/StreamVGGT)已核对。本地尚未发现StreamVGGT安装或权重。实施时固定上述代码提交、权重revision与哈希，先用官方推荐的518最长边预处理，所有新组共享同一输入映射；不能将旧低分辨率分数作为直接配对对照。

### 四组固定比较

索引沿用每个旧片段的0-based帧编号。所有组使用相同首帧0作为锚点；当前查询只读、不写回。完整条件读取原图；持续遮挡复用原late4/6/8/10和query11的物理遮挡区域，经统一预处理映射。首帧0内容在各组相同，不暗中给予History独有坐标锚点。

| 组 | 构建与读取 | 回答的问题 |
|---|---|---|
| R：锚点＋近期 | 从RGB独立重放 `[0,4,6,8,10,11]` | 同锚点短历史基线 |
| H：完整因果历史 | 重放 `[0,1,2,3,4,6,8,10,11]` | 增加1/2/3帧是否产生实际用途 |
| H-mask：同长度、早期内容遮挡 | 与H相同，但将1/2/3帧中投影到查询ROI的来源patch遮挡，之后全部重编码 | 改善是否与早期可见内容有关，而不只是序列长度 |
| H-drop：只撤掉最终直接读取 | 沿H重放到10，query11前移除1/2/3的直接缓存项；保留其余状态 | 最终输出是否依赖这些直接缓存项；这是辅助扰动 |

12地点×2条件×4组，固定**96份最终查询输出**。H-drop不能替代R：后来的特征本身可能已经包含早期信息。删缓存需同步处理各层与相机头中的相应来源及帧身份；首帧和当前帧处理保持一致。检查官方缓存路径的无修改回放及一个短序列的因果批处理对应即可，不扩大数值门禁。

H-mask采用既有传感器投影规则生成输入遮挡，不按查询预测成绩挑选像素；这是人为控制条件，模型不能读传感器深度或真值对应。首帧锚点本身可能覆盖ROI，所以重新报告1/2/3相对共同锚点和近期来源的新增支持。保留零新增支持地点，不将旧“早期0..3独有覆盖率”直接搬到本轮。

### 评价、资源与取舍

主比较为持续遮挡ROI的H对R；H对H-mask辅助解释早期内容作用。全图、可见区、去均值空间误差及均值偏差共同说明代价，完整输入是正常条件对照。主要使用模型原生尺度的深度log-MSE和AbsRel；若需尺度辅助指标，单列预先固定的每序列对齐结果，不用对齐后的改善替换原生主分数，也不套用旧VGGT的模型尺度到新检查点。

逐地点配对重采样，报告效应量、区间及地点方向；固定前三片段与最大退步地点作图。原生输出有改进才支持任务用途；缓存删除敏感或来源覆盖增加单独只能支持机制线索。不要求每个辅助指标、每个地点都获胜，也不把微小数值差当新失败。

- H有实际改善，且H-mask支持早期内容的作用：建立本条件的原生历史基线，转入同内容的高斯PE比较。仍不证明原方法只败在PCA或单层接法。
- H仅在少数地点或只改善整体尺度：保留有限范围，下一阶段以该范围为开发假设，不能称精细历史补缺成功。
- H并未建立用途：结束这一有界原生基线验证，结合源支持和缓存移除判断是否被共同锚点饱和、是否需要不同观测条件或读取载体；不据此启动一批高斯公式或压缩扫描。Point3R可作为随后一次显式记忆载体验证的备选，而不是同时展开第二套训练。本结果不作为所有PE研究的永久前置门禁。

## 4. 随后的方法设计：原生内容＋高斯空间地址

候选结构保持精炼：`空间状态(μ,Σ,来源身份) + 原生特征/KV → 带位置项的原生attention → 原生输出`。先保留原生内容，不同时做PCA32、强制均值合并和新解码器。初次PE比较使用完全相同的来源token、内容维度和数量，不先加入新的压缩损失；这一阶段尚不是紧凑高斯场景表示已经完成。

同一载体内比较：原生位置项、中心3D RoPE、中心＋各自尺度球形、中心＋完整协方差。球形保留相应高斯的迹，帮助区分仅范围大小与方向/非球形关系。完整高斯候选使用独立的形状位置项，不把物理协方差再塞进RoPE幅度衰减。保持全局内容读取，几何提供偏好，不重新引入硬可见性排除。

这四组必须同内容、同来源、同可训练范围和训练预算；中心不能只用一个弱距离惩罚代替Point3R式强3D编码。移植的是位置机制，不能称已经复现整个Point3R。接收网络若需适配，所有组共同适配，不能让高斯组独享解冻层或监督。

查询三维位置及区域必须来自因果可获得的预测，例如上一观测的pointmap；不使用查询真值深度。投影式方案若使用已知查询相机，所有控制共享相同信息，并明确为条件性结果。具体形状映射、查询几何规则和适配预算须在该阶段评价前固定；本次先确定原生通路是否有用途，不在尚无可用基线时预定一批PE扫描。

预定收益假设是不同观测尺度、斜视区域及部分重叠下，范围/方向比中心点提供更多读取信息。分层规则只依输入几何/训练统计确定；全部普通条件仍报告，不能按哪组获胜反向选场景。

只有PE增量值得保留时，再研究固定预算的场景压缩与在线更新。届时采用相同总字节数的普通token/KV和高斯状态对照，并把持久存储与读取预算分开报告；同槽数不代表同存储成本。初始可采用保留代表内容而非按空间位置强制平均的控制，再决定是否需要可学习融合。不直接叠加M3记忆库、Slot3R多槽和额外门控。

已有区域PE正面证据、粗记忆读出的有限用途以及全部原生内部接法负结果继续保留。未用地点确认安排在方法和条件固定之后；本轮12旧地点不能重新命名为确认数据。

## 5. 最近的明确交付

先交付 `native_history1` 的96份输出、来源/尺度说明、一张主比较表、固定正反例和真实缓存成本，回答：**当前数据中的历史，在原生已训练通路里到底有没有可用价值？** 这项结论决定后续高斯PE比较是否有合适的载体，而不是以更多注意力代理分数延长旧分支。

实施前补充：本批原图经官方crop预处理为518×392，原生深度以双线性映射回280×210的既有传感器评分网格；原物理ROI保持不变，不使用任何旧模型尺度或新拟合尺度。主误差另分解缺失ROI内部的去均值误差和偏差平方，避免只看全图分解漏掉区域尺度变化。官方相机头在每帧四次迭代均追加缓存，H-drop按来源同步移除这四份条目；保留官方行为，不修改其缓存算法。

H-drop相对R也作为事前辅助比较：两者最终直接缓存数量相同，前者后期状态仍编码了早期信息，可量化这部分间接保留的用途。它与H对H-drop的直接缓存比较共同解释信息通路，不替代H对R的整体用途主比较。

解释范围：R本身已保留首帧0及近期历史；H对R严格检验的是额外1/2/3帧在共同锚点之上的净增益。阴性结果不能写成“原生记忆整体无用”，更不能说明高斯PE无效。共同锚点可能已经提供足够信息，这也是必须保留的竞争解释。
