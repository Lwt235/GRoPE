## 问题和固定比较

假设：目标查询读取参考内容时，投影后的区域支撑关系有助于学习。
竞争解释：只需投影中心；直接矩阵 MLP 已足够；相机射线投影已足够；
当前小数据图像模型的瓶颈与 PE 无关。没有理由把改变接法预称为成功。

先做给定参考深度的解释性开发实验，不把它视为 RGB-only 或原生优化 3DGS。
12 次拟合：observed_target_distance、observed_target_direct、
observed_target_relative5、observed_urope，各种子 11/22/33。
R70 observed_prope 的三次训练和预测按身份复用为公共基线，不计为新独立证据。
同时展示 R70 observed_relative5，不以跨轮改动唯一归因于接入位置。

同一 R70 288/32/240 旧三元组，3/1/5 场景，96×128，patch 8，
6 层宽 192 的同一 LVSM 骨干、完整共同几何内容与输入流；
60 epochs/2160 updates、AdamW、纯 RGB MSE、验证选模、三种评价条件均继承 R70。
全部 12 个模型选定后才导出 old_eval。所有比较包含全部三种子和五场景。
不读取未用场景、不追加预算、不扫描投影尺度或温度。

## 投影关系，保持一个 MLP

参考高斯先转到目标相机：m=Rμ+t，S=RΣRᵀ；用透视投影中心 u 和
投影 Jacobian J 得到 C=JSJᵀ+10^-8 I（归一化图像坐标 x/W,y/H）。
这是局部矩近似，不是精确投影概率积分，也不处理完整可见性/遮挡。
目标 patch 中心 p 已知，其均匀面积二阶矩 Q=diag((8/128)^2,(8/96)^2)/12。
δ=p−u。五维沿用相同关系：

`[||δ||/.2, log1p(δᵀQ⁻¹δ), log1p(δᵀC⁻¹δ),
  log1p(tr(Q⁻¹C)), log1p(tr(C⁻¹Q))]`。

Distance 输入第一项；Direct 输入 δ/.2、第一项及对称 log(C) 三维
（Q 对所有 token 相同且已知）。三者都是输入→96→192 的 GELU MLP，末层无偏置。
因 Q 固定，五项可能代数相关；此轮不将维数本身当作新颖性。
三者均使用同一投影、共同内容和有效性规则。目标相机深度 <=0.1
（本仓库坐标单位3m）、参考 coverage=0 的 pair 只将额外项置零，
保留基础 PRoPE attention，不删 token；不按图像颜色或目标深度筛选。
不裁剪正深度的离屏中心，不通过可见性 oracle 排除难例。

仅给 **目标 query→参考 key** 添加 q·r/√48；其余 attention 保持 PRoPE。
不保留 R70 的参考—参考附加项，不增加渲染器、解码头、损失或模块串联。
保留直接 r 张量计算以避免混入 bf16 代数重排；本轮不宣称速度优化。

## 结果改变什么决定

主比较仍为 base 场景等权 PSNR，SSIM/LPIPS 同时报。
relative5 相对 Target Distance、Target Direct、observed_prope、URoPE
均需三种子 PSNR 正向、均值 ≥0.10dB，LPIPS 均值不更差，才推进 RGB
预测几何版本和后续未用数据确认。若只胜部分对照，报告局部价值但不晋升。
不要求每个次指标、每个场景微小差异同号。
若投影距离/直接 MLP 有效而五维无额外价值，将收益归为坐标/接法，
不归为高斯形状；若全部无用，停止这条小模型投影接法。
若都学不到可靠细节，承认用途证据有限，不靠新门禁或无限拟合解决。

## 与结论相称的检查及执行

正式拟合前：独立投影/有限差分 Jacobian、正定矩、五维手算、
目标 RGB/深度接口拒绝、共同初始化、URoPE 坐标/公式等价、CUDA 有限梯度及代价。
只修实现问题并记录，不按预检损失选配置。冻结源码、数据身份和固定设置后训练。
结束后：输入流/选模检查、保存图像独立 PSNR/MSE 复算、逐种子与场景汇总、
固定首例图像实际查看。没有新增静态积分、超高精度或外部审稿门槛。

使用用户授权的 GPU1 共享串行策略，启动前检查至少12GiB空余；
不停止其他用户作业。共享耗时不作为公平速度排名。整体研究目标仍未完成。
