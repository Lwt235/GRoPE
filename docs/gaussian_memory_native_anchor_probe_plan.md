# 当前观测保持尺度、历史提供相对结构：下一项固定诊断

2026-11-11。由 `history_read1` 完整结果提出；用户再次要求“明确下一步计划后将其设为目标并执行”，现建立有限目标 `native_anchor_probe1`。本文件规定一次旧数据上的开发诊断，不构成未用数据确认或已验证的新方法。

## 为什么先做这一项

固定 Soft-dynamic 在累计重建 Prefix 下，保留早期历史使主 log-MSE 从 0.164595 变为 0.164797，几乎持平；但预定去均值空间误差降低 9.25%，三个种子、11/12 地点改善，配对区间为正。空间项降低 0.001926，同时平均 log 深度偏差平方增加 0.002128，抵消了整体收益。高斯组相对强 C 的空间优势仍不确定，不能直接宣称 PE 成功。

Corrective 另有容量吸收问题：末态平均 243 槽含早期来源，只有 27 槽含晚期来源。Prefix 改善了当前覆盖，却没有建立整体历史收益，因此暂不根据容量统计直接修改更新器。

**假设：** 当前观测提供较可靠的整体尺度，历史读取包含可利用的相对结构；约束它只改变相对结构，可能保留空间收益并减少尺度漂移。

**竞争解释：** 旧模型实际依赖记忆修正整体偏差，约束反而有害；空间改善是普通内容读取同样获得的效果；原生尺度本身不可靠；已有历史与当前任务缺乏足够相关信息。

## 唯一固定变换

利用本轮已经保存的原生输出 (D_0) 与记忆输出 (D_M)，定义

\[
r(x)=\log D_M(x)-\log D_0(x),\qquad
\widetilde D_M(x)=D_0(x)\exp\left[r(x)-\frac1{|U|}\sum_{u\in U}r(u)\right].
\]

(U) 是当前 RGB 中未被人工遮挡的全部像素；完整输入用全部像素。**不得用传感器有效深度掩码、目标深度或目标误差确定 (U) 或校正量。** Native 与 memory 输出来自相同四帧输入，保持原固定相机标定与所有数值尺度。固定系数为1，不扫描权重、温度、分位数、掩码范围或种子。预测正值核对后直接取 log，不按成绩设计额外裁剪。

该算式只是消除“记忆相对 Native 的平均 log 深度改变量”，没有额外可学习模块。它首先是读出边界诊断；即使有效，也不能单独归因于高斯位置编码。

## 结果改变的决定

1. 若整体用途改善且对同样修正的强 C/Center 有可信增量，再考虑把这个精炼边界放回读取接口，并在未用地点确认；仍不直接宣布一般有效。
2. 若 C/Soft 同样改善，结论是通用残差读出约束有用，高斯 PE 的必要性仍未确立。
3. 若只 Prefix 保留明确历史收益、Corrective没有，再研究容量/更新策略，先有信息用途证据后改 writer。
4. 若没有整体改善，结束这一次尺度分工诊断；下一问题回到原始历史中实际存在什么与当前任务相关的信息，而不是继续搜索校正公式。
