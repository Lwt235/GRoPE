# history_visibility_train1：一次匹配训练检验（已授权执行）

2026-11-11。接续[受控历史读取结果](../results/gaussian_memory/history_visibility_control1/report.md)。用户要求明确计划、设为目标并执行；已建立本项有限目标，完成训练、评价、核对和方法取舍后结束。

要检验的假设是：既有读取器没有见过跨上下文持续缺失和不同历史范围，因此未能稳定利用早期补充信息；在同一任务分布训练后，现有精炼高斯读法能够利用历史，并超过同输入的内容和Center控制。竞争解释是预测/压缩后的记忆本身不够可靠，或者普通内容/中心读法已足够，训练匹配也不会建立形状特有收益。

本轮已有一个应保留的信号：一致遮挡下Soft对强旧C的区域/全图误差降低16.21%/14.57%；但History对Recent以及Soft对Center尚不确定。下一项只改变训练分布，不修改PE公式、骨干插入位置、256槽容量、Prefix构造或写入器，不扫描权重和温度。

## 固定实施

1. 使用原state_read1的12个训练片段和原三种子20261110/20261111/20261112。它们与本轮12个fidelity评价地点完全分离。已只读检查训练片段的早期、晚期及query11共108个传感器帧均在本地；其余查询标签已有因果缓存，无需扩大数据下载。
2. 训练查询沿用5/7/9/11；每个查询的早期来源固定0/1/2/3，晚期来源仅包括查询前的4/6/8/10。采用本轮同一mask0规则，固定完整、仅查询、持续遮挡及Recent/History两范围。每个查询独立构造条件，避免将一个较晚查询的掩码或输入状态倒用到更早时间。早期RGB在晚期重编码中使用相应遮挡副本；共享原完整输入尺度和固定相机。源传感器只构造训练干预，不成为模型特征或状态。
3. 只新增C、Soft Gaussian、Soft Center各三次拟合，共9次。各组完整初始化、训练样本顺序和优化器预算配对，沿用2000步、有效batch2、原学习率与全图原生log-MSE目标。三可见性条件和两记忆范围等概率抽样；不额外加入区域权重、蒸馏损失或模块。冻结VGGT和全部几何状态。
4. 固定本轮全部12个fidelity地点、query11、三条件及两范围，评价新九模型；保留本轮强旧C与全部冻结结果，Native/Local作为固定参照。不得因为新C变差而宣称新Soft已超过强内容。数据身份和完整输入重放沿用既有核对；不重做与本结论无关的数值门禁。

执行细节：训练枚举原计划的地点顺序，再按查询5/7/9/11、条件完整/仅查询/持续、范围Recent/History排序，共288种样本。沿用原随机排列循环、每步两样本、三方法同种子完全配对；最终2000步模型统一评价，不按评价成绩选模。Center沿用原训练统计的固定方差。预计168次持续条件骨干提取，另在首个训练片段的q5/q11重放完整及仅查询四个窗口以核对缓存；新增648份评价预测，原1224份评分按身份复用。对全部新预测独立评分；核对因果来源、配对初始化与训练顺序；固定展示fidelity_00/01/02和持续条件下Soft对强旧C区域误差最大的反例。新拟合C/Soft/Center均比较历史增量，保留旧模型的完整参照。

## 读数与分支

主读数仍是一致遮挡下固定区域原生log-MSE：同一新Soft的History对Recent、History下Soft对新C及强旧C、对新Center。报告三种子与地点配对区间，以及从仅查询遮挡到持续遮挡的历史增益变化。全图/可见区代价、偏差与去均值空间误差并列报告。全部地点保留，不以区域支持量或收益筛选评价集。

- 历史增量及高斯相对强C/Center的优势都稳定：保留结构，下一项再考虑未用数据确认及真实可见性条件。
- 历史有用、C或Center已足够：明确共享记忆的用途，收窄高斯形状的额外主张。
- 只有对内容的收益，历史或形状仍不确定：保留受控条件的读取证据，结束这条固定Prefix接法的推广检验，不循环补种子、换掩码或修公式。
- 各方法仍无可靠历史收益：停止以训练分布不匹配解释当前失败；将剩余缺口记为状态信息与读取目标的边界，另行决定是否值得改变表示。

这些评价地点已经用于设计和诊断，只属于开发验证。此训练的成功也不等于一般PE有效，不覆盖严格纯RGB标定、真实遮挡、在线更新成本或全新场景确认。
