# 第三轮任务与证据审计建议

日期：2026-10-29。本文是独立协议审查，不是实验结果，也不替主线程预选具体编码公式。审查依据为第二轮报告、渲染器、观测生成器和 Attention 算子源码。

## 1. 第二轮验证的目标与高斯支撑并不完全一致

`rendered_scene.pair` 的正类是查询 patch **中心点**在目标图像落入的 patch，且接收 patch 中心必须在同一表面。这个目标没有要求查询与目标的两个三维区域接近同样大小、具有相同协方差或最大区域重叠。同一正确中心点可以落入很大或很小的目标区域；局部法向由表面决定，而切向支撑主要由相机、patch 大小与投影决定。

因此，有关完整协方差的第二轮负结果仍然有效，但其准确含义是“协方差未改善这个点到 patch 的任务”。它不能判定“高斯区域作为 PE 没有价值”。反过来，只在同一 Gaussian primitive 跨视角检索中取得很高准确率，也可能再次测到稳定身份信息，而非区域几何。

原任务应保留为冻结外部对照。新方法如果只在为其新建的区域任务上成功，要明确把结论限定为“区域信息得到有效编码”，不能宣称已经改善普通像素匹配、真实三维理解或 NVS。

## 2. 最小可实施的新任务：可见区域分布传递

可以复用当前 RGB、相机、深度缓冲与表面渲染器，增加密集区域标签，无需另写 GPU renderer。

1. 每张图独立划分区域，基础版本仍为独立 patch 网格；相机之间不共享区域中心、patch 编号或 primitive 身份。训练中随机化网格相位和区域大小，确认测试使用预先留出的相位、大小及宽高比范围。固定网格版本作为较容易的对照。
2. 每个查询区域使用固定的 6×6 或 8×8 子像素格，从真实渲染表面取得世界坐标。把样本投影到目标图，按目标深度缓冲检查可见性，再按**实际目标区域掩码**计数。被遮挡或投到画幅外的质量进入 dustbin。不得再要求目标区域中心与查询在同一表面。
3. 令 `w_ij` 为查询区域样本落入目标区域 j 且可见的比例，`w_i,unmatched = 1 - sum_j w_ij`。这是由表面与可见性决定的软分布，不用任何候选 Gaussian PE、Bhattacharyya 距离或协方差核生成标签。目标是学习把一个区域的信息按真实覆盖比例送到多个区域。
4. 每个 token 的 `(mu, Sigma)` 由其**自身区域**中独立采样的三维表面点拟合。计算标签的密集采样格与拟合几何的采样格应错开，防止同一有限采样噪声成为可利用指纹。使用总体归一化单位及固定的小对角厚度，不向模型提供样本 ID、表面 ID、对应关系、真实可见性或误差幅度。
5. 主结果先报告单表面区域；单表面判定只用于数据分层与评价，不作为模型输入。完整混合边界区域另列，记录单 Gaussian 近似的失配程度。不能在看到结果后只保留效果好的纯区域。

这个标签测量的是查询图像区域的像素面积质量传递，**不是物理表面积 IoU，也不是对称 Gaussian overlap**。倾斜表面两视角的图像采样密度不同，必须把这个区别写清楚。若要测对称物理区域重叠，另用预先生成的世界表面均匀采样点和两个区域的实际成员掩码；不能直接交换 `w_ij` 的行列当作反向标签。

最便宜的优化目标为软交叉熵。主指标报告逐区域 KL（减去固定标签熵），同时报告模型选择的候选包含的真实质量、dustbin Brier/校准和遮挡质量误差。硬 top-1 标签应只作次指标，因为一个大区域可合理覆盖多个目标区域。

## 3. 必须同时具备的对照

所有方法共用 RGB 内容编码器、数据批次、特征宽度、优化步数及 checkpoint 选择规则。每个方法报告实际激活参数量与每 token 计算量，不能仅用登记了未使用分支来称“同容量”。

| 对照 | 排除的解释 |
|---|---|
| 位置 RoPE，使用相同 `(mu)` 与相同频率集合 | 收益仅来自三维位置或新频率设计 |
| 位置+法向的逐 token PE | 完整 Gaussian 的收益其实全部来自法向 |
| 各向同性支撑 PE，保留 `tr(Sigma)` | 收益只来自区域大小而非旋转/各向异性 |
| 位置+完整协方差的普通绝对 MLP/加性 PE | 收益仅来自更多几何输入与容量，而非提出的编码结构 |
| 同场景内按位置/尺度分层打乱协方差，保持 RGB、中心及标签不变 | 协方差是否真的与空间区域对应；这是错误输入压力实验，不是等信息基线 |
| 固定区域大小/形状的强投影位置核 | 支撑变化是否有独立贡献 |
| 预先固定解析区域核 | 任务是否已被一个零训练几何公式解决；此项是参考上限或结构基线，不是 PE |

正交或复数相位方案需要将“相同频率+点极限”与普通 3D RoPE 做到数值一致。轴对齐频率无法完整观察协方差非对角项，若使用斜方向频率，应让位置基线也用同样方向，避免把新方向的收益记到协方差名下。

不要再次创建跨视角共享的随机 token 形状当作物理支撑，也不要让真值正类由“两个 token 的随机形状最近”决定。共享形状可以是明确标注的身份机制反例，不能作为主证据。

## 4. 分割、确认与统计协议

- 初筛可用 3 个训练种子与独立 validation；选择公式、频率范围、几何权重后冻结。保存探索期间所有候选与淘汰理由。
- 确认阶段至少 5 个新训练种子；每种子至少 200 个独立测试场景。确认测试场景前缀不能复用第二轮 800/900，也不能被预览/调参读取。
- 场景级分割，不能同一表面或同一重建模型的其他 token 随机进入另一 split。合成场景应独立抽样布局、纹理、相机与区域划分。真实场景测试必须按场景隔离，只有一个真实场景时只能称场景内验证。
- ID 区域分布、宽高比/尺度外推、相机基线外推和几何观测误差分别汇报；测试不做噪声等级选优。不能把 oracle 与 RGB 预测几何混为同信息条件。
- 主比较只预指定一个位置基线与一个同信息强基线。以场景/训练种子为统计单位做分层配对 bootstrap，报告五种子的全部值、差值及 95% 区间；查询不是独立重复。多候选探索不宣称已作多重比较校正。
- 一个合理的继续条件：主区域任务对位置及同信息强基线的预先指定指标均稳定改善，五种子至少 4 个同方向，配对区间排除 0；同时旧点任务与位置误差压力实验没有无法解释的明显退化。实际最小改善幅度应在看确认集之前按应用价值确定，不能事后移动门槛。
- 如果闭集排序很好但 dustbin 失配，分别报告两者。新增编码应先与相同训练的 dustbin 校准策略公平比较，不能只给新方法额外校准。

## 6. 最小真实参数验证与证据边界

第一步可以只读采样每个模型最多 10,000 个 opacity 合格的 Gaussian，统计尺度、条件数、点极限、极薄支撑、旋转 gauge 等情况下新 PE 的有限性、范数与梯度。此项成本低且必要，但只是数值可行性，没有任务效果证据。

第二步的真实任务不能用同一 primitive ID 的跨视角再识别作为主结果。更合适的是独立图像区域的聚合：每视角各自从渲染贡献/表面观测构建局部区域，用区域中可见三维分布拟合 Gaussian，评价真实图像区域的信息传递或渲染留出预测。primitive ID 可以用于生成对应监督，但不得输入模型，也不得把同一 primitive 的原始唯一协方差当作两端 token 的共同身份。

若仅有两个确认场景，应明确报告逐场景结果与数量限制。真实 RGB 几何预测误差、重建本身错误和 PE 表达误差要分别列出。要宣称一个可信研究方案，至少应有独立表面区域任务的正结果、旧任务/噪声/身份反例的解释，以及真实参数数值验证；要宣称实际视觉任务提升，还需要真实图像任务或正式 NVS 对照。
