## 固定问题和比较

假设：实际高斯场景与其视图贡献能帮助VGGT读取来源内容；在同一场景内容下，投影位置项可能超出可学习中心—射线PE。竞争解释是普通历史token已足够、场景构建损失或接收网络限制用途、投影PE无额外作用，以及变化主要来自共同适配和区域偏差。

沿用[详细方案](gaussian_scene_memory_plan_20261111.md)：L无历史同容量适配、T同字节历史token、C高斯内容、P同内容中心PE、G投影PE。共享width256/4-head读取器在global块0/6/12/18后复用，冻结原生权重与DPT；T/P额外192个PE参数据实披露。五组各三配对种子20261110/11/12、2000步、有效batch2，最终检查点，AdamW 1e-4、wd .01、clip5，原始及去均值log-MSE等权。不得用开发查询调构建、选checkpoint或换公式。

## 数据与接口具体化

- 复用12训练地点及12隔离旧开发地点，不是新确认。来源固定[0,3,6,9]，查询[2,5,8,11]；四查询共用每片段一份来源状态。这是静态来源任务，早查询也可使用后时刻来源。
- 源构建函数仅接受来源RGB、来源相机及冻结构建器的来源预测。查询RGB和标签不进入构建、选基元或特征写入。查询相机仅在读取时使用。源相机用于公共坐标/尺度对齐，不使用查询GT进行逐查询尺度对齐。
- 初始2048基元、1024维FP16视觉内容，几何/opacity/计数及全部相机元数据计入状态预算。T按完整状态字节上限计算能保存的整token数量，不能只按同槽数声称同预算。
- 图像预处理遵循固定构建器接口，并同步变换给定内参、标签与掩码；具体裁切/分辨率在两个旧训练片段预检后记录，正式评分前锁定。预定缺失条件为中心半宽、半高矩形，约25%图像，填固定RGB均值；同一ROI也用于完整输入评分，来源图像保持完整。它是人工缺失诊断，不能称自然遮挡或历史因果预测。
- 特征写入和PE的alpha贡献由标准gsplat在声明的特征像素网格上渲染单位基颜色获得。它包含实际前后合成，不能冒称完整patch上的概率积分；RGB拟合与几何渲染单独报告分辨率和成本。
