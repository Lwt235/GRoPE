# 三个对称关系量：旧数据上的精简设计检验

2026-11-06，新增训练前确定。起点是 matched256 的完整负面/混合结果：准确率增益接近零、CE 仍改善、更大输入数量存在反例。不能据此断定病因是方向性，也不把本计划写成已证实方案。

## 假设、竞争解释和具体设计

当前五维分别编码两端的位移标准化量和形状关系。假设：将其中两组方向合并，可以保留支撑方向/范围的有用关系，同时减少不必要的角色区分；内容 query 仍保留方向性，因此不强制整个注意力对称。

竞争解释：两端的独立信息是区域用途所需；原生数量依赖来自训练、选模或采样统计，合并方向不会改善。可学习单散度也可能已足够，不能为了保留三维而省略它。

沿用当前 `relative5` 的定义、协方差 floor、数据坐标及 `.2` 距离单位。令其输出为 `[d,a_i,a_j,b_i,b_j]`，其中 `a_i=log1p(δᵀΣ_i⁻¹δ)`，`b_i=log1p(tr(Σ_i⁻¹Σ_j))`。候选为：

`symmetric3 = [d, (a_i+a_j)/2, (b_i+b_j)/2]`。

平均发生在原 log 变换之后，不把“先平均原度量再取 log”混入这次改动。候选是当前五维输入去掉两个反对称分量的限制形式；保留位移—形状和形状—形状两类量，不先合成单个 KL。

为保持完整初始化、参数量和旧优化器设置，配对训练使用 `[d,u,u,v,v]` 的五槽实现，只有三个独立量，原 `5→96→96` MLP 不增加参数。第一层的第 1/2 列、第 3/4 列分别相加，可在部署时折叠为三输入线性层；本轮不声称已获得完整训练或运行速度收益。实际三输入从头训练的优化轨迹不保证与重复槽相同。

可学习 Jeffreys 控制沿用已完成的区域定义 `[d,j,j,j,j]`，`j=log1p(KL(i||j)+KL(j||i))`，不是新距离公式。原生控制复用相同模块及初始化，没有新温度、尺度搜索、门控、损失或骨干。

## 分析与不同结果的决定

主读数为区域基础 R@1、原生 512→512 mCA 和 256→256 mCA。区域的中心 PCK、hard/soft EPE、CE，原生的 OA/CE，全部条件、来源、逐种子及逐场景/类别同时报告。条件间共享对象，不计作独立复现；排列仅为实现检查。

报告 symmetric3 对完整五维、Distance、固定球形及 Jeffreys 的配对差；原生同时报告 Jeffreys 对五维、Distance、固定球形，避免只挑较弱基线。区域复用原有场景/有效查询统计方法；原生复用类别均值与种子×类别敏感性区间。bootstrap 固定 10,000 次，基础随机种子 79001，按固定任务/条件/比较顺序递增；不基于结果追加种子、变换主指标或另选参数。

- 若三维保留区域与原生主要用途、形状相对固定球形的作用，且数量条件的反例减少，才把它作为后续未用数据确认的候选。少数旧种子的正面信号不是一般有效证明。
- 若单散度同样或更有效，则优先考虑其更精简的关系组织；其区域已知限制也必须保留，不能只凭原生成功推广。
- 若三维明显损失原有区域用途，或原生仍接近 Distance / 固定球形，就不把“对称化”解释为已找到病因或完成改进；保留失败并重评设计，不继续追加小模块。
- 混合或宽区间结果按不确定报告，不要求所有微小子组同号；也不把均值接近当成正式非劣性/等效性证明。

## 执行范围

只新增模型/适配器和结果目录，不更改已冻结代码或报告。CPU 检查覆盖与原五维的限制关系、交换两端对称性/共同刚体变换、完整初始化与 RNG 状态一致、三输入折叠的函数关系。GPU 在真实旧 fit batch 上检查有限损失及 PE 梯度、实际输入数量和资源峰值；不引入静态积分门禁。

启动前固定来源代码、旧缓存、旧对照 checkpoint/预测/报告身份。最多六张实际空闲卡、每卡一个自有任务，核实实时占用与 CUDA 后启动；不停止其他用户任务。控制器保存身份和重复启动保护，普通实现错误记录后修复，不增加科学轮次来冻结失败。

本轮不读取官方 TEST、九个已用区域确认场景或其他未用对象来选设计。原生官方确认、区域确认和投影确认的历史结果不改写；新设计若在开发数据有前景，另行固定适用的几何、鲁棒性、实际用途和未用数据确认安排，不能直接继承旧模型的确认结论。
