# GRoPE：将高斯参数化转为 Transformer 位置编码

更新：2026-11-04（Asia/Shanghai）。本文是当前设计、证据链、分析与结论的统一入口。历史原文及草案见[归档索引](archive/2026-11-04/INDEX.md)；原始结果仍位于 `results/`。归档不表示删除负结果，也不表示历史草案已执行。

## 1. 当前判断

**我们已得到一个结构较精炼、在观测区域匹配与给定参考几何的图像任务上有正面开发证据的候选，但还没有得到经验证的一般性方案。** 当前候选叫 `relative5`：由两个高斯区域的中心和协方差构造五个相对量，经一个小型 MLP 生成 Transformer 的相对位置项。

最可靠的正面证据来自 R68–R69：给所有方法相同的完整几何信息，并固定稀疏前后的查询与标签后，候选仍优于距离 MLP、直接几何 MLP 和法向/尺度对照，区域匹配与中心定位共同改善。它支持“**如何组织已有几何信息会影响有限预算下的学习效果**”。

限制同样明确：此前 RGB 匹配和真实优化 3DGS 分类没有建立相对强 MLP 的稳定优势；直接跨域迁移也失败过。当前五维的 R73 原生分类已开始拟合。五个未使用场景的投影任务确认已完成，但对投影 Distance 的 PSNR 差为 +0.224/+0.505/−0.471 dB，未通过完整稳定用途标准；不能继承其他版本的成功，更不能消除它们的失败。

**R70 的参考—参考接法没有稳定收益；R71 改为目标 query→参考 key 的投影关系后，给定参考几何组通过了固定用途标准。** R71 五维 PSNR 为 18.581 dB，对同投影 Distance / Direct 分别 +0.205 / +0.265 dB，对 URoPE +0.440 dB，三个种子主指标均改善，LPIPS 也改善。大部分相对 R70 的增益来自投影交互方式，不能全部归给高斯形状。R72 的 RGB 版本已四卡完成：18.236 dB，对 Distance / Direct 平均 +0.127 / +0.172 dB，但各有一个种子更差；对 URoPE 仅 +0.044 dB。LPIPS 一致改善，PSNR 尚未稳定胜出，故仅推进 R71 给定几何组的新场景确认。[R70 负结果](../results/round70_nvs/attempt1/report.md) · [R71 完整结果与审阅](../results/round71_target_projection/attempt1/report.md) · [R72 结果与审阅](../results/round72_rgb_projection/attempt1/report.md)

**新场景确认保留了投影交互收益，但没有稳定确认五维形状关系的额外优势。** 五维在新场景对 Direct / URoPE / PRoPE 的基础 PSNR 分别 +0.186 / +0.333 / +0.599 dB，三个种子均正；对 Distance 仅平均 +0.086 dB，种子 33 在五个场景均更差。外推与变焦也存在对 Distance 的退步。这是已完成的混合确认结果，不是数值核查未完成。[确认报告与审阅](../results/projection_confirmation/attempt1/report.md)

## 2. 要解决的问题，以及为什么考虑高斯参数

中心坐标编码能表达“token 在哪里”，但一个图像 patch、局部点云区域或 3DGS 基元还具有范围和方向。两个中心距离相同的区域，沿长轴接近与沿薄轴接近可能对应不同的几何关系。只编码中心距离不会显式区分这些情况。

3DGS 的几何参数提供了紧凑的区域描述：

\[
G_i=(\mu_i,\Sigma_i),\qquad
\Sigma_i=R_i\operatorname{diag}(s_i^2)R_i^\top\succ0.
\]

中心负责位置，协方差表达方向、尺度和各向异性。当前 PE 使用这部分参数化；不把 opacity、颜色或全部 3DGS 渲染参数都纳入位置公式。出现颜色/opacity 的实验中，它们可以是各方法共同获得的内容特征。

这里必须区分三种来源：

| 来源 | 代表实验 | 协方差的实际含义 | 可以据此声称什么 |
| --- | --- | --- | --- |
| 观测点集或深度 patch 的二阶矩 | R58–R61、R68–R69、R70 RGB-D | 被观测到的局部区域支撑 | 高斯参数化对观测区域关系有条件性用途 |
| RGB 特征预测的中心与正定矩阵 | R62、R64、R70 RGB-only | 为任务学习的几何/潜在参数 | 必须单独验证任务收益及几何解释，不能默认是物理真值 |
| 优化后的原生 3DGS 参数 | R65–R67 | 重建得到的高斯基元 | 可直接检验真实基元属性用于 Transformer 的价值 |

**支撑范围不等于位置预测误差。** 把一个真实存在的大区域当成“中心很不确定”，可能错误衰减位置编码。当前设计继承早期的解耦思想：保留位置关系，再用独立的形状关系补充它，不直接把物理协方差塞进期望 RoPE 的幅度衰减。

这也不意味着普通 MLP 或 Transformer 无法表达这些关系。真正需要回答的是：同信息、同骨干、相近容量和训练预算下，这种组织方式能否让模型更容易学到有用关系，并在实际任务和新数据上保留收益。目前证据只部分回答了这个问题。

## 3. 当前精炼设计：五个相对量，一个 MLP

记 \(\delta_{ij}=\mu_i-\mu_j\)，在各实验规定的公共坐标和尺度下构造：

\[
\phi_{ij}=\begin{bmatrix}
\|\delta_{ij}\|/0.2\\
\log(1+\delta_{ij}^{\top}\Sigma_i^{-1}\delta_{ij})\\
\log(1+\delta_{ij}^{\top}\Sigma_j^{-1}\delta_{ij})\\
\log(1+\operatorname{tr}(\Sigma_i^{-1}\Sigma_j))\\
\log(1+\operatorname{tr}(\Sigma_j^{-1}\Sigma_i))
\end{bmatrix},\qquad
r_{ij}=\operatorname{MLP}(\phi_{ij}).
\]

注意力中加入查询相关的位置项：

\[
\ell_{ij}^{(h)}=\ell_{ij,\mathrm{base}}^{(h)}
+\frac{(q_i^{(h)})^\top r_{ij}^{(h)}}{\sqrt{d_h}}.
\]

五个输入分别表示普通距离、相对位移在两端区域形状下的标准化大小，以及两个方向的形状相容关系。它们保留了位移与方向/范围的耦合，没有先压成一个固定散度标量。MLP 学习各项对任务的作用。

- **R69 区域匹配：** `5 → 96 → 96`，GELU，最后一层无偏置；9,792 个 PE 参数，比距离 MLP 多 384，比原 11 维版本少 576。作为视图内自注意力的位置项，跨点云注意力与最终匹配使用内容。
- **R70 图像任务：** 同样五个量，输出适配为 192 维；19,008 个 PE 参数。保留 PRoPE 相机编码，额外关系仅作用于参考—参考 token；目标—参考与目标—目标仍使用原相机编码。
- **R71 目标—参考接法：** 先将参考三维高斯的局部矩投影到目标图像，以投影中心/协方差和已知目标 patch 的中心/协方差构造同样五类关系。关系项只作用于目标查询读取参考 key；不使用目标 RGB/深度，不再叠加参考—参考关系。
- **表示性质：** 对共同刚体变换，五个几何量在精确算术下不变，也没有协方差主轴符号选择的歧义。但固定距离尺度不提供无条件尺度不变性；共同内容仍含坐标相关信息，不能声称整个网络精确刚体不变。
- **复杂度：** 五维是关系输入的精简，不代表整个网络大幅压缩。成对关系仍有二次复杂度，逆协方差与中间张量也有代价。

实现：[R69 候选](../models/round69_compact_relation.py)、[R70 适配](../models/round70_nvs.py)、[R71 投影接法](../models/round71_target_projection.py)。当前版本属于可学习相对 PE，不能称为新 RoPE 公式、新高斯距离定理或首次提出高斯 attention。

另有一次独立的小型 CPU 代数检查：末层无偏置时，\(q_h^\top W_h z_{ij}=(W_h^\top q_h)^\top z_{ij}\)，可避免显式存储完整关系向量。按 R70 张量形状，一个 bf16 中间量约为 432 MiB；但隐藏成对量仍约 216 MiB，反向和临时内存仍存在。检查未更改本轮训练，bf16 重排有舍入差异，尚无实测 GPU 峰值/速度收益。[检查结果](../results/round70_nvs/attempt1/cost_diagnostic1/result.json) · [代价说明](../results/round70_nvs/attempt1/cost_diagnostic1/interpretation.json)

## 4. 证据链如何走到这里

### 4.1 早期机制：形状有信息，但语义和输入条件很重要

2026-10-29 的 125 次合成训练中，中心 3D RoPE 的 Recall@1 为 92.87%，把物理形状协方差直接用于期望 RoPE 后降到 83.51%。另一次验证集校准后的新合成场景评估中，中心基线为 **92.84%**，加入截断形状距离/平滑二阶矩分别为 **98.96%/99.28%**。这两组数字属于不同评估表，不能混写为同一次比较。

它们支持位置与形状解耦，但形状由合成生成器提供，共享支撑可能成为容易匹配的身份信息；形状噪声和打乱后也出现明显下降。因此没有证明真实预测器能学习出同样的收益。[早期完整记录](archive/2026-11-04/research_report.md)

R6 的五维二次 Q/K 编码在当时五个新扫描的条件区域匹配中降低 KL，但 R7 的真实深度用途只获得约 0.335% 改善且区间跨零，R9 的 GS/RGB 用途也未通过。**R6 的“五维二次 Q/K”与当前 R69 的“五维关系输入”是不同方法。** 当年的确认数据也不能再次称为当前候选的新数据。[R6](archive/2026-11-04/round6_report.md) · [R7](archive/2026-11-04/round7_report.md) · [R9](archive/2026-11-04/round9_report.md)

### 4.2 静态积分路线的教训，不再作为所有方法的前置门禁

R15–R39 长期集中于静态投影概率核、区域分布与参考求积。R38 固定筛查为 0/8：区域 KL 约 0.36660，相对 quad 的 0.30835 差 18.89%；中心定位保护也未通过。而在真实基元 \(a=\mu\) 时，修正项 \((\mu-a)(\mu-a)^\top\) 为零，合成 patch 修补不能直接证明真实 3DGS 参数有用。

这条路线没有提供推翻早期解耦结论的证据。旧资源/精度/定位约束也没有经过一般性的不可满足性证明，不能把执行失败写成整个函数族的数学不可能。2026-11-01 后的路线调整是回到可学习 Transformer PE 与真实用途，让数值核查服务具体科学结论，而非让所有新方法重过历史积分门禁。[R38 结果](archive/2026-11-04/docs/round38_rms_anchor_triage_report.md) · [历史门禁图](archive/2026-11-04/docs/research_gate_map_20261101.md)

### 4.3 回到 Transformer 后：局部机制改善仍可能输给强对照

R40–R57 检查了形状通道、频率参数化、原生坐标、动态高斯及相机/射线框架。代表性反例是 R47：动态三维高斯 PCK8 为 **83.480%**，完整椭球优于自己的球形/对角简化，但仍低于 3D RoPE 的 **85.158%** 和直接三维 MLP 的 **88.251%**。组件有用不等于整个方法值得采用。

相机、单应与射线对照也说明，改进可能来自交互坐标或已有投影关系，不能只比较 NoPE 后归功于高斯。既有 Gaussian affine frame 等尝试有单独记录，不应换名后当新方案重新宣称发现。[R47](archive/2026-11-04/docs/round47_conditional_gaussian_report.md) · [R53](archive/2026-11-04/docs/round53_ray_frame_report.md) · [R55](archive/2026-11-04/docs/round55_budget_diagnostic_report.md) · [R57](archive/2026-11-04/docs/round57_gaussian_pair_report.md)

## 5. 当前最重要的正面证据：R68–R69

### 5.1 R68 补上两处关键控制

首先，所有方法都获得相同的完整 20 维区域内容：原 11 维描述、中心 3 维和完整对称 log 协方差 6 维。候选没有独占协方差信息；直接 MLP、距离 MLP、法向/尺度及打乱关系控制共享骨干和内容。

其次，在稀疏输入中保留同一组参考区域、中心、标签和查询，只减少原区域内的观测。两条件都保留 **20,422/61,440 个有效查询（33.239%）**，避免人群变化造成表面鲁棒性。这个实验使用已知原区域成员，不等同于从稀疏点云重新发现区域的完整流程。

数据是旧 SUN3D 3/1/5 场景划分，576/64/480 对；各视图 64 个区域。五方法、三种子、每次 60 epochs/1,080 updates，从配对共同初始化训练，实际输入流一致，验证选模后才统一导出评估。

### 5.2 R69 保留关系，去掉额外绝对谱输入

在相同条件下，新增 `relative5`、仅位移标准化的 `metric3`、距离加两端谱的 `spectrum7`，各三个种子。其余控制按身份复用 R68，不能计为新的独立实验。

| Distance MLP | 36.6698 | 32.8734 | 12.5278 | 10.8464 |
| Direct MLP | 35.6419 | 32.7698 | 12.1154 | 10.9473 |
| 法向/尺度 | 36.8162 | 33.9761 | 12.6303 | 11.3655 |

### 5.3 这些结果支持与不支持什么

| 解释 | 当前判断 |

| 收益仅因候选多拿了协方差信息 | R68 的完整共同内容与 Direct 控制削弱了这一解释 |

## 8. 对 HRoPE / PRoPE / URoPE 的吸收与边界

已有相机/单应方法的启发是：**选择合适的交互坐标，可能比增加形状参数本身更关键。** 当前实验因此保留强相机、射线与同信息 MLP 控制，不把优于 NoPE 等同于高斯优势。

R70 运行时已核实 URoPE 正文及官方源码：它将沿 key 射线的固定深度点投影到 query 图像坐标，再组织相对编码。相关源码身份留在[文献来源记录](../results/round70_nvs/attempt1/related_work_sources.json)。R70 未训练该对照；R71 已加入官方源码的坐标、单位、头数和 dtype 明确适配，详见 [R71 计划](round71_target_projection_plan.md)。

这一阅读提出的假设**已在 R71 完成开发验证并通过主用途标准**：在参考—目标交互中，用目标相机坐标下的参考高斯投影与已知目标 patch 范围构造关系，避免使用目标 RGB/深度。同投影 Distance、Direct 以及 URoPE 有助于区分坐标/交互方式和关系组织的作用。R71 同时改变了坐标与接入位置，不能仅凭跨轮差异唯一归因；它也不豁免 R70 的负结果。

目前方法新颖性尚未确证：高斯二次 attention、协方差距离和几何关系编码都有先例；R47 已讨论过高斯二次位置形式。完整移植范围、相机约定、头数/深度锚与单位注意事项见[归档的阅读记录](archive/2026-11-04/docs/round70_related_work_update.md)。另一次[定向公式补查](../results/round71_target_projection/attempt1/targeted_related_work.json) 区分了 GS 中心/时间编码、标量 Gaussian RBF 与完整区域协方差关系；它不是新颖性证明。

| 五维候选是否改善图像任务 | R71 旧场景通过；新场景对 Direct/相机控制有收益，但对 Distance 不稳定；R72 RGB 为混合结果 | 额外形状关系的一般用途未确证 |
| 是否用于真实优化 3DGS 也稳定有效 | 已有版本分类负结果；R73 当前五维正在拟合 | 未完成 |
| 是否有未使用数据确认 | R71 五个新场景、冻结模型确认已完成并审阅 | 完整用途标准未通过，正面子比较保留 |
| 是否结构精炼且实际高效 | 一个关系 MLP，输入五维；但 pairwise 二次开销显著 | 结构精炼有依据，整体高效未确立 |

因此当前最准确的研究结论是：**高斯参数化值得作为区域关系的组织方式继续研究；现有证据还不足以把它提升为优于强编码方式的一般性位置编码。** “区域形状关系能帮助某个任务”与“必须采用高斯/所有任务都受益”之间仍有证据缺口。

R70 的旧接法停止，R71、[R72 RGB 验证](round72_rgb_projection_plan.md) 及 R71 新场景确认均完成。新场景未通过完整用途标准；保留对部分强控制的收益，也保留对 Distance 的不稳定。下一步执行已冻结的 R73 原生验证与旧数据固定形状诊断，分别回答真实基元适用性和收益归因。RGB 感知指标和几何诊断的正面信号不被删除，也不替代主判断。适用的几何/鲁棒/泛化验证继续保留，但不要求每一处微小尾数同号，不恢复静态求积通用门禁。
