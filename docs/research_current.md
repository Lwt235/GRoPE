## 2. 要解决的问题，以及为什么考虑高斯参数

中心坐标编码能表达“token 在哪里”，但一个图像 patch、局部点云区域或 3DGS 基元还具有范围和方向。两个中心距离相同的区域，沿长轴接近与沿薄轴接近可能对应不同的几何关系。只编码中心距离不会显式区分这些情况。

3DGS 的几何参数提供了紧凑的区域描述：

\[
G_i=(\mu_i,\Sigma_i),\qquad
\Sigma_i=R_i\operatorname{diag}(s_i^2)R_i^\top\succ0.
\]

中心负责位置，协方差表达方向、尺度和各向异性。当前 PE 使用这部分参数化；不把 opacity、颜色或全部 3DGS 渲染参数都纳入位置公式。出现颜色/opacity 的实验中，它们可以是各方法共同获得的内容特征。

这里必须区分三种来源：

| 来源 | 代表实验 | 协方差的实际含义 | 可以据此声称什么 |
| --- | --- | --- | --- |
| 观测点集或深度 patch 的二阶矩 | R58–R61、R68–R69、R70 RGB-D | 被观测到的局部区域支撑 | 高斯参数化对观测区域关系有条件性用途 |
| RGB 特征预测的中心与正定矩阵 | R62、R64、R70 RGB-only | 为任务学习的几何/潜在参数 | 必须单独验证任务收益及几何解释，不能默认是物理真值 |
| 优化后的原生 3DGS 参数 | R65–R67 | 重建得到的高斯基元 | 可直接检验真实基元属性用于 Transformer 的价值 |

**支撑范围不等于位置预测误差。** 把一个真实存在的大区域当成“中心很不确定”，可能错误衰减位置编码。当前设计继承早期的解耦思想：保留位置关系，再用独立的形状关系补充它，不直接把物理协方差塞进期望 RoPE 的幅度衰减。

这也不意味着普通 MLP 或 Transformer 无法表达这些关系。真正需要回答的是：同信息、同骨干、相近容量和训练预算下，这种组织方式能否让模型更容易学到有用关系，并在实际任务和新数据上保留收益。目前证据只部分回答了这个问题。

## 3. 当前精炼设计：五个相对量，一个 MLP

记 \(\delta_{ij}=\mu_i-\mu_j\)，在各实验规定的公共坐标和尺度下构造：

\[
\phi_{ij}=\begin{bmatrix}
\|\delta_{ij}\|/0.2\\
\log(1+\delta_{ij}^{\top}\Sigma_i^{-1}\delta_{ij})\\
\log(1+\delta_{ij}^{\top}\Sigma_j^{-1}\delta_{ij})\\
\log(1+\operatorname{tr}(\Sigma_i^{-1}\Sigma_j))\\
\log(1+\operatorname{tr}(\Sigma_j^{-1}\Sigma_i))
\end{bmatrix},\qquad
r_{ij}=\operatorname{MLP}(\phi_{ij}).
\]

注意力中加入查询相关的位置项：

\[
\ell_{ij}^{(h)}=\ell_{ij,\mathrm{base}}^{(h)}
+\frac{(q_i^{(h)})^\top r_{ij}^{(h)}}{\sqrt{d_h}}.
\]

五个输入分别表示普通距离、相对位移在两端区域形状下的标准化大小，以及两个方向的形状相容关系。它们保留了位移与方向/范围的耦合，没有先压成一个固定散度标量。MLP 学习各项对任务的作用。

- **R69 区域匹配：** `5 → 96 → 96`，GELU，最后一层无偏置；9,792 个 PE 参数，比距离 MLP 多 384，比原 11 维版本少 576。作为视图内自注意力的位置项，跨点云注意力与最终匹配使用内容。
- **R70 图像任务：** 同样五个量，输出适配为 192 维；19,008 个 PE 参数。保留 PRoPE 相机编码，额外关系仅作用于参考—参考 token；目标—参考与目标—目标仍使用原相机编码。
- **R71 目标—参考接法：** 先将参考三维高斯的局部矩投影到目标图像，以投影中心/协方差和已知目标 patch 的中心/协方差构造同样五类关系。关系项只作用于目标查询读取参考 key；不使用目标 RGB/深度，不再叠加参考—参考关系。
- **表示性质：** 对共同刚体变换，五个几何量在精确算术下不变，也没有协方差主轴符号选择的歧义。但固定距离尺度不提供无条件尺度不变性；共同内容仍含坐标相关信息，不能声称整个网络精确刚体不变。
- **复杂度：** 五维是关系输入的精简，不代表整个网络大幅压缩。成对关系仍有二次复杂度，逆协方差与中间张量也有代价。

实现：[R69 候选](../models/round69_compact_relation.py)、[R70 适配](../models/round70_nvs.py)、[R71 投影接法](../models/round71_target_projection.py)。当前版本属于可学习相对 PE，不能称为新 RoPE 公式、新高斯距离定理或首次提出高斯 attention。

这四个形状相关分量与经典高斯 KL 直接相关：双向 KL 之和 `J=(mi+mj+ti+tj−6)/2`。R58 已使用 `sqrt(J)`，但其固定 sin/cos 加线性读出失败，不能单独说明“先合成标量”就是病因。新增的可学习单散度控制已完成（§5.7）：以普通距离加 `log1p(J)` 的重复槽输入同样 MLP，保留完整初始化和训练预算。它明显改善 Distance，五维在其上仍有区域召回收益，但并非全部中心指标更好。该控制只有两个独立输入，不宣称五维必然最小或已经测得二输入实现效率。[公式来源与比较缺口](../results/research_related_work/gaussian_relation_20261105/notes.md) · [固定控制计划](../results/region_jeffreys_control/preparation/plan.json)

## 8. 对 HRoPE / PRoPE / URoPE 的吸收与边界

已有相机/单应方法的启发是：**选择合适的交互坐标，可能比增加形状参数本身更关键。** 当前实验因此保留强相机、射线与同信息 MLP 控制，不把优于 NoPE 等同于高斯优势。

R70 运行时已核实 URoPE 正文及官方源码：它将沿 key 射线的固定深度点投影到 query 图像坐标，再组织相对编码。相关源码身份留在[文献来源记录](../results/round70_nvs/attempt1/related_work_sources.json)。R70 未训练该对照；R71 已加入官方源码的坐标、单位、头数和 dtype 明确适配，详见 [R71 计划](round71_target_projection_plan.md)。

这一阅读提出的假设**已在 R71 完成开发验证并通过主用途标准**：在参考—目标交互中，用目标相机坐标下的参考高斯投影与已知目标 patch 范围构造关系，避免使用目标 RGB/深度。同投影 Distance、Direct 以及 URoPE 有助于区分坐标/交互方式和关系组织的作用。R71 同时改变了坐标与接入位置，不能仅凭跨轮差异唯一归因；它也不豁免 R70 的负结果。

目前方法新颖性尚未确证：高斯二次 attention、协方差距离和几何关系编码都有先例；R47 已讨论过高斯二次位置形式。完整移植范围、相机约定、头数/深度锚与单位注意事项见[归档的阅读记录](archive/2026-11-04/docs/round70_related_work_update.md)。另一次[定向公式补查](../results/round71_target_projection/attempt1/targeted_related_work.json) 区分了 GS 中心/时间编码、标量 Gaussian RBF 与完整区域协方差关系；它不是新颖性证明。

进一步核对原文：[GaussianGPT](https://arxiv.org/html/2603.26661v1#S3.SS2) 将 GS 属性压缩成体素潜变量，RoPE 编码体素坐标与 token 类型；[各向异性局部编码工作](https://arxiv.org/html/2601.02339v1#S3.SS1) 用协方差构造邻域图与谱描述符，再加中心 PE 输入 Transformer。这些先例说明必须区分“形状进入内容特征”与“形状改变位置关系”，不能把使用 Gaussian token 本身当作当前 PE 的贡献。后者的有界度量 `(I+βΣ)⁻¹` 可启发后续建模，但它也可能抹去有效形状差异；当前仅记录假设，待 R73 与固定形状诊断完成后判断，不据此改动在跑实验。[原文、实现对应及边界](../results/research_related_work/comparison_scope_20261104.json)

这也给出一个精简设计的线索：固定形状输入实际只有两个变化量，普通距离 `d` 与目标 patch 单位下的 `t=log1p(δᵀQ⁻¹δ)`。设第一层矩阵的五列为 `w0…w4`，则其输出为 `w0*d+(w1+w2)*t+b+log(3)*(w3+w4)`；重复列和常量可合并成两输入 MLP 的权重与偏置。因此该控制的函数表示不需要变化的参考协方差。此处仅作代数解释，尚未重新训练两输入版本；合并参数后单独训练的优化路径未必相同，现有实现也仍计算上游协方差，不能据此声称已实现加速。

RGB 组则有小幅一致的基础收益：PSNR 平均 +0.055 dB，SSIM +0.00400，LPIPS −0.00411，三个种子方向均有利于原五维。诊断没有另设 +0.10 dB 门槛来否定这条信号。但外推 PSNR 差 −0.007 dB、LPIPS 差 −0.00017，近似持平且方向混合。两组变焦 PSNR 都略好，LPIPS 均值却分别差 +0.01258 / +0.01159，不能概括为全面改善。

固定形状不是自动晋升的新方案：RGB 对 Distance 的 PSNR 仍只有一个种子明显更好，对 URoPE 均值近似持平；尚无其原生或未用场景验证。此诊断削弱的是**投影图像任务中变化协方差的专属归因**，不删除 R68–R69 区域匹配证据，不证明共同内容中的形状无用，也不更改 R72 和新场景确认的混合结果。

### 10.1 最新收敛安排：先决定原生任务的适用边界

近期交付是回答“什么高斯几何关系、在什么条件下，相对强位置编码值得采用”。完整五维保持为唯一主候选；区域证据、原生证据和图像证据分别保留各自强度。区域已支持范围和方向参与相对关系组织的价值；原生已支持相对固定球形的额外价值，但对 Distance 的稳定优势仍未确立。前者不能替代后者。

**本次已完成检验的事前假设：原生五维的部分用途来自基元采样变化时仍能利用协方差描述的支撑范围，而中心配置编码对这种变化更敏感。竞争解释是，同等的采样数量增强已足以让 Distance 获得这部分用途，无须增加五维关系。** 提出问题的依据是 512 训练后的新对象 sparse256 比较为 +2.005 pp，而匹配 256 的开发比较仅 +0.123 pp；两个结果来自不同对象组，数值不能直接相减作为因果效应。匹配 256 还同时改变了训练和选模数量，因此本轮固定选模数量。此假设不等于“越稀疏越有用”，也没有预设协方差是真实表面范围。

用户恢复目标后，将下述有限比较落实为[固定执行方案](native_count_augmentation_plan.md)。六次配对训练于 2026-11-08 全部完成，方案原文保持冻结：

1. **公式与任务固定。** 保留完整五维 F 和当前原生已测的主要强对照 Distance，完整共同内容、骨干、对象划分与类别头一致。固定球形只承担已有形状归因证据的职责。
2. **只改变训练采样策略。** 比较原 512 固定训练与预先固定比例的 256/512 混合数量训练；F 与 Distance 接受相同对象、数量序列、增强和更新预算。两种策略都按同一 512-token 验证 CE 选模，避免再次同时改变选模条件。符合身份匹配的固定数量结果可复用；新增训练只服务于这一竞争解释。相同更新数不称为相同 FLOPs。
3. **固定三个评价条件。** 同对象、配对基元子集下报告 256、512、1024，后者用于观察未见过的数量增加。分别比较每种训练策略的 F−Distance，以及混合数量训练使该差改变多少。512 基础效果保留为主要实用读数，256 检验原有稀疏用途，1024 明确边界；不把三个均值合并来掩盖某个条件退步。
4. **按结果决定范围。** 优先看自然输入上的净准确率收益、配对不确定性、类别/来源一致性及额外成本；CE、纠正/新错误用于解释。微小浮点变化不成为门禁。无需重跑全部机制控制或等待每个分量都被解释。

| 可能结果 | 改变的决定 |
| --- | --- |
| Distance 接受同等混合数量训练后差距明显收窄，五维没有明确实用增益 | 收窄原生推广；将旧现象描述为特定训练/采样流程下的优势，保留形状归因证据，核心贡献以区域匹配为主 |

| 只在某个事前指定的数量变化条件有优势 | 仅提出该条件下的用途，基础分类和其他条件的限制同时保留 |
