# 未知位姿下的高斯关系一致性：设计前提检验

2026-11-10，新增描述量和分数计算前固定。上一轮完成18组既有预测筛选，已知标签有效性没有挽救两帧对齐，同掩码的理想区域对应仍明显更好。上一目标轮归类progress。完整五维仍为主候选，本轮不改变既有Transformer、监督、求解器或确认结果。

## 科学问题与候选含义

假设：两帧独立构造的区域虽非同一中心/支撑，在正确参考对应给定时，完整五维关系的一致性比中心距离和固定球形更能区分其他查询的正确候选。竞争解释：高斯协方差随可见性/分区变化，直接跨帧匹配这种关系反而不稳；中心距离已提供主要可传递线索。

在每帧自身坐标中计算原五维 `phi`，避免相减未经对齐的跨帧中心。对A端查询i和B端候选k，使用其他源区域j的参考对应分布P[j,l]：

`E[i,k,c] = sum_{j!=i,l} P[j,l]*(phiA[i,j,c]/s[c] - phiB[k,l,c]/s[c])**2 / sum_{j!=i,l}P[j,l]`。

P沿用原软区域目标：当该源查询max(overlap)>=0.3时，将overlap*(overlap>=0.1)行归一化；否则整行0。**完全排除正在评价的查询i的整行参考标签**，不让自己的标签直接给出答案。双向分别计算，不输入真实旋转/平移。没有其他参考查询时不输出匹配，原有效查询仍计错误。源和目标各自旋转/平移不会改变E；排列在P和几何同步排列时等变。这些是条件代数性质，不是可部署网络的泛化证明。

本轮P来自标签，属于乐观的机制诊断；不把它作为可部署PE或实际位姿系统。若得到正面证据，未来可研究把注意力自身的对应概率放入同一关系项，在score中用一个一致性能量；当前没有实现或训练该Transformer。它与R50/R53的局部坐标矩阵变换不同，不恢复已关闭的高斯框架。关系匹配已有[GW图匹配](https://proceedings.mlr.press/v97/xu19b.html)等先例；[GeoTransformer](https://openaccess.thecvf.com/content/CVPR2022/html/Qin_Geometric_Transformer_for_Fast_and_Robust_Point_Cloud_Registration_CVPR_2022_paper.html)也利用刚体不变的几何关系，本轮不能宣称发明关系匹配或击败完整GeoTransformer。

## 固定数据与比较

只使用原576个fit0帧对与480个旧eval帧对，五个场景；不访问val、已有确认缓存或新场景。每帧64区域、双向评价。三个关系：原完整五维F；距离D（F第一列）；原固定球形S（相同五维容量，其中仅径向信息变化）。各分量s用各自旧fit0双视图非对角关系的总体标准差；常数列s=1，不用eval选尺度。

三个关系各报告两种分数：固定等权 `-mean(E,channel)`；拟合非负权重 `-sum(w[c]*E[c])`。后者只在fit0、相同原软区域目标上最小化CE，全部有效且有参考查询的行等权；没有参考的行无法影响拟合，明确报告数量，评价时不删除。D一个、F五个、S五个非负权重；S的常数和重复列没有额外独立信息，不能把其个别权重解释为机制。权重直接含整体温度尺度，不另扫描温度或加入截距。

三个标量校准均用确定性L-BFGS-B，初值每列1/C、非负约束，maxiter=200、maxls=40、ftol=1e-10、gtol=1e-6；固定优化规则、不按eval选迭代。完整保留收敛状态与拟合历史。仅校准这几个标量，零Transformer训练、零网络推理、零位姿求解。

主比较为校准F−校准D、校准F−校准S；固定等权的对应两项为预定补充。分别使用99401–99404、整场景配对bootstrap10,000次。每个场景先计算双向正确区域查询数/原有效查询数，再五场景等权；无其他参考对应的有效查询计错误。另报覆盖、全查询正确比例、拟合前后CE、全部场景和原有效查询数。不把确定性校准伪装成三个神经网络种子，也不将跨轮帧对复用视为独立数据。

## 判断与边界

若校准F对D平均至少+1个百分点、场景区间位于零以上，且对S保留正的额外关系信号，支持进一步设计这种紧凑关系一致性PE，仍需实际预测的P、完整学习强对照、几何/泛化和未用数据确认。若负面或混合，保留结果并结束这一固定的非负线性一致性能量，不扫描参考数量、阈值、频率或重新选择主比较来救分。任何负结果只约束这项具体设计，不宣称所有高斯关系学习无效；本轮静态/低参数控制不是所有后续Transformer的通用前置门禁。

实现检查覆盖新公式：矩阵乘法展开对显式四重求和、查询自身P行排除、独立双帧刚体变换、排列等变、CE梯度、原五维对NumPy公式；GPU前两帧真实数据与独立CPU直接求和核对，最终全部预测的评价计数独立复算。不需要高精度求积或无关历史门禁。GPU启动前重复占用检查、CUDA探测与复查，保留其他任务。

原五维公式、相对Distance的已确认区域用途、HRoPE/固定旋转强对照、原生与图像负结果均保留。总体目标仍active，本项诊断不能完成一般性3DGS参数化PE目标。
