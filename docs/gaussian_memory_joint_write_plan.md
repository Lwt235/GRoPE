# 紧凑共享写入与当前读取器的配对验证

2026-11-10。事前固定，输出 `results/gaussian_memory/joint_write1`。

当前冻结 Gaussian Latent 读取在上轮二十地点比 GlobalSummary/强 Local 降低主误差15.71%/22.74%，但收益主要是平均深度偏差减少，协方差相对 Center 的额外收益尚弱。本轮回到导师的共享场景记忆方向：多个参考写入一份状态，保存，再由不同查询视角读取。

假设：保持当前读取接口时，精炼共享写入可以学出非恒等的内容与几何更新，并保留冻结记忆的跨地点用途。竞争解释是共同场景监督不足以约束几何，联合优化使路由偏移；或写入只需更新内容，几何改变无额外价值。参数增加与优化路径改变也可能解释增量，不能仅凭胜出归因为物理几何改善。

固定三组新增训练：Full Gaussian、Full Center、Content-only Gaussian，各种子20261110/11/12，各2000步，从原读取器初值开始；不在旧训练终点续训。复用冻结 Gaussian/Center、GlobalSummary、67宽Local、191宽强Local共15个已固定模型。前两组学习中心/正定协方差/opacity/32维内容，内容组保持几何与opacity。相同初始化、训练样本序列、12地点×1片段、batch2、AdamW lr3e-4、wd.01、clip5，仅监督原有每查询有效patch平均log-depth平方误差。不新增损失，不扫超参或选检查点。

写入只看已有参考紧凑信息：32维内容、中心3维、Cholesky对角对数3维。LayerNorm内容后，38→64→64→42两层GELU MLP，共9450参数；末层零初始化。沿用旧写入参数化：中心最大每轴偏移.25规范化单位；Cholesky右乘正对角下三角矩阵（对角exp(.7*tanh)，非对角.5*tanh）；opacity初始.7；内容残差。总参数154927，强Local435757。内容组有650个不参与任务的末层几何输出参数。所有方法源信息相同，写入组没有2048维额外参考context。本轮不是旧289066参数写入器的直接复现，也不检验从RGB完全自主发现槽位：256槽初始化/分组及VGGT冻结，学习的是共享残差写入。

使用已有66片段，零下载、零PCA重拟合。全部为已用开发数据，上一轮二十地点不能再叫新确认。主比较为32个非训练地点等权（旧12地点每地点两个片段先平均，再与已用20地点合并）；同时分别列出这两批以及其他全部历史片段，不能以合并掩盖反向。场景按原数据scene键聚合。主量log-MSE，辅助遮挡/可见/完整输入、RMSE/AbsRel、每查询均值偏差平方和去均值空间误差。固定地点×种子配对区间，不以全部辅助量获胜作为推进条件。

固定比较：FullG vs FrozenG、ContentG、FullCenter、强Local/GlobalSummary；ContentG vs FrozenG/强Local；FullCenter vs FrozenCenter。每份写入状态单独保存并重新加载，之后读取不调用writer、不接触参考RGB/context。固定移除、内容槽打乱、错误相机、恢复初始几何（含opacity）及恢复完整初始状态干预。报告中心/形状/内容更新幅度、正定性、参考与查询隔离。干预是模型依赖诊断，不替代重新训练的内容组，也不自动等于物理几何因果贡献。

决策：若FullG保留强对照用途且稳定优于FrozenG/ContentG，继续固定共享几何写入作后续独立确认；若与冻结相近而写入确被学习使用，仅支持可学闭环，不声称额外增益；若内容组保留用途而完整组退步，冻结几何是当前可用边界，下一步聚焦几何更新约束/任务可识别性；若两者均损害用途，保留冻结读取事实，停止把该写入作为成功方案。不要求小误差或宽区间变成通过，也不追加训练追分。

验证强度：训练前输入/初值配对与梯度通路，训练后有限值/采样身份、旧评分回放、保存状态独立CPU读取及NumPy评分；浮点容差2e-5（评分2e-6），不逐位追责。固定查看fit_00、transfer_00、fidelity_07、confirm_00/05/10/15首查询首mask与总览；保留失败记录。单个已授权共享GPU worker，启动前检查占用，12GiB上限，不影响他人进程。
