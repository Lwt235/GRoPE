# 区域概率的中心锚约束：理论审查

2026-10-30。仅阅读冻结的数学工具、协议与已有报告；未改模型、读取新增效果数据或运行候选。结论：**值得做一次有明确止损条件的 TRAIN-only 成本诊断，作为工程约束基线；目前不宜把它升级为主 PE 方案。** 它可以回答“保留一个合法定位器的决策，同时利用区域概率是否有实际价值”，不能把借来的定位性能称为协方差学到了中心。

## 1. 闭合确实很小，但平局问题必须修正

令 p 为 full4 最终区域概率，j 为冻结 point_pck 在相同输入/原生分区上的 winner。求

\[
q=\arg\min_{r\in\Delta}D_{\mathrm{KL}}(p\|r),\qquad r_j\ge r_i\;\forall i.
\]

这是 R13 已验证的凸 pooling：将 j 与超过最终水位的最大概率合并为共同均值，其他项不变。这里输入必须是**模型 p 和合法预测 j**，不是传感器 g 或 GT allowed set。

但是 q_j 最大只允许平局，**不能保证旧 first-index argmax=j**。若主张工程保证，必须预先固定可在输出精度下验证的严格裕量，并仍使用同一个最终概率做区域指标、原生 argmax 和实际 attention @ V。例如数学上

\[
r=(1-\epsilon)q+\epsilon e_j,\quad \epsilon>0
\]

使 j 严格最大，且额外 KL(p||r) 至多 −log(1−ε)。有限精度中需固定 margin/ε规则、归一化顺序，并逐行断言原始 argmax 精确等于 j；不能通过另一个 tie-break decoder 保证它。严格不等式的可行集是开集，边界上的 pooling 解通常只是严格问题的 infimum，不能把微扰后的结果说成同一个精确最优解。

若 j 来自 point_pck，则 PCK 与 baseline 相同是**借用 baseline 的硬决策**；如果来自几何中心的最近 key，就没有对 point_pck 的保证。前者也锁住 baseline 的定位错误，可能压掉 full4 原本正确的决策。

## 2. 自身概率改动小，不代表传感器 KL 改动小

真正需要测的是

\[
\Delta_{GT}=D_{KL}(g\|r)-D_{KL}(g\|p)
=\sum_i g_i\log(p_i/r_i),
\]

而不是只测 D_KL(p||r)。R13 使用 g 及真实允许集合，不能直接转移为本候选的低成本保证。

反例：K 个 key 中 p_j=0、另一个 key 概率2/K，其余K−2项为1/K。Pooling 得到均匀分布，D_KL(p||q)=2log2/K 可以很小；若真实 g 全在被压低的 key 上，真实 KL 增量仍为 log2。K=432 时自身成本约0.00321，真实增量约0.693。实际正 floor 可以任意逼近此例。

可给出的统一界很松：pooling 的每个被压低项最多减半，因为转给锚的总质量≤最终锚概率，所以 q_i≥p_i/2，进而 Δ_GT≤log2（严格微扰后再加−log(1−ε)）。这远不足以保证旧实验的2%非劣门槛。因此“成本界诊断”必须同时保留实际 GT KL 增量，不能只用模型自身 KL 作通过证据。

## 3. 主要结构问题是它已不只是位置编码

若 p 和 j 都包含内容 logits，闭合是对**最终 attention 分布**的约束。其修正依赖内容和整组竞争 key，不再是仅由位置/支撑参数决定的两两 PE bias。可合法称为“带定位约束的区域 attention”；不能在闭合后再加一次内容并仍宣称 winner 保证成立。

这个限制不是换个名字就能消除：对任意共享内容偏置 c，如果两个纯位置 logits a、b 总满足 argmax(a+c)=argmax(b+c)，则必须有 b−a 为常数。否则取两个 key 的内容差位于其不同的几何排序阈值之间即可翻转 winner。故**非平凡地区域形状改动、任意内容下精确继承 point winner、纯内容无关 additive PE**三者通常不能同时拥有。

闭合也不与原生 key 细分交换。例如 p=(.4,.6)、锚为第一项，pool 后为(.5,.5)；把第二项拆成(.3,.3)后，(.4,.3,.3)已有锚最大，无需投影，合并回去仍是(.4,.6)。所以它不是统一连续区域测度的精确离散化，必须保留原九分区及新增尺度检查。加一个固定锚虽不等于“堆网络”，但两个分数来源、全 key 约束和离散 winner 仍是实质设计复杂度。

## 4. 值得投入的边界

建议只做一次预冻结的48旧训练pair诊断，固定 full4、point_pck、quad16 参数和一个严格裕量规则，不开ρ/ε/h/T搜索，不读取新确认。原九条件及五尺度条件都保留；先保存 p、point winner 和闭合 r，再读取标签。必须报告：

- 所有 query 的有限性、归一化和原生 argmax 与 point winner 完全一致；区域 KL、PCK、V 均消费同一个 r。
- D_KL(p||r)、搬运质量、pool大小与最差行；另按原 direct/common 定义计算真实 Δ_GT 与强 baseline 差值。
- 锚正确/错误及两者决策分歧的事后诊断，但这些标签绝不影响前向规则、mask或anchor选择。
- 共用几何/内容可以复用，但必须计入 point 评分、argmax、pool/排序和完整 V 使用成本。

若真实区域收益或强 quad16 非劣条件消失，就停止该分支，不靠“PCK保证”抵消。若训练阶段有希望，也只值得重新经历完整冻结验证；它的独立价值是**区域质量与成本**，PCK的零差是结构约束而不是另一个学习成功。

更贴近原始“支撑参数→PE”的形式，是把中心与范围放在同一个连续测度中，例如共同中心的尺度混合或此前讨论的同矩 OU 连续收缩；它们避免新增内容相关决策投影，却没有精确保留 point_pck winner 的保证，真实多峰/遮挡场景也可能因强制中心峰值而受损。不存在已经证明同时保留这两种优点的免费替代。本阶段不选择这种替代，也不把一个自然解释当成通过证据。

因此，该锚闭合适合作为**一次有限成本的约束工程对照**，帮助判断双目标能否通过合法输入共同满足；作为一般、精炼的 3DGS 参数 PE 主线，优先级较低。无论结果如何，旧 R12 失败和真实 GS/深度任务要求都保留。
