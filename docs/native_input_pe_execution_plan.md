## 固定比较

编码器输出处一个width256/4-head attention残差替换旧MLP融合，只调用一次；无旧融合或四层读取叠加。L使用当前patch作为K/V、无几何偏置；P/S/G使用同一保存2048×1024内容、相同有效槽。8→16→4几何MLP的前七维为多尺度中心—射线描述，第八维为零/球形/完整log1p(2048×alpha合成贡献)。球形只在PE计算中令协方差为同迹球形，保存内容不重绑，opacity不变。四组形式参数1054672，公共1054464；L几何映射未使用、P第八列无有效自由度，S/G有效容量相同。

## 结果取舍
