# 区域监督控制的解释修正与配对有效查询控制

2026-11-10。在读取两项新oracle的成功率、误差或分场景结果前记录；原程序只输出执行进度，原方案、锁和求解结果全部保留。该修正不是由新的结果触发。

原准备记录显示，30,720个源查询中只有10,264个满足区域有效阈值。原控制将其余查询全部替换为GT-nearest。这使两项全查询oracle能够检验一个乐观复合流程，但大量真值辅助的无监督查询可能主导求解。因此，**原主参照成绩高不能单独证明区域监督查询足以对齐**。原程序的`proposed_next_direction`只保留为原规则的自动计算，不再直接作为科学决定。

补充三个确定性的不可部署控制，仅使用原`max(overlap)>=0.3`的同一源查询集合：

1. `valid_gt_nearest`：在此集合上选择真值最近中心。
2. `valid_overlap_nearest_tie`：在此集合上选择最大overlap，并在完全并列中取真值中心最近者，为主要区域控制。
3. `valid_overlap_first_tie`：同一集合上按原最低索引argmax取最大overlap，报告并列敏感性。

全部方法使用同一原刚体估计器、同一0.1半径、最多5次重估；只变同一个已固定查询子集中的对应索引。每帧对共有m个源查询，两个主要控制都枚举C(m,3)个假设；不再声称与原64查询的41,664个假设预算相同。少于3个有效源查询的帧对记为失败，其余退化情况按原求解器返回值处理，全部480对保留。最终仍对全部64个源中心评分，RMSE<0.2米。使用真值有效性掩码，不能与可部署模型排名，不能称理论上界。

主比较为`valid_overlap_nearest_tie − valid_gt_nearest`；完整报告最低索引版本−有效GT及最有利并列版本−最低索引版本。五场景等权，整场景配对bootstrap10,000次，随机种子99201–99203。报告所有场景、成功率及中位/p90、因有效查询不足而不可估计的数量；沿用既有二维位移组只作描述，不另挑子群。无新模型训练或推理。

研究决定要同时考虑主差的实际幅度、场景方向与区间，以及有效GT自身的绝对能力：若区域最大重叠在相同有效查询中仍有较大一致劣势，则有依据进一步检验共同的区域几何读出；若两种真值辅助对应都明显高于当前模型且没有明显的区域对应损失，则优先研究学习到的对应和有效性，不从乐观全查询结果独断因果。混合结果保留，不为本次机制诊断额外建立通用通过门禁。

这是对实质性混杂的修正，不是数值精度加码。保持原全量模型结果、原oracle原始记录、上一项已关闭的二维位移解释和整体研究目标；本次仍只使用原480个旧帧对。
