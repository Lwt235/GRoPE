## 最新质量对照的证据边界

## 本轮结构与证据边界

真实粗3DGS保存`μ/R/s/α/f/DC`及必要元数据；一个共享attention在四层读取，投影/遮挡进入位置偏置。保存重读与内容—几何对应使用成立，但在固定条件下未建立相对L/T/P的可靠净用途；这些层次不能互换。给定相机、静态来源、300步来源拟合和冻结骨干是临时限制；无新确认。

| 官方因果记忆通路中的额外历史稳定改善输出 | native_history1：96输出，H对R缺失区平均误差高0.24%，8/12地点改善但区间跨零；R本身已有共同首帧和近期历史 | 未建立额外1/2/3帧的稳定净增益；不能概括为原生记忆整体无用 |
| 失败已经定位到压缩、V 编码或 decoder 中的某一个 | 来源和注意力代理有信息，但单地点输出可与覆盖方向相反 | 尚未定位，不能按代理分数盲目修模块 |

上一轮诊断的两个核心事实：持续遮挡下，历史独有的有效像素来源覆盖从原始 **11.37%** 到最终槽成员的 **4.83%**；固定旧 Soft Q/K 时，高斯先验把对应来源读取分数从 **0.08560%** 提高到 **0.99047%**，固定球形为 **1.02233%**。前者是来源代理，后者是寻址代理，都不是最终任务成绩。全图 History 相对 Recent 的槽成员覆盖净减 **6.46 pp [−13.92, −1.13]**；缺失 ROI 的 −2.91 pp 区间跨零，不能笼统宣称所有区域退步。

此前地址干预把旧 Soft 的对应来源读取分数进一步提高到 **3.02276%**，新 Soft 为 **2.98348%**，但没有优于原读取的可靠输出增量；仅早期独有来源的干预也未改善主任务。旧 Soft 对应组比打乱组的去均值空间误差低 **7.39% [1.03,14.23]**，相对原读取的空间改善仍不确定。查询真值参与地址构造，只有一个固定混合比例及每片段一个打乱置换；干预不是完美教师，失败不能推出记忆内容无信息或某个模块已被确诊。

原生通路的新发现是：H对移除早期直接缓存的H-drop平均低5.10%、9/12地点改善，但区间[−0.25,+10.24]%仍跨零，仅为方向性依赖线索。额外早期来源带来平均7.65%的新增一致ROI支持，5地点为零；覆盖与输出方向并不一致。H的ROI误差约97.03%来自均值偏差平方；去均值空间误差对R平均低0.59%、区间跨零，没有经辅助指标得到明确几何增益。新模型原生单位与旧模型校准后绝对分数不能直接比较。

## 后续决策原则

“保留下来的内容，在更直接读取对应槽时，能否改善当前任务”已完成一次固定诊断，尚未得到净改进。结束这项地址干预，不自动扫描强度或重开固定 Prefix 训练修补。现有寻址代理上升已不足以支持继续沿同一读法调参。

官方原生通路已完成一次有界复现和历史验证，结束本轮追加、遮挡、删除缓存的诊断。当时计划后续回到同一内容上的位置编码增量（现已按后续授权完成，见首段及native_gaussian_pe1）：固定原生内容、来源和共同适配范围，制定原生位置项、强中心三维RoPE、球形和完整形状的配对学习比较，并在评价前分开尺度与空间结构。具体查询三维位置、形状映射和预算尚未选定；当前没有启动后继训练。

当前结果没有证明“改V”或“解冻decoder”必然有效，也不把额外三帧能否获益当作所有PE研究的永久门禁。允许收窄到已有证据支持的范围，保留较早粗记忆和区域PE的有限用途。

不以这次注意力提升为理由扩展模型、扩大任务集、补种子或扫描温度；不把固定容量的局部成员损失当作所有特征信息的丢失；不要求全部代理指标过关才能研究真实用途。旧来源、配置、强对照和所有负结果完整保留。本轮没有启动后继任务。
