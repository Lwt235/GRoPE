# 共享高斯记忆：当前可以说什么

更新：2026-11-11，完成 `native_gaussian_pe1` 后。完整目标仍是将高斯参数化作为 Transformer 读取共享场景记忆的位置依据，得到结构精炼、具有可信用途的方法。以下是当前证据边界，不把中间信号替代总体目标。

## 当前精炼结构与实际状态

最新四组原生PE比较已完成：共同适配ROI误差降低13.87%，99.95%的下降对应均值偏差平方减少；完整高斯、球形、强中心与原生适配的主误差几乎重合。D对B原始ROI误差高0.000393%、对C低0.000304%，没有实用增量，空间及输入条件分组也未建立有用优势；D查询310ms，对B/原生直接接法多9.2%/47.7%。结束此末四层、冻结writer/DPT、未压缩内容的形状扩展，不采纳新方法。不能将这一阴性扩展为粗高斯记忆无效或通用前置门禁。[完整报告](../results/gaussian_memory/native_gaussian_pe1/report.md)

粗状态保存 256 个 `中心 μ / 形状 Σ / 内容 f` 槽。位置参数通过已知相机投影，对读取同一槽内容的 cross-attention 提供空间偏好。内容放在 V，空间参数用于地址；协方差表示支撑范围，不被自动当作定位不确定性。当前状态由预测深度区域的矩合并得到，并非已经过真实 3DGS 光度优化的场景表示。相机和尺度条件也尚未消除。

较早独立粗读出接口的 Content Gaussian 保留有限工作基线地位；实际 VGGT 内部插入接口的旧 Soft 只保留研究参照。两者接口、任务和证据不同，不混写成绩。最新任务匹配训练未被采用，固定 Prefix 训练修补保持关闭。

最新 `native_history1` 复现了官方StreamVGGT的未压缩原生K/V通路，作为后续位置编码研究的载体参照。它不是256×32粗高斯状态，查询前聚合器K/V约488 MiB（近期）/781 MiB（历史），另有相机缓存；不能把它与旧高斯状态的差异称同预算改进。

| 研究主张 | 当前证据 | 判断 |
| --- | --- | --- |
| 高斯区域形状关系能帮助区域匹配 | 原固定五维与强位置编码、固定球形及地点确认的结果 | 已有有限正证据；不是所有任务的一般性优势 |
| 共享粗场景内容具有补充用途 | geometry_transport1 / global_summary1 / write_confirmation1 / content_center1 | 有条件正证据，主要伴随整体深度偏差改善；精细几何恢复未建立 |
| 空间参数能引导查询读取对应的记忆来源 | memory_addressability1 同 Q/K 换先验，旧/新 Soft 都有正向寻址增量 | 本分支有机制证据，排除了“位置项完全没有作用”的解释 |
| 更直接读取对应槽即可改善当前原生输出 | address_intervention1 固定一半对应读取提高寻址分数，但旧/新 Soft 区域误差平均增加0.47%/1.02%，区间跨零 | 没有支持净改进；旧模型打乱地址退步3.83%、区间支持退步，只是有限地址作用证据 |
| 完整高斯形状是当前 VGGT 内部读取的必要优势 | 与固定球形的寻址及实际输出比较 | 尚未建立；Center 必须保留为强对照 |
| 加入历史就能保存更多有用来源 | 原始来源覆盖增加，但重建 256 槽后全图成员对应覆盖下降 | 不成立为一般推论；需要同时报告新增和丢失 |
| 历史记忆稳定改善原生 VGGT 输出 | history_read1、visibility_control1、visibility_train1 | 尚未建立；有限受控结果不能替代整体结论 |
| 官方因果记忆通路中的额外历史稳定改善输出 | native_history1：96输出，H对R缺失区平均误差高0.24%，8/12地点改善但区间跨零；R本身已有共同首帧和近期历史 | 未建立额外1/2/3帧的稳定净增益；不能概括为原生记忆整体无用 |
| 失败已经定位到压缩、V 编码或 decoder 中的某一个 | 来源和注意力代理有信息，但单地点输出可与覆盖方向相反 | 尚未定位，不能按代理分数盲目修模块 |

上一轮诊断的两个核心事实：持续遮挡下，历史独有的有效像素来源覆盖从原始 **11.37%** 到最终槽成员的 **4.83%**；固定旧 Soft Q/K 时，高斯先验把对应来源读取分数从 **0.08560%** 提高到 **0.99047%**，固定球形为 **1.02233%**。前者是来源代理，后者是寻址代理，都不是最终任务成绩。全图 History 相对 Recent 的槽成员覆盖净减 **6.46 pp [−13.92, −1.13]**；缺失 ROI 的 −2.91 pp 区间跨零，不能笼统宣称所有区域退步。

此前地址干预把旧 Soft 的对应来源读取分数进一步提高到 **3.02276%**，新 Soft 为 **2.98348%**，但没有优于原读取的可靠输出增量；仅早期独有来源的干预也未改善主任务。旧 Soft 对应组比打乱组的去均值空间误差低 **7.39% [1.03,14.23]**，相对原读取的空间改善仍不确定。查询真值参与地址构造，只有一个固定混合比例及每片段一个打乱置换；干预不是完美教师，失败不能推出记忆内容无信息或某个模块已被确诊。

原生通路的新发现是：H对移除早期直接缓存的H-drop平均低5.10%、9/12地点改善，但区间[−0.25,+10.24]%仍跨零，仅为方向性依赖线索。额外早期来源带来平均7.65%的新增一致ROI支持，5地点为零；覆盖与输出方向并不一致。H的ROI误差约97.03%来自均值偏差平方；去均值空间误差对R平均低0.59%、区间跨零，没有经辅助指标得到明确几何增益。新模型原生单位与旧模型校准后绝对分数不能直接比较。

## 后续决策原则

“保留下来的内容，在更直接读取对应槽时，能否改善当前任务”已完成一次固定诊断，尚未得到净改进。结束这项地址干预，不自动扫描强度或重开固定 Prefix 训练修补。现有寻址代理上升已不足以支持继续沿同一读法调参。

官方原生通路已完成一次有界复现和历史验证，结束本轮追加、遮挡、删除缓存的诊断。后续回到同一内容上的位置编码增量：固定原生内容、来源和共同适配范围，制定原生位置项、强中心三维RoPE、球形和完整形状的配对学习比较，并在评价前分开尺度与空间结构。具体查询三维位置、形状映射和预算尚未选定；当前没有启动后继训练。

当前结果没有证明“改V”或“解冻decoder”必然有效，也不把额外三帧能否获益当作所有PE研究的永久门禁。允许收窄到已有证据支持的范围，保留较早粗记忆和区域PE的有限用途。

不以这次注意力提升为理由扩展模型、扩大任务集、补种子或扫描温度；不把固定容量的局部成员损失当作所有特征信息的丢失；不要求全部代理指标过关才能研究真实用途。旧来源、配置、强对照和所有负结果完整保留。本轮没有启动后继任务。
