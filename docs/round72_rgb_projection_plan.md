# R72：投影区域 PE 从给定几何回到 RGB 预测几何

2026-11-04。R71 的 12 次训练与实际审阅已完成，固定用途标准通过。
基础 PSNR：relative5 18.5807，投影 Distance 18.3753，Direct 18.3156，
URoPE 18.1408，R70 PRoPE 17.3590 dB。对四个主对照三个种子均正向，
LPIPS 均改善。外推相对距离有一个负种子、变焦 LPIPS 略差，保留这些限制。

## 假设、竞争解释与唯一主要改动

假设：仅凭参考 RGB 学到的高斯几何，也能让目标 query→参考 key 的五维
投影关系比强对照更有用。竞争解释是 R71 的收益需要传感器深度；只有投影中心
有用；直接矩阵 MLP 已足够；学习几何只能成为无物理含义的任务潜变量。

沿用 R70 的共同七参数几何头（深度加正定协方差），所有 RGB 方法具有相同
头结构与初始化，联合训练后数值可以分别适配。不加入深度监督、额外预训练、
渲染模块或新损失。模型接口只允许 ref_rgb、K、c2w；参考/目标深度均不进入
前向，目标 RGB 只用于训练损失与评价。相机是所有方法共有的已知条件。

投影、Jacobian、目标 patch 协方差、五维描述、有效性规则和 attention 位置
完全继承 R71；只把观测参考矩替换为共同 RGB 预测头。三种关系都是一个 MLP。
不依据成绩调温度、深度范围、尺度、训练长度或筛除场景。URoPE 沿用同一
官方 commit、坐标/dtype/单位/四深度锚适配；也保留共同 RGB 几何内容。

## 固定对照与预算

- 12 次新拟合：rgb_target_distance、rgb_target_direct、rgb_target_relative5、
  rgb_urope，各种子 11/22/33。R70 rgb_prope 为配对主基线；另完整展示
  R70 rgb_relative5、rgb_raymap、rgb_hrope。复用结果不计为新独立证据。
- 仍用旧 SUN3D 288 fit / 32 val / 240 old_eval，3/1/5 场景；两参考一目标，
  96×128、patch8、6 层宽192/4头、完整共同几何内容。
- 与 R70/R71 相同的共同初始化、每 epoch 输入流、60 epochs / 2160 updates、
  batch8、AdamW、纯未裁剪 RGB MSE、验证最低 MSE 选模。
- 全部 12 个模型选定后统一导出 base、extrapolate、target_zoom；不读确认数据。

## 判断与检查

主判据继承 R71：五维对 Target Distance、Target Direct、R70 RGB PRoPE、
RGB URoPE 的 base 场景等权 PSNR 均为三种子正向、均值至少 +0.10dB，
同时 LPIPS 均值不更差。完整报告 SSIM、未裁剪 MSE、裁剪比例、种子和场景。
raymap/HRoPE 的结果同时展示，若未超过它们不能称最佳。

通过则支持准备独立场景确认，并另行检验学到的几何含义与原生基元适用性；
不自动宣称一般有效。若只有给定深度通过、RGB 不通过，明确将收益限制于
给定几何条件，先诊断预测几何与学习路径，不反复延长拟合。若只胜部分对照，
保留局部用途但不晋升。次指标的小幅差异完整报告，不改成额外通用门禁。

只对本轮新风险做必要检查：严格 RGB 接口、共同初始化、与 R71 在相同显式
几何输入时的前向一致、投影关系对预测深度和协方差的有限差分/有限梯度、
CUDA 正常反向及显存。R71 的独立投影和 URoPE 检查按源身份继承。
之后核对输入流和选模、复算保存图像指标、实际查看固定样例。

## 执行

用户已明确恢复多显卡并行。最多四个自有 GPU 子任务，每次训练仍是独立单卡
训练；不改变 batch、优化器或更新次数。优先实际空闲卡（占用≤512MiB、
利用率≤10%、可用≥12GiB），GPU1 可沿用此前共享授权且可用≥12GiB。
启动前重新核实占用，不终止其他用户任务。共享/并行墙钟不用于公平速度排名。
先固定源码、依赖、数据和设置身份，再启动训练；保持 R70/R71 原文件不变。
