# R40 GPU learned PE: complete development result

2026-11-01。结论：固定主方案 `decoupled` 未通过初步深度筛选；本轮没有得到满足完整研究目标的方案。旧失败、完整目标和未使用确认数据的隔离均保留。

## 实验与核心结果

实际在两张空闲 RTX A6000 上完成 13 个角色 × 5 个配对种子 = 65 次训练，每次 1000 步。相同初始化、批次、576 个旧训练对、128 个旧验证对；每个角色独立按预定验证规则选择检查点。主方案预先固定为中心 3D RoPE 加七维中心协方差描述符距离，仅增加一个可学习标量。完整源代码和数据身份见 `results/round40_decoupled_gpu/attempt1/lock.json`。

下表为两个旧验证场景等权、再对五个种子取平均的 AbsRel；越低越好。

主方案比最强旧位置对照 point 差 2.1833%，比同容量 center_rbf 差 1.6945%，比 singleview 差 1.3421%；三个比较均为 0/5 种子获胜。相对 point 两个场景都变差。这个结论不是数值告警造成的。
主方案关闭形状惩罚后的 AbsRel 为 0.164470504，略好于保留形状。这是固定检查点的干预，不是重新训练的替代主结果；不能据此选择新模型或宣称形状永远无用。
center_rbf 明显优于 center_rope，说明本轮固定频率的相位关系不足以替代明确的局部距离偏置。独立形状描述相似度未补上这一点。这是值得进一步控制变量验证的解释，不是已证明的唯一病因。

## 值读出与可信度

另一个需要保留的反常现象：point 的原始 AbsRel 为 0.161017277，反转 V 顺序后为 0.159816470；point_pck 也从 0.161050762 改善到 0.158847653。这不证明空间错配更好，也不推翻指标复核；它说明在这个残差深度任务中，较低误差和非零 V 梯度本身不能证明模型利用了正确跨视角对应。下一步应在直接的颜色读出/渲染任务检查这一点，而不是只追求深度数字。

65 次训练和全部保存的深度干预指标已独立用 NumPy 重算；最大指标绝对差 3.64e-12。配对初始化/批次、完整输出身份和预定检查点选择均核对。独立复数 RoPE / 显式距离公式复核 65 组固定样本，赢家变化为零；“独立”指公式/计算路径独立，同一作者编写，未冒称独立人员审核。
原审计在 point_pck seed11 的最大 P 误差 2.1193e-5 时按 2e-5 阈值停止。保留原审计、日志和冻结源后，新增 impact 版本只把超差记录为待判断告警，继续所有原始指标与身份检查，没有改变容差、预测或训练。最终只有 point_pck seed11/44 告警，最大 2.2016e-5；固定抽样的 P 不改变赢家，最大深度变化 1.399e-6 m。主方案及三个决定性对照均无告警，因此该瑕疵不改变本轮负结论。该抽样不是全体数值误差上界。
区域脚本首次运行有旧 projected_support 三返回值被解包为两项的接入错误，在任何模型概率导出或标签读取前失败；原源和日志保留于首次目录。只修复解包后在 attempt2 重跑。60 组概率样本无数值告警、无赢家变化；全区域 KL/中心命中数独立重算通过，最大 KL 累加差 4.37e-11。没有因此重训模型或改变指标。

## GPU、资源与下一步

完整训练两片分片耗时分别 720.14 秒和 330.39 秒，最长分片约 12 分钟；实际阶段包括输入/身份读取等成本。峰值分配显存低于 0.47 GiB/进程，区域 GPU 前向全部 60 个模型耗时 16.08 秒。它们不是正式端到端成本门禁。
同一个合成 batch8、432×432 注意力训练工作量，3 步预热后 20 步计时：CPU 四线程 34.233 ms/步，GPU 10.898 ms/步，实测 3.141 倍。仅一次短计时、不含加载和验证，不推广为所有实验的加速比。
此前静态积分的 CPU 参考求积与 Python 调度并不能代表 GPU 不适用。之后学习、批量注意力和渲染应优先使用空闲 GPU；小型独立公式和指标重算继续用 CPU。GPU 加快验证，但不能修复目标不一致或无效设计。
停止把这版 decoupled 当成已有有效方案；不对旧验证结果进行频率/温度救援。下一项直接推进真实 GS 的 context-only 可学习颜色读出，保留全像素目标和强位置/原始 GS 对照，不以静态核门禁作为启动前提。其任务适配要单独预先固定；不能把未知 SfM 尺度直接当米，或把常量像素协方差形成的无效形状通道称为成功。具体工作草案见 docs/round41_actual_gs_working_plan.md；尚未执行，不是结果。
实际 GS、适用的完整几何/鲁棒性/尺度/成本检查、内部 R/S 贡献和未使用数据确认均未完成。研究目标继续保持 active。
