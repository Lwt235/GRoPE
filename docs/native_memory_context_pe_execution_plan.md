# 保存前的高斯邻域关系 PE：一次有限开发检验

2026-11-13，round_003，结果产生前固定。输出 `results/gaussian_memory/native_memory_context_pe1`。这不是 `native_render_parameter_pe1` 的继续训练或改版复测；该接法已结束，旧结果、配置与模型均不改。机器计划见 [round_003/plan.json](../results/gaussian_memory/autonomous_research_loop/round_003/plan.json)，形成依据见 [完整分析](../results/gaussian_memory/autonomous_research_loop/round_003/analysis.md)。

## 1. 一个问题与最小结构

**问题：在投影汇聚之前，基元之间的高斯关系能否帮助学出一份多视图共用的内容记忆，并相对强中心关系 PE 改善原生深度输出？** 此前参数字段是在渲染后送到查询 Q/K；native/coarse 的关系项也主要用于查询读取。这里改变的是内容形成阶段和参与 attention 的对象，不把换个名字或更大模型当新假设。

在原有来源特征绑定之后，仅增加一个共享的、128 维四头、固定中心邻域的 Transformer block，输出各基元1024维内容残差。它接收一份保存的来源状态，生成一份更新内容的状态；不接收查询 RGB、相机、深度、有效掩码或查询编号。几何、opacity、has_content 均固定。原 Render、覆盖衰减、2048→256→1024 融合、原生2D RoPE和DPT保留；上一轮24层读时参数PE完全不装入新模型。没有第二个writer层、新reader、几何更新、几何监督或新增损失。

这检验未被旧结果覆盖的组织方式，**不预先断言投影丢失关系是失败的唯一原因**。竞争解释包括：原独立绑定内容已足够；中心邻域和完整共同几何已覆盖有用信息；邻域更新破坏局部内容；固有3DGS形状更适合渲染而非内容关系；训练片段拟合或整体标定变化仍不能转成跨地点空间用途。

## 2. 三组真正共有的信息

复用原44份、每份2048基元的sensor/joint-validity状态和1024维FP16来源内容。以**第一来源相机**的坐标系和既有来源尺度 `u` 表示中心 `p_j`、协方差 `S_j`；该坐标变换不使用任何查询相机。单位与源身份沿用旧manifest。`S_j=R_j diag((scale_j/u)^2) R_j^T`，是单基元固有形状，不混入邻居中心离散矩，也不解释成定位不确定性。

三组共同 token 输入均为 `[LayerNorm(f_j), asinh(p_j), svec(log S_j), opacity_j]`，共1034维，线性映射到128维。`svec` 的非对角项乘√2；所有组都能通过普通内容路径访问**完整固有形状**。因此对照隔离的是把已有几何组织成关系PE的增量，不是给G独占形状数据。

只对原 `has_content=true` 基元更新。每个基元使用自己和最近31个有效中心作为邻域；少于32时全部使用、其余mask，按距离再原基元索引确定并列顺序。P/S/G共用同一邻域、有效性、输入内容及全部可学习张量。无内容槽保持原值与原有效标记，不通过writer扩大来源覆盖。

共同中心关系为14维：五个 `log1p(||δ||²/s²)`，`s=(.02,.05,.1,.2,.5)`；三个 `asinh(δ)`；以及 `δ=p_j-p_i` 分别与i的三个最近非自身有效中心方向、`-δ`与j的三个相应方向之间的六个余弦。零向量/不足参考方向填0，范数分母仅用1e−12防除零。邻域、三点角度、中心相对方向、多尺度距离及绝对中心均对P开放；任何由这些中心集合信息产生的用途不能归为高斯固有形状独有收益。这是本实验的强中心对照，不声称穷尽全部中心编码。

在共同14维后附四个关系量，三组使用同一18→64→128 GELU MLP（末层无bias）：

| 组 | 最后四维 | 共同内容中的完整协方差 | 原Render几何/覆盖 |
| --- | --- | --- | --- |
| P | 四个0 | 保留 | 原完整形状、完全相同 |
| S | 用 `S_j^iso=tr(S_j)I/3` 计算下式 | 保留 | 原完整形状、完全相同 |
| G | 用原 `S_j` 计算下式 | 保留 | 原完整形状、完全相同 |

四量为 `log1p(δᵀS_i⁻¹δ), log1p(δᵀS_j⁻¹δ), log1p(tr(S_i⁻¹S_j)), log1p(tr(S_j⁻¹S_i))`。FP64由保存的正尺度/旋转计算后转FP32；复用已有五维关系的量，不新增距离公式、温度或可调截断。P的256个首层系数对应恒零输入，正式参数量相同而有效输入秩不同，必须明报。

单层pre-LN block的每头分数为 `(q_iᵀk_j + q_iᵀr_ij)/sqrt(32)`，四头32维，邻域softmax，残差输出映射；FFN为128→256→128 GELU。最后LayerNorm与128→1024线性层生成内容残差，最后线性权重/bias全零初始化。`f'_j=FP16(f_j.float()+residual_j)`；训练前向与永久保存均使用这一同样的FP16表示，再按原接口转FP32渲染。三组共同初始化；P/S/G关系MLP也逐参数相同。普通权重/Adam仍FP32，writer算术FP32、原生网络沿用BF16。

writer只改变内容，由同一组参数服务全部地点。训练监督经查询损失更新共享writer，并不意味着查询可进入writer的输入；不逐场景优化或保存查询特定状态。评价必须为每个模型×场景保存并重载**一份**完整状态（9×44=396份），随后八个视角及两输入条件只访问该状态、查询和原renderer，不再次调用writer或参考RGB。同场景状态身份不得随查询变化。

“同内容”指三组得到完全相同的原始来源特征/完整几何及同容量writer，学习后内容不同是PE处理的结果。原Render的**算子、贡献权重和覆盖**保持，新的渲染内容 `r'=sum_j w_ij f'_j` 允许变化；不能说输出r逐值不变或用途已经保持。

## 3. 与旧尝试的区别与大纲对应

- [joint_write1](../results/gaussian_memory/joint_write1/report.md)为256槽、32维内容的逐槽MLP，学习几何/内容后接独立粗深度头；总误差收益伴随空间退步，几何更新额外作用不明。本轮不更新几何，首次在本原生Render接口中检验**跨基元关系 attention 的共享内容写入**；不把学习writer本身说成新发现。
- [gaussian_scene_memory1](../results/gaussian_memory/gaussian_scene_memory1/report.md)、[learned_projection_pe1](../results/gaussian_memory/learned_projection_pe1/report.md)、[native_input_pe1](../results/gaussian_memory/native_input_pe1/report.md)均有实际高斯特征场/attention，阴性保留；其内容为独立绑定，PE在查询读取侧，未检验本次来源内邻域编码。旧bound/soft约束、source_geometry质量诊断和native/coarse关系PE失败同样保留，不自动修补。
- 早期区域关系PE已有“相同完整几何内容、self-attention中q依赖关系向量”的条件正证据；那是观测区域，不是实际3DGS，也不是本任务效果保证。只复用已有运算形式，不称新PE公式；中心距离/角度控制在本轮共同提供。源代码参照 `models/round58_support_pe.py`、`round69_compact_relation.py`，没有恢复已失败的跨注意力一致性模块。
- O2/O3仍是一份公共粗3DGS状态；O4/O5保留原渲染读取；O6在保存前的Transformer中直接比较。它是**服务VGGT公共记忆的writer Transformer PE**，不是给VGGT原生query attention直接加PE，后者保持原2D RoPE。大纲将PE位置列为C4接口选择，未限定只能在原生query attention；因此仍回答同一公共记忆目标下的参数PE问题，但成功结论必须带这一接口范围。P/S/G共同writer对R的收益不计作O6，只有同内容/同writer的关系PE差才支持O6。C1源几何、C3读取、C5相机条件保持；C2变为共享内容编码，C4移到来源内部，C6新增writer与原接收共同训练。O1仍是图像patch token。2048槽/32邻域/128宽/单层、传感器辅助来源、已知相机尺度、静态四来源、冻结编码器、深度任务及旧数据都是实现选择或临时范围，非核心要求。

## 4. 固定数据、训练与资源

身份以 `native_training_coverage1/plan.json`（SHA `c5ff5fec2df6a7d3857a43eb1e4a60b94255dff6c317acdd6f723e4efd32c73c`）及其configuration_lock为权威：32训练/12开发地点，来源[0,3,6,9]，拟合查询[2,5,8,11]，其他查询[1,4,7,10]，原full/missing输入与标签。全部已用，无下载、无新来源拟合；`confirm`文件名及其他视角不称新确认。真正未用身份尚未核实，本开发轮不访问或预占所谓fresh数据。

P/S/G×种子20261110/11/12，共九次各2000步，batch2，18000正式更新/36000样本呈现。每次从原官方VGGT初始化，融合采用原同种子初值；新writer在独立RNG域初始化，不续训旧R/P/S/G。训练原24组frame/global blocks、DPT、原融合及writer；图像encoder和原来源状态冻结。native lr1e−6、fusion/writer lr1e−4，AdamW wd.01、clip5，原 `.5 raw logMSE + .5 centered logMSE`，同种子同逐步采样，固定step2000，不能选checkpoint或补训。保存参数量/实际活跃范围；新writer约0.4M参数，实施时精确计数而不据尾差改结构。

硬预算：**8 GPU worker小时，最多两worker，6336新预测＋4224继承评分，非训练原生前向≤6600（含200成本前向），另≤600次独立writer前向用于396状态导出/成本/必要回放；预检最多6个丢弃更新，单独计费。** source图/关系预计算纳入GPU工时，不能把准备或恢复移出预算。写入训练前向包含在正式训练工时/步数，另列次数；不与独立导出混淆。只在空闲/有余量卡运行，原12GiB进程上限、18GiB准入和6GiB余量；完全空闲卡可用14/20GiB配置，保留其他任务。

Sol启动前实时检查并建剩余字节账，不以当前约383GiB可用代替检查。预计剩余固定/峰值产物扣除后数据盘余量≥8GiB、项目盘≥8GiB准入；每30秒及大写入前检查。预计峰值余量<6GiB、实际可用<5GiB，或预计峰值余量已<8GiB且30秒出现≥0.5GiB无解释下降时暂停新作业、完整保存并让出。空间充足时的外部正常写入只记账，不因固定下降阈值反复停GPU。扣除**尚未写入**产物和真实临时重叠，不能重复扣已有文件。这些是工程预留而非科学条件；普通资源恢复不改科学锁，不删旧/他人成果。到硬预算、无法安全保存或实质科学变更则交回分析，不擅自增额。

## 5. 主量、成本和事前决定

主量不变：12开发地点原四查询、missing ROI centered log-MSE，地点及种子等权；G/P主比较、G/S形状组织归因、S/P简化比较。P/S/G相对旧32地点同2000步R/Local都报告；旧控制不重训，参数/输入差异明示。5000次配对种子×地点bootstrap，固定20261113，输出绝对差、相对降误差、每种子/地点；区间只描述三个种子与当前地点，不宣称新确认。

全部辅助量保留：raw ROI、bias²、完整全图AbsRel、开发其他四查询/合并、训练拟合查询与其他查询、原12/新增20训练地点分开，以及既有支持分组和全部失败样本。训练内或raw正结果不替换主终点。共享适配/内容改写的收益与PE额外收益分别判断。

成本分别记录：(1)原来源构建成本，继承且非零；(2)每份共享状态的新增图/关系准备、writer、保存/重载时间和字节；(3)已缓存状态的完整查询（编码器、实际Render、原融合、原生输出），writer不能藏入或漏出；(4)`T_source+T_write+N*T_query`，固定N=1/4/8/32及增量比值 `(T_write+N*T_query)/(N*T_R)`。八个独立查询是本轮可观察复用范围，32仅摊销示意。原R/P/S/G使用种子20261110、fit_00/q1 missing与fidelity_00/q2 full，各5暖身20测量，共200完整查询；相同两状态三新组writer各5+20测量，另150次，连同396导出等不超过600。没有把旧source拟合成本置零，也没有把G/P很小成本差当整个方法免费。

开发候选筛查沿用**主相对降误差≥1%、95%区间下界>0、三种子均正**，这是实用开发决定，不是统计等价或最终确认。

1. G/P达到主筛且成本/净用途无材料性反证：保留参数关系写入候选，下一步只制定真正未用数据的锁定确认。G/S均值为正、95%区间下界>0且三种子均正才支持非球形关系的额外用途；未成立则明确归因未决，不要求靠新增实验补过线。若S/P达到主筛而G/S未建立，优先较简单的球形关系候选，仍保留完整G结果。
2. P/S/G对R有共同改善而G/P、S/P未达到主筛：只保留“共享内容编码”的用途线索，**关闭本单层局部高斯关系PE写入路线的自动变体**，不能把共同新模块收益记为O6成功或为G追加层数/邻域/强度。
3. 仅训练片段或raw改善，或没有可用主增量：结束这一固定写入接法；与此前查询侧阴性一起收窄当前固定源场＋原生深度路线，不继续扫描本接口。不外推为所有Gaussian PE不可能，总体目标也不因此完成。

R/Local均值与训练内对R的差别是排序/适用范围证据，**不设置零容差均值否决**。材料性开发伤害沿用相对增加≥1%且95%区间支持增加：主量对R/Local、raw与完整AbsRel对P/R/Local。负均值跨零仍未决，不称保留用途或非劣性。成本以N=8的增量总代价相对R及候选相对P的实测代价为准，增加>10%记为当前实用性反证，完整报告N=1范围；不为临界计时差启动扫描。符合开发筛查只是允许下一次独立确认设计；确认须同时锁定PE增量、可靠下游净用途和完整输出代价，不能只确认漂亮的G/P。
