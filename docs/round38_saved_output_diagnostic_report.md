# R38 失败后诊断：位移已存在于位置质量，不能简单归咎于内容

全部 2304 个封存查询完成，独立实现逐行与汇总核验通过。结果支持的有限结论是：在能比较预测锚点格的 1506 行中，**387 行（25.6972%）的原始位置质量最大格已不包含预测中心**。原内容将 11 行移出、将 18 行移回中心格，最终不含中心的行数为 380。因此“偏移完全由内容引起”不符合这些保存输出；没有证据据此优先调整内容温度。

## 全人口与判定对象

原顺序 48 对、三个场景各 768 查询全部保留。2301 个锚点在相机前方，3 个在后方；2304 个投影都有限。1506 个位于视野内部，其余 798 个在视野外，包括上述 3 个后方锚点。没有恰落网格边界的锚点，全部为 variable-depth 分支，没有结构零。

“可比预测中心”要求前方、有限投影、处于闭 FOV、非结构零；不适用的 798 行仍保留一般 winner 和状态诊断。这 1506 行**不是**原 PCK 的 1096 个有效真值中心，不能据此重定义任务人口或推算新的 PCK。

最大格指封存 native cell 的积分质量；它不是连续密度 mode。距离取预测中心到获胜矩形的最近距离，不把到网格中心的量化误差当作格外位移。记录保留精确并列集合和 first-index 选择；本次主锚点集合与 first-index 计数一致。

## 内容、floor 与物化的分开结果

全人口中，原内容改变了 161/2304 行的 first winner。在可比人口内，完整 2×2 表为：两者都含中心 1108，仅加内容前含中心 11，仅加内容后含中心 18，两者都不含中心 369。这描述相对**预测中心**的移入/移出，不是相对 GT 的收益/损害；也不能从净移回 7 行断言内容改善了真实 PCK。

单次等面积 floor 使全人口 97 行的 first winner 改变、99 行的最大值集合改变；这些变化全部在 798 行主锚点不适用人口中。原因归类为保存数值向量加 floor 后的并列/次序变化，不能误归给内容，也不能把它称为正 raw 质量被证明为零。可比 1506 行的 raw/floor winner 没有变化。logits→log-P 和 log-P→普通 P 均无 winner 改变。

raw 锚点 log-gap 的最大值为 1.159196185；到 raw 获胜矩形距离在这 1506 行中的 p90=1.545193px、p99=13.923743px、最大值=33.391250px。大部分行的距离为零，不能把所有格外位移都解释成超过 PCK 的 8px 容差。

## 证据和下一步约束

事前冻结的 10 个边界 toy 与禁用真实加载/模型的双 metadata 冻结均通过。诊断耗时 9.888s，独立复算 15.062s，均低于各自 120s。两路分别核验并读取 2352 个原封存档案、21024 个白名单字段；没有读取新标签、重跑模型或积分、扫描参数或产生新的任务指标。每条源身份、状态、并列、2×2 计数精确一致，连续统计按冻结容差复核。

该检查不能区分 RMS 横向正则、前方条件、透视非线性和有限网格积分各自的因果贡献；也不能用 raw winner 的反例定位连续 mode。完整独立概率参考仍未通过，因此结论只针对已保存的数值实现。R38 原八门 0/8 及停止决定不变。
