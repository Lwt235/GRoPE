# R58：停止单标量高斯关系式，追踪可学习关系编码的正面证据

2026-11-02。18次训练、18个选定模型核验、72组评估及独立指标重算全部
完成。主方案不晋升，完整研究目标尚未实现。值得继续研究的正面信号来自
原先的同信息MLP对照；其收益来源仍需要拆分验证，不能直接宣称高斯结构有效。

## 实验回答什么

按照[事前协议](/home/liwt/GRoPE/ROUND58_OBSERVED_SUPPORT_PROTOCOL.md)，从
旧ModelNet官方训练集划分中构造未知相对位姿的局部对应任务。两幅点云使用
不共享原始点编号的独立采样，分别形成64个区域；每个区域以32个观测点的
中心和协方差表示，并明确加入.02²I分辨率项。这是高斯中心／旋转／尺度形式
的支撑估计，不是优化后的真实3DGS。没有读取官方测试集或保留场景。

完整式将高斯双向KL之和的平方根编码成96维正余弦向量，参与Transformer
内部的自注意力。两个点云之间的交叉注意力和最终对应只使用内容；真值位姿
仅用于标签和评分。共享骨干为两组self/cross层，全部Q/K/V、FFN与描述符
都训练。18次拟合均为60epochs、14880次更新，验证CE选模后统一导出评估。

高斯协方差在本轮描述观察区域。对应标签来自点集重叠，未将高斯公式当成
答案。非重叠查询不参与监督，但掩码不进入前向。本任务不测重叠检测或完整
配准，也没有纹理输入；几何对称性可能带来歧义，未估计其性能上限。

配对差为−4.762、−3.926、−3.435pp。条件于这三个模型、按对象重采样的

所有显式几何编码都明显超过NoPE，因此几何关系在这个任务中有用；这不等于

完整式在四个条件中都低于MLP，区域召回与中心PCK的12个配对差全部为负；
Soft EPE和CE也均更差。稀疏条件相对普通距离／距离＋角度分别低2.161／

局部正面信号也存在：低重叠时比普通距离高.365pp、比距离＋角度高.563pp，
区域召回三个种子均正向。但对象条件区间跨零，中心指标方向不一致，且仍
比MLP低2.639pp、比高斯自适应距离低.243pp。不能选取这一个条件作整体胜出解释。

四个条件的有效查询比例分别为63.49%、62.99%、45.71%、48.61%。尤其稀疏
条件改变了支撑和可评分人群；其绝对召回变高不代表对相同查询更鲁棒。
判断方法差异使用各条件内的相同查询与配对种子。没有有效查询的对象对
仍保留在缓存及覆盖率统计中：分别为58、59、161、58个／965个对象对。

## 区域描述与中心定位：冲突存在，但不构成本轮落后的充分解释

旧验证数据上的输入诊断发现：在考虑全部最大重叠并列项后，仍有4.407%的
有效查询无法同时最大化区域重叠并满足.1中心阈值，尽管有其他可用中心满足
该阈值。这是具体目标之间的有限冲突，不是两类指标一般不能一起提高的证明。

本轮MLP在四个条件中，同时改善区域与中心指标，三个种子均成立。完整式
当前效果也远低于基础条件82.340%的可用中心PCK上界。因此，不能把此次
落后视为已经达到区域／中心之间的必要妥协。

另一个[事前登记的重复性诊断](/home/liwt/GRoPE/docs/round58_development_diagnostics.md)
在旧val上比较了107710组对应关系：普通距离的平均对称相对变化为9.443%，
高斯自适应距离17.907%，完整式17.419%。893个可分析对象中，99.44%的
对象上高斯形式变化更大。这支持观察支撑关系容易随采样改变的解释，但
中心变化、支撑成员变化和非线性度量都参与其中，未独立证明协方差噪声是病因。
完整式略比去掉相容项稳定，也不能单独归咎于trace项。

该诊断不作为额外门槛。对应区域本来就可能具有不同支撑；学习型位置投影
也可以压低不稳定分量。诊断中的一次括号缺漏发生于模块解析阶段、未读取
数据，已修复并保留失败源码；主实验冻结源码没有变化。

## 决定与下一步

停止本轮单标量高斯关系候选，不开启未使用数据确认。保留MLP的正面发现：
它相对距离与距离＋角度在四个条件、三个种子的区域召回／中心PCK／CE均
改善。它只用一个两层映射，将11个高斯相关不变量变成相对PE，结构并不复杂。
这提示可以把3DGS参数化用于表达可学习的位置关系，无须先将全部关系压成
一个固定散度。

但目前缺少同一MLP结构的距离控制，以及只比较本地形状描述符的控制。
其收益可能来自更灵活的位置函数、内容比较，或者协方差方向关系；本轮
无法区分。该MLP此前是开发对照，现在选它继续研究仍属于开发发现。

下一项限定问题：在原任务、数据、骨干、预算与三个种子不变的条件下，
精确复用这个MLP，加入距离MLP、距离＋本地描述符MLP，以及距离／角度＋
本地描述符MLP。区分通用函数容量、本地内容比较和方向性高斯关系的作用。
新比较须先冻结，不能把重用数据称为新确认；通过后才设计实际场景验证。
当前尚未冻结或启动这项比较。R57的分类限制与完整一般性目标继续保留。
