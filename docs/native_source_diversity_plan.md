# 固定五维的类内来源变化开发检验

2026-11-09。在读取本轮新增高斯训练对象、拟合或评分前固定科学设计。原620对象直接迁移确认已结束；本轮是新的已用开发对象实验，不修订其结果，不使用这620对象训练、选模或重复确认。完整五维保持主候选。

## 问题、竞争解释与决策价值

前一轮三组固定模型在七个同名ModelNet类别上几乎全错，约99.8%的预测进入原训练中的ModelNet来源输出，而目标类别在训练中只来自MACGS。原60类的类别与来源绑定，因此整体迁移失效不能有效区分PE收益。

本轮假设：在固定分类任务和训练曝光预算下，引入同一类别的来源变化后，完整五维仍能比强Distance和同参数固定球形提供可靠收益。竞争解释：原生分类主要缺少类内来源覆盖；改善来源覆盖后普通距离已经足够，形状关系没有值得额外成本的稳定用途。另一个结果可能是整个任务仍学习不良，无法用它支持PE推广。

这一干预同时增加实例多样性，并减少原MACGS对象的重复曝光；不声称只隔离了抽象的“来源”变量。新增实例与来源覆盖各自的因果作用不在本轮分解，也不增加源判别器、适配器、损失模块或新PE。

## 固定训练：保留类别曝光预算，加入类内来源变化

三个方法：完整relative5、distance_mlp、fixed_isotropic5，各种子11/22/33，共九次拟合。沿用原始单基元骨干、13维完整共同内容、60类输出、原参数化和FP32计算；不混入64×32区域化、数量增强、归一化或关系投影重排。

每个训练周期仍由原6,227个fit对象按原种子序列打乱，产生390次更新，最后一个batch保留原大小。原槽位的类别、512基元子集、旋转、抖动和每步随机种子均保留。仅对上述七类槽位，以独立、固定来源采样RNG作概率1/2的替换：不替换时用原MACGS对象，替换时从相同类别的新增ModelNet fit对象中均匀抽取一个。其他53类不替换。不同PE严格使用同一有效对象、来源、子集和增强流。

因此每类对象曝光数量与原流程相同，总计120个周期、46,800次更新，原AdamW、学习率计划、标签平滑和梯度裁剪不变。它增加可抽样实例数，不能称每个对象曝光相同或与旧训练完全等价。为避免增加常驻GPU缓存，允许在CPU按同一索引采样后传输本batch；必须用旧数据核对与原GPU索引的数值及单步梯度。该执行方式不改变输入、数学公式或样本流。

选模每五个周期一次，只使用原val和新增ModelNet val。验证CE先在每个类别的可用来源内平均，再在来源之间等权，最后60类等权；七个共同类别的两来源各占该类别的一半，其他类别沿用唯一来源。所有方法和周期采用同一规则。全部九模型选定后才开放dev_eval评分，不据逐模型开发评价选择下一模型或训练长度。

## 固定评价与比较

仅base512，共九组新模型评价，人口为原765个dev_eval对象加新增262个ModelNet dev_eval对象，完整60类argmax。没有类别掩码、重校准或测试时适配。

主用途指标：七个共同类别中，每类别两来源各自准确率等权，再七类等权的准确率；它明确覆盖这七类来源变化，不能替代全60类表现。主比较F−Distance，主要归因比较F−固定球形，均为三个配对种子。

同时完整报告：相同七类各来源mCA；原765对象全60类mCA/OA/CE；七类与其余53类结果；逐类别、来源和种子；目标七类预测到其余53类的比例。F的绝对准确率与强对照是否能正常完成任务必须共同解释，不能在两者都接近零时晋升相对差。

仅作为已用数据背景，原三个方法各三种子的既有模型可在新增262个ModelNet dev_eval对象上做一次base512评价；原765对象预测按身份复用。旧新训练策略的变化是描述性结果：选模规则与可抽样实例集合也有变化，不将它当作单一来源因素的因果估计，不用背景结果替代新模型主比较。

统计采用10,000次配对种子和每个类别×来源单元内对象重采样，各方法、种子共用对象抽样；主区间条件于七个类别与这两个来源。另列类别重采样敏感性区间及逐种子差。主比较随机种子92001，归因92002，其他描述性区间按固定顺序递增。没有事后选择类别、来源子集或统计口径。

## 不同结果改变的决定

- F−Distance均值至少+0.5pp、三种子均正且联合95%区间下界>0，作为有限开发用途信号；F−球形同样须结合幅度、配对稳定性和区间支持形状归因。绝对性能、两个来源和原60类损失同时报告，不把微小次指标尾差设成新的通用门禁。
- 若整个任务得到改善但F没有稳定领先Distance，说明加入来源变化后仍未建立采用五维的原生理由，结束这一固定训练策略的推广检验。
- 若仍整体失效，报告训练/数据覆盖方案没有解决任务问题，不从地板差异推断PE普遍无效，也不自动搜索采样概率、输入归一化或分类头。
- 若只在某个来源改善，保留预定分组读数，不在本轮事后挑该组晋升一般用途。
- 满足有限开发信号后，才评估新的、覆盖该条件的未使用对象确认是否可行；本计划不授权将已有确认集改名重用。不满足时不补种子、不扫描1/2比例、不根据消融更换主方法。
