# global_summary1：固定读取候选，检验空间组织是否超过全局摘要

2026-11-10。本方案在新增训练、RGB下载、确认数据像素解码及评分前固定。承接geometry_transport1的对照发现：冻结VGGT高斯状态、协方差引导的Latent读取比强Local主误差低16.04%，比中心项低6.38%；主要来自每查询平均深度偏差减少，全部旧数据，尚未新确认。总体目标仍是可学习共享3DGS场景记忆与精炼Transformer位置编码，深度是当前读取探针。

## 假设与竞争解释

主假设：保持参考内容与空间位置的逐查询对应，比把相同参考信息汇成一个场景摘要更有用，并能在本路线未用地点维持对中心位置项及强Local的收益。

竞争解释：旧收益主要是场景级深度校准；一个依赖查询图像和相机的全局摘要就足够。旧开发选择、有限训练地点或预测几何质量也可能限制迁移。无论结果如何，本轮不改变候选、不扫描权重、不继续补种子追分。

## 固定模型与唯一新增对照

- 固定geometry_transport1的VGGT/协方差Latent、VGGT/中心Latent和宽67 Local各三种子；原surface1宽191强Local各三种子也保留。十二已有checkpoint不重训、不选模、不修改。
- 新GlobalSummary与Latent共享LayerNorm、query/local/output层、42维key、33维value及4头尺度参数，恰好145,477参数，完整初值逐值复制相同种子的协方差Latent初值。
- 局部分支仍逐patch处理。全局读取用所有query的64维q均值作为一个query，与同一256槽key学习attention；同一相机可用性、opacity及内容/几何输入保留，value相同。四头softplus尺度作为内容logit温度，初值1。读取为每个视图唯一64维摘要，广播给全部patch；没有逐patch到槽的中心距离或协方差位置bias。无效候选及空记忆规则完全沿用。
- 这个对照有完整相机坐标几何和查询条件化的内容选择，具有额外参考信息；它不是把几何删光的弱无记忆模型。它检验这项全局汇总能否替代当前逐patch空间读取，不单独隔离空间bias、query池化或温度的各自因果作用。其失败也不能否定所有可能的全局摘要形式。
- 三个新模型仍用旧十二训练地点/十二片段、72查询/288遮挡、2000步batch2、AdamW 3e-4、wd .01、clip5，种子20261110/11/12和每步采样完全配对。先训练并保存全部checkpoint，再提取确认数据。

## 固定评价与解释

主指标是有效patch的log-depth MSE，先在同地点汇总，再对三个种子配对。主比较为Gaussian对GlobalSummary、Center和强Local；同参数量附近Local为额外容量控制。报告绝对差、相对差、每种子、逐地点以及地点×种子bootstrap95%区间；这些是效果与不确定性描述，不作为三项全部通过才能继续研究的硬门禁。

三个记忆方法均作移除、打乱内容与空间绑定、错误记忆相机干预，当前视图相机不变。GlobalSummary的联合key/value槽置换应不变；只打乱内容仍可能变差，因为其全局汇总也依赖内容—几何关联。干预仅说明依赖，不替代重训对照。

## 不同结果对应的决定

1. Gaussian对全局摘要与Local有清楚增量：支持当前空间读取，按Center比较限定协方差额外价值，再在固定读取上研究共享写入。

3. Gaussian只超过Local而未超过Center：保留空间记忆用途，收窄协方差主张。
4. 新地点净收益不保持：保留旧开发正结果和全部反例，结束本固定候选的推广，不在确认集上换结构补救。
