# 3DGS 参数化位置编码研究进展与导师汇报参考

截至 2026 年 11 月 10 日上午。适合准备 10–15 分钟组会汇报；数值来自仓库已完成报告。正在进行的独立确认不计入结论。pp 表示百分点，区间为对应报告的配对 bootstrap 区间。

**当前最准确的定位：已经从“把高斯塞进 RoPE”收敛到一个五维高斯关系编码，在观测区域匹配上有独立场景证据；但尚未证明它在原生 3DGS 和强二维旋转骨干上具有普遍、稳定的额外收益。**

# 一 可以直接使用的汇报开场

“老师给我的题目是把 3DGS 的参数化形式用于 Transformer 的位置编码。我目前重点研究的是：一个 token 如果表示有大小和方向的空间区域，编码它与其他 token 的关系时，除了中心距离，是否值得显式使用高斯形状信息。

最初我尝试直接把协方差放进 RoPE 的期望形式，发现它会削弱旋转特征，效果反而下降。这提示我们，高斯的物理大小不等于中心位置的不确定性。之后也探索过静态积分核，但这条路线逐渐偏离了学习任务，所以已经停止继续修补，回到可学习注意力与强基线比较。

目前主方案只有五个关系量：一个欧氏距离、两个考虑各自形状的距离、两个有方向的形状比较量，再用一个小 MLP 接入注意力。在给所有方法相同几何输入的情况下，它在新的区域匹配场景上仍有收益。但原生高斯分类的稳定优势还不足，RGB 和投影任务也没有给出一致的形状增益。

最近加入 HRoPE 和固定二维旋转对照后，我们发现简单旋转本身就很强。因此现在的重点不是继续叠模块，而是确认五维高斯关系在这样的强骨干上到底还能带来多少可靠增量，以及适用范围应当收窄到哪里。”

# 二 这个题目想解决什么问题

## 1 中心相同 不代表空间支持相同

把 token 只看作一个点，会忽略它覆盖多大范围、沿哪个方向延伸。两个区域中心之间相距同样远，可能在各自长轴方向上接近，也可能在短轴方向上相隔很远。这两种关系可能需要不同的注意力。

高斯参数化恰好提供一种紧凑描述：中心表示位置，协方差表示大小、方向和各向异性。研究假设是：**显式组织这些关系，可以提供适合区域匹配的归纳偏置。**

这不是说 MLP 无法学到形状，也不是说现有 PE 都只知道序号。实验给对照方法同样的完整几何内容，检验的是组织方式是否更好。现代几何编码和 HRoPE 都是必须面对的强对照。

## 2 三类高斯来源必须分开

| 来源 | 含义 | 当前证据位置 |
|---|---|---|
| 深度或点集形成的区域高斯 | 对观测区域做中心与二阶矩描述 | 最可靠的正面证据 |
| 优化得到的原生 3DGS 基元 | 场景或物体重建中的真实高斯参数 | 有形状增量，但对强 Distance 的稳定优势不足 |
| RGB 预测的几何或潜在高斯 | 网络从图像估计几何 | 收益较弱且混合，暂不扩展 |

因此，现阶段不能把“区域高斯编码有效”直接写成“原生 3DGS 编码普遍有效”。渲染是尝试过的下游验证，不是研究主目标。

早期数字要分两组讲：同一组评估中，中心 3D RoPE 的 Recall@1 为 92.87%，直接期望 RoPE 为 83.51%。另一组经过验证集校准的新合成评估中，中心基线为 92.84%，独立形状通道达到 98.96%–99.28%。两组不能混成一次横向比较，合成任务也可能包含稳定形状身份线索。

# 四 现在的方法到底是什么

## 1 用五个量表达两个高斯的关系

设两个区域的中心差为 δ，协方差为 Σᵢ、Σⱼ。实际计算使用实现中固定的正定化与尺度约定。

```math
\delta_{ij}=\mu_i-\mu_j,\qquad
\phi_{ij}=\left[
\frac{\|\delta_{ij}\|}{0.2},
\log(1+\delta_{ij}^{\top}\Sigma_i^{-1}\delta_{ij}),
\log(1+\delta_{ij}^{\top}\Sigma_j^{-1}\delta_{ij}),
\log(1+\operatorname{tr}(\Sigma_i^{-1}\Sigma_j)),
\log(1+\operatorname{tr}(\Sigma_j^{-1}\Sigma_i))
\right].
```

| 分量 | 直观解释 |
|---|---|
| 欧氏距离 | 两个中心相距多远 |
| 两个形状归一化距离 | 分别站在两端区域的尺度和方向下，这个位移有多大 |
| 两个协方差比较量 | 两端的大小、形状和方向是否相容，保留比较方向 |

关系 MLP 为 5→96→96，使用 GELU，最后一层无偏置；PE 参数量为 9,792。距离对照为 9,408，规模接近。五维比旧十一维更精炼，但尚不能声称它是最小或理论最优表示。

这些关系在共同三维刚体坐标变换下不变；**不意味着整个网络严格不变，也不意味着尺度不变**。目前只使用中心和协方差，不把颜色、不透明度也包装成 PE 贡献。

## 2 与旋转如何结合

当前共同旋转版本可以概括为：先对内容 Q/K 做相同二维位置旋转，再加上 query 与高斯关系向量的交互。

```math
r_{ij}=\operatorname{MLP}(\phi_{ij}),\qquad
s_{ij}=\frac{T_i(q_i)^{\top}T_j(k_j)+q_i^{\top}r_{ij}}{\sqrt{d}}.
```

这里的二维位置来自图像区域的平均坐标，按固定规则归一化，不是 token 的排列序号。高斯关系只用于同一帧的自注意力；两帧三维坐标未对齐时，不直接计算跨帧三维差。

这是说明核心评分的简化式。当前实现还对 V 和输出做相应变换，因此不能称为“仅改变 Q/K 的标准 RoPE”。完整 HRoPE 对照还预测单应相关几何；固定 H 对照去掉该学习部分，保留相同二维旋转结构。HRoPE 原论文已经包含二维 RoPE，不能把这部分说成我们的新设计。[论文附录](https://arxiv.org/html/2610.28284v1#A1.SS3)

五维关系是成对计算后加入注意力，尚未证明能精确分解为两个 token 各自矩阵的相对乘积；所以不应直接宣称它与 HRoPE 具有相同数学形式。

## 3 计算代价

方法精炼不等于零成本：成对关系仍有二次复杂度。一次原生 512 基元基准中，代数重写将前后向时间从 188.60 ms 降到 123.81 ms，显存峰值从 10.986 GiB 降到 7.888 GiB；但相对同样优化的距离对照仍有约 16.34% 时间开销。它是特定基准结果，不能当成全部训练的加速比例。

# 五 哪些实验构成目前的证据链

不同表格的数据、任务或骨干不同，绝对分数不能直接相减来归因。以下重点保留同一实验内部的配对比较。

## 1 区域匹配 已有较可靠的独立场景证据

固定既有模型，在 9 个可用新地点、864 帧对上评价；原定第 10 个地点缺标定，没有按结果替换。所有方法获得同样完整几何内容。

| 方法 | Recall@1 |
|---|---:|
| 五维高斯关系 F | 41.389% |
| Distance | 38.402% |
| Geo 几何编码 | 38.028% |
| 固定球形控制 | 39.607% |

F 对 Distance 高 2.988 pp，对固定球形高 1.782 pp；后者配对区间为 [0.493, 3.206] pp，三个种子均为正。中心定位也改善。这支持变化协方差关系提供了超出中心距离与固定径向控制的用途。

**边界：**该 Recall@1 只在有有效标签的查询上计算，有效覆盖为 35,859/110,592，即 32.42%。它不是全部查询准确率，更不是整帧对齐成功率。另一次重新划分区域的独立确认，对 Distance 高 1.919 pp，区间 [0.019, 3.841]，但对其他强对照仍有不确定性。

证据：[区域确认报告](/home/liwt/GRoPE/results/region_confirmation/attempt1/report.md) · [区域重划分确认](/home/liwt/GRoPE/results/region_retokenization_confirmation/attempt1/report.md)

## 2 原生 3DGS 有形状价值 尚未稳定超过最强距离对照

正式测试中，以 3,845 个无已知历史重叠对象、五组新种子作为主组：

| 方法或差值 | 类别平均准确率 mCA |
|---|---:|
| 五维 F | 79.601% |
| Distance | 78.479% |
| F−Distance | +1.122 pp，区间 [−0.326, 2.693] |
| F−固定球形 | +2.244 pp，区间 [1.001, 3.446] |

因此可以说“变化形状有条件性价值”，不能说“原生任务已稳定优于强 PE”。训练后稀疏到 256 基元的条件曾有更强收益，但训练、测试都匹配为 256 时，F 对 Distance 只高 0.123 pp 且不稳定，不能据此宣布“越稀疏越适合”。

跨来源测试还暴露了整个模型的域迁移问题；加入来源多样性改善了所有方法，并未确立五维的普遍优势。这些结果限制一般性主张，但不抹掉区域任务的证据。

证据：[原生确认](/home/liwt/GRoPE/results/native_confirmation/attempt1/report.md) · [匹配数量控制](/home/liwt/GRoPE/results/native_matched256/attempt1/report.md)

## 3 两帧对齐 从局部召回走向实际几何用途

采用统一匹配和刚体求解流程，以全部 64 个源中心的对齐 RMSE < 0.2 m 判定成功。这个指标更接近实际用途，但仍只代表当前区域构造、数据和求解器。

新增 HRoPE 后，在 10 个此前未用地点、960 帧对上的固定模型确认结果为：

| 方法 | 两帧对齐成功率 |
|---|---:|
| HRoPE | 35.382% |
| 原五维 F | 32.569% |
| Distance | 30.938% |
| Geo | 30.625% |
| 固定球形 | 30.729% |

HRoPE 对原五维高 2.813 pp，区间 [0.035, 5.313]，三个种子均正。这说明强旋转与相机相关编码确实改变了竞争格局，不能只报告五维对旧弱基线的优势。这里的 HRoPE 为相同输入下的受控实现，并非照搬原论文完整图像系统。

证据：[HRoPE 独立确认](/home/liwt/GRoPE/results/region_hrope_confirmation/attempt1/report.md)

## 4 在共同二维旋转骨干上 高斯仍有开发增量

随后回到旧开发数据，给各关系方法相同的旋转结构，完成 12 次训练，另复用 6 个 HRoPE/固定 H 模型。以下为三个种子、480 帧对的结果，**尚不是新地点确认**：

| 方法 | 对齐成功率 | F 相对该方法的差值与区间 |
|---|---:|---:|
| 五维 F＋共同旋转 | 41.736% | — |
| Distance＋共同旋转 | 38.542% | +3.194 pp [1.111, 5.833] |
| Geo＋共同旋转 | 38.056% | +3.681 pp [0.069, 7.292] |
| 固定球形＋共同旋转 | 39.097% | +2.639 pp [0.069, 5.556] |
| 完整 HRoPE | 38.889% | +2.847 pp [0.278, 5.417] |
| 固定 H 旋转骨干 | 40.000% | +1.736 pp [−0.556, 3.819] |

五维在这些配对中三个种子均更高，但对最简固定 H 的区间仍跨零。**当前最关键的缺口，是高斯关系能否可靠优于这个简单且强的旋转骨干。**不能因为完整 HRoPE 均值更低，就说单应矩阵无用；完整与固定 H 的差异本身也不确定。

此外，五维仍有 58.264% 的帧对失败，尾部误差没有一致改善。结果值得继续确认，但还不适合描述为成熟对齐方案。

证据：[共同旋转比较](/home/liwt/GRoPE/results/region_rotary_relation/attempt1/report.md)

## 5 投影与 RGB 没有建立稳定的额外形状收益

五个新场景的给定几何投影确认中，五维 PSNR 为 18.059 dB，Distance 为 17.973 dB，平均只高 0.086 dB；三个种子差值为 +0.224、+0.505、−0.471 dB。虽然优于一些其他编码，但距离对照已解释了相当一部分收益。RGB 分支同样混合，因此当前暂缓扩大渲染或 RGB 任务。

证据：[投影确认](/home/liwt/GRoPE/results/projection_confirmation/attempt1/report.md)

# 六 最近的负结果 帮我们排除了什么

| 问题 | 观察 | 能得出的结论 |
|---|---|---|
| 是否特别适合大图像位移？ | 高位移组 F 15.741%，固定 H 16.680%，条件差异不确定 | 目前不支持“大位移是优势来源” |
| 是否主要是区域标签与中心求解冲突？ | 相同有效查询中，真值辅助区域对应可达 71.042%，最近中心为 75.417% | 这种冲突存在，但不足以单独解释实际约 42% 的成绩 |
| 筛掉无效查询能否挽救？ | F 41.736%→39.653%，各方法均值均下降 | 该固定筛选方法没有改善用途，不扫描阈值补救 |
| 跨帧关系一致性是否能变成收益？ | 真值参考下有条件性信息；自预测参考接法 F 降至 38.958% | 有信息不等于可部署设计能用好，关闭这个接法 |
| 是否对坐标重表达特别稳健？ | F 41.736%→41.319%，相对优势变化区间均跨零 | 没有明显任务崩溃，但高斯特有稳健性未确立 |

真值辅助实验只用于定位问题，不能当成可部署性能或严格上界。坐标重表达只改变已有三维坐标表示，没有产生新视角或新相机运动。

这些失败没有触发反复换主方法。当前仍固定完整五维，不追加筛选器、一致性模块或不变性模块来挽救每一个负结果。

# 七 为什么现在的证据比早期更可信

1. **相同信息与训练条件。** 对照获得相同完整高斯内容；固定训练预算、选模规则与种子配对，避免将额外输入误记为 PE 优势。
2. **强对照逐步补齐。** 比较 Distance、几何编码、球形控制、HRoPE 和固定旋转，不只比较自身删减版本。
3. **把层次分开。** 公式与实现正确、机制线索、实际任务收益、未用数据确认是四件不同的事。
4. **保留负结果。** 原生、跨域、RGB、跨帧一致性失败都保留；不会把已经看过的确认数据重新称为新数据。
5. **按场景和种子看不确定性。** 不把大量相关查询当成同等数量的独立场景；区间跨零表示证据不足，不表示已证明无效。
6. **审计服务于结论。** 必须检查配对、数据身份和评分正确性，但不再把微小浮点差异变成阻止任务验证的无限门禁。

仍需承认：数据范围有限，多轮开发有适应旧数据的风险；目前没有理论保证，也没有证明某个形状属性能跨任务稳定预测收益。

# 八 下一步已经固定 要回答一个明确问题

**假设：在未使用地点，五维高斯关系仍能在相同旋转骨干上，可靠超越 Distance 与固定 H。**竞争解释是：开发收益主要来自二维旋转、数据偶然性或对旧场景的适应。

已冻结 20 个未使用地点、1,920 帧对的独立确认，使用 18 个既有模型，零重训；基础条件与固定三维坐标重表达并行。元数据可用，2,841 份唯一深度数据的下载与后续评价由后台队列执行。截至本资料整理时尚无本批模型结果。

主比较是 F−Distance 与 F−固定 H：分别检查平均增益至少 1 pp、三个配对种子均正、联合区间下界大于零；Geo、球形、HRoPE 全部保留。不能只挑一个胜出的比较来宣布成功。

| 结果 | 对研究方向的实际影响 |
|---|---|
| 两个主比较均可靠为正 | 支持当前区域两帧对齐用途，整理精炼贡献；仍不推出原生 3DGS 普遍有效 |
| 对 Distance 正，但对固定 H 不确定 | 收窄结论：形状优于某些关系编码，但尚不足以证明值得加到强旋转骨干上 |
| 两者均无明确优势或退步 | 结束当前接法的推广主张，保留既有区域结果，不靠追加地点、种子或模块补救 |

这一步的价值是帮助做取舍，而不是保证得到正结果。它也不会追溯性地把旧开发未通过的比较改写为通过。

证据：[独立确认固定方案](/home/liwt/GRoPE/docs/region_rotary_confirmation_plan.md)

# 九 导师可能追问的问题

**为什么一定要用 3DGS？**

目前不能说“一定要”。更准确的理由是高斯中心和协方差能紧凑表达有限区域的几何关系，区域任务已有收益。它不依赖只有 3DGS 才有的信息；是否能形成原生 3DGS 特有优势仍待证明。

**MLP 给足数据不也能学出来吗？**

可以，这是合理竞争解释。我们的主张是显式关系组织可能改善有限数据下的学习与迁移，而非增强理论表达能力。相同输入的 MLP 和强关系基线正是用于检验这个问题。

**现在的贡献到底在哪里？**

可守住的贡献候选是：一个精炼的五维高斯关系编码、位置与形状使用方式的经验区别，以及相对于强对照的用途与失效边界。不能把已知高斯距离、二维 RoPE 或矩阵相对变换本身当作新发明；正式创新性论证还需系统文献定位。

**为什么不继续把更多模块加上去？**

目前的瓶颈是收益是否值得，而不是模块数量不足。最近跨帧一致性和查询筛选都未改善结果，继续叠加会模糊证据链。

**是不是只要 qk/√d 就已经最好？**

不是。固定旋转对照仍然进行了位置变换，当前完整实现还有 V/输出变换；五维方案则另有关系项。标准点积形式不等于没有位置结构。现有结果也未证明固定旋转在所有条件下优于完整 HRoPE。

**成功率只有约 42%，为什么还值得研究？**

相同条件下的增量可以支持研究判断，但如此高的失败率限制应用主张。需要同时报告均值、失败比例和尾部表现，不能只报告相对提升。

**最希望导师帮忙判断什么？**

如果独立确认支持区域用途，是否接受将核心贡献明确限定为“有限区域 token 的高斯关系编码”，把原生 3DGS 作为边界验证；若强旋转上的增量仍不确定，是否应结束这一接法，重新选择更符合参数化优势的任务，而不是继续扩大实验规模。

# 十 建议汇报顺序与证据入口

建议 8 页、10–15 分钟：

1. 选题与问题：中心位置不足以描述区域支持。
2. 早期发现：物理形状不能直接当作位置不确定性。
3. 方法收敛：五维关系与注意力接法。
4. 最可靠证据：独立区域匹配结果。
5. 边界：原生、投影与 RGB 为什么尚不能推广。
6. 最新强对照：HRoPE、固定旋转及共同骨干比较。
7. 负结果与诊断：为什么不继续堆模块。
8. 下一步决策：独立确认如何决定保留或收窄贡献。

时间紧时，优先讲第 1、3、4、6、8 项。不要逐轮报 R 编号；每个阶段讲清“提出什么问题、什么结果改变了判断”。
