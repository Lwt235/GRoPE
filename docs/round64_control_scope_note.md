# R64 对照能支持什么结论

2026-11-02，训练进行中、全部九次训练及评估尚未完成时记录。
本说明不改变已冻结的方案、训练预算、比较组或接受标准。

`depth_local_mlp` 与高斯组共享 RGB、像素、内参、相对相机输入，保留相同
相机注意力路径，并获得相同来源的深度及局部差分。它是有用的整体接法
对照，但其十维关系输入不与高斯关系具有完全相同的显式标定信息：前者
拼接两个相机局部的 `[z, fx*z_u, fy*z_v, r_x, r_y]`，后者还使用 `fx/fy`
构造区域大小，并用已知相对旋转/平移将中心和协方差变到共同坐标系。

一个不读取任务数据的例子：令 `z=1`、`r=(0,0,1)`、深度导数均为零、
`fy=100`，把 `fx` 从 100 改为 200。两者的局部描述均为 `[1,0,0,0,0]`，
但高斯的 x 方差从 `0.0005361111` 变为 `0.0001423611`。另一个例子保持
局部描述不变，只把两个相机的相对 x 平移从 0 改为 0.1（3米单位），
高斯距离关系 `||mu_i-mu_j||/0.2` 从 0 变为 0.5。

这些例子只证明十维关系输入没有逐项保留上述显式标定计算。完整的
普通 MLP 模型仍通过相同的相机路径、特征和 query 获得标定信息；不能
据此说它没有相机信息、两组使用不同传感器输入，或它原则上无法学习
相关关系。例子也没有测量训练后哪个因素在起作用。

因此，若高斯组胜出，可以报告该完整参数生成与关系接法在本任务中的
收益，并保留同局部信息对照的结果。仅此一项差异不能把收益唯一归于
正定性、协方差或“高斯结构”，也不能排除显式几何计算和坐标系组织的
贡献。只有后续确实需要更窄的归因时，再考虑显式接收同一公共坐标几何
的直接关系对照；这不是给所有实验新增一条强制前置门禁。若本轮没有
实用收益，该说明也不构成事后增加模块或延长预算的理由。

原有 `depth_surface` 与 `depth_footprint` 对比仍更集中：二者共享标定
构造、关系映射和初始几何，差异是加入深度导数项的整个学习过程。
