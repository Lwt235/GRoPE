# 第七轮：尺度迁移、真实 V 深度任务与实际 GS 参数

2026-10-30。已执行计划的三项实验。**证据继续支持精炼的“区域支撑位置编码”，但未支持它成为一般有效的深度预测模块，也没有支持优化后 GS 内部 R/S 的独立收益。** 第六轮封存的正结果不变，本轮负结果完整保留。

## 方法保持什么结构

图像区域由 RGB 预测三维点的均值和协方差表示。协方差包含区域内点的离散程度及连续像素自身的面积；它不被解释成中心预测的不确定度。经给定相机变换和投影，得到查询支撑 `(m_i,C_i)`。规则目标网格的所有 key 共享原生协方差 `C_k`。

令 `A_i=(C_i+C_k+h²I)⁻¹`，共同平移查询/目标坐标以改善数值条件，构造：

```
Qg_i = [(A_i m_i)_x, (A_i m_i)_y, -A_i,xx/2, -A_i,xy, -A_i,yy/2]
Kg_j = [x_j, y_j, x_j², x_j y_j, y_j²]
attention = softmax(T × visual_similarity + Qg @ Kgᵀ)
```

五个几何通道精确表示该条件下的高斯重叠分数，差别只是 softmax 消去的查询行常数。已有数学工作见[第六轮报告](round6_report.md)，这里不提出新的 Gaussian kernel 或五维二次展开定理。

本轮下游模型只有一个学习注意力/V 路径：共享、恒等初始化的视觉 Q/K 投影；V 和 query 各自一次 64 维投影；`[query, attention @ V]` 经一个 64 维隐藏层预测 log-depth 残差。六个学习对照均为 **41,345 个参数**，没有协方差网络、置信度门控或多层模块堆叠。[模型](models/round7_depth_attention.py)。

## 未见 24 像素尺度：区域优势延续，点精度有代价

沿用第六轮锁定的全部 h/T。24px 特征由原 stride8 的 3×3 特征均值再 L2 归一化获得；网格共 48 个 token，原生协方差为公共 8px 单位下的 `.75 I`。标签仍来自全部 192×144 源像素的传感器深度投影与硬目标 cell 计数。尺度改变也改变了特征聚合，因此这不是仅改变几何尺度的消融。

使用旧两个验证场景和已经打开过的第六轮五个测试场景。**这是未见尺度的旧场景诊断，不是新增独立确认集。** 后五个旧场景的等权结果如下：

| query→key stride | full 相对 fixed 的区域 KL 变化 | 改善场景数 |
|---|---:|---:|
| 8→24 | −1.82% | 5/5 |
| 24→8 | −12.53% | 5/5 |
| 16→24 | −8.07% | 5/5 |
| 24→16 | −14.87% | 5/5 |
| 24→24 | −14.44% | 5/5 |

五种新尺度等权 KL：full **0.198624**，尺寸感知 fixed **0.223403**，下降 **11.09%**。旧场景描述性配对区间约 `[−17.23%,−5.98%]`，不将重复使用的场景重新包装成独立证据。

24→8 的 PCK8 相对 fixed **下降 0.460 个百分点**，五个旧场景均下降，描述性区间 `[−0.878,−0.071]` 个百分点。相对 point_pck 均值下降 0.633 个百分点，但区间跨零。目标 stride24 的固定 PCK8 还受到目标网格量化上限影响，完整报告包含相同量化条件的对照与 oracle。

这支持区域面积对应分布更准确，也说明区域支撑变宽未必改善中心定位。[尺度报告](results/round7_scale_probe/review.md)保留全部 15,200 个 role/pair/grid 指标行、首对尚未完成时发现的 int32/long 适配失败记录、修复后协议及独立计数检查；该修复未改变模型、h/T 或评价群体。

## 实际 V 融合深度任务：独立确认未过主门槛

### 数据与公平条件

训练：旧 Harvard c3/c5/c6，各192对。验证：旧 Harvard c8、Brown bm4，各64对。新测试在任何模型分数之前按官方目录和相机元数据选定，每场景固定96对，共480对：

- `mit_46_6conf/bcs_floor6_conf_1`
- `mit_32_g725/g725_1`
- `mit_w59_conference/conference_w59_nov_6_2012_scan1_erika`
- `harvard_robotics_lab/hv_s1_1`
- `home_md/home_md_scan9_2012_sep_30`

排除此前使用或预览过的全部16个顶层 place。固定 RGB 预览未发现明确重复房间；没有按表现或 GT 有效率替换场景。这是五个 scan/place 组，不是五个独立机构。[采集审计](results/round7_split_audit/README.md)。

输出为固定24×18网格中心的 query 米制深度。所有 query 传感器有效位置进入评价，包含另一视图不可见、遮挡或出界的位置；key 传感器深度不进入前向或标签构造。V 深度由 key 的 RGB 预测点变换至 query 相机后取 z。K/C2W 来自 RGB-D 重建，因此系统不称为严格 RGB-only。

测试共有 **179,848 个有效 query 位置、50,960 个边界位置**。每个查询帧随两个固定 source 视图评价，统计不把相关观测当独立场景。边界由 query GT 的预定四邻域规则生成，只用于评价。这是粗网格深度任务，不代表原始分辨率薄结构恢复。

六角色×五配对种子 `11,22,33,44,55`，每次1,000步；初始化、batch序列、优化器和预算一致。每100步验证，选择最早达到最小场景宏平均 AbsRel 的 checkpoint。singleview 独立训练同容量的 query 自注意力模型，全部参数实际参与；另保留冻结单目预测为原始基线。

full/fixed/isotropic 沿用 `(h=.5,T=5)`，point 沿用 `(1,10)`，point_pck 沿用 `(.5,10)`。这是上轮区域校准的迁移，未声称各深度方法已完成最优调参。full/fixed 的 h/T 相同，给出直接的协方差归因对照。

验证预选的强融合基线是 **point**：AbsRel 0.161017，full 为0.161131。即使测试中另一点配置均值更低，也不更换预选基线。测试前重放全部30组验证预测，封存协议、代码、分析器、场景选择和 checkpoint，随后才导出新测试标签。

### 结果

先在各 scan/seed 内按有效位置累计，再等权平均五个场景和五个种子，无 GT 尺度对齐。表中误差越低越好。

| 方法 | AbsRel | RMSE（米） | 边界 MAE（米） |
|---|---:|---:|---:|
| 原始冻结单目预测 | 0.229687 | 0.674017 | 0.571035 |
| 同容量单视图控制 | **0.169525** | **0.581457** | **0.484106** |
| point，验证预选基线 | 0.172123 | 0.591970 | 0.499724 |
| point_pck，另一固定点配置 | 0.171505 | 0.589589 | 0.497101 |
| fixed，已知区域尺寸 | 0.171615 | 0.589916 | 0.497640 |
| isotropic，同迹各向同性 | 0.171645 | 0.590282 | 0.497919 |
| full，完整投影区域协方差 | 0.171546 | 0.589778 | 0.497217 |

full 相对锁定 point 的 AbsRel 仅降低 **0.335%**。绝对差 `−0.000577`，20,000次配对 seed×scene 交叉 bootstrap 的95%区间为 **`[−0.001358,+0.000372]`**；相对区间约 `[−0.936%,+0.169%]`。五个 seed 宏平均和四个场景方向改善，但未达到预设2%，区间也未排除零。

full 相对同 h/T 的 fixed 仅降低 **0.041%**，差值区间 `[-0.000385,+0.000201]`；相对 point_pck 则略高。full 相对 singleview 的误差均值高 **1.19%**，差值区间 `[-0.003201,+0.005478]`。**单视图均值更好，但不能称为统计显著更好。**

五项门槛中，种子改善方向与 RMSE 保护通过；2% AbsRel 改善、差值区间上界小于零、胜过 singleview 三项失败。原始预测到学习模型的整体改善说明学习深度校正有效，不能归因于 Gaussian PE。

V 路径确实参与：真实数据的 attention、V、投影和输出头梯度非零，改变 V 会改变输出。新测试 full 的 zero-V / 反序 V 干预后，平均 AbsRel 为 **0.172684 / 0.173147**，均比正常 full 略差；开发验证上反序 V 却改善了均值。这个跨分割不稳定现象不支持准确配准已带来可靠下游收益的解释；冻结干预不能替代独立重训的单视图控制。

[确认统计](results/round7_depth_analysis/README.md)包含全部方法、逐场景/种子、leave-one-scan、边界、干预和失败门槛，原始预测全部保留。

## 真实优化后 GS 参数：五维精确性有边界

在旧开发场景 Tea/Waldo 的实际优化 primitive `(μ,R,s)` 上，导出协方差与 `R diag(s²) Rᵀ` 的最大相对误差约 `3.84×10⁻⁷`。

各 key 投影协方差不同时，`(C_i+C_j)⁻¹` 随 key 变化，log-determinant 也不再是可消去的查询行常数，原五维式因而不再精确。两个真实64×64样本的去行常数 log-kernel 数值秩为 **19/14**（相对阈值10⁻⁶），超出五维 Q/K 的秩上限。把各 key 协方差替换成共同均值，在旧开发带宽 `.5` 下最大注意力概率误差约 **0.045/0.039**；共同协方差反事实则恢复约10⁻¹³的一致性。

另用独立 SfM 标签、相同均值、有效 key 集合及固定单位 key mass 做区域机制对照：旧开发主 parity 的 full CE **1.3091**，仅中心分布协方差 **1.2991**，中心距离 **1.2345**。full 优于 trace，但未胜过更强控制；另一个 parity 方向一致。无对应标签的 primitive 数值诊断与有独立标签的区域匹配分别解释，没有用高斯生成标签证明自身有效。

因此当前正结果来自**输入区域的空间支撑**，不等同于已验证“将优化后3DGS primitive内部R/S直接编成通用PE”。[实际GS与理论边界](docs/round7_gs_scope.md)保留全部细节。一般协方差的完整 pair kernel 仍可计算，低维近似也可研究，其效果需要新的证据。

## 审计与研究结论

- [开发审计](results/round7_depth_audit_development/README.md)：独立 NumPy 复算30份预测、3,840个pair指标，最大误差1.82×10⁻¹²；10个checkpoint CPU重放最大深度差7.63×10⁻⁶米。GT/mask注入不改变前向，未用GT可见性筛行。
- [新测试原始审计](results/round7_depth_test_audit/README.md)：31份预测、14,880个pair指标独立复算，最大误差7.28×10⁻¹²；240张原生sensor PNG独立解码和取样，target/valid/boundary逐位一致。
- [统计独立复算](results/round7_depth_bootstrap_audit/README.md)：1,414项核对，最大差异6.59×10⁻¹⁶，独立确认门槛失败。
- 最终相关测试 **117 项全部通过**（3.80秒），覆盖第六轮保留算子及本轮数据、V路径、尺度、统计和独立审计；通过测试不等于通过研究效果门槛。
- [预先协议](ROUND7_PROTOCOL.md)与[确认锁](results/round7_depth_confirmation/lock.json)：锁SHA256为 `7886185a8aa39f486a0ae02079b8123a99a1c3d12eb536fe828a4f7a194e4376`。第六轮封存内容未修改。

结论收窄为：**高斯支撑对区域质量如何跨尺度搬运提供了有用信息；当前简单深度网络没有显示这种信息相对强位置和单视图控制的可靠收益。** 大区域的点定位退步和内部R/S负结果还表明，区域范围、中心对应精度和渲染高斯形状需要分别验证。

保留五维区域支撑PE作为有证据的精炼子方案。关于“一般性好、真实下游有效”的更高目标，本轮仍未完成。下一设计应先检验高斯范围是否给目标提供不可替代的信息，通过强点位置和同容量单视图控制，再扩展网络；当前结果不足以支持继续堆模块或依据已打开的新测试集调参。
