# 第十轮：真实区域划分与单高斯压缩

本轮仍是旧开发数据上的方案迭代。A、B的实现和独立审计均通过，但预设效果门槛均失败。尚未获得“通过全部验证的一般方案”，未打开新的确认集，也没有改写第七、九轮下游失败。

## 为什么做这轮

此前第六轮证明：把区域支撑协方差写入位置项，在规则网格的区域匹配上优于尺寸感知位置基线。这个结论没有回答：同一个图像区域被拆分、合并或改成混合尺度后，一个高斯是否仍值得用，尤其能否胜过少量真实几何采样。

本轮固定 RGB、冻结的 RGB 深度与视觉特征、给定相机，只重新分组同一批像素。3 个旧训练场景48对用于校准，2 个旧验证场景32对用于开发验收；每对有3种 query×3种 key 划分。mixed 包括16×16、8×16、16×8、8×8真实矩形。

所有80对 forward 档案先完成，再读取 sensor 深度生成独立标签。每个像素都参与前向支撑，真实可见性不进入编码、采样选择或融合。独立数据重放核验80对、1120项源文件hash；投影 covariance 最大误差2.15e−10，其余前向量完全一致。

## 共同指标与结构

主参考固定为16×16 query父区域向8×8 key网格的真实像素质量分布。各方法先在自己的真实分区上预测，再把 key概率按面积展开到8×8，将 query按源面积聚合到16×16。所有条件使用同一批真实可见像素计分。这个设计避免目标类别数不同造成的指标错觉；它不是按真值可见质量做前向融合，也不保证可见条件分布严格不变。

Query高斯由**逐像素投影之后**的均值、scatter和像素 footprint矩构成，区别于第六轮先拟合3D高斯再线性投影。对应式是已知的Gaussian overlap相对位置bias；mixed key covariance不满足五维精确lift条件，本轮没有宣称通用五维编码。

4/16点对照也使用全部预测像素，分别取2×2/4×4等面积子区域的投影中心和平均像素covariance，舍弃子区域内部scatter。它们是概率密度混合，不是平均logit。强度预算与高斯相同：4个h×3个内容温度，逐方法在训练场景选择，再锁定验收。另设保留真实key大小的中心点控制，避免把已知目标面积信息算作查询高斯收益。

## A：Gaussian query / Gaussian key

| 方法 | 固定公共网格KL↓ | g8/g8 PCK@8↑ |
|---|---:|---:|
| 校准点基线 | 0.547630 | 94.9955% |
| 中心点＋真实key covariance | 0.576035 | 94.8079% |
| 尺寸感知fixed | 0.500434 | 95.6027% |
| 同trace各向同性 | 0.456413 | 95.4369% |
| full Gaussian | 0.442620 | 95.0768% |
| 4点 | 0.448642 | 95.3623% |
| 16点 | 0.437169 | 95.4980% |
| 单独为PCK校准的点控制 | 0.583719 | 95.6898% |

Full对主点基线KL降低19.175%，两个验收场景均改善；但对预选16点控制反而差1.247%。Full平均增量PE耗时1.758ms，16点2.633ms，仅约1.50倍速度优势，未过预设精度/速度交换门槛。该计时包含支撑准备、内容池化、算子和共同网格汇总，不含共享视觉/深度预测器和数据传输，不是端到端模型加速。

更细的证据：g8→g8时full比16点好2.758%，g16→g8时反而差3.912%；mixed query→g8差1.084%。较粗query的压缩损失值得优先分析。Full的PCK相对专门校准的点控制下降0.613pp，超过0.5pp保护线；不能只取它相对主点基线的定位微增来宣称通过。

把query covariance旋转90°而保持均值、特征、质量、特征值不变，KL变为0.562361，表明实际方向信息有作用。但方向消融有效不等于full胜过强采样。

预设门槛：点基线增益通过；强采样精度/速度、逐分区保护、PCK保护失败。具体数值和全部条件见[原始统计](results/round10_partition_a/summary.json)。

## A 审计与机制诊断

独立核验36,288条校准记录、32份预测档案中的2,592个公共概率数组、选择与门槛。指标复算最大误差1.46e−11；两个验收场景首对、所有分区和角色的162个完整概率数组用NumPy Cholesky/logsumexp重算，最大差7.69e−6。[独立审计](results/round10_partition_audit/verification.json)通过；它没有把效果失败改成成功。

另在3个训练场景首对和恒定深度同相机解析例子中，固定query高斯，仅改变key划分并合回相同g16网格。高斯key替代产生平均L1=0.016625；实际矩形积分的平均差1.15e−16，raw单元拆分误差最多2.22e−16。极大normalized outlier来自FOV外query约1e−6的尾部质量，不能代表典型效果。这一诊断只证明已知key高斯近似造成划分依赖，不能证明它是A效果失败的主因。[机制报告](docs/round10_key_partition_diagnostic.md)。

## B：只去掉已知 key 的高斯近似

保留一个query Gaussian，将位置质量改为对实际key矩形的概率积分。没有新增学习网络、置信模块或额外特征；对照也改用同样的矩形积分。原生key面积已包含在积分内，不重复添加log area。所有指标和效果保护门槛不变。

积分用固定GL32；点/各向同性控制用解析可分CDF。仅旧训练首对的1,226,178个积分与高精度通用参考最大差8.88e−16，378个独立SciPy积分最大差3.33e−16。数值正确不等于效果正确。其已知数学与EWA/区域积分相关，不能作为新颖性证明。[B协议](ROUND10B_PROTOCOL.md)、[积分数值审计](results/round10_cell_integral_audit/verification.json)。

B对预选点基线KL降低23.572%，两个场景均改善；对16点KL反而高0.762%。实测full增量7.238ms、16点80.229ms，约11.08倍速度优势，通过精度/速度交换条件。但g16→g8仍比16点差3.077%，PCK相对专门校准点控制下降0.626pp，两项保护线失败。B的成本也高于A的1.758ms，不能把同属B的11倍优势写成相对A加速。[B全部统计](results/round10_partition_b/summary.json)。

独立复算36,288条校准记录和2,592份共同概率，指标最大差7.28e−12；固定query-parent重放最大概率误差8.36e−6，18项独立adaptive积分最大差5.55e−17。[B审计](results/round10_cell_b_audit/verification.json)通过，效果门槛保持失败。

一次程序问题已保留：原B selector对数学等价的point/center汇总使用逐位相等检查，GPU舍入使全局指标相差4.44e−16，在读取B验收标签前停止。没有修改冻结源码或校准结果；单独冻结修复扩展，只将等价保护改为绝对容差1e−12，选择顺序、分数及效果阈值不变。[修复记录](docs/round10_selection_numerical_fix.md)。

第十一轮只检验一个由诊断支持的改动：在已有四个子区域代表的covariance中补回内部scatter，保留中心、权重及父区域视觉特征。无标签稠密预测几何参考支持其近似精度，但尚不能据此声称真实任务改善。[第十一轮协议](ROUND11_PROTOCOL.md)。
