# R62：RGB接回未胜过强对照，观测形状收益在同一任务中成立

2026-11-02。18次新增训练完成，另复用12个身份相同的R55模型。
36组新预测与24组旧预测的指标均经独立路径复算。全部新模型选定后才
导出新评估。使用旧开发场景，未使用确认数据；完整研究目标尚未达成。

## 问题与比较范围

检验RGB与相机条件下预测的高斯中心、协方差，经过既有11→96→96关系
编码进入Transformer后，能否优于直接学习PE、一般关系及已知相机强对照。
同时用仅中心、观测完整几何和观测中心区分可能的收益来源。

共用冻结ResNet特征、两层匹配骨干、相机信息、实际采样顺序及共同参数
初始化。新增模型均5000步，以验证CE选择检查点；未按结果延长预算。
RGB特征提取器冻结，参数头、PE及匹配网络联合训练。关系编码从R58的
视图内自注意力接入当前的跨视图注意力，不能视为完全不变的原网络。
观测组额外使用传感器深度，是诊断组，不是公平的RGB竞争方法。

## 主结果

以下为三个种子平均、五个旧评估场景等权的连续像素EPE，越低越好。

| 输入与方法 | EPE / 像素 | PCK8 / % |
| --- | ---: | ---: |
| PRoPE式相机对照 | 3.86360 | 87.336 |
| 标定平面HRoPE对照 | 3.87887 | 87.337 |
| 射线中心对照 | 3.70651 | 88.062 |
| 射线仿射对照 | 3.66693 | 88.312 |
| 相机＋MLP相位 | 3.92554 | 87.070 |
| 直接学习一般关系 | 3.86734 | 87.374 |
| RGB预测完整高斯关系 | 3.99521 | 86.935 |
| RGB预测中心 | 4.09188 | 86.452 |
| 观测完整高斯关系，额外深度 | 3.12407 | 91.230 |
| 观测中心，额外深度 | 3.38778 | 90.140 |

RGB完整高斯相对PRoPE、标定平面、射线中心、射线仿射、MLP相位的EPE
三个种子全部更差；相对直接关系只有1/3种子更好。相对射线仿射平均
差+0.32829像素，配对差+.29152/+.42262/+.27072，五个场景平均均更差。
因此本轮RGB候选不晋级未使用数据确认，也不宣称得到有效的通用方案。

RGB完整高斯相对自身仅中心控制，EPE改善0.09667像素，配对差
−.13454/−.04077/−.11469；三个种子和五个场景均改善，PCK8提高.483pp。
但CE均值反而差.00370，只有1/3种子更好。这是有限的形状参数化流程收益，
不是相对强对照的成功。完整组初始三轴尺度不同、中心组为球形，因此
不能仅据此将收益全归于学出的形状；见round62_rgb_interpretation_limits.md。

观测完整形状相对观测中心，EPE改善.26372像素，配对差
−.08951/−.44275/−.25889；EPE、PCK8和CE均三个种子、五个场景平均改善。
PCK8提高1.089pp，CE降低.05181。两组观测中心相同，支持当前任务中
区域形状关系具有额外价值。观测完整组相对RGB完整组低.87115像素，
但输入信息不同，不能把此差值写成公平RGB方法收益。

这组结果也限制了“指标只看中心，无法体现形状优势”的解释：在同一中心
匹配任务中，观测形状已有一致增益。RGB负结果的具体病因仍未确定，可能
涉及预测、参数范围、优化或接口适配，不能由观测与预测的差距直接确诊。

## 其余证据及限制

15/60帧间隔下，RGB完整高斯EPE为2.52095/6.97174，均差于PRoPE的
2.46311/6.66836及射线仿射的2.33141/6.30378。观测完整形状相对观测
中心在两种间隔均更好。帧间隔不是孤立的缩放或倾角干预。

RGB置换后，完整预测/中心预测EPE为5.42612/5.73226，观测完整/观测中心
为4.10927/4.63735。完整预测的置换分数虽略低于部分强对照，不能据此
抵消正常输入的失败，或宣称真实外观扰动鲁棒性。置换改变内容和预测
参数，不能唯一分离哪条路径贡献了差异。

观测协方差来自深度patch相对中心的二阶矩，不是优化后的3DGS或真实不确定性。
观测中心缺失时使用patch中位数，整个patch缺失则回退3m及固定球形。
旧评估719个唯一帧中，310608个token有35182个缺失中心，14771个patch
全缺失；保留全部token。该计数不等于配对查询的评估分母。

实际检查了两幅生成图。配对EPE图清楚保留了主候选相对强对照的负结果，
并显示其相对仅中心的三个正收益种子。学习曲线显示各组损失已明显下降，
射线仿射的后期验证CE较低；这些曲线不证明收敛，也不支持事后自动加预算。

## 核验与执行

原控制器session13530、观察器session17714均退出0（fe74d2、d37989）；
27个子任务全部退出0。44个冻结科学源文件未变，18个选择、60组指标
及生成文件身份核对通过（e9ecc9）。独立指标最大差1.98e−9，验证CE
复算最大差3.99e−8，CPU logit重放最大差4.98e−5，新算子独立路径最大
差2.53e−6。五项实现测试此前通过；图表在读取报告的同次工具调用中
实际打开检查。核验支持实现一致性，不证明方法效果。

新增拟合与选模累计16438.75秒；共享主机时间不是正式速度比较。
前向预检查中关系模型峰值约8.3–9.0GiB、相位MLP约.62GiB；这是相同
预检查设置下的记录，不是完整效率基准。结构层数简洁不等于计算开销小。

## 决定

保留R58–61观测几何关系候选的条件性证据，以及本轮观测形状增益；完整
保留本轮RGB主候选失败。暂不改变关系公式或堆叠新模块，不进入确认集。

下一步做一次有边界的旧fit/val诊断，检查预测参数与观测支持的差异、
当前参数范围是否限制了表达，并在固定模型上交叉替换中心与形状以定位
敏感环节。干预有分布变化，仅用于提出后续设计假设，不能替代同预算
重训对照。具体样本、干预、统计与不同结果对应的决定必须先写定。
真实3DGS、跨任务、适用鲁棒性/泛化和未使用数据确认仍未完成。

完整数字见results/round62_rgb_relations/attempt1/report1/report.md及comparisons.json。
