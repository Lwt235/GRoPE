# R17 失败后的单一方向：先否证 Gaussian 中心的语义

2026-10-31。后验设计审查，已读取[主 VAL 根验收](../results/round17_validation_root_acceptance_20261031.json)、
[完整门槛](../results/round17_validation_report_tables/accepted_decision.json)、
[全部角色宏指标](../results/round17_validation_report_tables/all_alias_scenario_macros.csv)
与[逐条件对比](../results/round17_validation_report_tables/primary_against_every_control.csv)。
主审计通过，科学门槛失败，固定 R17 停止；本文没有执行新实验、选择新参数、
读取新数据或修改冻结文件。以下是下一次旧 TRAIN 否证诊断的建议，不是已验证方案。

**只建议检查一个尚未实际测试的语义变化：Gaussian 的位置取合法预测的源
区域中心射线投影，范围取关于该中心的二阶矩。** 暂不扫描温度、协方差倍率
或径向核。它保留一个 Gaussian，但改变了输入参数的构造；不能把它包装成
仅由旧区域均值/协方差推出的新定理，也不保证区域、定位或扰动全部改善。

## 检索到的是“中心已计算”，不是“中心已用于这个模型”

[R13 predicted_centers](../experiments/round13_mixture_mechanism.py) 已用 query
RGB预测深度，在源矩形几何中心双线性取深度，沿该中心射线反投影、变换、
再投影，得到合法的 a。它只进入 `center_statistics`，没有进入 Gaussian
component bank。R13 的 OU/full1/full4 仍保持同一个区域均值。

[R10 的 center 角色](../experiments/round10_cell_probe.py)仍使用
`query['mean']`；其名称表示去掉 covariance，并不是改用该中心射线。
[R10 support](../models/round10_partition_pe.py)及
[R15/R17 查询准备](../models/round15_validation_pe.py)的 mean 是所有预测像素
投影的平均。因此，在这些相关实现及报告中未找到 `mean=a`、并以 a 为中心
重新计算范围的已执行对比。此前的[中心假说](round15_pre_result_mechanism_hypotheses.md)
仅提出需给 point 同样中心信息，没有测试这个构造。

“仅有旧区域 μ/C 不能识别指定源中心”的置换反例仍正确，但 a 使用了合法
源坐标及其预测深度，新增了旧边缘矩丢掉的对应身份，故该反例不排除它。
同时，R16 证明同 μ 的形状差异足以产生定位损失；它反对把全部失败都归咎
中心，却没有证明这次中心语义变化无用。这里的依据是一个可检验缺口，
不是已有中心改善证据。

## 一个 Gaussian 的明确形式

令 X 为原预测区域的完整投影支撑，已包含原 pixel footprint；旧
`μ=E[X]`、`C=Cov(X)`。a 来自上述合法中心射线，单位仍为 reference-8。
定义

    μ′ = a
    C′ = E[(X−a)(X−a)ᵀ] = C + (μ−a)(μ−a)ᵀ
    S′ = C′ + h²I
    τ′ = T h² / (h² + tr C′)
    P_k ∝ [∫cell_k N(x; a, S′) dx + 原面积floor] exp(τ′ content_k).

这不是把区域搬到 a 后假称保持原矩：输出均值改变，协方差为 C′，通常大于
旧 C。C′ 是原支撑关于指定中心的二阶矩，不是原区域的中心协方差，也不是
中心预测误差的 confidence。没有新增混合权重、网络、winner 投影或独立读出；
全部指标及实际 V 仍消费同一个 P。h/T 的探索预算若将来需要，必须另行冻结；
这里不选择新的数值或网格，也不声称可以直接继承 R17 的已选配置资格。

有限二阶矩下，一个有用但有限的理论解释是：对原预测支撑加独立 h blur
得到分布 ρ_h，在**全平面、没有内容或 floor、Gaussian 均值固定为 a**时，
最小化 `E_{ρ_h}[−log N(X; a, S)]` 的解为 `S=C′+h²I`。这是固定均值的
Gaussian交叉熵闭合；不是对真实可见区域标签、截断 FOV 或最终 attention
KL 的最优性。a=μ 时回退旧参数构造；C′−C是PSD，trace增加后τ′不增。
这些恒等式不能推导 native argmax 位于 a，也不能提供 PCK 保证。

证明可直接写为：令 `M=E_{ρ_h}[(X−a)(X−a)ᵀ]=C′+h²I`，h>0使M正定。
忽略与S无关的常数，交叉熵为
`H(S)=½ log det S + ½ tr(S⁻¹M)`，所以
`H(S)−H(M)=½[tr(S⁻¹M)−2−log det(S⁻¹M)]≥0`。
不等式逐一来自正特征值的 `u−1−log u≥0`，且仅在S=M时取等号。
这证明的是给定a的协方差选择，不证明所选a正确；a的源中心身份确实超出了
旧μ/C的信息。最终接口仍可压成一个位置与一个协方差，但不能隐瞒这项输入
语义变化，也不能把理论最优等同于下游有效。

## 下一次只做能决定去留的中心语义诊断

先在任何效果前冻结一次旧 TRAIN 诊断；先封存全部合法输入统计及前向，再
读旧标签。人口不能只取 R17 失败的行或 a 在FOV内的行。中心采样、深度非有限
处理、相机前后、出视野、坐标裁剪及精度必须明确沿用或单独声明，不能用标签
选择插值、中心或fallback。扰动时 a 与原预测像素支撑必须使用同一被扰动变换。

必须同时保留原 μ 和新 a 的 point/fixed 控制，旧强角色及全部原门槛不变。
若只给 full 新中心，收益混有额外输入身份，不能归为 covariance。最少要回答：
合法 a 相对 μ 是否更接近独立中心、两种中心下 full 相对同信息 point 的
定位代价是否减小、以及区域 KL 是否因此受损。逐场景/尺度的配对 benefit/harm
与完整人口都保留，不用新阈值筛掉困难行，不事后挑一种中心。

这一诊断应覆盖原中心与区域条件及原六扰动；可以分阶段冻结执行，但不能
以仅24→8成功就启动实际 V。若 a 本身没有可用优势，或换中心只让 point
同样受益而 full 的联合缺口仍在，中心语义假说缺少后续投入理由。若只改善
中心而损伤区域/扰动，也应保留失败，不能追加中心插值系数来挽救同一假说。
这些是建议的事前止损逻辑，尚未成为机器执行协议或新增已生效门槛。

## 实际 V 与真实 GS 的边界尤其重要

即使旧几何联合验证通过，仍必须按新锁完成相同容量的在线 learned Q/K/V
训练、原强对照/singleview、V干预与完整成本；R7/R8的源值质量限制没有因
换中心得到解决。计算 a、关于 a 的矩及所有检查都计入实际算子成本。

对真实 optimized GS，primitive 本来就有自己的中心 a 和关于它的 Σ；本构造
并没有产生一个新的 GS 读出算子。若原实验已直接投影该中心及Σ，它可能直接
退化成已有 Gaussian PE 的参数语义。因此这条方向首先是图像区域到Gaussian
的构造假说，不能把图像 patch 的改善称作 optimized R/S 的新证据。真实 GS
仍要解决合法 content 的定义，并通过原 RGB/原GS/强point和iso等完整比较。
若它只能修复图像patch中心、不能支持实际GS或V效用，应收缩结论，不能宣称
实现了一般目标。最终未触碰场景确认仍在所有旧阶段通过之后。
