# R25：固定 Student-t4 的旧 TRAIN 必要条件筛查

R25 的全量数值审计通过，但固定 Student-t4 方案的必要效果筛查失败：八项检查中六项 PCK 保护通过、两项区域 KL 检查失败。两项失败对应 `strong_quad` 和 `legacy_quad16` 这两个角色，它们实际是同一个 quad16 配置，不能算两个独立反例，也不能因为其余六项通过而称方案“基本通过”。等场景 KL 为 **0.468172471106**，对照为 **0.308352829322**，恶化 **51.830120%**，超过预先冻结的 2% 容许范围。

[根验收](../results/round25_student_root_acceptance_20261031.json)接受结果可供数值与开发解释，`necessary_efficacy_screen_passed=false`、`scientific_gate_passed=false`、`goal_complete=false`。按[冻结协议](../ROUND25_STUDENT_SCREEN_PROTOCOL.md)，停止这个固定 t4 候选；本报告不选择替代参数或候选，也不据此否定所有 Student 或单分布方案。

本次只使用原来的 48 对 TRAIN，三个场景各 16 对，固定 q24→g8：每对 48 个 query、432 个 native key，共 2,304 个 query。全部预测先封存，随后完成 4,608 次独立参考积分，根接受数值审计之后才打开原区域与 R13 中心标签。标签阶段保留全部 query；有效中心共 1,096 个，c3/c5/c6 分别为 382/402/312。区域可见像素质量与中心可见掩码分别使用原合同，不合并、不按预测前方或 FOV 筛选。这不是新的确认集。

固定算子以已接受的 R20 中心 a 和协方差 Ca 为输入，h=0.25、ν=4、名义 T=10。Student 的实际协方差为 S=C_exec+h²I，其 scale matrix 为 S/2；密度为 `1/(π√det S) × [1+(x−a)ᵀS⁻¹(x−a)/2]⁻³`。每个 native cell 先积分 raw mass，再加一次 `1e−30×area`，随后加内容 bias 并 softmax。τ 沿用 R20 的 float32 trace 温度，内容由完整的 Torch float32 Q24@K8ᵀ 矩阵与 τ 相乘；积分与 P 为 float64。没有重新归一化特征、调参或训练网络。

输入仅为 R20 封存支持中的六个字段：a、Ca、τ32、Q24 特征、K8 特征和 key 像素边界；没有重新读取 RGB、深度或相机数组。a/Ca 已在 reference-8 单位，key 物理边界为 `(bounds_px−0.5)/8`。协议预先声明保留原 Ca，并用其上三角定义对称 C_exec；48 对数据的非对称性和 upper-copy 改变量实际都恰为零，因此本次效果差不能归因于该处理。输入审计继承 R20 的输入构造 provenance，没有重新证明相机或局部矩构造。

正式执行前，17 项完整源码闭包、运行环境及两侧快照共同冻结；联合 66 项合成测试通过，metadata-only 预检禁止 `np.load` 和积分调用。生产与参考使用 CPU 四线程的冻结环境。根验收前后顺序为：全局预测封存→独立数值审计→数值根接受→标签效果计算→独立指标重建。两套指标的最大行差 4.547473509e−13、汇总差 9.094947018e−13，整数/Fraction/八项决定完全一致。

开发期间有一次测试失败：`1.5e−30` 字面量与 `1.5×1e−30` 乘法的 ULP 差导致测试用 `array_equal` 误拒绝。只将该合成期望检查改为 `allclose(rtol=1e−15, atol=0)`；未修改生产/参考公式或正式数值门槛。随后还在冻结前完善了工作量增量留存和 completion 自排除；正式运行使用最终联合冻结源。详见[开发历史记录](../results/round25_audit_development_history_20261031.json)：它明确说明原失败源码哈希和原始终端日志未保存，属于工具输出的转录，不伪称完整同期原件。正式执行七个阶段均完成，效果 FAIL 与程序执行成功分开记录。
