# Round15：纯四次闭合的完整训练校准与停止决定

记录时间：2026-10-30T11:17:48+00:00。

**停止当前固定 quartic_full 候选，保留全部证据，不启动旧验证。** 完整训练校准及
独立审计已经结束；这是看过训练结果后新增的开发止损决定
`post_result_development_futility`，不是预注册的 Stage B 验收失败，也不是 VAL 失败。
本轮没有得到满足原研究目标的方案。

## 设计与完成范围

候选保留相同预测像素、均值 μ、协方差 C、内容和原生 key 矩形，仅采用固定
`p(x)=exp(−q²/(4π))/(π²√det S)`，`q=(x−μ)ᵀS⁻¹(x−μ)`，`S=C+h²I`。
它是已知广义高斯分布的矩闭合，不是新分布；C+h²I也不是高斯卷积。

完成 Harvard c3/c5/c6 三个旧 TRAIN 场景、每场景16 pair，八族各12配置
（h=.25/.5/1/2，T=0/5/10），全部九分区与五尺度条件。选择目标固定为
`J=.5×common9 KL+.5×direct5 KL`；各scene/condition内按可见像素质量加权，
条件与场景分别等权。common9先进行无GT的固定面积聚合；direct5使用原生cell。
J仅用于训练选参，不能替代之后任何科学门槛。

Stage A 先按三尺度、三个定位参考的精确0.5pp保护得到可行集 `[6,9]`；Stage B
完整计算全部配置，包括不可行配置，再在该集合内选参，没有中途停止或删配置。

## 数值、独立审计与保存边界

- Stage A独立核验全部5,184概率数组、精确PCK人口/可行集；修复后的审计仅修正
  路径解析工程问题，旧失败审计链保留。Stage B全部5,184重叠概率及输入hash精确一致。
- Stage B生产端64,512概率记录先完整前向封存，再逐条bitwise重放后评价；
  独立审计重聚合全部64,512 rows、独立重建672计数表、重算固定三首pair的4,032
  保存数组指标，并恢复全部选参。每个首pair的所有配置/条件均入样本。
- 独立数值覆盖1,428矩阵，每矩阵固定8个query与全部key；最大概率误差
  1.81100834e-05（阈值1e−4），GL64→96最大归一化概率差2.25486296e-13
  （阈值1e−8），argmax变化0。tiny/zero-FOV行未删除；没有用argmax不变豁免数值误差。
- 固定样本指标最大差3.63797881e-12；summary与selection差为0。
  审计通过指来源、实现与聚合正确，不指候选科学门槛通过。
- 独立审计没有重放全部原始概率矩阵；全量独立重算的是population/aggregation，
  raw数值与指标重算为预声明样本。只保存三首pair原始概率，共1,537,304,832
  raw bytes；其余概率保留完整hash与确定性重放来源，不声称所有数组仍在磁盘。
- GL16真实数值预检的三个失败保留；同域固定GL24修复预检及后续数值审计通过。
  本轮没有新的公平角色PE计时，早期synthetic积分计时不能充当本候选效率gate。

## 为什么此时停止，以及哪些结论没有得到

冻结合同只预声明了Stage A空可行集早停；Stage B明确禁止中途早停，本轮已完整
执行并独立审计。合同没有预注册“TRAIN区域误差超过多少便停止”的Stage B gate。
因此此决定是完整结果之后的资源分配判断，不回写协议或制造一个事先存在的阈值。
明显的区域代价及可行性取舍不足以支持继续投入旧VAL，而不是已经证明VAL必败。

原 `selection.json` 的主配置、控制配置、hash和
`next_action=freeze_separate_old_validation_regression_protocol` 原样保留；
[新增停止决定](../results/round15_regional_post_result_decision.json)只停止执行该原计划下一步。
旧VAL协议、模型/runner/审计草稿和合成测试保留，但对应实验没有freeze、forward、
label evaluation、匹配isotropic效果或公平计时；真实V、实际optimized-GS/RGB/NVS
和新场景确认均未运行。R7/R9等历史失败仍未修复，通用、精炼且可信的最终目标未完成。
后续若改闭合形式，须作为新候选重新冻结设计并完成所有适用验证，不能继承一个
未运行的VAL通过或改选当前被排除的配置。
