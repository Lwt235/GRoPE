# R64计划：由一个深度场生成高斯中心与形状

2026-11-02，R63完成后的下一项设计。尚未实现、冻结或训练。

## 科学问题

R62的观测形状有效，但RGB独立预测中心及六维Cholesky形状未胜过强对照。
R63显示固定模型不能直接换入观测几何；没有广泛预测饱和证据。
下一假设H：减少中心/形状的独立自由度，用同一深度场生成高斯区域，
能改善RGB匹配的归纳偏置。竞争解释为：独立形状不是主要问题；中心预测、
特征或注意力接法仍限制效果；或增益仅来自局部邻域信息而非高斯结构。

沿用既有11维关系→96→96映射及相机Q/K/V/输出接法，只改变RGB参数生成。
不增加骨干层、几何监督、预训练特征或渲染任务。任务收益是判断标准；
不要求学到的参数逐项恢复传感器几何，也不声称当前诊断已经证明H。

## 候选：单深度场的局部高斯

保留R62一维深度头与softplus正深度映射，深度使用3米单位。相机射线
r=K^-1[u,v,1]，中心mu=z*r。token间隔8像素，内参fx/fy使用144×192图像
的像素单位。由深度场求像素导数z_u、z_v，构造

    J_u = (z/fx, 0, 0)^T + r*z_u
    J_v = (0, z/fy, 0)^T + r*z_v
    Sigma = 5.25*(J_u J_u^T + J_v J_v^T) + (1/300)^2 I

5.25是8个离散像素中心的方差。该式是局部一阶表面patch的二阶矩近似，
不是任意非平面patch的精确协方差，也不是完整纹理传输映射。
中心和协方差按既有相机变换进入同一参考系，再使用原11维高斯关系。

每层从当前token特征预测深度。内部使用中心差分：左右/上下深度差除以
16像素；边界使用相邻单边差分除以8。不使用额外平滑或可调窗宽。
按已知像素位置重建规范网格再求导，并映射回输入顺序；应保持token
排列等变，不能直接依赖输入张量顺序的reshape。此RGB生成器的输入契约
是完整规则图像网格，不能冒称处理任意缺失token集合。

协方差是秩至多2的表面项加原1cm方差地板，不再独立预测六个形状坐标。
核心关系PE仍接受一般正定协方差；这个RGB生成器的表面假设并非对所有
真实GS输入增加约束。范围与参数耦合同时改变，因此相对旧模型的差异
属于整个参数生成流程；不把任何提升唯一归因于自由度减少。

## 必要的同信息控制

三个新角色，各三个种子11/22/33，共9次新训练：

- depth_surface：上述主候选。
- depth_footprint：相同预测深度、中心和关系映射，仅令J中的z_u/z_v为0。
  两个高斯角色在初始恒深度下具有完全相同的几何，隔离加入局部导数的影响。
- depth_local_mlp：相同深度场与差分，用每个端点的
  [z,fx*z_u,fy*z_v,r_x,r_y]拼接成10维输入，经10→96→96普通MLP产生关系，
  保留同一query交互及相机路径。它获得同一局部深度/导数信息，用来判断
  高斯关系构造是否比直接学习这种信息更有价值。

相同主干初始化、实际采样流、训练/选择规则。高斯两组关系权重使用R62
的初始化方式；普通MLP输入维数不同，记录真实参数差，不宣称PE权重相同。
保留八个已有RGB控制：R55的camera_only、camera_plane、ray_point、ray_affine，
R62的camera_mlp、free_relation、predicted_full、predicted_point，各三个种子。
复用需核对模型、数据、预算和共同初始化身份，不重复计为新训练证据。

## 固定预算与决定

沿用R62原3/1/5场景、576/64/480对旧数据、冻结RGB特征和全部查询。
新增模型5000步、batch8、原AdamW/学习率及验证CE选模，不事后延长。
全部9个新模型选定后才导出新旧评估预测。基线和原固定RGB置换；
总33个RGB模型、66组指标，其中18组新预测、48组按身份复用。
主指标仍为五场景等权连续EPE，辅以PCK、CE、尾部、配对种子/场景及帧间隔。

若主候选稳定胜过同信息MLP、无导数控制和现有强对照，保留该RGB生成器，
继续适用鲁棒性/泛化开发。若仅无导数足迹有效，优先考虑更简洁足迹方案。
若只胜过R62旧完整高斯，却未胜过强控制，不视为成功。若同信息MLP更好，
不能把局部信息收益归于高斯结构。若全体失败，保留负结果并重新评估
当前RGB接法，不能自动叠加模块、提高预算或进入确认集。

先实现并检查局部公式、导数、正定性、有效梯度、排列等变及基线身份，
再冻结具体源/配置/数据；用核实空闲的GPU执行。判断无需静态核完美门禁。
实际3DGS、跨任务和未使用确认仍属于完整目标。

## 文献范围

将有限空间区域表示为高斯并用于编码已有先例；Mip-NeRF用高斯区域的
积分编码处理采样尺度。因此本设计不宣称“区域高斯编码”这一概念新颖。
这里暂时保留独立关系通道，不恢复过去已失败的物理协方差直接衰减RoPE
方案。[Mip-NeRF作者项目页](https://jonbarron.info/mipnerf/)

HRoPE将局部表面结构用于相对注意力，也明确区分可学习变换参数与严格
物理对应。它的参数来源及注意力接法实验提醒我们检查结构与输入信息，
不能把其结果直接当作本设计的效果证据；本轮同信息MLP为此保留。
[HRoPE方法与消融](https://arxiv.org/html/2610.28284v1#S3.SS3)

3DGS的可优化各向异性高斯是本项目的参数化来源；局部深度场生成器不是
原始GS优化/渲染流程的复现，也尚未验证真实优化基元上的通用效果。
[3D Gaussian Splatting原论文](https://arxiv.org/abs/2308.04079)
