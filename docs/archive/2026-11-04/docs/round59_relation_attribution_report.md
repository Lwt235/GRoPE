## 本轮检验的方案

本轮候选是R58中已经取得正面结果的`invariant_mlp`，按开发结果选择继续
研究，属于自适应开发发现。R58原先的单标量高斯散度方案仍是负结果。
18个R58模型及其72组预测精确复用；新增四类控制各三个种子，共12次拟合。

高斯描述32个输入邻居形成的观测支撑，使用中心和正定协方差。这是3DGS
参数化形式的使用，不是优化后的真实3DGS基元，也没有恢复纹理传输变换。
候选将以下11个量送入一个11→96→96的GELU MLP：

- 两中心的距离；
- 两协方差各自的三个对数标准差；
- 相对位移在两个协方差下的马氏二次型，各取log1p；
- 两个方向的协方差相容项tr(Σᵢ⁻¹Σⱼ)，各取log1p。

归一化、分辨率项及输入顺序均精确保留R58定义。所得相对向量参与自注意力
的q·r项；跨点云注意力和最终描述符匹配只使用内容，真值位姿不进入前向。
没有新预测器、损失、混合核或堆叠模块。共同骨干有314449个参数，候选PE
有10368个参数；新控制PE分别为9408、11520、11616、10752个参数。

按照[事前方案](/home/liwt/GRoPE/ROUND59_RELATION_ATTRIBUTION_PROTOCOL.md)，
控制分别检验普通距离的非线性映射、局部描述符的直接比较、中心距离与
三邻居角度，以及完整相对中心／协方差矩阵的通用映射。最后一项保留全部
相对高斯信息，避免把移除方向信息的消融误称为同信息架构比较。

全部使用相同旧ModelNet官方训练集划分、缓存、三个配对种子11/22/33、
共同权重初始化、实际样本序列和60epochs/14880次更新。验证CE选模；全部
选定后才导出新预测。旧对象和复用模型不成为新确认，官方测试集与保留
场景未读取。

中心定位解释。R58记录的有限标签冲突和支撑变化敏感性仍保留。

## 坐标变换诊断与任务收益分开解释

对全部30个模型实际评估固定坐标变换，物理点对和评分标签保持不变。
候选三个种子的区域与中心指标均精确保持，最大行概率差1.34e−6。全部
A→B查询中仍有446个argmax编号变化，因此不能声称逐查询赢家完全不变；
这一计数包含无效查询，且没有改变上述任务指标。

完整矩阵MLP最大概率变化.200，三种子共62306个A→B赢家变化；区域均值
反而微增.043pp，中心低.112pp，CE增加.00110。它的坐标敏感性是已声明
的设计属性，不能把它当实现错误，也不能仅凭这一诊断断定其4.221pp基础
差距由坐标敏感性单独造成。

两个角度控制在全量诊断中有局部较大变化，最大概率差分别.057和.113；
区域均值变化仅+.002和−.006pp。小样本检查未覆盖这些局部情况，故不能
把小样本通过扩大为全量逐查询不变保证。保留该现象及原始预测；本轮不
追溯修改冻结实现，不将其放大为阻止任务结论的数值门槛，也不把未经隔离
的近邻选择或浮点边界猜测写成已确认病因。

该变换只是一项固定开发诊断，不能替代对整个姿态分布或实际任务的验证。
