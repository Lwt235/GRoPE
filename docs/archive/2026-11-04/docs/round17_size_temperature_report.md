# R17 旧训练集温度归因结果

2026-10-31。**观测 trace 温度没有显示一致的区域精度优势；在24→8、24→16中心定位上有小幅优势。当前证据不足以替换主方案，也不足以把自适应温度称为一般性贡献。** 主 R17 VAL 的完整独立审计仍在运行，本报告没有读取它的效果。

该实验固定已接受的 h=.25/T=10，仅比较 `τ=T h²/(h²+tr C)` 与由原生矩形宽高给出的 `τ=T h²/(h²+(w²+h_rect²)/(64×12))`。两者保留完全相同的 μ、完整 C 几何、内容、原生格积分与面积 floor。这里的 h_rect 是矩形像素高度，不是带宽 h。协议见 [冻结设计](../ROUND17_SIZE_TEMPERATURE_PROTOCOL.md)。研究没有选参、等效性检验或新增科学门槛。

48 个旧 TRAIN pair、三场景、14 条件、两角色的 1,344 个矩阵全部保存并在读取旧标签前全局封存。原方案的 672 个矩阵全部逐位重现已接受的 R17B。生产与独立审计均完成；[根证据链验收](../results/round17_size_root_acceptance_20261031.json)核对了两个目录的全部 836/43 项文件、来源与快照及四项生产结果绑定，之后才解释以下效果。

## 区域变化很小，中心变化随尺度不同

区域 KL 越低越好。下表的相对变化均为“尺寸温度相对观测 trace 温度”；没有把它们当作通过门槛。

| 指标 | 观测 trace 温度 | 尺寸温度 | 尺寸温度相对变化 |
| --- | ---: | ---: | ---: |
| common9 KL | 0.511794322 | 0.511192982 | −0.1175% |
| direct5 KL | 0.184888119 | 0.184725860 | −0.0878% |
| 描述性 J | 0.348341220 | 0.347959421 | −0.1096% |

14 个条件的 KL 场景宏平均均略偏向尺寸温度，但不同场景并不一致：c3 的 common9/direct5 分别恶化 0.0776%/0.0181%，c5 分别改善 0.0373%/恶化 0.0580%，c6 分别改善 0.2717%/0.1925%。不能把宏平均的方向写成所有场景都获益。

完整中心结果如下；PCK 差值是“尺寸 − 观测”，单位为百分点。benefit/harm 是改成尺寸温度后，可见查询由错变对/由对变错的整数数量。指标仍按原协议先在场景内汇总，再等权平均三场景，所以百分点不等于池化净计数除总查询数。

| --- | ---: | ---: | ---: |
| 8→8 | −0.3078% | +0.2049 | 33 / 15 |
| 8→16 | −0.0825% | −0.0404 | 18 / 22 |
| 8→mixed | −0.1110% | +0.1568 | 31 / 17 |
| 16→8 | −0.2022% | +0.0992 | 4 / 2 |
| 16→16 | −0.0493% | +0.0065 | 3 / 3 |
| 16→mixed | −0.0903% | +0.0899 | 3 / 1 |
| mixed→8 | −0.2360% | +0.1316 | 14 / 8 |
| mixed→16 | −0.0711% | −0.1113 | 9 / 15 |
| mixed→mixed | −0.1140% | +0.0295 | 14 / 13 |
| 8→24 | −0.2040% | +0.1003 | 10 / 1 |

24→8 的观测温度 PCK 为 91.9355%，尺寸温度为 91.5756%；尺寸温度在 c3/c5/c6 分别净损失 1/2/1 个正确查询，三个场景都略差。相反，8→8 在三个场景都略偏向尺寸温度。这样的尺度取舍不能由“哪个宏指标稍好”消除，也没有证明一种温度全面更优。

两角色在各条件全部查询上的 argmax 翻转率约 0.217%–1.997%。这些是方法之间的变化，不能与下文数值审计的 production/reference argmax 差异混淆。完整场景、条件、原生尺寸分层、精确 Fraction、翻转及输入描述保存在 [原始已审计汇总](../results/round17_size_temperature_attribution/summary.json)，另有保留全部人口的 [JSON/CSV表格与外部验收回执](../results/round17_size_temperature_report_tables/acceptance.json)。没有给非线性的 common KL 分配虚构的原生尺寸贡献。

## 全量温度并不像早期小样本那样接近

本轮输入描述涵盖 39,888 个唯一查询，按 scene×query partition×width×height 的预设21组统计，不随 key 条件重复计权。以下给出三个方形 query 分区的全量中位数，包含所有原人口查询。

| query | 名义尺寸温度 | c3 观测温度中位数 | c5 | c6 |
| --- | ---: | ---: | ---: | ---: |
| 8 | 2.7273 | 2.2040 | 2.4165 | 2.1539 |
| 16 | 0.8571 | 0.6560 | 0.7325 | 0.6340 |
| 24 | 0.4000 | 0.3028 | 0.3401 | 0.2879 |

24px 的中位数比值为 0.7570/0.8503/0.7196，分布还包含更低和更高的温度；mixed 的两个矩形方向也完整保留。因此，早期96查询描述的近似不能外推到全量人口。效果差异较小并不是“两种温度逐位或数值近似相同”的证明；输入分布差异也不是效用或因果机制证明。

## 验证范围与后续决定

11 项生产测试与21项审计测试通过，正式独立审计重新检查全部概率/argmax、672套目标计数、指标、配对与分层汇总，并核对全部实际 τ。三个首 pair 的84矩阵、672固定 query 行使用独立 NumPy 支撑与 GL64/96 参考；最大 production/reference 概率误差为 5.142×10⁻⁶，same-raw 误差为 5.329×10⁻¹⁵，GL64/96 收敛误差为 1.193×10⁻¹⁵，指标与汇总误差分别为 9.095×10⁻¹³、5.552×10⁻¹⁷。预声明容差全部通过。14个 tiny-FOV 参考行保留，数值参考 argmax 差异为0。[独立验证记录](../results/round17_size_temperature_independent_audit/verification.json)说明了共享旧准备/高斯重放与独立参考各自的边界；没有把全量共享重放称为全量独立前向。

保留固定主方案，等待其完整 VAL 科学判定与同温度各向同性归因。[结果后决定](../results/round17_size_post_result_decision_20261031.json)不新增 λ 网格或其他模块，不把尺寸温度改成新的主选。观测 trace 在温度中的额外作用目前是有限、随尺度变化的；两角色都使用完整 C 几何，故本研究没有检验“删除 C 是否无损”。

这是条件性、设计后的旧 TRAIN 描述，不能提供统计等效性、成本优势或独立泛化结论，也没有完成实际 V、真实优化 GS 和未使用场景确认。生产 summary/completion 中原有的 `independent_audit_pending=true` 是封存时状态；实际审计验收由外部回执绑定，不回写封存文件。此前的合成 dtype 接口失败、元数据预检脚本字段错误及其修正记录保留，正式数据运行未发生这些失败。
