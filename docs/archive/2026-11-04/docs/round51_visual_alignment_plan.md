# R51 下一步：在真实视觉匹配中检验同一个局部框架

2026-11-02。以下保留初始设计草稿；现已由ROUND51_VISUAL_ALIGNMENT_PROTOCOL.md
落实并完成，30次GPU训练和60组评估均已结束，详见round51_visual_alignment_report.md。
用户追加的HRoPE/MLP比较已纳入，共10方法×3种子。
包括R50适配版和按论文截断/旋转约定实现的HRoPE；官方代码尚未公开可运行实现。
用户已授权持续研究，无需再次请求继续许可。真实确认数据仍未访问。

R50的RGB置乱几乎不影响结果，说明提供三维中心和标定相机后，实验主要在
学习几何映射。这限制了它对视觉邻域对齐假设的解释力。R51只改变任务输入
条件与真实图像来源，优先保留R50位置算子，避免同时更改多个科学因素。

拟用已反复使用的SUN3D匹配开发数据：R46锁定的576训练、64验证、5场景480
旧评估对及原标签。所有方法接收同一128维RGB ResNet特征、图像位置及相机
内外参；不向任何模型输入真值或预测的三维中心、深度、法向和协方差。
HRoPE/GS的局部参数从公共视觉/相机表征学习，不声称物理真值或唯一性。
相机信息表达在每对的查询相机坐标系，并固定单位，保留内参和相机原点信息。
原生像素坐标与归一化内参必须保持一致；R50对角内参假设不能直接用于任意K。

主方案暂保留完整GS协方差框架。比较相同信息的MLP、自由仿射、HRoPE适配、
普通RoPE、各向同性GS、恒等框架及NoPE。距离偏置可保留为R50连续性对照。
NoPE仍接收相同位置/相机信息，只去掉显式位置算子。所有模型重新训练；
不同输入条件的R46/R47模型不能冒充本轮相同输入的配对对照。

沿用两层96D完整双向Transformer和最终无额外几何的匹配头。种子11/22/33，
1000更新、batch8，公共初始化/实际批次配对，按64旧验证对的CE选模。
真实旧标签可能只有q->k方向；先核对接口，明确单向监督而非重新造标签。
冻结科学方案后再训练，普通实现修复保留记录即可，不再加全历史门禁。

主要观察连续定位误差（soft EPE，连同CE/AUC/PCK4/PCK8、各场景差值），
先计算网格可达上限再解释阈值。不得沿用R50基准+1pp这个已证实不适用的
幅度要求。精细误差改善不能掩盖明显的粗匹配或尾部退化。三个种子属于
开发信号，不是可信度已经充分的最终确认。

必须以固定RGB置乱诊断检查视觉内容是否真的参与；相机/位置共同保留。
如视觉内容仍不影响匹配，先解释任务信息结构，不能按几何拟合高分晋级。
如框架收益也被恒等/各向同性/自由仿射复现，不归因于完整GS形状。
若整体和几何敏感条件支持同一精炼形式，再扩种子/第二任务及未用确认；
若仍无收益，应据竞争解释迭代，不能只靠换主指标重命名成功。

可复用资源：experiments/round46_native3d_train.py的lock记录、
experiments/round46_native3d_data.py的帧身份、experiments/round5_cache.py的
RGB特征/相机来源。读取原有缓存即可，不重新运行深度模型。R50模型源码冻结，
新内容维度或NoPE接口应在R51文件中实现，不修改R50。实际GS位置模块将继续
是一个紧凑的相对矩阵算子，不引入渲染头、额外任务损失或多分支补丁。
