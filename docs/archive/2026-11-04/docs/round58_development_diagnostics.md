# R58 开发诊断：观察支撑关系在独立采样后的重复性

在 R58 仍训练、尚无 old_dev_eval 模型预测时登记。主实验协议、代码、
预算及选模规则保持冻结。本诊断使用已有 val 缓存，结果只帮助解释机制，
不新增晋升门槛，也不据此选择温度、频率或新候选。

问题：使用有限邻域估计的高斯关系，能否在正确对应的局部区域之间保持？
竞争解释是普通距离已经足够稳定，而协方差参与后放大了采样或中心变化；
也可能三种关系都稳定，后续差异主要来自编码或学习方式。

固定比较：同一批对应 token 对上的欧氏距离、双侧高斯自适应距离和完整
高斯关系。对应映射只在本离线诊断中使用真值共同坐标，选最近中心且中心
误差<=.1、点集重叠>=.3 的 token。两个 token 均满足条件、映射到不同的
目标 token，且源/目标两边中心间距均>=.1，才构成一个可比较关系。两方向
都计算。每个对象、每个方向用固定随机种子最多选64个无序 token 对；
未满足条件的对象/方向保留计数。不是训练数据筛选或前向位姿输入。

报告三个量：对称相对误差 2|a-b|/(a+b) 的分布；实际96维正余弦输入的
RMSE；每对象两个方向合并后的平均误差及其跨对象摘要。普通距离使用
主实验固定的/.2；高斯量分别为 sqrt(metric/2) 和 sqrt((metric+shape)/2)。
不按结果修改这些尺度。输入身份、样本数量和选择规则随输出保留。

若高斯关系明显更易变，这支持“观察支撑及其关系不够重复”的解释，但不能
单独定位为协方差估计误差：中心变化与非线性度量也参与其中。若重复性接近，
则不能把后续弱收益简单归咎于形状噪声。任何方向都不代替主实验的训练、
强对照、鲁棒性和未使用数据确认。
