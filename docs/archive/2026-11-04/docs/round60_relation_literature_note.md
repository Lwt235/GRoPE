# R60运行期间：法向点对关系是需要纳入的竞争解释

2026-11-02。在R60旧评估结果尚未导出时查询原始论文。本文不改变R60的
模型、数据、预算、指标或判断范围，也不把未执行的控制当成已完成比较。

[RoITr原文§3.1](https://arxiv.org/html/2303.08231v2#S3.SS1)使用PPF描述点对：
距离、两条法向各自与位移的夹角，以及两法向的夹角；并将几何关系用于
注意力和消息聚合。它还包含分层局部描述、全局聚合及匹配流程。因此，
“将不变几何关系映射到注意力”本身已有明确先例。本项目没有复现该完整
系统，不能将现有距离／中心三点夹角控制称为RoITr复现或法向PPF控制。

以下是对本项目公式的独立代数分析，不是该论文的实验结论。若观察区域
近似轴对称，写作

    Sigma_i = a_i I + b_i n_i n_i^T,
    P_i = alpha_i I + beta_i n_i n_i^T,
    alpha_i = 1/a_i,
    beta_i = 1/(a_i+b_i) - 1/a_i.

其中a_i>0、a_i+b_i>0、n_i为单位向量；薄平面对应b_i<0。令delta为中心
位移，可直接得到

    delta^T P_i delta
      = alpha_i ||delta||^2 + beta_i (delta dot n_i)^2,

    tr(P_i Sigma_j)
      = 3 alpha_i a_j + alpha_i b_j + beta_i a_j
        + beta_i b_j (n_i dot n_j)^2.

所以在这一条件下，当前方向关系可由距离、谱和无符号法向夹角组合表示。
这并不证明所有真实区域轴对称，也不证明PPF控制与候选效果相同；它说明
必须保留“普通法向关系足够解释收益”的竞争解释。一般三轴协方差还含有
切向各向异性，而完整张量在各向同性附近不需要任选一个法向方向；这些
只是可能的结构差异，尚未建立任务优势。

R59的局部描述符控制不含法向方向，中心三点角度控制也未单独检验法向。
完整矩阵MLP包含该信息，但它同时改变了旋转不变性与信息组织方式。因此
这些控制无法独自确定“协方差关系比常见法向PPF更有价值”。

后续若继续这一候选，应固定同骨干、数据、预算和训练流程，加入从同一
输入协方差导出法向／谱的关系控制。符号与近重根处理要先明确；高斯只
提供无向轴，不能偷偷给控制或候选额外定向真值。若仅适配PPF关系输入到
共同MLP，应明确称为PPF启发的同骨干控制，不称完整RoITr复现。是否进一步
对比完整系统，取决于最终实际任务主张的范围。

当前没有执行这些新控制，没有由此修改R60冻结协议，也没有新增通过门禁。
先完成R60，再结合实际结果决定具体下一步；无论结果正负，都不以“高斯”
命名或不变性的数学性质作为新颖性与一般有效性的证明。
