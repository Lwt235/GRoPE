# R17 VAL 已验收证据的独立解读

2026-10-31。**工程/数值独立审计通过，预声明科学交集未通过；应停止原样候选，保留全部失败。** 零态区域精度和相对 quad16 的速度是实质性优点，但不能抵消大 query 尺度、旋转扰动及两项定位保护失败。本记录只读取已完成且已被 root 验收的 JSON/CSV；没有读取新数据、解码概率/标签、执行实验、修改算子或重新选参。

唯一主选仍是 TRAIN 已选择的 `trace_full,h=.25,T=10`（o00）；它用完整 query 协方差 C 的高斯原生格质量乘内容因子，内容系数为 `tau=T*h²/(h²+tr C)`。定义、数值路径和门槛见 [候选协议](../ROUND17_CANDIDATE_PROTOCOL.md) 与 [VAL 协议](../ROUND17_VALIDATION_PROTOCOL.md)。C 是空间支撑，不是已校准的几何不确定度。

本轮是重复使用的旧开发 VAL：Harvard c8、Brown bm4 各 16 对，共 32 对；19 个语义 alias 对应 15 个唯一算子。每对保留七状态×九原分区条件，加零态五个 24px 尺度条件，共 68 条件、32,640 个矩阵。strong regional point 与 legacy point 同为 o02；strong quad16 与 legacy quad16 同为 o07。保留两个命名比较，但不把同一算子的重复 alias 当作独立复现。

区域 KL 先在场景/条件内按可见像素质量加权，再等权平均条件和场景。原九条件是固定 common 空间的 KL；五尺度是 native direct KL，不能混成同一个逐行平均。PCK@8 使用原生 argmax、固定合法中心人口、整数计数和精确等场景 Fraction；下文 pp 是百分点，显示舍入不参与门槛判断。没有把这些描述性结果写成新的场景总体统计推断。

## 可信度、适用范围和两个机制含义

独立审计重算了全部 **32,640 行**指标；全部 **32,640 矩阵**做了共享生产算子逐位重放。保留概率 **4,080 arrays / 2,085,968,160 raw bytes** 全部重算指标；独立重建 **26,592 sensor centers、448 count-table pairs、224 pair/state 重投影**。独立数值参考覆盖两个固定首 pair 的 **2,040 matrices / 16,320 query rows**，不是全部矩阵的独立前向：最大概率误差 **4.617028342e−5**（阈值 1e−4），参考收敛误差 **4.074518500e−14**，数值失败 0、数值 argmax 变化 0；逐行指标最大误差 **1.818989404e−12**，summary 误差 0。数值 argmax 一致不等于 PCK 科学通过。

归因另核对全部 **704 support groups / 176,928 queries**，主选和 isotropic tau32 精确一致、最大差为 0；该检查共用准备路径，只证明控制匹配，不能单独证明效果。生产 summary/completion 内 `independent_audit_pending=true` 是封存当时状态；后来的外部 verification/验收绑定其完成状态，不能回写封存对象。

1. **内容抑制缓解了当前强固定内容的 KL 损害，却没有解决单高斯在大 query 和视角误差下的区域/中心目标冲突。** g24→g8 与 Ry±1° 的失败，以及 mixed 定位退化，表明连续点密度的位移界不能当作原生格 argmax、PCK 或真实区域 KL 保证。这是结果与理论边界相符的解释，不是已定位出唯一因果来源。
2. **方向性 C 的区域价值、定位价值和积分成本需要分别判断。** 同 tau 的 full 比 isotropic 有稳定方向的宏 KL 改善，但 coarse-query 定位和约 4.70×成本代价仍在；这不能证明“完整 C 必须用于所有角色”，也不能据本轮失败把 isotropic 自动改成新主选。

正式决定仍为 `stop_unchanged_candidate_preserve_failure`。本轮没有 actual learned-V run、optimized-GS run 或 fresh confirmation，也没有恢复旧 R12 失败训练门槛；因此既未完成一般研究目标，也未授权新鲜确认。后续如有新假设，应另行声明和冻结，不能在本次 VAL 上更换 h/T、候选、人口或门槛以消除失败。
