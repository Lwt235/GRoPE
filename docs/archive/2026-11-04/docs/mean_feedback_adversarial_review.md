# 一次均值反馈的边界反例

2026-10-31。只作解析推导，无数值或真实数据实验；未读取 R20 效果。
本意见补充 [未选方向性补偿草稿](directional_content_compensation_review_draft.md)，
没有修改已留档的草稿或 R20 冻结方案。独立审查确认其无限域线性恒等式、
一般光滑内容的一阶均值响应及凹二次方差反例均正确，但给出两个直接限制。

第一，反馈不能当作 R18 连续法则的数值修复。令一维均值为零，
`c(y)=-kappa*y²/2`。对称性令反馈恒为零；当 h→0 时，反馈分布的方差
仍为 `C/(1+T*kappa*C)`，而 R18 应恢复原 prior，方差为 C。
因此它不会通过针对 R18 连续分布定义的原参考误差检查；改换参考不能称为
修复了 R18。

第二，native 格中心反馈会在小内容强度下反向。取两个原生格
`[-3,0]`、`[0,3]`，格中心 ±1.5，`h=1/4, C=1/8, mu=0`，两格内容为 ±1。
于是 `S=3/16`、`A=C/S=2/3`。第一次 native 概率均值为
`m_T=1.5*tanh(T)`，所以中心更新为 `mu'=-A*m_T`。

记 phi 为标准正态密度。无内容的格中心均值对 Gaussian 中心的导数为

```text
J = 3 * [phi(0)-phi(3/sqrt(S))]
      / [sqrt(S) * Pr(|N(0,S)| <= 3)] .
```

第二次概率均值在 T=0 的导数为 `1.5*(1-A*J)`，该量严格为负。
原内容偏好右格，反馈反而使微弱内容的输出向左移动。既定极小面积 floor
不足以改变这个符号。此例不需要外推、不需要负协方差或梯度估计误差；
它来自以原生格中心代表连续位置时，均值对几何中心的响应已不等于 1。
坐标若采用 reference-8，格宽 3 对应 24px，故不能仅把它看成无关的无限
粗网格反例。

这不证明该算子在所有实际任务上失败，却足以拒绝“连续均值公式自动保证
native 尺度稳健”的解释。用新的 Jacobian、步长、协方差反馈或截断修复它
又会产生新的设计选择，当前没有据此继续加模块或运行真实实验。

结构上它仍是一种固定一次的确定性反馈，但需要两次几何求值；新中心依赖
全部 key 的内容，不能描述为仅由 3DGS 参数独立生成的位置编码。
**当前决定：保持未选择，不将它视为 R20 失败后的默认下一候选。**
