# R57：双侧高斯关系有有限组件收益，尚无稳定的强对照优势

2026-11-02。九次新训练、39个精确复用对照、48个选定模型核验、336组条件
评估和三次固定检查点消融均完成。完整式基础OA为89.292%，与同容量距离
控制、MLP及自由二次项接近；种子方向不一致。保留组件与部分扰动条件的
正面信号，当前候选不晋升，不启动未使用数据确认。完整研究目标仍未完成。

## 问题与比较

R56的高斯区域只由query决定。R57让两个token各自的中心和协方差共同定义
位置关系，同时保留中心RoPE对内容的旋转。令c_i=x_i+m_i、P_i=Sigma_i^{-1}，
则新增位置分数为

    b(i,j) = -1/4 [(c_i-c_j)^T(P_i+P_j)(c_i-c_j)
                   + tr(P_i Sigma_j+P_j Sigma_i)-6].

它等于两个高斯的双向KL之和乘以−1/2，可写成19维附加位置Q/K内积。
中心与协方差从当前token特征预测，属于学习型比较参数；不声称恢复物理
GS支撑或局部纹理变换。固定高斯参数下的共同仿射不变性不等于整个网络
的仿射/旋转不变性。该经典散度及其展开不作为新的理论贡献。

按照[事前协议](/home/liwt/GRoPE/ROUND57_GAUSSIAN_PAIR_PROTOCOL.md)，新训练：

- 完整式pair_full；
- pair_distance：仅去掉协方差相容trace项，保留相同的中心、自适应距离、
  1746个PE参数、初始函数和初始一阶导数；
- pair_center：学习两个中心，协方差固定为16I，582个PE参数。

各使用11/22/33三个配对种子。39个R56/R48参考模型及预测按身份精确复用，
不计为新增独立实验，不混入旧五种子均值。全部模型保持同一个四层96维、
双头Transformer、实际采样/增强序列、初始化与优化设置，每次120epochs、
29760次更新。每五个epoch用验证CE选择模型，严格相同时保留较早模型。

数据仍为ModelNet官方训练集缓存的7910 fit /965 val /965 old_dev_eval。
所有48个模型先选定，再导出新评估；官方测试集和保留的跨场景确认数据
均未读取。相同对象上的开发结果不构成新的独立数据确认。

相对仅学习中心，主方案OA高0.415pp、mCA高0.467pp，两项均三个种子正向；
相对固定距离，分别高0.484pp、0.902pp，同样三个种子正向。完整的自适应
关系相对这些简单控制有组件收益，但相容项与自适应距离的比较没有同样
稳定，且较强的通用位置函数已接近相同表现。

以上判断来自配对方向及强对照，未使用任意1pp门槛或微小浮点误差来判负。

正面信号：jitter02下完整式比MLP高0.553pp，三个种子均更好；1024点下比

边界也明确：jitter02仍比自由二次项低0.173pp，两负一正；256点时比仅学习

整网没有SO(3)不变结构，本轮没有解决这一既有局限。固定参数下的几何
性质不能用来替代网络的实际旋转泛化结果。点序反转保持全部模型分类赢家
不变；相应数值差异作为实现注记，不用于方法优劣判断。

## 去掉新增相容项后的表现

在三个已选定完整模型上，仅关闭trace相容项，仍保留形状参与的自适应距离。
OA从89.292%降到89.050%，三个变化为−0.311、+0.207、−0.622pp；平均CE
增加0.009674，三个种子均增加。因此该项确实影响预测，尤其是概率分配，
但这不证明恢复了物理形状或具有强对照优势。

该消融只移除新增相容项，不等于删除所有形状作用。前层干预还会改变后层
输入和随后预测的中心。不能将它与R56修改整个精度矩阵的干预直接比较，
也不能用固定检查点依赖性代替重新训练的同容量距离控制。

## 优化、成本与核验

完整式分别选择epoch100/95/100；距离控制100/115/120；中心控制80/105/120。
完整式没有选在预算终点，部分控制仍选在终点。曲线后期趋缓但不证明全局
收敛，本轮不据此启动额外预算扫描。

九次新训练/选模累计24645.52秒，包含检查点保存等开销；共享主机时间
不构成正式吞吐量排名。完整式和距离控制共340254参数，其中PE为1746。
位置乘积当前使用FP64再与FP32内容分数相加，尚无融合内核的效率主张。

原控制器77259退出0（a2dd48），15个子任务均退出0；报告进程87784退出0
（2eb30b）。两张图已实际检查。冻结的29个科学源文件锁为
3e1f37a49b82a07d48a5ac0432b9c803d84bf4563ba2b928aa94a5ec0507de0a。
预训练四项有界单测及39个原函数身份、初始化、真实输入梯度检查通过。

48个独立公式样本包含新模型第一层八个query与全部key及两边预测形状；
新九模型最大概率差7.35e−7，全48模型最大6.93e−6，赢家变化0、告警0。
保存验证CE回算最大差1.33e−8。336组指标正确计数重算完全一致，CE差
不超过1.14e−7，三次消融正确计数也一致。这是同一作者的独立算术路径，
不是第二实验室复现或完整网络重写。当前效果判断不受这些误差影响。

## 决定与后续问题

当前学习型双侧高斯与强基线表现接近，但尚未达到稳定收益目标。不晋升，
不启动新确认；按协议结束此候选在分类任务上的温度、频率和预算调参。
普通形状相似度的条件性备用控制继续保留为未执行方案，其启动条件未满足。

下一项研究优先围绕原生三维局部对应，明确高斯表示何种区域以及区域之间
应满足什么关系。若使用输入支撑矩，须给强控制相同信息，并同时保留区域
对应与中心定位指标；若是未知位姿配准，真值变换只能用于监督/评分。
适用的距离/角度几何编码也应成为强对照。新任务不能抹去本轮分类限制，
分类上的近似持平也不是禁止单独几何诊断的门禁。

具体数据、坐标系、标签、候选及预算将在下一次训练前确定。本报告没有
冻结或启动下一轮。原始一般性目标、已有负结果及未使用确认数据继续保留。
