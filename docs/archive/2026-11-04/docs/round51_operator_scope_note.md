# R51 算子解释边界：协方差框架并不等于完整局部姿态

2026-11-02，在R51固定训练进行期间记录。以下是当前算子的代数性质，
不使用评估结果选择方法，不修改已冻结的实验，也不新增验收门禁。

当前GS框架使用L=Σ^(1/2)=R diag(s) R^T，G=[L,μ;0,1]，A=G^(-1)。
这样避免相同高斯因轴符号/轴排列不同而产生不同编码。但是它也有明确限制：

    linear(A_i A_j^(-1)) = L_i^(-1) L_j
    L_i^(-1) L_j ~ L_i^(-1/2) L_j L_i^(-1/2)

右侧是对称正定矩阵，因此相对线性块的全部特征值均为正实数。
三维非平凡纯旋转的特征值包含e^(+iθ)、e^(-iθ)；θ=π时包含负值，
因此它不能由该线性块精确表示（θ=0的恒等旋转除外）。非交换的两个SPD
因子之积仍可以非对称，极分解也可能包含旋转成分；不能把上述结论误说成
“完全没有方向信息”或“不能对方向变化有帮助”。

HRoPE的R+κtn^T在t=0时直接包含旋转R，自由仿射矩阵指数也能表示相应
范围内的旋转。两者和当前SPD平方根框架的表达空间不同。R51的共同内容
网络能接收相机姿态并学习补偿，所以这个限制不推出任务指标必然更差，
也不证明任何已经观察到的误差由此造成。模型范围/训练动力学也存在差异。

若后续HRoPE稳定优于GS，而GS形状又无法超过恒等/各向同性对照，一个
有针对性的候选方向是显式分离已知相机投影和高斯区域形状，例如检验
相机变换与高斯框架的单次矩阵组合，并同时比较相机单独、一般仿射和
校准HRoPE局部平面。此处仅记录竞争解释；尚未实现、冻结或运行新方案。
不能因该代数观察跳过R51的固定对照，也不能据此把现有负结果归咎于实现。

当前实现：models/round50_local_frame.py；R51输入和论文形式适配：
models/round51_visual_alignment.py。HRoPE的旋转/平面形式见
[原论文 §3.2](https://arxiv.org/html/2610.28284v1)。
