# R17 实际 V 接口：纯合成预检完成

2026-10-31。**新接口通过73项单元测试及16项预先冻结的数值检查；没有运行真实数据训练，也没有新增方法效果结论。** 本次工作在主 R17 VAL 全量独立审计运行期间完成，未读取其效果。它准备下一阶段的数值接口，不能替代主验证、实际深度任务、优化 GS 或新场景确认。

[模型接口](../models/round17_depth_attention.py)保留 R7 的全部41,345个参数、参数名、初始化顺序和随机状态。融合路径每次在线计算 learned Q/K，使用冻结 R17 的 float32 tau×content、float64 geometry 加法和 softmax，然后只在与实际 V 相乘前把 attention 转为 float32。单视图模式沿用原 R7/R12 的 float32 自身几何和读出，输出与梯度逐位一致。模型没有增加可学习参数或读取标签/可见性字段；几何缓存的真实来源仍须由未来导出与数据锁验证。

[合成协议](round17_value_interface_preflight_protocol.md)在执行前冻结。数值检查使用一个1×432×432完整原生大小接口和一个2×6×7批量矩形接口，固定随机种子；几何是合成负平方距离，只检验接口，不是实际原生高斯积分的新增验证。两接口分别覆盖 trace/constant 与原值、zero-V、reverse-V，以及 T=0/C=0 极限，共16项检查。保存了全部实际/参考概率、深度、温度、V/汇聚、初始参数及梯度数组。

| 数值检查 | 最大误差 | 冻结容差 |
| --- | ---: | ---: |

| 分别组装的 Torch 双精度参考，每参数梯度相对 L2 | 1.2163×10⁻⁶ | 10⁻³ |

所有 τ32 与独立参考逐位一致；梯度最大绝对误差为2.7698×10⁻⁸。T=0 的 Q/K 梯度精确为0。zero-V 时 V 的两组参数可断开梯度，这一例外明确记录；其他双方无梯度的情况不能自动通过。[完整验证记录](../results/round17_value_interface_preflight_numpy_first/verification.json)保留每项检查，不能把一个最大误差替代完整人口核验。

独立性边界：same-content 检查共享实际 learned Q/K GEMM；完整前向参考用 NumPy 重新计算 affine、归一化、GELU、attention、V 和输出头；梯度参考独立组装计算图但仍使用 Torch autograd，并非另一套自动微分引擎。单元测试通过 head 输入钩子逐位核对实际 cast 后汇聚，同时验证初始化、单视图、在线 Q/K 改变、V 干预、字段隔离和非法输入拒绝。通过这些检查不保证实际训练的梯度条件、内容效用或泛化。

首个尝试的测试子进程遇到 MKL/OpenMP 兼容错误，未进入16项数值循环，已封存为失败。随后仅将测试子进程改为先导入 NumPy 再导入 Torch；新目录重新冻结并执行。原失败、两次完整文件清单、原始快照和[单行修复记录](../results/round17_value_preflight_import_repair_20261031.json)均保留。两个尝试的合成输入 canonical 哈希完全相同，模型、测试源码、协议、误差容差未改；没有通过强制 MKL 后端或修改系统库解决。
