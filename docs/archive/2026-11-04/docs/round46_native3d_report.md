# R46：三维非线性位置映射有收益，尚无高斯参数化优势

2026-11-01。55 次新训练、5 个复用历史对照、完整旧场景评估与核对均完成。
主方法不晋级；完整研究目标仍未完成。没有渲染器，未使用确认集没有打开。

三维高斯 PE 的 PCK@8 为 **87.9150%**，相对同输入三维点 RoPE 的
85.1576% 提升 **2.7573 个百分点**，五个种子、五个旧场景全部正向。
但三维 MLP 位置映射为 **88.2506%**，高斯方法低 **0.3356 个百分点**，
五个种子全部落后。因此保留三维非线性映射的正面证据，同时不能将它归因于
高斯参数化的特有优势。完整椭球也未超过各向同性版本。

## 研究对象与边界

[冻结协议](../ROUND46_NATIVE3D_PROTOCOL.md)。保持两层双向 Transformer 的
Q/K/V、残差、FFN、匹配头及 166611 个共享参数，仅改变位置算子。
主方法用 64 个可学习中心与正定精度矩阵定义高斯空间基，再以零初始化的
64×3 系数生成坐标修正，随后在修正坐标上应用 RoPE；新增 768 个参数。
所有层、头和注意力方向共享这一位置场，没有形状分支或渲染分支。

协方差是可学习 PE 的参数，具有旋转与轴尺度的高斯参数化形式；它不是从
物理渲染基元读取的支撑协方差。高斯/RBF 基函数及可学习坐标映射已有先例，
本轮不宣称新的基函数或已经证明 3DGS 特有机制。

使用现有 RGB 预测深度，在 token 中心的四个半像素邻点取平均后反投影。
相机位姿来自已有重建元数据。每对输入的 864 个点统一到查询相机坐标系，
中心化、按 RMS 半径归一化并乘 12。三维点与三维映射对照使用相同输入；
新二维点/高斯对照使用同一批中心点的投影，控制锚点改变的影响。
历史二维点模型保留旧 patch 质心交叉投影，只作为历史几何对照。

55 个新模型使用相同共享初始化、1000 个采样批次、优化器与选模规则。
不同位置模块的新增参数量如表所列，不声称位置模块容量完全相等。
九个三维角色初始函数完全等于三维点基线；两个二维角色初始函数等于
同输入二维点基线，不声称二维与三维初始函数相同。

| gaussian3d − fixed_centers3d | +0.116501 | 4/5 | 5/5 |

在这项任务中，改为中心提升只带来小幅二维收益，不能将先前的失败统一归因于
“区域质心与中心定位冲突”。新几何下二维高斯修正仍接近点基线。
三维完整高斯相对固定基/固定中心有小幅正向效应，但各向同性版本更高；
没有显示完整方向/轴尺度自由度的稳定必要性。

三维点与二维点的差异同时包括坐标表示、归一化与频率方向配置，不能解释成
“三维本身无效”。预测深度误差、这些坐标约定与映射归纳偏置之间的影响仍未
分离。两个高斯模型还存在基函数数量与参数量差异，不能声称纯维度交互。
本轮只约束冻结的候选和预算，不否定所有高斯 PE 或所有优化方法。

## 运行、复核与决定

- 六项 CPU 检查和 11 个角色 CUDA 检查通过。新坐标在全部 1120 个旧数据对、
  每对全部 token 上经过独立几何公式核对，最大坐标差约 3.815e−6；视觉特征
  逐项相同，标签直接复用。输入未使用传感器真值深度。
- 55 个选定模型的共享参数与所有存在的可学习位置参数均更新。最佳步数为
  500:7、600:6、700:6、800:15、900:14、1000:7；不宣称证明收敛。
- 独立 NumPy 相位/概率样本最大差 3.669e−7，最大概率项变化 0，无告警。
  该核对覆盖第一层固定查询与全部 key，不是第二套完整网络或另一位作者的审计。
- 60 个模型、两种 V 条件共 57600 个帧记录重算；PCK4、PCK8、有效查询数
  全部一致。最大帧 CE 求和差 1.612e−4。候选决定来自任务对照，不由浮点门槛决定。
- 主方法关闭注意力 V 路径后 PCK@8 为 65.1677%，正常为 87.9150%。这只验证
  内容聚合路径参与，不证明高斯形状参数独有的作用。
- 新训练峰值 allocated 774.835MiB；逐次训练及选模时间之和 2417.218s。
  共享主机的这些记录不构成正式吞吐量对照。
- 控制器工具 handle82629 已直接观察到 exit0，15 个子进程全部 exit0，活动
  列表为空。本轮没有遗留运行任务；不要重启历史 PID。

保留三维非线性映射的真实正面结果，停止晋升这一全局高斯坐标映射候选。
后续设计需明确：中心、方向和尺度提供了什么普通非线性映射没有提供的
位置归纳偏置，再进行完整 Transformer 内的强对照。不能用渲染任务的局部
改进替代这个问题，也不能把跨视图匹配的单项结果当成一般性结论。
本报告没有冻结新候选、扩大训练预算或打开新的确认数据。
