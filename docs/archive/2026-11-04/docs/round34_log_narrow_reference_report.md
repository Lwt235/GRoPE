**修订和固定验证人口。** 按 [设计](/home/liwt/GRoPE/docs/round34_log_narrow_reference_design.md) 与 [协议](/home/liwt/GRoPE/ROUND34_LOG_NARROW_REFERENCE_PROTOCOL.md)，保留窄区间判定 `halfwidth × (abs(midpoint)+halfwidth) ≤ 0.25`，只把该分支的正态 PDF 求积点数从 16 减为 8。全有限 X 域、X 方向 GL32/48、SVD、几何断点与中点合并、固定 pilot 尺度、深度截断、外层 GK21、floor 和所有误差/预算规则均保留。

局部正态积分写成 `h φ(m) ∫[-1,1] exp(−a u−b u²) du`，其中 `a=mh`、`b=h²/2`。原分支条件蕴含 `|a|+2b≤0.25`；在更保守的 `0.5` 包络上，GL8 余项公式给出相对界 `1.8779378947512938e−13 < 1.88e−13`。审计独立复算这个常数，并核对成功记录的 `narrow_y_pdf_nodes = 8 × narrow_normal_nodes.sum_count`。这项等式是工作账本一致性检查，没有逐点重新分类窄区间；该界只适用于局部、精确算术下的求积余项，**不包含浮点误差，也不是外层积分或全流程误差证书**。
