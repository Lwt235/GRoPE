# R60：真实场景适配有收益，直接迁移仍受限

2026-11-02。30个已有源模型、30次新的目标域训练、120组预测和指标回算均已
完成，两张结果图已实际查看。主结论是：R59的高斯不变关系MLP值得继续研究，
但目前证据支持的是目标域训练后的区域匹配收益，不能宣称无需适配的一般
迁移能力、高斯独有优势或原始研究目标已经完成。

本轮事前同时安排直接迁移和固定目标域适配，没有在看到迁移失败后追加训练。
协议为`ROUND60_REAL_SCENE_PROTOCOL.md`，完整十方法表、三种子配对与五场景
差值见`results/round60_real_scene/attempt1/report1/report.md`及`comparisons.json`。

## 实际检验的问题

假设：从观察区域的中心与协方差构造不变关系，进入Transformer自注意力，
能将R59的合成点云收益延伸到真实传感器点云。竞争解释包括距离关系已足够、
普通局部特征比较已足够，以及源数据支持形状的统计不能直接迁移到室内场景。

候选保持11→96→96的单个MLP，PE参数10368。输入为中心距离、两端各三个
对数标准差，以及两项方向Mahalanobis量、两项精度—协方差迹关系。它产生
相对向量，作为q与相对向量的点积加入自注意力；交叉注意力和最终匹配仍由
内容特征计算。没有新模块或新增相机、法向真值。此处是相对位置编码，
并不要求将每种有效设计都写成旋转相位。

旧SUN3D九场景，3/1/5场景分别用于fit/val/old_eval，576/64/480对。
原生传感器深度在本任务中是公开输入，这与早期RGB匹配实验不同。各视图
独立去中心、使用不依赖位姿的配对共享尺度；相机位姿仅生成标签和评分。
64个区域，每区域32个输入近邻，协方差带原有固定底噪。
这是观察点集的高斯参数化，尚非优化后的3DGS基元实验。

十种方法各三个种子。目标训练从各自的源模型开始，共同60epochs、1080更新，
实际批次、输入、优化预算和验证CE选模规则相同。各方法目标初始骨干权重不同，
所以这是完整源训练＋目标适配流程的比较，不是固定目标骨干后的PE单独替换。

直接迁移base相对距离MLP低1.113pp，相对正弦距离＋角度低1.646pp；候选
三个种子的R@1分别36.527/30.169/40.190%，差异较大。sparse256相对距离MLP
低1.693pp，三个种子均低，连续误差与CE也全部更差。虽然候选对局部描述符
等控制的平均区域分数较高，仍不能据此声称稳定的跨域优势；这些控制上的
连续误差大多也不占优。

适配后base相对距离MLP高1.810pp，配对种子为+4.172/−0.254/+1.512pp，
五场景平均差均正向。centerPCK高1.135pp，2/3种子改善；softEPE低0.020704、
CE低0.068383，两项均3/3种子、5/5场景改善。对局部描述符、角度＋描述符、

均3/3种子、5/5场景改善。这支持目标训练后的一项实际任务收益，但不能
忽略最强距离MLP对照上的种子差异。

适配后sparse256相对距离MLP高2.081pp，配对+2.359/+0.907/+2.978pp，
区域3/3种子、5/5场景改善；centerPCK高0.451pp，三个种子改善、五场景中
三个改善。对局部描述符、角度＋描述符、完整矩阵，区域高2.929/2.760/3.780pp，
均3/3种子和5/5场景改善。完整矩阵对照的中心指标只有2/3种子改善，不能
把区域结果扩大成所有指标、每个场景都胜出。

## 覆盖率和解释边界

base有效查询为20422/61440，即33.239%；25/480对没有有效查询。
sparse256为8811/61440，即14.341%；117/480对没有有效查询。没有因原始输入
文件或点数不足而排除的视图对。稀疏条件改变了区域与可评估查询集合，故
48.782%高于46.280%不表示稀疏使同一批查询更容易；有效结论来自各条件内
对相同查询的配对方法比较。

center阈值0.1、softEPE使用配对归一化场景单位，不是米或像素。真实传感器
点与标签坐标仍有测量噪声，不是无噪声真值。五场景数量有限，近邻帧相关；
不使用查询独立的置信区间。所有场景都是旧开发数据，源候选也在此前结果后
被选中，故本轮不是未使用数据确认。

当前共同改善区域和中心指标，不支持把失败一概解释成“区域描述与中心定位
必然冲突”。另一方面，适配恢复收益只说明学习目标域统计有帮助，尚未隔离
法向、采样密度、噪声、形状分布及优化各自的作用。

## 已完成的实现检查

四个有界实现测试、十方法初始梯度检查、30个选模及实际输入顺序检查通过。
独立指标回算最大差1.33e−15；选定模型验证CE回算最大差8.89e−16，GPU批次
回放logit差至1.53e−5。原生输入/支持重建有界检查最大差7.92e−6。这些检查
支持实现与记录的一致性，不构成方法有效性证明，也不需要再扩展静态积分门禁。
独立算术由同一作者完成，不是另一实验室的独立复现。

24个冻结科学源身份不变。原控制器69037/PID10878和报告观察器4685均退出0，
38个子进程全部退出0。30次新目标训练及选模累计1323.42秒；共享主机时间
只用于资源记录，不是受控速度排名。候选选模epoch27/27/21，曲线后期趋缓；
这些结果不证明全局收敛，也不触发继续加预算寻找更好排名。
两张PNG的三种子配对与验证曲线已实际查看，汇总表和主要差异一致。

## 决定

保留此简洁候选，接下来区分完整协方差与常见法向点对关系的贡献。
R59的中心三点角度控制不等于法向PPF；普通矩阵MLP又同时改变旋转不变性。
[RoITr §3.1](https://arxiv.org/html/2303.08231v2#S3.SS1)已有将距离和法向点对
关系用于注意力的工作。因此当前结果还不能支持高斯独有收益或新颖性。
具体下一步见`docs/round61_normal_relation_plan.md`。

保留R55局部框架、R57分类、R58标量形式及R59稀疏负结果。本轮适配收益
不推翻它们。原始一般性目标继续有效：还需要明确几何归因、跨任务与实际
基元适用性、适用鲁棒性和未使用数据确认；此时不晋升为完整成功方案。
