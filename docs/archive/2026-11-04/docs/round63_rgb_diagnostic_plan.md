# R63计划：固定模型定位RGB高斯关系的差距

2026-11-02，依据已完成的R62制定。尚未实现、冻结或执行本诊断。
不修改R62结果，不追加训练，不接触旧评估或未使用确认数据。

## 问题、竞争解释和决定

R62观测完整形状比观测中心稳定有效，而RGB完整候选未胜过强对照。
待区分的解释包括：中心预测不合适、形状预测或可表达范围不合适，以及
参数头与关系编码的共同训练/接口适配问题。也可能存在开发场景差异，
不能预先将失败归因为预测器精度。

本轮不检验新方法是否胜出，只为下一次最小设计修改提供证据。
若在固定RGB模型中替换观测中心就改善，优先研究中心学习；若替换形状
改善而中心替换不改善，优先研究形状学习/范围。若同时替换才改善，
保留中心与形状耦合解释。若同时替换仍无帮助，而观测训练模型有效，
应优先检查共同训练与接口适配，不能简单结论为“给准几何就行”。
所有替换都有分布变化；改善或恶化都不是独立因果证明，后续设计仍需
同预算重训强对照。负诊断不抹去R62观测形状的结果。

## 固定数据和模型

使用R62原fit的三个场景，各按原manifest顺序在192对中均匀取16对
（索引floor(linspace(0,n-1,16))），共48对；使用全部64对原val。
实施前核实原计数，保存精确pair ID及输入身份。fit子集与单个val场景
只用于开发诊断，不代表完整训练集拟合或普遍泛化能力。

固定R62选定的predicted_full、predicted_point和observed_full各三个
种子模型。检查点、原始源文件和数据身份保持原样；不更新任何参数。
相机、RGB特征、任务标签、评分分母和参数化常数沿用R62。

## 固定前向干预

对predicted_full逐个执行以下七种情况，两层均使用相同干预规则：

1. 原始预测中心和协方差，作为基线。
2. 观测中心＋预测协方差。
3. 预测中心＋观测协方差。
4. 观测中心＋观测协方差。
5. 预测中心＋固定初始三轴协方差。
6. 预测中心＋R62固定球形协方差。
7. 将新增关系logit项置零，保留原相机Q/K/V及输出路径。

另外重放predicted_point和observed_full原始基线。每种子9种模型/干预，
两个数据部分，共54个汇总组；全部是固定权重前向，无新拟合。
观测几何仅在明确指定的诊断干预中使用，不能将改善解释为公平RGB收益。
第一层干预会改变第二层特征和预测；结果属于完整前向干预，不声称第二层
预测保持不变。先验证未干预分支与原模型一致，再执行全部固定情况。

## 记录及范围检查

按R62方式保存预测并复算CE、连续EPE、PCK及尾部错误，给出配对种子和
逐场景差异。保留fit/val区别，不按诊断结果选择检查点、干预强度或样本。
原始val分支与R62已保存的验证结果核对，指标继续采用已有独立求和路径。

仅在原始predicted_full及predicted_point分支记录两层预测几何：中心与
观测中心的米制距离、深度差异，协方差相对谱的对数差异，以及预测头
各坐标的分布和距饱和边界的情况。传感器支持是参照，不称真实3DGS参数。
从同一批已使用的原始深度派生中心是否缺失及patch有效样本数；这些标记
只分层解释诊断，不能进入模型或改变任务查询分母。区分全部token、原生
中心有效token、至少16/64样本有效的patch及全缺失patch，避免3m回退
使预测误差显得更小。

对观测协方差检查R62对Cholesky对角和非对角的限制。若从去除共同方差
地板的矩阵构造Cholesky，必须记录半正定/数值稳定处理。报告越界比例和
固定坐标截断后的协方差变化大小，区分接近方差地板的微小差别与实质
范围限制。截断不是协方差距离下的最优投影，不能把其误差冒充不可避免
的最小表达误差。只有数据支持实质范围问题时，后续才单独改变范围验证。

## 执行及边界

先实现以上固定干预和统计，再冻结实际源、样本与检查点身份。检查输入
路由、原始分支一致性及干预确实只替换声明的几何/关系项，检查力度与
诊断结论相称。核实空闲GPU后执行短前向任务并独立复算指标、检查图表。
普通实现修正保留版本记录，不另起科学轮次。

确认结果。实际3DGS、跨任务、鲁棒性/泛化及未使用数据确认仍属于完整
研究目标；先让本轮证据决定下一项具体修改。
