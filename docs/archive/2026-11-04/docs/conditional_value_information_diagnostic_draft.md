# 条件几何值：最小信息诊断草稿

**目前不能说条件几何值能解决原 1.031% oracle-route 收益限制。** R8 只更换
路由时仍使用原预测 patch V；条件值改变的是 V 的信息压缩，因而该数字不是
它的理论上限。但条件值没有增加源观测，也不会消除源预测深度的系统偏差、
遮挡或相机误差。R8 的 GT-value 收益较大支持检查值端，不能证明恢复局部
斜率就足够。R9 的 full RGB 读取只改善0.1460%且两场景方向不一致，也不
提供将几何深度读取推广为 RGB/任意 learned-V 改善的依据。

完整三维 Gaussian **可以保留某些旧表示没有的信息**，但“普通 PE”须限定。
例如三维均值同为(0,0,z0)，协方差为

    Sigma_± = [[s²,0,±c], [0,s²,0], [±c,0,t²]],  c²<s²t²。

中心 PE、常数深度V=z0，以及光轴附近一阶投影的二维协方差
`s²/z0²*I` 都相同；保留 cross-covariance 时，线性化条件深度却为
`z0 ± c*z0/s²*u`。这是信息可区分性证明，不是效果数据；不能用 Gaussian
自己生成的条件均值当唯一真值来证明胜过平面。完整三维参数 PE 当然也能
直接编码这些块，故这不是所有 PE 必然丢失信息的定理。

在精确透视、正深度概率测度下，完整三维 Gaussian 的 camera-z 条件均值
是 F3/F2，不是密度 line integral 的 F1/F0，也不是 ray maximum。它一般
非仿射，不能直接压成 R12 的三个固定通道；有限格/二维平滑还要分别处理
概率与深度一阶矩。因此目前不建议直接实现完整射线版本来追求这个可能
存在的信息。应先否证其最便宜、已经明确的局部条件值极限。

**唯一建议：固定已有合法路由的一次旧 TRAIN 原深度任务读值诊断，不训练。**
使用事前固定的48对及原g8网格，不按 R19 成败或旧错误选行；P 事前指定为
一个已接受的预测路由，全方法相同，不重选 h/T。源像素仅用 RGB 预测深度
和原相机变换到 query 坐标，再拟合单个联合局部矩(r,z)，其中r是其实际
query图像投影。原 query 像素中心是条件坐标，不使用 GT对应、GT源值或
GT可见性，也不需要重新选择 R19 的投影中心。

主诊断只把常数 patch z 换成
`v_ik=d_k+Czr_k(Crr_k+h²I)^(-1)(r_i-m_k)`，沿同一个P聚合，输出仍是原
query中心深度。h 只沿用那个已固定操作点并统一单位，不扫描。此处的h²
是待否证的岭收缩假设，不能称为已校准深度置信度。一个key仅保留三个
仿射系数，可先AV再求值；不加网络、mixture或额外输出旁路。

公平比较必须同时保留：相同P/原预测像素的常数值、同信息的岭深度平面
（它与仿射 Gaussian 条件值应代数等价，属于核验而非独立赢家），以及
三维最小二乘平面/射线相交和逆深度仿射平面。后两者避免拿错误的深度
仿射假设削弱平面控制。原始预测源深度的标准 bilinear 读取另作完整方法
强参考：使用预先定义的合法预测投影，它的路由不同，不能冒充仅换V的
消融；不能为强行统一P把它裁成较弱的patch内clamped bilinear。

所有方法共享原合法观测、相机、单位、范围、先冻结的无效/平行/外推处理，
计入构造与读取成本；传感器标签仅在全forward封存后评价。保留原深度任务
全部query sensor-valid中心及原AbsRel/RMSE，不换成区域平均深度、对应KL、
RGB渲染分数或仅跨视图可见子集。单列fallback触发率但不删行。先完成软件
恒等/退化检查，不把失败样本或数值积分容差当作新效果自由度。

若条件值相对常数无可重复的实质信息，或对更简单的平面/bilinear没有精度
或可信成本优势，停止以它修复 R8 的投入假说；这不是所有 learned-V 的
不可能性定理。若只比常数好而等价于平面，结论只能是原patch压缩丢了斜率，
不能声称完整GS形状不可替代。即使合法路径有优势，也只允许考虑另冻真正
V训练协议，不能把这次直接传输的变化与R8训练后1.031%相减当作突破。

原V头先对(feature,log z)做GELU，条件求值、log、GELU和AV一般不能交换。
之后若训练，必须公开新的V语义，给全部强位置/平面控制相同信息、容量与
预算，保留singleview、真实V干预、原五种子/原目标及所有旧门槛。当前既
没有这个收益证据，也没有授权训练或完整3D射线实现；不是未选reserve的
fallback胜利宣言。
