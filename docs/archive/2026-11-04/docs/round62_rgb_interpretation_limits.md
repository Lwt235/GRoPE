# R62 RGB结果的解释边界

2026-11-02，训练期间的源码复查记录；尚未读取R62评估结果。
这不是新增验收门槛，不改变冻结模型、预算、选模或评估。

R62的完整高斯初始化使用三个不同轴长，目的是避免可学习谱映射在初始时
遇到完全重合的特征值。仅中心控制使用固定球形。两组关系MLP的初始权重
相同，但其初始几何输入不同。因此完整组优于中心组，支持当前可学习形状
参数化流程的增量价值；单凭此比较不能区分固定初始各向异性、可学习形状
与两者同训练过程的交互。参见models/round62_rgb_relations.py中的
gaussian_from_raw、POINT_VARIANCE和RGBRelationMatcher初始化。

若结果需要进一步声称“预测出来的形状带来收益”，可在旧开发数据上先用
固定初始协方差替换、形状置换等前向干预定位依赖；这种干预有分布变化，
不能替代同预算重新训练的固定初始各向异性控制。只有结果确实需要区分
这些解释时才追加对应验证，不提前扩大实验。

完整高斯相对free_relation的差异也包括射线、正定结构及显式几何关系的
组织方式。更大的一般关系MLP控制有助于检验结构是否实用，不能单独证明
收益来自额外信息、恢复了物理形状，或其他非高斯编码无法表示这些关系。

观测几何诊断额外使用传感器深度。完整观测与仅中心观测的比较用于判断
区域形状是否提供额外价值；观测优于RGB预测只把问题缩小到输入与学习的
差别，不能单独确诊为预测精度不足。当前实际接入位置是跨视图注意力，
也需保留与R58视图内自注意力接法的区别。

最终优先依据冻结的RGB强对照、配对种子和场景结果作决定；以上边界用于
约束结论，不以新的静态核或数值完美性要求阻挡实际任务验证。

训练期间补充核对了fit缓存中的射线衔接：q/k各248832条观测中心除以各自
深度，与RGB缓存中居中像素、归一化内参算出的射线作NumPy比较。最大分量
差均6.71e-8，无大于1e-5的射线，深度均为正。结果存于
results/round62_rgb_relations/attempt1/postprocessing/fit_ray_alignment.json。
仅读取旧fit几何与相机字段，没有读取标签、评估数据或模型输出。这验证
中心射线约定的一致性，不验证深度物理精度、完整外参标定或PE效果。
