# 单个偏斜分布能否分离中心与重心：备选理论审查

2026-11-01。只阅读既有设计、失效报告和一手文献，作解析推导；没有读取真实 NPZ、标签或新数据，没有运行模型或合成数值实验，没有修改 R38 冻结源与协议。本文件是决策准备，不选定后续轮次，不宣称新颖性、数值可用性或任何实验门槛已通过。

结论是：**单轴 two-piece Gaussian 确实能以一个连续测度和一个可逆 transport 分离 mode 与 mean，但保持给定 covariance 时只有有限可行域；即便在可行域内，它也不保证原生区域 argmax 对齐指定中心。** 因而暂不把它作为“原矩不变、全人口合法、中心门自然修复”的一般方案。这里的否定只针对下述精确定义及过强承诺，不是所有偏斜分布或 Gaussian PE 的不可能性证明。

## 1. 为什么只审查这一条

[R21 同信息分解](round21_matched_decomposition_report.md)已经区分了区域质心 μ 与独立中心 a 的作用：将单 Gaussian 中心改为 a 可改善中心定位，却可能损伤粗区域；保留更多区域形状也没有自动恢复中心。此处只问能否让同一分布同时具有 mean=μ、mode=a、covariance=Σ，避免新增分量或第二套输出。

这里选择的唯一构造是已知的 two-piece normal 的单轴扩展。它和常见的 Azzalini skew-normal 是不同分布族；后者的位置参数一般不是 mode，mode 还需解标量方程，不能把位置参数直接改名为 a 就宣称控制了峰值。[Capitanio 的原论文，第5节、命题7](https://rivista-statistica.unibo.it/article/download/11591/11626)

Two-piece 的左右尺度在同一个 mode 处接合，连续性固定两侧质量比例，不能再自由调一个混合权重。其一维密度与归一化可核对 [Rubio 与 Steel，2014，第2.1节、式(2)–(3)，作者机构全文](https://warwick.ac.uk/fac/sci/statistics/staff/academic-research/steel/steel_homepage/techrep/barevfinsupp.pdf)；[正式出版信息](https://doi.org/10.1214/13-BA849)为 *Bayesian Analysis* 9(1)。以下面向 `(a,μ,Σ)` 的逆映射、可行域和任务边界为本文直接推导，不把它们冒充已由文献验证的 PE 设计。

## 2. 唯一分布及精确逆映射

先取 k 维正定 covariance `Σ=BBᵀ`，其中 B 可用任意可逆因子。设

```text
δ = μ − a
v = B⁻¹ δ
t = ||v||
u = v / t                         (t>0)
b = sqrt(2/π)
```

在白化空间沿 u 只改变一个标量分布。令 Y 的 density 为

```text
g(y) = 2/(l+r) × φ(y/l),           y<0,
       2/(l+r) × φ(y/r),           y≥0,
l>0, r>0.
```

注意分段中的 `φ(y/l)` 不另除以 l；外部归一化系数已使两侧质量分别为 `l/(l+r)`、`r/(l+r)`。g 连续、唯一 mode 为 0。半 Gaussian 积分直接给出

```text
E[Y]   = b(r−l),
E[Y²]  = l²−lr+r²,
Var[Y] = lr + (1−b²)(r−l)².
```

取与 Y 独立的横向标准 Gaussian `E_perp`，covariance 为 `I−uuᵀ`，定义

`X = a + B(uY + E_perp)`。

要求 `E[Y]=t` 和 `Var[Y]=1`，则唯一正尺度解必须满足

```text
Δ = r−l = t/b,
p = lr = 1−(π/2−1)t²,
s = sqrt(Δ²+4p),
l = (s−Δ)/2,    r = (s+Δ)/2.
```

因此，存在此全支撑、连续、可逆构造的充要条件为

`δᵀΣ⁻¹δ < 2/(π−2)`。

在此条件下，`mode(X)=a`、`E[X]=μ`、`Cov[X]=Σ` **同时严格成立**。密度可直接写为

```text
z = B⁻¹(x−a),    y = uᵀz,    z_perp = z−uy,
f(x) = 2 / [(l+r)(2π)^(k/2)|det B|]
       × exp{−[||z_perp||² + y²/s_side²]/2},
s_side = l if y<0 else r.
```

一个联合 mode、一个方向和左右两个由输入唯一决定的尺度；没有自由的分量中心、独立权重或神经网络。改变 B 的正交基不会改变这个密度，整个统计量定义也与可逆仿射变换相容。这些是实数算术性质；没有为近奇异矩阵或接近可行域边界的浮点计算给出误差证书。

## 3. 确实可以写成单个可逆 transport

令 Φ 为标准 Gaussian CDF。上述 Y 的 CDF 为

```text
F(y) = 2l/(l+r) Φ(y/l),                   y<0,
       1−2r/(l+r) Φ(−y/r),                y≥0.
```

设 `p0=l/(l+r)`，其 quantile 为

```text
F⁻¹(p) = l Φ⁻¹[p(l+r)/(2l)],              0<p<p0,
         −r Φ⁻¹[(1−p)(l+r)/(2r)],         p0≤p<1.
```

对单个 `ε~N(0,I_k)`，有

`T(ε)=a+B{(I−uuᵀ)ε + u F⁻¹[Φ(uᵀε)]}`。

l,r 严格为正时，沿 u 的映射严格单调，横向恒等，因此 T 在全空间可逆。此表达没有离散分量采样。不能用“ε 的正负两侧直接乘 r/l”替代：那会固定两侧各一半质量，并在零点产生不同的密度高度，已经不是本构造。

可逆 transport 只是表示该分布的另一种方式；它不自动提供矩形积分、有限维 Q/K 分解或 RoPE 的正交旋转性质。直接使用上节 density 时也不需要每次计算 quantile。

## 4. 可行域、退化与一个直接拒绝理由

当 `δ=0` 时，取 `l=r=1`，u 任意，恢复 `N(μ,Σ)`，其结果不依赖 u。接近边界 `t²→2/(π−2)` 时，l→0，分布趋于单侧极限；边界上不再是从全空间到全空间的可逆 transport。超界时 p<0，不存在两个正尺度满足所需矩。

例如合法的抽象输入 `Σ=I, μ−a=2e₁` 已超界。这个例子来自代数，不是读取真实输入所得的反例；当前没有证据证明全部实际 patch 都在可行域内。删除超界行、裁剪 t、移动 a 或改大 Σ 都会改变原问题或全人口合同，不能作为未声明的实现细节。

若 covariance 秩亏，只有当 δ 位于 `range(Σ)` 时，才可能在其支撑子空间内重复上述推导，并用子空间 Mahalanobis 距离检验边界；它不再有全空间 Lebesgue density 或全空间可逆 T。δ 不在该子空间时，给定 covariance 的随机变量不可能同时以 μ 为均值并在 a 处拥有支撑内 mode。此处不添加 jitter 或特征值截断。

一个容易混淆的“修复”是把目标 covariance 换成 R38 的 `Q=Σ+δδᵀ`。对正定 Σ，Sherman–Morrison 恒等式给出

`δᵀQ⁻¹δ = t²/(1+t²) < 1 < 2/(π−2)`，

所以同一 two-piece 公式总能构造 mode=a、mean=μ、covariance=Q。然而其关于 a 的二阶矩为

`E[(X−a)(X−a)ᵀ] = Σ + 2δδᵀ`，

不再等于原支撑的 `Σ+δδᵀ`。R38 Gaussian `N(a,Q)` 的关于 a 二阶矩恰为 Q；两者不能称“仅改变偏度、完全保留原二阶量”。这里指出的是语义变化，不提出第二个候选或选择这个增宽规则。

## 5. 区域可加性成立，但中心 gate 没有因此得到保证

对同一个固定 f，以 `M(A)=∫_A f(x)dx` 定义 raw mass，则不交区域满足 `M(A∪B)=M(A)+M(B)`。投影到图像时同样可以定义

`M_img(A)=∫ 1{z>0, π(x)∈A} f(x)dx`，

这仍是可加的有限测度，不需要先离散成多个中心。对完整划分，固定 FOV 后的共同归一化也与合并相容。单次面积 floor 是另一可加测度；但是对各子格分别改变内容 logits、温度或重新归一化，不能再从 raw 的可加性推出最终 attention 具有同一细分恒等式。这里没有定义新的内容规则。

**mode、均值、原生最大质量格是三种不同对象。** 即使在一维，mode 所在等宽格也可能不是最大质量格：令 mode=0，取很小的 l 和固定 r>0；让包含 mode 的格为 `[-1+η,η]`，相邻右格为 `[η,1+η]`。当 l→0、η→0⁺，前者的质量趋零，后者保持正质量。因此存在严格正 l、η 的连续全支撑实例，使另一格胜出。它无需透视或内容就否定“精确固定 mode 即保证 native argmax”的推断。

此外，非线性透视和截去非正深度可以改变 projected mode/mean；三维 a 是 mode 不代表二维 π(a) 是 mode。只有可逆同维仿射变换自动保留 mode 的对应关系，降维边缘化与透视不是这种变换。R38 的横向 RMS 正则若再作用于本分布，也需重审 mode 与 covariance，不能直接继承上述等式。

加入任意内容后，也没有恢复原 point winner 的定理。[R13 的理论审查](round13_anchor_closure_review.md)已经说明：若两个纯位置 logits 对任意共享内容都保持相同 winner，则两者只能相差行常数。把点读出改成直接返回 a 会绕过当前“区域和定位消费同一个最终 P”的合同，不能用来宣布旧中心 gate 通过。

## 6. 3DGS 参数映射与成本

实际 3DGS 的位置 μ、covariance `R diag(s²)Rᵀ` 和 opacity α 可以给出上述 Gaussian 极限。原论文采用未归一化 Gaussian 形状并以 opacity 参与 alpha blending；μ 同时就是其均值与峰值。[Kerbl 等，2023，第3–4节、式(4)–(6)](https://arxiv.org/html/2308.04079v1#S4)

标准单个 GS 没有独立于 μ 的 a。若不增添额外信息，令 a=μ 就严格回到 Gaussian，本偏斜机制没有收益来源。patch 的 a 可以来自既有中心射线，但它是额外的合法几何统计量，不能称已经从原 GS 的 `(μ,Σ,α)` 恢复。也不能从 patch 的潜在改善推出真实 optimized GS 门能够通过。

为区分 opacity 与概率质量，可把此分布的对应峰值形状写成 `G_skew(x)=f(x)/f(a)`，振幅为 `α G_skew(x)`。在 a=μ 时它恢复原未归一化 Gaussian。其总质量是 `α/f(a)`，一般不是 α；把 α 直接当概率总质量是不同约定。单查询的共同正振幅在无 floor 的行归一化中会抵消，加入固定面积 floor 后则一般不会。opacity=0 对应零振幅，不能冒称仍有正的可见质量。本文未改变现有 attention 的 opacity、floor 或 rendering 合同。

准备成本为一个 k×k 因子及线性解，通用为 O(k³)，k=3 时规模很小；每个点的 density 主要为 O(k²) 变换、一个方向投影及分段二次型。构造本身无需标量 root finding，也没有 K 个自由成分。它在物理坐标中是由一个超平面分隔的两个二次指数区域；这不等于每个 key 的精确质量只需两个普通矩形 Gaussian CDF。旋转后的格、严格正深度与透视锥体同时涉及多个不对齐约束，二维/三维区域积分和独立参考仍是实际工程问题。

因此，不能由 density 便宜推断完整算子成本低，不能把点 density×area 当区域积分，也不能声称它具备旧五维 Gaussian Q/K 恒等式或 RoPE 性质。正式成本仍须包括自身输入、内容、几何、积分和 attention/V；[原研究门图](research_gate_map_20261101.md)的所有要求不变。

## 7. 对后续决策的意义

可证实的部分是：在明确可行域内，一个已知分布族足以用单个可逆 transport 同时承载 mean、mode 和 covariance，raw 区域可加性不会因此丢失。无需先堆多个 Gaussian 或加一个中心 head，便可以表达一类偏斜支撑。

未证实且不能跳过的是：实际全人口可行性、投影后的 native argmax、相对强 quad 的区域质量、完整成本、数值尾部与独立参考、实际 learned V、optimized GS 以及未使用数据确认。当前尤其有两个直接障碍：全域原矩映射并不存在；中心 mode 保证又不对应旧中心决策。

据此，**不建议仅凭“偏度分开 mean 和 mode”就启动完整新实验或取代当前 R38**。这个准备结果保留为解析限制及受限表达能力的记录；若以后重新考虑，应先给出能够解释原生格质量和投影语义的独立机制，并在任何新数据或实验前明确全人口定义。当前没有选择这种机制、参数、预算或下一轮。
