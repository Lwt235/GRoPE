# R57训练期间的归因注记

2026-11-02。在原R57队列仍运行、尚无新dev_eval导出时记录。本注记不修改
冻结模型、比较、预算或选模规则；R57仍按原协议判断。它只约束未来正结果
能支持多强的解释，不把尚未执行的控制当作已有结果。

## 高斯形状相容项也可能承担内容比较

R57的中心偏移与协方差来自当前token特征。完整式相对pair_distance增加

    S_ij = -1/4 [tr(P_i Sigma_j + P_j Sigma_i) - 6].

该项直接比较两个内容条件化的形状参数，不直接依赖锚点间位移。因此，若
完整式改善分类，它可能改善了参数空间中的内容分组，而未必学到物理区域
形状。pair_distance是同容量的重要控制，但不能独自区分“高斯散度结构”与
“另一个有用的形状特征相似度”。此前的形状干预也不能补足这项归因。

R57的实际任务收益仍可以成立；较强的物理形状或高斯特有效果解释需要
另外的证据。纯几何项的共同仿射不变性也不意味着内容预测器或整网等变。

## 若出现可靠收益，可用一个不增加参数的后续控制

保留完整式的同一个预测器、相同P_i和中心距离，仅把S_ij换为固定的普通
二次相似度。沿用实际参数化

    P = L L^T / 16,
    diag(L) = exp(a),  lower(L) = (b21,b31,b32),

定义六维向量

    phi = (2a1,2a2,2a3,sqrt(2)b21,sqrt(2)b31,sqrt(2)b32).

在所有形状参数接近初始零值时，令A为P相对初始精度的一阶变化，则
diag(A)=2a、A21=A12=b21，其他非对角项同理。直接展开可得

    tr(P_i Sigma_j + P_j Sigma_i) - 6
      = ||A_i-A_j||_F^2 + O(epsilon^3)
      = ||phi_i-phi_j||_2^2 + O(epsilon^3).

因此可固定普通相似度为 -||phi_i-phi_j||^2/4，而不根据验证结果挑温度或
尺度。它与高斯形状项具有相同初态、初始零梯度和局部二阶项；两者都保留
自适应中心距离，其梯度能在初始化时驱动形状预测器。这避免了单独零初始化
平方特征距离可能永远没有学习信号的弱对照。

这个控制不需要另一个网络、损失或混合门控。它的全局几何性质不同，也不
保证效果更好；上述展开不是任务效果证据，更不是新的散度理论。目前未
实现、未训练、未冻结为下一轮。是否执行应由完整R57结果决定，优先完成
现有实验，不能用它提前扩大或收缩本轮结论。

若两者接近，应保留一般形状比较的解释；若高斯式稳定更好，仍需检查差异
是否在适用的几何变化、第二任务和未使用数据中保持。任一局部通过都不能
代替原始一般性目标。

## 后续局部对应任务的输入语义

训练等待期间核对了已有数据生产代码和报告，尚未运行新诊断：

- R46 使用 RGB 预测深度得到的中心坐标，统一到查询相机坐标系；
  `round46_native3d_data.for_role` 对所有现有角色提供零物理协方差。
  它可以检验学习型位置参数化，但不能证明模型利用了输入区域形状。
- R5 帧缓存另有 `mean3/cov3`，来自每个 8×8 预测深度 patch 的三维点矩。
  这是输入支撑的估计，并不是优化后真实 3DGS 的 R/S。不同视角中固定像素
  patch 也未必覆盖相同物理区域，不能直接将协方差相同当作正确匹配的定义。
- R41 输入真实 GS 的中心与 R/S，但任务是固定几何上的颜色读出/渲染。
  其负结果继续有效，同时不能替代完整 Transformer 的位置编码比较。
- R57 的协方差由当前 token 特征预测。学习型高斯参数化可以作为 PE 候选，
  不要求它首先成为物理协方差估计器；一般任务收益与物理形状解释须分开。

因此，后续局部对应实验需先说明其高斯表示学习型区域还是输入支撑，以及
这些量处于哪个坐标系、对应 token 是否应有相同支撑。比较必须给强控制
相同信息；额外几何输入的收益不能归因于 PE 公式。这里没有选定新的数据
划分、模型或训练预算，也不将这些说明增加为 R57 的事后通过条件。

证据：`experiments/round46_native3d_data.py`、`experiments/round5_cache.py`、
`experiments/round5_pairs.py`、`docs/round41_actual_gs_report.md`。

## 局部对应任务还需要区分已知与未知坐标关系

核对了 [GeoTransformer 的 TPAMI 扩展版 §III-B](https://arxiv.org/html/2308.03768v1#S3.SS2)：
其单点云 self-attention 编码点对距离与三点夹角，cross-attention 使用特征
相关性。[REGTR](https://arxiv.org/html/2203.14517v1#S3) 则将任务定义为从两个
点云估计未知刚体变换，并由 Transformer 预测对应位置。这些是任务/对照
设计依据，尚未移植或复现，也不比较论文分数与本项目分数。

据此，未来协议须明确选择哪一种问题：已有共同坐标系下的匹配，或未知
位姿下的配准。前者可以计算跨集合中心位移；后者不能先用真值位姿将输入
对齐再宣称解决配准。若将高斯关系用于后者，需要说明它在各点云内部的
作用及跨点云特征如何比较，并纳入适用的距离/角度几何强对照。不能只与
绝对坐标 MLP 比较后，把普通刚体不变性的收益归因于高斯形状。

这不要求复制上述论文的完整骨干、损失或配准后处理。若仅适配其位置算子，
应明确适配范围并保持其余部分一致。真实支撑矩的旋转规律、学习型预测器
的行为与整个网络的不变性仍是不同层次的性质。此处只补充下一任务的设计
边界，R57 的冻结实验与判断标准不变。
