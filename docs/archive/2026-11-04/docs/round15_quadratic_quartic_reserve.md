## 单密度、唯一归一化与协方差系数

设 `d=x−μ`、`S≻0`、`q=dᵀS⁻¹d`，定义

\[
 p(x\mid\mu,S)=\frac{\exp(-a q-bq^2)}{\pi I_0(a,b)\sqrt{\det S}},
 \qquad I_n(a,b)=\int_0^\infty q^n e^{-aq-bq^2}\,dq.
\]

二维白化极坐标体积元为 `√det(S) dq dθ/2`，所以归一化常数如上。
角方向均匀给出 `Cov(x)=S E[q]/2`。要求实际 `Cov=S` 等价于
`I₁/I₀=2`，而不是直接把某个未修正的尺度矩阵叫协方差。

对 b>0，使用稳定的 scaled complementary error function：

\[
 I_0(a,b)=\frac{\sqrt\pi}{2\sqrt b}
       \operatorname{erfcx}\!\left(\frac{a}{2\sqrt b}\right).
\]

分部积分给出 `a I₀+2b I₁=1`，因此

\[
 E[q]=\frac{I_0^{-1}-a}{2b},\qquad
 E[q]=2\iff I_0=\frac1{a+4b}.
\]

当 a=1/4、b 从0增加到∞，E[q] 从4连续降到0。其严格单调性来自

\[
 \partial_b E[q]=-\operatorname{Cov}(q,q^2)<0.
\]

对于非退化的非负 q，该协方差严格为正，例如用两个独立副本可写成
`E[(q−q′)²(q+q′)]/2>0`。故存在且仅存在一个 b>0。
求根只解这一协方差方程，不使用任何拟合误差或效果指标。

数值为：

| 数量 | 固定结果 |
|---|---:|
| a | .25 |
| b | .03649395645637156 |
| I₀ | 2.5254066909648114 |
| `1/(πI₀)` | .1260430200500431 |
| E[q] | 2.0000000000000004 |
| E[q²] | 6.850449342177369 |
| `∂E[q]/∂b` | −17.63836795819504 |

独立径向 adaptive quadrature 给出的归一化误差约2.2×10⁻¹⁶。
另外在 `[−10,10]²` 用 Cartesian GL128/192 检查三个密度的质量、均值和
协方差：质量与1的最大差约2.7×10⁻¹⁴，协方差对角与1的差≤4.5×10⁻¹⁶。
这只是良态合成数学核验，不是原生24px/极端尾部/float32 的数值认证。

## 可微性及参数含义

在 b>0 时全部径向矩有限，积分和其 a/b 导数光滑。隐函数定理给出

\[
 b'(a)=-\frac{\operatorname{Var}(q)}{\operatorname{Cov}(q,q^2)},
\]

固定点处约−.16160505036。它说明协方差约束的解平滑，不构成调整 a 的
授权。实际上 a∈[0,1/2] 的两个端点分别对应已有 pure quartic 与 Gaussian；
中间值 a=.25 仍然是一个人为固定、需要证据的形状选择。

本次 a/b 都是常数，没有新学习网络、混合、门控或逐样本形状参数。
对 μ 与 SPD 的 S，密度及其梯度光滑：

\[
 \nabla_\mu\log p=2(a+2bq)S^{-1}d,
 \quad
 \nabla_S\log p=-\tfrac12S^{-1}
 +(a+2bq)S^{-1}dd^\top S^{-1}.
\]

仿射变换下 `(μ,S)→(Lμ+t, LSLᵀ)` 的密度按 `1/|det L|` 变换。
如果以后仍采用 `S=C+h²I`，这规定总协方差，**不等于 Gaussian 卷积**。
`C=0,h>0` 得到这种新形状的 point blur；再令 h→0 才收敛到点质量。
原生矩形质量若实际积分则可加；query 拆分后重做单密度矩闭合仍不精确可加。

## 弱线性内容：中心曲率改善，但不保证中心定位

在白化坐标 `z=S⁻¹/²d` 中，给点 log-density 加固定线性内容 `s vᵀz`，
其中 `‖v‖=1`，`s=T‖g‖`，g 是白化后的内容梯度。这里 s 是合成扰动强度，
不是另一个待选模型参数。真实内容未必全局线性，该实验只检查局部机制。

沿 v 的唯一 mode 半径 r 满足

\[
 2a r+4b r^3=s.
\]

固定中间密度在原点的 log-Hessian 是 `−.5 I`；Gaussian 是 `−I`；
pure quartic 是0。因而弱扰动时中间密度 `r≈2s`，Gaussian `r=s`，
pure quartic `r=(πs)^(1/3)`。这确实修复 quartic 点势的非线性弱扰动
放大，但中心约束仍弱于同协方差 Gaussian。

更重要的是，**点 log-density 的零 Hessian 不意味着 cell integral 的
log-score 也没有中心曲率**。为避免混淆，另对中心在 `(r,0)` 的单位正方形
`[r−.5,r+.5]×[−.5,.5]` 积分 p，再给其 log-mass 加 `s r`。这是连续移动
窗口的机制探针，不是实际离散网格的 PCK，也不是新的读出器。

| 密度 | 点中心 log 曲率 | 单位 cell log-mass 中心曲率 | s=.01 的点 mode | s=.01 的 cell mode |
|---|---:|---:|---:|---:|
| Gaussian | −1 | −.91941085 | .01000000 | .01087653 |
| pure quartic | 0 | −.10534924 | .31553676 | .09260443 |
| 固定 a=.25 | −.5 | −.52447173 | .01999767 | .01906521 |

固定四个 s=.001/.01/.05/.1 全部归档，不据此选择 a、带宽或温度。
单位 cell mode 的 GL48/96 差≤6.7×10⁻¹⁶。s=.1 时三者 cell mode
分别为.10876354/.52823831/.18911363，同样只说明这个合成机制的折中。

更直接的离散反例：比较中心0和1的两个相邻单位 cell、内容差 s。
后一个 cell 超过前一个所需的 s 分别是：

| Gaussian | pure quartic | 固定 a=.25 |
|---:|---:|---:|
| .46001615 | .12561732 | .29168427 |

因此它有更大的 quartic 抗扰动余量，却仍有有限阈值；例如 s=.3 时中间
密度偏向相邻 cell，而 Gaussian 仍偏向中心。没有任何 PCK 工程保证。
同时 μ 仍是预测区域均值，不能把变尖误解为学会了真实 sensor 中心。

## 同协方差均匀方形：明确的区域代价

预先指定的合成真分布为 `[−√3,√3]²` 上均匀分布，Cov=I。
它的 `E[q]=2`、`E[q²]=28/5`，于是连续分布 KL 可精确计算为

\[
 KL(g\Vert p)=\log\frac{\pi I_0}{12}+2a+\frac{28}{5}b.
\]

| 密度 | 连续 uniform-square KL |
|---|---:|
| Gaussian | .3529704166 |
| pure quartic | .2501869626 |
| 固定 a=.25 | .2905915077 |

Cartesian 均匀积分与解析式差≤5×10⁻¹⁶。该结果不是原开发场景的
FOV-normalized native KL；不能替代任何历史验收门槛。
中间密度优于 Gaussian，却比 pure quartic 更偏离这个有限区域分布。
同理，当真分布恰为 Gaussian 或 pure quartic 时，相应已有密度的 KL=0，
中间密度不可能普遍支配它。尾部仍比 Gaussian 轻，但比 pure quartic 重；
“兼顾中心与尾部”不是“同时比两者都好”。

## 是否值得继续

这是一条精炼而可证伪的**条件备用**：只有独立机制证据支持“固定协方差下
quartic 的弱中心曲率导致区域/定位折中”，且当前候选完整既定流程给出需要
改变形状的结论时，才值得考虑另行预注册。它没有绕过强 Gaussian point、
quad、legacy、尺度、扰动、成本或下游真实值比较；不能根据当前未读的分数
倒推本假说。若 T=0 仍存在明显失败，尤其区域均值与中心目标冲突或单椭圆
不能表达多峰 support，该变化并不针对这些病因。

密度求值只多一个二次项，但可靠原生质量积分仍需单独数值认证与成本检查。
已有 GL24 对旧 quartic 的认证不自动覆盖这一新密度；本次没有实现生产
积分、混合公式、运行调参或实际效果实验。当前生产与验证保持原样。
