去掉尺度项相对原完整形状距离改善 3.13895%，但仍比 point 差 8.16464%。
shape-only 在 Teatime / Waldo 的 MSE 分别为 .017317824 / .030870162。
这支持“该原始尺度相似度在当前固定模型中有害”，不证明 GS 尺度普遍无用，
也没有把删掉尺度项后的消融重新定义为成功主方法。

注意力诊断覆盖两场景、五种子、全部 481,160 次可读源观察；种子重复不是新场景。
各源视图协方差 trace 位于最高十分位的 keys 得到的平均概率质量，
full / off / scale-only / shape-only 分别为 .10625 / .07394 / .13373 / .05347。
分组依据输入协方差，不是真值边缘或真实不确定性；分位点并列可能使组大小超过十分之一。
这说明尺度项确实把概率移向较大像素支撑，并不能单独证明这些位置错误。
相对投影 GS 中心的概率加权 RMS 像素位移分别为 47.12 / 47.33 / 47.54 / 47.17。
删掉尺度项没有消除整体空间分散；RMS 也可能受离群样本影响，不能解释为每行都错位。
