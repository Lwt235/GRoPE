主方法 PCK@8 为 91.9974%，普通点 RoPE 为 92.3508%，差 −0.3534 个百分点；五个旧场景均更低。与自由频率和各向同性频率几乎持平。判断不依赖 1pp 门槛：相对强点 RoPE 的平均方向已经为负。

## 研究问题与实现

借用高斯均值、旋转和尺度的参数化，在频率空间组织四组、每组六条旋转频率：`w_gm = sigma_g (mu_g + L_g epsilon_gm)`。只替换 R5 两层双向 cross-attention Transformer 内的 Q/K 位置算子，V、残差、LayerNorm、FFN 和最终匹配头保持一致。没有渲染器或 RGB 读出。
频率协方差是学习参数，不是输入 GS 的物理协方差。这是 GS 参数化形式的一种候选用法，不能证明真实 GS 形状信息有效。主方法增加 20 个参数，整体 166631；自由频率增加 48 个参数。整网容量差很小，不能宣传为整网压缩。
强对照包括同初始化的固定高斯频率、各向同性/对角协方差、共享/分组仿射和自由频率，以及完整重训的六个 R5 角色。分组仿射包含主方法的有限频率函数族；没有新表达能力或新核理论的主张。

## 有限诊断：位置编码是否参与计算

主实验的零 V 干预使主方法 old_eval PCK@8 从 91.9974% 降到 61.7890%，证明 V 路径参与，但这一点本身不证明位置编码有用。
因此另行预先冻结了[旧验证集诊断](../ROUND43_FREQUENCY_DIAGNOSTIC.md)，只用原 64 个验证对、四个角色的五个既定 checkpoint，共 50 次前向条件，不训练、不选择新模型、不接触确认集。完整 logits 导出到 CPU 后由 NumPy 重算全部查询指标。

| 旧 VAL 方法 | 正常 PCK@8 (%) | 关闭位置相位 (%) | 恢复初始频率 (%) |
| --- | ---: | ---: | ---: |
| gaussian_full | 93.9920 | 48.5942 | 93.9219 |
| free_frequency | 94.0337 | 48.7287 | 94.0148 |
| fixed_gaussian | 94.0811 | 48.8443 | 原本固定 |
| point | 94.5169 | 44.6609 | 原本固定 |

主方法关闭位置相位下降约 45.40pp，说明位置路径明确有效；恢复初始频率只下降约 0.0701pp，CE 几乎不变。自由频率恢复初始值也只下降约 0.0189pp。结论是：这些选定模型依赖位置编码，但学习频率形状带来的额外作用很小。干预存在分布改变，不能据此等同于重新训练的消融或断言优化的全部因果机制。
[诊断输出](../results/round43_frequency/diagnostic1/summary.json)中正常条件复现已保存选择结果：PCK 计数变化为零，最大单帧 CE 求和差 5.724e-5。

## 验证与适用范围

- 4 项 CPU 预检、13 角色 CUDA 小样本检查通过。全部 65 个选定模型共享权重均更新，30 个可学习频率角色的频率均更新。
- 65 个 checkpoint 独立 NumPy 频率/复数相位公式样本核对，最大概率误差 3.721e-7，零最大项变化、零数值告警。这是第一层固定样本检查，不是第二套完整网络。
- 62400 个完整评估帧记录由保存的逐查询充分统计重算。有效查询、PCK4、PCK8 计数全部一致。最大单帧 CE 求和差 1.826e-4、argmax EPE 求和差 0.001359px；这些误差没有改变 PCK 排名。
- 五个训练、五个导出、训练核对、完整指标核对和诊断进程均正常退出。峰值训练 allocated 805.68MiB；逐次训练/选择墙钟时间之和 3815.66s，五张空闲 A6000 并行。这不是排除共享主机影响的正式成本比较。
- [适用范围与文献](round43_scope_note.md)记录了有限 Cholesky 模板不自动旋转等变的反例，以及与六项旧验证的对应；不把矩匹配等同于完整高斯积分，不把该反例误报成任务误差。

## 决定

结束对这组高斯频率约束的晋升和参数补救，不扫描组数、带宽、温度或更多步数来追逐这批旧结果。没有把任何消融赢家改名为主方法。
本轮恢复了正确的研究对象：同一 Transformer 中的 PE 替换。下一项待论证的不同假设是直接用可学习空间高斯基函数构造位置向量，让中心与椭球尺度决定局部空间响应；这须比较已有 Gaussian Point Encoder 思路、普通 RBF、Fourier/MLP 位置编码，并继续接受同等强度的实际任务、几何/成本、泛化和未使用数据确认。当前尚未冻结或训练该下一候选。
