# 若真实 V 检查仍失败：一个单算子层面的备选假设

2026-10-30。写于 Round12 深度训练之前。当前没有新深度成绩，本文不改 full4、门槛、h/T 或正在准备的训练。先完成已冻结候选的检查；此处只明确一个可证伪方向，避免失败后继续盲目增加几何分量。

R8 的结果提示源值质量可能比对应路由更限制当前深度任务。R11 的四高斯改动主要近似区域质量，仍把一个 key 的 V 当作区域内常数。即使路由完全正确，“某个区域的平均深度”也未必是 query 射线处的深度。这个偏差与源深度预测的整体误差是两回事，不能假设它足够解释现有失败。

一个可检查的最小构造是让同一高斯同时提供位置质量和条件一阶矩。将源像素预测三维点变换至 query 相机，再用其实际投影拟合联合局部矩 `(u,v,z)`。对于该近似高斯，设二维投影均值为 m、深度均值为 d，协方差块为 C_uu、C_zu，则标准高斯条件均值为

\[
\widehat z_j(u)=d_j+C_{zu,j}(C_{uu,j}+h^2I)^{-1}(u-m_j).
\]

这是既有条件高斯公式，且通过投影后拟合只是一阶局部近似，不是精确透视表面相交。它在斜面上可描述深度随射线位置的变化；在断层、多峰、预测偏差或 FOV 外时可能更坏。四个固定分层能限制局部范围，但不能因此省略这些反例。

若线性读取 V，记 beta=C_zu(C_uu+h²I)^−1、a=d−beta·m，值端只需三个标量 `(a,beta_x,beta_y)`，即可在同一注意力权重下先聚合三通道，再于 query 坐标求值。无需逐 pair 的大值张量或额外预测网络。但是原 R7 先经过 GELU 的 value MLP 后再聚合，一般不能把条件求值与非线性交换；直接把上述等式塞入现有头会改变算子，必须公开新的合同与同信息控制，不能称为原头的等价优化。

这里的三个固定通道只对每个 key 的**单个仿射条件值**成立。若 key 也细分为四个高斯，其条件混合权重依赖 query 位置，通常不能压成同一组三个固定系数。四 query 支撑与单 key 仿射值、四 key 条件混合是不同候选；不能在实现中悄悄互换。

启用之前应先做旧训练集诊断：固定已有路由，比较源区域常数值与条件值；用传感器对应只作为清楚标记的诊断参照，正式候选只用合法 RGB 预测几何。所有 query 有效位置均保留，单独列出可核验对应与其余位置；不能只报对条件读取有利的可见区域。若收益远小于整体源误差，或简单 bilinear/source-plane 控制同样有效，应停止此方向。若确有稳定额外信息，再另开新协议检验是否能由一个紧凑的位置/值变换表达，并给点/平面/高斯控制相同信息和容量。它不能替代 full4 的原深度验收。

相关已有工作限定创新边界：

- [GTA](https://arxiv.org/html/2310.10375v3) 已将几何相对变换作用于 key/value 特征，对齐不同坐标系。因此“位置也应作用于 V”不是新主张。
- [PGSR](https://arxiv.org/html/2406.06521v2) 区分中心深度混合与基于平面/射线的深度读取。这支持检查具体读取语义，不能直接证明本任务的条件高斯会有效。
- [Direct Conditional Parameterization for N-Dimensional Splatting](https://arxiv.org/html/2610.22778v1) 已直接研究高斯条件均值、协方差和回归坐标。上述条件公式和有限回归通道不作为新的数学贡献。

当前决定：保留为机制备选，不启动效果实验、不新增角色、不改变正在进行的 Round12。
