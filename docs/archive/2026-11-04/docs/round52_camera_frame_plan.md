# R52候选：相机映射与高斯区域的单一组合

执行状态更新：R52已完成，见docs/round52_camera_frame_report.md及
ROUND52_CAMERA_FRAME_PROTOCOL.md。下文保留执行前的原始设计草稿。

2026-11-02。R51后的设计草稿，尚未实现、冻结或运行；不是已验证方案。
完整目标仍是精炼、一般且有实证支持的3DGS参数形式位置编码。研究已获授权，
不需要为开始常规开发再次询问。所有未用确认数据继续保留。

R51证据：HRoPE适配版可以小幅稳定超过MLP/恒等框架，但论文形式版不稳定，
较长帧间隔没有连续定位优势，NoPE的全局连续误差更好。完整GS和仿射、
各向同性、恒等框架接近，未证明完整形状的必要性。RGB置乱显著降分，
已排除R50那种几乎只靠输入中心做几何拟合的情况。

候选假设：跨视角任务需要先表达已知相机间的映射，再用高斯描述局部区域。
当前A=G^(-1)主要依靠公共网络吸收相机信息，且SPD相对线性块无法精确表示
纯旋转。拟检验A_i=P_i G_i这类单个4×4组合，其中P为既有标定相机映射，
G由紧凑μ和Σ^(1/2)构成。线性顺序、坐标尺度和已知相机约定必须先推导核对。
这是单一相对矩阵算子，尚无理由增加多任务头、渲染损失或额外并联模块。

竞争解释：相机映射单独已足够；完整形状不是必要自由度；二维相位/值传输
对大位移引入了不利先验；或者该数据和预算下显式位置算子就不比公共
位置/相机特征更有用。不能只比较当前较弱的MLP/RoPE而省略NoPE。

固定比较应至少覆盖NoPE、相机单独、相机×完整GS、相机×各向同性GS、
相机×一般仿射；校准HRoPE平面可作为直接表面几何参考，须按公式明确适配。
信息、公共网络、监督、训练预算和样本批次配对。沿用已使用真实数据的全局
指标、15/60帧切片及视觉依赖检查，另需明确相机尺度/坐标规范。该阶段不打开
未用确认集，也不把静态积分核门禁当成前置条件。

若相机单独或NoPE复现收益，就接受该竞争解释，不把一般相机/注意力收益
重命名为GS优势。若完整GS在同一预算下提供稳定且有实质幅度的增益，才进行
第二任务和未用数据确认。接近持平的微小差异不放大成数值失败；数学限制
也不能替代实验因果证据。HRoPE两版差异可在旧数据上做隔离诊断，但不应让
该实现诊断无限拖延主任务的直接GPU实验。
