# Round14 预审：先隔离内容温度，再考虑结构修改

2026-10-30。只审视父线程提出的诊断设计与已完成 R13 证据；没有读取 R14 效果或改写、运行其源文件。本记录不是新的验收协议。

**同 h=.5 的 full4/full1 × T0/T5 对照，比继续增加模块更适合作为下一步。** R13 中 full4 与 dense 在 T5 下的 argmax 已有 23/24 一致，而 dense 自身加入父内容后中心格对齐数下降。完整旧训练 cohort 上的固定温度对照，能够查明这是小样本偶然，还是同一个已冻结内容分数经常改变了有用的几何排序。它不预设 T0 更好。

拟定的七角色足以隔离两个关键作用：full4(.5,T0/T5) 的差是当前内容项；full1(.5,T0/T5) 给出该变化是否依赖四分量；full1(.25,T0) 与 full1(.5,T0) 则把旧 full1 的带宽差单独显示。冻结 point_pck(.5,T5)、quad16(.5,T5) 是必要任务参照。不要直接用 full4(.5,T5) 对旧 full1(.25,T0) 的总差归因于多峰；不要把七角色择优当作已预注册的候选胜出。

48 个旧训练 pair、所有 q8/q16/q24→g8 查询，比 R13 的三个 first-pair 子样本更能说明机制。必须保持每角色相同的 sensor-valid 区域与独立中心人口，按场景/尺度分别报告区域 KL、中心 PCK、成对变化和预测 argmax 改变。区域与中心合法人口本就不同，应明确两个分母；不能只报两者同时有效的有利子集。所有前向结果先保存，再读旧训练标签；原生分布的 argmax 和区域概率仍是同一个输出。

如果 T0 只修复 q24，却损害 q8/16，或区域收益消失，就不能只拿粗尺度的中心改善推进。若 T0 在三个尺度上共同兼顾区域和中心，它说明**在当前预测几何、父 token 池化特征和温度单位下，内容项不合适**；并不证明内容特征普遍无用，也不自动定位为 covariance、视角不变性或网络训练错误。可以保留按尺度/场景的内容前后排序变化来缩小解释，暂时不增加温度函数、门控或置信度模块。

“联合区域/中心约束校准”本身合理：把定位保护纳入训练集选择规则，比先按区域 KL 选配置、然后反复撞已知定位失败更一致。但选择规则必须在新分数前固定：一个全局配置，先满足全部声明的训练约束，再按预定区域目标及固定 tie-break 选择；无可行配置就报告无可行解。不能按 query/场景/尺度使用标签切换 T，不能在旧验证集反复搜索，也不能把训练约束当验证通过。当前七个固定角色首先是归因诊断；是否建立新的候选校准协议应另行记录。

**T0 还有实质结构边界。** 它是纯几何路由，学习内容 Q/K 在此 attention 中无数据梯度。作为参数到区域权重的精炼算子，它可以是合法候选；作为通用的“PE 改进内容 attention”，它尚未给出所需证据。若将来推进真实 V 训练，必须另写锁定协议，披露有效参数数与梯度路径，并保留强几何读取、同容量单视图和实际 V 对照。不能把旧 R12 的 T5 深度协议原样标成已覆盖 T0，也不能通过闲置 Q/K 权重掩盖容量变化。

这次最小诊断若有希望，后续仍需回到原九分区、五尺度、六扰动、真实 V 和独立确认；其中只有三个 query 尺度、固定 g8 key 的训练分数不能代替分区可迁移性。若没有共同可行性，则暂停“只调当前区域分布”的路线，比继续加平滑/锚定/内容模块更符合精炼与可信目标。
