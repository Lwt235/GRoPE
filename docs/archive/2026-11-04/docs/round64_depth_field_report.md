# R64：单深度场耦合中心与形状，仍未改善强对照下的 RGB 匹配

2026-11-02。九次新训练、选模检查、66组指标复算和两幅实际结果图的审阅
均已完成。**主候选未通过本轮效果验证，不进入确认集。** 完整研究目标
仍未达成；本轮没有访问未使用确认数据。

## 问题与比较

R62独立预测深度和六维形状没有胜过强对照；R63固定权重替换观测几何
也没有修复结果。本轮检验一个更简洁的生成约束：每个token、每层只预测
一个深度，用同一深度场生成中心和局部表面协方差，保留原11维关系MLP
和相机注意力接法。竞争解释是：问题不在独立形状自由度，或任何收益
仅来自邻域信息、标定计算及现有注意力接法。

新增三组、各三个种子：表面高斯（主候选）、去掉深度导数的足迹高斯、
同局部深度信息的直接MLP。576/64/480对旧RGB数据、5000步、共同初始化、
实际采样、验证CE选模及冻结RGB特征保持一致。复用24个R55/R62模型；
这24个模型及其48组预测不是新的独立训练证据。

主候选比射线仿射EPE高0.27953像素，即7.62%；三个配对种子分别差
+0.31554/+0.26414/+0.25892，五个场景平均值均更差。PCK8低0.987个百分点，
三个种子均更差；argmax EPE高0.16151像素，也在三个种子及五个场景均更差。
连续误差超过16像素的尾部比例高0.253个百分点，三个种子均更差。
因此失败不能只解释为“使用概率期望作为读出”的问题。

相对PRoPE，连续EPE高0.08286像素，三个种子均更差；但CE低0.02464，
三个种子均改善。PCK8只差−0.011个百分点，应视为几乎持平，不能将其
夸大为实质退化。相对同局部信息MLP，EPE高0.03081像素，只有1/3种子、
1/5场景均值有利；这个小差异不证明高斯普遍更差，也没有提供稳定优势。

## 保留的局部正结果及其边界

表面高斯相对无导数足迹的连续EPE改善仅0.02127像素，配对差值为
−0.01086/−0.09145/+0.03849，只有2/3种子改善。不过PCK8提高0.434个百分点、
CE降低0.05998，两项均在三个种子及五个场景均值中改善；argmax EPE降低
0.07292像素，三个种子均改善。这说明局部深度导数在部分匹配指标中有用，
不能把本轮概括为“导数完全无用”。但它没有转化为相对强对照的整体收益，
也不能事后用次指标替换已冻结的主指标。

相对R62固定球形中心组，表面高斯EPE降低0.14542像素，三个种子、4/5场景
均值改善。足迹高斯也降低0.12415像素，三个种子改善。区域大小与方向的
构造优于该特定球形基线，但二者都没有胜过射线强对照。相对R62独立完整
高斯，主候选只降低0.04875像素，2/3种子改善；耦合方式与可达范围同时
改变，不能把差异唯一归因于减少自由度。

RGB置换后，表面高斯EPE为6.00109，足迹为5.35487，局部MLP为5.64301。
表面组在这一诊断中更差；没有获得稳健性通过的证据。15/60帧间隔下，
表面组EPE为2.51319/6.81562，射线仿射为2.33141/6.30378，两档均落后。
帧间隔并非独立的缩放或表面倾斜干预。

## 实现与审计证据

52个冻结源保持一致；四项实现测试通过，包括解析公式、边界导数、梯度、
初始等价、输入排除和独立token排列。原控制器及15个子任务全部正常退出。
九个模型的选模完成在新评估导出之前；实际采样、共同初始化、训练步数、
模型与验证记录身份一致。独立复算全部66组指标，最大差异2.12e−9；验证CE
差异4.78e−8，CPU重放logit差异5.86e−5，独立关系算子差异3.85e−6。
这是独立算术路径及有限重放检查，不是另一实验室的完整网络复现。

两幅实际图已查看：配对EPE图清楚显示对射线强对照的三个正向差值；
验证曲线在初段快速下降后变化较小。训练后期较平并不证明全局收敛，
也不提供事后延长预算的依据。九次训练及选模累计11933.55秒；表面/足迹PE各10465参数，
局部MLP为10369。实际峰值显存约9.03/9.03/8.32GiB。结构简化没有消除
逐对关系计算的开销；共享主机耗时不是受控速度基准。

## 决定

保留局部正结果和整体负结果。停止沿用“继续微调RGB高斯生成器即可解决”
这一未经支持的推进方式，不扩预算、不增加损失或骨干模块来挽救本轮。
下一步重新检查核心PE在**真实优化3DGS参数直接作为输入**时的价值，并与
获得相同属性的强对照比较；先核实开发数据来源与训练划分，再冻结实验。
这补上原主题中尚缺的真实基元与跨任务证据，并不撤销RGB失败或完整目标
中的泛化、鲁棒性和未使用确认要求。暂不宣称新方案成功或具有一般性。
