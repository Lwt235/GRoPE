# 后续基线证据复用边界（未采用、未执行）

本文是后续协议准备，不选择 R18 候选、不授权运行、不实现缓存框架。
**R17 当前冻结的完整前向、评价、计时及独立审计流程保持不变。** 没有读取
当前 R17 VAL 分数。只有其完整结果经独立审计并正式接受后，未来另行冻结的
协议才可引用；不能复用部分完成、未审计或存在未解决数值错误的结果。

依据：[R17 候选复用约定](../ROUND17_CANDIDATE_PROTOCOL.md) 与
[R17 旧验证合同](../ROUND17_VALIDATION_PROTOCOL.md)。接受的是证据完整性，
不是把历史候选的科学结论带入下一轮：即使 R17 primary 效果失败，已审计
正确的控制仍可作为固定比较；失败记录、适用范围和来源必须一同保留。

## 可以复用什么，怎样绑定

仅当完整算子、配置、输入、数值路径、partition/state、标签和评价人口
完全一致时，直接引用旧控制逐行证据，避免全量重复前向。未来新锁应绑定：

- 旧 source/lock、全部 forward commitments、evaluation rows、completion、
  acceptance decision，以及独立 audit 的锁、verification 和完成链的 SHA；
  明确新语义 alias 对应哪个旧 operator，而非按角色名称猜测等价。
- 每行以 **scene、pair、state/scenario、condition、operator** 严格 join，
  核对 config、canonical probability/argmax hash、input/target hash、native
  shape；保留 KL/JS/direct 指标和、mass、PCK 整数及分母，不只引用宏平均。
- 新候选和任何变化的 matched control 先完成新前向并封存，再评价。新的
  独立分析器校验全体行身份、无缺漏/重复及新旧共同人口，重新汇总联合表、
  精确 PCK 差值和全部原门槛；继承基线不减少科学比较。

不继承任何“新候选已有效”或“已通过旧门槛”的结论。固定 strong point/quad
可以继承其已接受的 **TRAIN** 选择及来源，不能在 VAL 挑另一个有利配置。
若未来设计改变合理校准预算，必须在新协议中先说明并完成相应 TRAIN 校准；
已有精确相同配置的结果仍可引用，新增配置须计算，旧科学比较不得删除。

## 哪些变化使直接复用失效

| 变化 | 必须补做 |
|---|---|
| 预测器、相机/投影、前向像素集合、特征或池化/归一化、partition/state、support/λ、geometry/content/tau、h/T、dtype、积分、floor、截断或 softmax 改变 | 对受影响算子重新前向、承诺概率、评价和独立数值审计。相同 h/T 或代数相等不足以证明同一执行路径 |
| 标签、中心定义、评价 mask/人口或指标定义改变，而前向确实未变 | 旧逐行指标不能直接引用；用原保存概率或按旧冻结算子重放后重新计分、审计。若旧加性统计足够支持新聚合，也须先声明并独立验证充分性 |
| 新增学习 V/head、训练种子、checkpoint 或训练策略 | 新下游训练及完整预测/指标证据；区域 attention 指标不能代替任务效果 |

matched constant/iso 的名称不保证等价。只有完整配置及数值语义完全相同才
可引用；例如 primary 新 λ、h/T 或 tau 定义通常会同时改变其 matched 控制。

## 审计继承和成本边界

旧 control 的完整重放、标签/中心及投影审计、独立数值样本可作为**继承证据**
绑定，无须虚构新一轮再次读取所有大数组。必须准确披露旧覆盖和误差：不能
声称本轮重新执行了这些控制、重算了全部原始指标或独立积分；新联合汇总的
独立计算是另一项检查。旧样本数值通过也不证明新候选正确。新候选自身的
数值、标签接线及完整指标审计仍必须完成；少量预声明旧控制 hash 哨兵可
检查当前环境兼容性，但不能改称全量新重放。

**计时不继承历史数值。** 下一轮仍在同设备、线程和配对顺序下，对候选、
参加成本比较的全部旧控制及归因角色现场计时；保留原五场景×九条件、
3 warmup/15 repeats 规则及其完整准备/积分/内容/softmax 范围。各角色重算
自身统计，不给旧基线免费缓存，也不让候选借用 primary 的准备。公共预测、
投影等按原合同单列。准确率证据复用与现场新计时必须分开披露。

最小实现只需一个明确的来源 manifest 和严格逐行合并，不需要通用复用框架。
旧 VAL 已用于开发；减少重复计算不会恢复其独立性，也不授权 fresh 确认。
