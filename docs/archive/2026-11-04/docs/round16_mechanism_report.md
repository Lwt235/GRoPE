# Round16：完整旧训练概率的机制诊断

记录时间：2026-10-30 11:44:17 UTC。

**当前纯四次 full 核的大尺度定位损失，与较小的原生格几何间隔及内容项诱导的 winner 改变相符；不能仅归因于共享均值不准，也不能据此认定所有内容项都有害。** 在 h=0.25、0.5 时，q24 的 full 核 T0 定位实际上优于相同均值的点核，加入 T5 后才出现显著净损失。q8 的作用方向相反或弱得多。这解释了本候选的一部分失败机制，不撤销 Round15 的停止决定，不产生新的候选或验证通过结论。

本轮在完整 Round15 TRAIN 结果和停止决定已知后固定分析合同，属于探索性开发诊断；不是独立确认。它复用三个旧训练场景各 16 对，共 48 对的全部 Stage A 概率，无新模型前向、参数搜索、区域标签读取、VAL 或新数据访问。先前的三个机制假说及其实际记录时间见[假说说明](/home/liwt/GRoPE/docs/round15_pre_result_mechanism_hypotheses.md)，本轮执行边界见[冻结协议](/home/liwt/GRoPE/ROUND16_MECHANISM_PROTOCOL.md)。

这不是单场景的 q24 异常。h=0.25 时，c3/c5/c6 的 q24 变化分别为 −6.806/−7.960/−3.205 个百分点，q8 却分别为 +0.277/+0.203/+1.662。h=0.5 时 q24 仍三个场景皆降（−7.592/−9.950/−5.449），q8 则为 −0.185/−0.465/+0.990。因此 h=0.5 的 q8 微小宏平均收益不能说成每场景受益，更不能据 q24 推断关闭全部内容必然更好。

原生几何间隔定义为 `log P0[j0] − log P0[j2]`，其中 j0、j2 是 T0 概率的前两名，按原 first-index 规则处理精确平局；它包含既定 floor。full 核的间隔随 query 变大明显缩小，而同 h 的点核没有同等幅度变化：

h=0.25/0.5 的 full q24 间隔分别只有 q8 的约 1/11.77、1/7.29。h=0.5、q24 时，T0→T5 的平均 winner 位移为 4.114 px；同 h 的 quartic_point/Gaussian point 仅 1.088/0.822 px，且定位分别小幅改善 +0.185/+0.059 个百分点。full 与同 h/T Gaussian point 的配对中，full 额外正确 2.512%、额外错误 9.222%，净差 −6.710 个百分点；二者 winner 一致率为 61.944%。共享 μ 和内容不能消去这个差异。

这里支持的是“full 支撑及宽度对应更小的离散几何间隔，内容更易改变 winner”的解释。逐 query 还核验了

`log PT[jT] − log PT[j0] = (T·content[jT] − T·content[j0]) − (log P0[j0] − log P0[jT])`。

T 与 content 的乘法先按原路径在 float32 中完成再转 double。它是对既有概率的代数核验，不是独立因果证据；连续四次密度中心 Hessian 为零，也不等于矩形积分后离散分数的曲率为零。完整 Stage A 没有 Gaussian full，因此不能从本轮独立分离 full 协方差下的径向核形状、支撑宽度、各向异性和有限格积分贡献。另一方面，h=2、q24、T5 时 quartic_point 也只有 69.725%，Gaussian point 为 83.026%，说明仅归咎 full 新增的协方差同样不充分。

纯几何的 T0 证据也限制了归因。h=0.25/0.5 的 full q24 PCK 比同 μ 的两个点核高 +0.929/+1.012 个百分点；h=0.5、q24 的配对整数为 full 错而 point 对 2 个、full 对而 point 错 13 个。因此不能把这一配置的大尺度净失败主要叙述成 T0 几何 winner 已经严重错位。q8/q16 仍有小幅 T0 净损失及具体几何错位样本，不能说几何项没有问题。保留的方向、条件数与网格相位可供审查，但本报告没有追加按效果选取的分箱、阈值或关联检验，也没有证明各向异性是唯一原因。

均值偏差是共享的绝对误差来源，不能单独解释 full 相对点核的损失：

| query | μ→独立中心真值均距（px） | 最近 μ 的 key 中心 PCK % |
|---|---:|---:|
| q8 | 2.195 | 92.830 |
| q16 | 2.355 | 92.205 |

这三个族使用同一 μ、父内容和中心标签，均值到真值的误差与 h/T 无关。最近 μ 格只是诊断参照，不是性能上限，未替换原 argmax readout；full 的 q24 T0 结果已经能超过该参照。当前证据不足以支持统一更换中心作为主要修复。各族记录的 `S=C+h²I` 条件数/方向均以共享 full-support C 为机制上下文；point 实际核仍用 C=0，不能把这个记录误称 point 的实际核协方差。

独立审计已通过，原始 5,184 条 PCK/argmax、全部诊断数组、配对统计、来源及时间链均被重算。μ/C 准备和 float32 内容乘积明确复用冻结 Stage A 路径；本轮独立的是新诊断数学与汇总，**没有声称独立重建 μ/C**。原 `summary.json` 保留生成时的 `independent_audit_pending=true`，之后完成的审计结论在单独 verification 中，未回写冻结 summary。
