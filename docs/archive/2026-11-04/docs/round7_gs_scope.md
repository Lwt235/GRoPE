# Round 7: real optimized 3DGS primitives are a separate applicability claim

2026-10-30. The five-channel encoding is exact for **one common key covariance**, as in a uniform image-cell bank. It is not an exact general encoding of arbitrary optimized 3DGS primitives. The real-data mechanism audit below confirms this limitation and does not find an independent benefit from primitive internal R/S in the reused regional SfM task. No Round-7 fresh test input or label was read.

## Three different meanings of Gaussian support

An optimized primitive has parameters `(mu,R,s)` and covariance `C=R diag(s^2) R^T`, together with opacity and radiance parameters. These ellipsoids are optimized for rendering. The [original 3DGS paper, §4–5](https://arxiv.org/html/2308.04079) uses anisotropic splats, projection and visibility-aware compositing; a primitive's extent is not a calibrated posterior error bar for its center. The [official implementation](https://github.com/graphdeco-inria/gaussian-splatting/blob/main/scene/gaussian_model.py) constructs covariance from scaling/rotation parameters. Our actual files are trained local MiniColmap exports, not a claim to reproduce the official model's reconstruction quality.

The earlier regional exporter instead combines many visible primitives:

\[
C_{region}=\underbrace{\sum_iw_i(\mu_i-\bar\mu)(\mu_i-\bar\mu)^T}_{C_{centers}}
+\underbrace{\sum_iw_i C_i}_{C_{internal}}.
\]

`center_dispersion` retains the first, shape-rich term. It is **not** the point-only position control. `full` also retains optimized primitive internal covariance. The mean, visibility, weights, masks and labels remain fixed when comparing those terms.

Round-6/7 image-region supports estimated from predicted depth are a third representation: their scatter and within-pixel covariance describe an input pixel region's pushforward. Native key-cell covariance is known and common within a grid. Such supports are not optimized 3DGS R/S; region area is not primitive opacity or covariance determinant. A result with one representation cannot validate all three.

Normalizing an optimized splat into a probability density is an additional modeling choice. A normalized Gaussian contributes a determinant-dependent amplitude, whereas the rendering primitive also has its own opacity and compositing. The fact that both use a Gaussian shape does not make a density-overlap correspondence score equal to rendering overlap, surface area or visibility probability. This audit uses **unit key mass identically in every control**, so an R/S ablation cannot also change an implicit mass prior.

## Existing evidence already constrains the claim

The archived R3 decomposition uses independently observed sparse SfM track transfer, not labels generated by Gaussian overlap. On its train/validation development rows, full regional BC CE was 1.1706 versus center-dispersion 1.1588. The R4 frozen normalized-PE intervention found full-minus-both-center CE `+0.004614`, with its fixed-scene camera/seed interval positive. Neither result supported a benefit from internal R/S.

R5 additionally **retrained** full and center-dispersion at the old selected scale and identical optimization budget, removing the input-swap distribution-mismatch concern. Its full arms reproduced the old checkpoints exactly. Primary all-scene pooled CE was 1.170130 versus 1.161619; the positive difference favored center. The scene-macro interval crossed zero and the aggregate was principally driven by Figurines. This does not establish that R/S is universally useless. It establishes that the previous project evidence cannot be cited as proof of its independent value. See [R5 mechanism interpretation](../results/round5_primitive_retrain_raw/analysis.md).

## New audit, fixed before execution

Code: [round7_primitive_audit.py](../experiments/round7_primitive_audit.py). Results and exact source/data SHA256s: [summary.json](../results/round7_primitive_audit/summary.json). Only the already inspected Tea/Waldo **validation pair NPZs** were opened; no old test pair NPZ or Round-7 fresh data was opened. The shared source reconstructions themselves may contain information from old evaluation photos. This is not an unseen-geometry or unseen-image experiment.

The two audit branches have different purposes:

1. **Individual primitive operator diagnostic, without correspondence labels.** For the first validation camera pair in each scene, select 64 query and 64 key primitives by fixed opacity/opaque-center visibility and evenly spaced sorted primitive IDs. Query-even/key-odd IDs are disjoint. Keys must project in front of and inside the query image; selection never examines covariance quality, labels or model scores. Both primitive sets are projected into that image using the same camera Jacobian. The saved sample includes actual scales, wxyz quaternions, world covariance and IDs. A bounded deterministic V probe tests attention differences; it is not a task label or accuracy measurement.
2. **Regional matching against real observed SfM tracks.** Process all 36 validation camera pairs per scene and both primitive parities, using the archived decomposition. Reproject every covariance variant at the same serialized means. Evaluate the complete pair Gaussian kernel with point-distance, center-dispersion, same-trace full and full controls. All share unit key mass and bandwidth `.5` in the old `24-pixel` coordinate unit. This bandwidth comes from the archived R3 projected-center-RBF development selection; there is no new search or old-test retuning. The regional density kernel has not been separately optimized for this task, so this estimates behavior at that common old operating point.

The primary regional mask retains at least 95% of the original target mass; the looser conditional mask is also reported. All controls share each exact row/key mask and label renormalization. Four pair/parity conditions have zero eligible query rows under the original masks and are explicitly listed in `regional_skipped_conditions`; all 72 camera pairs were opened, yielding 140 nonempty pair/parity archives. The independent track labels are fixed observed image-region counts; they are not dense area truth, and their reconstruction provenance is not statistically independent of the shared scene geometry.

## Real primitives falsify the unrestricted exact-five-channel claim

The sample covariance reconstructed from the actual scales/quaternions agrees with the exported world covariance to maximum relative error `3.84e−7`. Thus the diagnostic uses optimized primitive R/S, not a renamed pixel-cell covariance. Both source reconstructions contain one million primitives; only the declared fixed sample is used in the following operator matrices.

For variable key covariance, the reference score is

\[
b_{qk}=-\tfrac12\Delta^T(C_q+C_k+h^2I)^{-1}\Delta
-\tfrac12\log\det(C_q+C_k+h^2I)-\log(2\pi).
\]

The current five-channel map substitutes the **unweighted mean key covariance** for every key. That is a declared approximation, not a fitted best approximation. It is compared with the full variable-covariance reference and with a common-covariance counterfactual. The pair implementation also agrees with an independent float64 solve/slogdet reference within `3.4e−15` in probability.

| Scene / pair blur | Row-centered log-kernel rank, relative tol 1e−6 | Best rank-5 logit relative Frobenius residual | Mean-key-C lift maximum probability difference | Mean total variation | Changed top key / 64 |
|---|---:|---:|---:|---:|---:|
| Tea / old `.5` = 12px | 19 | .00501 | .04487 | .00922 | 2 |
| Waldo / old `.5` = 12px | 14 | .00234 | .03868 | .00330 | 0 |
| Tea / fixed 1px | 57 | .11568 | 1.00000 | .26776 | 11 |
| Waldo / fixed 1px | 45 | .04454 | 1.00000 | .22931 | 16 |

The one-pixel setting is a predeclared local mechanism scale, not a label-selected operating point. The changed top keys are **disagreements between operators**, not correspondence errors. The V probe's maximum output difference is `.0761/.0491` at the old blur and `1.697/1.733` at the one-pixel blur for Tea/Waldo. This quantifies a real attention consequence without inventing primitive ground truth.

For any five-channel Q/K factorization, the score matrix has rank at most five; subtracting each query-row constant cannot increase it. The observed row-centered rank substantially above five therefore rules out an exact five-channel representation of these variable-covariance matrices up to row constants. The best-rank-five residual is a bound in **logit Frobenius norm**, not an attention-probability or task-performance bound. The error of the particular mean-key-C substitute is not a lower bound on every possible approximation.

When the actual key covariances are replaced by that same common mean, the actual five-channel implementation and the pair reference recover probability agreement within `9.72e−14`. The failure is the unequal-covariance domain condition, not a faulty five-channel expansion. Finite-dimensional approximations or other kernels remain possible, but the current results do not authorize calling one exact or useful.

The new replay adds only a six-second CPU mechanism check, with zero parameters fitted and no new network or large Fourier feature expansion. The initial execution is preserved separately; the final execution additionally records the four empty conditions explicitly, without changing any scored row or result.

## Consequence for the research route

Retain the concise five-channel method for **projected region supports against a uniform known target-cell bank**. Treat direct arbitrary primitive-to-primitive matching as an unresolved extension, requiring the full variable kernel or a separately justified approximation. Do not conflate a negative internal-RS attribution with a negative result for all region-support PE, or a positive area-transfer result with successful optimized-primitive R/S encoding.

Before proposing a direct primitive task, obtain task labels that are independent of the candidate kernel—such as externally grounded semantic/surface correspondences or a declared downstream rendering/geometry objective. Primitive IDs in one reconstruction would make identity matching trivial; Gaussian-overlap pseudo-labels would make the proposed kernel its own judge. The existing SfM task remains useful as a regional mechanism control, with its sparse-label, fixed-visibility and reused-reconstruction limitations plainly stated. No new module is justified by this audit alone.
