依赖该样例的 7 项比较全部留档，记录为缺少完整 `log_raw_mass` 的 `KeyError`。这是两次参考失败的后续依赖结果，不是七个额外的数学反例；也不能将这些比较删除后宣称整轮通过。初始 edges/pilot 数组尚未加入可保存集合，失败档案没有给出具体是哪两个断点相邻；本报告没有重建或重跑它们。
