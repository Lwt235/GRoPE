# R36 固定合成独立参考协议

执行前冻结 [设计](docs/round36_component_round_reference_design.md)、R35失败验收及诊断、全部输入/旧输出的来源哈希、新参考、runner、独立审计和测试。

只允许23个原合成输入的46次新参考。全部135个旧oracle身份唯一，共339项必要比较；先独立输入审计，后新参考全部封存，再读旧输出。没有生产重跑、真实数组或标签授权。

外层GK21保留原标量截断估计，累计全部历史舍入向量后取max；当前叶积分和标量误差用fsum重算。新停止量包含截断与舍入之和，仍严格小于原相对容差maxnorm的八分之一。确定的逐次细分、失败、完整trace及成本语义以设计为准。

全部原raw/P、归一化、直接FOV、尾界和单调用/合成阶段预算保持。完整交付不等于数值通过；成功子集不得代替全部人口。新参考通过也不等于科学方案通过；不得回写历史失败或把partial提升为oracle。
