- 历史程序的冻结锁可能要求文档位于旧路径；重跑旧轮次时按 manifest 临时恢复对应原路径或创建软链，仍使用原始字节及原锁，不改写摘要。当前 R70 所需的两份计划留在原路径。
- 本目录中的旧 README 和状态长文仅作历史证据，不再是研究入口；未执行草案不视为已完成实验。
