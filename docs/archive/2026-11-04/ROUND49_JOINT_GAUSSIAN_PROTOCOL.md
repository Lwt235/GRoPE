# R49：在同一注意力分数中保留中心相位与高斯空间先验

2026-11-01。R48 已全部完成；完整高斯在原生分类中未稳定超过 RoPE、MLP
和自由二次项，R47 三维匹配负结果也保留。冻结本方案及代码后再启动训练。
本轮是旧开发数据上的机制实验；无论结果如何，都不直接完成一般性研究目标。

## 问题与备择解释

主假设：R47 的条件高斯空间项与内容相关的相对相位可以互补；保留中心 RoPE
后，完整高斯比两部分各自单用、普通坐标映射及等容量二次项更有效。
备择解释：两者重复；固定距离先验已经足够；额外通道/非线性而非高斯结构
解释收益；较简单的轴对齐或各向同性形式已足够；输入几何的信息限制仍占主导。

高斯局部注意力及高斯/RoPE 组合已有先例。本轮不是首次提出高斯注意力，
也不是现有论文的完整复现。已有文献核对记录：
`results/round48_modelnet/literature_scope1.json`。仓库中的覆盖空白不是新颖性证据。

## 唯一位置公式

沿用 R47 的完整双向两层 96D/2 头 Transformer、V 聚合、残差、FFN、48D
匹配头及 166611 个公共参数。只将注意力分数改为：

    delta_ij = x_j - x_i
    score_ij = T <R(x_i) normalized(q_i), R(x_j) normalized(k_j)>
               - .5 (delta_ij-m_i)^T P_i (delta_ij-m_i).

中心相位沿用同域的 R46 point/center RoPE 频率。高斯参数、尺度、界限和
初始化完全沿用 R47：一个跨层、跨方向共享的线性预测器从 LayerNorm(token)
输出每头相对中心及 Cholesky 精度；m=4*tanh(raw_m/4)，形状 t=3*tanh(raw_t/3)，
L=diag(exp(t_diag))+strict_lower(t_off)，P=LL^T/16。没有新的混合系数或调温参数。

忽略 softmax 中抵消的查询行常数后，空间项仍是 2D 的 5 个、3D 的 9 个
二次位置 Q/K 通道。它们可与旋转后的内容通道组成同一个点积；当前实现保持
旧 float32 内容点积加 float64 位置点积后转换，以便和既有实现保持一致。
不据此声称已经实现单次融合 GEMM/FlashAttention 或获得推理提速。

没有附加几何匹配头、形状距离分支、渲染器、训练目标或后处理。输入物理
协方差不参与位置预测。高斯幅度/行 logdet 仍抵消，不加入无效 opacity 参数。
算子具有相应的相对位置代数性质；训练网络没有自动 SO(3) 不变性。

## 新训练、复用与数据

两个坐标域均训练六个联合角色，各 5 个种子 11/22/33/44/55，共 60 次新训练：

| joint_ 后缀 | 2D / 3D 新增参数 | 用途 |
| --- | ---: | --- |
| conditional | 970 / 1746 | 动态完整形状；joint_conditional3d 为固定主方案 |
| diagonal | 776 / 1164 | 动态对角形状 |
| isotropic | 582 / 776 | 动态标量宽度 |
| static | 10 / 18 | 每头固定中心和完整形状 |
| fixed | 0 / 0 | 中心 RoPE 加固定宽度 4 的距离先验 |
| free_quadratic | 970 / 1746 | 等容量自由二次项，加相同中心 RoPE |

自由二次项沿用 R47，匹配高斯初始值及初始一阶导数；正定约束、中心精度耦合、
非线性及可达系数范围同时改变，两个有界系数集合互不包含。因此不将差值
解释为孤立的正定性因果效应。所有联合高斯角色在同一域初始函数相同。

复用 R47 已封存并回算的全部 95 个对照（其中含 R46 的 30 个模型），核对
源文件、公共初始化、1000 步采样流、选模记录、模型及原预测哈希。
这包含两域的高斯项单用、自由二次项、NoPE，以及点 RoPE、Gaussian warp、
MLP/Fourier warp 等强对照。复用不意味着重新标记其数据为未使用确认。

沿用 R46 已核对的全部输入数组：576 TRAIN / 64 VAL / 480 old_eval 对，
432 个候选 key、110189 个有效 old_eval 查询、五个旧场景。视觉内容、预测
深度、相机元数据、标签和可见性人口均不变，不重新构造几何。二维与三维
位置输入的任务信息不同；同域对照用于归因 PE，跨域结果用于报告任务竞争力。
原始确认场景及 ModelNet40 官方测试集均不访问。

## 优化、核验与资源

保持旧匹配实验的 1000 更新、batch8、AdamW(.001,.0001)、clip1、cosine 到
初始学习率的 .2；独立采样 RNG seed+50000，公共初始化和实际采样摘要匹配。
在 0,100,...1000 步按验证场景宏平均 CE 严格最小选模，平局取最早。
不增加角色专属预算，不扫描频率、温度或宽度。固定预算不证明收敛。

全部 60 个新模型选定、核验并与 95 个复用对照封存后才导出本轮 old_eval。
保存主路径及 zero-V 路径的全部查询统计，并独立回算 PCK8、PCK4、CE、EPE
和 soft-EPE。zero-V 是路径诊断，不是另一个训练方法。

CPU 合成检查：配对公共初始化/参数量、初始函数、两部分消融与旧实现一致、
非零参数的独立复数相位+直接高斯能量、有限差分/梯度、平移/排列和输入边界。
CUDA smoke 覆盖 12 个联合角色，再启动训练。选定模型第一层 8 查询行、
全部 key、两个头使用独立公式核对；概率误差 >5e-5 为定位告警，结合实际
影响判断，不自动否决小幅数值差异。公式核对由同一作者实现，不是外部复现。

只用连续两次确认空闲的 GPU，最多 5 个种子分片，CPU 每进程 4 线程；
TF32 关闭、确定性算法、16GiB allocated 和每种子 3 GPU 小时上限。
无活动任务时最多等 GPU 一小时；保存真实进程及退出记录，只管理自己的任务。
没有旧静态积分求积或 CPU 延迟前置门槛。

## 预先固定的解释和决定

固定三维主方案 `joint_conditional3d`。同三维输入的机制信号要求：相对
rope3d、warp3d、mlp3d、fourier3d、conditional3d、free_quadratic3d、
joint_free_quadratic3d、joint_fixed3d 和 NoPE，每项 PCK8 平均提高至少 1pp，
至少 4/5 配对种子及 4/5 旧场景正向，CE 不恶化超过 2%。报告全部连续差值。
对角/各向同性/静态组件报告效果与代价，不强迫每个组件差值都达到 1pp。

同时保留 R47 的跨表示参考 rope2d/warp2d，并报告含这两项的旧广义筛选是否
通过。它与同输入机制信号分开标记；没有通过的旧比较不能宣称通过。
更强的二维输入参考不作为禁止三维机制诊断或后续原生点云开发实验的前置门禁。
同域进步也不能被写成优于任务最佳表示、跨任务一般有效或整体目标完成。

预定二维次要比较 joint_conditional2d 对 rope2d、warp2d、conditional2d、
free_quadratic2d、joint_free_quadratic2d、joint_fixed2d、NoPE，使用相同信号
定义并保留全部组件。二维结果不能替代失败的固定三维主方案。

若联合式不能稳定超过强对照，停止推广这个固定设计，不扫温度/宽度追分。
若收益由固定距离项或自由二次项同样实现，不能归因于自适应 GS 形状。
若同输入结果支持互补性，再检验同一公式在原生点云中的效果、成本和鲁棒性；
跨表示负结果继续保留。只有匹配强对照、适用范围及跨任务证据充分后，才安排
未使用数据的独立确认。任何单项开发信号都不构成完整目标达成。
