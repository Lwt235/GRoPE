# 第三轮：把高斯参数化变成一个简洁的位置编码

本轮保留“把 3DGS 的参数化形式转成 PE”这一基本想法。当前获得明确正面证据的方案是：**高斯期望旋转之后，对每个 Token 的 Q/K 再归一化**。它保持 48 维，不增加可学习参数。收益已在开发后固定方案、未用于匹配器开发的相机图像上复现；适用范围是已有重建几何时的条件区域匹配。

网页端《分析技术路线》的最新实质讨论仍是对第二轮的分析：排除随机形状身份捷径、分清投影中心与形状贡献、重视 Expected RoPE 的评分和拒绝校准问题。本轮据此重新设计标签和对照，没有继续堆叠法向、尺度惩罚和门控。

最新回合已完整同步到 [web_latest_sync.md](docs/web_latest_sync.md)，服务返回无截断；最后核对时间为 2026-10-30 08:49（北京时间）。

## 方案只有一个位置变换

对于高斯参数

\[
G=(\mu,R,s),\qquad \Sigma=R\operatorname{diag}(s^2)R^\top,
\]

将其均值和协方差投影到查询相机，得到 \(m,C\)。固定频率 \(\omega_\ell\)，令 \(q_\ell\) 表示内容向量的一个二维通道对：

\[
\widetilde q_\ell
=\exp(-\tfrac12\omega_\ell^\top C\omega_\ell)
\operatorname{Rot}(\omega_\ell^\top m)q_\ell,
\qquad
\boxed{\operatorname{PE}_G(q)=\|q\|_2\frac{\widetilde q}{\|\widetilde q\|_2}}.
\]

K 使用相同变换，随后仍做普通 Q/K 点积。零内容输出零。

均值控制相位；方向和尺度通过协方差控制哪些频率应保留。归一化保留这种相对频率选择，同时消除整条向量变短对评分尺度的影响。归一化必须在期望旋转**之后**；仅在之前归一化不能消除随支撑变化的范数。

这不是正交或酉变换：它依赖内容，不能保持任意两个内容向量的内积。协方差趋零、公共分辨率模糊也为零时，退化为普通 RoPE。实现见 [gaussian_pe.py](models/gaussian_pe.py) 中的 `normalized_rotary`，数学与数值边界见 [方案说明](docs/normalized_gaussian_pe.md)。

本实验将区域内可见 GS 的中心散布和内部协方差合成为区域高斯，再做投影；它验证的是**高斯形式的区域支撑如何进入 PE**。不能把它等同于“每一个训练得到的 GS 的 R/S 都有独立贡献”。支撑范围也不是中心估计误差的不确定性。

## 最关键的验证：开发后固定方案，再评估未用相机

候选和设置在训练、评价新相机之前冻结于 [frozen_protocol.json](results/round3_normalized_confirmation/frozen_protocol.json)，SHA256 为 `f07f70c053ee654e46da634fbc4bfc4ba6fe0c09b40843ee808f06a614d754b9`。

- 5 个训练种子，只用 Teatime train 拟合，Teatime validation CE 选择检查点，包括未训练状态。
- 从全部历史导出相机 ID 的补集中，按文件名固定分组选择 305 张照片、203 对图像；没有根据标签质量或模型表现筛选图像对。
- 主检验为 figurines + temple：1,917 个有效查询区域，91 个查询相机。另两个场景剩余有效数据很少，保留逐场景结果，不放大其统计意义。
- 原始 RGB 为主输入，共享冻结 ResNet18 特征为预先指定的复现。查询拟合均值和协方差对所有模型相同；固定、同迹、同面积和打乱消融仅改变 Key 的协方差。
- 所有方法使用完全相同的有效区域和候选掩码。强投影中心 RBF 获得相同的拟合中心，带宽和温度沿用早期验证集设置。

## 防止把相关图像当成独立证据

独立算术审计没有导入模型代码，重新从源标签、掩码和概率文件计算指标，核对了 100 个检查点、832 份概率档案；最大指标差异为 4.44e-16。独立实现的相机簇重采样支持原始结论。

考虑相邻视频帧可能相关，额外按连续 5、10 个查询相机成组重采样。完整支撑相对固定、同迹和同面积的 CE 收益仍成立。最严格的 10 相机分组下，原始 RGB 相对强 RBF 的区间为 [-0.10821, 0.00121]，触及零；冻结特征下为 [-0.13659, -0.02862]。因此不能把原始 RGB 对强 RBF 的优势说成对所有相关性假设都稳健。

## 结论的范围与创新性

现有证据支持：**高斯区域支撑可以作为每 Token 的位置分布，借助归一化期望旋转，在不扩展 Head、不引入成对模块的情况下改善条件区域匹配。** 这是本轮推荐继续使用的精简方案。已有可靠重建几何，是目前证据的前提。

数学组成有明确先例：[mip-NeRF 的积分 PE](https://jonbarron.info/mipnerf/)、[WorldRoPE 的概率旋转积分](https://arxiv.org/html/2610.16337v1)、[QK Normalization](https://arxiv.org/abs/2010.04245)。不能把高斯特征函数或 Q/K 归一化本身当作新的理论贡献，也不能仅靠这里的初步验证宣称论文创新性已经充分。

真实目标来自独立观测的 SfM 公共轨迹计数，是稀疏显著点的区域转移代理，不是稠密面积、遮挡或无对应真值。当前几何导出器采用较高不透明度（opacity≥0.3）中心的 CPU 深度筛选和矩拟合，不是精确 alpha 合成。GS/SfM 重建可能使用测试照片。因而本轮不是从未见照片重建，也不是完整 HRoPE / WorldRoPE / NVS 网络复现。

参考实现以 float64 中间值保护稀疏内容和大协方差下的归一化；结构精简不等于已经优化了 GPU 推理速度。独立测试包括点极限、平移性质、非线性反例、数值反例和普通值/梯度参考比较。极病态超出浮点表示范围的 Jacobian 不承诺有限。

单线程 CPU、batch16、两边各48个Token的整个浅层匹配器参考前向：位置 RoPE 约1.81 ms、普通期望旋转2.41 ms、96维等距3.28 ms、当前稳定归一化实现5.58 ms。因此这里的“精简”指算子结构、参数和输出维度；**当前参考实现尚没有速度优势**。原始重复测量见 [cpu_reference_cost.json](results/round3_normalized_confirmation/cpu_reference_cost.json)。
