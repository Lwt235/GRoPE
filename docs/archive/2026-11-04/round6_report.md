# 第六轮：把高斯支撑转成五维位置编码

2026-10-30。**这轮得到一个通过预先冻结验收的精简方案。** 在五个未参与选择的新 SUN3D 扫描、480 个相机对、四种 token 尺度组合上，相对同位置、同输入条件、同校准预算的已知尺寸对照，区域分布 KL 降低 **6.08%**，五个扫描全部改善。两个跨尺度方向分别降低 **3.20% / 9.51%**。中心点 PCK@8 为 **95.076%**；相对专门按点精度校准的点对照下降 **0.089 个百分点**，通过预设的 0.5 个百分点非劣保护门槛。

当前应保留的方案是**支撑协方差驱动的五维非对称 Q/K 位置编码**。它给已有视觉特征增加五个几何通道，不增加学习网络；只有两个全局校准标量。证据限于提供相机条件下的真实多视图区域对应及点定位保护，尚不是通用 Transformer、任意 3DGS token 或新视角合成的验证。

## 1. 从最初的 idea 到当前结构

3DGS 的几何参数可以写成

\[
G=(\mu,\Sigma),\qquad \Sigma=R\operatorname{diag}(s^2)R^T.
\]

它既描述中心，也描述空间支撑的方向和尺度。当前方案用这两个量定义位置关系：在区域较宽的方向，允许匹配位置有更大的范围；在区域较窄的方向，保持更强的位置区分。

先把源 Gaussian 变换、投影到目标图像，得到中心 \(m\) 与二维协方差 \(C\)。目标 token 是规则图像网格，同一 target bank 内的原生协方差 \(D\) 相同。定义

\[
A=(C+D+h^2I)^{-1},\qquad
b(m,x)=-\tfrac12(m-x)^T A(m-x).
\]

这个位置分数与高斯密度重叠的 log 相差行常数；规则 target 网格下，面积项和行列式项也都是行常数，在 softmax 中消去。因此，本轮实际检验的是**支撑形状决定的 Mahalanobis 位置项**，不是面积权重的新贡献。

展开二次式，去掉 query 行常数后得到精确的五维表示：

\[
Q_g=[(Am)_x,(Am)_y,-A_{xx}/2,-A_{xy},-A_{yy}/2],
\quad K_g=[x,y,x^2,xy,y^2].
\]

二者内积就是所需的位置分数。实现把同一个 target-grid 中心从两侧坐标减去，以改善数值条件。与冻结的 128 维视觉特征 \(f\) 拼接：

\[
Q=[\sqrt{T}f_q,Q_g],\quad K=[\sqrt{T}f_k,K_g],
\qquad p=\operatorname{softmax}(QK^T).
\]

最终是 **133 维 Q/K，零新增学习网络参数，两个全局标量**。本轮选择 \(h=0.5\)（公共八像素单位，即四像素 blur）和 \(T=5\)。上述点积不再额外除以 \(\sqrt{133}\)；接入默认缩放的 attention API 时需要保持这个分数约定。相同权重可以直接聚合 V；本轮正式收益来自匹配分布评价，不能据此宣称下游网络训练已有收益。

源码：[gaussian_quadratic_pe.py](models/gaussian_quadratic_pe.py)。对一般不等 covariance 的 key bank，完整核见 [gaussian_measure_pe.py](models/gaussian_measure_pe.py)，五维精确分解不适用于该一般情形。

## 2. 为什么没有继续堆叠模块

第五轮的真实两层 attention 实验未支持 normalized Gaussian RoPE 的预设点匹配增益，其结论保持不变。本轮最初试过相同两层 body 加直接几何位置项：在旧验证场景的 300 步开发实验中，full KL 为 0.390、point 为 0.487。但更小的“冻结内容特征 + 几何分数”已表现出充分信号，所以不把两层 body、gate 或额外编码器纳入最终方案。300 步不是收敛比较，不能宣称小方案击败了充分训练的深层 matcher。

两个验证扫描上的最终公平校准结果为：full 0.358659、fixed 0.444060、isotropic 0.376992。四个方法各搜索相同的 35 组 h/T；正式方案没有通过反复查看新测试选择结构。新测试收益 6.08% 小于验证集的 19.23%，报告以新测试为准。

## 3. 确认实验和结果

协议：[ROUND6_PROTOCOL.md](ROUND6_PROTOCOL.md)。冻结文件：[lock.json](results/round6_confirmation/lock.json)，SHA256 `878ce25b0273333e9e58438261d1a58c7ba1fd28005aade37d9321986815cd92`。

新测试扫描为 Brown cogsci1、Brown cs3、MIT d507、home_at、home_bksh，每个 96 对。潜在与验证 Brown bm4 共享走廊的 Brown bm1，在读取任何候选测试分数前已排除；保留了原清单、固定 RGB 预览和替换理由。详见 [分割审查](results/round6_split_audit/README.md)。扫描可能包含多个房间，同机构也不等于独立建筑，统计单位称为五个命名扫描/place 组。

标签由真实传感器像素投影到目标硬网格后计数，**没有用 Gaussian 生成标签**。每对使用全部 192×144 源像素中心，最近邻读取原生 sensor depth；保留所有至少一个可见样本的 query。前向 Gaussian 只来自冻结 RGB 预测深度、相机和已知网格。四种尺度的可见质量严格守恒。测试中可观测可见源像素约占 **50.92%**；8 像素 query 有 129,013 个区域有效行和 106,669 个独立中心点有效行，完整 query 网格为 207,360 行。结果条件于这些真实可观测对应，不是对不可见点的检测性能。

主对照 fixed 保留每侧的真实已知 token 尺寸，却不使用投影形变。point 只用投影中心距离；isotropic 保留协方差 trace、去掉方向信息。全部使用相同视觉特征、均值、位置项作用位置与 35 点校准预算。point_pck 另外从相同预算中按中心点精度选择，防止把区域校准牺牲了点精度的 point 作为弱保护对照。

|---|---:|---:|---:|---:|
| 四种尺度等权 | 0.304822 | 0.324541 | **6.08%** | [−0.025666, −0.013993] |
| 8→8 | 0.466723 | 0.482461 | 3.26% | [−0.021589, −0.010324] |
| 8→16 | 0.239970 | 0.247905 | **3.20%** | [−0.010922, −0.005220] |
| 16→8 | 0.315858 | 0.349060 | **9.51%** | [−0.044908, −0.021494] |
| 16→16 | 0.196736 | 0.218738 | 10.06% | [−0.029868, −0.014149] |

先在每个扫描/尺度内按可见源像素数加权，再等权平均扫描和尺度。KL 是概率分配误差，**6.08% 不能说成匹配准确率提高 6.08%**。相应 CE 下降 1.42%，JS 下降 0.73%；query 行等权 KL 下降 7.13%。低覆盖率行仍保留，四个预设可见比例档均有改善，结论不依赖只挑接近完整可见的区域。

每个扫描的总体 KL 都改善：Brown cogsci1 约 9.30%、Brown cs3 9.18%、home_at 3.94%、home_bksh 5.13%、MIT d507 3.77%。删除任一场景后仍有改善；Brown、MIT、home 分组的描述性比较也同向。五组的 paired bootstrap 采用预定 20,000 次重采样，重复确定性运行没有被伪装成训练种子。

|---|---:|---:|---:|
| PCK@8 | **95.076%** | 95.083% | 95.165% |

| argmax EPE，像素 | 3.75433 | 3.75465 | 3.75410 |

PCK@8 相对 fixed 为 −0.008pp，95% CI [−0.064,+0.046]pp；相对 point_pck 为 **−0.089pp，CI [−0.176,−0.013]pp**。后者是小但可测的退步，不能声称点精度完全不变；它通过事先规定的 −0.5pp 下界保护。点 EPE 未证明有改善。

full 相对 isotropic 的总体 KL 另降 **1.49%**，五个扫描均改善，探索性差值 CI [−0.005347,−0.003854]。这支持方向/轴比信息有额外价值，但增益小于从固定尺寸转向投影支撑的总收益，且不是经多重比较校正的新主结论。

全部主收益、两个跨尺度收益、两个同尺度保护及两项点精度保护都通过。完整数据：[确认统计](results/round6_confirmation_analysis/README.md)、[逐扫描/尺度/覆盖率与区间](results/round6_confirmation_analysis/summary.json)。

## 4. 数值、成本与审计

- 67 项新增相关测试通过，覆盖像素计数、面积守恒、GT/forward 隔离、协方差单位、五维等价、V/几何梯度、校准冻结、身份完整性和统计规则。
- 两个验证扫描全部 128 个相机对、四种网格的独立数学审查，双精度五维实现相对完整高斯核最大概率差约 1.6×10⁻¹²；有效监督行的 argmax 一致。单精度误差另作报告，未把理论精确误称为浮点逐位一致。见 [数值审查](results/round6_quadratic_audit/README.md)。
- 确认前重放五个角色的验证结果；封存 source/protocol/selection/输入与标签哈希；测试核验 480 个相机对在四种网格下完整出现，各角色共用同一输入与监督。两次不同验证/root 路径的拼写被规范化比较，实际文件 SHA 必须一致。
- RTX A6000 上，batch=8、432×432 logits 的 100 次暖启动中位数：五维版本约 0.674ms，完整 pair Gaussian 核约 1.486ms，纯 128 维内容点积约 0.084ms。五维版本仍有 inverse、输入合同检查和拼接开销，不能由通道增加 3.9% 推断运行时间只增加 3.9%。该计时不含共享的深度/视觉 backbone、数据读取和预处理。[测量记录](results/round6_compute_audit/summary.json)。
- 全部正式角色测试及验证重放约 14.53 秒；这不包括约 54 秒的新 RGB 缓存推理、下载及 CPU 标签构建。没有训练大型网络，也没有把公共冻结预测器的成本归为零。

独立审计已通过：[概率与区间复算](results/round6_probability_audit/summary.json)。固定每扫描/每网格前两对，共200个概率归档（五个角色；40个扫描/网格/相机对输入条件，实际10个不同物理相机对）。保存概率的最大差约4.50×10⁻⁵；由概率独立重算的CE/KL/JS误差约2.05×10⁻⁷ nat以内；另用NumPy直接高斯能量与稳定log-sum-exp重构，KL误差约1.07×10⁻⁶ nat以内。该固定子集的正GT质量处没有零或subnormal概率，未发生无法从概率恢复CE的问题。全部逐对统计表的384项指标/区间算术独立复算误差为零，全部验收条件仍通过。概率重放范围是固定子集，不是全部480对预测的逐元素审计。

## 5. 目前能够支持的结论

这条路线满足了本轮“结构精炼、效果尚可、能跨新场景和已声明尺度复现”的目标：**让高斯支撑决定每个 query 的位置距离，再精确转成五个 Q/K 通道**，是比继续增加 RoPE 变体或辅助模块更值得保留的当前实现。

需要明确的边界：

1. 理论上的 Gaussian overlap 和五维二次 attention 编码已有先例，不能包装成新发现。[Cordonnier 等，ICLR 2020，Appendix E](https://arxiv.org/abs/1911.03584) 已给出五个一、二阶位置量；[Probability Product Kernels](https://www.jmlr.org/papers/v5/jebara04a.html) 已研究密度重叠核。这里确认的是由输入估计的区域支撑驱动该结构，在当前严格匹配对照中具有实际收益。
2. 五维形式依赖同一 target bank 的 covariance 相同，并使用 target-bank 的公共原点和尺寸；它是有条件的非对称 Q/K 编码，不是任意独立 Gaussian 的通用五维绝对编码。
3. 当前实际输入 Gaussian 由预测深度区域矩构造，继承了高斯参数化形式，但没有证明优化后的 3DGS 内部 R/S 有独立收益。第五轮 GS 分解的负结果仍保留；颜色/透明度也没有被宣称为已验证的位置变量。
4. 两种尺度及其组合都参与过验证校准，因此是跨尺度复现，不能称“未见尺度零样本泛化”。五个扫描的统计范围有限，bootstrap 区间不是跨任意数据域的保证。
5. 这轮收益主要是**区域概率分配**，不是点定位大幅提高；相机估计、遮挡检测、下游分类/重建/NVS、任意混合 key 尺寸及更大模型接入都仍需单独检验。

本轮没有因测试结果改换候选。进一步推进应保持这个单一位置机制，优先做未参与校准的新尺度与独立任务验证，而不是先增加新的网络模块。文献和候选淘汰逻辑见 [调研记录](docs/round6_literature_design.md)。
