# 两帧几何对齐中的预测版HRoPE：比较方向与适配边界

2026-11-09。根据用户所指分支的最新讨论，建议在下一批新场景开放前，补充预测版HRoPE的旧开发数据对照。完整五维继续为主候选；Distance、GeoTransformer PE与固定球形继续保留。本文件是适配方向，尚非已完成实现、训练或新的评价冻结。

## 为什么增加这个对照

旧五场景的共同刚体求解器已显示F的有限对齐收益，但现有对照主要约束距离、点配置和径向关系。预测版HRoPE提供另一种有明确结构的几何交互：从token特征学习旋转、平移、平面法向及逆距离，构造单应形式，再以相对变换作用于注意力。

新增问题是：显式高斯区域关系在当前观测区域匹配与对齐任务中，相比这种学习型结构化变换是否仍值得采用？竞争解释是HRoPE的学习型变换已能吸收共同区域特征中的有效信息，五维对既有控制的优势不足以说明其优于该类方法。对齐成功率与失败尾部能回答具体用途，胜负仍不能单独识别协方差与法向的因果贡献。

## 论文和现有代码的核对

[HRoPE原文§3.2–3.3](https://arxiv.org/html/2610.28284v1#S3.SS3)区分预测式和标定式。预测版由特征预测每patch的13个标量，组成R、t、n、κ，构造H=K(R+κtnᵀ)，相对因子为H_i H_j⁻¹。R和t也是预测的，不需要输入真实相机外参；其含义不要求是每个token真实的物理运动。已知内参K与二维位置约定仍须明确。不能因本任务未知位姿就排除预测版，也不能将其替换为丧失跨视图作用的退化版本。

当前F、Distance、GeoTransformer和球形的模型，在两层视图内self-attention使用PE，两层cross-attention仅使用内容。HRoPE的完整相对变换会改变Q、K、V及输出，并适合跨视图交互。应保留这一核心作用，同时报告接入位置和算子作用范围的差异；比较的是完整PE接法，不能把所有差异归因于一个几何描述量。

仓库`models/round70_nvs.py`已有13维预测和单应算子适配，但完整NVS前向还通过相机射线及世界坐标使用c2w。不能直接移植该前向到未知位姿任务。更早RGB特征任务的模型和训练结果也不能作为当前几何区域任务的现成对照成绩。

## 建议的最小实验

1. 保持现有区域、共同观测特征、骨干规模、训练/验证划分、预算和原种子11/22/33。HRoPE头从共同特征学习，不引入VGGT、DINO或独享RGB输入，不用真实外参、世界中心、对应标签作为前向输入。
2. 先解决相机输入约定：当前区域缓存是各视图中心化坐标，不保留完整K及原始像素位置。不能将中心化三维坐标直接冒充相机射线或图像坐标。若需恢复K、原始区域投影位置或相机原点，必须从各自观测恢复，记录新增信息并提供同信息对照；不得偷偷增加HRoPE的输入，也不为机械复用旧缓存删掉其关键几何分支。
3. 保留论文的预测参数化、闭式逆、相对Q/K及V/输出变换，先完成公式、无真实位姿输入、有效梯度及共同训练入口的适配检查。记录PE/总参数、显存和耗时，不以参数完全相等为由扭曲原方法。
4. 使用共同匹配损失和原验证规则选模，再在旧五场景统一评估区域对应与既有两帧求解器。对齐RMSE<0.2米仍为用途主指标，保留全部帧对、错误尾部及三种子差异；不为HRoPE扫描求解阈值。
5. 将开发结果与实现限制一同解释，再固定完整确认名单和比较规则。是否纳入HRoPE取决于是否忠实、信息条件明确且能正常学习，不以其是否输给F筛选。若它更强，收窄F的相对优势主张；若F仍有稳定优势，则增强当前任务中选择高斯关系的依据；若相近，则结合成本与适用范围报告。

当前没有RGB纹理patch，本比较属于几何区域任务适配，不能全面衡量原论文的视觉透视校正效果，也不等同于论文完整模型/基准复现。先做这一有界对照，不自动铺开RGB和更多下游任务。
