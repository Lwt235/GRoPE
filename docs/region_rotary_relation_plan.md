# 同一二维旋转骨干下，固定五维关系是否仍有额外用途

2026-11-10。在新训练与新评价前固定。上一轮固定H=K达到40.000%、完整HRoPE为38.889%，其差异尚不确定；F为35.694%。这些结果没有分离各关系编码在共同旋转骨干中的条件收益。下一项保持F的五个量、MLP和self层作用不变，给F、Distance、Geo PE、固定球形统一提供现有固定H=K的二维旋转接法。它是固定方法的适用范围检验，不将F与预测HRoPE叠加为新方法，不新增预测头、门控或损失。

**假设：** 相同图像位置与跨帧旋转已提供强线索时，高斯区域关系仍带来额外对齐收益。**竞争解释：** 原关系收益与二维位置线索重叠，或加入任何帧内关系都只改变训练偏好；当前强基线之上的稳定用途消失。R50/R53的学习局部框架及R56的条件高斯联合式负结果保留，本轮不重新训练这些结构。

四个新增角色为`relative5`、`distance_mlp`、`geotransformer_rpe`、`fixed_isotropic5`，每个三个原种子11/22/33，共12次。模型从原同相机角色构造，公共参数与各自关系模块初值逐元素相同。固定H不含学习参数，沿用原24维几何块、24维二维旋转、频率、xy×8，以及两层self、两层cross的Q/K/V/输出变换。旧数据同帧对K相等，固定几何块代数抵消；保留原实现以使与已完成固定H对照一致。

self层的分数是`(Tq(q)·Tk(k) + q·r_ij)/sqrt(48)`，其中第二项使用旋转前的q，恰好保留各方法原关系项；cross层只有原固定H旋转注意力，绝不构造未经对齐的跨帧三维距离。V与输出沿用同一固定旋转传输。各方法原有参数量不变；二维旋转是共同比较条件，不能将其总体收益都归给高斯。原完整HRoPE和固定H的六模型及两诊断结果直接复用。

仅用最初576 fit / 64 val / 480旧开发帧对，旧数据已反复使用，不称确认。保持原60周期/1,080更新、batch32、验证batch16、AdamW、学习率、每3周期验证并按CE选模。逐种子匹配公共初始化与全部60条增强流；12模型全部选定后再导出。刚完成的十地点及其他确认缓存不访问。

主比较为同骨干F−Distance及F−固定H。完整报告F−Geo、F−完整HRoPE、F−固定球形。每项10,000次配对种子×整场景bootstrap，随机种子98001–98005。两项主比较平均至少+1 pp、三个种子均正且联合区间下界>0，支持在该共同骨干中的额外开发用途；反向采用对称条件，其他情况明确不确定，不能宣称等效。若同时未保住相对Geo/HRoPE的优势，不能声称胜过全部强对照；形状归因依据F−球形的实际幅度与区间，不为组件额外设置1 pp门槛。

主指标、求解器及范围完全不变：全部64个top1对应，41,664三点假设，0.1一致性半径，最多五次非恶化重估；所有源中心对齐RMSE<0.2米，先场景等权再种子等权。完整报告区域R@1、全查询正确、中心PCK、soft EPE、旋转/平移/RMSE中位与p90，保留绝对失败率。已有15个无旋转关系模型的结果只作历史背景，不重训、不覆写或计作新增独立样本。

正结果只支持准备该条件的后续鲁棒性与未用数据检验，不直接完成总体目标；不确定或负结果结束这个固定接法，不补种子、扫描频率/权重、据单个消融换主候选或堆叠模块。原五维与所有历史证据继续保留。

必要实现检查：去掉关系项时与已有固定H的前向和梯度一致；关闭固定旋转时恢复原各关系模型；以独立NumPy块矩阵公式检查含非零关系的注意力。只在旧fit做GPU前向/反向预检；新增预测和几何评分复用既有独立复算，实际查看学习曲线与结果图。科学源码、配置和数据身份固定，普通工程修复保存版本。
