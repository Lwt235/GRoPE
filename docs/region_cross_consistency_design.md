# 一个跨注意力公式中的高斯关系一致性

2026-11-10。依据[真值参考前提检验](../results/region_relation_consistency/diagnostic1/report.md)提出的下一项原型；当前没有端到端用途结果，完整五维原方案仍保留。

对一个原固定旋转cross层，先计算原内容分数S和P=softmax(S)。P完全来自该层Q/K，不读取overlap、有效性掩码、真实位姿或外部模型预测。分别在两帧自身坐标计算原五维phi，用P构造前项相同的关系平方差期望E，评价查询i时排除P的i行。然后只把分数改成 `S' = S - sum_c beta[c]*E[c]`，其余softmax、V/输出传输和残差不变。梯度穿过P，无额外迭代、预测头或拒识模块。

完整五维仅5个可学习系数，两个cross层和全部head共享；距离1个、固定球形5个。尺度使用已固定的旧fit非对角关系标准差，不继承真值参考校准得到的权重。所有beta从0开始，使公共初始化与固定H骨干完全一致；beta允许正负，直接学习关系项，不把未知/错误P先验强制当作可靠对应。若学习成负值必须报告，不能将其解释为非负一致性代价。self层使用原固定H骨干，不叠加此前9,792参数的self关系MLP，因此这是另一种精炼PE接法，不是把多个关系模块堆叠。

假设：当前注意力能给出足够有用的软参考，使区域位移/形状关系通过一个跨帧位置项改善对应和最终对齐。竞争解释：错误/无对应参考会放大混淆，或简单中心距离/二维旋转已经足够；真值参考下的1.117 pp不保证真实P有效。

计划配对训练三角色×原种子11/22/33，共9次，保持原576 fit/64 val/480旧eval、60周期/1,080更新、batch32、原损失及验证CE选模；公共参数和全部增强流配对。继续复用同条件的固定旋转、完整HRoPE、原五维/Distance/Geo/固定球形的既有模型作为强对照。模型全部选定后评价全部64查询、同一刚体求解器与RMSE<0.2米，主比较为新五维−同接法距离及−固定H；对球形、HRoPE、原五维和Geo的差完整报告。正式执行前另行固定完整实验源码、配置、比较和分析身份，本设计说明尚不表示已启动训练。

原型检查只针对变化：零系数恢复固定H前向与公共梯度；显式参考求和与梯度验证；关系项独立双帧刚体不变性和排列等变。不宣称整个网络刚体不变，原共同内容仍有中心/形状/图像位置。矩阵展开的复杂度O(C*N^3)、存储O(C*N^2)，这里N=64；尚未证明对512基元的实际代价或原生用途。旧R50/R53的局部框架没有被恢复。
