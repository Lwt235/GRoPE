## 一、先说最重要的结论

**第二轮结果已经足以让我们重新调整毕业设计的技术路线。**

我认为目前得到了四个重要判断：

1. 第一轮接近 99% 的匹配准确率，主要不能再作为 Gaussian PE 有效的证据，因为无几何意义的共享随机身份描述子也能达到类似成绩。
2. **表面法向存在一定的独立价值**，但其收益远小于第一轮表现，而且当法向预测错误时可能严重损害匹配。
3. **完整高斯协方差和额外各向异性尺度暂未表现出稳定收益**，现在不适合作为主要研究方向。
4. 投影区域重叠值得继续研究，但必须证明它的收益确实来自高斯的形状，而不是简单的跨视角重投影位置约束。

另外，这次发现了一个非常重要的新问题：**Expected RoPE 的不确定性衰减可能影响无对应 Token 的拒绝判断，即使正确候选的排序并没有明显恶化。**

这意味着接下来不能只研究几何位置编码，还需要考虑它如何影响 Attention 分数及匹配置信度。

## 二、第一轮 99% 的结果被成功证伪了原来的解释

第二轮增加了我们之前讨论的 Paired Random Identity Control。

| 方法 | 独立随机形状 | 区域共享几何 | 全部共享几何 |
|--------|--------|--------|--------|
| 位置 RoPE | 92.87% | 92.87% | 92.87% |
| \+ 法向 | 97.06% | 93.28% | 92.84% |
| \+ log 协方差 | 98.92% | 92.76% | 92.14% |
| \+ 共享随机身份 | **98.95%** | **98.95%** | **98.95%** |
| \+ 独立随机描述子 | 91.04% | 91.04% | 91.04% |

第一轮我们看到完整协方差提升到接近 99%，曾经认为它证明了高斯形状在跨视角匹配中的优势。

但现在，共享随机身份描述子同样获得 98.95%。

这说明在原来的任务中，模型需要的可能仅仅是一个能在两个视角间保持一致的额外特征。

当多个 Token 共享同一块区域的法向和尺度后，形状编码的优势基本消失，这进一步支持了上述解释。

**所以我们应该正式放弃“第一轮高斯形状大幅提高匹配准确率，因此完整 3DGS 参数适合做 PE”这一推论。**

这不代表形状信息没有用，而是说明原来的合成任务无法有效识别它是否具有独立的几何价值。

我认为这是第二轮实验最重要的一项成果。

## 三、真正有价值的结果来自带几何约束的渲染实验

这次使用了两个独立相机、带纹理的平面与立方体、真实的射线相交计算，以及基于可见性的匹配标签。

这里的“真实”指几何投影和可见性是根据三维场景计算得到的，并不是已经使用真实世界 RGB-D 数据集。

| \+ 投影高斯重叠 | **97.95%** | 97.28% | 90.77% |

这里我最关心的不是哪一列最高，而是三种趋势。

**第一，法向仍然有价值，但增益只有约 1 个百分点。** 逐场景配对增益为 1.07 个百分点，95% bootstrap 区间为 \[0.16, 1.96\]。这提供了初步正面证据，但它距离成为一个有说服力的新方法还有很长距离。

**第二，额外各向异性不仅没有明显提升，反而增加了错误几何带来的风险。** 相对于法向方法，增加各向异性比的逐场景平均增益为 −0.35 个百分点，区间为 \[−0.55, −0.16\]。

**第三，完整协方差的失败非常严重。** 法向被扰动后下降至 5.38%，说明这种强制相似性约束在错误几何下可能变成一种强烈的错误匹配先验。

因此，我会明确调整之前的建议：**暂时停止增加高斯自由度，不应再优先研究完整 \((R,S)\) 参数化如何直接进入 Attention。**

### 3.2 但投影重叠确实值得保留

仔细看下列结果：

| 方法 | 真值几何 | 混合误差 |
|--------|--------|--------|
| 3D RoPE | 95.28% | 92.42% |
| \+ 固定大小投影核 | 96.76% | **93.11%** |
| \+ 投影高斯重叠 | **97.95%** | 90.77% |

这里的对照很关键。

固定投影核已经利用了跨视角重投影位置，所以 3D RoPE 到投影高斯重叠的 2.67 个百分点提升，不能全部算作高斯形状的贡献。

真正与形状信息更相关的是：

\[
97.95-96.76=1.19\text{ 个百分点}
\]

仓库中逐场景配对计算得到约 1.22 个百分点，95% 区间为 \[0.76, 1.77\]。

这给我们提供了一个具体的研究信号：

**在几何准确时，高斯投影后的形状可能提供超出固定位置核的额外信息；但在混合误差下，这种额外信息反而有害。**

所以这一方向仍值得继续，但研究重点应该从“高斯形状越丰富越好”，改成：

> 高斯的二维投影范围什么时候有用？什么时候应该退化为只使用中心位置的投影约束？

这可能比之前单纯的 Gaussian Shape PE 更值得深入。

## 四、一个意外但重要的发现：WorldRoPE 的投影思路仍然很有竞争力

这部分我觉得应该特别关注，因为它可能影响毕业设计的选题方向。

在使用同一个小型 RGB 几何预测器时，结果如下：

| 方法 | RGB 预测几何 R\@1 | 无对应 AP |
|--------|--------|--------|
| 3D RoPE | 87.00% | 30.90% |
| \+ 法向 | 88.24% | 29.51% |
| \+ 完整协方差 | 87.89% | 25.83% |
| \+ 投影高斯重叠 | 81.83% | 34.80% |
| WorldRoPE 混合 Q/K 算子 | **90.41%** | **37.46%** |

以上采用 Oracle Train 的匹配器，评估时统一换成 RGB 预测几何；不是 WorldRoPE 完整模型的实验成绩。

这个结果比真值几何条件下的排名更值得注意。

因为它意味着：

**在当前简化任务中，直接使用三维中心进行 RoPE，并没有表现出比 WorldRoPE 风格的二维概率投影更强的几何误差鲁棒性。**

这与我们此前的理论讨论可以联系起来。

对于 3D RoPE：

\[
L_{ij}^{3D}
=f(q_i,k_j,\hat\mu_i,\hat\mu_j)
\]

Query 和 Key 两边的三维位置都可能预测不准确。

而 WorldRoPE 风格的编码可以利用 Query 已知的二维像素位置：

\[
L_{ij}^{2D}
=f(q_i,k_j,u_i,\pi_i(\hat\mu_j),\hat\Sigma_j)
\]

它不必依赖 Query 的预测深度来确定该 Query 的像素位置。

因此，至少在这个任务中，二维投影可能起到一种更稳定的几何约束作用。

这不意味着 WorldRoPE 一定优于三维编码，因为当前 Q/K 算子、频率设计、预测器适配程度等都不是完全等价的。尤其尚未复现 WorldRoPE 的学习式深度混合、层间更新和完整新视角合成网络。

但我会据此修改之前的排序：

**优先保留 WorldRoPE 风格的投影位置编码，再研究 3DGS 的形状信息能否提供互补收益，而不是一开始就抛弃二维投影。**

## 五、不确定性分支的问题，比我们之前预想的更复杂

这轮最大的意外之一，是“法向 + 独立不确定性”在 RGB 预测几何下只有 61.67% 的可见匹配 R\@1。

然而经过进一步审计：

法向 + 不确定性：RGB 预测几何

# 88.29%

候选排序 R\@1

# 61.67%

含拒绝的 R\@1

# 31.67%

可匹配查询被拒比例

也就是说，它并不是完全无法识别正确对应，而是有相当一部分正确对应被模型拒绝了。

### 为什么会这样？

对于 Expected RoPE：

\[
\mathbb E[R(X)]
=
e^{-\frac12\omega^\top\Sigma_{\rm unc}\omega}
R(\omega^\top\mu)
\]

不确定性越大，旋转分量受到的衰减越明显。

模型的匹配分数可以简化理解为：

\[
L_{ij}=s(q_i,k_j;\Sigma_{\rm unc})
\]

但无对应类别（Dustbin）的分数是另一条分支：

\[
L_{i,\varnothing}=b(q_i)
\]

在 GRoPE 当前实现中，Dustbin 分支没有使用对应的不确定性信息。

因此，当 Expected RoPE 使候选匹配分数整体变低时，Dustbin 分数可能相对过高。

即使正确候选仍然排第一，也可能出现：

\[
L_{i,\varnothing}>\max_j L_{ij}
\]

模型最终选择“无对应”。

### 后续校准证明了什么？

在独立的新场景上，仅调整 Dustbin Logit 偏移：

| 指标 | 校准前 | 校准后 |
|--------|--------|--------|
| 可见匹配 R\@1 | 61.47% | 79.83% |
| 错误接受率 | 68.29% | 87.55% |
| 无对应 AP | 17.50% | 17.50% |

这证明了一部分下降确实来自分数校准，但也说明简单调低拒绝门槛只是把部分拒绝错误变成了错误接受。

**新的研究问题是：概率位置编码在表达位置不确定性的同时，应该如何影响匹配置信度和无对应判断？**

这可能成为一个值得研究的独立问题，不过目前我不建议将它立即提升为毕设的主创新。

## 六、可靠性门控：方向合理，但当前实现并没有成功

这点需要明确区分。

我们此前提出：

\[
L_{ij}
=
L_{ij}^{\rm position}
-
g_{ij}\lambda_n d_n(i,j)
\]

其中 \(g_{ij}\) 希望衡量几何信息是否可靠。

第二轮已经进行了可学习门控实验。

在 Robust Train 条件下：

| 方法 | 真值几何 | 法向误差 | RGB 预测几何 |
|--------|--------|--------|--------|
| 3D RoPE | 95.85% | **95.85%** | 87.84% |
| \+ 法向 | **97.30%** | 84.14% | **88.27%** |
| \+ 法向门控 | 97.04% | 87.51% | 88.24% |

门控确实让法向误差条件下的性能从 84.14% 提升到 87.51%。

但是与完全不使用法向的 3D RoPE 相比，仍然落后 8 个多百分点。

而在 RGB 预测几何条件下，门控甚至没有超过直接使用法向。

因此，我们还不能证明网络成功估计了几何可靠性。

我检查了 `rendered_attention.py`，当前门控主要利用几何一致性特征，通过一个小型 MLP 输出系数。

这里存在一个根本问题：

**两个表面方向一致，并不意味着预测的方向就是正确的。**

例如，一整块错误估计的平面可以在内部保持很高的一致性，却偏离真实表面。

下一步若继续研究门控，我认为应该考虑跨视角重投影残差、循环一致性以及预测不确定性的实际校准质量，而不是单纯依靠局部几何一致性。

## 七、代码审查后，我认为仍需要注意的三个实验局限

这次不仅阅读了报告，还检查了 `rendered_data.py`、`rendered_attention.py`、`rgb_geometry_probe.py` 等核心实现。

| 问题 | 当前实现 | 对结论的影响 |
|--------|--------|--------|
| Patch 对应定义 | 使用查询中心点投影到目标 Patch | 主要验证点到区域匹配，而不是真正的区域到区域对应 |
| 高斯支撑来源 | 通过相机投影雅可比与局部平面构造 | 尚未验证真实 3DGS 优化得到的高斯 |
| 几何预测 | 小型合成域 RGB MLP，冻结后替换真值 | 尚未验证高质量几何预测器和端到端联合训练 |

尤其是第一个问题。

你的新研究方向如果是 **Gaussian Support / Overlap PE**，那么目前的标签仍然以 Patch 中心点为主。

它不能充分检验两个局部区域实际覆盖面积不同、部分重叠或遮挡时，Gaussian Shape 应该如何参与对应关系建模。

此外，仓库的 16 项单元测试通过，并保存了源码快照和检查点重放审计，这是很好的实验工程基础。但这些检查证明的是实现一致性与部分数学性质，不等于证明了新方法的有效性。

## 八、现在我会怎样重新确定技术路线？

我建议把下一轮研究集中在一个主问题上：

> **在 WorldRoPE 风格的概率投影位置编码基础上，能否引入独立的局部三维表面信息，同时避免其对错误几何预测的过度敏感？**

比起继续直接预测完整的 3DGS \(R,S,\mu\)，我更推荐以下顺序。

**第一优先：建立可靠的投影位置编码基线**

先把 WorldRoPE 风格的 Query/Key 编码与当前 3D RoPE 在同一预测几何条件下做公平对照。

重点测试深度预测误差与相机基线变化，弄清二维重投影为何可能更稳定。

---

**第二优先：验证 Gaussian 支撑的独立贡献**

在相同投影位置编码上，加入局部法向、投影高斯形状或区域覆盖关系。

必须与固定大小投影核对照，确认收益来自真实的形状信息，而不是投影位置本身。

---

**第三优先：在必要时设计可靠性控制**

只有形状信息在准确几何条件下具有稳定的独立收益，才值得投入精力研究可靠性门控及其与概率位置编码的联合校准。

这一顺序的好处是，每一步都能独立回答一个问题，而不是把位置预测、表面形状、概率不确定性和门控一次性加入网络，最终无法解释性能变化。

### 下一轮最有判别力的实验

我会优先让 Codex 做一个非常小但重要的四组对照：

| 组别 | Position Encoding | 局部形状信息 |
|--------|--------|--------|
| E0 | 3D RoPE | 无 |
| E1 | 2D 投影位置编码 | 无 |
| E2 | 2D 投影位置编码 | 固定大小支撑 |
| E3 | 2D 投影位置编码 | 预测的各向异性高斯支撑 |

所有组使用同一个几何预测器、同一个 RGB 编码器和相同的训练协议。

然后分别测试 Oracle、RGB 预测几何和不同程度的噪声。

这比继续做很多新增变体更重要。

如果 E3 在准确几何条件下始终优于 E2，但在预测几何时退化，那么研究重点应当转向可靠的 Gaussian Support 建模。

如果 E3 连准确几何条件下都没有稳定独立收益，那我们就应该考虑放弃“完整 3DGS 形状参数化”这条主线。

如果 E1 已经获得了大部分提升，则说明当前任务真正需要的可能只是更合理的跨视角投影位置编码。

## 九、最终判断

目前研究方向排序

**投影位置编码与深度不确定性** (优先研究)

预测几何条件下的结果提供了较强动机，尤其值得分析 WorldRoPE 风格的二维投影为何更稳定。

---

**局部法向与投影高斯支撑** (继续验证)

存在一定正面证据，但还没有证明相较于平面几何的明显独立优势。

---

**完整 3DGS 协方差与仿射 Frame** (暂缓)

目前的额外复杂度、表示歧义和几何误差敏感性尚未得到合理回报。

**我现在最想进一步验证的，是 WorldRoPE 的概率投影机制与 3DGS 的局部支撑参数能否形成真正的互补，而不是相互重复。**

但也需要提醒你：如果本科毕设最终必须强调“3DGS 的参数化形式转为 Position Encoding”，那么目前这些额外 Attention Bias 还只是探索性机制，并不完全等于导师要求的 PE。后面最好进一步探索能否将经过验证的局部几何信息设计为逐 Token 的 Q/K 编码算子。

另外，第二轮还没有证明任何新方法在真实世界数据或完整 HRoPE、WorldRoPE 架构中取得了优势。现在最合理的阶段判断是：**理论筛选已初步完成，下一步应该从合成匹配器走向更可靠的几何预测与真实多视角任务验证。**

相比第一轮，我现在对“直接使用完整 3DGS 参数一定比 HRoPE 更好”这个想法的信心明显下降；但对“利用三维高斯明确区分投影位置、局部支撑和位置不确定性，构造更合理的几何位置编码”仍然认为值得继续探索。
