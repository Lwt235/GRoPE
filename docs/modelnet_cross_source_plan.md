# 固定原生模型的跨来源确认

2026-11-06，在读取本批高斯或模型分数前确定。此前对称三维开发检验已经完成并审阅：它损失区域和原生 512 的核心用途，因此仍保留 relative5 为当前候选。本实验没有新增训练、模型选择或超参数搜索。

## 科学问题和竞争解释

问题是：高斯相对关系的收益，能否从当前训练中 MACGS 来源的同名类别，迁移到 ModelNet CAD 对象？假设 relative5 的五个相对量提供有用的区域关系组织，在这个来源变化下仍优于同信息的 Distance，并优于同参数固定球形控制。

竞争解释包括：此前收益依赖来源特有的基元形状/外观统计；现有完整内容与中心距离已经足够；完整五维只在当前来源和输入数量有效。若所有方法绝对准确率都很低，应报告整个固定模型的迁移失败，不能把微小相对差当作实用成功。该实验不隔离颜色、重建算法、类别语义及采样分布各自的影响，也不是零样本学习新类别。

## 对象、来源和输入

采用已生成的 `results/research_data_usage/native_candidates_20261106/modelnet620_candidate_metadata.json`，SHA256 `d783be4eb40ee2a187f5987de07a230cb986d50c30bc092cdd648098bbaf8125`。其 620 个对象均来自作者 ModelNet 原 test 清单，排除了已知历史 R48/R58 与 GSModel60 全 TRAIN/TEST 的源对象 ID。七类为 airplane/bottle/bowl/car/chair/guitar/table；bowl 20 个，其余各 100 个。沿用已固定的严格同名对应，目标输出 ID 分别为 20/1/15/13/12/11/4。

高斯来源为 `ShapeSplats/ModelNet_Splats`，发布版本 `6538575534e3a48a31d91beaef781e6c1db2b456`，七个 ZIP 的尺寸及 LFS SHA256 见候选元数据。原始归档约 15.06 GiB，下载到用户指定的数据盘，优先使用 hf-mirror.com 直连，不消耗本地代理流量。首先检查现有访问权限，不代用户提交访问申请或接受新条款。

对象集合与语义对应不得在看分数后改变。归档目录只按精确 model_id 匹配；若发布多个训练迭代，机械选数值最大的 iteration 对应 `point_cloud.ply`，不看预测效果。重复同一最高迭代、缺失对象或格式不兼容须记录并定位，不以别的对象替换。只解码这 620 个对象；下载包含其他对象的完整归档不等于将其纳入评价。

沿用现有 `round65_data.native_arrays`：全部中心的均值与 RMS 半径归一化，原始 log scale 指数和单位 quaternion 构造物理协方差，中心/协方差统一空间缩放，原 covariance floor=1e−8，原四维外观变换，缓存 2,048 基元。使用固定虚拟路径 `<taxonomy_id>/<model_id>.ply` 与原 sample_salt 决定采样，保证每种方法输入相同。使用完整 13 维共同内容，不采用作者预训练属性的中心化 scale 作为物理轴长，不根据本批统计调整 floor/尺度。

将解码源文件的精确 SHA256 与已用原生目录核对。若出现已知字节重复，保留在原 620 对象覆盖报告中，并从无已知重叠主组机械排除；不补入对象。若主组不再覆盖七类或出现缺失/损坏，报告未完整完成，不把部分人群称完整确认。不同 ID/字节也不能证明没有近重复几何。

## 固定模型和评价条件

原官方确认锁 `results/native_confirmation/attempt1/evaluation_lock.json` 中 31 个已经选定的模型全部复用：relative5 和 Distance 各八种子 11/22/33/44/55/66/77/88；其余 full11、Direct、中心 3D RoPE、NoPE、固定球形各三种子 11/22/33。另补入本次已选定的原生 512 symmetric3、可学习 Jeffreys 各三种子，合计 **37 个固定模型**。后两项是预定辅助对照，不因本批分数自动改为主候选。全部 checkpoint、原选模记录及源实现身份在访问新高斯前固定。

完整保留原 60 类输出；预测到另外 53 类仍算错误，不在七类中重新取 argmax，不重训或校准分类头。沿用 base512、sparse256、dense1024、jitter02、tilt、permuted 六条件，最多 222 组预测。原所有模型均按 512 基元训练与验证；本实验不混入 matched256 模型，以免混淆迁移与训练流程。

在旧验证对象上检查新增执行适配器与原选定输出的一致性，再使用实际空闲 GPU 并行推理。最多六个 GPU 任务、每卡一个、16 GiB PyTorch 分配上限；启动前核实占用和 CUDA，保留其他任务。复用原推理计算，不引入关系投影重排。常规实现修复保留版本和失败记录，不据此更换科学方案。

## 指标、统计与不同结果的决定

主比较：base 条件下，relative5−Distance，八个预先固定种子、无已知重叠对象，七类等权的 mCA。这里八种子是新实验事前确定的主比较；不改写旧官方确认以新五种子为主、结果不确定的结论。

主要归因比较：base 的 relative5−固定球形，同样对象，配对 11/22/33。其他对照、旧三/新五种子的 Distance 差、其余条件均为预定辅助分析。报告完整各方法的绝对 mCA、OA、60 类 CE、逐类别准确率、每种子配对差，以及预测到七类之外的比例。条件共用对象，permuted 只作实现检查，不计独立重复。

沿用 `native_confirmation_analysis.paired_accuracy_summary` 的配对种子、类内对象及种子×类内对象重采样，10,000 次，基础随机种子 80001，按固定比较/条件顺序递增。主区间条件于这七个类别；另外报告七类重采样敏感性区间，不声称推广到所有类别或所有来源。OA/CE 的均值与逐种子差同时报告，不以事后挑选指标救主结果。

- 主 mCA 均值至少 +0.5 pp 且种子×对象 95% 区间下界大于零，记为该限定来源迁移的正面信号；绝对表现、归因比较和其他条件仍须共同解释，不据此完成总体目标。
- 平均正但区间宽，记证据不足；平均不正，记本设置未保留平均收益，并报告不确定性。若变化协方差不优于固定球形，则不将全部用途差归因于变化形状。
- 若原有三维或单散度在此更好，保留为结构依赖来源的反例；后续设计只能作为开发线索，不能在本批改模型后再称 fresh confirmation。
- 缺失或不可访问的数据不等于模型失败，不用替代队列补齐漂亮结果。小数值尾差不自动构成科学失败，核查程度应与结论影响相称。
