# 固定区域PE几何对齐用途：未用场景确认

2026-11-09。旧五场景开发检验已完成并审阅：固定共同求解器下，F对Distance、GeoTransformer PE、固定球形的成功率分别高5.000/5.833/5.764 pp，三种子与联合区间均正。绝对成功率仍仅32.986%，尾部错误严重。本确认不改完整五维、权重、匹配或求解器，也不重启原生来源混合策略。

## 假设、对照和决定

假设：固定区域匹配器中五维关系带来的几何对齐收益，在未用于开发的新SUN3D地点仍超过两项强PE。竞争解释是旧五场景反复开发使收益偏乐观，或新场景的区域中心关系不足以提供一致的刚体约束。固定球形单独约束额外形状归因。

保持F、Distance、GeoTransformer位置算子、固定球形各原种子11/22/33，共12个原验证已选checkpoint；不重新训练、适配、改种子或选模。完整共同内容、原FP32网络与batch16、每帧512点构造64区域/32邻居、几何floor及尺度沿用原base条件。本次只确认base，不增加新的扰动或图像任务。

每源区域取logit最高目标，全部64对进入同一既有FP64刚体估计器，枚举41,664三点假设，0.1原归一化单位一致性半径，最多5次非恶化内点重估。无置信度阈值、真值过滤、ICP或精匹配模块。估计器只接收局部中心和预测索引；真值仅用于评分和明确不可部署的诊断。

主指标保持全部64源区域中心的对齐RMSE<0.2米，场景等权、再三种子等权。F−Distance和F−Geo分别要求平均至少+1 pp、三个配对种子均正且联合95%区间下界>0，才支持当前固定接法的有限确认；绝对成功率、尾部错误和诊断必须共同解释，不以相对差掩盖全流程失败。F−固定球形单独报告幅度、方向和区间，仅三个种子均正且联合下界>0时支持额外形状作用。无需每个场景或次指标都正，不增设微小数值误差门禁。

10,000次配对种子×整场景bootstrap，三项依次种子94001/94002/94003；另列种子、场景单独区间及逐场景效果。同一场景96帧对不作为96个独立场景。保留全帧对RMSE、旋转、中心化坐标系平移误差中位数与90%分位数；无解记失败。恒等变换和真值辅助中心最近邻仍是诊断，后者不可部署且非理论上界。

若强对照确认混合或失败，结束这项固定接法的推广确认，保留全部结果与已有区域排序证据，不补种子、换场景或调求解器补救。若用途成立而形状归因不确定，分别报告。即使全部正面，也只支持被测观测区域、基础构造与共同配准接法，不覆盖原生3DGS、RGB、拒识或所有稀疏条件，不宣布一般性目标完成。

## 新数据开放前固定队列

已有目录与最新实际使用记录核对后，206个官方地点名称排除46个，余160个候选。46个包括21个历史使用/预览、投影五地点、先后两批各九个已用区域地点，以及两个缺标定地点。排除整个顶层place，不把已用批次的新指标称为fresh。

按brown、harvard、home、hotel、mit各取两个，以SHA256(`GRoPE-region-pose-confirmation-20261109-v1:`+place)升序固定，共十地点；每个取字典序首个子扫描。只按目录身份选择，不查看新像素、几何、覆盖或模型结果。不同名称不保证物理地点无别名，发现已知重叠需披露。

沿用原机械取帧：RGB文件名排序，48个linspace查询索引30..N−91，各配+15/+60，最近时间戳深度，目录最后一版官方外参。每场景计划96对、共960对。元数据不可用时保留缺失，不换地点、扫描或帧；技术重试仅访问原来源。少于两个可用地点时不进行跨地点用途确认。不是每一批都能覆盖原计划的十地点，缺失及原因须完整报告。

元数据阶段只允许公开目录和相机文本；计划、地点、12个checkpoint与已用排除先固定。新深度读取前另固定评价源码、元数据、缓存和评分规则。只下载深度，不下载RGB像素；沿用用户指定数据盘`GRoPE/region_pose_confirmation_20261109/`。官方SUN3D直连、显式禁用代理，最多四请求并发。

复用已核对的模型、求解器和独立统计函数。只对新的执行适配做旧数据转换回放及必要输入检查，原验证回放与源身份保持一致；不重复无关历史门禁。推理和批量求解选实时空闲GPU，CPU4、TF32关闭、有限分配上限。正式得分完成后独立CPU复算、实际图表与科学审阅；普通执行失败保留版本后修复，不另起科学轮次。全部比较完成前不根据中途分数改变实验。
