**完成记录（2026-11-13）：** 4224新干预预测、2112继承评分、24基准回放（最大差0）、独立复算及两图实际审阅全部完成；0训练、4248前向、0.199164 worker小时。train32 C−R+0.009208有明确范围内代价，N/M保留大部分片段空间用途但不称等效，N完整输入AbsRel仍有代价；固定诊断结束交回Astra，无新方案或自动训练。[完整结果](../results/gaussian_memory/native_render_factorization1/report.md)、[实施交接](../results/gaussian_memory/native_render_factorization1/implementation_handoff.json)。下列公式、预算、对照及分支保持事前原样。

**问题与固定假设。** 旧32地点 Render 的片段内跨视角用途，在保持权重/内容/查询相同时，是否主要依赖局部内容排列、实际覆盖衰减，或两者的共同作用？竞争解释是场景整体条件已足够、去衰减只改变整体输入幅度，以及固定接收网络对分布扰动敏感。新 G 比旧 R 差不能预先归因其中任一项；本轮即使有清晰结果，也只限制旧 Render 路径，不唯一识别新 G 的失败机制。

**五个固定输入，四格加一个幅度控制。** 令 `f_j` 为原保存特征，`w_ij` 为原实际前后合成贡献乘 `has_content`；有效覆盖 `a_i=Σ_j w_ij`，原缓存输入 `r_i=Σ_j w_ij f_j`。令 `g` 为所有有效保存槽的特征算术均值，`n_i=r_i/a_i`（`a_i>0`），`a_i=0` 时 `n_i=g`。无有效槽时 g=0，保留该样本。这里 a 必须是有内容槽贡献之和，不能用包含无内容槽的总渲染 alpha。

| 代号 | 送进原融合层的 extra | 解释 |
| --- | --- | --- |
| R | 原缓存 r | 局部内容＋实际覆盖；历史基准，模型及输入不变 |
| N | n | 保留有覆盖位置的局部归一内容，去掉衰减；无覆盖回到场景均值 |
| C | a×g | 去掉逐位置局部内容，保留原覆盖；同旧 Global 的输入定义，但用固定 Render 权重 |
| U | g，广播到各 patch | 同时去掉局部排列和覆盖衰减 |
| M | s×n，`s=||r||F/||n||F` | 每查询一个标量匹配 R 的完整特征图范数，区分整体放大与空间覆盖变化 |

范数使用全部1024 patch×1024通道，既不使用GT/ROI，也不按输出成绩挑 s；若 `||n||F=0`，令 s=0。M 保留无覆盖填 g 的同一规则。r/a 在非零处用安全的双精度除法后返回 FP32，不加覆盖阈值、平滑、epsilon超参或重新计算绑定；R 直接使用原缓存，不通过乘除重建。所有输入都只依赖已存场景及给定查询相机，full/missing 共用同一 extra。M 仅匹配一个整体范数，不能排除局部分布与接收适应差异。

“去覆盖”包括取消连续衰减及无覆盖位置读入全局内容这两个既定行为，不单独识别其中哪一项；本轮不再拆子实验。C 将局部内容替换为场景均值，也改变内容分布，D_address 是该条件替换的名称，不是严格只改变地址的因果量。

只加载 native_training_coverage1 的三份 Render 最终 step_2000 权重（种子20261110/11/12），包括各自原生参数和融合层，均 eval/no_grad、沿用 BF16 计算/FP32状态。各干预用同一权重、同一输入 patch、同一有效GT/评分尺度和同一查询；不加载新 G 来交换读值，不训练新的 Global 或门控。旧 Local 仅使用有明确来源的原预测作为用途参考，不能把 R 权重下的 C/U 叫匹配训练的新方法。

**指标与决定量。** 主终点是32训练片段其他查询、missing ROI 的 centered log-MSE。设同一集合地点/查询/种子等权的误差为 E，预定报告：`D_address=E_C−E_R`、`D_coverage=E_N−E_R`、`I=E_U−E_C−E_N+E_R`；同时报告 `E_U−E_N`、`E_U−E_C` 和幅度控制 `D_matched=E_M−E_R`。正的简单差表示移除该因素有代价；交互为条件差的变化，不能与主效应机械加总成唯一因果贡献。

沿用5000次配对地点/种子重采样、固定 bootstrap seed 20261113，逐种子/逐地点和原12/新增20训练片段分组均列出。区间是描述性配对估计，不把多个相关对照称独立检验或确认。可以将主简单差除以原 R 相对 Local 的平均收益作量级参照，标明“干预抹去的基准差距比例”；不截断负数或>100%值，不把它称独立机制贡献。开发集合分母很小且不确定，不给该比率作主要判断。

必须同步报告12开发地点相同差值、每臂绝对误差、相对 R 和 Local 的方向，以及原始ROI log-MSE、偏差平方、完整全图AbsRel。原支持分层可直接复用作辅助，不按GT支持筛样本或选阈值。按查询记录 alpha=0比例、固定alpha分位数、s、输入范数比及相对r的差，帮助判断扰动是否主要改变幅度；这些是解释量，不能替代深度结果。没有按效果选择新分层。

**决定分支（本轮不触发新训练）。**

- D_address 有清晰且相对原用途较大的代价，M 保留原用途：后续 PE 候选应保留显式局部对齐，不以覆盖门控为优先修补；不能由 D_coverage 区间跨零宣布覆盖无效。
- D_coverage 的代价经 M 仍保留：今后若比较新读法，覆盖幅度必须被控制；若 D_address 也大或交互明显，保留原完整渲染通路，不再一次同时替换地址与衰减。
- N 受损而 M 恢复：先限制为整体幅度敏感，不能叫覆盖置信度必要，更不能自动新增学习门控。
- C/U 仍保留多数片段内用途、局部干预没有明确损失：削弱用旧 Render 作为高斯局部 PE 的设计理由；未来必须检验超出场景整体条件的增量。
- 地点/种子方向不清、开发与训练范围不同，或分布扰动解释无法区分：如实收窄/未决，结束本诊断。不得增加比例、归一化规则、控制、查询或种子追求清晰结果。

效果大小、配对区间及重复方向一起判断；未拒绝零不等于等效，任何模型对人工破坏敏感都不等于相对匹配训练强对照有净用途。完成后由同一 Astra 任务直接选择方法或收束分支，不延伸成长机制分解链；下一方法仍须明确 O6 的同内容强中心比较。这不是所有未来PE的普遍前置门槛。
