## 当前判断

**当前固定内容＋单次输入融合没有可靠整体净收益；场景内容的空间组织仍有局部作用。下一项建议检验原生接收网络共同适配是否能将这种局部作用转成净用途。** 不能把本轮理解成“3DGS无用”，也不能用支持区域的正结果宣布方法成功。

| 已完成的固定比较 | 主空间误差相对降低 | 可以支持的判断 |
| --- | ---: | --- |
| Render 对 Local | −3.20%，95%区间[−31.37,+17.04]%；三种子均负，7/12地点正 | 当前候选未超过强当前图像控制；地点异质性大，尚非总体必然有害 |
| Render 对 Global | +6.00%，区间[−6.01,+18.57]%；三种子均正 | 保留空间排列的平均线索，整体优势仍不确定 |
| 支持ROI内 Render 对 Global | +13.60%，区间[+1.81,+25.75]% | 在这些预定评价区域，局部排列比场景平均内容更有用 |

Render 对 Local 的缺失ROI原始误差高18.99%，完整全图AbsRel高17.15%，相应区间支持增加。这些是有实际大小的代价，不是数值舍入或主区间最后一位的问题。Local/Global/Render主空间误差为0.025019602/0.027469592/0.025821325。[最终报告](../results/gaussian_memory/rendered_feature_native1/report.md) · [全部固定统计](../results/gaussian_memory/rendered_feature_native1/scoring/summary.json)。

## 已有预测进一步告诉了我们什么

新增的仅是事后描述性分解，使用全部12地点、四查询、三个种子，不删反例、不选阈值、不生成新置信区间。[可追溯数值与日志身份](../results/gaussian_memory/rendered_feature_native1/post_completion_analysis_20261112.json)。

**原始误差退步主要伴随整体偏差增加。** 每个查询内的log-depth MSE可以分为误差均值平方和去均值空间误差。Render−Local的原始差为+0.01675804，其中均值偏差平方差+0.01595632，占95.22%；空间差+0.00080172。它是误差账目的精确分解，不能唯一解释为物理尺度估计错误，也没有据此增加查询真值校准。

**空间退步也不是所有区域都变差。** 令w为每个查询ROI中原有支持标签的像素占比，则总空间误差等于：支持区内方差×w＋无支持区内方差×(1−w)＋w(1−w)×两区域误差均值差的平方。按同一查询/地点/种子权重汇总，Render−Local为：

| 空间误差组成 | Render−Local；负值有利Render |
| --- | ---: |
| 支持区域内，按像素占比加权 | −0.00211661 |
| 无支持区域内，按像素占比加权 | +0.00315551 |
| 两区域误差均值差项 | −0.00023718 |
| 总和 | +0.00080172 |

这说明在当前样本中，支持区域的改善被无支持区域内更大的退步抵消；两区域之间的相对偏差项反而略改善。该恒等分解最大账目差约1.2e−15，空子区域按零权重处理，全部查询保留。这与分别汇总的支持/无支持ROI百分比是不同统计，不能直接相加那些百分比。

平均约77.56%的有效ROI像素有来源支持，但这里的支持由**来源与查询传感器深度、给定相机的重投影一致性**定义，仅供评价。它不证明实际高斯场景在这些位置准确，也不是renderer的alpha覆盖率。不能把GT支持标签变成推理门控或据此宣称已有可部署适用范围。

地点差异也有实际大小：brown_bm_4、mit_46_6conf的主空间误差分别下降约21.20%、34.85%；brown_bm_1、brown_cogsci_1分别增加约54.65%、49.84%。所有地点均保留，不能靠移除反例建立总体优势。

## 可能原因及证据强弱

1. **保存内容和实际表面的对应仍不可靠。** 多来源patch按alpha权重平均写入，再渲染给查询；原通道数保留不代表局部信息未混合。支持区域正线索、无支持区域负贡献与此相容；前轮sensor来源也不是准确oracle。现有结果不能把错误唯一归给writer或几何。
2. **接收网络适应性可能限制用途。** 本轮只训练787,712参数的输入MLP；原生frame/global交互层与DPT保持冻结。它们接收的token已被来源内容改变，却没有通过任务学习调整自身行为。这是代码事实及待检验解释，尚未证明解冻必然有效。
3. **训练地点较少，可能学到了不稳定的场景关联。** 三种子Render末500步组合训练损失约0.00411–0.00413，Local约0.00530–0.00541；Render训练目标更低、开发主指标更差。两者统计口径不同，而且日志是抽样训练损失，不能直接确诊过拟合或认定优化已充分收敛。增加训练自由度也可能加重此问题。
4. **强Local比较仍有输入结构边界。** Local附加输入为当前patch均值，Render为来源渲染内容；两组都保留当前patch，但不是“完整Local再追加来源”的严格嵌套结构。因此阴性足以否定当前候选的采用，不足以证明来源的条件信息为零。本次不把这一边界当成必须立即补一组的门禁。
5. **本轮没有直接验证新增PE。** 高斯几何通过渲染权重影响特征，三维参数未作为独立PE送入原生attention；原生2D RoPE保持。投影特征也不唯一决定米制三维状态。该表示边界不等于当前失败原因已被定位。[代码与理论解释](../results/gaussian_memory/rendered_feature_native1/interpretation_notes.md)。

早期joint_write1及后续write_confirmation1已证明独立粗读出有条件的内容/空间用途，也保留了精细空间代价；surface1和geometry_transport1则包含联合writer、深度V及直接深度传递的负结果。不能将“加入writer”“加入深度”重新包装为首次解决方案。

对原生接收网络的适配也并非从未尝试：native_gaussian_pe1已有末四个global块的rank8 QKV/输出LoRA，共同收益主要来自偏差减少，没有实用PE增量。新的建议必须改变这个有限接收范围，不能重复相同小适配器并仅更换名称。

相关原文提供训练设计参照：[StreamVGGT §4.1](https://arxiv.org/html/2507.11539v1#S4.SS1)冻结图像编码器、微调其余约9.5亿参数；[Point3R §3.3](https://arxiv.org/html/2507.02863v1#S3.SS3)让交互解码与记忆相关部分参与多阶段训练。这些事实支持把接收训练条件视为实验因素，**并不证明本项目的瓶颈、也不要求复现其训练规模或预言共同微调会成功**。

## 下一项建议：原生接收网络共同适配

**建议名 native_receiver_adaptation1；仅设计、尚未设目标或执行。** 科学问题是：同一保存3DGS内容、同一输入融合结构，允许原生接收网络参与任务学习后，Render相对Local/Global的净收益是否增加？

假设：当前固定接收网络限制了来源内容转化为原生深度收益。竞争解释：保存内容质量/混合、输入选择、有限训练地点或当前观测已足够；即使接收器能学，来源也可能没有净收益。结果只约束这个固定状态和训练条件。

| 训练条件 | Local | Global | Render |
| --- | --- | --- | --- |
| 仅训练输入融合 | 复用本轮三个检查点与评价 | 同左 | 同左 |
| 融合＋原生接收网络共同训练 | 新增三个配对种子 | 同左 | 同左 |

原生接收范围一次固定为**全部24组frame/global块及原深度DPT头**；图像编码器、来源构建、场景几何与1024维内容仍冻结。原结构没有新增writer、门控、替代解码器或新的PE模块。该选择是C6的一次实质变化，不做逐层解冻范围扫描，也不宣称已完成写入/骨干的全链路联合训练。

新增九次拟合，从相同官方模型和原对应种子的融合初值开始，沿用12训练/12旧开发地点、实际样本顺序、三个种子、有效batch2、2000步、原组合损失与最后检查点。融合lr1e−4，原生接收参数lr1e−6；AdamW/wd.01/clip5。两类学习率属于本次固定训练处理，不按开发成绩搜索。全部组享有相同可训练范围，不能只解冻Render。旧冻结行与新适配行的处理包括增加可训练参数及其优化，不能声称只隔离了某个单层机制。

主判断仍是新Render对新Local及新Global的缺失ROI空间误差。另报告配对交互：

`(E_Render−E_Local)_共同训练 − (E_Render−E_Local)_仅融合`，以及相对Global的对应差；负值表示共同训练使来源相对对照的优势增加。交互改善而新Render仍未超过控制，只支持受限机制线索，不构成方法采用。

原始误差、完整输入代价、来源支持/无支持贡献、全部地点/种子和成本继续报告。对两行保存模型补同口径的完整训练集合评分，与开发指标比较；不再用末20/500步训练日志直接替代泛化差。固定绑定打乱可沿用为依赖诊断，不能替代重训控制。没有精确1%门槛、没有全部辅助项获胜要求、没有GT支持区筛选。

12个训练地点是明显局限：本项是对当前条件的有界检验，不是足以训练通用模型的预算保证。若主要变化出现在训练集，需承认训练覆盖/泛化缺口，而不是延长同12地点训练或用开发地点调超参。更广场景训练与新确认应在方法和数据使用身份明确后另作决定，本次不混入数据规模变化而失去对训练条件的比较。

实施准备只需在两个原训练片段验证梯度、零更新原生一致性、显存/吞吐和保存恢复。共同训练可能明显增加优化器显存和磁盘需求，必须先实测；优先空闲GPU并保护其他任务，不能假定上一轮7GiB上限仍适用，也不能因显存不足自动退回旧末四层LoRA并宣称执行了本计划。此处不承诺未经测量的时长或显存。

| 结果 | 改变的决定 |
| --- | --- |
| Render相对新Local/Global出现可重复且有实际意义的净收益，交互也改善 | 保留这一接收训练条件；随后在同内容/同训练内比较强中心、球形与完整高斯PE，直接回答O6。仍不把接收适配收益算作PE收益。 |
| 三组绝对误差改善，但Render相对优势未增加或仍无净收益 | 主要支持共同任务适配，未证明场景记忆额外有用；不将新训练包装成高斯成功。 |
| 只有训练集改善，开发净用途仍无 | 当前训练覆盖或记忆迁移问题仍在；停止该固定小数据适配候选，后续须实质改变训练分布/任务目标才有信息价值。 |
| 收益只在GT支持子区域，或仅对打乱敏感 | 保留有限证据，不能据此部署GT门控或晋升整体方法。 |

这是一项优先级建议，不是将“先赢所有原生指标”设为所有PE研究的通用前置门禁。O6仍须得到明确实验回答；本项阳性也不满足总体研究目标。

## 大纲对应与防重复

已核对[研究入口](research_current.md)、[大纲对应](research_outline_alignment.md)及相关旧结果。本项服务O4/O5，复用O2/O3，主要改变C6；C1/C2保存状态、C3单次融合固定，C4投影标量修补保持结束。C5给定相机及来源传感器、静态条件、旧数据和小训练集仍为临时边界，不是导师大纲永久要求。O6未执行、不取消。

- [rendered_feature_native1](../results/gaussian_memory/rendered_feature_native1/report.md)：输入融合学、整个原生接收冻结；本项只改变接收训练条件，保留其全部阴性和局部正结果。
- [native_gaussian_pe1](../results/gaussian_memory/native_gaussian_pe1/report.md)：原生未压缩K/V、末四层LoRA及冻结DPT，空间/PE增量缺失；本项是保存真实3DGS的同层输入和完整原生接收＋DPT共同学习，不能称首次原生适配。
- [surface1](../results/gaussian_memory/surface1/report.md)、[joint_write1](../results/gaussian_memory/joint_write1/report.md)、[write_confirmation1](../results/gaussian_memory/write_confirmation1/report.md)：已有联合写入与独立粗头的正负结果；本项没有新增writer或粗头，判定仍用原生深度。
