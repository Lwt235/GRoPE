# 下一项：窗口外原始历史究竟提供了什么信息

2026-11-11。由 `history_read1` 与 `native_anchor_probe1` 的完整结果提出；用户再次要求明确计划并执行，现建立有限目标 **raw_history_information1**。一次有界的输入信息诊断，目的在于决定是否值得修改记忆写入/读取，不提出新的深度渲染方法或替代 Transformer PE 主任务。

## 科学问题与竞争解释

已有历史能改善部分相对空间结构，但整体收益与对强内容读取的独立PE增量尚未建立。统一尺度约束没有改善Soft，因此结束该公式分支。

下一问题是：在这12对窗口的规定来源中，早期观测是否实际包含当前查询所缺少、近期观测无法提供的可用几何信息？

- 假设：原始历史有补充信息，256槽压缩、更新或当前attention读取没有充分利用它。
- 竞争解释：窗口间重叠/可见表面太少，或近期窗口已覆盖所需信息；预测深度/位姿误差使潜在信息不可用。当前任务本身也可能更依赖尺度而非历史几何。

## 一次固定的匹配诊断

沿用同一12对旧窗口、四个查询、完整/两遮挡条件、原相机标定和因果来源列表。保留所有查询，不因重叠度筛选地点；用history_read1已经固定的近期来源与“近期＋早期”来源逐项配对。只用已下载数据，不训练、不搜索阈值或场景。

先对相同原始来源做两份投影：一份使用源视角传感器深度，作为**已知几何的诊断对照**；一份使用缓存VGGT预测深度，作为当前几何可用性的对照。两者均使用同一给定相机、相同像素采样和最前方深度的可见性规则。源传感器深度不进入本项目候选模型；查询传感器深度只在最终评分/可见一致性诊断中使用。无查询标签对齐或按误差选择来源。

报告三件事：

1. 所有当前像素、人工隐藏像素中，原始历史新增了多少支持；与近期来源重叠多少。
2. 新增支持在查询传感器深度上的几何一致性/误差；同时报告未支持比例，不能只报有对应子集的好分数。
3. 同一查询位置在已存256槽Corrective/Prefix状态中是否仍被覆盖。原始观测与压缩状态的信息/存储预算不同，差异仅用于定位损失，不能称为公平方法优劣或PE上界。

像素采样、投影栅格化、有效深度与容差采用已有工具的统一默认值，在打开新诊断输出前写入机器配置；仅做少量变换/索引正确性检查。若需要新栅格化实现，固定最近像素落点、前向z-buffer、不插值补洞；不要展开核近似、数值精度或阈值扫描。

## 执行前具体化（尚未查看本轮诊断结果）

- 192个来源帧的传感器深度全部在本地。旧缓存仅保存来源区域矩、patch中位深度和置信筛选，没有保存稠密深度；用同一冻结VGGT和原因果四帧输入重放24片段×5窗口=120次，保存192张来源深度，不改变原标定尺度。核对重放的区域中位深度与旧缓存一致。该补存不属于新训练或新数据。
- 主查询为12地点×4查询=48个相机。三种RGB遮挡只划分评分区域，不改变来源投影，因此有144个查询条件；不能把遮挡或像素当成独立地点。
- Early来源固定为A的0/1/2/3/4/6/8/10；Recent为B的0/1/2/3以及查询之前的偶数写入帧；History为二者并集。这里Recent指此前实验的晚期窗口来源，不等同于原生网络的最近四帧。所有只读查询帧都不进入来源。
- 固定210×280网格、像素中心(i+0.5,j+0.5)，源深度有效范围沿用(0.1,10)米；投影采用floor(uv)的最近中心落点和最小正z，z>1e-4米，不补洞、不插值、不扫描分辨率。来源自身无效深度分别排除。为区分深度值与缺测范围，再保留双方源深度均有效的相同像素集合这一匹配对照；它仅供诊断，不冒称无标签部署输出。
- 主报告原始投影支持、History新增支持及相对查询传感器深度误差≤10%的几何一致支持；阈值沿用writer的depth_agreement=0.1。同时报告误差连续值、前景冲突、被遮挡的更远表面和未支持比例，不由目标标签改投影。
- 256槽状态直接复用既有投影（3σ、0.1 patch²模糊、coverage>0.1），patch覆盖/合成深度在对应14×14像素内展开。此处保持原读取接口；原始点投影和高斯区域投影的表示/预算不同。比较支持保留、几何一致性和新增区域上的可见性，不把差异直接归因容量，也不把覆盖当精确深度或Transformer用途。
- 5000次地点配对重采样；本轮无训练种子，不能把旧三个模型种子复制为新增观测。固定例fidelity_00/01/02的q11完整/mask0，并展示按传感器一致新增支持最少的地点（如与固定例重合不另换）。只据完整统计做一个分支决定。

## 结果改变的决定与停止边界

- 若传感器来源也缺乏明显新增支持，先明确当前数据/任务无法有力测试窗口外历史优势；停止在它上面修writer或继续补种子，不否定所有高斯PE。
- 若传感器来源有信息、预测来源明显丢失，优先研究几何可信度/坐标一致性；不把它误诊为高斯PE公式失败。
- 若原始预测来源有可用新增信息而压缩状态丢失，下一项才针对一种最小写入/容量改变做GPU端到端比较。
- 若原始预测与压缩状态都保留支持、输出仍无收益，下一项转向Transformer读取/监督的正对照；覆盖不能代替用途证据。

这是一轮解释输入与状态的诊断，不能证明PE有效或信息论上限，不能作为以后所有可学习实验的永久前置门禁。交付上述三项事实及一个分支决定后结束；不反复扩充投影算子。强内容读取、Center控制、全部历史负结果和未用数据边界继续保留。
