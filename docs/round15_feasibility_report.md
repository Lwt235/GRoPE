候选使用预测像素的整体均值 μ 和协方差 C，以 C_h=C+h²I 定义二维径向四次密度：`exp(−q²/(4π))/(π²√det(C_h))`，其中 `q=(x−μ)ᵀC_h⁻¹(x−μ)`。对实际 key 矩形积分后，加一次 `1e−30×area` 密度底值，取对数，再加 `T×`归一化 RGB 特征内积并做 softmax。`quartic_point` 将 C 置零；`gaussian_point` 使用同一均值/内容与高斯点核。位置、协方差和积分面积使用一致的 8px 参考单位。这里不声称该二维核是三维四次分布的精确投影。

数据固定为原开发集 TRAIN 的 c3/c5/c6 三场景，各 16 对、共 48 对。只测 q8/q16/q24→432 个原生 g8 keys，完整网格为 h∈{.25,.5,1,2}、T∈{0,5,10}。前向只读取 `q_to_k_xy`、`q_to_k_pixel_cov`、`q_features`、`k_features`；所有 5,184 个 float64 概率数组保存并完成三场景全局封存后，才解码已有 R13 的传感器中心标签 `point_xy/point_visible`。未解码区域 histogram/counts，未在前向使用传感器。
