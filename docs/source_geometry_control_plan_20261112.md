# source_geometry_control1：来源几何质量×PE有限验证

2026-11-12制定并获授权，现已完成有限验证。以下保留原定假设、配置、决策规则和带日期进展；最终结果见末节及[报告](../results/gaussian_memory/source_geometry_control1/report.md)。原gaussian_scene_memory1保持原结果。

## 对应、假设与决定

服务O2/O3的公共粗场景及O4–O6的读取与PE，暂改C1的初始化来源；C2的alpha特征绑定、C3/C4的共享读取与PE、C5/C6的给定相机和静态冻结条件保持。参考[完整原因分析](gaussian_scene_memory_analysis_20261112.md)、raw_history_information1传感器/预测投影差距、address_intervention1冻结模型地址干预阴性及gaussian_scene_memory1的G对P主误差高6.97%结果。本轮实质变化是同一来源相机反投影构建器下，预测/传感器深度分别建立场景并匹配训练P/G；不是换名修原核或对旧检查点临时换输入。

假设：来源几何及其一致绑定误差压制了投影PE增量。竞争解释：中心PE已经足够、局部位置与当前内容不匹配、固定投影规则/冻结接收网络限制用途。主问题为Δpred=error(P-pred)−error(G-pred)、Δsensor=error(P-sensor)−error(G-sensor)及交互Δsensor−Δpred，正值表示G收益。

若场景质量及交互可靠改善，支持可靠性影响此PE，后续才研究纯RGB可靠构建；若P/G都改善而无PE增量，保留场景质量线索、不晋升G；若场景改善而输出不改善，上游质量不能单独解释；若传感器条件没有改善保存状态，操纵未生效，不外推为PE或接收网络无效。所有失败与辅助正结果保留。

## 仅两旧训练片段具体化的构建实现

- 复用原12训练/12旧开发地点和四来源[0,3,6,9]、四查询[2,5,8,11]，不得挑选低误差地点。无需下载新数据。
- source-only payload保存来源RGB、给定K/C2W、原AnySplat预测来源深度（既有source-only尺度）及来源传感器深度；不包含查询RGB/标签。传感器深度先按与RGB相同的448方形预处理进行最近邻变换，保留原有效掩码；预测/传感器共同有效范围0.1–10m。
- 两行共享同一来源像素候选与有效性：224网格每7×7特征单元选最近中心的共同有效像素，按source-major候选序列均匀分位选2048；若不足2048单元，确定性退回所有共同有效像素。该共同有效性本身使用传感器信息，因此预测行也是有额外诊断信息的受控参考，不能称部署纯RGB成绩。不得排除失败地点；若某来源集合连2048共同有效像素都没有，先记录实现失败再处理。
- μ由各行深度和相同来源相机反投影。旋转为给定来源相机R，四元数WXYZ；切向尺度为depth×7/√12/focal(224)，法向厚度为切向几何平均的0.1倍；初始opacity=.5，DC颜色取同一来源像素。共同长度单位复用原source-only单位，两行相同。
- 同样300步来源RGB+各行来源深度+初始覆盖保持拟合，优化μ/rotation/scales/opacity/DC；学习率和权重沿用上一轮固定值。无查询损失或开发选步数。
- 用实际alpha贡献写入相同冻结模型的1024维来源特征；保存后释放原来源，四查询共享状态。P/G每一行使用完全相同内容。两行的几何和后续绑定可一同变化，不能进一步归因成纯几何或纯内容的独立效应。
- 原两个训练片段检查候选一致、反投影、协方差、保存重读、共同参数和有效梯度；不按开发输出调配置。随后写入唯一配置及源码/输入身份。

## 固定训练、评价与成本

P-pred/G-pred/P-sensor/G-sensor各三配对种子20261110/11/12，2000步、有效batch2、相同样本轨迹与最终检查点。沿用共享width256/4-head读取器及0/6/12/18层，冻结原模型/DPT，AdamW1e−4、wd.01、clip5，.5*(原始全图log-MSE+去均值log-MSE)。P额外192有效参数披露。原L经输入/样本/初始化身份核对后复用为共同适配背景；原T/原AnySplat-P/G为历史背景，不将传感器成绩称公平超越RGB控制。

12次拟合各96份评价，共1152份适配预测；两个G模式各三种子全部96输入做原定移除、绑定打乱、错相机三干预，共1728份；合计2880份新原生输出。原288份参照、原L等结果按身份复用并单列，不计新独立证据。

沿用主终点缺失ROI去均值log-MSE、原始/偏差/完整输入/全图/来源支持分层、地点等权、三种子配对和5000次重采样。主交互以绝对误差差为主，另报相对误差差。源码和源/查询身份固定，不按中间分数改容量、PE、遮挡、采样和终点。

场景质量与原生用途在同一有限轮同步测量：source/query直接深度、覆盖与条件分母、特征重观察、来源RGB、全部地点对比。查询GT仅在这里做评价；不是先过某项渲染分数才准训练。没有质量改善时，解释操纵无效而非推导所有PE无效。

报告预处理来源RGB/深度张量到保存场景的构建成本、共享模型/状态字节、暖查询含重新编码/几何/全部native/DPT的成本，冷加载与I/O边界另列。实际查看总体结果、固定场景重观察、最大退步例，独立NumPy复算全部新预测并保留匹配身份。

使用实时空闲GPU，优先4/5等空闲卡；共享卡最多两张，进程12GiB上限并在外部任务新增压力时退让。保持原GLIBC。全部为旧数据和静态已知相机的额外输入诊断，无新确认、未知相机、在线更新或自动后继。
