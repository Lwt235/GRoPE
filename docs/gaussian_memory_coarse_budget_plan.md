# coarse_memory_pe1：有限场景记忆预算下的范围与形状用途

2026-11-11。**建议方案，尚未设为执行目标、未启动新训练。** 上一有限目标 `native_gaussian_pe1` 已完成；本文不修改该轮方案、模型、评价指标或负面结论。

## 1. 从本轮结果得到的判断

见[完整结果](../results/gaussian_memory/native_gaussian_pe1/report.md)。四组各三种子、2000步匹配训练后，持续遮挡ROI的原生适配／强中心／球形／完整高斯log-MSE分别为1.364770／1.364773／1.364783／1.364778。完整高斯对中心没有实用增量，查询却慢9.2%。结束这个末四层接法的形状扩展是合理的。

共同适配相对官方模型的ROI误差下降13.87%，其中99.95%的减少对应区域均值偏差平方下降；空间误差改善0.26%、区间跨零。完整输入的全图空间误差平均增加5.11%。这些结果支持有限的偏差改善，不支持精细几何恢复或高斯形状贡献。偏差分解本身不证明唯一的物理尺度病因。

还应注意接口边界：本轮查询的global[20]输入和DPT的4/11/17层特征，已经由读取完整原生历史的冻结前缀生成。它检验的是在这种表示之上增加末层几何读取的收益。强中心PE也几乎不改变输出，不能据此单独认定协方差没有信息。既有预检证明梯度通路存在，不能进一步证明任务充分使用了几何，也没有确诊writer或decoder是唯一瓶颈。

下一轮改变的是**被验证的信息瓶颈和记忆表示**，不是为微小差异补种子、扫温度或修五维公式。旧原生路线计划中“未压缩PE先获胜、才研究压缩”的顺序不作为普遍科学门槛。原有区域PE、粗状态读出和所有原生负结果继续保留。

## 2. 一个可被否定的假设

**假设：当多个观测合并为数量受限、空间范围不同的场景token时，中心不能完整描述每个token代表的区域；范围或完整协方差能在相同内容与存储预算下，改善查询的几何预测。**

竞争解释：强中心已经足够；共同特征聚合丢失的信息无法靠PE恢复；预测几何噪声抵消范围/形状信息；任何优势仍仅来自整体偏差调整。压缩不会自动证明形状有价值，本轮也不声称能够唯一定位这几种失败原因。

## 3. 最小结构与接入边界

沿用官方StreamVGGT检查点和现有RGB、预测几何。先静态构建一次跨观测场景记忆：在源patch的预测三维中心上，固定起点的最远点取样选择代表中心，再按最近中心分组；排序和并列处理确定化。所有方法、种子使用完全相同的成员关系。分别固定256和1024个场景槽，前者为主要预算，后者用于判断收益是否随较宽松预算改变，不扫描更多容量。

每槽保存共同的内容，以及中心μ、协方差Σ、成员数n。源patch等权；协方差用总体矩合并，同时保留patch内部协方差与成员中心散布：

`μ_j = mean_i μ_i`

`Σ_j = mean_i [Σ_i + (μ_i − μ_j)(μ_i − μ_j)^T]`

这里的Σ表示观测的空间支持，不冒称概率置信度，也不是经过光度优化的完整3DGS。各层原生历史K/V按同一组成员等权聚合，读取保留共同的log(n)计数补偿，避免把聚合后的成员数损失误当作形状收益。聚合在原生K的归一化和二维旋转之后完成；额外三维中心旋转作用于聚合键，三组一致。特殊token和相机状态采用相同处理并单独计入预算。

**查询必须从第一层开始读取这些粗槽。** 不复用上一轮已经读过完整历史的query prefix或早期DPT特征；第一遍预测查询几何也只允许访问同一预算内的粗记忆。第二遍从当前RGB重新执行查询，使用第一遍预测几何和粗记忆。第一遍、第二遍、特殊token、相机缓存都纳入实际成本。查询真值深度或姿态不进入PE。

源内容构建使用冻结模型，临时完整源缓存可用于一次性构建，但在查询前释放，并报告构建峰值与耗时。本轮验证的是静态场景记忆的读取预算，**不宣称已实现构建全过程的固定内存或在线增量融合**。

读取器只保留既有中心旋转和五维关系映射。为使几何在特征形成过程中参与，关系项覆盖全部global块；各组匹配地训练这些块的rank8查询Q／输出投影适配，冻结原生权重、历史K/V和DPT，不增加融合网络、额外解码器或门控。当前帧临时K/V按原生路径从当前特征计算。此配置是新的受限适配实验，不能称完整模型端到端训练。

## 4. 固定比较与预算

| 组别 | 读取时的空间描述 | 回答的问题 |
|---|---|---|
| B：强中心 | 同一三维中心RoPE＋五尺度距离关系 | 在相同粗内容上，强点位置编码能做到什么 |
| C：球形范围 | 同一中心RoPE，Σ替换为tr(Σ)I/3，沿用五维关系 | 范围是否有额外用途 |
| D：完整高斯 | 同一中心RoPE＋完整Σ的五维关系 | 方向和形状是否超出范围本身 |

三组共享槽内容、成员数、来源、查询、所有适配容量、初值和采样。B与C/D为固定容量的描述选择，不是假装严格嵌套的特征消融；C与D直接检验同迹条件下的形状信息。

按D的每档完整状态定义共同存储上限，统计全部K/V、几何、成员数、特殊token和相机状态。B/C同样不得超过该上限；如果省下的元数据足以增加整槽，应提供额外容量的强中心控制，不能只用同槽数声称严格同字节。报告实际字节、查询计算和构建成本，不能只计μ/Σ或最后四层。

原生未压缩官方模型保留为质量和成本参照，不当作同预算对照；另保留共同的冻结粗读取参照和当前视图独立预测参照，帮助判断是否只是修复压缩损失。与强中心的同预算比较才是PE主证据。成本收益用实测质量—存储—时间关系描述，不保证压缩必然加速。

## 5. 有限执行安排

1. **普通接口预检。** 只用两个固定旧训练片段核对来源、矩合并、真实查询通路、有限梯度和显存。给定非零位置关系时检查注意力确实变化，零新增位置项时检查共同粗读取路径一致；不要求预检就体现任务收益。先实测全层反传与两遍查询成本，再锁定共同实现。普通实现错误留修复记录，不拆成新科学轮次。
2. **一次匹配训练。** 沿用上一轮12训练片段、12个地点隔离的旧开发片段和完整／持续遮挡条件。每方法三个配对种子20261110/11/12，各2000步、有效batch2、AdamW 1e-4、wd .01、clip5，原始log-MSE加去均值log-MSE等权。两档容量按共同顺序等量训练，不按开发成绩选容量或检查点。共9个拟合、18000步；预检模型丢弃，只有最终检查点评价。GPU使用与并发由现场空闲和显存实测决定。
3. **统一分析与决定。** 每个模型在两档预算、全部旧开发地点和两输入条件上评价，共432份适配输出。以地点和种子配对报告不确定性、逐地点结果及成本。对导出预测独立复算指标，保留固定示例与最大退步例。没有新下载或未用数据确认，所有开发复用如实登记。

若预检显示拟定预算不可执行，在任何正式比较前共同修订资源配置并留记录，不能根据某个方法的效果给它额外训练。不要沿用上一轮末四层训练的耗时估算本轮全层反传。

## 6. 结果如何改变决定

主任务仍是原生深度输出，主要关注256槽、持续遮挡ROI的**去均值log-MSE**；同时强制报告该ROI原始误差、偏差平方、全图和完整输入表现。新主指标是在新比较开始前明确选择，以区分空间结构与偏差收益，不改写上一轮的主终点。1024槽和两容量之间的效应差为预定辅助比较。

每档预算内，三组共用相同的第一遍预测几何。不同预算也可能改变第一遍几何质量，因此容量间效应差反映整体读法的条件变化，不能单独证明收益由范围大小引起。

实用幅度的事前参考为：相对强中心的ROI空间误差至少下降约1%，种子和地点证据支持同向，同时原始误差及完整输入没有相当幅度的系统退步；这不是统计等效界限。1%是研究投入的最低兴趣量级，不能把刚越过某个小数位当成功，也不能只看区间是否跨零。主比较D对B，C用于决定范围与方向分别获得了什么证据；报告所有区间与反例。

- **D对B/C都有有用的空间增量，且质量—成本权衡成立：** 保留完整形状，限定为该粗记忆条件；方法和适用范围固定后再规划未用地点确认。
- **C对B有增量，D对C无有用增量：** 证据支持中心＋范围，暂不主张方向/完整协方差有价值。
- **仅区域均值偏差改善：** 将用途限制为粗场景条件下的整体估计，不称精细几何编码改进。
- **三组仍接近，或共同压缩损失压过收益：** 结束这一固定粗读取接法，不追加容量扫描、种子或公式修补；收窄到既有证据支持的区域关系用途，重新讨论是否继续投入原生VGGT分支。

一次阴性不否定所有高斯PE，一次开发阳性也不建立一般性。本轮交付应明确回答：在固定粗场景内容与预算下，中心、范围和方向分别是否值得保留，以及代价是什么。
