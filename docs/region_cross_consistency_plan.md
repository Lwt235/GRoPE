# 自预测参考下的跨帧高斯关系编码：固定开发比较

2026-11-10，正式训练前固定。上一轮真值参考给校准五维带来有限形状增量，但等权五维明显落后。本轮检验：由 Transformer 当前注意力自行提供软参考时，一个五系数的跨帧关系项是否改善真实对应和两帧几何对齐。竞争解释是错误、无对应参考破坏关系一致性，或中心距离与已有二维旋转足以解释收益。真值参考成绩不作本轮效果预测或可部署上界。

模型详见[原型设计](region_cross_consistency_design.md)。原固定 H=K 骨干、相同28维内容、二维旋转与两层self/两层cross不变；仅将cross分数S改为 `S - sum(beta[c]*E[c])`。P=softmax(S)，梯度经过P；E是两帧各自帧内关系的平方差在P下的期望，排除查询自己的参考行。五维/距离/固定球形分别只有5/1/5个跨层、跨head共享系数，全部从0开始、允许正负。self层不再加原关系MLP。本轮是紧凑接法替换，不把旧MLP和新项叠加；原五维作为重要对照保留。

尺度固定为上一轮仅由旧fit0非对角几何计算的标准差，常量列设1；不采用真值校准权重。前向不接受overlap、有效性掩码、真实位姿或外部模型预测。完整五维公式不删项；报告全部选中系数，包括负值，不将负权重解释成非负一致性代价。关系项条件于P的独立双帧刚体不变性不代表共同内容和完整网络不变。矩阵收缩采用已预检的FP64；复杂度O(C*N^3)、存储O(C*N^2)，仅验证N=64，不预先声称原生512基元可用或高效。

新增 `cross_full5`、`cross_distance`、`cross_sphere5` × 原种子11/22/33，共9次拟合。保持576 fit/64 val/480旧eval，原两种fit缓存、60周期/1,080更新、batch32、验证batch16、AdamW与原学习率、原区域CE、每3周期验证按最低CE选模。所有公共参数和全部60条增强流与原固定H及完整HRoPE配对。全部9模型选定后才能导出eval；不按对齐或eval成绩选checkpoint。CPU3项、旧fit两步GPU预检已通过且权重丢弃，冻结其身份后复用，不额外重复预检。

复用原同旋转F/Distance/Geo PE/固定球形12个模型，加完整HRoPE/固定H六个模型及恒等/真值最近中心诊断，共27个学习模型、29组几何结果。所有旧成绩和预测逐份固定身份；本轮只新增9份预测与9组求解。完整报告新F对另外8个学习角色的差，依次为新Distance、固定H、新球形、完整HRoPE、原F+旋转、Geo+旋转、原Distance+旋转、原球形+旋转；bootstrap种子99601–99608，每项10,000次种子×整场景配对重采样。主比较为前两项：平均至少+1 pp、三个种子均正且联合95%区间下界>0支持额外开发用途；反向对称，其他情况记不确定。其余比较按实际幅度与区间解释；新球形、原F和原球形不额外要求1 pp。不得用部分主比较通过声称胜过全部强对照，形状特有价值必须参考新球形。

主指标保持全部64个top1对应、原41,664三点假设、0.1 pair单位一致性半径、最多5次非恶化重估，全部源中心RMSE<0.2米；先场景再种子等权，所有480帧对保留。报告区域R@1、全查询正确率、中心PCK、soft EPE、旋转/平移/RMSE中位与p90、无效解和绝对失败率。共同相机信息相同，完整HRoPE仍是区域适配而非论文完整复现。无效/无限尾部显式标注，不删除。

实现与证据核对沿用已通过的零系数恢复骨干、显式求和与梯度、刚体与排列检查；再检查共同初始化/完整流、独立验证CE、预测回放、SciPy独立真值与评分，以及独立重采样算术。实际查看训练曲线和结果图后书面审阅；这些核对不能代替效果判断。源代码、固定尺度、预检、数据、旧预测/评分及计划一起冻结；普通工程错误保存版本与原因，不改科学设置。已有十地点及其他确认数据完全不访问，本轮全为旧开发证据。

若主比较和相应强对照/形状比较支持收益，仅进入适用的鲁棒性与未用数据计划，不直接完成总体目标。不确定或负结果结束此固定接法，不扫描初始系数、频率、温度、损失，不补种子或自动开启新确认；继续保留原五维的既有证据及所有负结果。推广须另有证据。

资源沿用既有授权，最多3个并行工作进程，优先连续观测空闲卡；否则最多一个与外部任务共享的进程，连续确认≥12 GiB空余且利用率≤60%，CUDA探测后再核对。NVML查询超时仅推迟启动，不中止在跑进程。不改变其他用户任务、系统GLIBC或已冻结历史文件。
