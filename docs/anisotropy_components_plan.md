# 两组各向异性关系的四组配对检验

2026-11-07。局部大小球形检验已完成并审阅，完整五维对它的区域基础/稀疏 R@1 高 +2.804/+3.820 pp，原生基础 mCA 高 +2.558 pp、联合区间仍宽。本轮沿用户恢复的自主研究目标继续解释两组关系的职责，使用旧开发数据；不启动新的确认数据访问或模块搜索。

## 科学问题与竞争解释

假设：两个协方差的相对形状关系能保留主要的额外用途，位移项未必需要完整方向度量。竞争解释是位移—形状耦合更关键，或两组各向异性共同作用，或区域和原生任务不同。旧 metric3 改变了输入维度与初始化，不能作为严格配对的单因素控制；本轮保持五个输入槽位。

记 δ=μi−μj、d²=δᵀδ、ri=tr(Σi)/3。五个槽位的第一个始终是 ||δ||/0.2，其余四个都取 log1p：

| 四组 | 两个位移量 | 两个协方差量 | 状态 |
| --- | --- | --- | --- |
| T：trace_isotropic5 | d²/ri，d²/rj | 3rj/ri，3ri/rj | 复用上一轮 |
| M：metric_anisotropy5 | δᵀΣi⁻¹δ，δᵀΣj⁻¹δ | 3rj/ri，3ri/rj | 新训练 |
| S：shape_anisotropy5 | d²/ri，d²/rj | tr(Σi⁻¹Σj)，tr(Σj⁻¹Σi) | 新训练 |
| F：relative5 | δᵀΣi⁻¹δ，δᵀΣj⁻¹δ | tr(Σi⁻¹Σj)，tr(Σj⁻¹Σi) | 复用原五维 |

所有组均保留局部大小与有序两端，不取平均，不改变协方差 floor。朝向与轴比仍联合改变；本轮不是纯朝向干预，也不把成绩差解释为物理量的信息比例。共同内容仍含完整协方差；改变的是 PE 中关系的组织。

两个新增版本继续使用同一 5→96→96 MLP（9,792 个 PE 参数），不增加模块或可学习系数。先构造旧完整五维模型，再包裹原 MLP，保持所有参数与 RNG 状态和相同种子原五维完全一致。用原完整/trace 描述计算路径选择分量，避免同时引入新的代数重排；不宣称计算量或速度已经降低。

## 数据、拟合与固定比较

区域匹配沿用 R68 的 576 fit / 64 val / 480 dev 对，64 tokens，60 epochs / 1,080 updates。原生分类沿用 R65 的 6,227 fit / 765 val / 765 dev 对象，512 tokens，120 epochs / 46,800 updates。M、S 各在两任务训练种子 11/22/33，共 **12 次新拟合**；不追加种子或预算挽救某一结果。

保持原优化器、学习率、数据增广和实际采样流，原生保留既有 memmap 搬运优化但不使用关系投影重排。区域按原 selection_ce（两方向等权），原生按原 ce 选模；全部 12 个模型统一选定后导出开发预测。完整五维、trace 球形、固定球形、Distance 均复用已选权重和旧预测，不重新选模。

区域保留 base 与固定查询 sparse256，原生保留 base/sparse256/dense1024/jitter02/tilt/permuted。六方法、三个种子，共 **48 组新预测与 96 组既有预测**。原生保持完整 60 类输出，区域的有效查询与标签不变。九场景和官方 TEST 的已用状态不变，本轮不读取其新分数。

## 主分析与决定

两类任务分别判断，以区域场景宏 R@1、原生类别宏 mCA 为主。四个核心差按固定顺序为 F−S、F−M、M−T、S−T；同时报告 M/S 对 Distance 与固定球形、M−S、F−Distance、F−T、T−Distance，避免单因素控制之间的差异取代强对照。所有分数和配对种子均保留。

再报告四组的成绩交互量 I=F−M−S+T（每个匹配种子/场景或类别先计算，再平均）。正值表示此训练与指标尺度下两项结合超过相加，负值表示冗余/替代的可能；非线性指标和重新训练使其不能直接等同真实几何的因果交互。不得把 I 独自作为胜出标准。

区域同时看中心 PCK、hard/soft EPE、CE、原四分组和高/低中心歧义组；原生看 OA、CE、逐类和 MACGS/ModelNet 来源。保留全部纠正/新增错误事件、种子方向反转及按 ID 排序的有限案例。没有给所有子组同号设门槛，微小差异不自动判失败。

描述性区间继续使用配对种子×场景/类别的 10,000 次重采样；基础随机种子 82001，先按区域条件/比较/分组，再原生条件/比较顺序递增，最后按任务/条件/分组计算 I。同时保留仅种子与仅场景/类别区间。不因看过结果而改统计方法或改分组。

- 如果 S 保留主要用途而 M 明显损失，则支持优先保留协方差—协方差关系，后续才评估能否简化位移公式；反之则优先保留位移—形状耦合。
- 如果两种单独保留版本都明显输给 F，则保留联合五维，不通过添加别的模块凑回分数；用本次差异界定适用条件。
- 若分任务或种子混合，明确保留不确定性，不用两任务平均消除冲突。以 1 pp 作为主指标工程损失的预定参考，同时看实际幅度、配对方向、区间、中心指标及强 Distance；不是自动晋升/淘汰阈值。接近均值或区间跨零不能声称等效。
- 本轮只决定哪种表达值得继续研究。任何简化候选仍需适用的鲁棒性、泛化和实际用途验证；已有新对象主确认的不确定性、RGB 与迁移负结果不因本轮改变。

## 执行检查与资源

事前检查独立标量公式、球形极限、刚体不变性、置换对应、两组分量对变换的预定敏感性；核对全模型初始化/RNG、共同内容不变和 PE 梯度。使用真实旧 fit 批次做 CUDA 检查，原生实际 512 tokens。冻结实现、数据清单、缓存、旧权重/预测及上一轮实际审阅身份。一般实现修复记录版本，不另立科学轮次。

最多六个 GPU 任务、每卡一个，优先空闲卡；按既有授权共享最多两卡，启动时至少 20 GiB 空闲，每项 PyTorch 分配上限 16 GiB。两次占用观察和启动前 CUDA 检查后才启动，保留其他任务。训练故障保留检查点和失败记录，观察超时不是重启依据。全部评价后再实际审阅和解释结果，不自动宣布总体目标完成。
