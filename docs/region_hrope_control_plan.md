# 旧开发数据：同相机信息的HRoPE与区域几何PE比较

2026-11-09。承接[比较方向](region_pose_hrope_comparison_plan.md)。本计划在本组新训练与得分产生前固定；仍只用历史3/1/5场景，不读取已选十个新地点的像素。完整五维公式不变。

## 假设与比较

在相同观测区域、可用相机信息、训练预算和刚体求解器下，完整五维F仍能比预测版HRoPE获得稳定的两帧对齐收益。竞争解释是HRoPE的学习型单应变换已能更好地组织共同输入，或此前五维的优势依赖未提供图像坐标的输入条件。

固定五组：relative5、distance_mlp、geotransformer_rpe、fixed_isotropic5、predicted_hrope；各原种子11/22/33，共15次新训练。原四组重新训练是为了提供相同的新增相机信息，旧无相机输入结果仅作为历史参照，不把旧新变化解释成纯PE作用。

## 共同输入与坐标

复用R68原区域缓存的全部特征、中心、协方差、标签与身份。另从各自旧深度观测及原token成员恢复平均像素位置，不使用外参、世界中心、对应或重叠标签计算这个新增输入。像素位置为成员像素的平均值，除图像宽/高并减0.5；内参用同一图像坐标归一化，保留主点和skew。

所有方法的共同20维内容增加8维：归一化K的前两行6个元素，以及归一化区域图像位置2个元素。共同stem首层20→28，其旧20列和偏置保持原同种子初始化，新增8列为零；其余共同层初始化也保持原样。这样所有方法都能学习利用新增信息，不能把内参或位置只提供给HRoPE。基础缓存不修改，新数据适配单独保存输入与来源身份。

沿用fit0/fit1的原观测成员、原合成坐标变换及每批额外随机刚体增强。图像坐标对应同一实际观测，随token同步排列，但不随人为几何坐标换基改变。不给模型真实相对位姿或为了消除增强而提供外参。恢复区域成员时核对旧缓存、像素回投及坐标换基一致性。

## HRoPE适配

共同stem输出经一个96→13线性头，预测R的6维表示、t、n、κ。保持论文H=K(R+κtnᵀ)及Sherman–Morrison逆，t/κ截断至[-0.5,0.5]、单位法向、proper rotation、分母下限0.1及矩阵元素[-5,5]。初始R=I、t=0、n=(0,0,1)、κ=0.25，头权重为零。矩阵从共同stem特征预测一次，供四层使用。

每头48维中，前24维为8个3×3单应块，后12+12维为x/y的2D RoPE。采用论文Eq.18的频率，theta=10000、ell=1..6，图像位置乘8形成64个区域对应的固定名义8×8坐标尺度；这是不规则区域的适配约定，不扫频率或尺度。Q施加转置、K/V施加逆、聚合输出施加正变换。

在原两层self与两层cross注意力均使用HRoPE，并保留共同注意力尺度、残差及FFN。原四种编码仍仅在self层使用其原PE。两观测均预测参数，没有NVS目标视图的无观测回退。该比较包括编码算子和作用位置的差异，不是仅替换协方差与法向的因果消融。参数数目、计算成本如实记录，不为机械配平参数扭曲HRoPE。

本实现根据论文公式适配当前深度几何区域，不使用RGB、DINO/VGGT、预训练特征或真实外参，也不声称复现完整论文基准。

## 固定训练、评价与结果分支

576 fit/64 val/480 old_eval帧对，60 epochs/1,080更新，batch32、验证batch16、原AdamW/学习率计划、每3周期验证CE选模。五方法每种子共同初始化、样本与增强流配对；不因某方法学习慢增加预算或按开发对齐分数重选模型。原损失及全部查询评价保留，网络FP32、几何关系沿用原实现，TF32关闭。

全部15模型选定后，旧五场景base导出。主要比较F−HRoPE；同时报告同相机输入下F−Distance、F−Geo、F−球形和HRoPE相对Distance/Geo，解释是否存在共同任务失败。区域R@1、全查询正确率和中心定位为辅助证据。

对齐继续使用全部64个top1对应、相同41,664三点假设、0.1归一化一致性半径、最多5次重估，成功定义RMSE<0.2米。场景等权再种子等权；六项比较按上述顺序使用95001–95006种子、10,000次配对种子×整场景bootstrap，并保留逐种子/场景与全部帧对误差尾部。原恒等/真值辅助诊断可复用，不把真值辅助当部署方法或理论上界。

F−HRoPE均值至少+1 pp、三个种子为正且联合区间下界>0，才支持有幅度的有限开发优势；同时解释绝对成功率和失败范围。若HRoPE更好或相近，如实缩小“相对强编码”的主张，不删对照或调求解阈值。HRoPE的纳入取决于实现正确、信息公平和正常学习，不以其输给F作为条件。新确认在本组完成并实际审阅、模型与比较规则重新固定后才开放，不能因增加指标把旧数据称fresh。

## 必要执行核对

检查非平凡单应与闭式逆、完整Q/K/V/输出及跨视图矩阵作用、共同初始化与新增输入、排列对应、有限梯度；数据重建核对原成员和像素坐标。旧数据GPU预检查通过后用实时空闲GPU，最多沿用四任务并行，CPU4和小额显存上限，保护其他任务。普通失败保留版本记录后修复，不新增科学轮次。上述工程检查不替代最终效果审阅。
