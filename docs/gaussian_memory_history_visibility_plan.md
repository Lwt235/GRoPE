# history_visibility_control1：受控历史读取正对照（执行计划）

2026-11-11。接续 [raw_history_information1](../results/gaussian_memory/raw_history_information1/report.md)。用户再次要求明确计划、设为目标并执行后，采用本有限实验；不改变已完成实验的条件。

## 要回答的问题

当早期观察保留了当前观察缺失的区域时，已有高斯记忆是否改善 VGGT 原生输出？若改善，完整高斯位置关系是否比同信息的强内容读取和 Center 更好？当前窗口中，传感器来源的新增一致支持仅占有效查询像素的 0.86%，继续在相同信息条件下补种子很难回答这个问题。

竞争解释是普通内容记忆已经足够、预测几何或粗状态损失使信息不可用，以及已有读取器不能处理这类遮挡。此实验改变信息条件，固定方法；受控遮挡的失败也可能是分布外失效，不能据此否定一般历史记忆。

## 固定实施

1. 使用现有全部 12 个 fidelity 片段；每片段早期观察为帧 0/1/2/3，晚期写入为 4/6/8/10，查询为 11，Native 当前窗口为 6/8/10/11。早期信息确实在当前四帧之外。不下载、不换地点，不按本轮效果挑子集。
2. 查询使用已有 mask0 矩形。用早期**源传感器**有效表面点和已知相机，确定投影落入该矩形的表面，再投影到晚期各输入，遮挡其触及的 14×14 patch。无需查询深度选择表面。源传感器只用于人工任务构造，不输入候选记忆或读取器；这是带特权几何的受控诊断，不是可部署遮挡生成器。
3. 固定三种条件：完整输入、仅查询遮挡、当前窗口与所有晚期写入上下文一致遮挡。早期记忆从完整观察建立；当早期 RGB 再次出现在晚期编码的四帧上下文时也必须遮挡，不能通过重编码绕过历史记忆。查询帧不写入记忆。记录全部实际输入和掩码，不用源缓存中的完整输入特征冒充遮挡输入特征。
4. 复用冻结 VGGT，重算受影响的内容/预测几何。沿用各原输入的相机基线尺度及共同米制坐标，以隔离可见性变化；这保留了完整输入导出的标定，属于固定标定条件下的诊断，不声称严格纯 RGB 在线部署。Recent-Prefix 由四个晚期写入构建，History-Prefix 再包含四个早期观察，均为 256 槽。使用 Prefix 控制来源，不把离线重建称为常量成本在线写入。
5. 首次只复用现有五组各三种子冻结读取器：C-static、C-dynamic、Soft-static、Soft-dynamic、Center-dynamic；另保留 Local 与 Native。各方法相同 RGB、相机、状态来源与尺度，不训练、搜索温度或增加模块。先核对掩码确实改变晚期可见信息，随后直接做 GPU 原生输出评价；信息检查不扩展为长期静态门禁。

## 读数与决定

主读数是固定查询遮挡区的原生 log-MSE，完整图和可见区同时报告。先比较同一模型 History−Recent 在三种条件下的变化，再比较同状态的 Soft−强 C / Center。全部 12 地点等权、三种子配对；同时报告源区域可见度和无早期支持的地点，不排除、不把它们重新挑选成新确认集。来源/实现核对以能否改变结论为限。

- 历史稳定有益且 Soft 超过强 C 与 Center：才进入匹配训练和未用数据确认，结论仍限于该信息条件。
- 历史有益但强 C 同样好：支持历史记忆用途，尚不支持高斯 PE 的额外贡献。
- 信息确实保留而全部冻结读取器仍无益：记录分布外边界，再判断是否值得做一次直接匹配训练；不自动进入公式或写入器的逐项修补。
- 早期来源仍缺少相关支持：保留完整负结果，说明该受控构造的信息边界；不循环搜索能产生好结果的遮挡或地点。

## 运行前实施补充

三种条件均用原完整查询的同一个米制尺度；仅查询遮挡条件复用原 mask0 的特征和原生预测，但按共同尺度重新评分。所有条件的主评分区域都是固定 mask0 矩形，包括完整输入条件；这里的区域指标不意味着完整输入也被遮挡。

遮挡构造使用早期表面点投影的全部落点，不用查询深度进行可见性筛选，也不额外膨胀掩码。晚期源传感器深度只在掩码已生成后用于检查剩余直接支持；不进入候选状态。状态继续使用原预测置信筛选规则，不额外剔除遮挡 patch，因此模型自行推断出的内容和几何仍可写入；这与直接可见信息的诊断有所不同。

主比较预先固定为一致遮挡条件下：Soft-dynamic 的 History 对 Recent，以及同 History 的 Soft-dynamic 对 C-static、C-dynamic、Center-dynamic；两个内容对照均报告，不按地点选优。主指标固定区域 log-MSE，整体与可见区代价同时报告。12地点×3种子配对，5000次地点和种子联合重采样。全图、仅查询遮挡与一致遮挡的 History−Recent 差异用于辨别信息条件作用。

计划导出1224份原生输出（1080记忆读取、108 Local、36 Native）。新增骨干窗口为12片段×5个一致遮挡窗口，另在固定fidelity_00重放完整/仅查询两窗口核对缓存，共62次；其他完整输入来源与查询缓存按身份复用。固定例图为fidelity_00/01/02，另显示一致遮挡下Soft-dynamic相对C-static固定区域误差差最大的地点（种子均值、并列按地点名），不据此排除样本。

完成本轮结果、与结论相称的核对和分支判断后结束有限目标。完整的主研究目标仍是结构精炼且有可靠适用范围的高斯参数位置编码。
