# 条件值备选：独立审查与最小否证顺序

2026-10-30。只审查 [备选假设](round12_value_hypothesis_reserve.md)、[旧 projection-frame 审查](gaussian_projection_frame_candidate.md)及既有 R8 证据，并核对列出的原论文；没有读取 R12 分数、新标签或历史封存测试数组，没有实现新模型。

**判断：可以保留为一个小诊断，不能预设它会解决 R8，也不能直接当作更一般的 PE。** 它恢复的是原 patch-mean V 丢失的局部深度斜率，没有新增源观测。若源 RGB 深度有系统性偏差，条件回归仍以这些偏差点拟合；如果强双线性或平面读取已达到同等效果，就没有证据继续保留 Gaussian 条件值这一包装。

## 信息与结构边界

1. **确实保留了不同统计量，但信息来自原像素。** 原 R7 key V 只有预测 patch 平均三维点的 query-camera z；`Cov((u,v),z)` 包含平均值没有的局部相关性。应给双线性、局部平面与 Gaussian 条件值完全相同的原预测像素、相机与成本预算。它不能被解释为改善了上游单目深度，或获得了额外传感器信息。只保存二维 `xy/pixel_cov` 的 R11 缓存不足以恢复完整的联合深度 cross-covariance；若以后做 producer，须从原预测像素重新构造，而非猜测缺失的块。
2. **三个固定 V 通道的等式只对每 key 一个仿射值成立。** 单 Gaussian 的 `(a,beta_x,beta_y)` 可以在固定 attention 下先求加权和，再于 query 坐标求值；这部分是精炼的。但若每个 key 再用四个条件 Gaussian，条件均值为 `sum_s r_s(u)*(a_s+beta_s*u)`，其中 `r_s(u)` 依赖 query 坐标。通常不能把它压成三个与 query 无关的 key 通道。可选择“原四-query-support 路由＋每 key 一个仿射值”，或明确支付多分量值的计算；两者不能混称同一个三通道算子。
3. **它改变 V 的语义。** 原 value MLP 对 `[feature,log z]` 先做 GELU，深度残差头也非线性。条件深度的求值、取 log、GELU 与 attention 聚合均不能任意交换。新增三个深度通道不是原 R7 的等价实现；若放在原头旁边作为补充特征，就是新增深度分支，需要对应容量与同信息控制。若先只做线性标量传输，可以保持单算子结构，但暂时只能称局部几何读值，尚不是对任意内容 V 的通用位置编码。
4. **岭项有统计含义，不能仅叫数值稳定。** `C_uu+h²I` 会收缩斜率；把位置核带宽直接借给它，是一个新且可否证的耦合假设。区域 footprint、单目预测误差与条件坐标观测噪声不是同一件事。应先固定已有 h，不为此再搜索一组门控/置信度/回归尺度。

## 与旧 frame 路线的关系：平面是必须击败的解释

旧 `A_i A_j^+` frame 在同一 Gaussian 跨相机时变成正则化平面 homography，薄面极限丢失切向椭圆率。本备选不使用那个齐次 pseudoinverse，所以不能直接继承其错误中心排名、范数或组合律问题；但在单表面局部区域，它同样主要编码局部斜率/平面。不能因写成 covariance 就宣称完整 GS 形状有不可替代作用。

透视相机中的真实平面满足 `z(u,v)=d/(n·r(u,v))`，因此**逆深度对归一化图像坐标仿射，深度本身通常不仿射**。Gaussian 条件深度是后一种仿射近似。一个不用数据的反例：平面 `z(u)=1/(1+u/2)`，在 `u=−1/2,+1/2` 的深度是 `4/3,4/5`；对称样本的条件仿射深度在 `u=0` 为均值 `16/15`，真实值是 1，误差 6.67%，加岭项也不改变中心截距。相同样本的逆深度平面能精确给出 1。双线性深度在这个简单采样例子与仿射回归相同，也说明 Gaussian 写法没有自动额外信息。

因此至少需要：同信息的 3D 最小二乘平面/射线相交，以及图像逆深度仿射拟合。二者是物理参数化与回归坐标不同的直接控制，不需要新网络。PGSR 已明确讨论中心深度混合与平面/射线读值的差别，但其重建结果并不能证明本任务的条件回归有效。[PGSR 原文](https://arxiv.org/html/2406.06521v2)

## 先做什么，什么结果应停止

**第一步：纯解析/合成检查，不训练。** 同帧恒定面、斜面及大透视变化、两层深度断层、带噪平面、负/近零 ray-plane 分母、FOV 外外推；核对单位/共同坐标变换、常数退化、直接逐 pair 求值与三通道聚合恒等。四分量情形专门检查 query-dependent responsibilities，不能用固定先验平均代替。所有方法共享预定物理深度范围和失败 fallback，报告触发率，不按 GT 移除问题点。若无噪声单平面都明显输给简单平面控制，拒绝“更准确表面读取”的解释；剩余可能性只能是有噪声时的压缩/正则 tradeoff。

**第二步：固定旧训练 cohort 的一次前向诊断，不开新数据。** 在看这些新比较分数前固定原 R10 的 48 个旧训练 pair、同一个已有路由与物理单位、已有 h。先只比较常数 patch V、单仿射 Gaussian 条件 z、同信息平面值，全部使用相同 attention；所有 query sensor-valid 中心均保留。另将 dense source-depth 双线性读取作为一个便宜的完整方法对照，并明确它使用连续坐标、路由不同，不能把它包装成仅替换 V 的消融。

再用 R8 已有的合法范围定义做**标明特权的路由诊断**：在可核验对应处用相同 sensor-derived routing，其他 query 使用同一个原预测 fallback，V 始终只由 RGB 预测源深度产生。其目的仅是问：固定来源选择以后，斜率是否仍补回了可用信息；不重新跑整个 GT-source-value oracle 矩阵，不将 oracle 成绩当候选。分别报告全查询、可核验对应与 fallback；不能只保留对平面回归有利的表面。

这一步至少否证三个解释：

- 常数→条件值很小，而 dense 读取与传感器目标仍差很多：主要源误差未被解决，应停止以此修复 R8 的假设。
- 只在 privileged routing 下改善，合法路由下不改善：当前实现没有可部署效用，不能直接推进新场景训练。
- 与 bilinear/plane 等价或更差，且成本也无优势：采用更简单的控制，停止声称 Gaussian 条件值有独立价值。若有精度/成本 tradeoff，应先冻结统一的 tradeoff 门槛，不能事后只挑准确率或速度。

只有合法路径在完整人口上有稳定收益、对最强简单读取具有额外精度或可信成本价值后，才值得为线性值表示另写最小 head 的训练协议。仍须保留原 R7/R12 的实际 V、单视图与强位置比较；此备选不注销此前失败，也不能偷偷替换已冻结候选。

## 文献边界

GTA 已把几何相对变换作用于 key/value 以对齐坐标，故“位置可以作用于 V”本身不是新贡献。[GTA 原文](https://arxiv.org/html/2310.10375v3) Direct Conditional Parameterization 已研究 joint Gaussian 的条件均值与直接回归坐标；本文的条件公式、低维回归系数均不提出数学新颖性。其具体任务是 N-dimensional splatting 的条件切片，与当前 RGB 预测 patch 深度值并不相同，不能借用其效果数字。[原论文](https://arxiv.org/html/2610.22778v1)
