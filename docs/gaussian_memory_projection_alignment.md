# 高斯读取的投影接口一致性修正

2026-11-10，主实验完成后的开发修正。原九次训练、直接 Jacobian 版本的负结果与两个诊断均完整保留，不覆盖为成功。

原始三种子均值：同场景留出 Gaussian 0.40463 优于 Center 0.42390；六个未优化场景 Gaussian 0.49219 劣于 Center 0.41054。圆形替换仅部分改善，添加正向遮挡反而恶化，未解释全部问题。随后检查本地 gsplat 1.5.3 的 `_persp_proj`，发现写入阶段投影的 Jacobian 对画面外视角做了原实现的范围限制，而初版 attention 使用不限制范围的直接 Jacobian。两者数学上是不同的投影近似；对初版负结果的解释必须限定此接口差异。

零训练兼容性干预只替换显式二次项中的投影协方差，保持所有权重、完整 MLP 输入、中心、透明度、掩码不变。六场景误差降至约 0.39852，三个种子均优于 Center；Center 输出逐值不变。该结果提供实质性的投影接口证据，但属于开发数据上的训练后干预，不能直接当作独立确认或稳定训练方案。

因此仅作一次精炼修正：用原写入器所用 gsplat 投影同时训练和评价高斯读取；不添加可见性、额外模块、阈值扫描或新任务。新的三次 Gaussian 训练仍用原初始化、采样序列、2,000 步、同样的 λ_h 初值/优化器和完整输入；Center/MLP 在此替换下计算不变，复用原六个配对模型。保留原 center 固定尺度，不根据评价调参。新的投影代码单独保存，旧模型与原始源码保持不动。

先在相同开发查询检验重训结果。若两个留出范围、全部配对种子以及多数六个场景都支持 Gaussian 对 Center/MLP 的收益，则固定六个原控制、三个新 Gaussian，使用已在结果解释前按可用性选好的 R6/R7 全部 12 场景、每场景首 13 个已下载帧进行确认。固定教师 PCA、冻结原写入器、四参考/九查询，零场景拟合。确认数据来自历史研究，但未进入当前记忆设计；不是历史上从未使用的外部测试。不得根据确认结果再调参。

若修正后开发或确认不保留收益，则收窄结论，保留中心读取作为当前简单基线，结束本次迭代。该修正不改变原实验的失败记录。输出报告需并列说明原版本、诊断、修正版本及新场景结果，不能只展示最佳数字。
