# 单一四次势能支撑 PE：解析可行性与否证条件

2026-10-30。独立理论审查；未读取新的效果数组、运行候选或修改任何现有模型。只做了一次定向文献检索，并对以下闭式常数做算术核对。**径向椭圆版本值得先做纯数值/解析预检：它仅用原 μ,C，结构比四分量简单，而且确有更接近有限区域的形状动机。但它不保证中心保护，尤其不能预设能修复 T5。** 可分离版本更接近方形，却需要明确的额外局部轴语义。

## 1. 二维径向版本：协方差恰好为 C

设 `C≻0`，`d=x−μ`，`q=dᵀC⁻¹d`，令

\[
p_4(x\mid\mu,C)=\frac{1}{\pi^2\sqrt{\det C}}
\exp\!\left[-\frac{q^2}{4\pi}\right].
\]

这就是所问形式，**固定 `a=1/(4π)=0.0795774715`，无需校准**。取 `x=μ+Lz, LLᵀ=C`，用极坐标 `z=r(cosθ,sinθ)`：

\[
Z_2(a)=2\pi\int_0^\infty r e^{-ar^4}dr
=\frac{\pi^{3/2}}{2\sqrt a},\qquad
E[r^k]=a^{-k/4}\frac{\Gamma((k+2)/4)}{\Gamma(1/2)}.
\]

因 `E[z_i²]=E[r²]/2=1/(2√(πa))`，上述 a 令 `Cov(z)=I`，`Z_2=π²`。于是 `E[x]=μ, Cov(x)=C`，`E[r⁴]=2π`、`E[z_1⁴]=3π/4≈2.35619`、`E[z_1²z_2²]=π/4`。这些四阶矩是所选族的固定结果，**不是从输入读到了新的四阶几何信息**。

在 μ 处密度有限、唯一最大，`∇log p=0`，`∇²log p=0`；局部变化是四阶，故比 Gaussian 平。尾部是 `exp(−O(r⁴))`，比 Gaussian 轻，但支撑仍无界，并不等于有限 patch。对任意可逆仿射 `x'=Ax+b`，将 `μ'=Aμ+b, C'=ACAᵀ` 代入，密度按 `1/|det A|` 正确变换。该性质不需要选择可识别的特征轴。

`C→0` 时分布弱收敛为 μ 处的点质量，密度公式本身不能在奇异 C 上用 pseudoinverse 和伪行列式直接当二维概率密度。若取 `S=C+h²I` 保持正定，点极限变为协方差 `h²I` 的四次族，**不是原来的 Gaussian point kernel**。同一 h 只匹配总协方差，不匹配整个噪声分布；`p_4(C+h²I)` 也不等于 `p_4(C)*N(0,h²I)`。保留原 Gaussian point 强对照，并明确新的零支撑退化语义，是后续协议的必要部分。

部分退化还有一个容易忽略的问题：二维径向族压缩到一条线，其一维边缘通常不是一维 `exp(−b t⁴)`。该族没有 Gaussian 对边缘化、卷积和线性投影的全部闭合性质。直接把投影后的二维 μ,C 重新放入本式，是一个二维矩闭合假设，不能说成精确投影了某个三维四次 primitive。

## 2. 它确实更接近某些有限区域，但不是一般改进保证

以下是**无数据的解析分布 KL**，均在全平面上、均值0、协方差I；没有内容、h、像素分箱或传感器真值，不能当实验成绩。

对于均匀方形 `[-√3,√3]²`，`E[r⁴]=28/5`。相对同矩 Gaussian 与径向四次族，

\[
D(g_\square\|p_G)=\log(2\pi)+1-\log12=0.352970,
\]
\[
D(g_\square\|p_4)=\log(\pi^2)+\frac{7}{5\pi}-\log12=0.250187.
\]

对半径2的均匀圆盘（亦 Cov=I），相应 KL 为 `1−log2=0.306853` 与 `log(π/4)+4/(3π)=0.182849`。因此“相同矩、较平内部、较轻边缘外尾部”有具体的有限区域近似动机。

但 μ,C 仍不能区分方形朝向、环形、偏斜支撑和深度断层的多模态分布；唯一中心峰是人为施加的闭合。轻尾也可能更严重惩罚预测深度/相机误差产生的远端真实质量：正数 floor 能避免 Inf，不能消除真实 KL 的损失。保留原尺度、噪声、分区与中心门槛；不能只画漂亮的无噪声方形图推进。

## 3. 矩形质量有精确的一维表达，但没有免费的固定维积分编码

原任务需要 `M_R=∫_R p_4(x)dx`，不是在 key 中心采密度。白化后，轴对齐 key 矩形 R 成为平行四边形 `P=L⁻¹(R−μ)`。对方向 `u(θ)`，将射线 `r u, r≥0` 与 P 相交，若非空，交段为 `[r_lo(θ),r_hi(θ)]`。径向原函数可精确消去：

\[
M_R=\frac1{2\pi}\int_0^{2\pi}
\left[\operatorname{erf}\!\left(\frac{r_{hi}^2}{2\sqrt\pi}\right)
-\operatorname{erf}\!\left(\frac{r_{lo}^2}{2\sqrt\pi}\right)\right]d\theta,
\]

空交段贡献0。射线交段可直接用两个物理约束
`R_low−μ ≤ r L u(θ) ≤ R_high−μ` 与 `r≥0` 求交，不必构造通用多边形库。

这个表达只剩一维角度积分，不能误称矩形闭式 CDF。固定数值实现应在顶点射线及必要的平行方向处分段，再对每段做固定阶 Gauss–Legendre；整个 `[0,2π]` 用少量固定角度会漏掉远格的狭窄角窗口。白化后角密度均匀，通常比在物理角度中再处理强各向异性更自然。两端均在尾部时用 `erfc(lo)−erfc(hi)` 等稳定差分，避免两个 erf 都舍入为1。

计算量是每 query/key 对 `O(s n)` 次方向、射线求交和 erf 差，s 为固定有限分段数、n 为每段阶数。它避免默认的二维 `n×n` 网格；但还有四顶点角度、区间排序/掩码以及分支成本。Gaussian 的现有一维条件积分通常只需一段32节点，四分量约128节点；四次族能否更快取决于分段和实现，**现在没有可信实测比例**。至少先覆盖小/大协方差、极端相关、中心在边/角/格外、tiny-FOV 和梯度，再固定数值阶数；不得从真实效果选择积分精度。高维或双侧任意 key 支撑没有因此获得相同便宜表达。

## 4. 点 logits 的14维展开：精炼，但与区域积分分开

令 `Q(x,y)=αx²+βxy+γy²+ux+vy+w` 是 `q` 的展开，其中
`α=A11, β=2A12, γ=A22, (u,v)=−2Aμ, w=μᵀAμ, A=C⁻¹`。
其平方的非恒定系数按次数为：

- 四次：`(α², 2αβ, β²+2αγ, 2βγ, γ²)`，对应 `x⁴,x³y,x²y²,xy³,y⁴`；
- 三次：`(2αu, 2(αv+βu), 2(βv+γu), 2γv)`；
- 二次：`(u²+2αw, 2(uv+βw), v²+2γw)`；
- 一次：`(2uw,2vw)`。

因此点密度的 logit 去掉 query-only 常数后，可由14维 key 单项式与 query 系数 `−1/(4π)` 倍的内积**精确**实现。它是已知多项式展开，既不是新数学，也不是单位旋转 RoPE。较大绝对坐标的四次项会产生严重抵消，需对照直接相对坐标计算检查精度。

`log∫_R exp(−Q²/(4π))dx` 不能靠同14个 monomial 的普通 key 均值得到。那样算出的是平均 log-density，再取指数；Jensen 意义下与平均 density 不同。故14维点编码不能直接继承区域积分、key 细分与质量守恒的旧结论。

也不能默认 `exp(−a‖x−y‖⁴)` 是正定核：取一维三点 `0,ε,2ε`，记 `u=exp(−aε⁴), v=exp(−16aε⁴)`，Gram 行列式为 `(1−v)(1+v−2u²)`，小 ε 时第二因子为 `−12aε⁴+O(ε⁸)<0`。这不妨碍非对称 Q/K **logit** 展开，却排除了把它无条件称为同一正特征映射的内积核。

## 5. 保留局部轴的可分离版本

给定一个具有物理轴语义、可逆的 `L`，令 `y=L⁻¹(x−μ)`，

\[
b=\left[\frac{\Gamma(3/4)}{\Gamma(1/4)}\right]^2
=0.1142366453,\quad
p_{sep}(x)=\frac{4\sqrt b}{\Gamma(1/4)^2|\det L|}
e^{-b(y_1^4+y_2^4)}.
\]

每个一维分量的方差为1，因此 `Cov(x)=LLᵀ`；若 `LLᵀ=C` 就精确匹配 C。方向四阶矩约2.18844，更接近均匀方形的1.8。上面的标准均匀方形 KL 为0.200838，比径向版本更小；标准圆盘则为0.200415，差于径向版本0.182849，已表明轴假设带来的形状偏好。

**仅给 C 不能无歧义地保留方形轴。** `L` 与 `LQ` 对任意正交 Q 都有同一 C，而 separable 密度只对符号/轴置换不变。Cholesky 选择依赖坐标顺序；特征轴在相同/接近特征值时无唯一稳定方向。尤其 C=σ²I 时，若声称只从 C 构造且旋转等变，所得密度必须旋转对称，与一个固定朝向的 separable 方形先验矛盾。

若另行保留源 patch 的局部投影轴并要求 `L'=AL`，则密度可正确仿射变换；这是额外的轴统计/约定，不再是只用 μ,C。真实非线性、多表面投影还未必有一个既忠实这些轴、又满足 `LLᵀ=C` 的简单选取。不能把 Gaussian 在等轴时原本无物理作用的 R 当作免费可识别的方形方向；这里很容易重新引入旧 frame 路线的退化和约定问题。

在轴与矩形对齐时，一维 CDF
`F(t)=1/2+sign(t) P(1/4,b t⁴)/2`，P 为正则化下不完全 Gamma，矩形质量是两个 CDF 差的乘积。一般旋转/剪切时，白化 key 是平行四边形，只能按顶点分段做一维 `f(y1)[F(y2_hi)−F(y2_lo)]` 积分；仍需稳定 Gamma 尾差与梯度，不能把轴对齐的廉价乘积用于全部几何。

## 6. 唯一中心不能解决 T5，也不能恢复丢失的中心身份

第一，分布中心仍是区域均值 μ，透视/深度断层下不等于指定源中心射线的投影。第二，内容项可把唯一几何中心移开，而且四次平顶对弱斜率可能更敏感。沿一维方向，
`log p(x)+T c(x)=−a x⁴+T ηx+const` 的最大点是
`x*=(Tη/(4a))^(1/3)`；Gaussian `−x²/2+Tηx` 的最大点是 `Tη`。弱内容斜率下前者位移是立方根量级，不是更强的中心保护。这里 ηx 只是有限局部区域内的内容变化反例，不假定实际余弦内容在全平面无界。

对实际有限 key 集也一样：只要两个格的几何 log-mass 差小于 `T(c_j−c_center)`，模式就改变。中心接近相邻格的对称边界时质量差可任意小，T=5 的有界内积足以翻转；大区域的平顶还会扩大多个格接近等质量的情形。不会因为连续密度唯一最大，就自动通过离散 argmax/PCK 门槛。任何另设中心读出也不算原门槛通过。

## 7. 新颖性边界与最小投入顺序

上述径向形式是已知 multivariate generalized Gaussian / exponential-power family 的固定形状特例：经典论文以 `g(t)=exp(−t^β/2)` 定义 MGGD，本候选对应 β=2 再作协方差重标定，不能把分布本身称作新 PE 原理。[Zhang、Wiesel、Greco 原论文，式(5)–(6)](https://arxiv.org/pdf/1304.3206) 广义 Gaussian 参数进入视觉模型也已有先例，CVPR 2019 的工作研究的是分布统计层，并非这里的矩形支撑读出，不能借其成绩证明本任务。[原论文页面](https://openaccess.thecvf.com/content_CVPR_2019/html/Wang_Deep_Global_Generalized_Gaussian_Networks_CVPR_2019_paper.html)

本次定向检索没有核实到与这里完全相同的“14维四次位置 logit＋native-cell 积分”先行工作，但一次检索的未命中不构成新颖性证明。有限多项式特征、广义 Gaussian 与数值积分均为既有工具；若后来成立，贡献只能落在明确的支撑参数语义、精炼实现与对强基线的可重复效果上。

建议仅先推进径向版本的解析/数值实现预检，固定 β=2、上述 a，不增加轴估计、形状指数搜索或内容门控。验证归一化/矩、原点与退化语义、矩形细分可加性、相对点式14维等价、梯度与实际算子成本。只有这些成立，才值得另立一个固定旧训练 cohort 的效果协议，和同 μ,C 的 Gaussian、full4、quad16及原 point 强对照比较；不能凭均匀方形的解析 KL 提前晋级。若平顶仍损害中心或轻尾损害区域真值，就停止该闭合，不继续堆补丁。
