## 要分清的三件事

当前新增写入图像大多也在 VGGT 的原生四帧窗口内，训练状态匹配虽改善 Soft 自身，尚未建立对旧 C 的可靠净收益。因此下一项应让记忆含有明确的窗口外信息，并分别判断：

1. 同样 256 槽，保留较早观察是否比从近期窗口重建更有用？
2. 这种历史用途在 Soft 中是否超过相同记忆、相同骨干的 C？还应保留旧 C，避免较弱的新 C 放大相对优势。
3. 若累计观测重建有效而逐步更新无效，瓶颈是否在更新和容量管理，而非位置公式本身？

假设是可用的窗口外信息能让共享场景记忆发挥作用。竞争解释包括早晚窗口观察区域不重叠、预测几何错误、256 槽压缩或更新丢失信息、冻结读取器不适应长历史，以及当前内容表征不能保留有用信息。负结果不能独立否定所有可训练的高斯记忆。

## 已有数据与因果边界

- 使用已经核对的 12 个非训练来源，每个来源的 `transfer_XX` 为早期 A 窗口，`fidelity_XX` 为后期 B 窗口；每窗 12 帧，共 288 张已下载 RGB。两窗互不重叠且有较大帧间隔，是稀疏两段历史，不称连续长视频，也不是新确认。
- 这 12 来源按成对窗口的可用性确定，不按得分筛选；它们是 51 地点中的旧子集，当前结果的相对改善在此子集更明显。因此下一轮不能代表全部 51 地点的历史用途，也不能当作独立确认；全部 12 地点均须保留。
- A 的初始化 0–3 和写入 4/6/8/10 构成历史。A 的查询 5/7/9/11 始终不写入。B 使用同样的初始化、写入和只读查询；主评价仅在 B 的四个原有查询上，当前原生四帧输入、遮挡、标定规则和标签保持。
- B 的四帧初始化由四图联合编码，只有 B 第 3 帧到达后才整体可用。将其作为一个初始化批次处理，不能伪装成 B 第 0 帧时已经得到后续三帧的信息。
- 使用原始位姿文件恢复两窗的共同坐标。以 A 的初始坐标和尺度作为整个场景的公共约定，对两个记忆条件保持相同；近期对照因此共享公共坐标／尺度约定，但不读取 A 的几何和内容槽。
- B 缓存观察转换到公共单位时，同时转换中心、协方差、相机平移及 patch 深度。若按共同单位重建原有观察构造，应先扣除原单位的 `0.005² I` 再缩放、旋转并加入公共单位的同一正则，不能直接拼接两个独立归一化窗口。
- 当前 B 的 VGGT 前缀和原生输出使用完全相同的四张图，可以按身份复用；只替换记忆与其查询相机坐标，不重新提取或改变图像输入。

## 固定容量的四种状态

| 条件 | 允许的观察 | 建立方式 |
|---|---|---|
| Recent-Corrective | 只有 B 初始化及当前查询前的 B 写入 | 在 B 开头重置，再用既有纠偏更新规则 |
| History-Corrective | A 的可写观察，加同一批 B 观察 | 保留 A 末态，随后继续更新，256 槽和近期 4 帧缓冲保持 |
| Recent-Prefix | 与 Recent-Corrective 相同 | 从截至当前的观察重建 256 槽 |
| History-Prefix | 与 History-Corrective 相同 | 从截至当前的观察重建 256 槽 |

Prefix 只作累计观察的重建参照，不能称在线定长记忆或严格性能上界。Corrective 延续原融合、冲突和替换规则，不搜索阈值；更长 source 索引必须有新的版本。旧更新函数有 `(4,6,8,10)` 的帧号检查，不能只扩宽 source 数组便假设它支持 24 帧。旧冻结实现不改动，新版本先在原 12 帧条件核对相同操作。

## 冻结读取器与比较

拟复用 C-static、Soft-static、C-dynamic、Soft-dynamic、Center-dynamic 五组各三个已有最终检查点，零新训练。所有模型读取上述同一组状态，沿用现有 Soft 公式、内容特征、相机投影和原生后半网络。Center 的既有条件训练必须先完成，下一轮不根据其结果另挑种子。

核心报告 History-Corrective 的 Soft-dynamic/C-dynamic 对照、两者各自相对 Recent-Corrective 的历史收益，以及这两个历史收益的差。旧 C-static 是固定的强用途参照；Native 和 L 的相同输入评分继续保留。静态训练版本和 Center 限定训练分布与形状归因，不把大量比较中最有利的一项换成主结果。

主指标仍为地点等权的混合原生 log-MSE，同时报告完整／遮挡、空间误差、偏差和各地点、各种子。沿用配对地点×种子区间，重视效应大小及方向，不要求所有辅助指标先通过，也不将单一区间跨零直接等同于毫无信息。

查询独立的几何诊断记录覆盖、来源保留与更新容量事件，用于辨别旧历史是否仍在状态中、是否投影到当前视野；不据这些结果筛掉不利地点。额外在 A 的末次完整查询上比较 B 到来前后固定读取器的输出，明确标注为回访遗忘诊断，不混入因果主成绩。第一 Soft-dynamic 种子的内容置换与均匀先验控制沿用既有定义，仅检验依赖。

约需 60 个小评价条件 × 12 片段 × 12 查询条件，共 8,640 份主预测，另加固定回访和依赖诊断；不新增训练或下载。数值检查只覆盖共同坐标、原算法复用、输入因果性和独立评分，并审阅固定案例与一个明确标注的反例。

## 结果将改变什么

- 若历史改善 Soft 的输出，且对旧／匹配 C 有可信增量，再固定方法做未用地点确认；形状用途依据 Center，不能只依据 Soft 这个名字。
- 若历史帮助 C 和 Soft 但没有可靠位置增量，认定历史内容有用，C 保留为强工作基线，不宣称高斯位置编码必要。
- 若 Prefix 有用而 Corrective 无用，优先改最小的更新／容量环节，不继续调位置先验。
- 若两者都无用，结合历史覆盖和遗忘诊断判定当前表征／读取的限制，结束该结构的细小修补。后续需要直接检验记忆是否保留可用信息，而非再增加静态位置项。

本草案不是本轮结论；采用前需结合 `state_read1` 的完整报告确认范围和工作量。

输入准备已进行，不代表采用本实验：`experiments/gaussian_memory_history_geometry.py` 提供公共坐标和观察协方差正则的转换、显式 source 宽度及同算法建槽。12 对窗口的 60 批已缓存观察通过往返与相机关系核对；原 12 帧输入的建槽输出与父实现逐张量相同。记录见 `results/gaussian_memory/state_read1/history_geometry_preparation.json`；没有读取新标签或运行历史预测。
