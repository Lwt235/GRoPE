# 当前高斯记忆读取的相关工作与证据边界

2026-11-11。在 `bound_read1` 正式训练期间补充核查。以下文献事实来自作者论文；“对本研究的判断”为本项目推论。它不修改本轮固定配置、评价或条件规则，也不是全面新颖性检索。

## 已核查的四条路线

| 工作与固定版本 | 论文中的记忆／读取 | 对本研究的判断 |
|---|---|---|
| [M3，arXiv:2503.16413v1，§3.3 与附录 A](https://arxiv.org/html/2503.16413v1) | 高斯渲染低维 query，再以 attention 从保留原始高维特征的 PSC bank 重建特征；优化静态场景的高斯与查询属性。 | “高斯＋memory＋attention”已有先例。本轮是当前 VGGT token 查询高斯槽，几何支持进入对应槽的 attention bias，且需跨地点验证；这一结构区别不自动构成新颖性或效果证据。 |
| [StreamVGGT，arXiv:2507.11539v1，§3.2–3.3](https://arxiv.org/html/2507.11539v1) | 将 VGGT 的全局交互改为时间因果 attention，推理缓存历史 K/V；训练在因果结构中进行，并以双向 VGGT 蒸馏。 | 原生几何输出与历史内容缓存都是必要参照。冻结骨干的一层适配和完整因果模型训练不同，不能直接引用论文结果替本项目证明迁移性。 |

| [XStreamVGGT，arXiv:2601.01204v1，§3](https://arxiv.org/html/2601.01204v1) | 通过重要性裁剪和 K/V 量化压缩缓存，并保留初始与当前帧参照。 | 固定预算本身不是高斯的独有优势。未来若要提出紧凑场景状态的贡献，需要相同存储预算的普通 token/KV 记忆，而非只和无限增长的原始缓存比较。 |

## 本轮究竟能证明到哪里

本轮 [固定计划](gaussian_memory_bound_read_plan.md) 中，A/B 共享历史内容、参数量、训练样例、覆盖与 null 质量，仅比较均匀覆盖先验和逐槽几何先验。它能够检验“给定这份记忆，空间对应是否帮助内部读取”。内容置换与先验替换检查依赖性，匹配训练的 A/B 才承担比较用途。

L/C/A/B 都没有比较“高斯聚合状态”和“相同预算的普通历史 token 状态”。C 的内容本身仍来自相同高斯槽；即使 B 胜过 C，也不能宣称高斯压缩优于 token 缓存。Center 若触发，只检验形状与投影足迹的联合增量，也不解决记忆表征优劣。

动态评价能够显示固定读取器是否利用已有增量状态。静态训练与动态评价的分布差异仍未隔离。如果静态 B 获益、动态收益却缺失，下一项有辨别力的候选是固定结构与 writer，只改变训练时提供的状态分布；这比同时添加 writer、尺度模块和注意力层更容易定位原因。该候选尚未启动，须等本轮结果。

## 对后续选择的约束

1. 先完成当前固定结果与反例。论文不作为临时修改主指标、补模块或掩盖负结果的理由。
2. 若逐槽读取有可靠开发用途，先固定结构，再在“动态训练匹配”与“同预算普通历史记忆对照”中，按实际最重要的缺口选一项；不同时铺开。
3. 若 B 仅依赖几何却不胜过 A/L，就只得到机制信号。不能用已有论文的成功替代本项目的负结果，也不能只改称“新位置编码”绕过用途。
4. 若最终讨论紧凑存储，应计算全部持久状态、历史缓存和临时 attention 代价，并给出质量—预算权衡。单独统计 256×32 内容或缓存后半网络时延不够。
5. 未知相机、长序列、动态场景与一般 Transformer PE 仍不在本轮证据范围内。后续每项扩展要有明确对照与独立数据身份。

本轮结果入口仍为 `results/gaussian_memory/bound_read1/`。历史正负结果和原研究主线保持不变。

## 单种子现象引出的设计备选：可见性与信息相关性

2026-11-11 补记。首个完成评价的种子 20261112，在主 51 地点上 B 对 A 的主误差低 1.49%，但比 C 高 5.50%；A 比 C 高 7.10%，B 的去均值空间误差也更高。仅为单种子现象，详见 `results/gaussian_memory/bound_read1/interim_static_20261112.json`；其余种子、干预和动态评价尚未齐备，不能据此晋升或否定整个方法。

**待检验解释：** 渲染支持适合表示直接可见性，但将它作为读取的硬限制，可能同时阻止了有用的非局部历史信息。预测几何噪声、训练覆盖不足与优化敏感性仍是竞争解释，现有结果没有把它们分开。

若完整结果保留这一模式，可以考虑一个不新增模块或参数的备选位置项。对 M 个记忆槽，令原来的合成权重为 w_ij，给内容 logits 加：

```text
b_ij = log(1 + M * w_ij)
score_ij = q_i · k_j / sqrt(d) + b_ij
```

该备选对所有真实槽保留内容读取，null 槽与 C 一样屏蔽。它等价于将均匀先验 `1/M` 与几何权重 `w_ij` 相加后用于 attention；逐行常数在 softmax 中抵消。以下是代数性质，不是实验效果：

- 零覆盖时 b=0，精确回到 C 的无几何读取。
- 只保留均匀覆盖 `w_ij=a_i/M` 时，b 对每槽相同，也回到 C；因此额外作用来自具体空间对应，而非覆盖数值本身。
- `0≤w_ij≤1` 时，位置加分在 `[0, log(1+M)]` 内。没有槽因零几何支持而被永久排除；内容仍可选择不在直接投影范围内的信息。
- 沿用原 Q/K/V、输出层、几何缓存与 writer；这里只是对同一权重的另一种位置项解释。参数量可保持一致，不把形状协方差重新解释成预测不确定性。

**这不是已定稿的下一轮实验方案，也未启动训练。** 它是一项由首个结果提出的设计备选，不声明新颖性或有效性。先完成本轮三种子和条件分支，再判断该解释是否仍重要；若执行，另行固定同预算 C/L/B 对照、样例配对、形状控制及结果将改变的决定，依据已有自主授权推进。不能用该备选抹去当前硬先验的负结果。

这里的“零覆盖”指已有非空历史记忆没有直接投影到该 token；它不同于“根本没有历史记忆”。备选式保留前一种情况下的内容读取，不定义空记忆的数据结构或读取行为。

同一种子的动态评价也已完成：[中期动态结果](../results/gaussian_memory/bound_read1/interim_integrated_20261112.json)。主 51 地点 B 的 Static/Corrective/Prefix 主误差为 0.284686/0.288238/0.305726，即更新后分别高 1.25%/7.39%；A 则为 0.288997/0.285932/0.285955，约低 1.06%/1.05%。B 的 Prefix 退步在该种子的地点配对区间内方向明确，Corrective 主比较区间跨零。固定结构的读取对状态变化可能敏感，但不能从一组结果区分几何误差、内容分布变化与静态训练分布不匹配。原定动态三种子、干预和条件分支继续执行。

补充的[缓存支持诊断](../results/gaussian_memory/bound_read1/support_diagnostic.json)在读取统计前保存了假设、竞争解释、固定范围与决策边界，未修改本轮主实验。主 51 地点等权下，查询视图平均 35.84% patch 的覆盖恰为零，每 patch 平均仅 6.19/256 个槽具有正几何权重；有覆盖时，归一化真实槽先验的熵有效槽数平均为 4.21。训练 12 地点的零覆盖比例为 17.44%，平均正权重槽数 7.37。它们是内容 logits 之前的几何先验统计，不是已学到的 attention 分布，更不能证明被排除的槽有用。零覆盖会使该 patch 的直接记忆残差为零，但其他 patch／视图仍可经后续原生网络影响其预测；不能称整个输出与历史完全无关。

第二个已完成静态评价的种子 20261110 并未重复 B/A 的改善。[两种子中期汇总](../results/gaussian_memory/bound_read1/interim_static_two_seeds.json)中，主 51 地点 L/C/A/B 为 0.289751/0.266059/0.285506/0.285693。B 比 C 高 7.38%，两个种子均退步；A 比 C 高 7.31%，也是两个种子均退步。B/A 的配对方向相反、主均值近乎持平，B/L 平均改善 1.40%但地点×种子区间跨零。C/L 平均改善 8.18%，两种子同向。它进一步支持检查“几何限制的代价”，但第三个种子尚未完成；此处没有触发条件控制或选择新模型。

两种子在训练 12 地点的 B/C 误差为 0.005900/0.006351，B 平均低 7.11%、两种子同向；非训练地点的方向相反。模型能够拟合这些几何对应，尚未形成可靠迁移收益。它不排除训练数据规模、覆盖差异与几何噪声等解释，不能将问题全部归为硬先验一个因素。

首个固定种子的[全部绑定干预](../results/gaussian_memory/bound_read1/intervention_analysis.json)已完成：训练地点 B 为 0.005893，内容置换／均匀覆盖先验替换后为 0.128133/0.128127；主 51 非训练地点 B 为 0.286699，两干预后为 0.279129/0.279005，平均反而低 2.64%/2.68%，两项地点区间均跨零。因此可以说训练模型依赖对应关系，不能说这种依赖已被证明对迁移有益。BF16 完整后半网络的联合置换最大／平均输出差为 0.032079/0.002296，不能报告为严格数值相等；已准备一个固定样例的 FP32 复核来界定该差异，不把它升级为新的科学门禁。

该[固定样例的 CPU FP32 复核](../results/gaussian_memory/bound_read1/precision_diagnostic_cpu.json)现已完成：联合置换最大／平均差为 6.68e−6/1.18e−7，只置换内容的最大／平均差为 0.8903/0.1323。它支持逐槽对应实现正确；相对 BF16 GPU 同时改变了精度和执行后端，未单独隔离精度的贡献。三次 CPU4 前向合计约 14.23 秒，无新增训练、主评分变化或数值门禁。

[两种子动态汇总](../results/gaussian_memory/bound_read1/interim_integrated_two_seeds.json)中，B 的 Corrective/Prefix 相对 Static 分别高 1.23%/5.37%，两种子均为退步，混合主指标的地点×种子区间跨零。A 的动态方向混合；更大覆盖仍没有稳定转化为原生用途。完整三种子结论继续等待最后一个 B 拟合及评价。

另按来源身份选出当前训练三个 SUN3D 序列中的九个其他片段，RGB 路径与该三训练片段均无重叠，再读取其既有预测。[两种子同序列诊断](../results/gaussian_memory/bound_read1/same_sequence_diagnostic_two_seeds.json)中，其他片段 B/C 为 0.328266/0.325020，差约 1%、种子方向相反；B/C 对 L 均有改善，但两者均未优于原生均值 0.320260。该三训练片段自身 B/C 约为 0.008356/0.008056。极低拟合误差没有直接延伸到同源其他窗口，但这个落差不是 B 独有，只有三个来源也不足以建立总体机制结论。每个窗口重新建立其 M0，这不是同一记忆读取更远视角的测试；全部均为已用数据，不构成新确认。
