# R73：当前五维关系在原生优化 3DGS 上的直接开发验证

2026-11-04。R69 的五维关系在观测区域匹配上有正面证据；R71 给定几何
图像任务通过开发标准，R72 RGB 版本为混合结果。这些都不能代替直接使用
优化 3DGS 参数的检验。R65–R67 失败的是其他版本，当前五维尚未直接训练。
本计划不依赖正在进行的新 SUN3D 确认的得分，也不读取其结果来选择设计。

假设：去掉 R65 关系输入中重复的两端绝对谱，保留五个中心/形状相对量，
可能在相同完整内容下更容易学习有用的原生高斯关系。竞争解释包括：
普通距离已足够、完整内容已提供可利用的形状，以及优化基元的协方差对
对象语义关系存在干扰。失败只能限制本设计，不能证明任何高斯 PE 都无效。

## 唯一结构变化与固定比较

直接复用 `models/round69_compact_relation.py` 的 `CompactPosition('relative5')`，
即距离、双侧 Mahalanobis 二次量、双侧协方差 trace 相容量，共五维，
`5 → 96 → 96`，GELU，末层无偏置。仍是一个 MLP，以 q·r/sqrt(48)
加入原 R65 四层自注意力。共享层构造顺序与初始化逐种子匹配。

其他部分原样复用 R65：原生中心/协方差/opacity/DC 的完整 13 维内容，
96 宽、两头、四层骨干、同池化分类头，不添加相机、渲染、预测几何、辅助
损失或分组模块。保留固定距离尺度 .2 与共同 covariance floor 1e-8；
不扫描形状尺度、温度、频率或训练时长。

只新增 relative5 的种子 11/22/33 三次训练。复用 R65 已选定并完整审阅的
Distance、Direct、Center RoPE、NoPE、full11 五组，不重计为独立新证据。
复用按数据、源码、checkpoint、输入流与选择身份核实，不按本轮结果重选基线。

## 数据、预算与选模

使用已有 GSModel60 官方 TRAIN 7,757 对象/60 类的原 R65 缓存：
6,227 fit / 765 val / 765 dev_eval。这些都是用过的开发数据，官方 TEST
保持未用。真实优化高斯逐基元输入，不能替换成合成 patch 或观测二阶矩。
原来源版本、样本身份、缓存采样、13 维内容、协方差重建与归一化完全不变。

原 R65 120 epochs、batch16、512 tokens、46,800 updates、AdamW、学习率
.001→.00001、五 epoch warmup、label smoothing .1、完整 SO(3) 旋转和
固定 center jitter 不变。同种子实际 120 个 epoch 的对象/基元/增强输入流
须与原 Distance 匹配。验证 CE 每五 epoch（含 0）评价，最早严格最小值选模。
三个模型全部选定后才导出 dev_eval；不按 mCA 或某个扰动重新选择 epoch。

## 判断与完整报告

主指标继承 mean-class accuracy，报告 OA、CE、每类/来源、三种子。
六条件固定为 base512、sparse256、dense1024、jitter02、tilt、permuted，
始终使用相同对象。旋转已见于训练，不称为旋转分布外迁移。

开发用途条件继承 R65 的实用尺度：对 Distance、Direct、Center RoPE，
base mCA 三个配对种子均改善、平均至少 +0.5 pp、配对类别 bootstrap
95% 下界为正。NoPE 与原 full11 同时完整报告；不能只胜弱基线就晋升，
不能把较低 CE 改称主准确率成功。类别区间不代表种子总体置信区间。

若通过，说明当前五维在原生基元上也有值得确认的用途，再核对稀疏/密度等
边界并制定未用数据确认；不自动完成总体目标。若不通过，就保留本设计的
原生任务限制，并结合观测区域和投影结果重新评估其作用条件，不延长训练、
删类别或改门槛救分。未使用场景确认无论通过与否都不能覆盖本轮负结果。
