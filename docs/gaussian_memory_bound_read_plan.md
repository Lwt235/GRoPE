# 高斯几何与内容绑定的内部读取：事前计划

2026-11-11。承接 `incremental_vggt1` 的完整结果；本文件制定时尚未启动本轮训练。用户已授权持续自主研究，普通实验选择无需再次确认。

## 1. 本轮只解决一个缺口

上一轮 12 次内部训练完成：CG 与仅历史内容 C 的主误差几乎相同（0.272292/0.272118），新增覆盖没有变成稳定的原生输出收益。当前几何 Q/K 通路与内容 cross-attention 平行；固定几何、单独置换内容槽不改变结果，所以没有逐槽空间寻址。接口可训练与 attention 确实改变已验证，不继续围绕微小数值差异加门禁。

**假设：** 将每个高斯的投影支持作为“当前 token—该高斯内容”的相对位置项，可以让内部 Transformer 使用空间对应，而非只读取一个无序历史内容集合。

**竞争解释：** 覆盖门控本身就能解释收益；历史内容无需空间对应；预测几何/尺度太噪；小训练集迁移不足；静态 M0 训练和动态状态评价存在分布差异。绑定是一个有结构依据的解释，不预先认定它是唯一病因。

本轮替换几何注入的位置，固定初始状态、观测来源、插入层和更新器。此前外部 Content Gaussian 的正面证据保留，但不能替代新内部接口的比较。

## 2. 方法：一个带几何位置项的 memory cross-attention

保持原 VGGT 第 12 个 global block、原生二维 RoPE 和其余冻结网络完整。在该 block 输出后，仅保留一个 width64、4-head 的内容 cross-attention 残差，随后通过原生后续层和 DPT。每个 patch token 的 Q 为当前内部特征，256 个高斯的 32 维内容产生 K/V。

沿用上一轮的投影：给定相机，中心和形状协方差决定二维覆盖；3σ 截断、0.1 patch 方差模糊、opacity=0.7、前到后 alpha 合成均不变。对 token i 和高斯 j，令：

```text
w_ij = alpha_ij × product_(k before j)(1 - alpha_ik)
T_i  = product_j(1 - alpha_ij)
a_i  = sum_j w_ij
score_ij = q_i · k_j / sqrt(16) + log(w_ij)
score_i,null = log(T_i)
r_i = W_out × sum_j softmax(score_i)[j] v_j
```

权重从深度排序顺序恢复到原高斯槽身份，必须与 K/V 指向同一个槽。零权重的 log 为负无穷；额外 null slot 的 key/value 均为零，不增加可学习参数。空覆盖时只有 null 可选，输出为零；不把极小覆盖归一化成强记忆。

`W_out` 无偏置、零初始化，空记忆残差严格为零。所有组同样使用 token/content LayerNorm 和 Q/K/V 映射，参数量为 **137,472**。移除上一轮新增的 A/B 自注意力 Q/K 映射；没有额外位置 MLP、writer、损失、温度扫描或层号扫描。这里的 PE 是 token 与记忆槽之间的几何 attention bias；不是把投影内容向量重新命名为 PE。形状协方差仍表达区域范围，不表示位置不确定性。

## 3. 四组匹配训练

| 组 | K/V 内容 | 256 个槽的先验权重 | null 权重 | 回答的问题 |
|---|---|---|---|---|
| L | 同一短窗口池化的局部内容 | 1/256 | 0 | 容量匹配的短窗口对照 |
| C | 初始 M0 历史内容 | 1/256 | 0 | 无几何的历史集合读取 |
| A | 同一 M0 历史内容 | a_i/256 | T_i | 只知道覆盖、不知道对应哪一个槽 |
| B | 同一 M0 历史内容 | w_ij | T_i | 高斯几何与内容逐槽绑定 |

A 与 B 共享完全相同的逐 token 覆盖和 null 权重，因此 B−A 是核心绑定比较；B−L 检验实际用途，B−C 反映整体几何条件的增量。A−C 解释覆盖门控的作用。L 没有历史几何输入，不能将它称为同信息的几何表示对照；A/B 承担这一比较。

四组均重新匹配训练。旧 L/C/CG 含不同适配结构，只作为历史结果，不混入本轮容量匹配主表。原生 VGGT 基线可原样复用，因为 RGB、前缀缓存、尺度与原生网络完全不变。

## 4. 固定评价与判别

主指标仍为 51 地点等权的完整/遮挡混合原生 log-MSE，报告 B−A、B−L、B−C、A−C 及原生参照。三种子、地点配对区间和分批结果同时呈现；完整输入、隐藏区、可见区、去均值空间误差与均值偏差分列。不能只根据单个最好的种子或均值晋升方法。

首个固定 B 种子增加两项零训练干预，覆盖同一批全部查询：

1. 固定几何和覆盖，仅在每片段内以固定种子置换内容槽，破坏对应关系。
2. 将 B 的先验替换为 A 的均匀覆盖先验，保持该模型权重与覆盖不变。

二者只用于检查模型是否依赖对应关系；分布变化也可能造成损害，不能单凭干预下降宣称收益。A/B 的匹配训练才是主证据。联合置换几何与内容的等价性用固定样例检查，不对全部数据重跑同义评价。

如果 B 对 A 的主均值改善，且至少两个种子改善，追加 **B-center** 三次匹配训练：同内容、中心和 opacity，协方差替换为上一轮仅训练数据确定的固定球形方差。相同 alpha/null 计算保持不变。此控制同时改变形状描述/足迹，只支持二者整体作用，不能单独称各向异性必要。该条件是诊断资源分配，不是要求置信区间先通过才允许实验。

决定：

- B 胜过 A、C、L 且没有相当量级的完整输入代价，绑定干预与结果一致：固定此精炼接口，结合 Center 判断形状是否值得保留，再制定未用地点确认。
- A 与 B 接近、均优于 C：覆盖门控更可能是主要来源，保留更简单的解释，逐槽位置项尚无额外依据。
- B 只胜过自己的消融、仍不如 L 或原生模型：只有局部机制信号，不晋升为可靠方法。
- 各组主结果接近或迁移失败：记录这一接口的限制；根据空间误差与尺度/训练地点差异选择下一项有区分力的诊断，不自动添加模块或补种子。

## 5. 动态状态读取与条件纠偏复测

核心训练完成后，A/B 三种子固定权重读取上一轮保存的 Static4、Corrective、Rebuild-prefix 状态；共用全部因果观测，不重新拟合，不修改更新器。报告四个因果查询与分条件原生输出、覆盖以及成本。这一评价无须等待静态主比较获胜，能独立判断更明确的空间读取是否让已有积累信号变得有用。

若 B 同时相对 A 和 L 主均值改善、且两项均至少两个种子改善，再对首个 B 种子复用既有全部 ±20%/±5% 状态轨迹，完成普通平均/纠偏/静态的原生输出、固定受扰区域和早期视角回访。仍仅属单模型机制诊断。未触发时保留上一轮纠偏负结果，不宣称新读取器已通过纠偏验证。

即使投影空间绑定成功，也不等于已学会几何写入。动态读出失败仍可能来自静态训练状态分布；是否进行动态状态匹配训练由本轮结果决定。
