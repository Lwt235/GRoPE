# 与分布位置编码相关的新文献边界

检索日期：2026-10-30。以下是原始文献报告，不是本仓库复现实验。

[POD-RoPE v2](https://arxiv.org/html/2610.33745v2)（2026-10-28 修订）把
相机中心、视线与时间构成的观测覆盖表示为分布，并预聚合期望旋转。
它还以旋转相干度连接恒等映射和旋转，将同一统计用于 V/O。其消融中，
直接平均旋转作用于 V/O 反而弱于仅 Q/K，而带恒等分支的构造更好；
不同任务相对强对照的结果并不一致。该工作表明“分布 RoPE”与
“分布同时指导匹配和聚合”都已有明确先例。

[WorldRoPE](https://arxiv.org/html/2610.16337v1) 已将体积高斯支撑投影后的
期望旋转用于跨视图 Q/K，附录 A.7 还用其变换 V、再对输出反向旋转。
其附录报告该环节的消融。不能把给 V/O 加几何变换本身宣称为本项目原创。

对本项目的影响是限定创新解释、提示检查实际 V 路径；两篇论文均不能
替代本项目的实际 V、GS/RGB 与独立泛化验证。当前 R15 固定区域积分算子、
已冻结八族校准及门槛均未更改。后续若考虑 V 设计，必须先解释与这些方法
及已记录的条件高斯方案有何实质区别，并用同信息、同训练预算的强对照验证。
