# R17 Stage A：trace 条件内容强度的 TRAIN 定位可行性

Stage A 已完成并经独立审计接受。固定候选 `trace_full` 的 7 个可行网格索引为 **[1, 2, 3, 4, 5, 6, 9]**，对应 `(h,T)=(.25,5),(.25,10),(.5,0),(.5,5),(.5,10),(1,0),(2,0)`。这允许继续完整 Stage B 区域校准；**没有选定最终主配置，没有授权旧 VAL，也没有通过最终科学效果门槛**。[接受决定](/home/liwt/GRoPE/results/round17_feasibility/decision.json) 中 `primary_selected`、`validation_authorized`、`scientific_gate_passed` 均为 false。

本报告只解释已经接受的 Stage A，不读取或引用正在进行的 Stage B 区域结果。数值正确、TRAIN 中心定位可行、一般性科学效果是三个不同结论；本阶段提供前两项的限定证据。

候选保留原 Gaussian full1 的 μ、C、原生矩形积分和密度底值，仅将内容项强度改为

`τ = T h² / (h² + tr C)`，`p = softmax(log[mass_Gaussian(C+h²I) + 1e−30×area] + τ×content)`。

C 使用预测像素支持在 8px 参考坐标中的协方差，包含像素足迹与位置散布；它不是传感器真值、已校准的不确定度或已优化 3DGS primitive 的参数证明。Gaussian 积分沿用固定 GL32，24px key 保持既定积分子矩形，质量合回原生 key 后只加一次面积底值。τ 用已冻结的 double 缩放等价算式计算后转回 C 的 dtype；实际内容项执行 `tau32 * content32`，随后转 double 加几何 log mass、做 double softmax。C=0 精确回退原点核内容运算；T=0 时内容耦合不生效，不能把该配置的效果归因于新 τ。

数据是原开发 TRAIN 的 c3/c5/c6 三场景，各 16 对、共 48 对；固定 q8/q16/q24→432 个原生 g8 keys，完整 h∈{.25,.5,1,2}、T∈{0,5,10}。只新增 1,728 个 `trace_full` float64 概率数组；两个点族的 3,456 个原始数组复用已接受 R15 Stage A，连同旧源、输入、标签及独立接受链绑定。本轮独立审计重新读取全部 5,184 个数组并重算其中心计数。新候选三场景完整前向、哈希封存后才解码已有 R13 中心标签；前向只读四个预测几何/RGB字段，没有用传感器或区域 histogram/counts。

PCK8 使用原生 key 概率 argmax 的物理中心，距独立传感器投影的 query 中心≤8px 判正确；并列 argmax 取首索引。场景内合并正确/有效中心整数计数，再对三场景等权；全局点参考的配置选择再对三个尺度等权。有效中心总数分别为 q8=9,521、q16=2,463、q24=1,096，所有配置共享人口；这里的总数不是将三个场景改成按人口加权的依据。无效中心不计作错误。
