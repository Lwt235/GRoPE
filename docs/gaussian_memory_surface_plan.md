# 共享高斯场景表面的联合写入与 attention 读取：surface1

2026-11-10，结果产生前制定。沿用导师“网络能否记住场景几何”的方向；结束末层 token 蒸馏的逐项修补。此轮的粗深度是检验共同空间状态的探针，不是新增渲染任务，也不以达到深度估计最优精度为成功条件。

## 问题与竞争解释

假设：参考 RGB 写入的 256 个高斯及其内容，经共享写入器与一个 cross-attention 读取器联合学习，可以帮助当前视图恢复同一场景的表面；这种用途能够迁移到未参与本轮训练的地点。竞争解释是单视图特征已经足够、仅固定的 VGGT 初始几何有用，或中心位置足够而高斯形状无额外作用。旧 token 任务负结果保留，不把本轮当作对旧结果的追溯性解释。

## 明确的信息边界与结构

- 四参考 RGB、已知相机、冻结 VGGT 的参考专用初始几何与特征，写成 256 个 `(均值, SPD 协方差, opacity, 32维内容)`。沿用原型的 GaussianWriter，从同一零残差初值训练共享网络；不逐场景优化参数。
- 当前视图的冻结 S1 token 与相机作为 query。复用相同 RGB 遮挡输入，不把完整查询或传感器深度送入写入器。当前视图只读场景状态，不回写。
- 一个 64 维、4 头 cross-attention：Q 为当前 token/相机，K 为高斯内容及相机坐标几何，V 为内容和中心的对数米制深度；位置项分别为中心距离或完整投影协方差的二次型。沿用已验证的 gsplat 投影规则。读取结果加到局部分支，由一个线性头预测对数米制深度。没有额外融合网络或额外损失。
- 所有方法都获得相同查询相机与参考尺度信息。每次评估先保存记忆，再由保存的记忆、查询 token 与相机读取，保留写入—保持—读取的可检查边界。
- 监督是 SUN3D 的查询传感器深度：按最近时间戳匹配，最近邻缩至 210×280，每个 14×14 patch 对 0.1–10 米有效样本取中位数，有效比例至少 1/2 才评分。目标是相机射线上的场景表面；给定相机后可变换到共同三维坐标。缺测不填零、不筛除困难场景。传感器只进入训练标签及评分/固定对应关系诊断。

## 固定比较、预算、评价

四组，各三个种子 20261110/11/12，各固定 2000 步、batch=2、AdamW 3e-4、weight decay .01、梯度裁剪5；以有效 patch 对数深度 MSE 训练，每查询等权。无需下载新数据。

1. **Local**：只有当前视图的 MLP，宽度按总可学习参数与完整写入—读取模型近似匹配。
2. **Fixed**：固定初始均值/协方差，仍联合学习内容、opacity 与高斯 attention 读取器。
3. **Center**：联合学习写入和读取，注意力使用中心距离；K 仍可访问协方差。它是形状位置项的强对照，不能称完全不含形状。
4. **Gaussian**：联合学习完整高斯写入与协方差位置项。与 Fixed/Center 所有共同参数初值、训练样本顺序完全配对。

固定原 coverage1 的十二训练地点各一个片段、72 查询/288遮挡样本。评价原46片段的288查询/576遮挡样本及相同完整查询；主评价仍是十二非训练地点的两批片段，按地点合并，再跨三个种子配对。所有地点均为历史开发数据，不称新确认。保留训练片段留出视角、旧训练地点其他片段及剩余开发地点的结果。

主指标为所有有效 patch 的对数深度 MSE，另报遮挡/可见区域、米制 RMSE、AbsRel 与完整输入误差。场景和种子配对 bootstrap 只描述这批历史数据的不确定性，不充当普适性门禁。按预定真值几何对应检查两个视图的三维预测误差一致性；它与准确率联合解读，因为常量预测也可能一致。

记忆诊断固定为移除、替换成另一地点的记忆、只打乱内容与空间的绑定、恢复初始均值/协方差、错误查询相机；另给初始几何的无训练读取和训练标签均值基线。不再把“打乱后下降”单独当成超过 Local 或形状对照的证据。保存梯度、写入变化、训练曲线和正负例图。

## 结果改变的决定

- Gaussian/Center 稳定超过 Local，且正确记忆/空间绑定有用：支持此条件任务上的共同空间记忆，可进一步研究更真实的 VGGT 接入；还不支持未知位姿、长序列或一般 PE 优越性。
- Gaussian 超过 Fixed：支持学习几何写入的增量；否则只保留已有初始几何/内容读取的用途。
- Gaussian 超过 Center 才讨论形状位置项的增量；Center 相当或更好则保留中心读取，不添加形状模块追分。
- 只有同片段收益或均无稳定增量：结束这个固定原型，明确写入/读取的局限，不加种子、改权重或挑场景挽救。下一步根据实际失败位置提出新的可区分问题。

正确性检查限于数据与相机/单位匹配、查询与标签边界、初值与样本配对、有限梯度、独立评分及保存状态回放。常规实现错误先记录版本再修复；它们不是科学负结果，也不另设一轮研究。
