# 方向无关平均精度：一项匹配控制

2026-11-07。用户恢复自主研究目标，并已讨论本轮与 M/S 四组实验的区别。上一轮实际审阅完成：M 保住了区域用途，却未保住原生分类收益；S 未支持一般替代。当前保留 relative5，不把开发数据上的局部成功称为一般有效。

## 假设、竞争解释与固定表达

假设：平均大小与平均精度已能保留主要用途，显式方向耦合可能不是必要的。竞争解释：区域匹配需要位移方向与高斯轴向的联系，原生分类需要两组方向关系共同作用；也可能两任务依赖不同信息。旧 T 控制将大小相同的椭球换为球体，同时改变平均精度，因此它与 F 的差不能纯归因到方向。

新增唯一版本 Q=`mean_precision5`。记 δ=μi−μj、d²=δᵀδ、ri=tr(Σi)/3、hi=tr(Σi⁻¹)/3。五输入为普通距离 ||δ||/0.2，加以下四量的 log1p：

\[
(h_i d^2,\ h_j d^2,\ 3h_i r_j,\ 3h_j r_i),\quad i\ne j.
\]

只对 PE 的不同 token 关系去掉方向残差。**i=j 时保留原始自关系：两个位移量为 0，两个协方差量为 3。** 直接沿用上述乘积会把自关系从 3 变成 3hi·ri，新增强度随各向异性变化的自注意力项；这不是此次要检验的变化。同一 token 也不能相对自身独立旋转。此选择在训练前固定，不另试不保留对角线的版本；不同但几何重合的 token 仍按 i≠j 处理。

在 log1p 之前，非对角公式等于相应原始二次/迹量对均匀方向的平均；不是原完整 PE 或注意力经过非线性后的期望。保留的 r、h 不是完整特征谱，也不能由一个球形协方差同时表达。F−Q 检验方向相关残差的联合额外用途，不是证明某一种相对朝向为唯一原因。共同内容仍含完整协方差，不能声称整个模型不使用方向。

使用同一 5→96→96 GELU MLP（9,792 个 PE 参数），保留全部参数初始化与 RNG。精度矩阵采用现有 FP64 求逆，协方差 floor 不变，不增加可学习系数或模块，不使用关系投影重排。成对公式较简单，但本轮不预先宣称实测加速。

## 数据、拟合和比较

两任务、种子 11/22/33，共 **6 次新拟合**。区域沿用 576 fit / 64 val / 480 dev 对、64 tokens、60 epochs / 1,080 updates；原生沿用 6,227 fit / 765 val / 765 dev 对象、512 tokens、120 epochs / 46,800 updates。优化器、增广、采样流、参数量及共同内容匹配原 F。区域按原 selection_ce（两方向等权），原生按原 ce 选模；六模型全部选定后再导出开发预测。

复用已选定 F、T、M、S、Distance、固定球形的预测与权重，不重选。区域保留 base/sparse256，原生保留 base/sparse256/dense1024/jitter02/tilt/permuted；60 类头不变。总计 **24 组新预测、144 组旧预测、168 组预测**。不下载新数据、不读取九场景或官方 TEST 的新分数，其已用状态保持不变。

固定比较顺序为 **F−Q、Q−T、Q−Distance、Q−固定球形、Q−M、Q−S、F−Distance**。前四项是解释和决策重点，后两项与上一轮直接衔接，最后一项保留强对照背景。区域按场景宏 R@1、原生按类别宏 mCA；两个任务分别判断，不用合并平均隐藏冲突。

区域同时报告中心 PCK、hard/soft EPE、CE、五场景、原四分组及高/低中心歧义组；原生报告 OA、CE、逐类别及 MACGS/ModelNet 来源。保留纠正/新增错误、种子反转及按 ID 排序各方向前八个稳定案例。没有要求所有子组同号。

沿用配对种子×场景/类别的 10,000 次描述性重采样，基础随机种子 **83001**；先区域条件/比较/分组，再原生条件/比较递增，共 **112 项比较，种子 83001–83112**。保留仅种子与仅场景/类别区间，共 56 组错误分解。本轮不新增四组交互量，不改变统计规则来适配结果。

## 不同结果会改变什么决定

- 若 Q 相对强 Distance 保住主要用途，且对 F 的损失在预定 1 pp 工程参考附近或更小、中心/OA/CE 与扰动没有明显冲突，则支持继续研究方向无关的精炼表达；仍需适用的新数据确认，接近均值或区间跨零不等于正式等效。
- 若 F−Q 有明显且较一致的优势，保留方向关系，结合 Q−T 判断平均精度是否也提供额外价值；不据此立即堆加模块。
- 若两任务或种子混合，明确保留边界。Q−T 的局部改善不能替代 Q−Distance，1 pp 只是工程解释参考，不能自动晋升、否决或替代区间与实际幅度。
- 无论结果如何，不追加种子或预算挽救本轮，不覆盖既有原生主确认不确定性、RGB 与直接迁移负结果。任何推进决定在完整结果审阅后作出。

## 检查与执行

检查独立标量公式、球形极限、自关系、刚体与置换对应、每个协方差独立旋转时的方向不变性；用有限立方旋转群核对原始量的方向平均。核对两任务三种子的全模型初始化/RNG、共同内容和非零有限 PE 梯度。用人工已知成绩检验全部比较方向、分组和固定统计种子，不为微小尾数建立新门禁。

冻结实现、计划、检查结果、数据清单、缓存和六组既有模型/预测身份。真实旧 fit 批次的 CUDA 预检通过后训练。最多六个单卡任务、每卡一个，优先空闲 GPU；按已有授权最多共享两卡，启动时至少 20 GiB 空闲，单任务 PyTorch 分配上限 16 GiB。启动前两次占用观察及 CUDA 检查，保留其他用户任务。普通执行修复保存版本化失败记录，不另立科学轮次。

预测完成后做独立指标复算、实际图表和科学结果审阅。实现正确、旧数据机制证据、下游用途与未用数据确认分别记录，不自动宣布总体目标完成。
