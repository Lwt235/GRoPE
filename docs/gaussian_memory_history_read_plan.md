# 窗口外历史信息：history_read1 固定计划

2026-11-11。`state_read1` 的九次匹配训练、全部评价、独立评分和六幅图像审阅已完成，现采用本计划。制定时未运行任何长历史预测。只改变允许进入记忆的历史范围与建立策略，复用全部固定读取器，不新增训练或调整位置先验。

## 问题、假设与竞争解释

`state_read1` 中，Soft-dynamic 对新 C 的主误差平均低 2.58%，但对旧 C 仅低 0.42%，两项地点×种子区间均跨零；完整高斯对 Center 仅低 0.13%，种子方向混合。更新记忆仍未稳定改善输出。当前前三个查询的新写入图像全部存在于原生四帧窗口内，末次仅一个新增写入帧在窗口外。

因此停止该读取器的静态先验和训练状态修补，检验一个不同的问题：**当记忆包含明确的窗口外观察时，同样容量的高斯状态是否更有用，几何读取是否比纯内容读取更能利用这些信息？**

假设是较早、可用的场景信息能够帮助后续视角，而高斯空间组织有助于选择相关内容。竞争解释包括两段历史观察区域不重叠、预测几何错误、压缩或更新丢失信息、冻结读取器不适应长历史，以及内容表征不够有用。负结果只限定这些固定状态与读取器，不能独立否定所有可训练的高斯记忆。

## 固定数据与因果边界

- 使用既有 12 个非训练来源：每个来源的 `transfer_00..11` 为早期 A 窗口，`fidelity_00..11` 为后期 B 窗口；各 12 帧，共 288 张已下载 RGB。A 完全早于 B，两个窗口互不重叠且相隔较大，是稀疏两段历史，不称连续长视频或新确认。
- 12 来源按成对窗口可用性固定，不按分数筛选。它们是 51 地点中的旧子集；当前 Soft/C 相对改善在此子集更明显。全部 12 地点保留，不能把该子集的结果推广为全部 51 地点，也不能当作独立确认。
- A 初始化帧 0–3、写入帧 4/6/8/10；A 查询 5/7/9/11 永不写入。B 使用相同角色。主评价仅在 B 的查询 5/7/9/11，沿用完整／两个固定遮挡条件、原生四帧输入、标定规则与标签。
- B 初始化由四图联合编码，只在 B 第 3 帧到达后整体可用。把四帧观察作为一个初始化批次处理，随后才允许查询；不伪装成逐帧提前得到未来信息。
- 所有写入观察均来自不读取 memory 的既有直接分支。不同图像的预测可能相关，不把不同来源帧数当作统计独立性证明。查询和传感器深度不进入状态、更新选择或相机标定。
- 从原始位姿恢复公共坐标，以 A 的初始坐标和尺度贯穿两窗。近期对照共享这个坐标／尺度约定，但不读取 A 的几何和内容槽；不声称近期对照完全没有任何历史元数据。
- B 观察转换中心、协方差、相机平移和 patch 深度。重建到公共单位时先扣除原单位的 `0.005² I`，进行缩放和旋转，再加公共单位的同一正则。内容、置信度、有效性和内参保持原样。
- B 查询的 VGGT 前缀与 Native 输出具有完全相同的四帧图像身份，按身份复用；只改变提供给读取器的记忆及其相机坐标，不重新提取或改变当前图像输入。

## 四种同容量状态

| 条件 | 可用观察 | 建立方式 |
|---|---|---|
| Recent-Corrective | B 初始化与查询前 B 写入 | B 开头重置，再采用既有纠偏更新规则 |
| History-Corrective | A 可写观察与同一批 B 观察 | 从 A 末态继续吸收 B，保持 256 槽及近期 4 帧缓冲 |
| Recent-Prefix | 与 Recent-Corrective 相同 | 从当前可用观察重建 256 槽 |
| History-Prefix | 与 History-Corrective 相同 | 从当前可用观察重建 256 槽 |

Corrective 延续现有融合、冲突、替换及阈值。新版本只显式支持 24 帧来源索引及允许写入的帧号；旧冻结实现不改动，先在原 12 帧条件核对操作。History-Corrective 起点直接复用 A 的 Corrective 末态，并扩展来源记录；初始近期缓冲为 A 最后四次写入。B 初始化批次按帧号处理后，再吸收 B 的 4/6/8/10。

Prefix 是累计观察重建参照，不是严格性能上界，也不是在线定长缓存。Corrective 的高斯槽和近期缓冲固定，但 source/conflict 溯源列扩展到 24 帧；统计完整持久状态和缓冲，不声称任意长序列恒定字节。

## 固定模型与主比较

零新训练，复用 C-static、Soft-static、C-dynamic、Soft-dynamic、Center-dynamic 五组各三个最终检查点。各组种子为 `20261110/11/12`，保持原 attention、投影、位置公式、内容维度与原生后半网络。所有模型读取完全相同的四种状态，不根据本轮成绩另挑模型。

主问题由以下固定比较共同回答：

1. 在 History-Corrective 上，Soft-dynamic 是否胜过匹配 C-dynamic？同时报告对 C-static 的净收益；旧 C 是固定的强用途参照。
2. 同一冻结模型的 History-Corrective 对 Recent-Corrective 是否改善？分别报告 Soft-dynamic、C-dynamic、C-static，并比较 Soft/C 两者的历史收益之差。
3. History-Prefix 对 Recent-Prefix 的历史收益，及 History-Corrective 对 History-Prefix 的差，区分历史信息与更新策略。

完整高斯／Center、静态／动态训练版本都完整报告，用于限定形状与训练分布的作用。Native 和 L 使用相同 B 输入作为用途参照；不把比较中最有利的一项改成主结果。C 也读取相同高斯聚合内容，因此本轮不能证明高斯压缩优于相同预算的普通 token/KV 记忆。

主指标为地点等权的混合原生 log-MSE；另报完整／遮挡、隐藏／可见、空间误差、均值偏差、AbsRel 和 RMSE。保持 5,000 次配对地点×种子重采样、各地点及各种子结果。结合效应大小和不确定性判断，不要求所有辅助指标获胜，也不把单一区间跨零等同于毫无信息。

## 固定诊断与证据边界

- 记录投影覆盖、早期来源保留、更新与容量事件，解释旧历史是否仍在状态内、是否投影到当前视野。不据这些统计排除不利地点，也不把覆盖本身当作输出用途。
- 回访：全部 15 个固定模型，在 A 的 query11 完整输入上比较 A 末次 Corrective 状态与 B 末次 History-Corrective 状态。前者 180 行评分按身份复用，后者 180 份新预测；明确是事后回访，不混入因果主成绩。
- 依赖：仅首个 Soft-dynamic 种子，在 History-Corrective 的全部 B 查询条件上做内容槽置换、均匀先验两个固定干预，沿用父轮确定性置换。仅检验依赖，不代替匹配模型用途。
- 固定例图为 B 的 `fidelity_00/01/02`，query11 完整与 mask0；另加入按主地点 Soft-dynamic−C-static 误差最大的地点所对应 B 片段，标注事后反例，重复则合并。相同查询和公共传感器色阶。保留全部反例。
- 来源和检查覆盖公共坐标、原更新操作复用、先读后写、未写入查询、固定模型身份、独立原始标签评分及实际图像审阅。既有后半网络接口证据按身份复用，不重跑无关数值门禁。

60 个主评价条件 × 12 片段 × 12 查询条件 = 8,640 份新主预测；加 288 份依赖干预、180 份回访，共 9,108 份新预测。另按身份复用 Native/L 的 576 行 B 评分与 180 行 A 回访评分。无新训练或下载；记录实际提取、读取时间与完整状态大小，共享 GPU 时间只作运行成本。

## 不同结果改变什么

- 若历史改善 Soft 的输出，而且对旧／匹配 C 有可信增量，固定方法后优先做未用地点确认；形状用途依据 Center，不能依据方法名称。
- 若历史帮助 C 和 Soft，但位置项没有可靠增量，认定历史内容有用，C 保留为强工作基线，不宣称高斯 PE 必要。
- 若 Prefix 有用而 Corrective 无用，优先检查最小的更新／容量问题，不继续调静态先验。
- 若两者都无用，结合覆盖和回访诊断限定当前表征与读取器；结束这些结构的细小修补，直接检验记忆保留了什么可用信息。冻结读法的负结果不能冒称端到端训练无效。

输入准备已经完成，但长历史状态和预测尚未生成：公共几何辅助实现为 `experiments/gaussian_memory_history_geometry.py`。12 对窗口、60 批缓存观察的往返与相机关系检查，以及原 12 帧建槽逐张量复现记录在 `results/gaussian_memory/state_read1/history_geometry_preparation.json`。这些是实现准备，不是方法效果。
