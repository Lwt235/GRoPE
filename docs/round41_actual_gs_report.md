# R41：真实 GS 可学习颜色读出结果

2026-11-01。主实验、110 次训练、目标渲染和完整指标复核均完成。固定主方案 decoupled 再次失败，不能晋级为有效方案；总体研究目标仍 active。本文没有把本轮旧开发数据称为新确认。

## 实际完成的任务

使用 Teatime 和 Waldo-kitchen 原有 context-only 优化得到的真实 GS，每场景 12,000 个基元、24 个上下文视图。基元中心就是 μ，协方差来自真实 R/S，没有 (μ−a) 修正。几何、opacity、SH0 渲染器固定，16,384 参数的共享 Q/K 从头训练；形状/距离角色多一个标量。V 直接为源 RGB，没有残差颜色头。
11 个角色 × 5 个种子 × 2 个场景 = 110 次训练，每次 500 步。保留全部 27,648 个源像素作为 keys；可读基元分别 9,334 和 8,797，与 R9 一致，其他基元回退原始 GS 颜色。每个角色使用相同特征、可见性、配对批次、训练预算及上下文选择规则。
全部预测封存后才打开目标 RGB，评分每幅目标图像的全部 27,648 像素。原有每场景 4 calibration / 4 gate 分开报告；以下是 gate 的场景等权、种子等权 MSE。原有 18 种 R9 读出保留为外部对照。

## 真正发生了什么

固定主检查点关闭形状惩罚，MSE 变为 0.024185743，改善 2.7701%；反转 V 后为 0.046824345，恶化 88.2401%。形状通道在真实 a=μ 基元上确实有作用，但本轮作用有害。反转 V 明显伤害输出，说明本任务直接检验了值读出；这仍不单独证明对应关系正确。
源像素协方差取自同一 GS 期望深度的局部 backprojection 差分，所有源像素保留。每个源图像的形状描述都有变化，未退化为行常数。坐标为 R9 相机范围归一化单位，重新训练，没有把未知 SfM 单位当米或沿用 SUN3D 权重。

## 一次限定的机制消融

主结果之后预先固定两个分量干预：仅 log-trace 尺度差、仅前六维 trace-normalized 方向/各向异性差；所有十个主检查点、β、几何和数据不动，不训练、不扫描温度、不挑赢家。完整渲染已完成：scale-only MSE .025186092，shape-only .024093993。后者比原主方案改善 3.13895%，仍比 point 差 8.16464%。完整诊断见 docs/round41_component_diagnosis.md。
CPU 已完成同一固定上下文选择行的分解：

| 分量 | 上下文 RGB MSE |
|---|---:|
| full | 0.025398087 |
| zero_shape | 0.025026129 |
| scale_only | 0.026344654 |
| shape_only | 0.024511407 |

这些上下文结果与完整图像结果共同支持原始尺度相似度在固定模型中有害，但不能声称尺度项是最终图像损害的唯一原因。GS 支撑与像素支撑尺寸不同，是待检验的解释。
另一个具体信号：Waldo 中 full 形状项让上下文 MSE 从形状关闭时约 .0304115 降到 .0297972，却让目标图像 MSE 从 .0309577 升到 .0313877。中心颜色代理目标与实际渲染目标的效果方向在这里不一致。下一轮应考虑用匹配的图像损失控制来区分监督目标问题与表示问题，而不是继续微调频率。
CPU 分解首次在自设 1e-7 重算阈值处停止，原始源和日志保留。第二版本记录偏差并完成全部检查点：最大 CPU/GPU 上下文 MSE 差 3.39e-7，比最小观察到的 shape-only/full 差异小约 72.5 倍。该偏差保留为数值注记，不作为方法失败；没有重训。

## 验证与资源

独立 NumPy 复数相位/显式距离公式复核全部 110 个模型的固定概率样本：最大 P 差 8.93e-7，最大 RGB 差 5.04e-7，无赢家变化、无预定数值告警。完整 1,328 条模型/干预/外部对照帧指标重算通过，最大 MSE 差 9.72e-17。配对批次、初始化、预定检查点选择、全体输出身份和可读基元数均检查。独立是计算路径独立，同一作者编写。
GPU4/5 完成正式实验，分片耗时 300.76 / 256.59 秒；峰值已分配显存 837.88 MiB。全部 110/110 个选中模型的 Q/K 有更新。时间和显存是本任务观察，不是完整最终成本门禁。
主实验结束后，全部 GPU 一度被其他用户任务占用。新增分量渲染排队后已在空闲 GPU4 完成，队列 91902 退出 0。没有停止或共享已有任务。CPU 只做上下文指标诊断，没有替代 GPU 训练或渲染。

## 范围和下一步

本轮是场景内学习，摄像机来自已有 all-image SfM，固定几何用过全部24上下文。它没有证明跨场景权重泛化、完整几何门禁、鲁棒性、内部 R/S 归因或未使用数据确认。它证明了真实 GS 实验可以直接启动，并给出了有实际图像支撑的负结果。
两分量渲染消融已完成，R42 已固定配对的中心/渲染损失控制。原始 descriptor-similarity 候选不晋级；不能把一个消融胜者重新命名为主方案。进一步设计要正面检验局部性和支撑语义，保持结构精炼。相关既有方法边界见 docs/round41_related_work_note.md。
