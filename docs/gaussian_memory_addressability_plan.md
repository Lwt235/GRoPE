# memory_addressability1：历史来源是否保留，位置项能否找到它

2026-11-11；有界零训练诊断。上一轮 `history_visibility_train1` 的任务匹配训练没有改善固定 Prefix 方案，不再追加训练配方、种子或模块。本轮先把“可用信息—保存来源—位置寻址—原生输出”四件事分开，形成当前贡献及边界的明确陈述。

## 科学问题与固定比较

**假设：** 固定状态仍保存与缺失查询区域对应的历史图像块，高斯位置项可能比纯内容和固定球形更容易定位这些槽，但该寻址优势未必转成原生输出收益。竞争解释包括：有效历史本来很少；置信度筛选或槽合并丢弃对应来源；预测位置与内容来源不一致；学习 Q/K 淹没或已覆盖位置项作用；来源与注意力对应成立但特征值/后续网络没有产生所需输出。最后一项只能缩小疑点，不能仅凭注意力确诊。

固定复用 visibility_control1 的 12 个已用地点、full/query_only/persistent 三条件、Recent/History 两策略、256 槽。主分析为 persistent 的固定缺失 ROI，完整图像及另两条件作范围对照。读取器为旧 C-static、C-dynamic、Soft-dynamic、Center-dynamic 及上一轮新 C/Soft/Center，各三个已完成种子，共 21 个冻结检查点。所有地点保留，包括无早期支持的地点。

## 诊断方法

1. 用原实现重新得到每槽 8 个原始 patch 成员与权重，核对均值、协方差和内容与保存状态一致；原输入及状态不变。近期最多 1200、历史最多 2400 个来源 patch。
2. 读取已有来源传感器深度和已知相机，将未被直接遮挡的来源像素投到查询 11。与有效查询深度相差不超过 10% 的像素对，仅作为**评分标签**；不改变模型几何、先验、特征或输出。去重 `(查询像素, 来源patch)`，不填洞，不扫描容差。它是局部对应代理，不是渲染真值上界。
3. 分别统计原始可用、置信度接纳、至少成为一个槽成员后的查询像素覆盖。再记录“早期有对应、所有晚期均无对应”的历史独有像素。筛选和合并保留率与绝对覆盖一起报告，不能掩盖小分母。
4. 令 `M[p,j]` 为查询 patch p 中能与来源 patch j 对应的有效像素比例，槽标签 `U[p,s]=sum_j(w[s,j]*M[p,j])`。它保留固定混合权重，避免大槽只要碰到一个正确点就算完全正确。另报告任一成员命中的 attention mass。
5. 在原生 global block 11 后、记忆残差前提取真实 Q/K，重建四头注意力。对每个固定模型分别计算 uniform/Soft/Center 三种先验下的寻址评分，实际方案单列；只替换先验计算注意力，不解码、不选择新模型。这样隔离同一 Q/K 下的位置项作用。另列不含 Q/K 的三个先验。保存可复算的 Q/K、标签、来源与逐 patch 分数。
6. 主要寻址分数为 `sum_s(A[p,s]*U[p,s])`，按有效像素加权；另列命中质量、最佳标签槽的非部署参照及每头结果。不存在对应的 patch 在无条件分数中为零；条件分数明确分母和缺失地点，不能将无对应当作成功。注意力是路由分布，非因果特征贡献。

本轮只研究查询 11 的直接记忆读取；同一次插入的三个上下文视图还可间接影响输出，因此不能把直接注意力解释成完整网络的充分原因。DINO 来源特征具有上下文混合；成员来源保留不等于语义信息完整保存，未选局部 patch 也不等于信息完全消失。

## 统计、检查与取舍

以地点为样本、模型种子配对汇总；5000 次 bootstrap，固定种子 20261111，报告绝对量、配对区间、逐地点和逐种子，不新增用途通过门槛。来源几何诊断没有模型种子，不能把头/像素当独立地点。已用数据只提供开发机制证据。

检查围绕可能改变解释的错误：输入及检查点身份、48 状态来源重建、独立 NumPy 对应标签与汇总、BF16 attention 重建和原 SDPA 的实际残差误差、一个原生输出哨兵回放。不为微小舍入误差追加科学轮次。

- 对应来源明显缺失：优先重审数据互补性或状态表示，不再修位置公式。
- 来源保留但高斯位置项没有选择性增量：现有预测几何不足以提供可靠地址，不推广该 PE。
- 位置项具有选择性增量而完整注意力没有：记录内容与几何竞争线索；本轮不自动扫温度。
- 真实注意力也能定位而输出未改善：把寻址作为有限机制证据，保留特征值、读出及任务需求等未排除解释；不能声称已证明价值编码是唯一病因。
