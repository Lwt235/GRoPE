# R55：训练预算解释了平面的大部分劣势，仍未显示高斯形状的独有收益

2026-11-02。24次新训练、24个选定模型核验及48组预测评估全部完成。
严格执行一次固定预算诊断，没有扫描特征来源、频率、温度、损失或学习率。
结论：结束当前局部框架路线的调参救援，完整高斯不晋升；原始研究目标仍未
完成，未使用确认数据继续保留。

## 比较与干预确实一致

八种已有模型各三个种子，共同从1000步延长至5000步。前1000步沿用原始
初始化、实际批次及学习率时间表，随后4000步统一lr=0.0002，连续使用同一
AdamW状态。模型类、特征、输入、损失和验证CE选模规则不变。原优化器没有
保存，故本轮从相同初态重跑前缀，再连续延长，未从旧选定权重重置Adam。

24/24个前缀的选定模型输出、权重和完整验证曲线都与R52/R53/R54对应记录
完全一致。全部5000步模型先选定，才导出旧评估预测。这24次训练是与原轮次
相关的配对预算实验，不能增加独立数据重复数。仍是五个复用场景、三个种子，
576fit/64val/480old_eval对；没有输入真实token深度、法向或物理协方差。
本轮没有新增5000步NoPE/MLP对照，因此不把它们的旧1000步结果列入公平排名。

五场景等权、再对三个种子取均值。连续EPE来自匹配概率的坐标期望；PCK来自
最大概率匹配。5000步列均指在整个预算内按验证CE选出的模型。

主方案相对射线点的连续误差增量从原来的−0.0201px变为+0.0279px；三个
种子只有一个更好，五场景平均均略差。PCK8只差+0.00272pp，应视为持平。
大误差比例增加0.0671pp。差值很小，但不支持完整形状提供稳定额外收益。

主方案相对仿射从−0.00236px变为+0.06748px；三个种子仅一个、五场景均无
连续EPE优势。PCK8低0.2475pp，大误差比例高0.1269pp且三个种子均更差。
不能把仿射的改善改称为高斯成功，也不足以据此证明某一种矩阵分解是病因。

完整高斯相对各向同性仍有组件信号：PCK8高0.2413pp，三个种子、五场景中
四个更好；但连续EPE仅低0.0138px、种子方向不一致，而且射线点整体更好。
保留这项结果，同时不将它扩大为完整高斯优于强对照的证据。

主方案相对P仍改善0.1292px和0.7288pp PCK8，三个种子均正向、五场景中四个
正向。射线点和仿射也有这一收益；R53相对P同时改变了射线中心、框架顺序及
旋转通道分配，所以不能将跨路线收益单独归因于高斯、逆框架或白化。

## 对平面负结果的实质修正

平面相对P的连续EPE差距从+0.3399px缩至+0.0153px，预算干预缩小了0.3246px。
5000步下只在1/3种子、2/5场景更好，PCK8差+0.00148pp，整体应视为近似持平。
因此，R54在1000步时观察到的明显劣势不能外推到较长训练，更不能宣称
PRoPE普遍优于HRoPE。这条固定优化过程确实解释了大部分旧平面劣势，仍未
显示平面稳定超过同P基线。

平面相对offset-only的连续EPE从+0.2686px变为−0.0360px，三个种子均更好；
PCK8高0.2725pp，也为3/3正向。这是法向自由度相对该偏移控制的有限收益，
不是物理平面恢复的证明。前向高斯相对P的连续EPE差距则从+0.1943缩至
+0.0549px，仍为三个种子均更差、五场景中四个更差。

连续大误差比例8.093%对7.811%，也没有优势。帧间隔不是隔离的表面倾斜或
变焦干预；本数据焦距比都为1，不能声称已验证变焦鲁棒性。

增加预算改善了所有方法的平均连续EPE，但P、射线点、完整高斯的PCK8分别
比1000步低0.506、0.337、0.226pp。连续与离散定位存在取舍，不能只选有利
指标。主方案对点与仿射的判断并不依赖一个任意的幅度门槛或微小数值误差。

RGB置乱后分数明显升高：完整高斯仍损失13.652pp PCK8，说明仍使用局部
视觉信息，但这一依赖较1000步明显减弱。置乱保留每张图的特征集合及相机
元数据，不能区分更强的几何学习、图像级信息和开发场景统计记忆，也不能
据此断言已不需要RGB。这一现象进一步限制当前单任务结果的一般性解释。

## 决定与下一项问题

按事前计划停止当前相机/射线局部框架的调参救援，不继续扫步数、特征来源
或矩阵分解寻找胜出版本。保留射线中心、一般仿射和部分组件的有限收益，
但当前没有完整高斯形状的独有优势，也不进入未使用确认。

下一项结构假设应回到原生3D：保留中心RoPE对内容相似度的相对相位，再让
条件高斯描述空间区域，把两者写进同一个Q/K点积。中心相位不被形状幅度
衰减替代，高斯不被当作真实定位误差。该思路已有R49未执行草稿和相关文献
先例；不能宣称新颖性或已经有效，也不直接恢复它旧的投影输入、60次训练
安排或1pp门槛。

先在不需要相机/预测深度的原生点云开发数据上固定比较两部分各自单用、
联合式、联合固定距离/简化高斯/等容量自由二次项，以及RoPE/MLP等强对照。
相同数据与骨干，只有PE变化。若收益由固定距离或自由二次项同样实现，就
不能归因于3DGS形状。具体预算、复用身份和判定分支在下一次训练前冻结。
后续还需要跨任务、几何/鲁棒性及未使用数据确认，不能将单项开发收益缩减
为原始一般性目标已经完成。
