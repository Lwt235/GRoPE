# 二维对应位移与高斯关系收益：固定的旧数据条件诊断

2026-11-10，在读取新分组下的模型结果前固定。本轮复用共同旋转骨干比较的全部18个已选模型、20组既有几何结果，以及最初576 fit0 / 480 eval缓存。上一轮已完成且保持关闭：F−Distance +3.194 pp有正面开发证据，F−固定H +1.736 pp、联合区间[−0.556,3.819]仍不确定。本诊断不改写主比较、不补种子或新训练，也不自动访问十地点或其他确认数据。

**假设：** 当真实对应区域在图像中的位置变化较大，简单二维位置线索较不可靠，高斯关系相对固定旋转的收益更大，并且这种高位移条件的收益不能完全由普通距离或同容量固定球形解释。**竞争解释：** 位移较大只使所有方法共同变难，五维的相对收益不增加；或收益来自任意关系分支，并非变化形状的组织。

它检验模型效果与已知对应条件的关联，不是改变相机运动的因果实验。所用属性需要真值重叠标签，只作分析，不能作为部署时可直接使用的选择规则。HRoPE论文对跨视图形变和较大视角间隔的分析提供问题启发，不替本项目提供鲁棒性证据。[原文§4.2.3](https://arxiv.org/html/2610.28284v1#S4.SS2.SSS3)

## 唯一主分组

使用已保存的区域二维均值位置xy（x/width−0.5,y/height−0.5）。对于每个方向，沿用原训练目标：`w_ij = overlap_ij * [overlap_ij >= 0.1]`，归一化得到`p_ij`；有效查询仍是`max_j overlap_ij >= 0.3`。

每个查询的位移为`sum_j p_ij * ||xy_i−xy_j||_2`。帧对属性D是两个方向全部有效查询的该值均值，单位为图像宽/高归一化坐标的欧氏距离，不是米或纯相机运动。区域范围与重叠分布也会影响它。

阈值只使用旧fit0的有限D中位数，先保存阈值与输入哈希，再读取eval几何和模型结果。`D > 阈值`为高组，其余有限值为低组。没有有效查询的帧对标记undefined，单独完整报告，不能混入低组或从原全量评价消失。不扫描阈值、采用每场景不同切分或增加替代属性寻找正结果。

## 固定比较和统计

所有六种编码、三个种子、两个旧诊断参照完整保留。主比较为F−固定H；支持性比较为F−同骨干Distance及F−同骨干固定球形；Geo PE和完整HRoPE作为完整报告中的强对照。主指标仍为原全部64个top1对应求解的RMSE<0.2米成功率；不重跑网络或求解器，不重新选对应。辅助报告原RMSE中位/p90、各组帧对数、有效查询覆盖、二维最近区域的标签召回，以及恒等/真值最近中心参照成功率，用于辨别任务难度和可解性。真值参照不可部署且不是上界。

条件效果主表限于同时具有至少8个高组和8个低组帧对的场景，场景等权、种子等权。资格仅由固定阈值和输入分布决定；列出所有场景与未达条件的原因，并报告全量未分组结果。少于3个合格场景则明确无法支持主条件判断，不改阈值补人群。

对每个比较固定计算低组收益、高组收益及`高组收益−低组收益`。联合区间采用10,000次配对种子×整场景bootstrap，按F对固定H/Distance/球形/Geo/HRoPE的次序使用种子99001–99005。一次抽样保持方法、两个组和种子/场景配对。报告逐种子和逐场景方向，不把同场景帧对作为独立场景扩大样本量。分组分析没有增加独立证据份数。

## 结果会改变的决定

- 若合格场景足够，F−固定H在高组为正且高−低差为正，三个种子同向、对应联合区间下界为正，则保留“较大二维对应位移下更有价值”的开发线索；若Distance或球形控制不支持，限制高斯特有解释。此时才准备有针对性的、独立的视图变化验证，不据此宣布一般有效或自动打开新确认数据。
- 若收益没有随位移增加、方向混合或区间跨零，关闭这项条件解释，不继续切更多阈值或改用别的难度变量使本假设过关。上一轮全量正面比较与固定H不确定性保持不变。
- 若高组只是所有方法及真值参照都明显失败，优先把它解释为共同任务困难；不能用接近零的差证明PE等效。

数值检查限定于：固定阈值与身份、二维位移公式的独立小样本复算、原20组全量成功率回放、分组和配对统计一致性、实际结果解释。无需GPU，CPU读取已有小型结果更直接；不新增求积门禁、温度扫描或模型模块。
