## 已有证据的分量

| 内容 | 当前可以说 | 当前不能说 |
| --- | --- | --- |
| Gaussian 原生区域积分 | 一个 μ/C 可以定义单一连续位置测度，原生格质量来自积分 | μ/C 足以恢复任意真实区域形状或指定源中心 |
| R16 旧 TRAIN | quartic full 的宽支撑、较小离散几何间隔和内容引起的 winner 变化相符 | Gaussian full 的机制已被同一实验分离，或所有内容都有害 |
| R17 旧 TRAIN | 固定候选通过既定 TRAIN 检查；相对最优旧 full1 的 J 增量为 0.866% | 主要总收益都来自新 τ；已通过旧 VAL 或下游 |
| R17 旧 TRAIN 的短板 | q24→g8 区域 KL 相对 quad16 高 5.628%；同一候选仍须全部保护 | 可用总体改善豁免逐条件门槛，或改变核形状就能修复 |
| 连续线性内容推导 | 对特定全平面密度可精确计算 mode 位移及其界 | 对原生 cell argmax、PCK、区域 KL 或实际 V 的保证 |

旧最优 full1 的 T=0 虽然区域 J 接近 R17，却没有进入本次三尺度定位可行集合。
因此 0.866% 不能单独说明 τ 没有价值；它也不能证明观测 C 比已知尺寸更有价值。
目前需要区分的是温度是否确实帮助联合目标，以及这种帮助是否需要观测支撑。

## 两项归因各自回答什么

size-temperature 对照保持同一个完整 C 几何、μ、内容与积分，只把 τ 中
观测 trace 换成原生矩形的已知尺寸。它检验的是**观测 trace 相对尺寸能否
提供额外温度作用**。即使所有报告差异很小，也不能据此删除几何 C 或认定
全部 Gaussian PE 无用。本实验没有等效性门槛或独立确认人口，不能将
“观察到接近”写成统计等效，也不能在看结果后设定新通过阈值。

主 VAL 的 matched isotropic 保持由原 full C 计算的同一个 τ，只改变几何
方向信息；它回答另一问题：完整各向异性是否胜过同尺度等方几何。即使该
对照接近，观测尺度的作用仍未被排除。两项归因一起接近，至多说明当前
操作点缺少支持“trace 温度的观测适应”和“方向信息”的强证据，不能推出
所有 μ/Σ 方法都不可能有效。

若 full 明显优于等方而 trace 温度不优于尺寸温度，应保留各向异性几何的
解释，同时收缩温度机制的主张；不能把两者打包成一个被证实的贡献。
若 trace 温度更好而几何等方接近，则证据主要支持尺度条件化的内容融合，
对“GS 旋转/完整形状转换为 PE”的支持仍弱。无论哪种归因，都不能挽救
未通过主验证门槛的固定候选，也不能直接替换主候选后重述原 VAL 成绩。

## 唯一保留的条件假说及新的理论限制

[全局协方差倍率草稿](round17_global_covariance_scale_review.md)已经定义

    Sλ = λC + h²I
    τλ = T h² / (h² + λ tr C),   λ ≥ 0.

它仍直接由 μ/C 得到一个 Gaussian 测度，只增加一个所有场景共用的标量，
没有新网络或额外输入统计。其可证伪假说只能是：**用于 PE 的几何强度需要
一次全局重标定，且完整 C 的收益仍超过有同等校准机会的尺寸/等方控制。**
这不是物理矩守恒，也不是学习置信度。此前 R4 在不同 spectral 算子中做过
协方差倍率，因此不能宣称倍率本身是新想法。这里不指定 λ、网格或预算。

本稿新增一个限制它的解析检查。在忽略 floor 的全平面 Gaussian 中，设
内容为 c(x)=gᵀ(x−μ)，C 的两个特征值为 c₁,c₂≥0，且 h>0、T≥0。
内容引起的 mode 位移为 dλ=τλSλg。在 C 的第 j 个特征方向，其响应系数是

    a_j(λ) = T h² (h² + λ c_j) / [h² + λ(c₁+c₂)]
    da_j/dλ = −T h⁴ c_(3−j) / [h² + λ(c₁+c₂)]² ≤ 0.

所以**固定 h/T 时减小 λ 虽然收窄几何，却提高或保持连续内容响应**：
τ 同时增大，抵消了“收窄一定更稳”的直觉。这不证明 λ 在离散匹配中失败，
也不排除重新校准 h/T 的效果，但阻止将它叙述为已有 R16 机制直接推出的
中心保护。完整 trace 温度只能给出保守界；各向异性 C 下，非零标量 τ
也不能令 τS 在所有方向都等于同一个常数。矩阵或空间变化内容可以改变
这一限制，却会增加信息/算子，并非当前 μ/C 加 pooled 内容的免费推论。

只有在接受后的完整旧结果确实支持“支撑强度失配”且仍支持观测 C 的额外
作用时，才有理由另立冻结协议检验这一全局重标定。现有 q24→g8 的单项
差距并不足以辨别尺度失配、单高斯闭合误差或池化内容的信息损失。

## 哪些结果应结束这一轮继续改公式的冲动

- 若 R17 主验证通过，应继续既定实际 V、真实 GS 和最终确认，避免为了
  更漂亮的旧数据结果另加标量。通过几何验证仍不解决历史源值质量瓶颈。
- 若主验证失败，而两项归因也未提供支持观测 trace/方向作用的清楚开发
  证据，不应自动启动 λ、径向曲线或多模块扫描。保留负结果；此时合理
  判断是暂时没有有依据的 μ/C 新方案，而不是把旧失败重命名后继续。
- 若失败集中在实际 V 或真实 GS，不能依据几何 KL 的改善继续调整局部
  PE 并声称解决下游；要先辨别信息是否由合法输入提供、GS 内部 Σ 是否
  在相同容量强控制下有独立作用。新读出或额外特征须单独声明成本与范围。

上述是研究取舍，不增删任何当前冻结门槛，也不证明表示不可能有效。
最大科学风险是同一旧开发人口已经被连续使用多轮，微小的局部改进可能
越来越适应具体评测；同时，把区域散布、指定中心定位和真实 GS 外观读取
都交给同一个 μ/C 分布，本身包含尚未获得一般证据支持的语义迁移。
独立数值审计能排除计算错误，不能消除这种适应或创造下游有效性。
