# 固定区域模型对局部三维坐标重表达的稳健性

2026-11-10，在新变换输入的推理前固定。前一轮五系数cross接法已关闭，本轮不修补它、不新增模型或训练。保留原完整五维及同旋转Distance/Geo PE/固定球形、完整HRoPE区域适配、固定H=K六角色×种子11/22/33，共18个已有选定模型。

**假设：** 相同物理区域在另一套局部三维坐标中表达时，完整五维相对强对照的对齐用途仍成立；若相对固定H的损失更小，才支持将坐标稳健性作为额外理由。**竞争解释：** 共同内容中的中心和log协方差依然使完整网络依赖坐标，关系项代数不变并未成为网络稳健性；各方法已有随机刚体训练增强也可能足够，不存在高斯特有优势。

该问题来自实际输入路径，而非事后选择困难场景：原20维内容中9维中心/形状依赖三维坐标，新增8维相机信息仍保留。GeoTransformer利用刚体不变的距离与角度组织关系；RoITr进一步讨论了依靠数据增强与内建旋转不变性的区别。本轮据此检查我们自己的完整模型，不声称复现或击败这两个完整系统。[GeoTransformer作者原文](https://arxiv.org/abs/2202.06688) · [RoITr作者原文](https://arxiv.org/abs/2303.08231)

只使用原480个旧eval帧对，另用前8个旧fit0做实现检查。对每个帧对、每个视图独立使用 `SHA256("region-frame-gauge-v1:99701:{id}:{view}")` 前8字节的小端整数初始化NumPy RNG；先取4个标准正态数作为SciPy xyzw四元数，归一化为均匀SO(3)旋转R，再取3个U(−0.5,0.5)平移t。每对仅一套变换，全部角色与模型种子共用，无变换幅度或随机种子扫描，无测试时集成。范围沿用已有训练增强的SO(3)与平移范围。

中心改成 `R*mu+t`（先FP64算再回原float32），协方差改成 `R*Sigma*R.T`（FP64），原11维谱/径向内容、区域成员、ID、像素位置、内参和标签保持相同。11维内容由谱和中心化径向分位数组成，刚体重表达不改变其物理意义。这里没有重新分区、重新选择锚点或模拟新相机运动；这是同一传感器观测的局部三维表示变化，不能把它解释成对真实新视角、遮挡或RGB扰动的验证。

全部18个checkpoint、原base预测/评分、数据及源码在新输出前冻结。先在原eval回放各模型以核对身份，再只在变换后输入推理；不更新任何权重或用变换数据选模。原训练预算和选择规则的检查直接复用既有审阅。模型无外参/overlap输入，真值仍只用于评价。18组新预测、18组新求解，加20组复用base/诊断，共38组几何记录。

为使比较只反映模型的对应变化，求解器将新预测的64个top1索引作用于同一份原坐标中心。这与利用已知人为R/t将问题转回原坐标相容，不使用真实相机位姿；既有41,664三点枚举、0.1 pair单位半径、最多5次非恶化重估与全64源中心RMSE<0.2米均不变。所有480帧对保留，场景再模型种子等权。实现检查同时验证已知双帧变换下的对应距离和位姿复合关系。

主比较为重表达后的F−Distance及F−固定H，完整报告F−Geo/HRoPE/球形；顺序如此，10,000次种子×整场景bootstrap固定为99801–99805。平均至少+1 pp、三个种子正且联合95%区间下界>0才支持该条件下额外开发用途，球形不额外设置1 pp门槛；反向对称，其他情况不确定。对每一比较同时计算 `(F−对照)_reframed − (F−对照)_base`，种子99901–99905；只有实际差值与区间支持，才称相对更耐坐标变化。六角色分别报告reframed−base，种子100001–100006。没有把区间跨零当等效证明，也不要求微小尾数同号。

完整报告每种子/场景对齐成功率、绝对失败率、RMSE/旋转/平移中位与p90、区域R@1、全查询正确、中心PCK、soft EPE；另报双向top1改变比例（全部查询与原有效查询）、logit变化。变化率是实际网络敏感性，不当作成功率。一个固定变换样本不保证所有SO(3)变换稳健，模型训练种子与变换抽样不是两份独立证据。

核对仅针对新增路径：双帧坐标与位姿复合的独立公式；高斯关系和原局部谱/径向特征的不变性；ID到变换确定性。CPU检查后冻结；原预测回放、模型权重不变、独立匹配指标以及SciPy位姿评分复算沿用原流程，实际查看图表。普通执行错误留版本，不改变科学问题。优先连续观测空闲GPU，最多3个并行进程，原共享余量规则及CUDA启动前复查不变。

正面结果只推进适用的未用地点方案，不能继承以前模型接法的确认或直接完成总体目标。若不确定/负，记录这项几何边界，不扫描变换、改输入重跑本批、堆叠模块或自动开启新确认；原五维已有证据与失败全部保留。跨帧五系数方案维持关闭，RGB及其他任务暂不扩张。
