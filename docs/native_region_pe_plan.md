# 原生高斯区域 PE：固定四组学习比较

2026-11-09。完整五维 `relative5` 保持主候选。本项承接已完成的原生区域矩输入诊断，只使用旧 GSModel60 开发划分；不读取官方 TEST、新场景或新高斯，不复用它们作为 fresh confirmation。此前原生数量增强和区域重构确认的混合结论保持不变。

## 假设、竞争解释和范围

假设：以邻近原生高斯组成的空间区域为 Transformer token，完整五维关系能比强中心/角度 PE 更有效地组织共同几何信息，且物理基元协方差进入区域 PE 有额外用途。竞争解释：区域形状主要来自中心散布，可能普通区域关系已足够；也可能聚合损失信息，所有五维接法都无可靠强对照优势。

输入诊断中的 3.26% 总方差贡献、12.37% 最强方向贡献和 2.62% 关系输入变化均不是准确率贡献。分组与合并矩已有先例，本项不提出新合并公式、不复现完整 ShapeSplat/GeoTransformer 系统、不把聚合前后总分变化归因于 PE。

## 固定输入与四组

沿用 R65 fit/val/dev_eval：6,227/765/765 对象，60 类；原缓存、RMS 坐标、原始外观四通道不变。训练仍每对象抽取 512 原基元，执行同一 SO(3) 旋转和中心 jitter 后分组。所有组共同执行确定性 FPS 64 锚点、每锚点 32 个中心近邻、等权局部矩。原诊断没有运行时 jitter，本项明确包含原训练增强。

区域中心 m 是成员中心均值，B 是中心散布，W 是成员物理协方差均值。完整 C=B+W+1e-8 I，中心控制 C0=B+1e-8 I。缓存已经包含 floor，完整 C 直接用平均缓存协方差加 B，floor 只出现一次。几何分组和矩使用 FP64，区域中心转回 FP32 进入原骨干。四通道外观取成员特征均值；其中 opacity 是已有变换特征的均值，不是 alpha 合成或渲染质量权重。邻域可重叠，不是整对象的无损密度表示。

四组共享相同的内容 `[m, matrix-log(C), mean(appearance)]`、64-token 骨干和分类头；只改 PE：

| 角色 | PE | 用途 |
| --- | --- | --- |
| relative5 | 原五维 F(m,C) | 固定主候选 |
| centers_only | 相同参数和初始化的 F(m,C0) | 仅移除 PE 中的原生物理协方差，完整 C 仍在内容里 |
| distance_mlp | 原距离 MLP，距离单位 .2 | 强距离控制 |
| geotransformer_rpe | 固定官方距离/角度算子 | 更丰富的强中心几何控制 |

GeoTransformer 复用固定官方版本 `e7a135af4c318ff3b8d7f6c963df094d7e4ea540` 的距离/三点角度嵌入，宽度96、距离单位.2、角度单位15°、3近邻、max聚合。原生骨干四层均为 self attention，故保留每层独立的带偏置位置投影，共四个；不能照搬区域匹配中仅两个 self 层的数量。报告各组实际参数，不称严格等容量。其出处与许可作为源码身份保留。

## 预算、配对和评价

种子11/22/33，共12次拟合；120 epochs、batch16、每轮390更新，共46,800更新/模型。原 AdamW、学习率/预热、标签平滑、dropout、梯度裁剪保持不变。共同骨干先初始化再构建 PE；两种 F 全部初始参数相同。每步按原种子和 step 重新设 dropout 随机种子，实际原基元采样/增强序列按 epoch 哈希配对。共同 pooling 无随机数、无可学习参数。四组不能使用不同的分组或完整内容。

每5轮及epoch0在原 val 的512条件按最小 CE 选模，所有12模型训练结束、统一核对并封存选择后才导出旧 dev_eval。主条件 base512，辅条件 sparse256/dense1024/jitter02/tilt/permuted；所有条件仍64区域×32邻居。保留原任务60类和 mCA/OA/CE；来源分组按原MACGS/ModelNet类别划分，只作描述，来源与类别混杂。

`permuted` 在原基元层逆序，FPS从索引0开始，因而会改变区域发现；它是全流程鲁棒性条件，不要求 logits 不变。另外在同一已构造区域上检查 token 排列的分类输出不变性，以区分分组与 Transformer 算子。刚体变换下检查局部矩/五维的对应几何性质，但不要求含绝对坐标内容的整网络完全旋转不变。所有扰动均完整报告，不据某个正面条件替换主条件。

预定比较为 Ffull−centers_only、Ffull−Distance、Ffull−Geo，以及 centers_only−Distance/Geo，六条件共30项；主比较是 base 下前三项。报告逐种子 mCA 差、均值、种子/类别及联合种子×类别描述性95% bootstrap区间（10,000次，固定种子87001+比较索引），OA/CE、来源和纠正/新增错误。少量种子、60个固定类别和反复使用的开发对象不构成新数据泛化证明；这些区间不校正多重比较，主次顺序在此固定。

用于准备后续确认的开发信号：Ffull 对两个强对照均有至少0.5 pp平均 mCA 收益、三个配对方向均正。联合区间是否排除零决定能否将开发证据称为明确，并完整报告区间宽度；区间跨零不是数学无效证明。物理形状的额外用途单独要求 Ffull−centers_only 三种子同向、均值至少0.5 pp，并结合联合区间、OA/CE及扰动表现判断可信度；不把小差距当等效。

## 不同结果改变的决定

1. Ffull 的强对照收益及物理形状增益均保留：仅作为区域化原生任务开发支持，审阅后才准备真正未用且任务适配的数据确认；本轮不自动打开任何新集。
2. 两种 F 都优于强对照，但 Ffull 对 centers_only 没有明确额外收益：主要归于中心构成的区域关系；保留原生物理协方差归因不确定，不能冠以原生形状专属收益。
3. Ffull 没有稳定强对照优势：结束此固定输入接法；保留负结果和已有区域匹配贡献，不自动扫描分组大小/floor、补种子、加模块或修改主公式。

三个分支均不宣布总体目标完成。原始目标仍包括可信、精炼、相对强对照有效的 PE 及适用的几何、鲁棒、泛化与实际任务证据。

## 执行与适度核查

实现检查针对共同输入、物理协方差只在 PE 控制中移除、floor一次、独立局部矩/关系计算、几何变换、四层Geo位置路径及梯度、分组后排列、配对初始化和统计方向。CUDA预检含完整fit缓存常驻和实际batch的前后向/更新；实现错误记录版本后修复，不升级成新科学轮次，不为无关尾数增加门禁。

沿用原完整训练器及memmap读取优化，额外每进程allocator上限4 GiB。启动前连续两次检查GPU占用并实际探测CUDA；每卡一个本项目worker，最多4个、其中共享卡最多2个。共享卡须至少13 GiB空余（4 GiB上限后保留约8 GiB及运行时余量），优先低利用率/空闲卡，不终止其他用户任务。实际峰值和端到端训练时间完整保留，不以单batch预检宣称加速。小型CPU实现检查与独立指标算术不要求GPU。

源码/配置、旧缓存manifest、输入诊断身份和选模/预测身份保留。GPU验证回放及独立 NumPy/SciPy 指标复算属于实现审计，任务用途、机制归因和真正新确认分别陈述。
