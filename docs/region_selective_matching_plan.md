# 全查询区域匹配：固定模型的可靠输出诊断

2026-11-08。用户恢复目标后执行既定下一步：完整五维保持不变，先整理核心证据，再检查已有区域优势能否转化为可靠匹配输出。原生数量增强已收束；本轮不新增训练、模块、下载或官方 TEST 访问。

## 假设、竞争解释与决定

假设：完整五维对区域关系的改善，在包含无有效对应查询时仍能保留更多正确匹配，而不会仅靠输出更多错误匹配获得收益。竞争解释：五维只改善已知存在对应查询的局部排序；置信度不能区分不可靠匹配，实际选择输出时收益被错误抵消。

旧模型一直对全部查询产生分数。原 R@1 的分母只包含有有效对应的查询，这不是推理时使用真值过滤。本轮保留旧 R@1，同时增加全查询选择性输出评价。“无有效对应”严格指当前 64 个候选中没有 overlap≥0.3 的区域，不等同于物理空间完全不重叠或不存在任何像素对应。

若固定阈值和固定保留比例下的结果都支持收益，才考虑覆盖这一使用条件的一次未用数据确认；若只能改善有对应查询上的排序，结论限定在此范围。若收益与错误率增加交换、或者统计仍不确定，明确报告，不自动增加拒识头、改置信度公式、调温度、换子集或反复重选阈值。这次诊断不能直接完成一般性目标。

## 模型、数据和置信度固定

- 方法：relative5、distance_mlp、geotransformer_rpe、jeffreys_mlp、fixed_isotropic5；种子 11/22/33，均使用已选 checkpoint 的既有预测。完整共同内容不变。
- 阈值数据：R68 原 val，64 对、双向各 64 查询，每个模型一个阈值。它已经用于旧选模，不能称为独立校准确认数据。
- 评价：旧五场景开发对象与已用九场景分别报告；每组均包含 base / sparse256。九场景主诊断、旧五场景支持性读数，不合并。原缺失 home_han 保持缺失。所有数据均已用，不称 fresh confirmation。
- 同一物理查询及标签沿用原固定稀疏协议；两种输入条件共享原有查询与候选集合。不是区域重新发现或完整配准流程。
- 匹配选择：每个方向按原 logits 的 argmax，平分时沿用原首索引。置信度固定为该方向 64 个候选的 softmax 最大概率；稳定 float64 计算，不重新估计温度，不加入互选、熵、margin 或额外头。
- 预测文件身份、对象顺序、完整 64×64 形状与标签身份先核对。阈值确定与写入后才分析评价集合的选择性指标。方案与代码在得出新指标前冻结；已知的旧 R@1 不重称未见。

## 阈值与统计口径

主操作点是旧验证集的 **5% 错误匹配预算**；1% 和 10% 是预定敏感性读数。预算的分母是全部查询，不是接受的查询，因此 5% 不代表 95% precision。

每个方法、种子分别在同一个旧 val 上选择阈值：按置信度从高到低接受，平分置信度整组处理，选择满足 `错误接受数 / 全部查询数 ≤ α` 的最大接受集合。若全部可接受，阈值为 0；若一个整组也不能接受，阈值取高于最大置信度的最小浮点数。评价直接执行 `置信度 ≥ 阈值`。不使用评价标签调整阈值；base 校准阈值原样用于 sparse256。

沿用 overlap≥0.3 为正确匹配。有有效候选但选错，以及无有效候选却接受，都算错误。逐种子、逐场景报告原始计数及以下指标：

1. 正确输出率 = 接受且正确 / 全部查询；错误输出率 = 接受且错误 / 全部查询。
2. 保留率 = 接受 / 全部查询；precision = 正确 / 接受；有效查询 recall = 接受且正确 / 有有效对应查询。
3. 无对应误接受率 = 接受且无有效候选 / 无有效候选查询；有对应但错选的计数另报。
4. 零接受时 precision 记为缺失，不记为 100%；零有效/无效分母同理。核心正确/错误输出率与保留率仍有明确值。

主要比较是 5% 验证预算下五维减四个控制的 **正确输出率和错误输出率联合变化**。评价错误率可能漂移；不能只凭正确输出增加宣称“同等错误率下更好”。场景等权，再对三个种子平均；微平均与分场景结果完整保留。1%/10% 不替代主操作点，也不在三个预算中挑选获胜者。

补充固定保留比例 1%、2%、5%、10%、20%、40%、60%、80%、100% 的曲线。每个场景、方向合并的全部查询中，仅按置信度排序选择；边界若有同分，按所需比例赋同等分数的整组相同分数权重，表示随机打破同分时的期望指标。这些曲线不产生部署阈值；标签只用于评分。全曲线报告，不择点扩大主张。

按数据组（旧五、已用九）、条件（base、sparse256）、控制（Distance、GeoTransformer、Jeffreys、固定球形）顺序，共 16 个主对比。对每个配对种子×场景的正确/错误输出率差共用相同重采样，10,000 次交叉种子与场景 bootstrap，种子 86001 起递增。独立单元不按几十万查询计数；区间仅描述有限旧数据与三个训练种子的变异，不构成新确认。其他指标用于解释，不增加一套逐指标必须全部通过的门禁。
