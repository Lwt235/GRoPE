# R63：替换观测几何没有修复RGB模型，下一步检验中心与形状的结构耦合

2026-11-02。固定R62九个选定模型，在48对旧fit与64对旧val上完成54组
前向诊断，无新训练、无旧评估或未使用确认数据。完整研究目标尚未达成。

## 主要结果

下表为三个种子平均的连续像素EPE。fit对三个场景等权，val只有一个场景。
各干预使用同一个RGB完整高斯模型的固定权重，两层均按声明替换。

| 固定权重下的输入/干预 | fit EPE | val EPE |
| --- | ---: | ---: |
| 原始预测中心＋预测形状 | 1.41782 | 3.08519 |
| 换入观测中心 | 20.25401 | 26.44074 |
| 换入观测形状 | 8.02259 | 10.37488 |
| 同时换入观测中心与形状 | 19.93356 | 25.23301 |
| 换为初始固定三轴形状 | 2.60789 | 3.98137 |
| 换为固定球形 | 2.53002 | 4.24490 |
| 关闭新增关系项 | 18.99084 | 28.43777 |
| 原R62预测中心模型，另行训练的参考 | 1.57575 | 3.13941 |
| 原R62观测完整几何模型，额外深度 | 1.25153 | 2.67133 |

六种干预的EPE及CE在fit/val的三个种子中全部变差，各场景平均也均变差。
同时替换观测几何的val EPE配对增量为+22.31925/+21.95286/+22.17137。
关闭关系项的增量为+28.27403/+26.38025/+21.40349。即使只恢复初始三轴
形状，三个种子也全部更差，平均增加.89618像素。

这些结果表明模型确实依赖训练形成的参数与关系路径；直接换入观测参数
不具备即插即用的收益。结合另行训练的观测几何模型较好，这更支持共同
适配/接口分布差异值得研究。替换本身造成分布变化，第二层预测也会随
第一层变化，不能据此证明唯一病因，或声称真实几何有害。

恢复初始形状导致退化说明当前模型依赖学到的变化，但仍不能替代从头
训练的固定初始形状对照。关闭关系项也不等于从头训练的PRoPE；不能用
其退化数值宣称新增PE具有等量收益。R62相对强对照失败的结论保持不变。

## 参数参照与范围

仅在原始预测分支记录两层几何。有效原生中心上的中心距离误差，按三个
种子各自中位数取平均：完整模型fit第一/二层为.82068/.71939米，val为
1.07465/.85293米。val第二层配对中位数为.84355/.82074/.89450米；其
预测深度中位数均值2.49103米，观测参照为3.178米。

在至少16/64样本有效的patch上，完整模型val第一/二层协方差相对谱的
对数距离中位数均值为3.89996/3.39413，固定球形参照为3.49128。
这些参数没有表现为高精度的传感器几何复原；但任务可学习PE并不要求
参数逐项等于物理观测，不能据此增加“先完美恢复几何”的通用门槛。
fit和val场景、深度分布不同，也不能将误差差异全部归因为过拟合。

所有声明分层中的预测tanh坐标，超过95%饱和值的比例均为0。观测支持
确有部分超出当前Cholesky坐标范围：patch16群体中fit46.730%、val34.616%。
固定坐标截断造成的相对Frobenius变化中位数约1.27e-8/5.45e-9，但p90
达.85659/.75746。多数/中位样本的变化极小，尾部则有实质范围差异。
因此保留范围限制这个问题，但没有证据把广泛预测饱和当作当前主因。
坐标截断不是最优协方差投影，其误差不等于不可避免的最小表达误差。
patch16群体去掉方差地板后的矩阵均为正定，实际稳定jitter均为1e-12。

计数是配对token暴露次数。fit/val总量41472/55296，其中原生中心有效
33893/47951，patch16为36713/51150，全缺失patch3870/3355。默认3m回退
没有混入“原生中心有效”的误差统计；所有任务指标保留原查询分母。

四项实现测试通过。50个冻结源未变；原控制器session13530/PID93526
退出0于89af48，六个子任务全部退出0。此session编号是在R62结束后被

种子分歧及层间变化。前向累计42.89秒是共享主机记录，不是速度基准。

## 决定及下一项假设

暂不扩大参数范围，不添加几何监督或额外骨干。下一项设计假设是：让
同一个预测深度场同时决定中心与局部形状，减少独立七维参数自由度，
可能提供更有用的归纳偏置。关系编码本身先保持不变，以检验这一项修改。

具体考虑以mu=z*r定位中心，以深度场的局部导数构造三维patch的Jacobian，
由其二阶矩得到协方差。配套比较不含深度导数的像素足迹，以及使用同一
深度/导数信息的普通关系MLP，并保留R62/R55强对照。收益仍由同预算的
匹配效果与跨种子/场景表现决定，不由几何复原误差决定。

这只是诊断支持下待检验的下一项假设，不是已验证方法。实际3DGS、跨任务、
适用鲁棒性/泛化和未使用数据确认仍待完成。
