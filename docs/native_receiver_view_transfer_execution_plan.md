如果同片段新视角保留收益，支持有限的片段内用途，再另论训练覆盖对照；若明显消失，收窄为拟合观测效果；若不确定，保留不确定并结束此检查，不自动补种子或扫参数。沿用5000次地点/种子配对重采样，训练/开发地点分别抽样，同地点新旧查询保持配对。
