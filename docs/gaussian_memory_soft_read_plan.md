## 问题、假设与竞争解释

`bound_read1` 三种子的静态主误差 L/C/A/B 为 0.287893/0.269446/0.285197/0.286362。B 比 C 高 6.28%，三个种子均退步；A 比 C 高 5.85%。绑定在训练片段被使用，却未建立迁移用途。主评价查询 patch 中 35.84% 没有直接几何支持，当前 A/B 在这些位置的直接记忆残差为零。

**假设：** 直接可见性适合提供空间偏好，但不适合作为历史内容能否读取的硬限制。保留全部槽可读，再给对应区域加分，可能保留历史内容用途并获得几何增量。

**竞争解释：** 当前预测几何不够准确；VGGT 内容本身已编码足够关系；训练片段太少；静态训练与动态使用不匹配。软化读取并不自动解决这些问题。

score_ij = q_i · k_j / sqrt(16) - log(M) + log1p(M * w_ij)

这是一个固定公式，不新增模块、可学习标量或温度扫描。保留中心、形状、遮挡、3σ 截断、opacity 和 writer。物理协方差仍表示区域范围。零投影覆盖不等于不存在历史记忆；本轮只覆盖已有 256 槽的条件。
