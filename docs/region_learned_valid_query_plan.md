# 既有预测的相同真值有效查询诊断

2026-11-10。新增求解前固定。本轮承接共同旋转骨干与区域监督oracle，主方案完整五维不变；不训练、不重新推理、不访问新地点数据。

问题：现有两帧对齐是否主要受A→B方向缺少有效区域查询标签的对应干扰？假设是保留同一批已知有效源查询、完全保持预测索引，可以显著改善实际模型对齐。竞争解释是有效查询内部的对应预测或几何一致性仍不足，删除其余查询还会减少有用约束，改善有限或退步。无有效查询直接损失不表示token/logit完全没有梯度，其仍可能作为B→A的候选参与损失。

固定使用 `region_rotary_relation/attempt1` 已审阅的18个模型：五维、Distance、Geo PE、固定球形（均加共同旋转），完整预测HRoPE、固定H；每种seed11/22/33。复用原480帧对的原始logits和全64查询对齐结果；来源与checkpoint身份记录进锁。三个已完成的有效查询oracle仅作解释参照。

唯一处理是按原 `max(overlap)>=0.3` 保留A端查询；B端全部64候选及原argmax索引不变。掩码由标签提供，对所有模型完全相同。复用 `estimate_subset` 与原刚体求解器，半径0.1 pair单位、最多5次非恶化重估；m查询枚举C(m,3)假设，不声称与原全64的41,664假设预算相同。34对不足3个查询仍计失败，其他退化按原求解器处理；全部480对及全部64个源中心保留评分，RMSE<0.2米为成功。

主诊断是五维的有效查询−全64成功率变化；其余五种方法同样完整报告（bootstrap种子99301–99306）。补充在共同掩码内的F−Distance、固定H、Geo、完整HRoPE、球形（99311–99315）。五维与三个固定oracle的配对差（99321–99323）报告剩余差距，确定性oracle复制到三行仅为与模型种子配对，不伪造oracle的独立训练重复。全部区间使用原10,000次种子×整场景配对bootstrap；五场景等权，再三个种子等权，不把帧对当独立地点。

同时报告逐种子/场景、成功变失败与失败变成功计数、无有效估计数、全部失败保留的误差中位/p90。只追加一个预先固定的描述性分组：m<3与m>=3，以区分已知无法形成最小假设的帧对；不搜索阈值、温度、置信度、其他子群或额外mask。全部对照差是诊断，不是新可部署排名、独立确认或证明唯一病因。

决策：若F平均改善至少5个百分点、三个种子同向且联合区间位于零以上，说明已知有效性对当前流程有实质潜力，下一步可以考虑一个另行固定的可实现性检验，但不直接添加拒识头；5个百分点是本诊断的实际幅度参考，不是通用门禁。若小幅、混合或退步，优先研究有效查询内的对应预测和一致性，不假定拒识可解决。即使明显改善，仍报告oracle残余差距；若各方法共同改善，不将其归因于高斯PE。掩码内的PE排序不能替代原全64可部署结果，也不能选择性覆盖十地点确认。
