# R52 算子的解释边界：共同形状相消

2026-11-02，冻结训练进行中、旧开发评估导出之前记录。此推导不改变R52
源代码、对照、训练或指标，也不增加验收门禁。R52是否有用仍由训练结果回答。

令G_i=[L_i,mu_i;0,1]，R52使用A_i=P_i G_i，则

    A_i A_j^-1 = P_i [L_i L_j^-1, mu_i-L_i L_j^-1 mu_j;0,1] P_j^-1.

若两个token共享L，有

    G_i G_j^-1 = [I,mu_i-mu_j;0,1].

共同形状完全消去。若连mu也相同，则A_i A_j^-1=P_i P_j^-1，退化为相机
对照。它能表达不同局部框架之间的关系，但不能据此声称共同椭球尺度会对
相邻中心距离施加各向异性归一化。Q/K及其他网络层仍可能通过内容表达形状，
不同token的L也可能不同，因此这不证明模型不能学会有用匹配。

反向的局部规范A=G^-1在共享L时给出

    G_i^-1 G_j = [I,L^-1(mu_j-mu_i);0,1].

这才保留共同形状对相对中心位移的白化。改变组合顺序会改变几何含义，
不能仅凭“都是相对矩阵”认为二者等价。R52已包含A=G的局部对照；R51的
A=G^-1结果继续保留。此处没有要求事后交换主方案或挑选获胜的变体。

在[HRoPE原文](https://arxiv.org/html/2610.28284v1)中，3x3平面诱导映射
K(R+t n^T/d)将相机与平面参数耦合；这与相机4D矩阵后乘一个可逆局部基底
不是相同的物理声明。它的校准4D P F变体也应按相对算子的实际信息解释，
不把实验名称当成物理对应的证明。R52仍是潜在高斯框架适配，非物理3DGS恢复。

独立数据无关示例见experiments/round52_operator_scope.py，结果保存在
results/round52_camera_frame/attempt1/operator_scope/result.json。只核对这个
代数性质；不扩张为静态求积、额外训练或普适几何验收。

后续决策：若R52不能优于相机/NoPE/简化形状对照，就没有理由继续仅凭
协方差形状名称扩充本路线。下一候选必须明确形状究竟控制位移、观测变形
还是位置不确定性，并说明它与已失败的条件高斯/RBF/框架形式有何区别。
相关的WorldRoPE期望旋转、Point-GN高斯基函数和R46/R47/R48负结果已存在，
不把重新发现这些形式当作新方案。
