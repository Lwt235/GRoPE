# 共享粗高斯场景记忆：第一轮可学性原型

2026-11-10。用户已将导师明确的新方向设为自主目标。本文替代旧两帧 PE 路线的待办，不覆盖旧正负结果；本轮是开发实验，不是新的独立确认。

## 问题与最小结构

假设：参考图像的 VGGT 特征经过一个跨场景共享的小写入网络，可以生成一份有空间组织的高斯特征记忆；保存后，仅给查询相机就能读取对应视图的信息。竞争解释包括：直接搬运冻结特征已足够、只记住训练场景或视角、输出主要是固定先验、几何组织没有承担实际作用。

先用四张参考图像一次性建图，静态局部场景，给定内外参。冻结官方 VGGT；查询图像绝不参与参考 VGGT 推理。初始深度由参考 RGB 的 VGGT 推理产生，利用四个参考相机的两两基线将预测尺度对齐到给定相机；不输入传感器深度。用参考深度反投影得到 patch 的均值与协方差，在共同坐标中合并成固定预算的粗种子。

每个种子的多视图特征由同一个小 MLP 写成中心修正、正定协方差修正、opacity 和特征。场景没有单独的可学习参数表，也不做逐场景梯度优化。第一版读取用可微高斯投影/alpha 合成，读取器本身固定；可学习部分在写入网络。保存的实际中间状态只有几何、opacity、特征和坐标说明，读取不访问参考或查询图像。

主训练输出为低分辨率教师特征，不训练 RGB 渲染指标。教师是 VGGT 的冻结 DINO patch 编码器，每张图独立编码；仅在训练参考特征上拟合 32 维 PCA 和尺度归一化，查询只作为训练监督或留出目标。此输出用于检查信息传递，不能证明完整 VGGT 下游改进或 PE 创新。

## 固定的数据与比较

- 复用 R70 已用的九个 SUN3D 场景及原始图像、相机。三个旧 fit 场景训练；旧 val 和五个旧 eval 场景均不参与此次优化，不能称为历史上未用的新数据。
- 每个 fit 场景按缓存帧序选择起点序号 `0,40,80,120`，每段连续取 13 个缓存帧；其他六场景先取起点 0。共 12 个训练局部场景片段、6 个未优化场景片段，不按结果筛选。
- 段内参考序号为 `0,4,8,12`；训练查询 `1,3,5,7,9,11`；留出查询 `2,6,10`。训练查询与留出视角互斥。同一段的全部查询读取同一份记忆。数据准备记录原始帧、哈希、位姿、参考基线及 VGGT 尺度诊断。
- 原始 RGB 缩放为 `210×280`，教师输出 `15×20`；固定 256 个高斯种子，32 维特征，写入隐藏宽度 128。初始化复现不训练的几何提升/特征投影，用零末层残差。
- 首轮共享写入模型训练 2,000 步，AdamW，学习率 `3e-4`，种子 20261110；每步一个片段、两个训练查询，特征均方误差。固定最终步作为初次比较，不据留出成绩挑 checkpoint。若实现或优化失败，保留失败配置和原因后修复。
- 同预算训练“固定初始几何、仅写入特征与 opacity”控制，并保留零训练的直接提升结果。它检验学习几何的额外作用，不作为必须胜出的强基准门禁。

## 联合诊断与决策

同时看训练查询、同场景留出视角、未优化场景，报告各片段而不只平均。展示同一份保存后重新加载的记忆读取多个视角，以及目标特征/场景图像。检查移除记忆、交换场景记忆、打乱特征与空间的绑定、扰动中心、改变查询视角；与正常读取配对比较。原始坐标整体变换后的相机与记忆联合变换只用于实现核对，不建设新的数值门禁。

损失下降只说明可优化；打乱后变差只说明依赖。二者需结合留出视角、场景切换、几何投影及可视化，才支持有条件的场景记忆机制。若只在训练片段成立，先定位泛化/覆盖问题；若正常读取与空间扰动相近，先检查几何或旁路；若固定几何同样好，明确学习几何增量尚无证据。基本闭环成立后再研究 attention/PE 读取，暂不开展更多任务或声称先进性。
