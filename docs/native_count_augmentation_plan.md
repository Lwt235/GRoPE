# 原生适用范围：同等数量增强后的五维与 Distance

2026-11-07。执行依据为研究主文档 §10.1 和用户恢复目标。完整五维公式固定，
本轮只检验一种训练条件；平均精度归一化、RGB、跨来源下载均不加入本轮。

## 假设、竞争解释和决定

假设：基元数量变化时，五维可利用中心集合以外的支撑范围关系，因此相对
Distance 的优势在双方接受数量增强后仍能保留。竞争解释：旧优势部分来自
对数量变化的适应；Distance 通过同等数量增强即可获得这部分收益。
两者均获得完整中心、协方差、opacity/DC 内容。这不是测试额外输入信息。

现有 512→256 正面结果与匹配 256 的小差距是提出问题的线索，不能直接将
不同对象组的数值相减。旧 matched256 还改变了验证数量，本轮固定验证数量。
本比较不能单独证明协方差等于真实表面支撑，也不以人为破坏标签制造优势。

## 固定比较

- 方法：原 `relative5` 与原 `distance_mlp`；原模型、位置项、协方差 floor、
  .2 距离尺度、内容、分类头和初始化不变，不使用关系投影重排。
- 新训练：种子 11/22/33 × 两方法，共六次；不依结果追加种子或更换方法。
- 数据：R65 GSModel60 官方 TRAIN 的既有 6,227 fit / 765 val / 765 dev_eval。
  保持原缓存及对象身份，官方 TEST 不访问；旧开发数据不能称为新确认。
- 采样：原采样器每步仍产生同样的 512 个索引、旋转与 jitter；每个 epoch
  按批次序号交替使用前 256、全部 512，390 步中各 195 步。三种内容同步
  截取，协方差不重新估计。原始 512 输入流与旧模型逐 epoch 匹配；另记录
  模型实际接收的索引、增强及数量的摘要，两个方法配对。
- 预算：原 120 epochs、batch16、46,800 updates、AdamW、学习率与调度、
  label smoothing、梯度裁剪、SO(3) 与 jitter 不变。每步对象数不变；
  数量较少的步减少 token 暴露和计算量，不称为等 FLOPs。
- 选模：两方法及旧对照均用原 512-token val CE，每五 epoch（含 0）评价，
  最早严格最小值。六次新训练全部选定后导出 dev_eval，完整公式不变。
- 固定训练的旧对照：R73 relative5 与 R65 Distance，种子 11/22/33。
  核对源码、数据、初始化、原始输入流、训练预算与选模身份后复用，不算新证据。
- 评价：固定 base512、sparse256、dense1024，同对象、原缓存前缀基元。
  每组 18 份新/旧预测，共 36 份。512 是基础实用读数，256 检验原稀疏
  用途，1024 是未训练过的数量增加。已有其他扰动证据保留，不新增整套门禁。

## 固定分析和收束

主指标为类别平均准确率 mCA；同时报告 OA、CE、每类、两个来源、纠正与新错误。
来源包含不同类别，不将其差异当作来源的因果效应。

分别计算各数量下：
1. 固定训练和混合训练各自的 F−Distance（六项）；
2. 混合减固定的 F−Distance 变化（三项）；
3. 每个方法混合减固定的变化（六项），区分 Distance 追平与 F 自身退步；
4. 各训练策略中“256 的 F−Distance 减 512 的 F−Distance”及其策略间变化
   （三项），区分基础收益变化与数量改变带来的相对收益。

共 18 个预定对比，按上述顺序、bootstrap seed 84001 起逐项递增，10,000 次
配对种子、类别及交叉重采样。区间描述三种子旧数据下的不确定性，不是独立
确认，也不做胜出子集筛选。原 0.5 pp 可作实用幅度参考，不能单独决定晋升；
小差距或区间跨零不证明等效。保留基础性能下降、方向混合及全部负结果。

若 Distance 获得改善且差距明显收窄，收窄原生用途的解释；若差距收窄主要
来自 F 退步，明确写作增强损害候选，不声称基线已学到同样机制。若 F 在
双方接受增强后仍有可重复且值得成本的优势，考虑覆盖该条件的独立确认和
一个相关的距离＋角度 PE 对照；仅胜 Distance 不泛称胜过所有强 PE。
若只在预定数量条件有效，只支持该条件。若仍不确定，结束这次原生推广
尝试，交付适用范围与未解问题，不自动开启新一串消融。
