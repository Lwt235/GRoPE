## 假设、竞争解释与控制

原五维相对固定球形有额外收益，但固定球形同时去掉了不同基元的大小、方向和长短轴差异。既有成功/失败分析的各向异性关联不一致，不能代替主动控制。假设是：仅保留各自局部大小，就能解释大部分收益。竞争解释是完整椭球关系仍提供额外用途；也可能两类任务方向不同。

新增 `trace_isotropic5`：仅在 PE 中以 `tr(Σi)/3 · I` 替换每个协方差，中心、共同内容与标签不变。Σ 是现有流水线的正定矩阵，包含原来的 floor；不追加 floor、不重估尺度。保留每个基元平均平方尺度，联合去掉朝向与长短轴差异，不把结果解释为只隔离了朝向。

若 `ri=tr(Σi)/3`、`δ=μi−μj`，五维输入应为：

`[||δ||/.2, log1p(||δ||²/ri), log1p(||δ||²/rj), log1p(3*rj/ri), log1p(3*ri/rj)]`。

仍使用既有 `5→96→96` MLP、GELU、无偏置末层，共 9,792 个 PE 参数，不添加模块。全部初始参数和 RNG 状态与同种子 relative5 一致。从训练开始使用新控制，避免仅在推理中替换输入的分布变化混淆用途判断。共同内容继续包含完整形状：区域 20 维、原生 13 维。

固定比较为完整 relative5、Distance、固定球形和新增的各自大小球形。前三项复用相同种子、已选 checkpoint 和预测；不因本次结果重新选模或改变已有判断。

## 分析和决定

主读数是区域 base 场景宏平均 R@1 与原生 base 类别宏平均 mCA；核心差为完整五维−各自大小球形、各自大小球形−固定球形，以及各自大小球形−Distance。完整五维对两旧控制作为背景。所有比较均使用三个匹配种子。

对各比较记录四种预测事件：双方正确、左方纠正、左方引入错误、双方错误；沿用场景/类别等权，原始事件数另外列出。每个唯一查询/对象记录各种子纠正/退步次数、全种子一致和方向反转；保存全部事件，有限案例按固定 ID 字典序选取，不根据几何故事挑例子。区域归因仍基于同视图 PE，跨视图中心误差只是用途指标。

- 若各自大小球形保留主要用途、完整五维没有清楚的额外优势，优先研究局部尺度关系，但不把接近均值当正式等效；完整椭球的必要性相应收窄。
- 若完整五维在固定主指标上跨种子保留有实际幅度的优势、中心/次指标未显示相反的主要代价，则支持方向与非球形结构的联合额外用途；再分析纠正的样本，不宣称方向是唯一机制。
