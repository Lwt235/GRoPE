# R56：中心相位与区域偏好互补，但未建立完整高斯的额外优势

2026-11-02。九次新训练、30个精确复用对照、39个选定模型检查、273组指标
回算和12组形状干预均完成。结论是保留中心相位的组件收益，完整高斯联合式
不晋升，不进入未使用确认。完整研究目标仍未完成。

## 本轮回答了什么

在相同四层原生三维点云 Transformer 中，联合式为

    s(i,j) = T <RoPE(x_i) q_i, RoPE(x_j) k_j>
             - 0.5 (x_j-x_i-m_i)^T P_i (x_j-x_i-m_i).

中心相位保持单位幅度；P_i 为从特征预测的正定精度矩阵。高斯承担条件空间
偏好的作用，不代表测量到的物理 GS 支撑，也不声称恢复局部纹理对应。
高斯项可写成九维位置 Q/K 内积。实现将 FP64 位置乘积加到 FP32 内容分数，
没有新损失、渲染器或混合门控，也没有融合注意力内核的性能主张。

依据 [事前协议](/home/liwt/GRoPE/ROUND56_NATIVE_JOINT_PROTOCOL.md)，新训练
完整高斯、固定距离、自由二次项三种联合式，各使用11/22/33三个配对种子。
复用R48十种方法在这三个种子的原模型和预测；复用结果不计作新的独立训练，
不与R48原五种子均值混用。

全部使用7910个fit、965个val和965个旧dev_eval对象，来自同一官方训练集缓存。
每次120epochs、29760次更新；相同共享初始化、实际采样/增强序列、优化器、
学习率、骨干和最小验证CE选模规则。全部39个模型先选定，再导出新评估。
官方测试集及保留的跨场景确认数据未读取。

主方案相对完整高斯单用的OA提高0.898pp，三个种子分别为+1.244、+0.725、
+0.725pp，CE也均改善。这支持在当前骨干和数据中保留中心相位。
自由二次项加入中心相位后平均提高0.622pp，固定距离加入后提高0.864pp；
因此该互补现象不限于高斯参数化。

主方案相对联合自由二次项只高0.069pp，配对差为+0.829、−0.415、−0.207pp，
仅1/3种子获胜；mCA反而低0.444pp。相对MLP映射也只高0.069pp，配对差为
+0.829、+0.207、−0.829pp，mCA低0.709pp。CE均值略好，但两项比较都仅2/3
种子CE更好。现有证据应视为接近持平，不能宣布完整高斯优于强对照。

与对角高斯单用的OA均值完全相同，配对结果1胜2负；相对中心RoPE平均
提高0.449pp、2/3种子正向；相对联合固定距离提高0.415pp、2/3种子正向。
这些组件差异保留，但不足以绕开上述等容量自由二次和MLP对照。

完整联合式的三个OA为89.326%、89.223%、89.119%，在这三个种子中的跨度
确实较小。三个初始化不足以证明普遍的优化稳定性，不能据此改换主要判据。
自由二次与高斯虽等容量、初始函数及一阶导数相同，但非线性、取值范围和
中心—形状耦合不同，比较不能单独归因于正定约束。

## 模型依赖形状，但依赖不等于独有收益

按事前计划，对固定检查点的全部四层和两个头施加干预，不重训、不选参数。

| 模型 | 正常OA % | 保trace球化OA % | 固定旋转协方差90°后OA % |
| --- | ---: | ---: | ---: |
| 联合完整高斯 | 89.223 | 68.152 | 35.613 |
| 完整高斯单用 | 88.325 | 49.430 | 25.527 |

联合式球化后下降21.071pp，固定旋转后下降53.610pp，各种子都明显下降。
这反驳了“选定网络完全忽略形状参数”的解释，但不能证明参数恢复了物理
协方差，也不能证明此结构优于自由二次函数。干预同时改变训练过的注意力
分布；主结果恰好显示另一种参数化能达到接近的准确率。

输入锚点固定；每层干预保留由其当前输入预测的均值。前层干预会改变后层
特征和随后预测的均值，因此并没有锁住原始前向轨迹中所有层的中心。
本轮不将这些干预扩大解释为孤立的物理形状因果效应。

## 决定与下一项结构问题

不晋升完整高斯联合式，不启动其对角/各向同性联合版本的追分扫描，也不
继续调整预算、温度或频率补救。保留“中心相位对高斯区域偏好有帮助”及
“形状参数确实参与已训练计算”两项证据；完整目标和所有负结果继续保留。

下一项值得论证的问题是：让两个token各自的高斯参数直接定义相对关系，
能否比当前仅由query决定空间范围更有用。旧备用笔记已有高斯Jeffreys
相似度的19维Q/K表达；其区域质量可加性反例仍成立，但不直接否定其用于
学习型相似度。该数学构造尚未得到任务效果证据，不因闭式表达而晋升。

若继续这一方向，需事前比较完整形状相容项、删掉形状相容项但保留相同
自适应中心距离、以及仅学习中心的控制，并保留本轮RoPE/MLP/自由二次强
对照。这样才能判断收益来自两个中心、一般自适应距离，还是高斯之间的
形状关系。只替换一个位置分数，仍不把相似度当积分质量或纹理对齐变换。
该后续方案尚未冻结或启动，不接触未使用确认数据。
