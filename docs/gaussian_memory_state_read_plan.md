# 与增量状态匹配的读取训练：state_read1 固定计划

2026-11-11。`soft_read1` 的独立评分、六图审阅和方法取舍已完成，现采用本计划。制定时尚未启动新训练。只改变读取器训练时接收的记忆状态，不改变位置公式或增加模块。

## 问题与可辨别假设

当前 Soft 的三种子静态误差与 C 基本持平（平均高 0.32%）；Corrective/Prefix 更新后 Soft 平均误差高 1.01%/2.63%，三种子均退步，Prefix 的配对区间支持退步。C 在相同更新下基本持平。训练片段依赖几何对应，迁移用途仍未确立。

**假设：** 读取器只在初始 M0 上训练，学到的内容与几何对应不能适应更新后的状态。保持同一结构，让训练使用与查询时刻一致的 Corrective 状态，可以改善增量读取；关键仍是 Soft 对匹配 C 是否有额外价值。

**竞争解释：** 预测几何／固定更新器存在误差；冻结骨干及少量训练地点限制迁移；高斯位置偏好不提供有用信息；新增图像与原生短窗口高度重叠。状态匹配不会自动解决这些因素。

输入身份核对已确认：query5/7/9 的新增写入图像全在原生四帧窗口里，query11 只有写入帧 4 在窗口之外。因此本轮检验同一信息设置下的训练状态因素，不据此宣称长期记忆用途。下一步的窗口外历史验证单独进行，保持因果窗口与强原生对照；已用数据仍是开发数据。

## 唯一训练变化与匹配控制

- 沿用同一 137,472 参数 attention、同一冻结 VGGT 内部层、同一规则 writer 与已经保存的状态。
- 对 query5/7/9/11，训练时分别读 Corrective 状态 1/2/3/4；这些状态仅含此前的写入帧，查询及其标签不写回。记忆几何和内容不参与梯度更新。
- 新训练 `C-dynamic` 与 `Soft-dynamic` 各三个种子 `20261110/11/12`、各 2,000 步。每步片段、查询、遮挡条件、初始化、损失、优化器和最终检查点规则与父轮 C 完全配对；只将 M0 输入替换成对应时刻状态。
- C 仍为均匀真实槽先验；Soft 仍为 `-log(256)+log1p(256*w_ij)`，null 屏蔽。无温度、强度、学习率或早停搜索。
- 父轮静态训练的 C/Soft 及其 Static/Corrective/Prefix 全部评分按身份复用，形成「训练状态 × 读取方式」四组对照；L 和原生 VGGT 继续作为用途参照。
- 仍是同 12 训练地点、85 已用片段与 51 非训练主地点。新目录保存结果与源码，旧负结果保持原样。

## 评价与取舍

1. **主比较：** Corrective 状态上的 Soft-dynamic 对 C-dynamic，地点等权混合原生 log-MSE。报告完整／遮挡、隐藏／可见、空间误差、均值偏差与三个种子；原生 VGGT 参照保持。
2. **训练状态效应：** 分别比较 C-dynamic/C-static、Soft-dynamic/Soft-static 在同一 Corrective 状态上的变化；再报告两种读取方式的改善差，判断训练匹配是否特别帮助几何读取。配对重采样沿用 5,000 次地点×种子，微小均值差不自动升级为实际用途。
3. **状态范围：** 新六个模型全部评价 Static、Corrective 与 Prefix，均不受主比较结果限制；不把仅对训练状态更适应写成一般鲁棒性。
4. **依赖与回访：** 首个 Soft-dynamic 种子在 Corrective 状态上进行内容槽置换与移除几何位置项；C-dynamic/Soft-dynamic 首种子读取 query5 的初始、首次和末次 Corrective 状态。回访是事后诊断，不混入因果主成绩。
5. **条件形状控制：** 若主比较平均降低至少 1%，且至少两个配对种子改善，追加三个动态训练的 Soft-center 控制，并评价 Static 和 Corrective。1% 是本轮投入额外拟合的最低开发信号，不是显著性或成功定义；阈值以下结果仍完整报告。球形方差沿用既有训练统计，此控制同时改变形状和投影足迹。

训练前仅做输入配对、零残差及两步梯度／资源检查；既有模型接口测试与投影正确性证据按身份复用。独立复算新预测、核对六次训练配对，审阅预定例图和明确标注的反例。记录实际训练时间与显存；架构和算子未变，父轮后半网络成本作为带来源的描述性参照，不重复短时共享卡测速来追逐噪声。

## 不同结果改变什么

- 若状态匹配使 Soft 对 C 有可信增量，固定该精炼结构，再优先验证原生窗口外的较长历史；形状控制与原生用途一起限定主张。
- 若 C/Soft 都受益但二者仍接近，归因于训练匹配，采用 C 作为强读取基线，不宣称高斯位置项必要。
- 若 Soft 仅修复自己的退步，仍不胜过 C，保留为机制结果，不晋升方法。
- 若状态匹配也不能改善用途，结束对该固定读取器的状态训练修补。下一项应明确检验窗口外历史的信息贡献或记忆表征质量，不继续增加静态先验调节项。

已有数据中有 12 个非训练来源各包含两个不重叠的旧窗口，可用于后续 24 帧历史开发验证，原始相机文件已存在。各旧窗口的相机坐标分别以各自首帧为原点，实施时必须从原始位姿恢复共同坐标，不能直接拼接旧缓存。此处只是可行性记录，未将该扩展当作已经执行的证据。
