# R21 固定共同内容偏置分解：完整机制诊断报告

2026-10-31。R21 的执行、数值和独立指标审计已接受。**本轮没有效果通过门槛，也没有选出或晋升候选。** 它把 R20 的几项变化拆开后，发现了清楚的取舍：指定中心 a 改善等场景中心定位，却恶化 q16/q24 的区域分布；rank-one 增宽补回部分区域 KL，但没有同步改善中心指标；原 full4 保留更多局部形状，在 q24 显著降低区域 KL 的同时，中心 PCK 大幅下降。这些结果不能支持“加回形状信息即可同时解决所有要求”的结论。

尤其是共同内容下的 q24→g8，full4 相对原 full1 的 KL 从 **0.325719856 降至 0.258441118**，PCK 却从 **91.935526% 降至 46.125219%**，成对计数为 **23 benefit / 528 harm**，平均中心误差从 **4.228508 增至 8.606430px**。这是必须保留的机制反例，不是可忽略的附带指标。

**固定实验与人口。** 仅为原 48 对 TRAIN（c3/c5/c6 各 16 对），q8/q16/q24→g8 三条件，全部 432 个原生 g8 key。每对 588 个 query，共 **28,224 个唯一 pair/query 行**。8 角色共保存 **1,152 个 float64 P 矩阵**，4 几何保存 **576 个原始质量矩阵**；同一 query 跨角色重复，不增加独立样本。使用原区域可见像素合同与 R13 `*_point_visible` 跨视图中心合同；q8/q16/q24 中心有效总数仍是 **9,521/2,463/1,096**。预测 front/FOV、质量大小、旧成功情况均不参与筛选。

设旧 full1 矩为 μ32/C32，指定中心为原 R13/R20 预测中心像素坐标除以 8 后的 a64；三者沿用 reference-8 坐标单位，covariance 单位为其平方。固定 h=.25、T=10，并只计算一次

```text
Ca = C32.double() + (μ32.double()−a64)(μ32.double()−a64)ᵀ
τ = T h² / (h² + tr(Ca))
b32 = τ.float32 × content32
P = softmax64(log(raw_mass64 + 1e−30 × area_ref8) + applied_bias32.double())
```

四种几何是原 `G(μ,C)`、`G(a,C)`、`G(a,Ca)` 和原 full4；各自交叉 zero/content 两臂。zero 使用同形 float32 零偏置；content 对全部四几何使用**完全相同的 b32**。几何积分保持原 GL32、原生 cell 和面积 floor，full4 在四组件质量求和后只加一次 floor。没有改变 h/T、节点、协方差或进行拟合。

`a_c_content` 与 `a_ca_content` 分别逐位重现 R20 的 mean-only 和主角色。`mu_c_content` 也使用 τ(Ca)，因此仍经共同温度接入 anchor 信息；本轮只能归因于固定同一 bias 时的几何变化，不能称为完全移除 anchor 的控制。它**不是**原 R17 使用 τ(C) 的 trace 角色；不能将它的所有结果直接称为“旧 R17”。`mu_c_zero/full4_zero` 对应原 h=.25、T0 路径。full4 始终是诊断控制，参数量/计算结构不等于一个紧凑单 Gaussian。

**指标与方向。** 区域在 scene/condition 内先按完整可见像素质量加权，再三场景等权。q8→g8 的 KL/JS 为映射到共同 g16-query/g8-key 后的指标，direct KL/JS 保留原生 q8 分区；q16/q24→g8 的两组数值相同。三条件宏观值仅为描述性等权平均，不能称 common9、direct5 或新的选择目标。

中心 PCK 采用 first-index 原生 argmax、距离平方≤64px²，保留精确 scene/等场景 Fraction。mean、RMSE 单位是 px；宏观 RMSE 是 scene/尺度 RMSE 的等权平均，不是 pooled RMSE。成对变化统一为 to−from；KL/JS/距离下降为改善，PCK 上升为改善。benefit=from 错而 to 对，harm 相反。连续 benefit/harm/equal 按原 float64 距离平方排序，距离和/RMSE 仍按 px。显示值的舍入不参与整数或 Fraction 判定。

**指定中心的作用有清楚边界。** 在共同 b 下，a,C 相对 μ,C 的 q8/q16/q24 PCK 分别提高 **0.514803/0.674132/1.474287pp**，mean/RMSE 的等场景值也下降；但 q16/q24 的区域 KL/JS 在三个场景全部变差。q8 的 common KL 下降 0.000585，direct KL 却上升 0.004489，说明共同表示的平均可以掩盖原生区域方向。zero 臂也出现 q16/q24 的相同区域退化方向，所以不能将此现象全部归咎于内容偏置。

**增宽改善区域，不等于改善定位。** `widening_content` 在 9 个 scene×condition 的 KL 全部下降，但三尺度宏观 ΔPCK 为 **−0.017991pp**、Δmean **+0.002696px**、ΔRMSE **+0.007314px**。q24 的 PCK 三场景完全相同，B/H=0/0，却有 2 个 valid argmax flip；等场景 mean/RMSE 分别增加 **0.007118/0.026486px**。同条件 JS 也增加 0.000041951，c3/c5 都变差。这里固定 τ，隔离的是 rank-one 几何增宽，不能说它提高了中心定位或把区域分布全面变好。

**更多局部形状也不是统一改进。** full4 相对原 μ/C 的 q24 区域 KL/JS 在三个场景下降，但三个场景 PCK/mean/RMSE 同时变差；q8 的 common/direct KL 等场景值反而上升，尽管 JS 下降。q16 的等场景 KL 降低也伴随 PCK 降低、RMSE 增加，且 c6 的 KL 本身变差。这与区域分布保真和指定中心定位是不同目标的解释相容，但并不证明某个特定机制是唯一原因。

**full4 的“同矩”是实数陈述，实际并非逐位同矩。** 原 full4 的四个局部 Gaussian 都包含 within-pixel covariance 和各 stratum 的散布。实数中，其加权均值及“局部 covariance+节点间散布”的总 covariance 等于 full1 的前两矩；实际 float32 局部/整体归约顺序不同。全 28,224 行中，已测最大均值绝对残差为 **7.82012939453125e−5 reference-8 单位**，最大 covariance 绝对残差为 **0.0010942424487438984 reference-8²**；最大 `|差|/(1+|参考|)` 分别为 **1.7631075370750541e−6 / 1.510027066078467e−5**，低于原 1e−4 统计量比较限。节点和 covariance 未被修补。

因此 shape 对照保留了更多局部形状，并记录了有限精度限制；不能说所有差异已经被严格证明“纯由高阶信息引起”。更不能把它外推为在 a/Ca 下也完成了形状对照：full4 只位于原 μ/C 路径，本轮没有同 a/Ca 的 full4。该四几何×两内容设计也不是三个独立几何因素的完整全因子实验。全部支持/投影/残差证据见 [48 对完整支持检查](/home/liwt/GRoPE/results/round21_matched_report_tables/support_checks.csv)。
