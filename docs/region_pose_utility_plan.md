# 固定区域PE：已有匹配能否转成几何对齐用途

2026-11-09。本计划在计算任何本轮位姿/对齐成绩前固定。完整五维继续为主候选；已结束的原生来源混合策略保持关闭。本轮仅复用旧五场景的区域预测，零训练、零新模型推理、零新数据下载，不能称未用数据确认。

## 问题、竞争解释、决定

已有两批场景支持五维的区域对应排序，但最高置信少量输出没有可靠优势，区域重叠正确也不保证两区域中心恰好对应。本轮直接检验：给四种编码完全相同的刚体求解器，完整五维的排序收益能否提高两帧的几何对齐成功率？竞争解释是区域级召回尚不足以支持准确一致的中心对应，或常规距离/点配置编码已足够完成对齐。

这仍评估固定区域匹配器中PE的用途，不改网络、训练损失、置信度规则或PE参数化。求解器是各方法共同的评价接法，不作为新增学习模块或方法创新。不复现完整GeoTransformer配准系统，不使用其论文成绩作直接比较。

若对强Distance和GeoTransformer位置算子的对齐成功率均有稳定、非微小的开发收益，且相对固定球形有支持性形状归因，才考虑覆盖相同条件的未用场景确认。若收益混合或没有转化，关闭这项固定接法的推广检验，保留区域排序证据，不扫描求解阈值、增加训练种子、添加精匹配/ICP或选择有利帧对补救。若共同求解器连真值辅助对应都难以对齐，报告该区域中心接法受限，不据此否定所有配准用途。

## 对象与固定比较

只用R68旧五场景base的480帧对，每视图64区域；F、Distance、GeoTransformer PE、同参数固定球形，各使用原验证已选种子11/22/33，共12份既有预测。身份引用既有`region_selective_matching/attempt1/lock.json`的old5/base记录，再固定本轮输入与源码身份。所有帧对及64个查询都进入评价，包括没有原重叠有效标签的帧对；不得用真值筛除查询、匹配或失败样本。不访问此前两个九场景确认批次，也不重新称旧五场景为新确认。

主比较F−Distance及F−GeoTransformer PE；F−固定球形用于形状归因。旧区域召回不重新选模，新的位姿指标不回流修改任何模型。

## 坐标和评分边界

代码核对显示，模型输入来自各视图单独中心化的相机点及共同观测RMS尺度，真值位姿没有进入模型，也没有预对齐输入。PE用于视图内部self-attention，交叉attention依据内容描述子。

估计器仅接收两视图的局部区域中心及预测匹配索引，不接收世界中心、重叠标签、真值或有效查询掩码。评分器单独由base中每视图相同成员的局部/世界中心恢复局部到世界的刚体映射，从而得到真值相对变换。检查该映射能复现世界中心，仅用于评分与真值辅助诊断，不传回估计器。

主对齐误差：对全部64个源视图区域中心，计算预测变换与真值变换后的均方距离开方，再乘既有pair scale恢复米制；成功定义为RMSE<0.2米。报告所有帧对的成功率，场景等权，另列逐种子/场景、微平均、全部帧对误差分位数和失败数。旋转误差、中心化输入坐标系的平移误差同时保留；后者不能称原始相机原点的平移误差。本指标是当前64区域接法的对齐评价，不等同于完整3DMatch官方协议。

0.2米误差标准参考GeoTransformer公开配置中的RMSE阈值；现有0.1归一化距离对应本项目区域中心PCK。两者单位不同，本轮明确区分，不将归一化距离当米。

## 共同求解器与诊断

每个源区域取已有logit最高的一个目标，共64对；不做置信度阈值、真值过滤或事后互选。统一采用三点刚体最小二乘假设及一致性评分。64个查询仅有C(64,3)=41,664个三元组，本轮固定枚举全部三元组，以消除额外抽样种子的影响；只排除重复目标或数值退化的三角形。SVD使用proper rotation，不允许反射或缩放。

一致性半径为0.1个原pair归一化单位，沿用当前中心定位标准，不扫描。选择内点数最多的假设；相同内点数时选择截断平方残差总和更低者，再以三元组顺序打破精确并列。以该内点集合进行最多5次共同的刚体最小二乘重估，仅保留一致性目标不变差的更新，不采用外部点云ICP或学习匹配细化。

诊断固定两项：中心化输入中的恒等变换（检验近邻帧是否无需估计即可过线）；真值辅助中心最近邻对应进入同一求解器（观察区域中心接法的能力范围，明确不可部署，也不是理论上界）。它们不用于改阈值或选择方法。不从诊断较差直接推断PE无效。

## 不确定性及预定解释

各帧对成功按场景等权、再三训练种子等权。10,000次配对种子×场景bootstrap，三比较随机种子分别93001/93002/93003；同时保留仅场景、仅种子区间。只有五个场景与三个训练种子，区间不能代表任意场景或无限种子总体；不把同一场景内帧对当独立场景扩充样本数。

有限开发信号：F相对Distance和GeoTransformer PE的成功率平均各至少+1 pp、三个配对种子均正且联合95%区间下界>0；结合恒等基线、真值辅助诊断和绝对误差判断任务是否有实际意义。固定球形的幅度、配对稳定性与区间共同约束额外形状归因。无需每个场景或每个次指标同号，不以数值尾差设新科学门禁。

## 执行与证据

先用生成几何检查坐标变换、proper rotation、异常/退化输入及共识求解，再在实时空闲GPU执行合适的批量SVD和残差算术。使用FP64与有限显存上限；选择设备和分块大小只影响执行成本，不改变候选集合或评分。保留其他用户任务。源身份、已存预测身份、全部帧对输出和独立CPU评分复算足以支撑本轮，不重复历史积分门禁。

失败与普通执行修复保留版本记录；全部比较算完并独立复算后再进行科学判断。无论本轮结果如何，都不自动宣称一般性目标完成。
