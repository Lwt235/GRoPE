## 2. 最小可考虑修订：把现有 log 表示延续到正权重积分

保留同一个 Gaussian、RMS/QR 构造、\(h\)、负尾公式/余项界、GL24 节点权重、\(2h\) tiles、独立 direct-FOV 划分和全部预算。只让现有密度函数返回有限 log-density；不添加模型、截断半径、概率阈值、重试或新的尾部近似。

对 tile 的正权重求积，记 \(\ell_i=\log g(y_i)\)、二维 GL 权重 \(w_i>0\)、映射 Jacobian \(J>0\)：

\[
L_{tile}=\log J+\operatorname{LSE}_i(\ell_i+\log w_i),\qquad
L_j=\operatorname{LSE}_{tile\to j}L_{tile}.
\]

分别计算 native cells 的 \(L_j\) 和重新铺 tile 的整个 FOV 的 \(L_D\)；不得用 native 之和伪造 direct FOV。native 总质量为 \(L_F=\operatorname{LSE}_jL_j\)。一次面积 floor 与原 bias 的顺序仍是

\[
\log \widetilde M_j=\operatorname{logaddexp}(L_j,\log f_j),\quad
q_j=\log\widetilde M_j+b_j,\quad
\log P_j=q_j-\operatorname{LSE}_kq_k,
\qquad f_j=10^{-30}\operatorname{area}_j.
\]

这是原正权重求积和归一化的代数重写，不是将小 raw 置零或直接输出面积先验。舍入次序改变，因此不能承诺与旧普通域实现逐位相同；必须重新走冻结后的独立数值比较和恒等性检查。

内部 LSE 通常对减去最大值后的项取指数，极小的相对项仍可能舍入为零。不能因此宣称“消灭所有下溢”：需记录其数量和可解释的遗漏量上界。例如遗漏 N 个、相对 log 值都不超过 \(d<0\) 时，忽略舍入误差的缩放和遗漏上界为 \(N e^d\)，可在 log 域保存为 \(\log N+d\)，再计入误差分析。它不是求积/密度误差的总证书；未经界定的删项不允许冒充精确累加。

**两个接口层次不能混称。** 若最终所有正 raw 仍可转换为严格正 float64，可继续旧 raw 接口，内部 log 累加只解决过早节点/tile 下溢。若最终某个正 cell mass 也不可表示，仅内部改写仍不能满足旧普通 raw 输出合同；必须另冻一个明确的 log-mass 接口，才能讨论扩大表示范围。该接口以有限 `log_raw_mass`、`log_direct_fov` 表示正量，并保存普通值是否可物化的掩码。不能把物化失败的 0 当 canonical raw，再把 `all_raw_mass_zero` 或 `area_prior_used` 设为 true。结构零使用单独枚举/标志；partial 的未完成位置也单独标明。

最精简的起点只修复“有限 log-density → 过早普通指数”的表示损失，保持准备阶段已有失败条件。若未来确需允许普通 `front_mass` 下溢，可用有限 `log_ndtr(m/sigma)` 保留 log-front，但这是另一项需事先声明的输出/准入修订；它不会自动解决几何中间量溢出、RMS 丢失非零 rank 或独立参考的正深度截断。

## 3. 原门槛如何原义保留

不能将“有有限 log 输出”直接当作旧数值通过。保留生产/独立高阶参考的 P 最大误差 \(10^{-4}\)、raw-FOV 相对误差与 raw-L1/FOV \(10^{-6}\)，参考双阶 P/raw \(10^{-8}\)，归一化 \(2\times10^{-12}\)、direct-FOV 绝对差 \(10^{-8}\)、原截断门槛、恒等性及近常深度门槛。若只做 R28 这种无独立概率积分的适用性检查，仍只能报告输入/输出算术与可完成性，不能宣称下述独立数值门槛已经检验。

在另立 log 接口的协议中，原 raw 误差可以等价地比较，无需将极小质量转为 0。对两个有限 log 值 a、b：

\[
\log|e^a-e^b|=\max(a,b)+\log[-\operatorname{expm1}(-|a-b|)],
\]

a=b 时差为 0，单独处理。于是 FOV 相对差为 \(|\operatorname{expm1}(L_F^{prod}-L_F^{ref})|\)；raw-L1/FOV 的 log 值为各 cell 的 log-绝对差做 LSE 后减 \(L_F^{ref}\)。direct-FOV 仍比较 \(|e^{L_F}-e^{L_D}|\le10^{-8}\)，可等价比较 log-差与 \(\log10^{-8}\)。大差不必先指数到溢出，应明确判为不通过。这些只是同一门槛的稳定表达，不是新增宽松指标。

独立参考也必须能独立保留正量及其相对尺度；当前 R27 参考会把若干 Gaussian 区间或最终质量转回普通浮点，并拒绝正质量为 0。**它若仍下溢，结论就是独立核验未解决，不能让生产 log 值替参考作证。** 参考不能导入生产 log-density，也不能靠 floor 后 P 一致豁免 raw 比较。结构零的解析零豁免仍仅限原精确零分支。

## 4. 不能由 log 表示解决的限制

- 极小正数可以有有限 log 值，但有限 log 值不等于高相对精度。若 \(|L|\) 很大，float64 的 log 舍入间隔本身就可能超过 \(10^{-6}\)；几何平方、相减或除法也可能在取 log 前失去精度或溢出。没有独立证据就必须失败/未解决，不能把所有有限输入都纳入正确性声明。
- 原 GL 绝对误差界排除密度、分解、节点/权重及累加舍入。raw 很小时，绝对误差小仍可能相对误差很大；log-LSE 不提高 GL 阶数，也不提供新的相对求积证书。direct-FOV 一致只是必要条件，不能单独证明正确。
- floor 主导时，某个错误的 raw 也可能得到几乎相同的 P。仍须验证 floor 前的 raw 与独立参考；不能以“对 P 无影响”为由放弃既定科学流程。
- 节点数可保持原值，但 log 累加带来额外操作和存储，时间及整个阶段预算仍须实测；不得因新表示临时增加资源上限。失败现场应同时保留已完成 log 累加、完成掩码与实际 work，未计算区域不能假装为零。

若之后选择该方向，最少先做与正式人口不同的合成检查：一个节点指数下溢但 cell 质量可表示；正 cell raw 不可物化但 log 可保留；可解析常深度 Gaussian 的有限 log 区间质量；结构零对照；近常深度和已有原人口的完整回归。所有输入、参考能力边界与门槛必须先冻结。暂不据本文实施、不重试 R28、不修改任何失败记录，也不据表示改进推断区域/中心、V 或 GS 效果。
