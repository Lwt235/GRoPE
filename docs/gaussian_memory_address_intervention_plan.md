# address_intervention1：对应地址能否改善原生输出

2026-11-11；有界零训练诊断，承接 `memory_addressability1`。该轮已确认空间先验提高来源寻址分数，但对应来源损失和最终输出变化并不一致，因而不直接修改 writer 或 PE。

## 假设、竞争解释与决策

假设：固定槽内容中仍有可用于当前预测的信息，若让缺失查询更直接读取对应槽，原生输出会优于原读取及同程度打乱地址的读取。竞争解释：位置对应代理不代表任务有用的内容；粗 patch 或混合特征对应有误；当前 V/输出映射不能利用这种读取；输入分布外干预破坏已有协同；改善仅来自改变更新幅度或整体深度偏差，而非正确地址。

若对应地址同时优于原读法和打乱地址，得到固定通路的真值辅助可能性证据，随后才考虑可部署的读取设计；不能称高斯 PE 胜过强编码。若只比打乱好但不比原读法好，只说明错误读取有害。若两者类似或均变差，不将失败唯一归因于内容缺失，也不扫强度挽救；结束这项固定干预，保留所有历史正负结果。

## 固定范围与公式

- 12 个已用 fidelity 地点全部保留，query11。完整输入及持续遮挡；Recent/History 都是原有 256 槽，沿用已知相机和原完整输入标定。没有新场景、重建状态、训练、下载、选模或温度扫描。
- 旧 Soft-dynamic 与任务匹配的新 Soft，各三个既有种子，共六个冻结读取器。旧强 C-static、Center-dynamic、Native/Local 以及新 C/Center 作为原输出背景参照，不能将真值辅助候选与它们的差距叫公平可部署提升。
- 原生 global[11] 后的记忆残差位置、Q/K/V、输出映射和后续 VGGT 全部不变。**只干预 query11 的固定 ROI patch**，另外三个上下文视图、特殊 token、ROI 外 patch 的此层读取保留原样。
- 复用上一轮经独立核对的槽标签 U。`T[p,s]=U[p,s]/sum_s U[p,s]`。主干预用全部对应来源；History 另做只含“早期有对应而所有晚期没有”的来源标签。仅 `ROI & sum(U)>0` 的 patch 生效；无支持时严格保持原输出。局部少数像素的对应被用于整个 14×14 patch，必须作为教师不完美的边界报告。
- 保留原生 SDPA 读取值 O，以固定 `alpha=0.5` 做 `O_correct=0.5 O + 0.5 (T V)`。实际计算只改查询 patch 的读取值，随后走原 out 和后续网络；相当于理想实数算术下的注意力凸混合，不另拟合 value。
- 对照 `O_sham=0.5 O+0.5 (T_perm V)`。每片段固定一个由 ID 哈希决定的 256 槽单循环置换，没有固定点；各模型、种子、条件和策略共用，权重分布及熵严格相同，生效 patch 和混合比例相同。打乱地址可能偶然仍有对应，因此测量其实际来源分数。它并不保证与原输出的 L1 改变量或特征向量改变量完全相同；两者均报告，避免称为严格等范数对照。

每个 Recent 基例三臂：原读法、对应全部来源、打乱全部来源；每个 History 基例五臂，再加对应/打乱早期独有来源。12 地点 × 2 条件 × 2 模型族 × 3 种子 × (3+5)=**1152 份输出**，其中 288 份为原结果回放。使用原始预测缓存核对回放，全部新输出保存后独立评分。未用查询真值训练或调参，但**干预本身显式使用查询标签，不能称无真值推理或新确认**。

## 评价与检查

主指标：persistent / History 的固定 ROI 原生 log-MSE，对应全部来源分别比较原读取和打乱读取，旧 Soft 为主、新 Soft 为训练分布敏感性对照。历史独有干预单列，全 12 地点主分数保留无支持地点。

辅助：Recent、完整输入、全图/可见区 log-MSE、去均值空间误差、整体偏差平方、AbsRel、RMSE。用同一 History 状态定义各臂共享的“有来源支持 ROI 像素”“有保留早期独有支持的 ROI 像素”和“无保留来源支持的 ROI 像素”，只作辅助，明确各自地点/像素分母。注意力分数提升只验证干预是否起作用，不代替输出指标。

地点等权、种子配对，5000 次地点×种子 bootstrap、固定随机种子 20261111。报告均值、区间、地点/种子方向；不将多指标探索包装为确认。配对比较之外保留具体反例，按固定前三地点与主指标最差地点展示，不据图选方法。

检查集中在可改变结论的地方：父输入/模型身份、原输出回放、目标归一化/置换/无支持回退、干预只作用于指定 patch、保存的读取值混合及全部导出评分的独立核算。常规混合精度舍入按实际量级报告，不再扩展积分器门禁。本轮完成报告和方法取舍后结束，无自动训练后继。
