# 参考内容编码匹配：S=4 联合与 S=1 独立

2026-11-10。用户授权设为目标并执行。只新增三个固定预算拟合；所有数据为历史开发诊断，不是新确认。

## 假设与固定比较

假设：参考使用四视图联合 VGGT 特征，而查询与恢复目标使用单视图独立特征，这一内容编码方式的差异限制了当前读取器的跨场景用途。改变参考编码方式可能减少需要学习的转换。竞争解释包括：当前完整单视图token恢复目标不适合共享场景记忆、末层低秩残差接法限制、参考预测几何误差及固定数据/优化规模。S=4 与 S=1 不同不是已确定的实现错误，S=1 也可能丢失有用的多视图上下文。

三组：复用 coverage1 的宽覆盖 Wide Local（三种子，530,548参数）与 Direct-S4（三种子，531,652参数）；新增 Direct-S1（三种子，531,652参数）。S1 与 S4 使用同一个 DirectReferenceAdapter，复制完整初始权重，参数量、1200槽×2048内容、中心/协方差/有效掩码、几何位置项均相同。只替换参考内容特征。

S1构建入口只接受四张参考RGB和旧参考几何。每张图作为独立 S=1 序列运行冻结VGGT；可在batch维并行，不能在view维混入其他图。顺序仍为片段内 [0,4,8,12]，每图300patch；每token LayerNorm 后 half 存储，与 S4 相同。几何仍完全来自原 S=4 推理，不重新预测相机/深度，不读取传感器深度。查询图像、目标token不进入参考构建。可与已有独立参考帧缓存比较来源一致性，不能用查询教师构造记忆。

## 数据、训练和评价

完整复用 coverage1 的十二训练场景、十二片段、72训练查询、288遮挡样例；保留其初始权重、逐槽遮挡位置和采样序列。种子20261110/11/12，AdamW 3e-4、weight_decay .01、clip5、batch2、2000步；全patch等权归一化token MSE。采用最终步，不按评价选择模型或扫描层、损失权重、位置尺度。

主要评价仍为与训练隔离的十二地点40–52和80–92两批片段；两批单独报告，主汇总先在同地点平均片段，再十二地点等权。不能当作二十四独立地点。沿用全部46片段评价，新增训练场景的留出视角、共同训练片段、原地点被移出训练的片段及剩余一个开发场景分开报告；不能把已经转入训练的旧开发场景当作未训练数据。

主用途比较为 S1 对 Wide；S1 对 S4 检验内容编码方式的影响。全图MSE为主，同时报告遮挡、可见及完整输入改变量，提供逐种子/场景方向与配对场景×种子区间。保留冻结backbone分数，不用它取代已经训练的Wide。

S1与S4均进行正常、移除记忆和空间打乱评价。空间打乱在每张参考图的有效patch内固定随机置换特征，保持几何、有效掩码、每视图特征集合不变；同片段两模型使用同一个置换。它破坏特征与位置的绑定但仍是分布扰动，不能单独证明三维几何因果作用。Wide只作正常推理。

## 决策与范围

- S1在未训练场景可靠超过Wide，且正确空间对应有作用：支持这一参考内容选择，下一阶段可把相应表示写入紧凑高斯记忆并研究联合读写；本轮本身不证明高斯相对点记忆的优势。
- S1超过Wide但打乱对应几乎不影响：只能支持额外参考内容的用途，不能据此支持空间组织或高斯必要性。
- S1仅优于S4而仍未胜过Wide，或者差异很小/不稳定：编码方式有影响或证据不足，不推广。
- S1仍无净收益：结束当前末层单视图token恢复接法的逐项修补，重新设计共享场景记忆监督。负结果只检验这一具体替换，不能排除所有表示对齐方案，也不否定原共享记忆可学性。

固定数据/源码/配置身份，检查参考独立输入边界、几何逐值相同、初值与采样配对、有限训练、旧正常/移除评分回放及独立评分。新模型结构与读出接口未变，复用原已验证接口，不重复全套数值审计。实际查看覆盖正反例的误差图。GPU空闲优先；否则使用经实时两次检查满足空闲显存≥20GiB、利用率≤60%的单个共享进程，12GiB显存上限，不修改其他作业。全部阴性结果保留，不自动追加训练。
