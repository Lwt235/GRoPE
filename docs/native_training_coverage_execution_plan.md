# 原生任务训练覆盖对照：12到32地点，结构与计算预算固定

**完成（2026-11-12）：** 六次各2000步、4224新预测与2304继承评分、独立复算及两图审阅完成。主开发R对Local低8.76%但区间跨零；主覆盖交互有限有利，R自身误差低12.51%，其他查询/合并交互仍不确定。32地点版本保留为候选，不采用为可靠通用方法；有限目标结束，无自动后继。[完整报告](../results/gaussian_memory/native_training_coverage1/report.md)。以下为执行前固定方案与历史状态。

2026-11-12。用户已明确“设为目标并执行”，有限目标为`native_training_coverage1`。新增Local/Render各三个种子、各2000步，共六次拟合，复用12地点训练基线；完成结果分析与文档后结束，不自动继续扩大规模或调整结构。

**科学问题：** 在相同训练步数下，增加独立训练地点和不同训练样本，能否提高Render相对强Local的跨地点收益？主假设为训练覆盖限制了迁移；竞争解释包括来源内容可靠性/分布、片段特定适应、共同任务适配以及较大数据在固定步数下尚未充分学习。这里同时增加地点与样本，不能分离“纯多样性”“纯样本量”的因果贡献，也不能推断无限计算下的上限。

## 固定设计

- 原12训练地点全部保留，原12开发地点全部排除在新增训练候选之外。旧content_center1目录中，每个额外地点取字典序首个已有ID，要求前12帧RGB与深度均存在；21个合格地点按`SHA256(native_training_coverage1/place/v1/+place)`排序取20，保留1个未用地点。选择依据仅为元数据与可用性，排序与排除记录见[清单](../results/gaussian_memory/native_training_coverage1/inventory.json)。全部旧数据，不作新确认。
- 来源固定`[0,3,6,9]`，拟合查询仍`[2,5,8,11]`；完整/中央缺失两条件。新增场景使用完全相同的sensor/joint-validity初始化、2048高斯/300步来源拟合、1024维alpha绑定。旧24份场景及其内容不重建。AnySplat仅用于同样的来源预测深度、来源相机尺度与unit；新增来源不序列化未被sensor构建使用的稠密高斯输出，不改变模型输入。
- 融合仍2048→256→1024，787712参数；同样训练全部24组frame/global块与原DPT，冻结编码器/保存场景。复制同种子的原融合初值、相同预训练原生参数，AdamW、两学习率、损失、BF16运算及截断均不变。
- 32与12地点组均2000次更新、batch2，共4000次样例呈现；32地点共有256个条件样例，每样例平均呈现次数减少。Local/Render同种子使用同一32地点采样顺序。新增数据不是额外计算预算；不因结果追加步数或选中途最优模型。
- 主评价为原12开发地点、原四查询、缺失ROI centered log-MSE。主要交互`(E_R−E_L)_32−(E_R−E_L)_12`，负值有利；同时必须查看32地点组R对L的净用途和绝对误差，防止把Local变差写成Render变好。
- 新四查询`[1,4,7,10]`、八查询合并、原始误差/均值偏差、完整全图AbsRel与固定支持条件作为保留评价；32训练地点的拟合/未训练查询用于界定片段内用途。新预测六模型×(12开发+32训练)×8查询×2条件=4224；复用原12训练模型的2304份匹配结果。
- 5000次配对地点和种子重采样，固定开发地点、查询、比较和最终2000步模型；不扫描种子、GT筛选地点或新增结构。

## 结果取舍

若交互有利且32地点Render具有跨地点净收益，支持本固定预算下训练覆盖有作用，仍需之后的独立确认及O6对照。若两组共同改善但相对收益无增加，则支持普通任务适配而非覆盖解锁记忆。若只在扩入训练的片段有收益，跨地点缺口继续保留。若无改善或不确定，结束这一固定预算覆盖尝试，不外推所有数据规模无效，也不自动追加步数挽救。

## 大纲对应与历史

已核对[研究入口](research_current.md)、[对应记录](research_outline_alignment.md)、[coverage1](../results/gaussian_memory/coverage1/report.md)及[固定权重跨视角结果](../results/gaussian_memory/native_receiver_view_transfer1/report.md)。服务O4/O5、扩展O2/O3的数据实例，调整C1/C6的数据覆盖而保留构建/接收结构与训练范围；O6未检验。传感器辅助、共同有效性、给定相机尺度、静态来源、旧数据均是临时边界。

旧coverage1将同样12片段从3地点改为12地点，token代理任务中无跨地点净收益；负结果保留。本次实质变化是增加总片段/样本、实际高斯渲染内容、原生深度与完整接收训练。最新view_transfer1在同片段未训练视角低55.59%但跨地点无可靠净收益，为这一次覆盖假设提供动机，不保证其成功。不得改称首次泛化试验或把成功设为所有O6研究的通用门禁。

## 执行与身份

先建立20份新增来源与查询缓存，用原来源配方预检及原生两样例前后向确认实现/资源，再锁定源码、配置与采样并训练六次。适度核对新预测的独立评分、配对身份、权重/场景不变及实际图像；普通修复写版本化记录，不另起科学轮次。

最多三worker、最多两张有其他任务的共享卡，按实时占用准入；训练单进程11GiB上限，至少6GiB余量，资源不足只停止本任务并保存完整状态。完整优化器续训保存在本任务专用RAM目录，最终权重SHA确认后写数据盘；旧实验与其他任务不动。原始数据无需下载。
