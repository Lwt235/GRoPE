# native_gaussian_pe1：原生内容上的中心、范围与形状比较

2026-11-11。用户已授权设为目标并执行。全部数据为已用开发数据；不开放新确认数据。

## 科学问题和决策

假设：在同一份原生历史内容上，高斯区域的范围和方向提供超出强中心PE的信息，尤其在范围变化、各向异性和低重叠时。竞争解释：中心已足够；预测形状噪声抵消价值；变化只是尺度校正或增加适配容量；有限接收端适配无法利用几何。

固定四组 native / center / sphere / gaussian。所有组保留官方二维RoPE；后三组在图像patch的前60个head通道上叠加Point3R式连续三轴多基频RoPE（每轴20通道，余4通道及5个特殊token不旋转），避免64维不能按三个偶数块等分的问题。基频10/100/1000/10000，按官方实现平均四个旋转结果；不是单应矩阵HRoPE，也不是完整Point3R复现。物理协方差不进入旋转幅度。

四组共享5→16→16头偏置MLP、最后四个global块的rank8 QKV/输出LoRA，输出层零初始化。native的五输入为二维patch距离的五个不同尺度log1p平方距离；center为三维中心距离的相同五个尺度。sphere和gaussian使用已有五维关系：[距离/.2，log1p(δᵀPqδ)，log1p(δᵀPkδ)，log1p(tr(PqΣk))，log1p(tr(PkΣq))]。sphere只将每个Σ替换为tr(Σ)I/3。特殊token参与原生内容读取，其关系偏置为0。所有关系网络参数量相同，native属于额外带等容量二维关系标定的匹配适配基线，另保存未经适配的官方输出。

## 两遍预测几何与原生接收端

第一遍用冻结官方StreamVGGT逐帧因果预测深度和相机，所有组共用。逐14×14 patch反投影点求均值和总体协方差；加固定厚度方差以可逆。以首帧预测深度中位数统一归一化、首帧点均值作原点；厚度标准差为该归一化单位的0.001。源帧的几何和特征只依赖当时已见RGB，查询几何允许当前RGB但不含未来或真值深度。预测区域协方差是观测支持，不等同于估计不确定度或完整已优化3DGS。

缓存查询global[20]前的原生输入、DPT的4/11/17层查询特征，以及global[20:24]中各历史源的原生K/V和归一化输入。第二遍从global[20]开始，只适配查询读取，保留原生frame[21:24]、MLP、层尺度和DPT头。历史writer冻结，K/V的LoRA来自同一缓存输入；不跨组改内容维度、来源、数量或额外训练writer。后三层当前query特征可随读取变化，这是被检验的作用路径。当前query的临时K/V参加注意力但不写入后续查询。该实验不能代表全模型端到端训练的上限。

## 数据、训练和指标

训练沿用history_visibility_train1的12个训练片段及其地点；开发沿用native_history1的12个地点，地点隔离。训练query5/7/9/11，各用[0,1,2,3]+小于query的[4,6,8,10]作为源；开发query11使用全部八源。完整/持续遮挡两条件均保留首帧0。复用已有每query物理遮挡，不读查询标签生成遮挡；遮挡构造仍使用传感器几何，属于受控任务条件而非无标签数据。官方518×392预处理，标签及评分210×280。共96训练样本、24开发查询；另在两个固定训练片段做接口与资源检查，检查模型丢弃。

三个配对种子20261110/11/12；每组同种子相同初始化及样本顺序。默认2000步、有效batch2、AdamW lr=1e-4、weight_decay=.01、clip=5，无评价选模或提前停止。训练损失为全图有效像素原生log-MSE＋去均值log-MSE，两项等权，四组一致。仅最终步用于开发评价。资源检查若证明预算不可执行，只能在正式训练与开发比较前共同修改配置并留记录，不能按方法成绩分配预算。

主比较D−B与D−C，主终点为持续遮挡ROI原生log-MSE；同步预定ROI去均值空间误差，报告全图、偏差平方、AbsRel及完整输入。逐地点配对bootstrap，种子配对，报告均值、区间、各地点及种子方向，不把区间跨零称等效。开发总计四组×三种子×12地点×两条件=288份适配输出，另24份官方参照。

分层阈值只取训练输入几何的中位数：patch范围离散度、patch协方差各向异性、预测查询到历史中心的覆盖比例（最近距离<.1归一化单位）；不使用标签或方法成绩决定分组。分层是探索适用范围，样本小且多重比较，不独立构成确认。训练拟合、几何来源、独立指标复算和成本计量与方法效用分别报告。

D超过B/C且不是只有偏差收益：保留完整形状，后续另行固定方法并做未用数据确认；C超过B且D无额外价值：收敛到中心＋范围；仅偏差有益：限定为整体估计用途；无可靠形状增量：结束这个有限适配接法，不修公式或补种子挽救，保留既有区域任务证据。不得把阴性外推为所有高斯PE无效。
