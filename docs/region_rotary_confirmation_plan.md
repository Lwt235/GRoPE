# 固定五维关系与强旋转骨干：一次未使用地点确认

2026-11-10，在新地点目录选择和任何新像素访问前固定研究决定。沿用已完成开发及坐标检验的18个模型，零训练、零重新选模。完整五维公式、二维旋转频率、输入、损失、对应读出和刚体求解器均不改。

## 为什么现在做，以及什么决定会改变

旧开发五维对同骨干Distance、Geo PE、HRoPE及球形有正面用途信号，但相对固定H仅+1.736 pp，联合区间[−0.556,3.819]。坐标重表达后相对固定H为+1.944 pp、区间仍跨零；没有证实高斯特有稳健性。五系数cross接法和有效查询筛选没有改善结果，均保持关闭。

旧开发计划的两个主比较晋升条件没有全部满足，本方案不改写为通过，也不把重表达当新数据。此前“不得自动开启确认”的决定是要求另行论证，不能把不确定性变成无限修补旧数据的理由。现有冻结候选在两个条件下、三个种子上均对固定H呈正平均信号，主要剩余问题是地点变化下的额外用途，而非已发现的实现错误。本次是单独预定的一次独立辨别，不能借此继承旧无旋转F的十地点确认。

**假设：** 在共同二维旋转和相机输入已经提供强线索时，五维高斯关系仍能在未使用地点增加两帧对齐成功率，且该用途不依赖某一局部三维坐标表达。**竞争解释：** 旧开发收益来自有限地点、反复开发或与二维线索重叠；简单固定旋转已足够，添加高斯关系的可靠收益不成立。

若新地点上两个主比较得到支持，推进“观测高斯区域、共同相机信息、当前训练分布与求解器”这个明确范围的用途证据；仍不能声称原生3DGS或一般性研究目标完成。若固定H上的收益负或不确定，结束当前F＋旋转接法的推广主张，不再追加地点、种子、阈值或模块修补本批；保留已有区域关系证据。鲁棒条件单独解释，不以辅助指标替代基础主结果。所有结果都结束这一批确认，不进行顺序显著性停止。

## 固定模型与未使用数据

六角色为relative5、distance_mlp、geotransformer_rpe、fixed_isotropic5、predicted_hrope、fixed_hrope，各种子11/22/33。前四组来自region_rotary_relation/attempt1，HRoPE来自region_hrope_control/attempt1，固定H来自region_fixed_hrope/attempt1。全部权重、选择记录、原开发审阅及坐标检验审阅在新像素前绑定。共36组新预测和36组学习模型求解，另有恒等与不可部署GT最近中心诊断。

使用已记录的150个剩余SUN3D目录候选，排除全部56个已用或已保留地点。选择20个目录：brown 4、harvard 4、home 2、hotel 4、mit 6；home只剩2个候选，其余名额事先固定，非根据表现分配。每组按SHA256("GRoPE-region-rotary-confirmation-20261110-v1:"+place)排序取前列，之后不替换。采用20个地点而非继续增加旧种子，是为了增加独立地点覆盖；不保证统计功效或物理别名完全独立。主估计量为地点等权，而非五个目录前缀等权，不与旧地点均值拼接。

每地点使用字典序首个子扫描，原机械取帧规则不变：48个30..N−91均匀查询序号，偏移15/60，最近深度时间戳，每地点96对，共计划1920对。元数据失败原样登记且不替换地点；固定来源的暂时网络失败只重试相同URL，重试不更换子扫描。深度下载至用户指定数据盘GRoPE/region_rotary_confirmation_20261110/raw，官方SUN3D直连、不走代理，仅深度、不下载RGB。采用单连接、请求间至少1秒的低速下载，避免之前并发访问的源站问题。数据缓存存同一数据盘。

模型与评分冻结后才开放深度；一旦开始访问，全部20个选定地点保守登记为已保留，不能再次声称全新。至少两个可转换地点才计算跨地点区间；不完整必须披露实际覆盖，不能称完成全部20地点。仅沿用少于512观测点的机械排除，其他低重叠、困难或失败样本均保留。

## 两个固定输入条件与指标

base沿用CPU4的512点→64区域/32成员、共同完整高斯内容与K/xy，FP32模型batch16、TF32关闭。无需真实外参进入模型；位姿和世界中心只生成监督与评分。第二条件完全沿用region_frame_transform的ID确定性SO(3)和U(−0.5,0.5)平移、相同盐和采样次序，中心/协方差一致变换，其他观测字段不变。每视图一套变换，无扫描、重分区或测试时集成。它检验表示坐标变化，不检验新视角、遮挡或RGB扰动。

两条件的对应索引都交给原坐标中心上的同一求解器：全部64个top1、41,664三点假设、0.1 pair单位半径、至多5次非恶化重估，所有源区域中心RMSE<0.2米为成功，无解记失败。中心评分与区域监督不同，保留这个任务边界。主要报告地点等权再种子等权成功率、绝对失败率，以及RMSE/旋转/平移中位与p90；辅助报告区域R@1、全查询正确、PCK、soft EPE。恒等及GT辅助只作诊断，后者不作理论上界。

base主比较仍为F−Distance和F−固定H，补充F−Geo、F−HRoPE、F−球形，依次bootstrap种子101001–101005。reframed同序为101006–101010。每项10,000次模型种子×整地点配对重采样；不能把1920对当1920个独立地点。用途标准保持均值至少+1 pp、三个种子均正且联合95%区间下界>0，球形最低幅度为0；反向对称，其余报告不确定，跨零不证明等效。
