## 确认问题与对照

检验冻结模型在未用于开发的 SUN3D place 上是否保留相对强控制的收益，
不进行新场景适配、选模或参数修改。主要竞争解释是旧场景重复开发导致的选择偏差。

给定几何组固定为 R71 observed_target_relative5、target_distance、target_direct、
observed_urope 与 R70 observed_prope，各三个已选定种子。RGB 组仅在 R72 完成
审阅且通过原固定用途标准时进入正式确认：R72 四角色与 R70 rgb_prope，
并完整报告 rgb_raymap/rgb_hrope 作为额外相机控制。若 R72 未通过，不用新场景
挽救 RGB 开发负结果。R71 的确认仍可独立回答给定几何下的跨场景用途。

在读取新像素之前，另写不可覆盖的 evaluation_lock.json，列明所有要评分的
源码、已选定 checkpoint、评价条件和指标身份。只有验证集选择的冻结模型参加，
不按新数据得分选择种子、epoch、方法变体或超参数。全部预定结果统一导出后审阅。

主比较、条件与尺度继承 R71：base、extrapolate、target_zoom；场景等权
PSNR/SSIM/LPIPS、未裁剪 MSE、裁剪比例。确认的主用途条件仍为对四个主控制
base PSNR 三种子正向、均值至少 +0.10dB、LPIPS 均值不更差。
逐场景和种子差异完整报告；五场景区间只表达有限场景下的不确定性，
不能称大规模泛化。零学习复制/平均参照同样保留，避免将模糊输出当成成熟画质。
原生 3DGS 基元的适用性继续作为单独未完成问题，不由本确认替代。
