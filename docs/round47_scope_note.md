# R47 的先例、输入几何与解释边界

2026-11-01。R47 已完成，结果见 [实验报告](round47_conditional_gaussian_report.md)。
本文记录本轮期间的文献核对和旧 VAL 诊断；它们未改变 R47 的模型、预算、
主方案或评价标准。

## 动态高斯位置参数已有直接先例

- [Modeling Localness for Self-Attention Networks，EMNLP2018](https://aclanthology.org/D18-1475/)
  从中间表征预测高斯中心和窗口，再形成注意力偏置。
- [On the Relationship between Self-Attention and Convolutional Layers，ICLR2020，附录 E](https://arxiv.org/pdf/1911.03584)
  将非各向同性高斯注意力展开为二次相对位置函数，并报告该实验中增加
  非各向同性没有带来精度提升。这个负结果不能直接外推到所有任务，但限制了
  我们将“完整椭球”视为必然有效机制的理由。
- [SMCA，ICCV2021，§3.2](https://openaccess.thecvf.com/content/ICCV2021/papers/Gao_Fast_Convergence_of_DETR_With_Spatially_Modulated_Co-Attention_ICCV_2021_paper.pdf)
  已预测查询及头相关的二维中心和轴尺度，以高斯空间先验调制注意力。

因此，R47 的研究贡献当前只能表述为待验证的应用假设与受控比较，不能声称
首次提出动态高斯 PE。自由二次函数对照与主方法具有相同参数量及初始
一阶导数，能够检查收益是否来自一般条件化容量，而非高斯正定约束。
移除归一化常数与查询 opacity 是 softmax 行平移不变性的直接结果。

没有训练、尺度扫描、检查点选择或新确认数据。

二维与三维的 PCK8 配对计数为：同时正确 5679，仅二维正确 4183，
仅三维正确 159，同时错误 535。删除 Z 后，仅 XY 正确 1244、仅三维正确
1297，所以不能用“去掉深度轴即可修复”解释结果。

按标签的双线性权重插值预测 key 坐标，再减去预测 query 坐标，得到
对应条件下的预测坐标残差。三维残差协方差的 Z 轴方差占 87.70%，
最大/最小特征值比为 25.70。它显示各向异性，但不证明有一个固定椭球
就能恢复对应关系。这个残差使用预测锚点与对应标签，不是真值三维误差。
上述两种距离的坐标单位也不同，不能直接比较残差范数大小。

该诊断只覆盖一个旧 VAL 场景，不能代表全部场景；最近邻结果也不能代替
训练模型的评估。X/Y 控制同时删除信息并改变距离结构，不是独立的深度噪声
因果实验。运行 handle89911 已直接观察到 exit0。

## 居中三维坐标与相机投影并不信息等价

这是公式推断，不是从诊断分数拟合的新结论。令 C(X) 为减去点集均值并按
RMS 半径归一化的坐标，则对公共平移 t 有 C(X+t)=C(X)。但保持相机原点
固定的透视投影通常满足 pi(X+t)≠pi(X)。例如点 (1,0,2) 的横坐标为 1/2，
沿深度平移 2 后变成 1/4。

所以，当内容固定且位置算子只能读取这些居中坐标时，它无法对所有输入
恢复依赖相机原点的投影位置。R46/R47 的二维输入已包含投影运算的信息；
三维与二维比较同时检验坐标约定和任务适配，并非纯参数化消融。
这不抹去相同三维输入下高斯与 MLP/自由二次控制的比较，也不改变冻结的
任务实用性标准。不能据此宣称所有三维 PE 失败或现有任务完全无效。

## 后续任务边界

一般性还需要独立于相机预测深度的三维 Transformer 任务。原生点云分类是
可考察的方向；[ModelNet 官方说明](https://modelnet.cs.princeton.edu/download.html)
提供固定 train/test 划分，适合将 train 内部分出开发集、保留官方 test。
[Point Transformer，ICCV2021](https://openaccess.thecvf.com/content/ICCV2021/html/Zhao_Point_Transformer_ICCV_2021_paper.html)
提供了点云任务与位置编码的直接背景，但其局部向量注意力不能被我们的
小型全局标量注意力模型冒称为忠实复现。

目前只核对了任务来源；没有下载、训练或打开该数据集，也没有冻结新的
候选/第二任务标准。后续若采用，须在使用新数据前明确开发与确认划分，
保留当前匹配任务的全部负结果，不用另一个任务的正结果消除这些限制。
