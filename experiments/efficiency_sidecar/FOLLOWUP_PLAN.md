# 效率探索第二步：复核、拆分与单基元预计算

用户已要求执行前述三步计划，并允许与本项目训练共享 GPU。
仅新增 sidecar 文件及结果，不更改任何主训练源码、配置、数据或 checkpoint。
本轮使用旧 validation 前16对象作为重复输入池，模拟训练取样/旋转/jitter；
不是当前双来源完整训练的数据吞吐，也不是新数据确认。

## 1. 复核新几何计算

假设：在已有 factored 优化之上，新几何路径的改善超过共享时变负载造成的噪声。
竞争解释：此前小幅训练改善只是时序/共享负载影响。
固定旧 relative5 seed11，B4/N512，推理与含 AdamW 的步骤。
四个标签对应 baseline A/B（完全相同实现）和 candidate A/B（完全相同优化实现），
8块循环平衡次序；同权重、输入、随机数，每组2预热+5测量。
同时报告 A/A 差、B/B 差、每块两次均值的 A/B 差及全部原始值，不删异常块。
若优化差与重复噪声重叠，仅保留候选，不声称稳定训练加速。

## 2. 拆分实际步骤

同一旧输入池、固定32个 batch 索引/token/旋转/jitter，B4/N512。
两方法 relative5 与 Distance；原版 / factored / geometry_factored。
CPU取样、H2D、增强、共同几何特征、PE描述子、PE MLP、Transformer前向、反向、优化器分别计时。
分段同步会改变流水重叠，因此另外测不插入分段同步的整步 wall time，绝不把分段占比当作原训练精确占比。
包含损失有限性检查和 float(loss)；不包含每轮选模、checkpoint写入、双来源调度和全数据冷盘读取。

## 3. 单基元缓存原型

若拆分显示 eigh/inverse 相关几何准备有明显成本，则验证缓存 L=.5 log(Σ/.04)、P=Σ⁻¹，
旋转后复用 RLRᵀ/RPRᵀ；中心 jitter 后成对关系仍实时计算。
共同 log 协方差缓存公平用于两个方法；inverse 缓存仅在 relative5 中需要。
缓存仍是FP64，不改变floor、网络、损失。明确验证旋转误差、描述子/输出/参数梯度。
先CPU正确性，再共享GPU上的私有副本数值与整步成本，计入额外缓存取样/传输/旋转。
分别报告一次性预计算、常驻缓存字节、摊销步数与热缓存局限。
若数值影响显著或完整步骤无收益，保留负结果，不接入主任务。

资源：一张仅有已记录本项目训练的卡，6 GiB分配上限，单CPU线程，nice15，短组间休息。
新进程占卡或空闲显存低于8GiB则停止自身；主任务不暂停。
所有结果属于共享卡工程开发证据，不是独占性能定稿或科学精度确认。
