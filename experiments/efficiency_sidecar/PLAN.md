## 本次问题与比较

假设：保持五维关系和模型参数不变，二次型的矩阵乘法展开能减少几何计算成本；
结合已有 query 投影重排，可降低端到端执行成本。
竞争解释：FP64 运算、消去误差、MLP/attention 主导，或小矩阵调度开销，使收益消失。

固定比较：原版、已有 factored 实现、新几何展开 + factored。
同时比较 Distance 和 fixed_isotropic5；球形控制直接构造径向特征，避免计算后丢弃协方差关系。
所有对照使用自己的原 checkpoint；不改变内容特征、注意力、输入规模或精度。
新实现先只支持原生分类，几何作为固定输入，不声称支持学习几何或 RGB。

输入：可再生成的合成 SPD 数据；原 R65 已用 validation 的前 16 对象及前 512 基元；
尺寸诊断使用同批旧对象的前 64/128/256/512/1024 基元。仅旧 seed11 模型。
不读取当前来源多样性实验的效果分数，不访问新的确认数据。

## 分阶段执行

1. 低优先级单线程 CPU：描述子、全部参数梯度及旧权重输出核对；
   报告尺度/条件数/近重复中心的数值敏感性，不靠放宽阈值掩盖失败。
2. 同输入 CPU 微基准只用于筛选实现，不推断 GPU 加速。
3. GPU 基准必须显式启动并检查整卡空闲；主训练仍排队或后处理未结束时不启动。
   不在共享卡上跑、不后台自动抢占空闲卡。整模型推理、前后向与含 AdamW 的步骤分别测量；
   只更新私有内存副本，不保存或替换科学训练权重。公平应用优化到强对照。
4. 记录延迟、显存、数值误差、规模曲线及适用限制。几何和完整模型加速分开报告。

决定：若数值影响可接受且端到端收益成立，给主任务提供可选适配器和证据，
不自动替换本轮已冻结训练；若仅省内存/仅 CPU 快/数值失败，明确保留局限。
不把正确性检查称为科学效果确认，不将既有 factored 成果当作本次新发现。
