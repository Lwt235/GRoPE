# 反向计算优化：有界独立实验

用户要求执行算子定位→单项优化→完整步骤及短程验证。
保持相同五维公式、FP32网络/FP64几何、参数、初始化和损失，不改主训练。
基线为已有投影重排+新几何计算；以旧seed11 checkpoint及旧validation前16对象作工程输入。
本轮没有科学效果确认或新数据访问。

1. 在旧输入 B4/N512 上先做算子级 GPU profile，区分大矩阵乘法、布局复制、梯度累加和激活。
   profiler开销只用于定位，不用其总时间宣称实际加速；同时分析 relative5 和 Distance。
2. 根据profile选择一个结构不变的优化，优先减少关系隐藏量的布局复制和重复梯度物化。
   若已为高效算子，则保留无明显空间的结论，不堆叠多个未证实方案。
3. FP64/FP32 CPU及GPU上核对输出和全参数梯度；若通过，固定实现比较完整步骤。
   两个角色公平适配；B4/N512，旧16对象热池，固定取样/旋转/jitter，同权重与随机数。
   8块平衡交错，加入同实现重复标签，报告时间漂移，不删不利测量。
4. 若有明确净收益，用私有副本做64步配对短程训练，记录loss/梯度有限性与轨迹差异。
   短程检查只排查失稳，不替代正式完整训练和准确率确认；不写科学checkpoint。

一张仅与本项目任务共享的GPU；6GiB分配上限、1CPU线程、nice15、组间让出时间。
每GPU阶段最多10分钟，出现未知进程或显存不足则停止自身。主任务不暂停。
共享时延仍不是论文最终独占结果。代码与结果仅在sidecar及其backward1目录。
